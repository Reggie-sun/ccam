Самый простой способ запускать несколько аккаунтов Claude Code: отдельный псевдоним оболочки (alias) для каждого аккаунта. ccam внутри делает то же самое и добавляет общий доступ, переключение и отслеживание использования.

| | Псевдоним оболочки | ccam |
| --- | --- | --- |
| Отдельные входы | Да | Да |
| Настройка каждого аккаунта | Правка `~/.bashrc`, вход | `ccam add` |
| Работает в скриптах и других программах | Нет, псевдонимы есть только в оболочке | Да, `ccam work` и короткие команды вроде `ccwork` являются настоящими командами |
| Общие настройки, `CLAUDE.md`, расширения | Копировать или связывать вручную | По элементам, с резервными копиями |
| Общие MCP-серверы | Вручную, для каждого аккаунта | Один раз `ccam mcp add` |
| Продолжить разговор в другом аккаунте | Нет | `ccam next --continue` |
| Использование всех аккаунтов | Нет | `ccam usage` |
| Выбрать аккаунт с наибольшим запасом | Нет | `ccam next --auto` |
| Имя аккаунта в строке состояния | Нет | `ccam statusline install` |
| Исправление сломанных ссылок | Вручную | `ccam doctor --fix` |
| Дополнительное ПО | Нет | Один статический исполняемый файл |

Выбирайте псевдонимы, если у вас два аккаунта и между ними не нужно ничего делить. Выбирайте ccam, если хотите, чтобы аккаунты работали как единая настройка. Можно начать с псевдонимов и позже перейти на ccam: `ccam import` регистрирует существующие папки `~/.claude-*` там, где они находятся.

В руководстве [Как использовать два аккаунта на одном компьютере](/guides/multiple-claude-code-accounts) оба подхода описаны пошагово.
