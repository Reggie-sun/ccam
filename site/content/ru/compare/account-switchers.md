Инструменты для переключения аккаунтов Claude Code используют один из двух подходов. Большинство подменяют данные входа внутри единственной папки `~/.claude`, поэтому одновременно активен только один аккаунт. Другие, в том числе ccam, дают каждому аккаунту собственную папку через `CLAUDE_CONFIG_DIR`, поэтому все аккаунты остаются авторизованными и несколько из них могут работать одновременно. ccam добавляет к этому общие настройки и MCP-серверы и умеет продолжить разговор в папке другого аккаунта.

## Подменять один вход или завести отдельные папки?

**При подмене входа** остаётся один набор настроек, MCP-серверов и истории, потому что папка всего одна. Переключение происходит быстро, и работающий сеанс может подхватить новый вход. Но активен только один аккаунт за раз, сразу для всех терминалов и редакторов.

**Отдельные папки** — это способ, [описанный в документации Claude Code](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts). Каждый аккаунт остаётся авторизованным, и можно запустить рабочий и личный сеансы рядом. Цена в том, что у каждой папки изначально свои настройки, MCP-серверы и история, если только инструмент не сделает их общими.

## Сравнение инструментов

Данные взяты из документации каждого проекта 19 октября 2026 года. «Не описано» значит, что проект об этом не сообщает, а не что функции нет.

| Инструмент | Подход | Несколько аккаунтов одновременно | Использование за 5 часов и за неделю | Когда достигнут лимит | Платформы |
| --- | --- | --- | --- | --- | --- |
| ccam | Отдельные папки | Да | Да, `ccam usage` | Вы выполняете `ccam next --auto --continue`, чтобы продолжить разговор в аккаунте с наибольшим запасом | Linux, macOS, WSL |
| [claude-swap](https://github.com/realiti4/claude-swap) | Подменяет вход; отдельные папки через `cswap run` | Да, через `cswap run` | Да | `cswap auto` переключает вход при достижении порога; работающий сеанс продолжается | Linux, macOS, Windows |
| [CCS](https://github.com/kaitranntt/ccs) | Отдельные папки | Да | Частично, в приложении для строки меню macOS | Пулы аккаунтов передают запросы следующему аккаунту через локальный прокси | Linux, macOS, Windows |
| [clauth](https://github.com/uwuclxdy/clauth) | Подменяет вход; отдельные папки через `clauth start` | Да, через `clauth start` | Да | Переключается по цепочке резервных аккаунтов | Linux, macOS, Windows |
| [CAAM](https://github.com/Dicklesworthstone/coding_agent_account_manager) | Подменяет вход или изолированные профили | Да, с изолированными профилями | Да | `caam run` повторяет неинтерактивные команды в другом аккаунте | Linux, macOS, Windows |
| [cux](https://github.com/inulute/cux) | Подменяет вход и оборачивает `claude` | Не описано | Да | Подменяет вход и возобновляет тот же разговор | Linux, macOS, Windows |
| [CCSwitcher](https://github.com/XueshiQiao/CCSwitcher) | Подменяет вход | Нет | Да | Не описано | macOS |
| [Claude Switcher](https://github.com/Symbioose/claude-account-switcher) | Подменяет вход | Нет | Да | Переключение при 100% по желанию | macOS |

ccswap — это форк claude-swap, который также управляет входами в Codex. Некоторые из этих инструментов работают и с другими агентами для программирования, например Codex или Gemini.

## На чём сосредоточен ccam

- Каждый аккаунт остаётся авторизованным. Переключение никогда не выполняет выход, а `ccam work` и `ccam personal` могут работать в двух терминалах одновременно.
- MCP-серверы, `settings.json`, `CLAUDE.md`, агенты, навыки и плагины становятся общими для папок через ссылки, отдельно для каждого элемента и каждого аккаунта. Данные входа общими не бывают никогда.
- С общей историей одна команда, `ccam next --auto --continue`, открывает тот же разговор в папке аккаунта с наибольшим запасом.
- ccam запускает Claude Code и заменяет себя им, поэтому в фоне ничего не работает. Он не следит за вашим использованием и не переключается сам; когда переключаться, решаете вы.

## В чём другие инструменты умеют больше

- claude-swap, CCS, clauth, CAAM и cux работают в Windows без WSL. ccam так не умеет.
- claude-swap, clauth и cux переключаются сами, когда аккаунт превышает порог использования. ccam оставляет переключение вам.
- CCSwitcher, Claude Switcher и claude-swap показывают использование в строке меню macOS.
- CCS, CAAM, ccswap и Claude Switcher также управляют Codex и другими агентами для программирования.

## Что вам подойдёт?

Выберите инструмент с подменой входа, если вы пользуетесь одним аккаунтом за раз, хотите, чтобы переключение происходило автоматически, или работаете в Windows без WSL. Выберите ccam, если вам нужны аккаунты, работающие рядом, одна общая настройка и тот же разговор в следующем аккаунте. Если ничего общего не нужно, достаточно [обычных псевдонимов оболочки](/compare/aliases).

Можно ли использовать несколько аккаунтов, зависит от условий каждого аккаунта. Проверьте их заранее.
