ccam представляет собой небольшую консольную утилиту для тех, кто использует больше одного аккаунта Claude Code на одном компьютере: личный и рабочий аккаунт или несколько аккаунтов для одного долгого проекта.

## Проблема

Claude Code поддерживает несколько аккаунтов через `CLAUDE_CONFIG_DIR`: по одной папке на аккаунт. На практике каждая папка оказывается островом. Настройки, `CLAUDE.md`, MCP-серверы, агентов и навыки приходится настраивать заново в каждой папке и вручную поддерживать в одинаковом состоянии. Разговоры остаются там, где начались. А о том, что аккаунт достиг лимита использования, вы узнаёте, только попробовав им воспользоваться.

## Что делает ccam

- `ccam add` создаёт папку, выполняет вход и, если хотите, даёт аккаунту короткую команду с выбранным вами именем, например `ccwork`.
- `ccam work` и `ccwork` запускают Claude Code от имени этого аккаунта и передают все аргументы без изменений.
- MCP-серверы, настройки, `CLAUDE.md` и расширения становятся общими через ссылки, отдельно для каждого элемента и каждого аккаунта. Данные входа никогда не бывают общими.
- `ccam usage` показывает использование за 5 часов и за неделю для каждого аккаунта; `ccam next --continue` продолжает разговор в следующем аккаунте.

## Не мешать в работе

Утилита, которую вы запускаете перед каждой сессией, не должна заметно отнимать время. ccam читает один файл конфигурации, проверяет каждую общую ссылку одним системным вызовом и затем заменяет себя на `claude`. Это добавляет около 4 миллисекунд, и во время вашей работы ccam не запущен.

Кроме того, ccam бережно обращается с вашими файлами. Каждое изменение общего доступа сначала выводит план и сохраняет оригиналы в папке резервных копий. `ccam doctor` проверяет ссылки, права доступа и входы и исправляет то, что можно исправить безопасно.

## Попробуйте

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add
```

ccam является открытым и неофициальным проектом: он не связан с Anthropic и не одобрен ею. Можно ли использовать несколько аккаунтов, зависит от условий каждого аккаунта. Отзывы и переводы приветствуются на [GitHub](https://github.com/jhyunwoo/ccam).
