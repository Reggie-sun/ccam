`ccam` без аргументов открывает полноэкранную панель, если стандартный ввод и вывод подключены к терминалу; в остальных случаях он выводит `ccam list`. Панель показывает каждый аккаунт с его использованием и группами и делает то же, что и команды: запускает, добавляет, выполняет вход, меняет группы, задаёт правила папок, показывает фоновые сессии, проверяет и исправляет. При запуске или подключении к фоновой сессии она закрывается; при добавлении аккаунта или входе она уступает терминал и затем возвращается.

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Agents   Groups   Folders   Extensions   Health
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

Строка под названиями вкладок одним предложением говорит, для чего нужна текущая вкладка. В более широком терминале вкладка Accounts также показывает email каждого аккаунта.

При каждом открытии панель в фоне спрашивает у GitHub, есть ли более новый выпуск ccam; первый кадр никогда его не ждёт, а без сети ничего не показывается. Если выпуск есть, строка под заголовком рекомендует его:

```console
 ● ccam 0.10.2 is available (you have 0.10.1) · press U to update
```

`U` сначала спрашивает, а затем обновляет так же, как [`ccam update`](/features/update): выпуск проверяется по его контрольным суммам SHA-256 и заменяет ccam за один шаг. Открытая панель всё ещё работает в старой версии, поэтому выйдите и запустите `ccam` снова. Если обновить здесь нельзя, например для ccam, установленного из пакета `.deb`, панель показывает тот же совет, что и `ccam update`, и сохраняет предложение.

Первый кадр рисуется только по `config.toml`, гораздо быстрее чем за 100 мс; данные об использовании появляются по мере того, как отвечает каждый аккаунт. У каждого лимита своя полоса: 5-часовое окно, недельное окно для всех моделей и собственное недельное окно Fable; `-` означает, что у аккаунта такого окна нет. Процент становится жёлтым от 80% и красным на 100%, а значения из кэша после неудачного запроса рисуются бледным цветом. Окно, которое Claude Code сообщил заполненным, показывает 100% до своего сброса. Истёкший токен доступа показывается бледным `⚠ token expired` (Claude Code обновит его при следующем запуске), а `⚠ login expired` означает, что аккаунту нужен `ccam login`.

## Вкладки

| Вкладка | Что она показывает | Клавиши |
| --- | --- | --- |
| Accounts | номер, имя, email, полосы 5-часового, недельного окна и Fable, последнее использование, группы; `✔` аккаунт по умолчанию, `▸` аккаунт этой папки, `•` запущен (в том числе Claude Code, запущенный без ccam: обычный `claude`, IDE, фоновые сессии и их демон) | ниже |
| Agents | то, что показывает [`ccam agents`](/features/agents): фоновые сессии и открытые сессии каждого аккаунта с их состоянием, папкой и временем запуска (ниже) | `enter` подключиться (как `ccam attach`), `x` остановить, `r` перезагрузить |
| Groups | каждую группу, что она делит и её аккаунты, а также аккаунты без группы | `enter` изменить, `n` новая, `e` переименовать, `x` удалить |
| Folders | правила [`ccam folder`](/features/folder) и правило, которое действует здесь, в том числе когда вы попали в папку через символическую ссылку (новые правила сохраняются с раскрытыми ссылками) | `n` использовать аккаунт здесь, `enter` изменить, `x` удалить |
| Extensions | то, что показывает [`ccam ext`](/features/ext), каждое расширение один раз вместе с группами, из которых оно берётся, `off:` — аккаунты, в которых плагин не включён, серверы, которые есть у аккаунта только для этой папки, среди его собственных, `This folder's project` и проблемы, не относящиеся ни к одному аккаунту | `r` перезагрузить |
| Health | то, о чём сообщает [`ccam doctor`](/features/doctor), в виде рамки для каждого аккаунта (ниже) | `f` исправить выбранную рамку, `F` исправить всё (`doctor --fix`), `↑`/`↓` перейти между рамками |

`←`/`→` или `Tab` переключают вкладки, `?` показывает клавиши текущей вкладки, `r` заново запрашивает использование, минуя короткий кэш, и заново загружает вкладки Agents, Extensions и Health, а `q` или `Esc` закрывают панель.

## Клавиши на вкладке Accounts

| Клавиша | Действие |
| --- | --- |
| `Enter` | Запустить Claude Code от имени выбранного аккаунта |
| `1`–`9` | Перейти к аккаунту с этим номером; для 12 быстро наберите `1` `2`. Запускает только `Enter` |
| `↑`/`↓`, `k`/`j` | Перемещение |
| `n` | Запустить аккаунт, который выбрал бы [`ccam next --auto`](/features/next) |
| `o` | Запустить с параметрами: `--continue`, `--resume`, другие аргументы или пробный запуск |
| `u` | Подробности использования: 5-часовое, недельное и модельные окна с временем сброса и источником данных |
| `a` | Добавить аккаунт (мастер ниже) |
| `l` | Снова войти |
| `s` | Выбрать группы аккаунта |
| `d` | Сделать его аккаунтом по умолчанию |
| `f` | Использовать его в текущей папке |
| `e` | Переименовать его |
| `c` | Задать или удалить его короткую команду |
| `x` | Удалить его (сначала спрашивает, курсор стоит на No) |

**Места в тарифах Team и Enterprise.** При автоматическом выборе (`ccam next`, `--fallback`, `ccam pick`, клавиша `n` на панели, а также [`auto_switch`](/features/next#auto-switch), если вы его включите) ccam переключается и между местами одной и той же организации Claude Team или Enterprise. В справочном центре Anthropic ([тарифы Team](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129); аналогично для [тарифов Enterprise](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0)) сказано: «Each seat on a Team plan is assigned to one named individual, and only that person may use it» (каждое место в тарифе Team закреплено за одним конкретным человеком, и пользоваться им может только этот человек) и «Users can't route their work through another user's account to use that user's remaining usage» (пользователи не могут направлять свою работу через аккаунт другого пользователя, чтобы расходовать оставшийся лимит этого пользователя). Поэтому использование автоматического выбора между местами может нарушать условия Anthropic. Пользоваться ли им в этом случае, решать вам: прежде чем на него полагаться, уточните это у своей организации и у Anthropic. О личных тарифах (Pro, Max) см. [примечание об условиях в FAQ](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts).

## Вкладка Health

Вкладка Health при открытии выполняет проверки [`ccam doctor`](/features/doctor) и рисует тот же вид: первую строку с отметкой для каждого аккаунта, затем рамку для каждого аккаунта. Каждая строка в рамке соответствует одной проверенной области, сначала `Folder`, `Login` и `Share links`, с отметкой `✔` всё в порядке, `ℹ` информация, `⚠` предупреждение или `✘` ошибка, поэтому вы сразу видите, у какого аккаунта проблема и где. Результаты, не относящиеся ни к одному аккаунту, попадают в рамку `General`.

```console
 ✘ personal   ⚠ work

 ╭─ ✘ personal · 3 problems ─────────────────────────────────────────────────╮
 │ ⚠ Folder       folder permissions are 755 (should be 0700)                │
 │ ℹ              unknown entries (ccam knows the folder layout of Claude    │
 │                Code 2.1.309; it may have changed): newthing               │
 │ ⚠ Login        .credentials.json permissions are 644 (should be 0600)     │
 │ ✔              login valid (me@example.com, Claude Team · Acme)           │
 │ ✘ Share links  /home/me/.local/share/ccam/profiles/personal/settings.json │
 │                : set to shared but is a real file, not a link             │
 │ ✔ Usage        usage lookup OK                                            │
 ╰───────────────────────────────────────────────────────────────────────────╯
 ╭─ ⚠ work · 1 problem ──────────────────────────────────────────────────────╮
 │ ✔ Folder       OK                                                         │
 │ ⚠ Login        not logged in → `ccam login work`                          │
 │ ✔ Share links  share links OK                                             │
 ╰───────────────────────────────────────────────────────────────────────────╯

 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` переходят от рамки к рамке, а выбранная рамка выделяется акцентным цветом. `f` исправляет только выбранную рамку так же, как это сделал бы `ccam doctor --fix`: в рамке аккаунта исправляется только этот аккаунт, а в рамке `General` — результаты, не относящиеся ни к одному аккаунту (пути плагинов и короткие команды); все остальные аккаунты только проверяются заново. Сначала он спрашивает (``Like `ccam doctor --fix`: missing links and group folders are made, and a real file where a link belongs is backed up first; where the group has its own copy, the account then sees the group's. Nothing is lost.``), а для рамки, в которой нечего исправлять, просто сообщает `nothing to repair in <name>`. `F` исправляет всё сразу, как `ccam doctor --fix`, а `r` проверяет заново.

## Вкладка Agents

Вкладка Agents показывает то, что выводит [`ccam agents`](/features/agents): фоновые сессии и открытые сессии каждого аккаунта вместе с аккаунтом, которому принадлежит каждая из них. Она опрашивает Claude Code всех аккаунтов одновременно (`claude agents --json`, до 15 секунд на каждый) при первом открытии вкладки, по `r`, после остановки сессии и после изменения конфигурации и показывает `Asking every account's Claude Code for its sessions…`, пока не ответят все.

```console
  Accounts   Agents   Groups   Folders   Extensions   Health
 Background agents and open sessions of every account; enter attaches to one.

    Account   ID        Name   State          Folder      Started
 ❯  work      -         -      open (busy)    ~/code/web  now
    personal  49ec0028  probe  blocked, idle  ~/code/app  12m

 ✘ lab: could not list its sessions: exit status 1 'claude agents --json' is
   not available in this environment.

 enter to attach · x to stop · r to reload · ? for shortcuts
```

`State` показывает состояние фоновой сессии и то, чем занят её процесс, или `open` для интерактивной сессии, как в `ccam agents`. Аккаунт, который не удалось опросить, получает под списком строку `✘` с тем, что ответил Claude Code, как `lab` выше, у которого выключен просмотр агентов. Завершённые фоновые сессии не показываются (их выводит `ccam agents --all`), а если ответили все аккаунты и ни у одного нет сессий, вкладка сообщает ``No sessions. Start one in the background with `ccam <account> --bg "…"`.`` В узком терминале вкладка сначала убирает `Started`, затем `Name`, затем `Folder`, а длинный путь папки обрезает слева.

`Enter` на фоновой сессии закрывает панель и открывает сессию в этом терминале от имени её аккаунта, как это делает `ccam attach <id>`; панель не возвращается (в Claude Code `←` ведёт в просмотр агентов, а `Ctrl+Z` в оболочку). У открытой сессии нет идентификатора, поэтому `Enter` и `x` лишь сообщают, что нужна фоновая сессия. `x` сначала спрашивает, с курсором на `No, keep it`: ``It runs as personal. Like `ccam personal stop 49ec0028`, Claude Code stops it and keeps its conversation, which `ccam attach 49ec0028` opens again.`` При ответе «да» ccam выполняет `claude stop <id>` от имени этого аккаунта, сообщает ``49ec0028 (personal) stopped; `ccam attach 49ec0028` opens it again`` или почему остановить не удалось и заново читает список.

## Изменение групп

На вкладке Groups `Enter` открывает редактор: элементы слева, аккаунты справа, `Tab` переключает между ними, `Space` отмечает. Элемент, который один из аккаунтов уже получает из другой группы, показывается серым с указанием причины, как и аккаунт, который получил бы элемент дважды; элемент может браться только из одной группы. `Enter` показывает план:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

Сначала задаётся вопрос про каждый файл, который отличается от копии группы (оставить версию группы, взять свою или объединить). Затем изменение выполняется в фоне тем же кодом, что и [`ccam group`](/features/share): сначала сохраняется конфигурация, данные каждого аккаунта перемещаются по порядку, а оригиналы попадают в `.ccam-backup/`; аккаунт, который выходит из общего доступа к MCP, сохраняет серверы группы в своём `.claude.json`. Изменение, которое переместило бы данные запущенного аккаунта, отклоняется с указанием имени аккаунта, в том числе когда аккаунт запустили, пока план был открыт, а план, устаревший из-за изменения групп в другом ccam, отклоняется с сообщением `the groups changed while this plan waited; nothing was moved, make the change again`. Пока другой ccam меняет группы, новое изменение, переименование или удаление сообщает `another ccam is changing the groups right now`; после изменения, остановившегося на полпути, они ждут, пока его не завершит `F` на вкладке Health (или `ccam doctor --fix`).

## Добавление аккаунта

`a` открывает мастер, который `ccam add` использует и в терминале:

1. Имя аккаунта.
2. Способ входа: подписка Claude сейчас (в браузере), [ключ API](/features/api) или подписка Claude позже.
3. Для ключа API: откуда ccam читает ключ при каждом запуске (`env:NAME` или `command:COMMAND`), адрес, способ передачи ключа и модель.
4. Группы, в которые нужно вступить, с отмеченной `default`; пока групп нет, показывается, что будет делить группа `default`.
5. Короткая команда, если она вам нужна.
6. Сводка для подтверждения.

`Esc` возвращает на шаг назад, а на первом шаге закрывает мастер.

## Удаление аккаунта

`x` спрашивает, прежде чем что-либо произойдёт, с курсором на No, и сообщает, что сделает удаление: `It is logged out first (its login is revoked), then its folder goes to ccam's trash; the groups' shared files stay.` Для аккаунта с ключом API отзывать нечего, а если тот же вход есть у другого аккаунта, выход не выполняется. Импортированный аккаунт сохраняет свою папку: `It was imported, so its folder /home/me/.claude stays where it is: it leaves its groups first and keeps a copy of what they share, then ccam forgets it.`

## Цвета

Цвета следуют ролям интерфейса Claude Code в терминале, поэтому ccam выглядит рядом с ним естественно; имена групп получают цвет по своему имени. ccam запрашивает у терминала цвет фона и выбирает светлую или тёмную тему. Задать тему самостоятельно можно в начале `config.toml`, над первым `[[group]]`, `[[profile]]` или `[[folder]]`:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

Темы `-daltonized` предназначены для людей с красно-зелёной цветовой слепотой, а темы `-ansi` используют собственные 16 цветов терминала. `NO_COLOR` отключает цвета.

## Безопасность и особые случаи

- Панель вызывает те же функции, что и команды, поэтому действуют все правила: планы до перемещения данных, отказы для запущенных аккаунтов, резервные копии и токены входа, которые никогда не покидают аккаунт.
- В панели нет пробного режима: `ccam --dry-run` без имени выводит, как запустился бы аккаунт этой папки, а `o` на аккаунте предлагает пробный запуск только для этого одного старта.
- Терминал восстанавливается до запуска Claude Code или открытия входа.
- Если экран слишком мал для диалога, сначала убираются строки вкладки; строки обрезаются с `…`, а не переносятся. На низком экране затем убираются пустые строки и описание вкладки, чтобы строка клавиш осталась. При ширине меньше 40 столбцов или высоте меньше 8 строк панель показывает только `Too small: ccam needs 40x8 (now 36x7)`.
- `Ctrl+C` во время применения изменения, удаления, обновления или исправления ждёт его завершения: строка состояния сообщает `ccam quits when it is done.`
- После того как `U` обновил ccam, предложение не появляется снова, когда панель возвращается после добавления аккаунта или входа.
