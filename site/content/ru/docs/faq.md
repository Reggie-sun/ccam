## Является ли ccam официальным инструментом Anthropic?

Нет. ccam является неофициальным проектом с открытым исходным кодом, он не связан с Anthropic и не одобрен ею. Он использует параметр `CLAUDE_CONFIG_DIR`, который Claude Code документирует для одновременной работы нескольких аккаунтов.

## Разрешено ли мне использовать несколько аккаунтов Claude Code?

Это зависит от условий каждого аккаунта, а для рабочих аккаунтов также от политики вашей организации. Проверьте их, прежде чем использовать несколько аккаунтов. ccam лишь упрощает переключение между аккаунтами, которые у вас уже есть.

## Позволяет ли ccam обойти лимиты использования?

Нет. У каждого аккаунта остаются свои лимиты. ccam показывает их и позволяет продолжить работу в другом вашем аккаунте, когда в одном лимит исчерпан.

## Как использовать два аккаунта Claude Code на одном компьютере?

Дайте каждому аккаунту собственную папку конфигурации с помощью `CLAUDE_CONFIG_DIR`. ccam делает это за вас: выполните `ccam add` для каждого аккаунта, затем запускайте их командами `claude1` и `claude2`. В [руководстве](/guides/multiple-claude-code-accounts) также показано, как сделать это вручную.

## Как продолжить разговор в другом аккаунте?

Сделайте историю разговоров общей для двух аккаунтов командой `ccam share <name> --history on`, затем выполните `ccam next --continue`. Claude Code откроет в следующем аккаунте последний разговор текущей папки.

## Видит ли ccam мои данные входа и отправляет ли их куда-либо?

ccam никогда не копирует данные входа и не делает их общими. Он читает токен доступа аккаунта только для того, чтобы запросить у эндпоинта использования Anthropic данные об использовании этого аккаунта, когда вы выполняете `ccam usage`, `ccam next --auto` или `ccam doctor`. У ccam нет телеметрии, и больше он никуда ничего не отправляет.

## Где хранятся мои аккаунты?

В `~/.local/share/ccam/profiles/<name>/`, по одной папке на аккаунт. В macOS сами данные входа Claude Code хранит в Связке ключей, под именем, производным от этой папки.

## Что будет с моей существующей папкой ~/.claude?

Ничего, если вы не выполните `ccam import`. Импорт регистрирует папку там, где она находится, поэтому обычный `claude` и `ccam <name>` продолжают использовать тот же аккаунт и те же настройки.

## Какие системы поддерживает ccam?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine и другие) и macOS. В Windows используйте его внутри WSL.

## Почему MCP-сервер виден только в одном аккаунте?

Серверы, добавленные внутри сессии командой `claude mcp add`, сохраняются только для этого аккаунта. ccam сообщит об этом при следующем запуске аккаунта; перенесите сервер в общую группу командой `ccam mcp import <account> <server>`.

## Замедляет ли ccam работу Claude Code?

Запуск Claude Code через ccam добавляет около 4 миллисекунд; это измерено с помощью `scripts/perf-check.sh` на ноутбуке. ccam читает один небольшой файл, проверяет общие ссылки и затем заменяет себя на `claude`, поэтому во время вашей работы он не запущен.

## Как удалить ccam?

Удалите `ccam` и ссылки `claude1`… из `~/.local/bin`, а затем `~/.config/ccam`, `~/.local/share/ccam` и `~/.local/state/ccam`, если аккаунты вам больше не нужны. См. раздел [установка](/docs/install#uninstall).
