## Является ли ccam официальным инструментом Anthropic?

Нет. ccam является неофициальным проектом с открытым исходным кодом, он не связан с Anthropic и не одобрен ею. Он использует параметр `CLAUDE_CONFIG_DIR`, который [Claude Code документирует](https://code.claude.com/docs/en/env-vars) для одновременной работы нескольких аккаунтов.

## Разрешено ли мне использовать несколько аккаунтов Claude Code?

Это зависит от условий каждого аккаунта, а для рабочих аккаунтов также от политики вашей организации. Проверьте их, прежде чем использовать несколько аккаунтов. ccam лишь упрощает переключение между аккаунтами, которые у вас уже есть.

## Позволяет ли ccam обойти лимиты использования?

Нет. У каждого аккаунта остаются свои лимиты. ccam показывает их и позволяет продолжить работу в другом вашем аккаунте, когда в одном лимит исчерпан.

## Как использовать два аккаунта Claude Code на одном компьютере?

Дайте каждому аккаунту собственную папку конфигурации с помощью `CLAUDE_CONFIG_DIR`. ccam делает это за вас: выполните `ccam add` для каждого аккаунта, затем запускайте их командами `ccam personal` и `ccam work` или короткими командами с выбранными вами именами, например `ccwork`. В [руководстве](/guides/multiple-claude-code-accounts) также показано, как сделать это вручную.

## Как продолжить разговор в другом аккаунте?

Сделайте историю разговоров общей для аккаунтов командой `ccam group set default --add history` (или заведите для них отдельную группу: `ccam group add pair --items history --members work,side`), затем выполните `ccam next --continue`. Claude Code откроет в следующем аккаунте последний разговор текущей папки.

## Видит ли ccam мои данные входа и отправляет ли их куда-либо?

ccam никогда не делает ваши данные входа Claude общими для аккаунтов. Он читает токен доступа аккаунта только для того, чтобы запросить у эндпоинта использования Anthropic данные об использовании этого аккаунта, когда вы выполняете `ccam usage`, `ccam next --auto` или `ccam doctor`. `ccam migrate` копирует сохранённые данные входа MCP-серверов из `~/.claude` в собственные файлы входа ваших аккаунтов на том же компьютере. У ccam нет телеметрии. Кроме этих запросов, единственный запрос, который он делает сам, — это вопрос панели к GitHub о последнем выпуске ccam, и в нём нет ничего о вас или ваших аккаунтах.

## Как войти на удалённом сервере?

Выполните `ccam add` или `ccam login <name>` в SSH-сеансе как обычно. Claude Code ждёт входа на сервере, поэтому браузер на вашем компьютере в итоге открывает страницу `http://localhost:<port>/callback?code=…`, которая не загружается. Скопируйте этот адрес из браузера и вставьте его в терминал: ccam передаст его Claude Code на сервере, и тот завершит вход. Адрес содержит одноразовый код, поэтому никому его не передавайте.

## Где хранятся мои аккаунты?

В `~/.local/share/ccam/profiles/<name>/`, по одной папке на аккаунт. В macOS сами данные входа Claude Code хранит в Связке ключей, под именем, производным от этой папки.

## Что будет с моей существующей папкой ~/.claude?

Ничего, если вы не выполните `ccam import` или `ccam migrate`. Импорт регистрирует папку там, где она находится, поэтому обычный `claude` и `ccam <name>` продолжают использовать тот же аккаунт и те же настройки. `ccam migrate` копирует её настройки, `CLAUDE.md`, расширения и MCP-серверы в общие настройки и только читает папку.

## Какие системы поддерживает ccam?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine и другие), macOS и Windows 10 и 11, нативно или внутри WSL. В Windows для общего доступа к файлам, например `settings.json`, нужен режим разработчика; общие папки работают и без него ([общий доступ в Windows](/features/share#on-windows)).

## Почему MCP-сервер виден только в одном аккаунте?

Серверы, добавленные внутри сессии командой `claude mcp add`, сохраняются только для этого аккаунта. ccam сообщит об этом при следующем запуске аккаунта; перенесите сервер в общую группу командой `ccam mcp import <account> <server>`.

## Замедляет ли ccam работу Claude Code?

Запуск Claude Code через ccam добавляет около 4 миллисекунд; это измерено с помощью `scripts/perf-check.sh` на ноутбуке. ccam читает один небольшой файл, проверяет общие ссылки и затем заменяет себя на `claude`, поэтому во время вашей работы он не запущен. Windows не умеет заменять процесс, поэтому там ccam запускает Claude Code и ждёт его завершения, больше ничего не делая.

## Как обновить ccam?

Выполните `ccam update`. Команда скачивает последний выпуск, проверяет его контрольную сумму и заменяет файл `ccam`, а `ccam update --check` только сообщает, есть ли более новый выпуск. Панель тоже сообщает, когда есть более новый выпуск, и `U` устанавливает его после вопроса; ccam никогда не обновляется автоматически. Если вы установили пакет `.deb`, вместо этого установите новый `.deb` через apt. Подробности в разделе [обновление](/docs/install#update).

## Как удалить ccam?

Удалите короткую команду каждого аккаунта командой `ccam shortcut <account> --remove`, удалите `ccam` из `~/.local/bin`, а затем `~/.config/ccam`, `~/.local/share/ccam` и `~/.local/state/ccam`, если аккаунты вам больше не нужны. См. раздел [установка](/docs/install#uninstall).
