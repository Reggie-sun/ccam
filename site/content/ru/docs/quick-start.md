Добавьте каждый аккаунт командой `ccam add`, затем запускайте Claude Code командой `ccam <name>` или короткой командой, имя которой вы выбираете сами, например `ccwork`. Большинству этого достаточно.

Уже пользуетесь Claude Code? Прежде чем начать, прочитайте раздел [Уже используете ~/.claude?](#already-using-claude) в конце этой страницы.

## 1. Добавьте первый аккаунт

```sh
ccam add
```

Мастер спрашивает имя, например `personal` или `work`, какие элементы аккаунт должен делить с другими вашими аккаунтами и нужно ли создать короткую команду (см. шаг 3). Затем он выполняет `claude auth login`, который открывает браузер, чтобы вы могли войти. На удалённой машине ваш браузер может оказаться на странице `http://localhost:…/callback`, которая не загружается; вставьте этот адрес в терминал, и ccam завершит вход. Когда вход завершён, вы увидите:

```console
✓ personal (me@example.com) added
  no shortcut (add one with `ccam shortcut personal ccpersonal`)
```

## 2. Перенесите существующие настройки

Если вы уже пользовались Claude Code, ваши настройки, `CLAUDE.md` и расширения находятся в `~/.claude`, а MCP-серверы — в `~/.claude.json`. Скопируйте их в общую группу `default`, чтобы они были у каждого аккаунта:

```sh
ccam migrate
```

ccam показывает, что он скопирует, и сначала спрашивает подтверждение. Он только читает `~/.claude`, никогда не копирует данные входа и не переносит историю разговоров, если не добавить `--history`. Подробности в разделе [копирование существующей настройки](/docs/sharing#copy-an-existing-setup).

## 3. Добавьте второй аккаунт

```sh
ccam add work
```

Мастер пропускает вопрос об имени, которое вы указали в командной строке, и показывает группы для вступления, где отмечена `default`. На этот раз дайте аккаунту собственную короткую команду, например `ccwork`, чтобы запускать его одним словом. После выбора групп мастер спрашивает:

```console
 Create a shortcut command for work? [y/N]
 A command such as ccwork that opens Claude Code as this account.
```

Нажмите `y`, затем введите имя или нажмите Enter, чтобы принять предложенное:

```console
 Shortcut name [ccwork]: █
 a-z, 0-9, '.', '-' and '_'; Enter alone uses ccwork
```

Затем войдите в браузере с другим аккаунтом. ccam подтверждает аккаунт и его короткую команду:

```console
✓ work (work@example.com) added
  shortcut: ccwork
```

## 4. Переключение аккаунтов

`ccam work` запускает Claude Code от имени рабочего аккаунта. Если вы пропустили вопрос о короткой команде, её можно добавить в любой момент:

```console
$ ccam shortcut work ccwork
✓ shortcut for work: ccwork
```

Теперь каждая из этих команд запускает Claude Code от имени рабочего аккаунта (`2` — его номер в `ccam list`):

```sh
ccwork
ccam work
ccam 2
```

Если выполнить `ccam` без аргументов, откроется [панель](/features/dashboard): перейдите к аккаунту клавишами со стрелками или его номером и нажмите Enter.

Всё, что указано после короткой команды или имени аккаунта, передаётся в Claude Code без изменений, поэтому вы продолжаете пользоваться привычными параметрами:

```sh
ccwork --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | ccwork -p "what caused this?"
```

## 5. Выберите, что будет общим

По умолчанию MCP-серверы, `settings.json`, глобальный `CLAUDE.md` и расширения (агенты, команды, навыки и плагины) общие для всех аккаунтов через группу `default`. История разговоров не общая. Добавьте её в группу, если хотите продолжать разговоры в другом аккаунте:

```sh
ccam group set default --add history
```

Прежде чем что-либо изменить, ccam показывает, что он переместит для каждого аккаунта. Подробности в разделе [общий доступ через группы](/features/share).

## 6. Когда аккаунт достиг лимита

```sh
ccam usage
ccam next --continue
```

`ccam usage` показывает использование за 5 часов и за неделю для каждого аккаунта. `ccam next --continue` открывает тот же разговор в следующем аккаунте. В скриптах `ccam --fallback work -p "…"` переключается сам. См. раздел [лимиты использования](/docs/usage-limits).

**Места в тарифах Team и Enterprise.** Автоматический выбор аккаунта (`ccam next`, `--fallback`, `ccam pick`, клавиша `n` на панели и, если вы его включите, [`auto_switch`](/features/next#auto-switch)) переключается и между местами одной и той же организации Claude Team или Enterprise, что может нарушать условия Anthropic. Прочитайте [FAQ](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) и уточните это у своей организации и у Anthropic, прежде чем на него полагаться.

## Уже используете ~/.claude?

Зарегистрируйте папку вместо повторного входа:

```sh
ccam import
```

Папка остаётся на месте, а обычный `claude` работает как прежде.
