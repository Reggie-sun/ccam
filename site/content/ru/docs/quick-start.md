Добавьте каждый аккаунт командой `ccam add`, затем запускайте Claude Code командой `claude1`, `claude2` или `ccam <name>`. Большинству этого достаточно.

## 1. Добавьте первый аккаунт

```sh
ccam add
```

Мастер спрашивает имя, например `personal` или `work`, и какие элементы аккаунт должен делить с другими вашими аккаунтами. Затем он выполняет `claude auth login`, который открывает браузер, чтобы вы могли войти. По завершении вы увидите:

```console
✓ personal (me@example.com) 추가됨 — 단축 명령: claude1
```

Пока ccam выводит свои сообщения на корейском; команды и параметры одинаковы на всех языках.

## 2. Добавьте второй аккаунт

```sh
ccam add work
```

Войдите в браузере с другим аккаунтом. Он станет `claude2`.

## 3. Переключение

Любая из этих команд запускает Claude Code от имени рабочего аккаунта:

```sh
claude2
ccam work
ccam 2
```

Всё, что указано после имени аккаунта, передаётся в Claude Code без изменений, поэтому вы продолжаете пользоваться привычными параметрами:

```sh
ccam work --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

Если выполнить `ccam` без аргументов, откроется выбор аккаунта: используйте клавиши со стрелками и Enter или нажмите номер аккаунта.

## 4. Выберите, что будет общим

По умолчанию MCP-серверы, `settings.json`, глобальный `CLAUDE.md`, а также агенты, команды, навыки и плагины общие для всех аккаунтов. История разговоров не общая. Включите её для обоих аккаунтов, если хотите продолжать разговоры в другом аккаунте:

```sh
ccam share personal --history on
ccam share work --history on
```

Прежде чем что-либо изменить, ccam показывает, что он переместит. Подробности в разделе [общий доступ](/docs/sharing).

## 5. Когда аккаунт достиг лимита

```sh
ccam usage
ccam next --continue
```

`ccam usage` показывает использование за 5 часов и за неделю для каждого аккаунта. `ccam next --continue` открывает тот же разговор в следующем аккаунте. См. раздел [лимиты использования](/docs/usage-limits).

## Уже используете ~/.claude?

Зарегистрируйте папку вместо повторного входа:

```sh
ccam import
```

Папка остаётся на месте, а обычный `claude` работает как прежде.
