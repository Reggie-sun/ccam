`ccs usage` показывает, какую часть 5-часового и недельного лимитов уже использовал каждый аккаунт. `ccs next --auto` открывает аккаунт с наибольшим запасом, а `--continue` переносит текущий разговор.

```console
$ ccs usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccs next --auto 로 바로 열기)
```

Столбцы: аккаунт, использование за 5 часов, время до сброса, использование за неделю, время до сброса и давность данных.

## Откуда берутся данные

ccam запрашивает эндпоинт использования Anthropic для всех аккаунтов одновременно, используя собственный вход каждого аккаунта. Он ждёт не более 3 секунд на аккаунт и показывает каждый аккаунт, как только тот ответит.

Этот эндпоинт публично не документирован и может измениться. Если запрос не удался, ccam показывает последние известные данные и помечает их как кэшированные. `ccam doctor` сообщит, если формат ответа изменился.

Данные, полученные менее 60 секунд назад, используются повторно. Параметры:

| Параметр | Действие |
| --- | --- |
| `--watch [seconds]` | Обновлять непрерывно, по умолчанию каждые 60 секунд |
| `--json` | Машиночитаемый вывод |
| `-v` | Дополнительно показать недельные лимиты по моделям и источник каждого числа |
| `--no-cache` | Всегда запрашивать заново |
| `--source cache` | Никогда не запрашивать; показывать только сохранённые данные |

## Истёкшие входы

Когда токен доступа аккаунта истёк, ccam его не обновляет, потому что обновление во время сессии Claude Code, использующей тот же вход, может привести к выходу из аккаунта в этой сессии. Запустите аккаунт один раз командой `ccs <name>`, и Claude Code обновит токен сам.

`ccs usage --refresh` сам обновляет истёкшие токены, но только для аккаунтов, которые не запущены. Он никогда не обновляет данные входа, хранящиеся в Связке ключей macOS или в импортированной папке `~/.claude`.

## Использование в строке состояния

```sh
ccam statusline install
```

После этого Claude Code показывает в строке состояния имя аккаунта и его использование, например `[work] · Opus · 5h 24% · 7d 41%`. Если у вас уже есть команда для строки состояния, ccam сохраняет её и добавляет имя аккаунта в начало. Строка состояния также сохраняет свои данные, и `ccs usage` использует их, когда эндпоинт не отвечает.

## Переключение

```sh
ccs next              # the account after the one you used last
ccs next --auto       # the account with the lowest 5-hour usage
ccs next --continue   # the next account that shares your conversation history
```

`ccs next` пропускает аккаунты, в которые не выполнен вход, а `--auto` пропускает аккаунты на 100%. Чтобы продолжить разговор, оба аккаунта должны иметь общую историю разговоров; см. раздел [общий доступ](/docs/sharing).

В [руководстве по работе с лимитом использования](/guides/usage-limit-workflow) разобран полный пример.
