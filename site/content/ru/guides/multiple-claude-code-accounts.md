Дайте каждому аккаунту собственную папку конфигурации. Claude Code берёт путь к папке из переменной окружения `CLAUDE_CONFIG_DIR`, и в каждой папке хранятся свои данные входа, настройки и история. Это можно настроить вручную через псевдоним оболочки или поручить ccam.

## Вручную, через псевдоним

Этот способ описан в документации Claude Code. Добавьте по строке на каждый дополнительный аккаунт в `~/.bashrc` или `~/.zshrc`:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

Откройте новый терминал и выполните `claude-work`. Claude Code попросит войти, потому что папка новая. С этого момента `claude` будет вашим первым аккаунтом, а `claude-work` вторым.

Для двух аккаунтов это работает хорошо. Что нужно знать:

- Каждая папка изначально пуста: нет настроек, нет `CLAUDE.md`, нет MCP-серверов, нет агентов и навыков. Нужное вы копируете или связываете сами и сами поддерживаете копии в одинаковом состоянии.
- Псевдонимы существуют только в интерактивных оболочках. Скрипты, Makefile и другие программы их не видят.
- MCP-серверы хранятся в `.claude.json` рядом с данными входа, поэтому их нельзя просто связать между папками.
- Разговоры остаются в аккаунте, где начались, поэтому продолжить разговор в другом аккаунте нельзя.
- Нет ничего, что показывало бы использование всех аккаунтов сразу.

## С ccam

ccam автоматизирует ту же идею и добавляет недостающее:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

Теперь `ccam personal` и `ccam work` запускают два аккаунта, как и `ccwork`, короткая команда, которую вы дали рабочему аккаунту. Поскольку это настоящие программы, а не псевдонимы, они работают и в скриптах. Настройки, `CLAUDE.md`, MCP-серверы и расширения общие с самого начала, а общую историю разговоров можно включить, чтобы продолжать разговор в другом аккаунте командой `ccam next --continue`.

Если вы уже используете `~/.claude`, выполните `ccam import` вместо того, чтобы добавлять этот аккаунт заново, или `ccam migrate`, чтобы скопировать его настройки, MCP-серверы и расширения в общие настройки.

## Что выбрать

Для двух аккаунтов без общих данных достаточно псевдонима. Если вам нужны общие настройки и MCP-серверы, больше аккаунтов, обзор использования или продолжение разговоров, ccam избавит от ручного учёта. В [сравнении](/compare/aliases) различия приведены бок о бок.
