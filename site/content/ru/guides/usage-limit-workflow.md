Когда один аккаунт достиг лимита использования, продолжите тот же разговор в другом своём аккаунте: один раз сделайте историю разговоров общей, затем выполните `ccs next --continue`. Если аккаунт у вас один, дождитесь времени сброса, которое показывает Claude Code.

## Заранее

Настройте аккаунты так, чтобы переключение занимало одну команду:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

Теперь во время работы строка состояния показывает аккаунт и его использование за 5 часов, так что лимит не станет неожиданностью.

## Когда лимит достигнут

Выйдите из Claude Code (`/exit`), затем выполните:

```sh
ccs usage
```

```console
 1 personal  ████████ 100% 22분        █████░░░  68% 1일 9시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
```

Откройте разговор в аккаунте с наибольшим запасом:

```sh
ccs next --auto --continue
```

Claude Code запустится как `work` с последним разговором текущей папки, включая всё, что было сказано до этого.

## Что стоит учитывать

- Выполняйте `ccs next --continue` в той же папке, где работали; разговоры хранятся по папкам проектов.
- Не запускайте два аккаунта на одном и том же разговоре одновременно. ccam предупредит, если вы попытаетесь.
- Другой аккаунт тоже должен делить историю разговоров, причём в той же группе.
- Можно ли так переключаться между аккаунтами, зависит от условий каждого аккаунта.

Все параметры `ccs usage` и `ccs next` описаны в разделе [лимиты использования](/docs/usage-limits).
