`ccs usage` બતાવે છે કે દરેક એકાઉન્ટે 5 કલાકની અને સાપ્તાહિક મર્યાદામાંથી કેટલું વાપર્યું છે. `ccs next --auto` સૌથી વધુ જગ્યાવાળું એકાઉન્ટ ખોલે છે, અને `--continue` હાલની વાતચીત ત્યાં લઈ જાય છે.

```console
$ ccs usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccs next --auto 로 바로 열기)
```

કૉલમ આ પ્રમાણે છે: એકાઉન્ટ, 5 કલાકનો વપરાશ, તે રીસેટ થવામાં બાકી સમય, સાપ્તાહિક વપરાશ, તે રીસેટ થવામાં બાકી સમય, અને આંકડા કેટલા જૂના છે.

## આંકડા ક્યાંથી આવે છે

ccam દરેક એકાઉન્ટના પોતાના લૉગિનનો ઉપયોગ કરીને, બધાં એકાઉન્ટ માટે એકસાથે Anthropic ના usage endpoint ને પૂછે છે. તે દરેક એકાઉન્ટ માટે વધુમાં વધુ 3 સેકન્ડ રાહ જુએ છે અને દરેક એકાઉન્ટનો જવાબ આવતાં જ તેને બતાવે છે.

આ endpoint જાહેર રીતે દસ્તાવેજીકૃત નથી અને બદલાઈ શકે છે. જ્યારે કોઈ request નિષ્ફળ જાય, ત્યારે ccam છેલ્લા જાણીતા આંકડા બતાવે છે અને તેમને કૅશ તરીકે ચિહ્નિત કરે છે. જો જવાબનું ફૉર્મેટ બદલાયું હોય તો `ccam doctor` તમને જણાવે છે.

60 સેકન્ડ કરતાં ઓછા સમય પહેલાં મેળવેલા આંકડા ફરીથી વપરાય છે. ઓપ્શન:

| ઓપ્શન | અસર |
| --- | --- |
| `--watch [seconds]` | સતત રિફ્રેશ કરો, ડિફૉલ્ટ રીતે દર 60 સેકન્ડે |
| `--json` | મશીન વાંચી શકે તેવું આઉટપુટ |
| `-v` | મૉડલ પ્રમાણેની સાપ્તાહિક મર્યાદા અને દરેક આંકડો ક્યાંથી આવ્યો તે પણ બતાવો |
| `--no-cache` | હંમેશાં ફરીથી પૂછો |
| `--source cache` | ક્યારેય ન પૂછો; ફક્ત સેવ કરેલા આંકડા બતાવો |

## સમાપ્ત થયેલાં લૉગિન

જ્યારે કોઈ એકાઉન્ટનો access token સમાપ્ત થઈ ગયો હોય, ત્યારે ccam તેને રિન્યૂ કરતું નથી, કારણ કે કોઈ Claude Code સેશન એ જ લૉગિન વાપરતું હોય ત્યારે તેને રિન્યૂ કરવાથી તે સેશન સાઇન આઉટ થઈ શકે છે. એકાઉન્ટને `ccs <name>` વડે એક વાર શરૂ કરો, અને Claude Code તેને રિન્યૂ કરે છે.

`ccs usage --refresh` સમાપ્ત થયેલા ટોકન જાતે રિન્યૂ કરે છે, પણ ફક્ત એવાં એકાઉન્ટ માટે જે ચાલી રહ્યાં નથી. તે macOS Keychain માં કે ઇમ્પોર્ટ કરેલા `~/.claude` માં રાખેલાં લૉગિન ક્યારેય રિન્યૂ કરતું નથી.

## સ્ટેટસ લાઇનમાં વપરાશ

```sh
ccam statusline install
```

પછી Claude Code સ્ટેટસ લાઇનમાં એકાઉન્ટનું નામ અને તેનો વપરાશ બતાવે છે, ઉદાહરણ તરીકે `[work] · Opus · 5h 24% · 7d 41%`. જો તમારી પાસે પહેલેથી સ્ટેટસ લાઇન કમાન્ડ હોય, તો ccam તેને રાખે છે અને તેની આગળ એકાઉન્ટનું નામ મૂકે છે. સ્ટેટસ લાઇન પોતાના આંકડા પણ સેવ કરે છે, જે endpoint જવાબ ન આપે ત્યારે `ccs usage` વાપરે છે.

## સ્વિચ કરવું

```sh
ccs next              # the account after the one you used last
ccs next --auto       # the account with the lowest 5-hour usage
ccs next --continue   # the next account that shares your conversation history
```

`ccs next` લૉગિન ન થયેલાં એકાઉન્ટ છોડી દે છે, અને `--auto` 100% પર પહોંચેલાં એકાઉન્ટ છોડી દે છે. વાતચીત ચાલુ રાખવા માટે બંને એકાઉન્ટ વાતચીતનો ઇતિહાસ શેર કરતાં હોવાં જોઈએ; [શેરિંગ](/docs/sharing) જુઓ.

[વપરાશ મર્યાદા વર્કફ્લો માર્ગદર્શિકા](/guides/usage-limit-workflow) એક પૂરું ઉદાહરણ પગલું દર પગલું બતાવે છે.
