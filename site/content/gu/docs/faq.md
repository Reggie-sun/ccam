## શું ccam, Anthropic નું સત્તાવાર ટૂલ છે?

ના. ccam એક બિનસત્તાવાર ઓપન-સોર્સ પ્રોજેક્ટ છે. તે Anthropic સાથે જોડાયેલો નથી અને Anthropic તેને સમર્થન આપતું નથી. તે `CLAUDE_CONFIG_DIR` સેટિંગ વાપરે છે, જે Claude Code એ ઘણાં એકાઉન્ટ સાથે-સાથે ચલાવવા માટે દસ્તાવેજીકૃત કર્યું છે.

## શું મને ઘણાં Claude Code એકાઉન્ટ વાપરવાની છૂટ છે?

તે દરેક એકાઉન્ટની શરતો પર, અને કામનાં એકાઉન્ટ માટે તમારી સંસ્થાની નીતિ પર આધાર રાખે છે. ઘણાં એકાઉન્ટ વાપરતાં પહેલાં તે તપાસો. ccam ફક્ત તમારી પાસે પહેલેથી હોય તેવાં એકાઉન્ટ વચ્ચે સ્વિચ કરવાનું સરળ બનાવે છે.

## શું ccam વપરાશ મર્યાદાથી બચવાનો રસ્તો છે?

ના. દરેક એકાઉન્ટની પોતાની મર્યાદાઓ યથાવત્ રહે છે. ccam તેમને બતાવે છે, અને એક એકાઉન્ટની મર્યાદા પૂરી થાય ત્યારે તમારી માલિકીના બીજા એકાઉન્ટ પર ચાલુ રાખવા દે છે.

## એક કમ્પ્યુટર પર બે Claude Code એકાઉન્ટ કેવી રીતે વાપરવાં?

`CLAUDE_CONFIG_DIR` વડે દરેક એકાઉન્ટને પોતાનું કૉન્ફિગરેશન ફોલ્ડર આપો. ccam તમારા માટે આ કરે છે: દરેક એકાઉન્ટ માટે `ccam add` ચલાવો, પછી તેમને `claude1` અને `claude2` વડે શરૂ કરો. [માર્ગદર્શિકા](/guides/multiple-claude-code-accounts) આ હાથથી કેવી રીતે કરવું તે પણ બતાવે છે.

## બીજા એકાઉન્ટ પર વાતચીત કેવી રીતે ચાલુ રાખવી?

`ccam share <name> --history on` વડે બંને એકાઉન્ટ વચ્ચે વાતચીતનો ઇતિહાસ શેર કરો, પછી `ccam next --continue` ચલાવો. Claude Code હાલના ફોલ્ડરની સૌથી તાજેતરની વાતચીત આગલા એકાઉન્ટમાં ખોલે છે.

## શું ccam મારું લૉગિન જુએ છે કે મોકલે છે?

ccam ક્યારેય લૉગિન કૉપિ કે શેર કરતું નથી. જ્યારે તમે `ccam usage`, `ccam next --auto` કે `ccam doctor` ચલાવો, ત્યારે તે એકાઉન્ટનો વપરાશ Anthropic ના usage endpoint પાસેથી પૂછવા માટે જ એકાઉન્ટનો access token વાંચે છે. ccam માં કોઈ ટેલિમેટ્રી નથી અને તે બીજે ક્યાંય કંઈ મોકલતું નથી.

## મારાં એકાઉન્ટ ક્યાં સંગ્રહાય છે?

`~/.local/share/ccam/profiles/<name>/` માં, દરેક એકાઉન્ટ માટે એક ફોલ્ડર. macOS પર, લૉગિન પોતે Claude Code દ્વારા Keychain માં, એ ફોલ્ડર પરથી બનેલા નામ હેઠળ રાખવામાં આવે છે.

## મારા હાલના ~/.claude નું શું થાય છે?

કંઈ નહીં, સિવાય કે તમે `ccam import` ચલાવો. Import ફોલ્ડરને તે જ્યાં છે ત્યાં જ રજિસ્ટર કરે છે, તેથી સાદું `claude` અને `ccam <name>` એ જ એકાઉન્ટ અને સેટિંગ્સ વાપરતાં રહે છે.

## ccam કઈ સિસ્ટમને સમર્થન આપે છે?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine અને બીજાં) અને macOS. Windows પર તેને WSL ની અંદર વાપરો.

## કોઈ MCP સર્વર ફક્ત એક જ એકાઉન્ટમાં કેમ દેખાય છે?

સેશનની અંદર `claude mcp add` વડે ઉમેરેલા સર્વર ફક્ત તે એકાઉન્ટ માટે સંગ્રહાય છે. તમે તે એકાઉન્ટ આગલી વખતે શરૂ કરો ત્યારે ccam તમને જણાવે છે; `ccam mcp import <account> <server>` વડે સર્વરને શેર કરેલા ગ્રુપમાં ખસેડો.

## શું ccam, Claude Code ને ધીમું કરે છે?

ccam દ્વારા Claude Code શરૂ કરવાથી લગભગ 4 મિલિસેકન્ડ ઉમેરાય છે, જે એક લેપટૉપ પર `scripts/perf-check.sh` વડે માપ્યું છે. ccam એક નાની ફાઇલ વાંચે છે, શેર કરેલી લિંક તપાસે છે અને પછી પોતાની જગ્યાએ `claude` ચલાવે છે, તેથી તમે કામ કરો ત્યારે તે ચાલતું નથી.

## ccam અનઇન્સ્ટૉલ કેવી રીતે કરવું?

`~/.local/bin` માંથી `ccam` અને `claude1`… લિંક કાઢી નાખો, પછી જો તમને એકાઉન્ટની હવે જરૂર ન હોય તો `~/.config/ccam`, `~/.local/share/ccam` અને `~/.local/state/ccam` પણ કાઢી નાખો. [ઇન્સ્ટૉલ](/docs/install#uninstall) જુઓ.
