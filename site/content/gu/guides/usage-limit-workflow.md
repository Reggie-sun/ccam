જ્યારે એક એકાઉન્ટ તેની Claude Code વપરાશ મર્યાદા સુધી પહોંચે, ત્યારે એ જ વાતચીત તમારી માલિકીના બીજા એકાઉન્ટમાં ચાલુ રાખો: એક વાર વાતચીતનો ઇતિહાસ શેર કરો, પછી `ccam next --continue` ચલાવો. જો તમારી પાસે ફક્ત એક જ એકાઉન્ટ હોય, તો Claude Code જે રીસેટ સમય બતાવે ત્યાં સુધી રાહ જુઓ.

## એવું થાય તે પહેલાં

એકાઉન્ટ એવી રીતે સેટ કરો કે સ્વિચ કરવામાં એક જ કમાન્ડ લાગે:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

હવે તમે કામ કરતા હો ત્યારે સ્ટેટસ લાઇન એકાઉન્ટ અને તેનો 5 કલાકનો વપરાશ બતાવે છે, તેથી મર્યાદા અચાનક આવતી નથી.

## જ્યારે મર્યાદા આવી જાય

Claude Code માંથી બહાર નીકળો (`/exit`), પછી:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

સૌથી વધુ જગ્યાવાળા એકાઉન્ટમાં વાતચીત ખોલો:

```sh
ccam next --auto --continue
```

Claude Code હાલના ફોલ્ડરની સૌથી તાજેતરની વાતચીત સાથે `work` તરીકે શરૂ થાય છે, અત્યાર સુધી કહેલી દરેક વાત સહિત.

## ધ્યાનમાં રાખવાની બાબતો

- `ccam next --continue` એ જ ફોલ્ડરમાં ચલાવો જ્યાં તમે કામ કરતા હતા; વાતચીત દરેક પ્રોજેક્ટ ફોલ્ડર પ્રમાણે સંગ્રહાય છે.
- એક જ વાતચીત પર એક જ સમયે બે એકાઉન્ટ ચલાવવાનું ટાળો. જો તમે પ્રયત્ન કરો તો ccam તમને ચેતવે છે.
- બીજું એકાઉન્ટ પણ એ જ ગ્રુપમાં વાતચીતનો ઇતિહાસ શેર કરતું હોવું જોઈએ.
- તમે આ રીતે એકાઉન્ટ વચ્ચે સ્વિચ કરી શકો કે નહીં, તે દરેક એકાઉન્ટની શરતો પર આધાર રાખે છે.

`ccam usage` અને `ccam next` ના દરેક ઓપ્શન માટે [વપરાશ મર્યાદા](/docs/usage-limits) જુઓ.
