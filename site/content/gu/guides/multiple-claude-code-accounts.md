એક કમ્પ્યુટર પર બે Claude Code એકાઉન્ટ વાપરવા માટે દરેક એકાઉન્ટને પોતાનું કૉન્ફિગરેશન ફોલ્ડર આપો. Claude Code આ ફોલ્ડર `CLAUDE_CONFIG_DIR` environment variable પરથી વાંચે છે, અને દરેક ફોલ્ડરમાં પોતાનું લૉગિન, સેટિંગ્સ અને ઇતિહાસ હોય છે. તમે આ હાથથી શેલ alias વડે સેટ કરી શકો છો, અથવા ccam ને તે કરવા દઈ શકો છો.

## હાથથી, alias વડે

Claude Code ના દસ્તાવેજીકરણમાં આ જ રીત વર્ણવેલી છે. દરેક વધારાના એકાઉન્ટ માટે `~/.bashrc` કે `~/.zshrc` માં એક લાઇન ઉમેરો:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

નવું ટર્મિનલ ખોલો અને `claude-work` ચલાવો. ફોલ્ડર નવું હોવાથી Claude Code તમને લૉગિન કરવા કહે છે. ત્યાર પછી `claude` તમારું પહેલું એકાઉન્ટ છે અને `claude-work` બીજું.

બે એકાઉન્ટ માટે આ સારું કામ કરે છે. જાણવા જેવી બાબતો:

- દરેક ફોલ્ડર ખાલી શરૂ થાય છે: કોઈ સેટિંગ્સ નહીં, કોઈ `CLAUDE.md` નહીં, કોઈ MCP સર્વર નહીં, કોઈ agents કે skills નહીં. તમને જે જોઈએ તે તમે કૉપિ કે લિંક કરો છો, અને નકલોને સરખી રાખવાનું કામ જાતે કરો છો.
- Alias ફક્ત interactive શેલમાં જ હોય છે. સ્ક્રિપ્ટ, Makefile અને બીજા પ્રોગ્રામ તેમને જોઈ શકતા નથી.
- MCP સર્વર લૉગિનની બાજુમાં `.claude.json` માં રહે છે, તેથી તેમને ફોલ્ડર વચ્ચે સહેલાઈથી લિંક કરી શકાતા નથી.
- વાતચીત જે એકાઉન્ટમાં શરૂ થઈ હોય ત્યાં જ રહે છે, તેથી તમે તેને બીજા એકાઉન્ટમાં ચાલુ રાખી શકતા નથી.
- બધાં એકાઉન્ટનો વપરાશ એકસાથે બતાવે એવું કંઈ નથી.

## ccam વડે

ccam આ જ વિચારને આપમેળે કરે છે અને ખૂટતા ભાગ ઉમેરે છે:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
```

હવે `claude1` અને `claude2`, અથવા `ccam personal` અને `ccam work`, બંને એકાઉન્ટ શરૂ કરે છે. તે alias નહીં પણ ખરેખરા પ્રોગ્રામ હોવાથી સ્ક્રિપ્ટમાં પણ કામ કરે છે. સેટિંગ્સ, `CLAUDE.md`, MCP સર્વર અને એક્સટેન્શન્સ શરૂઆતથી શેર થાય છે, અને `ccam next --continue` વડે બીજા એકાઉન્ટ પર વાતચીત ચાલુ રાખવા માટે તમે શેર કરેલો વાતચીતનો ઇતિહાસ ચાલુ કરી શકો છો.

જો તમે પહેલેથી `~/.claude` વાપરતા હો, તો તે એકાઉન્ટ ફરીથી ઉમેરવાને બદલે `ccam import` ચલાવો.

## કઈ રીત પસંદ કરવી

બે એકાઉન્ટ અને કંઈ શેર ન કરવું હોય, તો alias પૂરતું છે. જ્યારે તમને શેર કરેલાં સેટિંગ્સ અને MCP સર્વર, વધુ એકાઉન્ટ, એક નજરમાં વપરાશ કે વાતચીત ચાલુ રાખવાની સુવિધા જોઈએ, ત્યારે ccam તમારું જાતે સંભાળવાનું કામ બચાવે છે. [સરખામણી](/compare/aliases) તફાવતો બાજુ-બાજુમાં બતાવે છે.
