Claude Code એકાઉન્ટ સ્વિચ કરવાનાં ટૂલ બેમાંથી એક રીત અપનાવે છે. મોટા ભાગનાં ટૂલ એક જ `~/.claude` ફોલ્ડરની અંદર લૉગિન બદલે છે, તેથી એક સમયે એક જ એકાઉન્ટ સક્રિય રહે છે. બીજાં ટૂલ, જેમાં ccam પણ છે, `CLAUDE_CONFIG_DIR` વડે દરેક એકાઉન્ટને પોતાનું ફોલ્ડર આપે છે, તેથી દરેક એકાઉન્ટ લૉગિન રહે છે અને ઘણાં એકાઉન્ટ એકસાથે ચાલી શકે છે. ccam તેમાં શેર કરેલાં સેટિંગ્સ અને MCP સર્વર ઉમેરે છે, અને વાતચીતને બીજા એકાઉન્ટના ફોલ્ડરમાં ચાલુ રાખે છે.

## એક લૉગિન બદલવું કે અલગ ફોલ્ડર?

**લૉગિન બદલવાથી** સેટિંગ્સ, MCP સર્વર અને ઇતિહાસનો એક જ સેટ રહે છે, કારણ કે ફોલ્ડર એક જ છે. સ્વિચ કરવું ઝડપી છે, અને ચાલુ સેશન નવું લૉગિન અપનાવી શકે છે. પણ એક સમયે ફક્ત એક જ એકાઉન્ટ સક્રિય રહે છે, અને તે બધાં ટર્મિનલ અને એડિટર માટે એકસાથે લાગુ પડે છે.

**અલગ ફોલ્ડર** એ રીત છે જે [Claude Code ના દસ્તાવેજીકરણમાં વર્ણવેલી છે](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts). દરેક એકાઉન્ટ લૉગિન રહે છે, અને તમે કામનું અને અંગત સેશન સાથે-સાથે ચલાવી શકો છો. તેની કિંમત એ છે કે દરેક ફોલ્ડર પોતાનાં સેટિંગ્સ, MCP સર્વર અને ઇતિહાસ સાથે શરૂ થાય છે, સિવાય કે કોઈ ટૂલ તેમને શેર કરે.

## ટૂલની સરખામણી

દરેક પ્રોજેક્ટના પોતાના દસ્તાવેજીકરણમાંથી 2026-10-19 ના રોજ લીધેલું. "દસ્તાવેજીકૃત નથી" નો અર્થ એ છે કે પ્રોજેક્ટ તેના વિશે કંઈ કહેતો નથી, એવો નહીં કે સુવિધા નથી.

| [cux](https://github.com/inulute/cux) | લૉગિન બદલે છે અને `claude` ને wrap કરે છે | દસ્તાવેજીકૃત નથી | હા | લૉગિન બદલીને એ જ વાતચીત ફરી ચાલુ કરે છે | Linux, macOS, Windows |
| [CCSwitcher](https://github.com/XueshiQiao/CCSwitcher) | લૉગિન બદલે છે | ના | હા | દસ્તાવેજીકૃત નથી | macOS |
| [Claude Switcher](https://github.com/Symbioose/claude-account-switcher) | લૉગિન બદલે છે | ના | હા | 100% પર વૈકલ્પિક સ્વિચ | macOS |

ccswap એ claude-swap નો fork છે, જે Codex લૉગિન પણ સંભાળે છે. આમાંનાં કેટલાંક ટૂલ Codex કે Gemini જેવા બીજા coding agents પણ સંભાળે છે.

## ccam શેના પર ધ્યાન આપે છે

- દરેક એકાઉન્ટ લૉગિન રહે છે. સ્વિચ કરવાથી કોઈ એકાઉન્ટ ક્યારેય લૉગઆઉટ થતું નથી, અને `ccam work` અને `ccam personal` બે ટર્મિનલમાં એકસાથે ચાલી શકે છે.
- MCP સર્વર, `settings.json`, `CLAUDE.md`, agents, skills અને plugins લિંક દ્વારા ફોલ્ડર વચ્ચે શેર થાય છે, આઇટમ પ્રમાણે અને એકાઉન્ટ પ્રમાણે. લૉગિન ક્યારેય શેર થતાં નથી.
- શેર કરેલા ઇતિહાસ સાથે, એક કમાન્ડ, `ccam next --auto --continue`, એ જ વાતચીત સૌથી વધુ જગ્યાવાળા એકાઉન્ટના ફોલ્ડરમાં ખોલે છે.
- ccam Claude Code શરૂ કરે છે અને પોતાની જગ્યા તેને આપી દે છે, તેથી બૅકગ્રાઉન્ડમાં કંઈ ચાલતું નથી. તે તમારા વપરાશ પર નજર રાખતું નથી કે જાતે સ્વિચ કરતું નથી; ક્યારે સ્વિચ કરવું તે તમે નક્કી કરો છો.

## બીજાં ટૂલ ક્યાં વધુ કરે છે

- claude-swap, CCS, clauth, CAAM અને cux WSL વગર Windows પર ચાલે છે. ccam નથી ચાલતું.
- કોઈ એકાઉન્ટ વપરાશની હદ વટાવે ત્યારે claude-swap, clauth અને cux જાતે સ્વિચ કરે છે. ccam સ્વિચ કરવાનું તમારા પર છોડે છે.
- CCSwitcher, Claude Switcher અને claude-swap macOS મેનુ બારમાં વપરાશ બતાવે છે.
- CCS, CAAM, ccswap અને Claude Switcher, Codex અને બીજા coding agents પણ સંભાળે છે.

## કયું યોગ્ય છે?

જો તમે એક સમયે એક જ એકાઉન્ટ વાપરતા હો, સ્વિચ આપમેળે થાય એવું ઇચ્છતા હો, કે WSL વગર Windows પર હો, તો લૉગિન બદલતું ટૂલ પસંદ કરો. જો તમને એકાઉન્ટ સાથે-સાથે, એક જ શેર કરેલું સેટઅપ અને આગલા એકાઉન્ટમાં એ જ વાતચીત જોઈતી હોય, તો ccam પસંદ કરો. જો કંઈ શેર કરવાની જરૂર ન હોય, તો [સાદા શેલ alias](/compare/aliases) પૂરતા છે.

તમે ઘણાં એકાઉન્ટ વાપરી શકો કે નહીં, તે દરેક એકાઉન્ટની શરતો પર આધાર રાખે છે. તેમ કરતાં પહેલાં શરતો તપાસો.
