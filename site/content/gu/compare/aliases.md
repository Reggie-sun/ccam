દરેક એકાઉન્ટ માટે એક શેલ alias એ ઘણાં Claude Code એકાઉન્ટ ચલાવવાની સૌથી સરળ રીત છે. ccam અંદરથી આ જ કામ કરે છે અને તેમાં શેરિંગ, સ્વિચિંગ અને વપરાશ પર નજર રાખવાની સુવિધા ઉમેરે છે.

| | શેલ alias | ccam |
| --- | --- | --- |
| અલગ લૉગિન | હા | હા |
| દરેક એકાઉન્ટ માટે સેટઅપ | `~/.bashrc` એડિટ કરો, લૉગિન કરો | `ccam add` |
| સ્ક્રિપ્ટ અને બીજા પ્રોગ્રામમાં કામ કરે | ના, alias ફક્ત શેલ માટે છે | હા, `ccam work` અને `ccwork` જેવા શૉર્ટકટ ખરેખરા કમાન્ડ છે |
| શેર કરેલાં સેટિંગ્સ, `CLAUDE.md`, એક્સટેન્શન્સ | હાથથી કૉપિ કે લિંક કરો | આઇટમ પ્રમાણે, બૅકઅપ સાથે |
| શેર કરેલા MCP સર્વર | હાથથી, દરેક એકાઉન્ટ માટે | `ccam mcp add` એક વાર |
| બીજા એકાઉન્ટમાં વાતચીત ચાલુ રાખવી | ના | `ccam next --continue` |
| દરેક એકાઉન્ટનો વપરાશ | ના | `ccam usage` |
| સૌથી વધુ જગ્યાવાળું એકાઉન્ટ પસંદ કરવું | ના | `ccam next --auto` |
| સ્ટેટસ લાઇનમાં એકાઉન્ટનું નામ | ના | `ccam statusline install` |
| તૂટેલી લિંક સુધારવી | હાથથી | `ccam doctor --fix` |
| વધારાનું સૉફ્ટવેર | કંઈ નહીં | એક સ્ટેટિક બાઇનરી |

જો તમારી પાસે બે એકાઉન્ટ હોય અને તેમની વચ્ચે કંઈ શેર ન કરવું હોય, તો alias પસંદ કરો. જો તમે ઇચ્છતા હો કે બધાં એકાઉન્ટ એક જ સેટઅપ જેવાં લાગે, તો ccam પસંદ કરો. તમે alias થી શરૂ કરીને પછી ccam પર જઈ શકો છો: `ccam import` હાલનાં `~/.claude-*` ફોલ્ડરને તેઓ જ્યાં છે ત્યાં જ રજિસ્ટર કરે છે.

[એક કમ્પ્યુટર પર બે એકાઉન્ટ કેવી રીતે વાપરવાં](/guides/multiple-claude-code-accounts) બંને રીતો પગલું દર પગલું સમજાવે છે.
