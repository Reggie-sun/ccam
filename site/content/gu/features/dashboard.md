standard input અને output ટર્મિનલ હોય ત્યારે આર્ગ્યુમેન્ટ વગરનું `ccam` ફુલ-સ્ક્રીન ડેશબોર્ડ ખોલે છે; નહીં તો તે `ccam list` છાપે છે. ડેશબોર્ડ દરેક એકાઉન્ટને તેના વપરાશ અને ગ્રુપ સાથે બતાવે છે, અને કમાન્ડ જે કરે છે તે જ કરે છે: શરૂ કરવું, ઉમેરવું, લૉગિન કરવું, ગ્રુપ બદલવાં, ફોલ્ડર નિયમો સેટ કરવા, તપાસવું અને સુધારવું. શરૂ કરવાથી તે બંધ થાય છે; એકાઉન્ટ ઉમેરવા કે લૉગિન કરવા માટે તે ટર્મિનલ છોડે છે અને પાછું આવે છે.

```console
 ccam v0.9.0 · 3 accounts · 2 groups         ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health

    # Account     Email             5-hour         7-day Last  Groups
 ❯ 1. personal ✔   me@example.com    █████▊░░  72%   41% 2h    default
   2. work      ▸• dev@company.com   ██░░░░░░  25%  100% now   default team
   3. side         -                 ✘ not logged in         -     no group

 ✔ personal is the default account
 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

પહેલી frame ફક્ત `config.toml` પરથી દોરાય છે, 100 ms થી ઘણા ઓછા સમયમાં; દરેક એકાઉન્ટ જવાબ આપે તેમ વપરાશ ભરાતો જાય છે. ટકાવારી 80% થી પીળી અને 100% પર લાલ થાય છે, અને નિષ્ફળ lookup પછી cache માંથી આવેલાં મૂલ્યો ઝાંખાં દોરાય છે.

## ટૅબ

| ટૅબ | શું બતાવે છે | કી |
| --- | --- | --- |
| Accounts | નંબર, નામ, ઇમેઇલ, 5 કલાકની bar, 7 દિવસનો વપરાશ, છેલ્લો ઉપયોગ, ગ્રુપ; `✔` ડિફૉલ્ટ, `▸` આ ફોલ્ડરનું એકાઉન્ટ, `•` ચાલુ | નીચે |
| Groups | દરેક ગ્રુપ, તે શું શેર કરે છે અને તેનાં એકાઉન્ટ, અને કોઈ ગ્રુપમાં ન હોય તેવાં એકાઉન્ટ | `enter` ફેરફાર, `n` નવું, `e` નામ બદલો, `x` દૂર કરો |
| Folders | [`ccam folder`](/features/folder) ના નિયમો અને અહીં લાગુ પડતો નિયમ | `n` અહીં એકાઉન્ટ વાપરો, `enter` બદલો, `x` દૂર કરો |
| Extensions | [`ccam ext`](/features/ext) જે બતાવે છે તે, દરેક એક્સટેન્શન એક વાર, તે જે ગ્રુપમાંથી આવે છે તેની સાથે | `r` ફરી લોડ કરો |
| Health | [`ccam doctor`](/features/doctor) જે જણાવે છે તે | `f` સુધારો (`doctor --fix`) |

`←`/`→` કે `Tab` ટૅબ બદલે છે, `?` હાલના ટૅબની કી બતાવે છે, `r` ટૂંકા cache વગર વપરાશ ફરી મેળવે છે, અને `q` કે `Esc` બહાર નીકળે છે.

## Accounts ટૅબ પરની કી

| કી | શું કરે છે |
| --- | --- |
| `Enter` | પસંદ કરેલા એકાઉન્ટ તરીકે Claude Code શરૂ કરે છે |
| `1`–`9` | એ નંબરવાળા એકાઉન્ટ પર જાય છે; 12 માટે ઝડપથી `1` `2` લખો. ફક્ત `Enter` શરૂ કરે છે |
| `↑`/`↓`, `k`/`j` | ખસે છે |
| `n` | [`ccam next --auto`](/features/next) જે પસંદ કરે તે એકાઉન્ટ શરૂ કરે છે |
| `o` | ઓપ્શન સાથે શરૂ કરે છે: `--continue`, `--resume`, બીજા આર્ગ્યુમેન્ટ્સ, કે dry run |
| `u` | વપરાશની વિગતો: 5 કલાકની, 7 દિવસની અને મૉડલની વિન્ડો, તેમના રીસેટ અને આંકડા ક્યાંથી આવે છે |
| `a` | એકાઉન્ટ ઉમેરે છે (નીચેનો વિઝાર્ડ) |
| `l` | ફરીથી લૉગિન કરે છે |
| `s` | એકાઉન્ટનાં ગ્રુપ પસંદ કરે છે |
| `d` | તેને ડિફૉલ્ટ એકાઉન્ટ બનાવે છે |
| `f` | તેને હાલના ફોલ્ડરમાં વાપરે છે |
| `e` | તેનું નામ બદલે છે |
| `c` | તેનો શૉર્ટકટ કમાન્ડ સેટ કરે છે કે દૂર કરે છે |
| `x` | તેને દૂર કરે છે (પહેલાં પૂછે છે, No થી શરૂ કરીને) |

## ગ્રુપ બદલવાં

Groups ટૅબ પર, `Enter` editor ખોલે છે: ડાબી બાજુ આઇટમ, જમણી બાજુ એકાઉન્ટ, બદલવા માટે `Tab`, ટૉગલ કરવા `Space`. જે આઇટમ કોઈ એકાઉન્ટને પહેલેથી બીજા ગ્રુપમાંથી મળતી હોય તે કારણ સાથે ઝાંખી બતાવાય છે, અને જે એકાઉન્ટને કોઈ આઇટમ બે વાર મળે તે પણ; એક આઇટમ ફક્ત એક જ ગ્રુપમાંથી આવી શકે છે. `Enter` યોજના બતાવે છે:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

ગ્રુપની કૉપિથી જુદી હોય તેવી ફાઇલ વિશે પહેલાં પૂછવામાં આવે છે (ગ્રુપની રાખવી, મારી વાપરવી, કે મર્જ કરવી). પછી ફેરફાર [`ccam group`](/features/share) ના જ કોડ સાથે બૅકગ્રાઉન્ડમાં ચાલે છે: પહેલાં config સેવ થાય છે, દરેક એકાઉન્ટનો ડેટા ક્રમમાં ખસે છે, અને મૂળ ફાઇલો `.ccam-backup/` માં જાય છે. જે ફેરફાર ચાલુ એકાઉન્ટનો ડેટા ખસેડે, તે એકાઉન્ટના નામ સાથે નકારાય છે.

## એકાઉન્ટ ઉમેરવું

`a` એ વિઝાર્ડ ખોલે છે જે `ccam add` પણ ટર્મિનલ પર વાપરે છે:

1. એકાઉન્ટનું નામ.
2. તે કેવી રીતે સાઇન ઇન કરે છે: હમણાં Claude subscription (browser માં), [API key](/features/api), કે પછીથી Claude subscription.
3. API key માટે: ccam દરેક શરૂઆતે key ક્યાંથી વાંચે છે (`env:NAME` કે `command:COMMAND`), endpoint, key કેવી રીતે મોકલાય છે અને મૉડલ.
4. જોડાવા માટેનાં ગ્રુપ, `default` ચેક કરેલું; હજી કોઈ ગ્રુપ ન હોય ત્યારે, `default` ગ્રુપ શું શેર કરે છે તે.
5. શૉર્ટકટ કમાન્ડ, જો તમારે જોઈતો હોય.
6. ખાતરી કરવા માટે સારાંશ.

`Esc` એક પગલું પાછળ જાય છે, અને પહેલા પગલે વિઝાર્ડ બંધ કરે છે.

## રંગો

રંગો Claude Code ના ટર્મિનલ UI ની ભૂમિકાઓ અનુસરે છે, તેથી ccam તેની બાજુમાં સ્વાભાવિક લાગે છે; ગ્રુપનાં નામને તેમના નામ પરથી રંગ મળે છે. ccam ટર્મિનલને તેનું background પૂછે છે અને light કે dark theme પસંદ કરે છે. `config.toml` માં તમે જાતે પણ એક સેટ કરી શકો છો:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` themes લાલ-લીલા રંગઅંધત્વ માટે છે અને `-ansi` themes ટર્મિનલના પોતાના 16 રંગો વાપરે છે. `NO_COLOR` રંગો બંધ કરે છે.

## સલામતી અને ખાસ કિસ્સા

- ડેશબોર્ડ કમાન્ડ જે functions બોલાવે છે તે જ બોલાવે છે, તેથી દરેક નિયમ લાગુ પડે છે: ડેટા ખસે તે પહેલાં યોજના, ચાલુ એકાઉન્ટ માટે ઇનકાર, બૅકઅપ, અને ક્યારેય એકાઉન્ટ ન છોડતા લૉગિન ટોકન.
- ડેશબોર્ડમાં dry run નથી: નામ વગરનું `ccam --dry-run` આ ફોલ્ડરનું એકાઉન્ટ કેવી રીતે શરૂ થશે તે છાપે છે, અને કોઈ એકાઉન્ટ પર `o` ફક્ત એ એક શરૂઆતનો dry run આપે છે.
- Claude Code શરૂ થાય કે લૉગિન ખૂલે તે પહેલાં ટર્મિનલ પાછું સામાન્ય થાય છે.
- dialog માટે નાની પડતી સ્ક્રીન પહેલાં ટૅબની હરોળો છોડે છે; લાઇનો wrap થવાને બદલે `…` સાથે કપાય છે.
