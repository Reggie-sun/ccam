একাধিক Claude Code অ্যাকাউন্ট চালানোর সবচেয়ে সহজ উপায় হলো প্রতিটি অ্যাকাউন্টের জন্য একটি শেল অ্যালিয়াস। ccam ভেতরে একই কাজ করে এবং তার সঙ্গে শেয়ার করা, অ্যাকাউন্ট বদল ও ব্যবহার ট্র্যাক করার সুবিধা যোগ করে।

| | শেল অ্যালিয়াস | ccam |
| --- | --- | --- |
| আলাদা লগইন | হ্যাঁ | হ্যাঁ |
| প্রতিটি অ্যাকাউন্টের সেটআপ | `~/.bashrc` সম্পাদনা, লগইন | `ccam add` |
| স্ক্রিপ্ট ও অন্যান্য প্রোগ্রামে কাজ করে | না, অ্যালিয়াস শুধু শেলে কাজ করে | হ্যাঁ, `claude2` একটি আসল কমান্ড |
| শেয়ার করা সেটিংস, `CLAUDE.md`, এক্সটেনশন | হাতে কপি বা লিংক | আইটেম ধরে, ব্যাকআপসহ |
| শেয়ার করা MCP সার্ভার | হাতে, প্রতিটি অ্যাকাউন্টে | একবার `ccam mcp add` |
| অন্য অ্যাকাউন্টে কথোপকথন চালিয়ে যাওয়া | না | `ccs next --continue` |
| সব অ্যাকাউন্টের ব্যবহার | না | `ccs usage` |
| সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্ট বাছাই | না | `ccs next --auto` |
| স্ট্যাটাস লাইনে অ্যাকাউন্টের নাম | না | `ccam statusline install` |
| ভাঙা লিংক মেরামত | হাতে | `ccam doctor --fix` |
| বাড়তি সফটওয়্যার | কিছু না | একটি স্ট্যাটিক বাইনারি |

আপনার দুটি অ্যাকাউন্ট থাকলে এবং সেগুলোর মধ্যে কিছুই শেয়ার করতে না চাইলে অ্যালিয়াস বেছে নিন। অ্যাকাউন্টগুলোকে একটিই সেটআপের মতো ব্যবহার করতে চাইলে ccam বেছে নিন। আপনি অ্যালিয়াস দিয়ে শুরু করে পরে ccam-এ যেতে পারেন: `ccam import` বিদ্যমান `~/.claude-*` ফোল্ডারগুলোকে যেখানে আছে সেখানেই নিবন্ধন করে।
