একাধিক Claude Code অ্যাকাউন্ট চালানোর সবচেয়ে সহজ উপায় হলো প্রতিটি অ্যাকাউন্টের জন্য একটি শেল অ্যালিয়াস। ccam ভেতরে একই কাজ করে এবং তার সঙ্গে শেয়ার করা, অ্যাকাউন্ট বদল ও ব্যবহার ট্র্যাক করার সুবিধা যোগ করে।

## অ্যালিয়াস দিয়ে সেটআপ

প্রতিটি অতিরিক্ত অ্যাকাউন্টের জন্য `~/.bashrc` বা `~/.zshrc`-এ একটি লাইন যোগ করুন, একটি নতুন টার্মিনাল খুলুন এবং লগইন করতে অ্যালিয়াসটি একবার চালান:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

`claude` আপনার প্রথম অ্যাকাউন্টই থাকে, আর `claude-work` দ্বিতীয়টি চালু করে। এটিই সেই পদ্ধতি, যা [Claude Code-এর ডকুমেন্টেশনে বর্ণনা করা আছে](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts)।

## ccam দিয়ে সেটআপ

ccam ইনস্টল করুন এবং অ্যাকাউন্টটি যোগ করুন, এখানে তার নিজস্ব একটি শর্টকাট কমান্ডসহ:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add work --shortcut ccwork
```

`ccam work` ও `ccwork` অ্যাকাউন্টটি চালু করে, এবং দুটিই স্ক্রিপ্টেও কাজ করে।

## পাশাপাশি

| | শেল অ্যালিয়াস | ccam |
| --- | --- | --- |
| আলাদা লগইন | হ্যাঁ | হ্যাঁ |
| প্রতিটি অ্যাকাউন্টের সেটআপ | `~/.bashrc` সম্পাদনা, লগইন | `ccam add` |
| স্ক্রিপ্ট ও অন্যান্য প্রোগ্রামে কাজ করে | না, অ্যালিয়াস শুধু শেলে কাজ করে | হ্যাঁ, `ccam work` ও `ccwork`-এর মতো শর্টকাট আসল কমান্ড |
| শেয়ার করা সেটিংস, `CLAUDE.md`, এক্সটেনশন | হাতে কপি বা লিংক | হ্যাঁ, আইটেম ধরে বেছে নেওয়া যায়, ব্যাকআপসহ |
| শেয়ার করা MCP সার্ভার | হাতে, প্রতিটি অ্যাকাউন্টে | একবার `ccam mcp add` |
| অন্য অ্যাকাউন্টে কথোপকথন চালিয়ে যাওয়া | না | `ccam next --continue` |
| সব অ্যাকাউন্টের ব্যবহার | না | `ccam usage` |
| সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্ট বাছাই | না | `ccam next --auto` |
| সীমায় পৌঁছালে একটি `-p` কাজ অন্য অ্যাকাউন্ট হিসেবে আবার চালানো | না | `ccam --fallback` |
| প্রতিটি প্রকল্প ফোল্ডারের জন্য একটি অ্যাকাউন্ট | না | `ccam folder` |
| স্ট্যাটাস লাইনে অ্যাকাউন্টের নাম | না | `ccam statusline install` |
| ভাঙা লিংক মেরামত | হাতে | `ccam doctor --fix` |
| বাড়তি সফটওয়্যার | কিছু না | একটি স্ট্যাটিক বাইনারি |

আপনার দুটি অ্যাকাউন্ট থাকলে এবং সেগুলোর মধ্যে কিছুই শেয়ার করতে না চাইলে অ্যালিয়াস বেছে নিন। অ্যাকাউন্টগুলোকে একটিই সেটআপের মতো ব্যবহার করতে চাইলে ccam বেছে নিন। আপনি অ্যালিয়াস দিয়ে শুরু করে পরে ccam-এ যেতে পারেন: `ccam import` বিদ্যমান `~/.claude-*` ফোল্ডারগুলোকে যেখানে আছে সেখানেই নিবন্ধন করে।
