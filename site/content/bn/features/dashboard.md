স্ট্যান্ডার্ড ইনপুট ও আউটপুট টার্মিনাল হলে আর্গুমেন্ট ছাড়া `ccam` একটি পূর্ণ-স্ক্রিন ড্যাশবোর্ড খোলে; অন্যথায় এটি `ccam list` প্রিন্ট করে। ড্যাশবোর্ড প্রতিটি অ্যাকাউন্ট তার ব্যবহার ও গ্রুপসহ দেখায়, এবং কমান্ডগুলো যা করে তা-ই করে: চালু করা, যোগ করা, লগইন, গ্রুপ বদলানো, ফোল্ডারের নিয়ম ঠিক করা, যাচাই ও মেরামত। চালু করলে এটি বন্ধ হয়ে যায়; অ্যাকাউন্ট যোগ করা বা লগইনের সময় এটি টার্মিনাল ছেড়ে দেয় এবং পরে ফিরে আসে।

```console
 ccam v0.9.0 · 3 accounts · 2 groups         ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health

    # Account     Email             5-hour         7-day Last  Groups
 ❯ 1. personal ✔   me@example.com    █████▊░░  72%   41% 2h    default
   2. work      ▸• dev@company.com   ██░░░░░░  25%  100% now   default team
   3. side         -                 ✘ not logged in         -     no group

 ✔ personal is the default account
 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

প্রথম ফ্রেমটি শুধু `config.toml` থেকেই আঁকা হয়, 100 ms-এর অনেক কম সময়ে; প্রতিটি অ্যাকাউন্ট উত্তর দেওয়ার সঙ্গে সঙ্গে ব্যবহার পূরণ হয়। শতাংশ ৮০% থেকে হলুদ আর ১০০%-এ লাল হয়ে যায়, এবং কোনো খোঁজ ব্যর্থ হওয়ার পর ক্যাশ থেকে আসা মানগুলো ফিকে করে আঁকা হয়।

## ট্যাব

| ট্যাব | কী দেখায় | কী |
| --- | --- | --- |
| Accounts | নম্বর, নাম, ইমেইল, ৫ ঘণ্টার বার, ৭ দিনের ব্যবহার, সর্বশেষ ব্যবহার, গ্রুপ; `✔` ডিফল্ট, `▸` এই ফোল্ডারের অ্যাকাউন্ট, `•` চলছে | নিচে দেখুন |
| Groups | প্রতিটি গ্রুপ, সেটি কী শেয়ার করে ও তার অ্যাকাউন্ট, এবং যে অ্যাকাউন্টগুলো কোনো গ্রুপে নেই | `enter` সম্পাদনা, `n` নতুন, `e` নাম বদল, `x` সরানো |
| Folders | [`ccam folder`](/features/folder)-এর নিয়মগুলো এবং যেটি এখানে প্রযোজ্য | `n` এখানে একটি অ্যাকাউন্ট ব্যবহার, `enter` বদলানো, `x` সরানো |
| Extensions | [`ccam ext`](/features/ext) যা দেখায়, প্রতিটি এক্সটেনশন একবার, যে গ্রুপগুলো থেকে আসে সেগুলোসহ | `r` আবার লোড |
| Health | [`ccam doctor`](/features/doctor) যা জানায় | `f` মেরামত (`doctor --fix`) |

`←`/`→` বা `Tab` ট্যাব বদলায়, `?` বর্তমান ট্যাবের কীগুলোর তালিকা দেয়, `r` স্বল্পমেয়াদি ক্যাশ ছাড়া আবার ব্যবহার খোঁজে, আর `q` বা `Esc` বন্ধ করে।

## Accounts ট্যাবের কী

| কী | কী করে |
| --- | --- |
| `Enter` | নির্বাচিত অ্যাকাউন্ট হিসেবে Claude Code চালু করে |
| `1`–`9` | ওই নম্বরের অ্যাকাউন্টে যায়; 12-র জন্য দ্রুত `1` `2` টাইপ করুন। শুধু `Enter` চালু করে |
| `↑`/`↓`, `k`/`j` | সরায় |
| `n` | [`ccam next --auto`](/features/next) যে অ্যাকাউন্ট বেছে নিত সেটি চালু করে |
| `o` | অপশনসহ চালু করে: `--continue`, `--resume`, অন্য আর্গুমেন্ট, বা একটি ড্রাই রান |
| `u` | ব্যবহারের বিস্তারিত: ৫ ঘণ্টা, ৭ দিন ও মডেলের উইন্ডো, তাদের রিসেট ও সংখ্যাগুলো কোথা থেকে আসে |
| `a` | একটি অ্যাকাউন্ট যোগ করে (নিচের উইজার্ড) |
| `l` | আবার লগইন করে |
| `s` | অ্যাকাউন্টের গ্রুপগুলো বেছে নেয় |
| `d` | এটিকে ডিফল্ট অ্যাকাউন্ট করে |
| `f` | বর্তমান ফোল্ডারে এটি ব্যবহার করে |
| `e` | এর নাম বদলায় |
| `c` | এর শর্টকাট কমান্ড ঠিক করে বা সরায় |
| `x` | এটি সরায় (আগে জিজ্ঞেস করে, No থেকে শুরু করে) |

## গ্রুপ বদলানো

Groups ট্যাবে `Enter` এডিটর খোলে: বাঁ দিকে আইটেম, ডান দিকে অ্যাকাউন্ট, বদলাতে `Tab`, টগল করতে `Space`। কোনো অ্যাকাউন্ট যে আইটেম ইতিমধ্যে অন্য গ্রুপ থেকে পায়, সেটি কারণসহ ধূসর করে দেখানো হয়, যে অ্যাকাউন্ট কোনো আইটেম দুবার পেত সেটিও; একটি আইটেম কেবল একটি গ্রুপ থেকেই আসতে পারে। `Enter` পরিকল্পনা দেখায়:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

গ্রুপের কপি থেকে আলাদা কোনো ফাইলের বিষয়ে আগে জিজ্ঞেস করা হয় (গ্রুপেরটা রাখবেন, আমারটা ব্যবহার করবেন, নাকি মার্জ করবেন)। তারপর পরিবর্তনটি ব্যাকগ্রাউন্ডে চলে, [`ccam group`](/features/share)-এর একই কোড দিয়ে: কনফিগ আগে সংরক্ষিত হয়, প্রতিটি অ্যাকাউন্টের ডেটা ক্রমানুসারে সরে, এবং মূল ফাইলগুলো `.ccam-backup/`-এ যায়। যে পরিবর্তন চলমান কোনো অ্যাকাউন্টের ডেটা সরাত, সেটি অ্যাকাউন্টের নামসহ প্রত্যাখ্যান করা হয়।

## অ্যাকাউন্ট যোগ করা

`a` সেই উইজার্ডটি খোলে যা `ccam add`-ও টার্মিনালে ব্যবহার করে:

1. অ্যাকাউন্টের নাম।
2. এটি কীভাবে সাইন ইন করবে: এখনই একটি Claude সাবস্ক্রিপশন (ব্রাউজারে), একটি [API key](/features/api), বা পরে একটি Claude সাবস্ক্রিপশন।
3. API key-এর ক্ষেত্রে: প্রতিবার চালু করার সময় ccam key কোথা থেকে পড়বে (`env:NAME` বা `command:COMMAND`), এন্ডপয়েন্ট, key কীভাবে পাঠানো হবে এবং মডেল।
4. যোগ দেওয়ার মতো গ্রুপগুলো, `default` চেক করা অবস্থায়; কোনো গ্রুপ তৈরি হওয়ার আগে, `default` গ্রুপ কী শেয়ার করবে।
5. চাইলে একটি শর্টকাট কমান্ড।
6. নিশ্চিত করার জন্য একটি সারাংশ।

`Esc` এক ধাপ পিছিয়ে যায়, এবং প্রথম ধাপে উইজার্ডটি বন্ধ করে।

## রং

রংগুলো Claude Code-এর টার্মিনাল UI-এর ভূমিকাগুলো অনুসরণ করে, তাই এর পাশে ccam মানানসই দেখায়; গ্রুপের নাম তার নাম থেকেই একটি রং পায়। ccam টার্মিনালকে তার ব্যাকগ্রাউন্ড জিজ্ঞেস করে এবং একটি হালকা বা গাঢ় থিম বেছে নেয়। `config.toml`-এ নিজে একটি থিম ঠিক করে দিন:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` থিমগুলো লাল-সবুজ বর্ণান্ধতার জন্য, আর `-ansi` থিমগুলো টার্মিনালের নিজস্ব 16টি রং ব্যবহার করে। `NO_COLOR` রং বন্ধ করে দেয়।

## নিরাপত্তা ও বিশেষ ক্ষেত্র

- ড্যাশবোর্ড কমান্ডগুলোর একই ফাংশন ডাকে, তাই প্রতিটি নিয়ম বহাল থাকে: ডেটা সরানোর আগে পরিকল্পনা, চলমান অ্যাকাউন্টের ক্ষেত্রে প্রত্যাখ্যান, ব্যাকআপ, এবং লগইন টোকেন যা কখনও অ্যাকাউন্ট ছেড়ে যায় না।
- ড্যাশবোর্ডে কোনো ড্রাই রান নেই: নাম ছাড়া `ccam --dry-run` প্রিন্ট করে এই ফোল্ডারের অ্যাকাউন্ট কীভাবে চালু হবে, আর কোনো অ্যাকাউন্টে `o` চাপলে শুধু সেই একবারের চালুর জন্য ড্রাই রানের বিকল্প পাওয়া যায়।
- Claude Code চালু হওয়ার বা লগইন খোলার আগে টার্মিনাল আগের অবস্থায় ফেরে।
- কোনো ডায়ালগের জন্য স্ক্রিন খুব ছোট হলে আগে ট্যাবের সারিগুলো বাদ যায়; লাইনগুলো মোড়ানোর বদলে `…` দিয়ে কেটে দেওয়া হয়।
