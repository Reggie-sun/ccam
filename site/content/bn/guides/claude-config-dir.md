`CLAUDE_CONFIG_DIR` Claude Code-কে বলে দেয় `~/.claude`-এর বদলে কোন ফোল্ডার ব্যবহার করতে হবে। অ্যাকাউন্টভিত্তিক সবকিছু সেখানে থাকে: লগইন, সেটিংস, MCP সার্ভার, প্লাগইন ও কথোপকথনের ইতিহাস। এটিকে আলাদা আলাদা ফোল্ডারে নির্দেশ করলে আপনি আলাদা অ্যাকাউন্ট পান।

```sh
CLAUDE_CONFIG_DIR=~/.claude-work claude
```

## ফোল্ডারের ভেতরে কী থাকে

Claude Code 2.1.302 দিয়ে যাচাই করা:

| পাথ | বিষয়বস্তু | শেয়ারযোগ্য |
| --- | --- | --- |
| `.credentials.json` | লগইন টোকেন (Linux), MCP OAuth টোকেন | না |
| `.claude.json` | অ্যাকাউন্টের তথ্য, ব্যবহারকারীর MCP সার্ভার, প্রকল্পভিত্তিক অবস্থা | না (MCP সার্ভার আলাদাভাবে) |
| `settings.json` | অনুমতি, হুক, মডেল, স্ট্যাটাস লাইন, প্লাগইন | হ্যাঁ |
| `CLAUDE.md` | গ্লোবাল নির্দেশনা | হ্যাঁ |
| `agents/`, `commands/`, `skills/`, `plugins/` | এক্সটেনশন | হ্যাঁ |
| `projects/` | `.jsonl` ফাইল হিসেবে কথোপকথন, প্রকল্পভিত্তিক মেমরি | হ্যাঁ |
| `history.jsonl` | প্রম্পটের ইতিহাস | হ্যাঁ |
| `sessions/`, `shell-snapshots/`, `cache/` এবং অন্যান্য | রানটাইম অবস্থা | না |

## দুটি খুঁটিনাটি যা অনেককে বিপাকে ফেলে

**`CLAUDE_CONFIG_DIR` ছাড়া `.claude.json` `~/.claude`-এর ভেতরে থাকে না।** তখন Claude Code এটি ফোল্ডারের পাশে `~/.claude.json`-এ রাখে। আপনি যদি `CLAUDE_CONFIG_DIR=~/.claude` ব্যবহার করা শুরু করেন, Claude Code এর বদলে `~/.claude/.claude.json` খোঁজে এবং আপনার অ্যাকাউন্ট খুঁজে পায় না। `ccam import` দুটিকে লিংক করে এটি সামলায়।

**macOS-এ লগইন ফোল্ডারে নয়, Keychain-এ থাকে।** Claude Code এটি `Claude Code-credentials` নামে রাখে, আর `CLAUDE_CONFIG_DIR` নির্ধারণ করা থাকলে নামের পরে ফোল্ডার পাথের একটি ছোট হ্যাশ যোগ হয়। তাই আলাদা ফোল্ডার আলাদা Keychain এন্ট্রি পায়। Keychain লিখতে না দিলে Claude Code ফোল্ডারের `.credentials.json`-এ ফিরে যায়।

## ফোল্ডারগুলোর মধ্যে শেয়ার করা

সিম্বলিক লিংক কাজ করে: Claude Code লিংক করা `settings.json` বা `projects/` ফোল্ডারের মাধ্যমে পড়ে ও লেখে, এবং লিংকটি অক্ষত রাখে। ব্যতিক্রম হলো MCP সার্ভার, কারণ সেগুলো লগইনের সঙ্গে `.claude.json` শেয়ার করে; এর বদলে সেগুলো `--mcp-config` দিয়ে দিন।

ccam ঠিক এই নিয়মগুলোর ওপর ভিত্তি করে তৈরি। এটি কীভাবে ফোল্ডার লিংক করে তা জানতে [শেয়ার করা](/docs/sharing) দেখুন, আর সামগ্রিক চিত্রের জন্য [একাধিক অ্যাকাউন্টের গাইড](/guides/multiple-claude-code-accounts) দেখুন।
