Claude Code-এর একটি অ্যাকাউন্ট ব্যবহারের সীমায় পৌঁছালে আপনার নিজের অন্য একটি অ্যাকাউন্টে একই কথোপকথন চালিয়ে যান: একবার কথোপকথনের ইতিহাস শেয়ার করুন, তারপর `ccs next --continue` চালান। আপনার যদি একটিই অ্যাকাউন্ট থাকে, Claude Code যে রিসেট সময় দেখায় ততক্ষণ অপেক্ষা করুন।

## সীমায় পৌঁছানোর আগে

অ্যাকাউন্টগুলো এমনভাবে সেট আপ করুন যাতে একটি কমান্ডেই বদল করা যায়:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

এখন কাজ করার সময় স্ট্যাটাস লাইন অ্যাকাউন্ট ও তার ৫ ঘণ্টার ব্যবহার দেখায়, তাই সীমায় পৌঁছানো আর অপ্রত্যাশিত থাকে না।

## সীমায় পৌঁছালে

Claude Code থেকে বেরিয়ে আসুন (`/exit`), তারপর:

```sh
ccs usage
```

```console
 1 personal  ████████ 100% 22분        █████░░░  68% 1일 9시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
```

সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্টে কথোপকথনটি খুলুন:

```sh
ccs next --auto --continue
```

Claude Code `work` হিসেবে চালু হয়, বর্তমান ফোল্ডারের সবচেয়ে সাম্প্রতিক কথোপকথনসহ, এ পর্যন্ত বলা সবকিছু নিয়ে।

## যা মনে রাখবেন

- যে ফোল্ডারে কাজ করছিলেন সেখানেই `ccs next --continue` চালান; কথোপকথন প্রকল্প ফোল্ডার অনুযায়ী সংরক্ষিত হয়।
- একই সময়ে একই কথোপকথনে দুটি অ্যাকাউন্ট চালাবেন না। চেষ্টা করলে ccam আপনাকে সতর্ক করে।
- অন্য অ্যাকাউন্টটিকেও একই গ্রুপে কথোপকথনের ইতিহাস শেয়ার করতে হবে।
- এভাবে অ্যাকাউন্ট বদল করতে পারবেন কি না, তা প্রতিটি অ্যাকাউন্টের শর্তাবলির ওপর নির্ভর করে।

`ccs usage` ও `ccs next`-এর প্রতিটি অপশনের জন্য [ব্যবহারের সীমা](/docs/usage-limits) দেখুন।
