কোনো অ্যাকাউন্ট ব্যবহারের সীমায় (প্রায়ই rate limit বলা হয়) পৌঁছালে আপনার সামনে দুটি পথ: সীমা রিসেট হওয়া পর্যন্ত অপেক্ষা করুন, অথবা একই কথোপকথন এখনই আপনার অন্য একটি অ্যাকাউন্টে চালিয়ে যান। ccam-এ দ্বিতীয় পথটি একটি কমান্ড: `ccam next --auto --continue`।

## Claude Code-এর কী কী সীমা আছে?

Pro ও Max প্ল্যানে Claude Code-এর [৫ ঘণ্টার সেশন সীমা ও একটি সাপ্তাহিক সীমা](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan) আছে। দুটিই ওয়েব ও অ্যাপের Claude-এর সঙ্গে শেয়ার করা, এবং ব্যবহার একই সময়ে দুটি থেকেই কাটে। একটি শেষ হলে Claude Code "You've hit your session limit · resets 3:45pm"-এর মতো একটি [বার্তা দেখায়](https://code.claude.com/docs/en/errors#youve-hit-your-session-limit)। মডেল বদলে লাভ হয় না, কারণ সীমা সব মডেলের ক্ষেত্রেই প্রযোজ্য।

## বিকল্প ১: রিসেটের জন্য অপেক্ষা করুন

আপনার একটিই অ্যাকাউন্ট থাকলে অপেক্ষা করুন। Claude Code-এর সাম্প্রতিক সংস্করণ [খোলা সেশনেই অপেক্ষা করে](https://code.claude.com/docs/en/interactive-mode#wait-for-a-usage-limit-to-reset) এবং সীমা রিসেট হলে নিজে থেকেই কাজ চালিয়ে যায়। Claude Code-এর ভেতরে `/usage` দেখায় আপনার প্ল্যানের সীমার কতটা ব্যবহার হয়েছে।

## বিকল্প ২: এখনই অন্য অ্যাকাউন্টে চালিয়ে যান

আপনার দ্বিতীয় একটি অ্যাকাউন্ট থাকলে সঙ্গে সঙ্গে একই কথোপকথন চালিয়ে যেতে পারেন। একবার সেট আপ করুন:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
ccam group set default --add history
ccam statusline install
```

এখন কাজ করার সময় স্ট্যাটাস লাইন অ্যাকাউন্ট ও তার ৫ ঘণ্টার ব্যবহার দেখায়, তাই সীমায় পৌঁছানো আর অপ্রত্যাশিত থাকে না।

সীমায় পৌঁছালে Claude Code থেকে বেরিয়ে আসুন (`/exit`), তারপর:

```sh
ccam usage
```

```console
 1 personal  just now
   5-hour   ████████████████████ 100%  resets in 22m
   Weekly   ██████████████░░░░░░  68%  resets in 1d 9h
 2 work      just now
   5-hour   ██░░░░░░░░░░░░░░░░░░   8%  resets in 4h 12m
   Weekly   ████░░░░░░░░░░░░░░░░  19%  resets in 5d 2h
→ Most headroom: work   (open it with ccam next --auto)
```

সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্টে কথোপকথনটি খুলুন:

```sh
ccam next --auto --continue
```

Claude Code `work` হিসেবে চালু হয়, বর্তমান ফোল্ডারের সবচেয়ে সাম্প্রতিক কথোপকথনসহ, এ পর্যন্ত বলা সবকিছু নিয়ে। ইতিহাস শেয়ার করা থাকলে (ওপরের `ccam group set default --add history`) দুটি অ্যাকাউন্টই একই কথোপকথনে কাজ করে; তা না থাকলে Claude Code কথোপকথনটি `work`-এ কপি করে, এবং ccam আপনাকে জানায় প্রথম উত্তরে কতগুলো টোকেন আবার পড়তে হবে।

Claude Code-এ [ccam প্লাগইন](/docs/install#claude-code-plugin) থাকলে সীমায় থেমে যাওয়া সেশন একটি নোটিফিকেশন দেখায় এবং পূর্ণ উইন্ডোটি রেকর্ড করে, তাই `ccam next --auto` রিসেটের আগে ওই অ্যাকাউন্টটি আবার বেছে নেয় না। `/ccam:switch` (বা `/ccam:switch work`) কথোপকথনটি `ccam next --continue`-এর জন্য টুকে রাখে, তাই এটি ঠিক সেই কথোপকথনটিই চালিয়ে যায়।

**Team ও Enterprise সিট।** স্বয়ংক্রিয় অ্যাকাউন্ট বাছাই (`ccam next`, `--fallback`, `ccam pick`, ড্যাশবোর্ডের `n` এবং আপনি চালু করলে [`auto_switch`](/features/next#auto-switch)) একই Claude Team বা Enterprise প্রতিষ্ঠানের সিটগুলোর মধ্যেও বদল করে, যা Anthropic-এর শর্তাবলি লঙ্ঘন করতে পারে। এর ওপর নির্ভর করার আগে [প্রশ্নোত্তর](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) পড়ুন এবং আপনার প্রতিষ্ঠান ও Anthropic-এর কাছ থেকে জেনে নিন।

## ccam কি নিজে থেকে অ্যাকাউন্ট বদল করে?

শুধু আপনি চালু করলে।

- ডিফল্টভাবে আপনি কাজ করার সময় ccam চলে না: এটি Claude Code চালু করে এবং নিজের জায়গায় সেটিকে বসিয়ে দেয়, তাই কখন বদলাবেন তা আপনি ঠিক করেন। `ccam next --auto` সবচেয়ে কম ৫ ঘণ্টার ব্যবহারের অ্যাকাউন্ট বেছে নেয়, যেগুলো 100%-এ আছে বা লগইন করা নেই সেগুলো বাদ দেয়, এবং একটি Team বা Enterprise প্রতিষ্ঠানের ভেতরে, বা ব্যক্তিগত প্ল্যানগুলোর মধ্যেই থাকে।
- `config.toml`-এ `relay = true` থাকলে ccam এর বদলে সেশনের পাশাপাশি চলতে থাকে, তাই `/ccam:switch` নিজে থেকেই কথোপকথনটি চালিয়ে যায়, সেশনের অপশন, permission mode ও effort level বজায় রেখে।
- `auto_switch = true` থাকলে (Linux ও macOS; পরীক্ষামূলক) ccam বদলটিও নিজেই করে: Claude Code সেশনটি তার সীমায় থামালে এবং একই ধরনের অন্য একটি অ্যাকাউন্টে জায়গা থাকলে, ccam সেশনটি শেষ করে এবং কথোপকথনটি সেখানে চালিয়ে যায় ([শর্ত ও খরচ](/features/next#auto-switch))।

অন্য কিছু টুল এর বদলে চলমান সেশনের লগইন অদলবদল করে; [ccam ও অন্যান্য অ্যাকাউন্ট সুইচার](/compare/account-switchers) পাতায় পার্থক্যটি ব্যাখ্যা করা আছে।

## যা মনে রাখবেন

- যে ফোল্ডারে কাজ করছিলেন সেখানেই `ccam next --continue` চালান; কথোপকথন প্রকল্প ফোল্ডার অনুযায়ী সংরক্ষিত থাকে।
- একই কথোপকথনে একই সময়ে দুটি অ্যাকাউন্ট চালাবেন না। এমন চেষ্টা করলে ccam সতর্ক করে।
- শেয়ার করা ইতিহাস না থাকলে কথোপকথনটি অন্য অ্যাকাউন্টে কপি হয় এবং দুটি কপি যার যার পথে চলে; `/rewind` যে চেকপয়েন্ট থেকে কোড ফিরিয়ে আনে, সেগুলো প্রথম অ্যাকাউন্টেই থেকে যায়।
- নতুন অ্যাকাউন্টে প্রথম বার্তা স্বাভাবিকের চেয়ে বেশি সীমা খরচ করতে পারে, কারণ সেই অ্যাকাউন্ট এখনো কথোপকথনটি ক্যাশ করেনি। `ccam next --continue --brief` এর বদলে সেটি একটি ছোট সারাংশ দিয়ে শুরু করে।
- এভাবে অ্যাকাউন্ট বদল করা যাবে কি না, তা প্রতিটি অ্যাকাউন্টে প্রযোজ্য শর্তাবলির ওপর নির্ভর করে।
