প্রতিটি অ্যাকাউন্টকে আলাদা কনফিগারেশন ফোল্ডার দিন। Claude Code `CLAUDE_CONFIG_DIR` এনভায়রনমেন্ট ভেরিয়েবল থেকে ফোল্ডারটি পড়ে, এবং প্রতিটি ফোল্ডারে নিজস্ব লগইন, সেটিংস ও ইতিহাস থাকে। তাই প্রতিটি অ্যাকাউন্ট লগইন অবস্থায় থাকে এবং আপনি সেগুলো একই সময়ে চালাতে পারেন। আপনি এটি শেল অ্যালিয়াস দিয়ে হাতে সেট আপ করতে পারেন, অথবা ccam-কে দিয়ে করাতে পারেন।

## কীভাবে হাতে সেট আপ করবেন?

[Claude Code-এর ডকুমেন্টেশনে এই পদ্ধতিই বর্ণনা করা আছে](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts)। প্রতিটি বাড়তি অ্যাকাউন্টের জন্য `~/.bashrc` বা `~/.zshrc`-এ একটি করে লাইন যোগ করুন:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

একটি নতুন টার্মিনাল খুলে `claude-work` চালান। ফোল্ডারটি নতুন বলে Claude Code আপনাকে লগইন করতে বলে। এরপর থেকে `claude` আপনার প্রথম অ্যাকাউন্ট আর `claude-work` দ্বিতীয়টি। প্রতিটি অ্যাকাউন্টের জন্য একটি করে অ্যালিয়াস যোগ করুন, প্রতিটির নিজস্ব ফোল্ডারসহ।

WSL ছাড়া Windows-এ আপনার প্রোফাইলে (`notepad $PROFILE`) একটি PowerShell ফাংশন একই কাজ করে:

```powershell
function claude-work { $env:CLAUDE_CONFIG_DIR = "$HOME\.claude-work"; try { claude @args } finally { Remove-Item Env:CLAUDE_CONFIG_DIR } }
```

## অ্যালিয়াস পদ্ধতিতে কী বাদ থাকে?

দুটি অ্যাকাউন্টের জন্য এটি ভালোই কাজ করে। যা জানা দরকার:

- প্রতিটি ফোল্ডার খালি অবস্থায় শুরু হয়: কোনো সেটিংস নেই, `CLAUDE.md` নেই, MCP সার্ভার নেই, agents বা skills নেই। যা দরকার তা আপনি কপি বা লিংক করেন, এবং কপিগুলো নিজেই হালনাগাদ রাখেন।
- অ্যালিয়াস শুধু ইন্টারঅ্যাকটিভ শেলে থাকে। স্ক্রিপ্ট, Makefile ও অন্যান্য প্রোগ্রাম সেগুলো দেখতে পায় না।
- MCP সার্ভার লগইনের পাশেই `.claude.json`-এ থাকে, তাই সেগুলো সহজে ফোল্ডারগুলোর মধ্যে লিংক করা যায় না।
- কথোপকথন যে অ্যাকাউন্টে শুরু হয়েছে সেখানেই থাকে, তাই অন্য অ্যাকাউন্টে সেটি চালিয়ে যেতে পারবেন না।
- সব অ্যাকাউন্টের ব্যবহার একসঙ্গে দেখানোর মতো কিছু নেই।

## এর বদলে কি /login দিয়ে অ্যাকাউন্ট বদল করা যায়?

হ্যাঁ, যদি মাঝেমধ্যে বদল করেন। Claude Code-এর ভেতরে `/login` টাইপ করলে আপনি যে ফোল্ডারে আছেন তার [অ্যাকাউন্ট বদলে যায়](https://code.claude.com/docs/en/quickstart)। একবারে কেবল একটি অ্যাকাউন্ট লগইন থাকে, তাই প্রতিবার বদলের সময় আবার লগইন করতে হয়, এবং দুটি অ্যাকাউন্ট পাশাপাশি চালানো যায় না। আলাদা ফোল্ডার ব্যবহার করলে এই দুটি সমস্যাই এড়ানো যায়।

## ccam দিয়ে কীভাবে সেট আপ করবেন?

ccam একই ধারণাকে স্বয়ংক্রিয় করে এবং যে অংশগুলো নেই সেগুলো যোগ করে:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

এখন `ccam personal` ও `ccam work` দুটি অ্যাকাউন্ট চালু করে, আর `ccwork`-ও, যে শর্টকাটটি আপনি work অ্যাকাউন্টকে দিয়েছেন। এগুলো অ্যালিয়াস নয়, আসল প্রোগ্রাম, তাই স্ক্রিপ্টেও কাজ করে। তালিকা থেকে অ্যাকাউন্ট বেছে নিতে শুধু `ccam` চালান, আর একটি অ্যাকাউন্টকে ডিফল্ট করতে `ccam use work` চালান।

সেটিংস, `CLAUDE.md`, MCP সার্ভার ও এক্সটেনশন শুরু থেকেই শেয়ার হয়, আর শেয়ার করা কথোপকথনের ইতিহাস চালু করে `ccam next --continue` দিয়ে অন্য অ্যাকাউন্টে কথোপকথন চালিয়ে যেতে পারেন। `ccam usage` একসঙ্গে প্রতিটি অ্যাকাউন্টের ৫ ঘণ্টা ও সাপ্তাহিক ব্যবহার দেখায়।

আপনি আগে থেকেই `~/.claude` ব্যবহার করলে, ওই অ্যাকাউন্ট আবার যোগ না করে `ccam import` চালান, অথবা এর সেটিংস, MCP সার্ভার ও এক্সটেনশন শেয়ার করা সেটিংসে কপি করতে `ccam migrate` চালান।

## কোন অ্যাকাউন্ট চলছে তা কীভাবে বুঝবেন?

Claude Code-এর ভেতরে `/status` দেখায় আপনি কোন অ্যাকাউন্টে লগইন করে আছেন। ccam-এ একবার `ccam statusline install` চালালে স্ট্যাটাস লাইন সবসময় অ্যাকাউন্টের নাম ও তার ব্যবহার দেখায়, যেমন `[work] · Opus · 5h 24% · 7d 41%`।

## এটি কি Windows ও WSL-এ কাজ করে?

Claude Code [সরাসরি Windows-এ এবং WSL-এর ভেতরে](https://code.claude.com/docs/en/setup) চলে। `CLAUDE_CONFIG_DIR` দুই জায়গাতেই কাজ করে, তাই নেটিভ Windows-এ ওপরের অ্যালিয়াস বা PowerShell ফাংশনই যথেষ্ট। ccam-ও সরাসরি Windows-এ চলে: PowerShell-এ `irm https://ccam.dev/install.ps1 | iex` দিয়ে ইনস্টল করুন, অথবা WSL-এর ভেতরে Linux-এর কমান্ড দিয়ে। শর্টকাটগুলো `ccwork.exe` হয়ে যায়, এবং `settings.json`-এর মতো ফাইল শেয়ার করতে Developer Mode লাগে ([ccam ইনস্টল করুন](/docs/install))।

## সমস্যা সমাধান

**Claude Code প্রতিবার লগইন করতে বলে।** নতুন ফোল্ডারে প্রথমবার চালু করলে সবসময় লগইন চায়। বারবার চাইলে লগইনের মেয়াদ শেষ হয়েছে বা সেটি মুছে গেছে: `ccam login work` চালান (অথবা অ্যালিয়াসটি একবার চালিয়ে লগইন করুন)।

**একটি MCP সার্ভার শুধু একটি অ্যাকাউন্টে দেখা যায়।** সেশনের ভেতরে `claude mcp add` দিয়ে যোগ করা সার্ভার সেই অ্যাকাউন্টেরই থাকে। একটি সার্ভারকে সব অ্যাকাউন্টে নিতে `ccam mcp import work <server>` চালান।

**অ্যাকাউন্টগুলোর সেটিংস আলাদা।** `ccam share work` দেখায় অ্যাকাউন্টটি কী শেয়ার করে এবং কোন গ্রুপের মাধ্যমে; `ccam group join default work` কী বদলাবে তা দেখিয়ে তারপর অ্যাকাউন্টটিকে দিয়ে সেগুলোই শেয়ার করায় যা `default` শেয়ার করে। `ccam doctor --fix` ভাঙা লিংক ঠিক করে এবং যে ফাইল বদলায় তার প্রতিটির ব্যাকআপ রাখে।

**দুটি অ্যাকাউন্ট একই কথোপকথন খোলে।** একই কথোপকথনে একই সময়ে দুটি অ্যাকাউন্টে কাজ করবেন না। এমন চেষ্টা করলে ccam আপনাকে সতর্ক করে।

## কোনটি বেছে নেবেন?

দুটি অ্যাকাউন্ট এবং কিছুই শেয়ার না করার জন্য একটি অ্যালিয়াসই যথেষ্ট। শেয়ার করা সেটিংস ও MCP সার্ভার, আরও বেশি অ্যাকাউন্ট, এক নজরে ব্যবহার দেখা বা কথোপকথন চালিয়ে যাওয়া চাইলে ccam আপনাকে এসব হিসাব রাখার ঝামেলা থেকে বাঁচায়। [অ্যালিয়াসের সঙ্গে তুলনা](/compare/aliases) পাতায় পার্থক্যগুলো পাশাপাশি দেওয়া আছে, আর [ccam ও অন্যান্য অ্যাকাউন্ট সুইচার](/compare/account-switchers) পাতায় সেই টুলগুলোর কথা আছে যেগুলো এর বদলে একটিই লগইন অদলবদল করে।

একাধিক অ্যাকাউন্ট ব্যবহারের অনুমতি আছে কি না, তা প্রতিটি অ্যাকাউন্টের শর্তের ওপর নির্ভর করে। ব্যবহারের আগে সেগুলো দেখে নিন।
