এক কম্পিউটারে দুটি Claude Code অ্যাকাউন্ট ব্যবহার করতে প্রতিটি অ্যাকাউন্টকে আলাদা কনফিগারেশন ফোল্ডার দিন। Claude Code `CLAUDE_CONFIG_DIR` এনভায়রনমেন্ট ভেরিয়েবল থেকে ফোল্ডারটি পড়ে, এবং প্রতিটি ফোল্ডারে নিজস্ব লগইন, সেটিংস ও ইতিহাস থাকে। আপনি এটি শেল অ্যালিয়াস দিয়ে হাতে সেট আপ করতে পারেন, অথবা ccam-কে দিয়ে করাতে পারেন।

## হাতে, একটি অ্যালিয়াস দিয়ে

Claude Code-এর ডকুমেন্টেশনে এই পদ্ধতিই বর্ণনা করা আছে। প্রতিটি বাড়তি অ্যাকাউন্টের জন্য `~/.bashrc` বা `~/.zshrc`-এ একটি করে লাইন যোগ করুন:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

একটি নতুন টার্মিনাল খুলে `claude-work` চালান। ফোল্ডারটি নতুন বলে Claude Code আপনাকে লগইন করতে বলে। এরপর থেকে `claude` আপনার প্রথম অ্যাকাউন্ট আর `claude-work` দ্বিতীয়টি।

দুটি অ্যাকাউন্টের জন্য এটি ভালোই কাজ করে। যা জানা দরকার:

- প্রতিটি ফোল্ডার খালি অবস্থায় শুরু হয়: কোনো সেটিংস নেই, `CLAUDE.md` নেই, MCP সার্ভার নেই, agents বা skills নেই। যা দরকার তা আপনি কপি বা লিংক করেন, এবং কপিগুলো নিজেই হালনাগাদ রাখেন।
- অ্যালিয়াস শুধু ইন্টারঅ্যাকটিভ শেলে থাকে। স্ক্রিপ্ট, Makefile ও অন্যান্য প্রোগ্রাম সেগুলো দেখতে পায় না।
- MCP সার্ভার লগইনের পাশেই `.claude.json`-এ থাকে, তাই সেগুলো সহজে ফোল্ডারগুলোর মধ্যে লিংক করা যায় না।
- কথোপকথন যে অ্যাকাউন্টে শুরু হয়েছে সেখানেই থাকে, তাই অন্য অ্যাকাউন্টে সেটি চালিয়ে যেতে পারবেন না।
- সব অ্যাকাউন্টের ব্যবহার একসঙ্গে দেখানোর মতো কিছু নেই।

## ccam দিয়ে

ccam একই ধারণাকে স্বয়ংক্রিয় করে এবং যে অংশগুলো নেই সেগুলো যোগ করে:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

এখন `ccam personal` ও `ccam work` দুটি অ্যাকাউন্ট চালু করে, আর `ccwork`-ও, যে শর্টকাটটি আপনি work অ্যাকাউন্টকে দিয়েছেন। এগুলো অ্যালিয়াস নয়, আসল প্রোগ্রাম, তাই স্ক্রিপ্টেও কাজ করে। সেটিংস, `CLAUDE.md`, MCP সার্ভার ও এক্সটেনশন শুরু থেকেই শেয়ার হয়, আর শেয়ার করা কথোপকথনের ইতিহাস চালু করে `ccam next --continue` দিয়ে অন্য অ্যাকাউন্টে কথোপকথন চালিয়ে যেতে পারেন।

আপনি আগে থেকেই `~/.claude` ব্যবহার করলে, ওই অ্যাকাউন্ট আবার যোগ না করে `ccam import` চালান, অথবা এর সেটিংস, MCP সার্ভার ও এক্সটেনশন শেয়ার করা সেটিংসে কপি করতে `ccam migrate` চালান।

## কোনটি বেছে নেবেন

দুটি অ্যাকাউন্ট এবং কিছুই শেয়ার না করার জন্য একটি অ্যালিয়াসই যথেষ্ট। শেয়ার করা সেটিংস ও MCP সার্ভার, আরও বেশি অ্যাকাউন্ট, এক নজরে ব্যবহার দেখা বা কথোপকথন চালিয়ে যাওয়া চাইলে ccam আপনাকে এসব হিসাব রাখার ঝামেলা থেকে বাঁচায়। [তুলনা](/compare/aliases) পাতায় পার্থক্যগুলো পাশাপাশি দেওয়া আছে।
