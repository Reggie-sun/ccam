## ccam কি Anthropic-এর অফিসিয়াল টুল?

না। ccam একটি অনানুষ্ঠানিক ওপেন-সোর্স প্রকল্প। এটি Anthropic-এর সঙ্গে যুক্ত নয় এবং Anthropic এটি অনুমোদন করেনি। একাধিক অ্যাকাউন্ট পাশাপাশি চালানোর জন্য Claude Code যে `CLAUDE_CONFIG_DIR` সেটিংয়ের কথা ডকুমেন্টেশনে বলে, ccam সেটিই ব্যবহার করে।

## আমি কি একাধিক Claude Code অ্যাকাউন্ট ব্যবহার করতে পারি?

তা প্রতিটি অ্যাকাউন্টের শর্তাবলির ওপর নির্ভর করে, আর কাজের অ্যাকাউন্টের ক্ষেত্রে আপনার প্রতিষ্ঠানের নীতির ওপরও। একাধিক অ্যাকাউন্ট ব্যবহারের আগে সেগুলো দেখে নিন। ccam শুধু আপনার আগে থেকে থাকা অ্যাকাউন্টগুলোর মধ্যে বদল করা সহজ করে।

## ccam কি ব্যবহারের সীমা এড়িয়ে যায়?

না। প্রতিটি অ্যাকাউন্টের নিজস্ব সীমা থাকে। ccam সেগুলো দেখায়, এবং একটির সীমা শেষ হলে আপনার নিজের অন্য একটি অ্যাকাউন্টে কাজ চালিয়ে যেতে দেয়।

## একটি কম্পিউটারে দুটি Claude Code অ্যাকাউন্ট কীভাবে ব্যবহার করব?

`CLAUDE_CONFIG_DIR` দিয়ে প্রতিটি অ্যাকাউন্টকে আলাদা কনফিগারেশন ফোল্ডার দিন। ccam এটি আপনার হয়ে করে: প্রতিটি অ্যাকাউন্টের জন্য `ccam add` চালান, তারপর `claude1` ও `claude2` দিয়ে সেগুলো চালু করুন। হাতে কীভাবে করতে হয় তাও [গাইডে](/guides/multiple-claude-code-accounts) দেখানো আছে।

## অন্য অ্যাকাউন্টে একটি কথোপকথন কীভাবে চালিয়ে যাব?

`ccam share <name> --history on` দিয়ে দুটি অ্যাকাউন্টের মধ্যে কথোপকথনের ইতিহাস শেয়ার করুন, তারপর `ccam next --continue` চালান। Claude Code পরের অ্যাকাউন্টে বর্তমান ফোল্ডারের সবচেয়ে সাম্প্রতিক কথোপকথনটি খোলে।

## ccam কি আমার লগইন দেখে বা কোথাও পাঠায়?

ccam কখনও কোনো লগইন কপি বা শেয়ার করে না। আপনি `ccam usage`, `ccam next --auto` বা `ccam doctor` চালালে, শুধু সেই অ্যাকাউন্টের ব্যবহার জানতে Anthropic-এর ব্যবহার এন্ডপয়েন্টে অনুরোধ পাঠানোর জন্য এটি অ্যাকাউন্টের অ্যাক্সেস টোকেন পড়ে। ccam-এ কোনো টেলিমেট্রি নেই এবং এটি অন্য কোথাও কিছু পাঠায় না।

## আমার অ্যাকাউন্টগুলো কোথায় সংরক্ষিত থাকে?

`~/.local/share/ccam/profiles/<name>/`-এ, প্রতিটি অ্যাকাউন্টের জন্য একটি ফোল্ডার। macOS-এ Claude Code লগইনটি নিজে Keychain-এ রাখে, ওই ফোল্ডার থেকে তৈরি একটি নামে।

## আমার বিদ্যমান ~/.claude-এর কী হবে?

কিছুই না, যদি না আপনি `ccam import` চালান। ইমপোর্ট ফোল্ডারটিকে যেখানে আছে সেখানেই নিবন্ধন করে, তাই সাধারণ `claude` এবং `ccam <name>` একই অ্যাকাউন্ট ও সেটিংস ব্যবহার করতে থাকে।

## ccam কোন কোন সিস্টেম সমর্থন করে?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine এবং অন্যান্য) ও macOS। Windows-এ এটি WSL-এর ভেতরে ব্যবহার করুন।

## একটি MCP সার্ভার কেন শুধু একটি অ্যাকাউন্টে দেখা যায়?

সেশনের ভেতরে `claude mcp add` দিয়ে যোগ করা সার্ভার শুধু ওই অ্যাকাউন্টের জন্য সংরক্ষিত হয়। পরের বার অ্যাকাউন্টটি চালু করলে ccam আপনাকে তা জানায়; `ccam mcp import <account> <server>` দিয়ে সার্ভারটিকে শেয়ার করা গ্রুপে সরিয়ে নিন।

## ccam কি Claude Code-কে ধীর করে?

ccam-এর মাধ্যমে Claude Code চালু করলে প্রায় ৪ মিলিসেকেন্ড যোগ হয়, যা একটি ল্যাপটপে `scripts/perf-check.sh` দিয়ে মাপা হয়েছে। ccam একটি ছোট ফাইল পড়ে, শেয়ার করা লিংকগুলো পরীক্ষা করে, তারপর নিজেকে `claude` দিয়ে প্রতিস্থাপন করে, তাই আপনি কাজ করার সময় এটি চলে না।

## ccam কীভাবে আনইনস্টল করব?

`~/.local/bin` থেকে `ccam` এবং `claude1`… লিংকগুলো মুছে ফেলুন, তারপর অ্যাকাউন্টগুলোর আর দরকার না থাকলে `~/.config/ccam`, `~/.local/share/ccam` ও `~/.local/state/ccam` মুছুন। দেখুন [ইনস্টল](/docs/install#uninstall)।
