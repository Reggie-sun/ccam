`ccam usage` দেখায় প্রতিটি অ্যাকাউন্ট ৫ ঘণ্টা ও সাপ্তাহিক সীমার কতটা ব্যবহার করেছে। `ccam next --auto` সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্টটি খোলে, আর `--continue` বর্তমান কথোপকথনটি সঙ্গে নিয়ে যায়।

```console
$ ccam usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccam next --auto 로 바로 열기)
```

কলামগুলো হলো: অ্যাকাউন্ট, ৫ ঘণ্টার ব্যবহার, সেটি রিসেট হওয়া পর্যন্ত সময়, সাপ্তাহিক ব্যবহার, সেটি রিসেট হওয়া পর্যন্ত সময়, এবং সংখ্যাগুলো কতক্ষণ আগের।

## সংখ্যাগুলো কোথা থেকে আসে

ccam প্রতিটি অ্যাকাউন্টের নিজস্ব লগইন ব্যবহার করে একই সময়ে সব অ্যাকাউন্টের জন্য Anthropic-এর ব্যবহার এন্ডপয়েন্টে অনুরোধ পাঠায়। প্রতিটি অ্যাকাউন্টের জন্য এটি সর্বোচ্চ ৩ সেকেন্ড অপেক্ষা করে এবং কোনো অ্যাকাউন্টের উত্তর আসামাত্র সেটি দেখায়।

এই এন্ডপয়েন্ট প্রকাশ্যে ডকুমেন্ট করা নয় এবং বদলে যেতে পারে। কোনো অনুরোধ ব্যর্থ হলে ccam সর্বশেষ জানা সংখ্যাগুলো দেখায় এবং সেগুলোকে ক্যাশ করা হিসেবে চিহ্নিত করে। রেসপন্সের ফরম্যাট বদলে গেলে `ccam doctor` আপনাকে জানায়।

৬০ সেকেন্ডের কম আগে আনা সংখ্যা আবার ব্যবহার করা হয়। অপশন:

| অপশন | প্রভাব |
| --- | --- |
| `--watch [seconds]` | ক্রমাগত রিফ্রেশ করে, ডিফল্টভাবে প্রতি ৬০ সেকেন্ডে |
| `--json` | মেশিনে পড়ার উপযোগী আউটপুট |
| `-v` | মডেলভিত্তিক সাপ্তাহিক সীমা এবং প্রতিটি সংখ্যা কোথা থেকে এসেছে তাও দেখায় |
| `--no-cache` | সবসময় আবার অনুরোধ পাঠায় |
| `--source cache` | কখনও অনুরোধ পাঠায় না; শুধু সংরক্ষিত সংখ্যা দেখায় |

## মেয়াদোত্তীর্ণ লগইন

কোনো অ্যাকাউন্টের অ্যাক্সেস টোকেনের মেয়াদ শেষ হলে ccam সেটি নবায়ন করে না, কারণ কোনো Claude Code সেশন একই লগইন ব্যবহার করার সময় নবায়ন করলে ওই সেশনটি সাইন আউট হয়ে যেতে পারে। `ccam <name>` দিয়ে অ্যাকাউন্টটি একবার চালু করুন, Claude Code সেটি নবায়ন করবে।

`ccam usage --refresh` মেয়াদোত্তীর্ণ টোকেন নিজেই নবায়ন করে, কিন্তু শুধু সেই অ্যাকাউন্টগুলোর জন্য যেগুলো চলছে না। macOS Keychain-এ বা ইমপোর্ট করা `~/.claude`-এ সংরক্ষিত লগইন এটি কখনও নবায়ন করে না।

## স্ট্যাটাস লাইনে ব্যবহার

```sh
ccam statusline install
```

এরপর Claude Code স্ট্যাটাস লাইনে অ্যাকাউন্টের নাম ও তার ব্যবহার দেখায়, যেমন `[work] · Opus · 5h 24% · 7d 41%`। আপনার আগে থেকেই কোনো স্ট্যাটাস লাইন কমান্ড থাকলে ccam সেটি রেখে দেয় এবং সামনে অ্যাকাউন্টের নাম বসায়। স্ট্যাটাস লাইন তার সংখ্যাগুলোও সংরক্ষণ করে, এন্ডপয়েন্ট উত্তর না দিলে `ccam usage` সেগুলো ব্যবহার করে।

## অ্যাকাউন্ট বদল

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # the next account that shares your conversation history
```

`ccam next` লগইন না করা অ্যাকাউন্টগুলো বাদ দেয়, আর `--auto` ১০০%-এ থাকা অ্যাকাউন্টগুলো বাদ দেয়। একটি কথোপকথন চালিয়ে যেতে দুটি অ্যাকাউন্টকেই কথোপকথনের ইতিহাস শেয়ার করতে হবে; দেখুন [শেয়ার করা](/docs/sharing)।
