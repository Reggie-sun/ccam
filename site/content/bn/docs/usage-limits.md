`ccam usage` দেখায় প্রতিটি অ্যাকাউন্ট ৫ ঘণ্টার সীমা, সাপ্তাহিক সীমা ও প্রতিটি মডেলের নিজস্ব সাপ্তাহিক সীমার (যেমন Fable) কতটা ব্যবহার করেছে। `ccam next --auto` সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্টটি খোলে, আর `--continue` বর্তমান কথোপকথনটি সঙ্গে নিয়ে যায়।

প্রতিটি অ্যাকাউন্ট একটি লাইন পায়, যা জানায় তার সংখ্যাগুলো কতক্ষণ আগের, তারপর প্রতিটি সীমার জন্য একটি বার, রিসেট হওয়া পর্যন্ত সময়সহ: ৫ ঘণ্টার উইন্ডো, সব মডেলের সাপ্তাহিক উইন্ডো, এবং প্রতিটি মডেলের নিজস্ব সাপ্তাহিক উইন্ডো, যেমন Fable। ৮০% থেকে বার হলুদ আর ১০০%-এ লাল হয়ে যায়। শেষ লাইনটি সেই অ্যাকাউন্টের নাম দেয় যা `ccam next --auto` খুলত।

## সংখ্যাগুলো কোথা থেকে আসে

ccam প্রতিটি অ্যাকাউন্টের নিজস্ব লগইন ব্যবহার করে একই সময়ে সব অ্যাকাউন্টের জন্য Anthropic-এর ব্যবহার এন্ডপয়েন্টে অনুরোধ পাঠায়। প্রতিটি অ্যাকাউন্টের জন্য এটি সর্বোচ্চ ৩ সেকেন্ড অপেক্ষা করে এবং কোনো অ্যাকাউন্টের উত্তর আসামাত্র সেটি দেখায়।

এই এন্ডপয়েন্ট প্রকাশ্যে ডকুমেন্ট করা নয় এবং বদলে যেতে পারে। কোনো অনুরোধ ব্যর্থ হলে ccam সর্বশেষ জানা সংখ্যাগুলো দেখায় এবং সেগুলোকে ক্যাশ করা হিসেবে চিহ্নিত করে। ওই সংখ্যাগুলো সংরক্ষণের পর যে উইন্ডো রিসেট হয়েছে, সেটি ০% দেখায়। রেসপন্সের ফরম্যাট বদলে গেলে `ccam doctor` আপনাকে জানায়।

৬০ সেকেন্ডের কম আগে আনা সংখ্যা আবার ব্যবহার করা হয়। অপশন:

| অপশন | প্রভাব |
| --- | --- |
| `--watch [seconds]` | ক্রমাগত রিফ্রেশ করে, ডিফল্টভাবে প্রতি ৬০ সেকেন্ডে |
| `--json` | মেশিনে পড়ার উপযোগী আউটপুট |
| `-v` | প্রতিটি অ্যাকাউন্টের সংখ্যা কোথা থেকে এসেছে তাও দেখায় |
| `--no-cache` | সবসময় আবার অনুরোধ পাঠায় |
| `--source cache` | কখনও অনুরোধ পাঠায় না; শুধু সংরক্ষিত সংখ্যা দেখায় |

## মেয়াদোত্তীর্ণ লগইন

কোনো অ্যাকাউন্টের অ্যাক্সেস টোকেনের মেয়াদ শেষ হলে ccam সেটি নবায়ন করে না, কারণ কোনো Claude Code সেশন একই লগইন ব্যবহার করার সময় নবায়ন করলে ওই সেশনটি সাইন আউট হয়ে যেতে পারে। `ccam <name>` দিয়ে অ্যাকাউন্টটি একবার চালু করুন, Claude Code সেটি নবায়ন করবে।

`ccam usage --refresh` মেয়াদোত্তীর্ণ টোকেন নিজেই নবায়ন করে, কিন্তু শুধু সেই অ্যাকাউন্টগুলোর জন্য যেগুলো চলছে না। macOS Keychain-এ বা ইমপোর্ট করা `~/.claude`-এ সংরক্ষিত লগইন এটি কখনও নবায়ন করে না।

## স্ট্যাটাস লাইনে ব্যবহার

```sh
ccam statusline install
```

এরপর Claude Code স্ট্যাটাস লাইনে অ্যাকাউন্টের নাম ও তার ব্যবহার দেখায়, যেমন `[work] · Opus · 5h 24% · 7d 41%`। ৯০% থেকে লাইনটি `ccam next --auto --continue`-ও প্রস্তাব করে। আপনার আগে থেকেই কোনো স্ট্যাটাস লাইন কমান্ড থাকলে ccam সেটি রেখে দেয় এবং সামনে অ্যাকাউন্টের নাম বসায়। স্ট্যাটাস লাইন তার সংখ্যাগুলোও সংরক্ষণ করে, এন্ডপয়েন্ট উত্তর না দিলে `ccam usage` সেগুলো ব্যবহার করে।

## অ্যাকাউন্ট বদল

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # carry this folder's conversation on as the next account
```

`ccam next` লগইন না করা অ্যাকাউন্টগুলো বাদ দেয়, আর `--auto` ১০০%-এ থাকা অ্যাকাউন্ট ও অন্য প্রতিষ্ঠানের অ্যাকাউন্টগুলো বাদ দেয়। দুটি অ্যাকাউন্ট কথোপকথনের ইতিহাস শেয়ার করলে `--continue` একই কথোপকথনটি খোলে; না করলে Claude Code সেটি নতুন অ্যাকাউন্টে কপি করে। দেখুন [শেয়ার করা](/docs/sharing) ও [পরের অ্যাকাউন্টে বদল](/features/next#continue)।

`claude -p` চালানো স্ক্রিপ্ট ও নির্ধারিত কাজের জন্য অ্যাকাউন্টের নামের আগে `--fallback` দিন। ওই অ্যাকাউন্ট তার সীমায় পৌঁছালে ccam একই কমান্ড সবচেয়ে বেশি জায়গা থাকা অ্যাকাউন্ট হিসেবে আবার চালায়, এবং শুধু যে রানটি শেষ হয়েছে তার আউটপুট প্রিন্ট হয়:

```sh
ccam --fallback work -p "review the diff" --output-format json
```

ccam কীভাবে সিদ্ধান্ত নেয় তা জানতে [সীমায় আবার চালানো](/features/next#run-again-at-the-limit) দেখুন।
