`ccam add` দিয়ে প্রতিটি অ্যাকাউন্ট যোগ করুন, তারপর `claude1`, `claude2` বা `ccs <name>` দিয়ে Claude Code চালু করুন। বেশিরভাগ মানুষের এটুকুই দরকার।

## ১. আপনার প্রথম অ্যাকাউন্ট যোগ করুন

```sh
ccam add
```

উইজার্ডটি `personal` বা `work`-এর মতো একটি নাম চায়, এবং জিজ্ঞেস করে অ্যাকাউন্টটি আপনার অন্য অ্যাকাউন্টগুলোর সঙ্গে কোন কোন আইটেম শেয়ার করবে। তারপর এটি `claude auth login` চালায়, যা সাইন ইন করার জন্য ব্রাউজার খোলে। শেষ হলে আপনি দেখবেন:

```console
✓ personal (me@example.com) 추가됨 — 단축 명령: claude1
```

ccam আপাতত নিজের বার্তাগুলো কোরিয়ান ভাষায় প্রিন্ট করে; কমান্ড ও অপশন সব ভাষায় একই।

## ২. দ্বিতীয় অ্যাকাউন্ট যোগ করুন

```sh
ccam add work
```

ব্রাউজারে অন্য অ্যাকাউন্টটি দিয়ে সাইন ইন করুন। এটি `claude2` হয়ে যায়।

## ৩. বদল করুন

এর যেকোনোটি work অ্যাকাউন্ট হিসেবে Claude Code চালু করে:

```sh
claude2
ccs work
ccs 2
```

অ্যাকাউন্টের নামের পরের সবকিছু অপরিবর্তিত অবস্থায় Claude Code-এ যায়, তাই আপনার চেনা অপশনগুলোই ব্যবহার করতে পারেন:

```sh
ccs work --resume
ccs work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

শুধু `ccs` চালালে একটি বাছাইয়ের তালিকা খোলে: অ্যারো কি ও Enter ব্যবহার করুন, অথবা অ্যাকাউন্টের নম্বর চাপুন।

## ৪. কী শেয়ার হবে তা বেছে নিন

ডিফল্টভাবে MCP সার্ভার, `settings.json`, গ্লোবাল `CLAUDE.md`, এবং agents, commands, skills ও plugins অ্যাকাউন্টগুলোর মধ্যে শেয়ার হয়। কথোপকথনের ইতিহাস শেয়ার হয় না। অ্যাকাউন্টগুলোর মধ্যে কথোপকথন চালিয়ে যেতে চাইলে দুটি অ্যাকাউন্টেই এটি চালু করুন:

```sh
ccam share personal --history on
ccam share work --history on
```

কিছু বদলানোর আগে ccam দেখায় এটি কী সরাবে। বিস্তারিত জানতে [শেয়ার করা](/docs/sharing) দেখুন।

## ৫. যখন একটি অ্যাকাউন্ট সীমায় পৌঁছায়

```sh
ccs usage
ccs next --continue
```

`ccs usage` সব অ্যাকাউন্টের ৫ ঘণ্টা ও সাপ্তাহিক ব্যবহার দেখায়। `ccs next --continue` একই কথোপকথন পরের অ্যাকাউন্টে খোলে। দেখুন [ব্যবহারের সীমা](/docs/usage-limits)।

## আগে থেকেই ~/.claude ব্যবহার করছেন?

আবার সাইন ইন না করে সেটিকে নিবন্ধন করুন:

```sh
ccam import
```

ফোল্ডারটি যেখানে আছে সেখানেই থাকে, এবং সাধারণ `claude` আগের মতোই কাজ করে।
