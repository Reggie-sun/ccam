প্রতিটি অ্যাকাউন্ট নিজের লগইন রাখে। বাকি সবকিছু **গ্রুপের** মাধ্যমে শেয়ার করা যায়: একটি গ্রুপ ঠিক করে সে কোন আইটেম শেয়ার করে এবং কোন কোন অ্যাকাউন্ট তাতে আছে, আর ccam ওই অ্যাকাউন্টগুলোর প্রতিটির ফাইল গ্রুপের ফোল্ডারের সঙ্গে লিংক করে, তাই একটি অ্যাকাউন্টে করা পরিবর্তন সবগুলোতে দেখা যায়।

## কী কী শেয়ার করা যায়

| আইটেম | কী শেয়ার হয় |
| --- | --- |
| `mcp` | MCP সার্ভার: গ্রুপের `mcp.json`, চালু হওয়ার সময় Claude Code-কে দেওয়া হয় |
| `settings` | `settings.json`: অনুমতি, হুক, মডেল, স্ট্যাটাস লাইন |
| `memory` | গ্লোবাল `CLAUDE.md` |
| `extensions` | `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/` |
| `history` | কথোপকথনের ইতিহাস: `projects/` ও `history.jsonl` |

আপনার প্রথম অ্যাকাউন্ট `default` গ্রুপটি তৈরি করে, যা কথোপকথনের ইতিহাস ছাড়া বাকি সবকিছু শেয়ার করে, আর পরের অ্যাকাউন্টগুলো তাতে যোগ দেয়।

লগইন ফাইল `.credentials.json` ও `.claude.json` কখনও শেয়ার হয় না। ccam শুধু একটি নির্দিষ্ট তালিকার পাথ লিংক করে, আর এই দুটি সেই তালিকায় নেই।

এই পাতায় দৈনন্দিন কাজগুলো আছে। প্রতিটি অপশনের বিবরণ বৈশিষ্ট্যের পাতাগুলোতে দেওয়া আছে: [গ্রুপ দিয়ে শেয়ার করা](/features/share), [শেয়ার করা MCP সার্ভার](/features/mcp) ও [বিদ্যমান সেটআপ কপি করা](/features/migrate)।

## গ্রুপ

```sh
ccam group                                   # the groups, what they share, their accounts
ccam group set default --add history         # every account in default shares history
ccam group add team --items history --members work,side
```

একটি অ্যাকাউন্ট একাধিক গ্রুপে থাকতে পারে, তবে প্রতিটি আইটেম আসে কেবল একটি গ্রুপ থেকে। তাই `work` ও `side`-এর মধ্যে ইতিহাস শেয়ার করতে চাইলে, কিন্তু আপনার অন্য অ্যাকাউন্টগুলোর সঙ্গে নয়, ইতিহাসকে `default`-এর বাইরে রাখুন এবং ওপরের মতো ওই দুটিকে তাদের নিজস্ব একটি গ্রুপ দিন। `ccam share work` দেখায় একটি অ্যাকাউন্ট কী শেয়ার করে এবং কোন গ্রুপের মাধ্যমে। [ড্যাশবোর্ড](/features/dashboard) তার Groups ট্যাবে একই জিনিস দেখায়।

## যখন একটি অ্যাকাউন্ট শেয়ার করা শুরু করে

কোনো অ্যাকাউন্ট একটি আইটেম শেয়ার করা শুরু করলে (এটি একটি গ্রুপে যোগ দেয়, বা তার গ্রুপ আইটেমটি যোগ করে) ccam:

1. প্রতিটি অ্যাকাউন্টের জন্য যে ফাইলগুলো সরাবে, কপি করবে বা লিংক করবে তার একটি পরিকল্পনা প্রিন্ট করে, এবং শুরু করার আগে জিজ্ঞেস করে;
2. গ্রুপ এখনও খালি থাকলে অ্যাকাউন্টের ফাইলগুলো গ্রুপ ফোল্ডারে সরায়, অথবা গ্রুপে যে ফাইলগুলো এখনও নেই সেগুলো যোগ করে;
3. একই ফাইল আলাদা হলে জিজ্ঞেস করে গ্রুপের সংস্করণ রাখবেন, আপনারটি ব্যবহার করবেন, নাকি JSON মার্জ করবেন;
4. আপনার মূল ফাইলটি অ্যাকাউন্ট ফোল্ডারের ভেতরে `.ccam-backup/<time>/`-এ রাখে;
5. মূল ফাইলটিকে গ্রুপের একটি লিংক দিয়ে প্রতিস্থাপন করে।

কথোপকথনের ফাইলের নাম তাদের সেশন ID অনুযায়ী হয়, তাই একাধিক অ্যাকাউন্টের ইতিহাস কোনো দ্বন্দ্ব ছাড়াই একত্র হয়।

কোনো অ্যাকাউন্ট হিসেবে Claude Code চলতে থাকলে, সেটি যেভাবেই চালু হোক (ব্যাকগ্রাউন্ড সেশনসহ), ccam সেই অ্যাকাউন্ট বদলায় না, কারণ সেশনটি যে ফাইলগুলো সরানো হচ্ছে সেগুলোতে লিখতে থাকে। আগে সেটি বন্ধ করুন। সংরক্ষণের ঠিক আগে ccam আবার পরীক্ষা করে, তাই ccam আপনার উত্তরের অপেক্ষায় থাকার সময় চালু হওয়া সেশনও এটি ধরে ফেলে।

## যখন একটি অ্যাকাউন্ট শেয়ার করা বন্ধ করে

```sh
ccam group leave team work                   # work leaves the group
ccam group set default --remove history      # nobody in default shares history any more
```

লিংকটি সরানো হয় এবং অ্যাকাউন্টটি গ্রুপের বর্তমান বিষয়বস্তুর নিজস্ব একটি কপি পায়; গ্রুপের MCP সার্ভারগুলো এর নিজস্ব `.claude.json`-এ যায়, এর নিজের সার্ভারগুলোর পাশে। এর বদলে খালি অবস্থা থেকে শুরু করতে `--fresh` যোগ করুন; তখন পরিকল্পনাটি সেই MCP সার্ভারগুলোর তালিকা দেয় যেগুলো আর লোড হবে না। `~/.claude`-এর মতো ইমপোর্ট করা ফোল্ডার সবসময় একটি কপি রাখে। অন্য অ্যাকাউন্টগুলোর জন্য গ্রুপ তার বিষয়বস্তু রেখে দেয়।

## আগের সেটআপ কপি করুন

ccam-এর আগে Claude Code ব্যবহার করে থাকলে আপনার সেটিংস `~/.claude`-এ আছে। `ccam migrate` সেগুলো একটি গ্রুপে কপি করে, যাতে ওই আইটেমগুলো শেয়ার করা প্রতিটি অ্যাকাউন্ট সেগুলো পায়:

```sh
ccam migrate
```

টার্মিনালে ccam প্রথমে আইটেমগুলোর একটি চেকলিস্ট দেখায়। কথোপকথনের ইতিহাস বাদে সবকিছু চেক করা থাকে; কোনো আইটেম বদলাতে Space আর পরিকল্পনা দেখতে Enter চাপুন। যে আইটেমের জন্য ফোল্ডারে কিছু নেই, সেগুলো `not found` হিসেবে চিহ্নিত থাকে।

এটি যা কপি করে:

- `settings.json` ও গ্লোবাল `CLAUDE.md`;
- এক্সটেনশন `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/` ও `rules/`;
- আপনার ইউজার MCP সার্ভার, অর্থাৎ `~/.claude.json`-এর `mcpServers` এন্ট্রি, গ্রুপের `mcp.json`-এ;
- কথোপকথনের ইতিহাস (`projects/` ও `history.jsonl`), তবে শুধু আপনি `--history` যোগ করলে।

উৎস ফোল্ডারটি শুধু পড়া হয়: এর ভেতরের কিছুই সরানো, লিংক করা বা বদলানো হয় না, এবং সাধারণ `claude` আগের মতোই কাজ করে। লগইন ফাইল `.credentials.json` ও `.claude.json` কখনও গ্রুপে কপি হয় না।

যে MCP সার্ভারগুলো OAuth দিয়ে সাইন ইন করে, সেগুলো তাদের টোকেন সার্ভার তালিকায় নয়, লগইনে রাখে। ccam ওই সাইন-ইনগুলো কপি করে না: কপি করা সাইন-ইন একই রিফ্রেশ টোকেন রাখে, আর প্রথম নবায়নই অন্য প্রত্যেক ধারককে, `~/.claude`-সহ, ওই সার্ভার থেকে লগআউট করে দেয়। পরিকল্পনা ও সারাংশ সেই অ্যাকাউন্টগুলোর নাম দেখায় যেগুলোকে `/mcp` দিয়ে নিজেরাই ওই সার্ভারগুলোতে সাইন ইন করতে হবে।

কিছু কপি করার আগে ccam পরিকল্পনাটি প্রিন্ট করে এবং জিজ্ঞেস করে:

```console
$ ccam migrate
Copy from /home/me/.claude into group default (/home/me/.local/share/ccam/groups/default):
  mcp         ~/.claude.json  new: context7, fs
  settings    settings.json   new: 80 B
  memory      CLAUDE.md       new: 31 B
  extensions  agents/         add 1 file the group lacks (17 B)
              commands/       add 1 file the group lacks (15 B)
              skills/         add 1 file the group lacks (32 B)
              not found, skipped: plugins/, output-styles/, rules/
  Conversation history (projects/, history.jsonl) is not included; add --history to copy it.
Copy these into group default? [y/N] y
✓ Copied into group default: 2 MCP servers, settings.json, CLAUDE.md, agents/, commands/, skills/
Group default: personal
To share them:
  ccam group join default work
```

শেষে ccam গ্রুপের অ্যাকাউন্টগুলোর তালিকা দেয়। গ্রুপটি কোনো আইটেম এখনও শেয়ার না করলে, বা কিছু অ্যাকাউন্ট তাতে না থাকলে, এটি সেটি বদলানোর `ccam group` কমান্ডগুলো প্রিন্ট করে।

গ্রুপে কোনো ফাইলের আলাদা একটি কপি আগে থেকেই থাকলে, ccam শেয়ার চালু করার সময়ের মতোই জিজ্ঞেস করে: গ্রুপের কপি রাখবেন নাকি আপনারটি ব্যবহার করবেন। `settings.json` ও অন্যান্য JSON ফাইল মার্জও করা যায়, আর `history.jsonl` লাইন ধরে ধরে। গ্রুপের আগের কপিগুলো গ্রুপ ফোল্ডারের ভেতরে `.ccam-backup/<time>/`-এ সংরক্ষিত থাকে।

| অপশন | প্রভাব |
| --- | --- |
| `--settings`, `--memory`, `--extensions`, `--mcp`, `--history` | চেকলিস্ট ছাড়াই শুধু উল্লেখ করা আইটেমগুলো কপি করে। টার্মিনালের বাইরে, কোনো আইটেম অপশন না দিলে, ccam কথোপকথনের ইতিহাস বাদে সবকিছু কপি করে। |
| `-g`, `--group <group>` | `default`-এর বদলে এই গ্রুপে কপি করে |
| `-y`, `--yes` | জিজ্ঞেস না করেই কপি করে; কোনো ফাইল আলাদা হলে গ্রুপের কপি রাখে |

কিছু কপি না করে পরিকল্পনাটি দেখতে কমান্ডের আগে `--dry-run` দিন, যেমন `ccam --dry-run migrate`। অন্য ফোল্ডার থেকে কপি করতে তার নাম দিন: `ccam migrate ~/.claude-work --group work`।

## MCP সার্ভার

Claude Code MCP সার্ভারগুলো লগইনের সঙ্গে একই `.claude.json`-এ রাখে, তাই ওই ফাইল শেয়ার করা যায় না। ccam শেয়ার করা সার্ভারগুলো গ্রুপের `mcp.json`-এ রাখে এবং `--mcp-config=<group>/mcp.json` দিয়ে Claude Code চালু করে। আপনার নিজের `--mcp-config` অপশনগুলো এর ওপরে প্রযোজ্য থাকে।

```sh
ccam mcp add fs -- npx -y @modelcontextprotocol/server-filesystem ~/code
ccam mcp list
```

সেশনের ভেতরে `claude mcp add` দিয়ে যোগ করা সার্ভার শুধু ওই অ্যাকাউন্টের জন্য সংরক্ষিত হয়, এবং আপনি যে ফোল্ডারে ছিলেন সেটির জন্য (Claude Code-এর local scope; `-s user` দিলে সেটি প্রতিটি ফোল্ডারে অ্যাকাউন্টটির জন্য পাওয়া যায়)। পরের বার ওই অ্যাকাউন্ট চালু করলে ccam সার্ভারটির নাম, তার ফোল্ডারসহ, এবং সেটিকে গ্রুপে সরানোর কমান্ড দেখায়:

```sh
ccam mcp import work gh
```

গ্রুপে যদি ওই নামে আগে থেকেই অন্য একটি সার্ভার থাকে, ccam সেটি বাদ দেয় এবং তা জানায়। `--force` গ্রুপের সার্ভারটি বদলে দেয় এবং পুরোনো `mcp.json` গ্রুপের `.ccam-backup/` ফোল্ডারে রেখে দেয়।

যে MCP সার্ভারগুলো OAuth দিয়ে সাইন ইন করে, সেগুলো তাদের টোকেন অ্যাকাউন্টের লগইনের সঙ্গে রাখে, তাই প্রতিটি অ্যাকাউন্টে `/mcp` দিয়ে একবার করে সেগুলোতে সাইন ইন করুন। অন্য কোনো অ্যাকাউন্ট যে সার্ভারগুলোতে সাইন ইন করা অথচ এই অ্যাকাউন্টটি নয়, `ccam ext` ও `ccam doctor` সেগুলোর নাম দেখায়।

সার্ভারগুলো যদি আপনি `claude mcp list` ও `/mcp`-এ সাধারণ ব্যবহারকারী সার্ভার হিসেবে দেখতে চান, তাহলে `~/.config/ccam/config.toml`-এর একেবারে ওপরে, প্রথম `[[group]]`, `[[profile]]` বা `[[folder]]`-এর ওপরে, `mcp_strategy = "sync"` নির্ধারণ করুন। তখন ccam চালু করার আগে সেগুলো প্রতিটি অ্যাকাউন্টের `.claude.json`-এ লেখে, Claude Code-এর নিজস্ব ফাইল লকের অধীনে এবং একটি ব্যাকআপসহ। কোনো গ্রুপ সার্ভারের নামে অ্যাকাউন্টটির নিজস্ব কোনো সার্ভার থাকলে ccam অ্যাকাউন্টের সার্ভারটিই রাখে এবং তা জানায়।

## একই ফোল্ডারে দুটি অ্যাকাউন্ট

যে অ্যাকাউন্টগুলো কথোপকথনের ইতিহাস শেয়ার করে, সেগুলো একই ফাইলে লেখে। একই গ্রুপের অন্য একটি অ্যাকাউন্ট যে ফোল্ডারে আগে থেকেই চলছে, সেখানে দ্বিতীয় একটি Claude Code সেশন চালু করলে ccam আপনাকে সতর্ক করে এবং চালিয়ে যাবেন কি না জিজ্ঞেস করে।

## কিছু ভেঙে গেলে

```sh
ccam doctor
ccam doctor --fix
```

কোনো শেয়ার করা পাথ যদি সাধারণ ফাইলে পরিণত হয়, যেমন আপনি হাতে একটি ব্যাকআপ পুনরুদ্ধার করার পর, তাহলে ccam Claude Code চালু করার আগেই থেমে যায় এবং `ccam doctor --fix` দেখিয়ে দেয়। এই মেরামত পাথটিকে আবার গ্রুপের সঙ্গে লিংক করে: গ্রুপের কোনো কপি না থাকলে ফাইলটিই গ্রুপের কপি হয়; না হলে গ্রুপ নিজের কপি রাখে, আর আপনারটা এমন একটি ব্যাকআপে যায় যার নাম `--fix` জানায়। মাঝপথে থেমে যাওয়া গ্রুপের পরিবর্তনও `ccam doctor --fix` শেষ করে।
