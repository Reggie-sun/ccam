یک نام مستعار شل برای هر حساب ساده‌ترین راه اجرای چند حساب Claude Code است. ccam در اساس همین کار را می‌کند و اشتراک‌گذاری، جابه‌جایی و پیگیری مصرف را به آن اضافه می‌کند.

## راه‌اندازی با نام مستعار

برای هر حساب اضافی یک خط به `~/.bashrc` یا `~/.zshrc` اضافه کنید، یک ترمینال تازه باز کنید و نام مستعار را یک بار برای ورود اجرا کنید:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

`claude` همچنان حساب اول شما می‌ماند و `claude-work` حساب دوم را اجرا می‌کند. این همان روشی است که [مستندات Claude Code توضیح می‌دهد](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts).

## راه‌اندازی با ccam

ccam را نصب کنید و حساب را اضافه کنید، این‌جا با یک فرمان میان‌بر مخصوص خودش:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add work --shortcut ccwork
```

`ccam work` و `ccwork` حساب را اجرا می‌کنند و هر دو در اسکریپت‌ها هم کار می‌کنند.

## در کنار هم

| | نام مستعار شل | ccam |
| --- | --- | --- |
| ورودهای جداگانه | بله | بله |
| راه‌اندازی برای هر حساب | ویرایش `~/.bashrc`، ورود | `ccam add` |
| کار در اسکریپت‌ها و برنامه‌های دیگر | خیر، نام‌های مستعار فقط در شل کار می‌کنند | بله، `ccam work` و میان‌برهایی مانند `ccwork` فرمان‌های واقعی‌اند |
| تنظیمات، `CLAUDE.md` و افزونه‌های مشترک | کپی یا پیوند دستی | مورد به مورد، با نسخه پشتیبان |
| سرورهای MCP مشترک | دستی، برای هر حساب | یک بار `ccam mcp add` |
| ادامه گفتگو در حساب دیگر | خیر | `ccam next --continue` |
| مصرف همه حساب‌ها | خیر | `ccam usage` |
| انتخاب حسابی که بیشترین ظرفیت را دارد | خیر | `ccam next --auto` |
| اجرای دوباره یک کار `-p` با حساب دیگر هنگام رسیدن به سقف | خیر | `ccam --fallback` |
| یک حساب برای هر پوشه پروژه | خیر | `ccam folder` |
| نام حساب در خط وضعیت | خیر | `ccam statusline install` |
| تعمیر پیوندهای خراب | دستی | `ccam doctor --fix` |
| نرم‌افزار اضافی | هیچ | یک فایل اجرایی ایستا |

اگر دو حساب دارید و نمی‌خواهید هیچ چیزی بین آن‌ها مشترک باشد، نام‌های مستعار را انتخاب کنید. اگر می‌خواهید حساب‌ها مانند یک مجموعه یکپارچه باشند، ccam را انتخاب کنید. می‌توانید با نام‌های مستعار شروع کنید و بعداً به ccam بروید: `ccam import` پوشه‌های موجود `~/.claude-*` را در همان جایی که هستند ثبت می‌کند.

[استفاده از چند حساب روی یک رایانه](/guides/multiple-claude-code-accounts) هر دو روش را گام به گام توضیح می‌دهد و [ccam و دیگر ابزارهای تعویض حساب](/compare/account-switchers) ccam را با ابزارهایی مقایسه می‌کند که یک ورود را عوض می‌کنند.
