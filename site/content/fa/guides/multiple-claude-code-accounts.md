به هر حساب یک پوشه پیکربندی جداگانه بدهید. Claude Code پوشه را از متغیر محیطی `CLAUDE_CONFIG_DIR` می‌خواند و هر پوشه ورود، تنظیمات و تاریخچه خودش را دارد. می‌توانید این کار را دستی با یک نام مستعار شل انجام دهید یا آن را به ccam بسپارید.

## به‌صورت دستی، با یک نام مستعار

این همان روشی است که مستندات Claude Code شرح می‌دهد. برای هر حساب اضافی یک خط به `~/.bashrc` یا `~/.zshrc` اضافه کنید:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

یک ترمینال جدید باز کنید و `claude-work` را اجرا کنید. Claude Code از شما می‌خواهد وارد شوید، چون پوشه جدید است. از این پس `claude` حساب اول شما و `claude-work` حساب دوم است.

این روش برای دو حساب خوب کار می‌کند. نکته‌هایی که باید بدانید:

- هر پوشه خالی شروع می‌شود: بدون تنظیمات، بدون `CLAUDE.md`، بدون سرورهای MCP، بدون agents یا skills. آنچه لازم دارید را کپی یا پیوند می‌دهید و هماهنگ نگه داشتن نسخه‌ها با خودتان است.
- نام‌های مستعار فقط در شل‌های تعاملی وجود دارند. اسکریپت‌ها، Makefileها و برنامه‌های دیگر آن‌ها را نمی‌بینند.
- سرورهای MCP در `.claude.json`، کنار ورود، قرار دارند، بنابراین نمی‌توان آن‌ها را به‌سادگی بین پوشه‌ها پیوند داد.
- گفتگوها در حسابی که در آن آغاز شده‌اند می‌مانند، بنابراین نمی‌توانید یک گفتگو را در حساب دیگری ادامه دهید.
- هیچ چیزی مصرف همه حساب‌ها را یک‌جا نشان نمی‌دهد.

## با ccam

ccam همین ایده را خودکار می‌کند و بخش‌های جاافتاده را اضافه می‌کند:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

اکنون `ccam personal` و `ccam work` دو حساب را اجرا می‌کنند و `ccwork`، میان‌بری که به حساب کاری داده‌اید، نیز همین کار را می‌کند. چون این‌ها برنامه‌های واقعی‌اند و نه نام مستعار، در اسکریپت‌ها هم کار می‌کنند. تنظیمات، `CLAUDE.md`، سرورهای MCP و افزونه‌ها از همان ابتدا مشترک‌اند و می‌توانید تاریخچه گفتگوی مشترک را روشن کنید تا با `ccam next --continue` یک گفتگو را در حساب دیگر ادامه دهید.

اگر از قبل از `~/.claude` استفاده می‌کنید، به‌جای افزودن دوباره آن حساب `ccam import` را اجرا کنید، یا `ccam migrate` را تا تنظیمات، سرورهای MCP و افزونه‌های آن در تنظیمات مشترک کپی شوند.

## کدام را انتخاب کنیم

برای دو حساب بدون هیچ چیز مشترک، یک نام مستعار کافی است. وقتی تنظیمات و سرورهای MCP مشترک، حساب‌های بیشتر، دیدن مصرف در یک نگاه یا ادامه گفتگوها را می‌خواهید، ccam شما را از این حساب‌وکتاب‌ها بی‌نیاز می‌کند. [مقایسه](/compare/aliases) تفاوت‌ها را کنار هم فهرست می‌کند.
