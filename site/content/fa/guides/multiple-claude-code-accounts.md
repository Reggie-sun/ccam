به هر حساب یک پوشه پیکربندی جداگانه بدهید. Claude Code پوشه را از متغیر محیطی `CLAUDE_CONFIG_DIR` می‌خواند و هر پوشه ورود، تنظیمات و تاریخچه خودش را دارد، بنابراین هر حساب وارد‌شده باقی می‌ماند و می‌توانید حساب‌ها را هم‌زمان اجرا کنید. می‌توانید این کار را دستی با یک نام مستعار شل انجام دهید یا آن را به ccam بسپارید.

## چگونه این کار را دستی انجام دهم؟

این همان روشی است که [مستندات Claude Code شرح می‌دهد](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts). برای هر حساب اضافی یک خط به `~/.bashrc` یا `~/.zshrc` اضافه کنید:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

یک ترمینال جدید باز کنید و `claude-work` را اجرا کنید. Claude Code از شما می‌خواهد وارد شوید، چون پوشه جدید است. از این پس `claude` حساب اول شما و `claude-work` حساب دوم است. برای هر حساب یک نام مستعار با پوشه مخصوص خودش اضافه کنید.

در Windows بدون WSL، یک تابع PowerShell در پروفایل شما (`notepad $PROFILE`) همین کار را می‌کند:

```powershell
function claude-work { $env:CLAUDE_CONFIG_DIR = "$HOME\.claude-work"; try { claude @args } finally { Remove-Item Env:CLAUDE_CONFIG_DIR } }
```

## روش نام مستعار چه چیزهایی را پوشش نمی‌دهد؟

این روش برای دو حساب خوب کار می‌کند. نکته‌هایی که باید بدانید:

- هر پوشه خالی شروع می‌شود: بدون تنظیمات، بدون `CLAUDE.md`، بدون سرورهای MCP، بدون agents یا skills. آنچه لازم دارید را کپی یا پیوند می‌دهید و هماهنگ نگه داشتن نسخه‌ها با خودتان است.
- نام‌های مستعار فقط در شل‌های تعاملی وجود دارند. اسکریپت‌ها، Makefileها و برنامه‌های دیگر آن‌ها را نمی‌بینند.
- سرورهای MCP در `.claude.json`، کنار ورود، قرار دارند، بنابراین نمی‌توان آن‌ها را به‌سادگی بین پوشه‌ها پیوند داد.
- گفتگوها در حسابی که در آن آغاز شده‌اند می‌مانند، بنابراین نمی‌توانید یک گفتگو را در حساب دیگری ادامه دهید.
- هیچ چیزی مصرف همه حساب‌ها را یک‌جا نشان نمی‌دهد.

## آیا می‌توانم به‌جای آن با /login حساب را عوض کنم؟

بله، اگر فقط گاه‌به‌گاه جابه‌جا می‌شوید. تایپ `/login` داخل Claude Code [حساب را عوض می‌کند](https://code.claude.com/docs/en/quickstart)، آن هم برای پوشه‌ای که در آن هستید. در هر لحظه فقط یک حساب وارد‌شده است، پس با هر جابه‌جایی دوباره وارد می‌شوید و نمی‌توانید دو حساب را کنار هم اجرا کنید. پوشه‌های جداگانه هر دو مشکل را برطرف می‌کنند.

## چگونه این کار را با ccam انجام دهم؟

ccam همین ایده را خودکار می‌کند و بخش‌های جاافتاده را اضافه می‌کند:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

اکنون `ccam personal` و `ccam work` دو حساب را اجرا می‌کنند و `ccwork`، میان‌بری که به حساب کاری داده‌اید، نیز همین کار را می‌کند. چون این‌ها برنامه‌های واقعی‌اند و نه نام مستعار، در اسکریپت‌ها هم کار می‌کنند. `ccam` را به‌تنهایی اجرا کنید تا حسابی را از یک فهرست انتخاب کنید، و `ccam use work` را تا یک حساب پیش‌فرض شود.

تنظیمات، `CLAUDE.md`، سرورهای MCP و افزونه‌ها از همان ابتدا مشترک‌اند و می‌توانید تاریخچه گفتگوی مشترک را روشن کنید تا با `ccam next --continue` یک گفتگو را در حساب دیگر ادامه دهید. `ccam usage` مصرف ۵ ساعته و هفتگی همه حساب‌ها را یک‌جا نشان می‌دهد.

اگر از قبل از `~/.claude` استفاده می‌کنید، به‌جای افزودن دوباره آن حساب `ccam import` را اجرا کنید، یا `ccam migrate` را تا تنظیمات، سرورهای MCP و افزونه‌های آن در تنظیمات مشترک کپی شوند.

## از کجا بفهمم کدام حساب در حال اجراست؟

داخل Claude Code، `/status` حسابی را که با آن وارد شده‌اید نشان می‌دهد. با ccam یک بار `ccam statusline install` را اجرا کنید تا خط وضعیت همیشه نام حساب و مصرف آن را نشان دهد، برای مثال `[work] · Opus · 5h 24% · 7d 41%`.

## آیا این روش در Windows و WSL کار می‌کند؟

Claude Code [به‌صورت بومی در Windows و داخل WSL](https://code.claude.com/docs/en/setup) اجرا می‌شود. `CLAUDE_CONFIG_DIR` در هر دو کار می‌کند، پس در Windows بومی همان نام مستعار یا تابع PowerShell بالا کافی است. ccam روی Linux و macOS اجرا می‌شود؛ در Windows آن را داخل WSL نصب و استفاده کنید، که در آنجا مانند Linux کار می‌کند.

## عیب‌یابی

**Claude Code هر بار از من می‌خواهد وارد شوم.** نخستین اجرا در یک پوشه جدید همیشه ورود می‌خواهد. اگر باز هم بخواهد، ورود منقضی یا حذف شده است: `ccam login work` را اجرا کنید (یا نام مستعار را یک بار اجرا کنید و وارد شوید).

**یک سرور MCP فقط در یک حساب دیده می‌شود.** سرورهایی که داخل یک نشست با `claude mcp add` اضافه شده‌اند به همان حساب تعلق دارند. با `ccam mcp import work <server>` یک سرور را به همه حساب‌ها منتقل کنید.

**تنظیمات بین حساب‌ها فرق دارد.** `ccam share work` نشان می‌دهد آن حساب چه چیزهایی را به اشتراک می‌گذارد؛ `ccam share work --settings on` پس از نشان دادن تغییرات، تنظیماتش را مشترک می‌کند. `ccam doctor --fix` پیوندهای خراب را تعمیر می‌کند و از هر فایلی که تغییر می‌دهد نسخه پشتیبان نگه می‌دارد.

**دو حساب یک گفتگو را باز می‌کنند.** از کار هم‌زمان روی یک گفتگو در دو حساب پرهیز کنید. اگر چنین کاری کنید، ccam به شما هشدار می‌دهد.

## کدام را انتخاب کنم؟

برای دو حساب بدون هیچ چیز مشترک، یک نام مستعار کافی است. وقتی تنظیمات و سرورهای MCP مشترک، حساب‌های بیشتر، دیدن مصرف در یک نگاه یا ادامه گفتگوها را می‌خواهید، ccam شما را از این حساب‌وکتاب‌ها بی‌نیاز می‌کند. [مقایسه با نام‌های مستعار](/compare/aliases) تفاوت‌ها را کنار هم فهرست می‌کند و [ccam و دیگر ابزارهای تعویض حساب](/compare/account-switchers) ابزارهایی را بررسی می‌کند که به‌جای آن یک ورود را عوض می‌کنند.

اینکه اجازه دارید از چند حساب استفاده کنید یا نه، به شرایط هر حساب بستگی دارد. پیش از این کار آن‌ها را بررسی کنید.
