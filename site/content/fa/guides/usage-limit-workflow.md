وقتی یک حساب به سقف مصرف خود می‌رسد، همان گفتگو را در حساب دیگری که متعلق به خودتان است ادامه دهید: یک بار تاریخچه گفتگو را به اشتراک بگذارید، سپس `ccam next --continue` را اجرا کنید. اگر فقط یک حساب دارید، تا زمان بازنشانی‌ای که Claude Code نشان می‌دهد صبر کنید.

## پیش از آنکه اتفاق بیفتد

حساب‌ها را طوری راه‌اندازی کنید که جابه‌جایی فقط یک فرمان لازم داشته باشد:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

اکنون خط وضعیت هنگام کار، حساب و مصرف ۵ ساعته آن را نشان می‌دهد، بنابراین رسیدن به سقف غافلگیرتان نمی‌کند.

## وقتی به سقف رسیدید

از Claude Code خارج شوید (`/exit`)، سپس:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

گفتگو را در حسابی که بیشترین ظرفیت را دارد باز کنید:

```sh
ccam next --auto --continue
```

Claude Code با حساب `work` و با آخرین گفتگوی پوشه فعلی اجرا می‌شود، همراه با همه آنچه تا این لحظه گفته شده است.

## نکته‌هایی که باید در نظر داشته باشید

- `ccam next --continue` را در همان پوشه‌ای اجرا کنید که در آن کار می‌کردید؛ گفتگوها برای هر پوشه پروژه جداگانه ذخیره می‌شوند.
- از اجرای هم‌زمان دو حساب روی یک گفتگو پرهیز کنید. اگر چنین کاری کنید، ccam به شما هشدار می‌دهد.
- حساب دیگر هم باید تاریخچه گفتگو را در همان گروه به اشتراک بگذارد.
- اینکه اجازه دارید این‌گونه بین حساب‌ها جابه‌جا شوید یا نه، به شرایط هر حساب بستگی دارد.

برای همه گزینه‌های `ccam usage` و `ccam next`، [سقف مصرف](/docs/usage-limits) را ببینید.
