`ccam` بدون آرگومان، وقتی ورودی و خروجی استاندارد ترمینال باشند، یک داشبورد تمام‌صفحه باز می‌کند؛ در غیر این صورت `ccam list` را چاپ می‌کند. داشبورد هر حساب را همراه با مصرف و گروه‌هایش نشان می‌دهد و همان کارهایی را انجام می‌دهد که فرمان‌ها انجام می‌دهند: اجرا، افزودن، ورود، تغییر گروه‌ها، تعیین قواعد پوشه، بررسی و تعمیر. اجرای یک حساب داشبورد را می‌بندد؛ افزودن حساب یا ورود، داشبورد را برای ترمینال ترک می‌کند و سپس به آن برمی‌گردد.

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

خط زیر نام زبانه‌ها در یک جمله می‌گوید زبانه فعلی برای چیست. در ترمینال عریض‌تر، زبانه Accounts ایمیل هر حساب را هم نشان می‌دهد.

نخستین قاب فقط از روی `config.toml` رسم می‌شود، در زمانی بسیار کمتر از ۱۰۰ میلی‌ثانیه؛ مصرف هر حساب به محض پاسخ دادن آن پر می‌شود. هر سقف نوار خودش را دارد: پنجره ۵ ساعته، پنجره هفتگی برای همه مدل‌ها، و پنجره هفتگی ویژه Fable؛ `-` یعنی حساب چنین پنجره‌ای ندارد. یک درصد از ۸۰٪ زرد و در ۱۰۰٪ قرمز می‌شود، و مقدارهایی که پس از یک پرس‌وجوی ناموفق از حافظه نهان می‌آیند کم‌رنگ رسم می‌شوند.

## زبانه‌ها

| زبانه | آنچه نشان می‌دهد | کلیدها |
| --- | --- | --- |
| Accounts | شماره، نام، ایمیل، نوارهای ۵ ساعته، هفتگی و Fable، آخرین استفاده، گروه‌ها؛ `✔` حساب پیش‌فرض، `▸` حساب این پوشه، `•` در حال اجرا | پایین‌تر |
| Groups | هر گروه، آنچه به اشتراک می‌گذارد و حساب‌هایش، و حساب‌هایی که در هیچ گروهی نیستند | `enter` ویرایش، `n` جدید، `e` تغییر نام، `x` حذف |
| Folders | قواعد [`ccam folder`](/features/folder) و قاعده‌ای که اینجا اعمال می‌شود | `n` استفاده از یک حساب در اینجا، `enter` تغییر، `x` حذف |
| Extensions | آنچه [`ccam ext`](/features/ext) نشان می‌دهد، هر افزونه یک بار همراه با گروه‌هایی که از آن‌ها می‌آید | `r` بارگذاری دوباره |
| Health | آنچه [`ccam doctor`](/features/doctor) گزارش می‌دهد، به‌صورت یک کادر برای هر حساب (پایین‌تر) | `f` تعمیر کادر انتخاب‌شده، `F` تعمیر همه (`doctor --fix`)، `↑`/`↓` جابه‌جایی بین کادرها |

`←`/`→` یا `Tab` زبانه‌ها را عوض می‌کنند، `?` کلیدهای زبانه فعلی را فهرست می‌کند، `r` مصرف را بدون حافظه نهان کوتاه‌مدت دوباره می‌پرسد و `q` یا `Esc` خارج می‌شود.

## کلیدهای زبانه Accounts

| کلید | کاری که انجام می‌دهد |
| --- | --- |
| `Enter` | اجرای Claude Code با حساب انتخاب‌شده |
| `1`–`9` | رفتن به حسابی که آن شماره را دارد؛ برای ۱۲، `1` `2` را سریع پشت سر هم تایپ کنید. فقط `Enter` اجرا می‌کند |
| `↑`/`↓`، `k`/`j` | جابه‌جا شدن |
| `n` | اجرای حسابی که [`ccam next --auto`](/features/next) انتخاب می‌کرد |
| `o` | اجرا با گزینه‌ها: `--continue`، `--resume`، آرگومان‌های دیگر، یا یک اجرای آزمایشی |
| `u` | جزئیات مصرف: پنجره‌های ۵ ساعته، هفتگی و ویژه هر مدل همراه با زمان بازنشانی‌شان و منبع عددها |
| `a` | افزودن یک حساب (دستیار پایین) |
| `l` | ورود دوباره |
| `s` | انتخاب گروه‌های حساب |
| `d` | پیش‌فرض کردن حساب |
| `f` | استفاده از حساب در پوشه فعلی |
| `e` | تغییر نام حساب |
| `c` | تعیین یا حذف فرمان میان‌بر حساب |
| `x` | حذف حساب (ابتدا می‌پرسد و روی No شروع می‌کند) |

## زبانه Health

زبانه Health هنگام باز شدن، بررسی‌های [`ccam doctor`](/features/doctor) را اجرا می‌کند و همان نما را رسم می‌کند: خط اولی با یک علامت برای هر حساب، و سپس یک کادر برای هر حساب. هر ردیف در یک کادر یک حوزه بررسی‌شده است، ابتدا `Folder`، `Login` و `Share links`، با علامت `✔` درست، `ℹ` اطلاعات، `⚠` هشدار یا `✘` خطا، تا فوراً ببینید کدام حساب مشکل دارد و کجا. یافته‌هایی که به هیچ حسابی تعلق ندارند در کادر `General` قرار می‌گیرند.

```console
 ✘ personal   ⚠ work

 ╭─ ✘ personal · 3 problems ──────────────────────────────────────────────────╮
 │ ⚠ Folder       folder permissions are 755 (should be 0700)                 │
 │ ℹ              unknown entries (Claude Code layout may have changed):      │
 │                newthing                                                    │
 │ ⚠ Login        .credentials.json permissions are 644 (should be 0600)      │
 │ ✔              login valid (me@example.com)                                │
 │ ✘ Share links  /home/me/.local/share/ccam/profiles/personal/settings.json: │
 │                set to shared but is a real file, not a link                │
 ╰────────────────────────────────────────────────────────────────────────────╯
 ╭─ ⚠ work · 1 problem ───────────────────────────────────────────────────────╮
 │ ✔ Folder       OK                                                          │
 │ ⚠ Login        not logged in → `ccam login work`                           │
 │ ✔ Share links  share links OK                                              │
 ╰────────────────────────────────────────────────────────────────────────────╯

 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` از کادری به کادر دیگر می‌روند و کادر انتخاب‌شده حاشیه‌ای به رنگ تأکیدی دارد. `f` فقط کادر انتخاب‌شده را تعمیر می‌کند، همان‌طور که `ccam doctor --fix` تعمیر می‌کند: در کادر یک حساب فقط همان حساب را تعمیر می‌کند و در کادر `General` یافته‌هایی را که به هیچ حسابی تعلق ندارند (مسیرهای افزونه‌ها و میان‌برها)؛ بقیه حساب‌ها فقط دوباره بررسی می‌شوند. ابتدا می‌پرسد، و کادری که چیزی برای تعمیر ندارد فقط می‌گوید `nothing to repair in <name>`. `F` همه چیز را یک‌جا تعمیر می‌کند، مانند `ccam doctor --fix`، و `r` دوباره بررسی می‌کند.

## تغییر گروه‌ها

در زبانه Groups، `Enter` ویرایشگر را باز می‌کند: موارد در سمت چپ، حساب‌ها در سمت راست، `Tab` برای جابه‌جایی بین آن‌ها و `Space` برای روشن و خاموش کردن. موردی که یکی از حساب‌ها از قبل از گروه دیگری می‌گیرد، همراه با دلیل آن کم‌رنگ نشان داده می‌شود، و همچنین حسابی که یک مورد را دو بار می‌گرفت؛ هر مورد فقط از یک گروه می‌تواند بیاید. `Enter` برنامه را نشان می‌دهد:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

ابتدا درباره فایلی که با نسخه گروه متفاوت است پرسیده می‌شود (نسخه گروه نگه داشته شود، نسخه من استفاده شود، یا ادغام شوند). سپس تغییر در پس‌زمینه با همان کد [`ccam group`](/features/share) اجرا می‌شود: ابتدا پیکربندی ذخیره می‌شود، داده‌های هر حساب به ترتیب جابه‌جا می‌شوند و نسخه‌های اصلی به `.ccam-backup/` می‌روند. تغییری که داده‌های یک حساب در حال اجرا را جابه‌جا می‌کرد، همراه با نام آن حساب رد می‌شود.

## افزودن یک حساب

`a` دستیاری را باز می‌کند که `ccam add` هم در ترمینال از آن استفاده می‌کند:

1. نام حساب.
2. روش ورود آن: اشتراک Claude همین حالا (در مرورگر)، یک [کلید API](/features/api)، یا اشتراک Claude بعداً.
3. برای کلید API: جایی که ccam کلید را در هر اجرا از آن می‌خواند (`env:NAME` یا `command:COMMAND`)، نقطه پایانی، روش فرستادن کلید و مدل.
4. گروه‌هایی که حساب به آن‌ها می‌پیوندد، با `default` علامت‌خورده؛ تا وقتی گروهی وجود ندارد، آنچه گروه `default` به اشتراک می‌گذارد.
5. یک فرمان میان‌بر، اگر بخواهید.
6. خلاصه‌ای برای تأیید.

`Esc` یک مرحله به عقب برمی‌گردد و در مرحله اول دستیار را می‌بندد.

## رنگ‌ها

رنگ‌ها از نقش‌های رابط ترمینالی Claude Code پیروی می‌کنند تا ccam در کنار آن آشنا به نظر برسد؛ نام گروه‌ها رنگی برگرفته از نامشان می‌گیرند. ccam پس‌زمینه ترمینال را از خود ترمینال می‌پرسد و یک پوسته روشن یا تیره انتخاب می‌کند. خودتان می‌توانید یکی را در `config.toml` تعیین کنید:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

پوسته‌های `-daltonized` برای کوررنگی قرمز و سبز هستند و پوسته‌های `-ansi` از ۱۶ رنگ خود ترمینال استفاده می‌کنند. `NO_COLOR` رنگ‌ها را خاموش می‌کند.

## ایمنی و موارد خاص

- داشبورد همان تابع‌هایی را فرا می‌خواند که فرمان‌ها فرا می‌خوانند، بنابراین همه قواعد برقرارند: برنامه پیش از جابه‌جایی داده، رد کردن تغییر برای حساب‌های در حال اجرا، نسخه‌های پشتیبان، و توکن‌های ورودی که هرگز از یک حساب بیرون نمی‌روند.
- داشبورد اجرای آزمایشی ندارد: `ccam --dry-run` بدون نام حساب چاپ می‌کند که حساب این پوشه چگونه آغاز می‌شود، و `o` روی یک حساب، اجرای آزمایشی همان یک اجرا را پیشنهاد می‌دهد.
- ترمینال پیش از شروع Claude Code یا باز شدن صفحه ورود به حالت عادی برمی‌گردد.
- در صفحه‌ای که برای یک پنجره گفتگو بیش از حد کوچک است، ابتدا ردیف‌های زبانه کنار گذاشته می‌شوند؛ خط‌ها به‌جای شکستن، با `…` کوتاه می‌شوند.
