`ccs usage` نشان می‌دهد هر حساب چه مقدار از سقف ۵ ساعته و هفتگی خود را مصرف کرده است. `ccs next --auto` حسابی را که بیشترین ظرفیت را دارد باز می‌کند و `--continue` گفتگوی فعلی را به آن منتقل می‌کند.

```console
$ ccs usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccs next --auto 로 바로 열기)
```

ستون‌ها به ترتیب عبارت‌اند از: حساب، مصرف ۵ ساعته، زمان باقی‌مانده تا بازنشانی آن، مصرف هفتگی، زمان باقی‌مانده تا بازنشانی آن، و اینکه عددها چقدر قدیمی‌اند.

## این عددها از کجا می‌آیند

ccam برای همه حساب‌ها هم‌زمان از نقطه پایانی مصرف Anthropic پرس‌وجو می‌کند و برای هر حساب از ورود خود همان حساب استفاده می‌کند. برای هر حساب حداکثر ۳ ثانیه صبر می‌کند و هر حساب را به محض پاسخ دادن نشان می‌دهد.

این نقطه پایانی به‌طور عمومی مستند نشده است و ممکن است تغییر کند. وقتی یک درخواست ناموفق باشد، ccam آخرین عددهای شناخته‌شده را نشان می‌دهد و آن‌ها را به‌عنوان داده حافظه نهان علامت می‌زند. اگر قالب پاسخ تغییر کرده باشد، `ccam doctor` به شما اطلاع می‌دهد.

عددهایی که کمتر از ۶۰ ثانیه پیش دریافت شده‌اند دوباره استفاده می‌شوند. گزینه‌ها:

| گزینه | اثر |
| --- | --- |
| `--watch [seconds]` | به‌روزرسانی پیوسته، به‌طور پیش‌فرض هر ۶۰ ثانیه |
| `--json` | خروجی قابل خواندن برای ماشین |
| `-v` | نمایش سقف‌های هفتگی ویژه هر مدل و منبع هر عدد |
| `--no-cache` | همیشه دوباره پرس‌وجو کن |
| `--source cache` | هرگز پرس‌وجو نکن؛ فقط عددهای ذخیره‌شده را نشان بده |

## ورودهای منقضی‌شده

وقتی توکن دسترسی یک حساب منقضی شده باشد، ccam آن را تمدید نمی‌کند، زیرا تمدید آن در حالی که یک نشست Claude Code از همان ورود استفاده می‌کند ممکن است آن نشست را از حساب خارج کند. حساب را یک بار با `ccs <name>` اجرا کنید تا Claude Code آن را تمدید کند.

`ccs usage --refresh` توکن‌های منقضی‌شده را خودش تمدید می‌کند، اما فقط برای حساب‌هایی که در حال اجرا نیستند. این فرمان هرگز ورودهایی را که در Keychain سیستم macOS یا در یک `~/.claude` واردشده ذخیره شده‌اند تمدید نمی‌کند.

## مصرف در خط وضعیت

```sh
ccam statusline install
```

پس از آن Claude Code نام حساب و مصرف آن را در خط وضعیت نشان می‌دهد، برای مثال `[work] · Opus · 5h 24% · 7d 41%`. اگر از قبل یک فرمان خط وضعیت داشته باشید، ccam آن را نگه می‌دارد و نام حساب را پیش از آن قرار می‌دهد. خط وضعیت عددهای خود را هم ذخیره می‌کند و `ccs usage` وقتی نقطه پایانی پاسخ ندهد از آن‌ها استفاده می‌کند.

## جابه‌جایی

```sh
ccs next              # the account after the one you used last
ccs next --auto       # the account with the lowest 5-hour usage
ccs next --continue   # the next account that shares your conversation history
```

`ccs next` از حساب‌هایی که وارد نشده‌اند می‌گذرد و `--auto` از حساب‌هایی که به ۱۰۰٪ رسیده‌اند می‌گذرد. برای ادامه یک گفتگو، هر دو حساب باید تاریخچه گفتگو را به اشتراک بگذارند؛ [اشتراک‌گذاری](/docs/sharing) را ببینید.

[راهنمای کار با سقف مصرف](/guides/usage-limit-workflow) یک نمونه کامل را گام به گام نشان می‌دهد.
