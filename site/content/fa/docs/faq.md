## آیا ccam ابزار رسمی Anthropic است؟

خیر. ccam یک پروژه متن‌باز غیررسمی است و هیچ وابستگی به Anthropic ندارد و مورد تأیید آن نیست. این ابزار از تنظیم `CLAUDE_CONFIG_DIR` استفاده می‌کند که Claude Code برای اجرای هم‌زمان چند حساب در مستندات خود معرفی کرده است.

## آیا اجازه دارم از چند حساب Claude Code استفاده کنم؟

این به شرایط هر حساب و، در مورد حساب‌های کاری، به سیاست سازمان شما بستگی دارد. پیش از استفاده از چند حساب، آن‌ها را بررسی کنید. ccam فقط جابه‌جایی بین حساب‌هایی را که از قبل دارید آسان‌تر می‌کند.

## آیا ccam سقف مصرف را دور می‌زند؟

خیر. هر حساب سقف‌های خودش را دارد. ccam آن‌ها را نشان می‌دهد و وقتی سقف یک حساب پر شد، به شما امکان می‌دهد کار را در حساب دیگری که متعلق به خودتان است ادامه دهید.

## چگونه از دو حساب Claude Code روی یک رایانه استفاده کنم؟

به هر حساب یک پوشه پیکربندی جداگانه با `CLAUDE_CONFIG_DIR` بدهید. ccam این کار را برای شما انجام می‌دهد: برای هر حساب `ccam add` را اجرا کنید، سپس آن‌ها را با `ccam personal` و `ccam work` اجرا کنید، یا با میان‌برهایی که نامشان را خودتان انتخاب می‌کنید، مانند `ccwork`. [راهنما](/guides/multiple-claude-code-accounts) همچنین نشان می‌دهد چگونه این کار را دستی انجام دهید.

## چگونه یک گفتگو را در حساب دیگری ادامه دهم؟

تاریخچه گفتگو را با `ccam share <name> --history on` بین دو حساب به اشتراک بگذارید، سپس `ccam next --continue` را اجرا کنید. Claude Code آخرین گفتگوی پوشه فعلی را در حساب بعدی باز می‌کند.

## آیا ccam اطلاعات ورود مرا می‌بیند یا جایی می‌فرستد؟

ccam هرگز اطلاعات ورود Claude شما را بین حساب‌ها به اشتراک نمی‌گذارد. توکن دسترسی یک حساب را فقط وقتی می‌خواند که `ccam usage`، `ccam next --auto` یا `ccam doctor` را اجرا کنید، و فقط برای اینکه مصرف همان حساب را از نقطه پایانی مصرف Anthropic بپرسد. `ccam migrate` ورودهای ذخیره‌شده سرورهای MCP را از `~/.claude` در فایل‌های ورود خود حساب‌هایتان روی همان رایانه کپی می‌کند. ccam هیچ تله‌متری ندارد و هیچ چیزی به جای دیگری نمی‌فرستد.

## چگونه روی یک سرور راه دور وارد شوم؟

`ccam add` یا `ccam login <name>` را طبق معمول در نشست SSH اجرا کنید. Claude Code روی سرور منتظر ورود می‌ماند، بنابراین مرورگر روی رایانه شما در صفحه‌ای با نشانی `http://localhost:<port>/callback?code=…` می‌ماند که بارگذاری نمی‌شود. این نشانی را از مرورگر کپی کنید و در ترمینال بچسبانید: ccam آن را به Claude Code روی سرور می‌دهد و ورود کامل می‌شود. این نشانی یک کد یک‌بارمصرف دارد، پس آن را با کسی به اشتراک نگذارید.

## حساب‌های من کجا ذخیره می‌شوند؟

در `~/.local/share/ccam/profiles/<name>/`، یک پوشه برای هر حساب. در macOS، خود اطلاعات ورود را Claude Code در Keychain نگه می‌دارد، با نامی که از آن پوشه ساخته می‌شود.

## چه بر سر پوشه ~/.claude فعلی من می‌آید؟

هیچ، مگر اینکه `ccam import` یا `ccam migrate` را اجرا کنید. import پوشه را در همان جایی که هست ثبت می‌کند، بنابراین `claude` معمولی و `ccam <name>` همچنان از همان حساب و تنظیمات استفاده می‌کنند. `ccam migrate` تنظیمات، `CLAUDE.md`، افزونه‌ها و سرورهای MCP آن را در تنظیمات مشترک کپی می‌کند و پوشه را فقط می‌خواند.

## ccam از کدام سیستم‌ها پشتیبانی می‌کند؟

Linux (Ubuntu، Debian، Fedora، Arch، Alpine و توزیع‌های دیگر) و macOS. در Windows، آن را داخل WSL به کار ببرید.

## چرا یک سرور MCP فقط در یک حساب دیده می‌شود؟

سرورهایی که داخل یک نشست با `claude mcp add` اضافه می‌شوند فقط برای همان حساب ذخیره می‌شوند. ccam دفعه بعد که آن حساب را اجرا کنید به شما اطلاع می‌دهد؛ سرور را با `ccam mcp import <account> <server>` به گروه مشترک منتقل کنید.

## آیا ccam سرعت Claude Code را کم می‌کند؟

اجرای Claude Code از طریق ccam حدود ۴ میلی‌ثانیه اضافه می‌کند؛ این عدد با `scripts/perf-check.sh` روی یک لپ‌تاپ اندازه‌گیری شده است. ccam یک فایل کوچک را می‌خواند، پیوندهای مشترک را بررسی می‌کند و سپس خودش را با `claude` جایگزین می‌کند، بنابراین هنگام کار شما در حال اجرا نیست.

## چگونه ccam را به‌روز کنم؟

`ccam update` را اجرا کنید. این فرمان آخرین نسخه را دانلود می‌کند، checksum آن را بررسی می‌کند و فایل `ccam` را جایگزین می‌کند؛ `ccam update --check` فقط می‌گوید که آیا نسخه جدیدتری وجود دارد یا نه. ccam هرگز خودبه‌خود به‌روز نمی‌شود. اگر بسته `.deb` را نصب کرده‌اید، به‌جای آن `.deb` جدید را با apt نصب کنید. [به‌روزرسانی](/docs/install#update) را ببینید.

## چگونه ccam را حذف کنم؟

میان‌بر هر حساب را با `ccam shortcut <account> --remove` حذف کنید، `ccam` را از `~/.local/bin` پاک کنید، سپس اگر دیگر به حساب‌ها نیاز ندارید، `~/.config/ccam`، `~/.local/share/ccam` و `~/.local/state/ccam` را حذف کنید. [نصب](/docs/install#uninstall) را ببینید.
