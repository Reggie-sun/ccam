هر حساب را با `ccam add` اضافه کنید، سپس Claude Code را با `claude1`، `claude2` یا `ccam <name>` اجرا کنید. بیشتر کاربران به چیزی بیش از این نیاز ندارند.

## ۱. نخستین حساب را اضافه کنید

```sh
ccam add
```

دستیار راه‌اندازی یک نام مانند `personal` یا `work` از شما می‌پرسد و اینکه حساب کدام موارد را با حساب‌های دیگر شما به اشتراک بگذارد. سپس `claude auth login` را اجرا می‌کند که مرورگر را باز می‌کند تا وارد حساب شوید. در پایان این را می‌بینید:

```console
✓ personal (me@example.com) 추가됨 — 단축 명령: claude1
```

ccam فعلاً پیام‌های خود را به زبان کره‌ای چاپ می‌کند؛ فرمان‌ها و گزینه‌ها در همه زبان‌ها یکسان‌اند.

## ۲. حساب دوم را اضافه کنید

```sh
ccam add work
```

در مرورگر با حساب دیگر وارد شوید. این حساب `claude2` می‌شود.

## ۳. جابه‌جا شوید

هر یک از این فرمان‌ها Claude Code را با حساب کاری اجرا می‌کند:

```sh
claude2
ccam work
ccam 2
```

هر چه پس از نام حساب بیاید بدون تغییر به Claude Code می‌رسد، بنابراین می‌توانید همان گزینه‌هایی را که می‌شناسید به کار ببرید:

```sh
ccam work --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

اجرای `ccam` به‌تنهایی یک انتخابگر باز می‌کند: از کلیدهای جهت‌نما و Enter استفاده کنید یا شماره حساب را بزنید.

## ۴. تعیین کنید چه چیزهایی مشترک باشد

به‌طور پیش‌فرض، سرورهای MCP، `settings.json`، فایل سراسری `CLAUDE.md` و همچنین agents، commands، skills و plugins بین حساب‌ها مشترک‌اند. تاریخچه گفتگو مشترک نیست. اگر می‌خواهید گفتگوها را بین حساب‌ها ادامه دهید، آن را برای هر دو حساب روشن کنید:

```sh
ccam share personal --history on
ccam share work --history on
```

ccam پیش از هر تغییری نشان می‌دهد چه چیزهایی را جابه‌جا خواهد کرد. برای جزئیات، [اشتراک‌گذاری](/docs/sharing) را ببینید.

## ۵. وقتی یک حساب به سقف خود می‌رسد

```sh
ccam usage
ccam next --continue
```

`ccam usage` مصرف ۵ ساعته و هفتگی همه حساب‌ها را نشان می‌دهد. `ccam next --continue` همان گفتگو را در حساب بعدی باز می‌کند. [سقف مصرف](/docs/usage-limits) را ببینید.

## از ~/.claude استفاده می‌کنید؟

به‌جای ورود دوباره، آن را ثبت کنید:

```sh
ccam import
```

پوشه در همان جایی که هست می‌ماند و `claude` معمولی مثل قبل کار می‌کند.
