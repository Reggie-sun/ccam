ccam은 한 컴퓨터에서 Claude Code 계정을 두 개 이상 쓰는 사람을 위한 작은 명령줄 도구입니다. 개인 계정과 회사 계정을 함께 쓰거나, 긴 프로젝트 하나에 여러 계정을 쓰는 경우가 그렇습니다.

## 문제점

Claude Code는 `CLAUDE_CONFIG_DIR`로 여러 계정을 지원합니다. 계정마다 폴더를 하나씩 쓰는 방식입니다. 하지만 실제로 써 보면 폴더 하나하나가 외딴섬입니다. 설정, `CLAUDE.md`, MCP 서버, 에이전트, 스킬을 폴더마다 다시 설정해야 하고, 서로 맞추는 일도 손수 해야 합니다. 대화는 시작한 폴더에만 남습니다. 게다가 한 계정이 사용량 한도에 도달했는지는 직접 써 봐야 알 수 있습니다.

## ccam이 하는 일

- `ccam add`는 폴더를 만들고 로그인을 진행한 뒤, 계정에 `claude1`, `claude2` 같은 단축 명령을 붙입니다.
- `ccam work`와 `claude2`는 해당 계정으로 Claude Code를 시작하고, 모든 인자를 그대로 전달합니다.
- MCP 서버, 설정, `CLAUDE.md`, 확장 기능은 링크로 공유하며, 항목별·계정별로 고를 수 있습니다. 로그인 정보는 절대 공유하지 않습니다.
- `ccam usage`는 모든 계정의 5시간·주간 사용량을 보여 주고, `ccam next --continue`는 다음 계정에서 대화를 이어 갑니다.

## 작업을 방해하지 않는 설계

세션을 시작할 때마다 실행하는 도구라면 그 비용이 체감되지 않아야 합니다. ccam은 설정 파일 하나를 읽고, 공유 링크를 하나당 시스템 호출 한 번으로 확인한 다음, 자기 프로세스를 `claude`로 바꿉니다. 추가되는 시간은 약 4밀리초이고, 작업하는 동안에는 실행되고 있지 않습니다.

파일도 신중하게 다룹니다. 공유 설정을 바꿀 때는 항상 시작 전에 계획을 출력하고, 원본은 백업 폴더에 보관합니다. `ccam doctor`는 링크, 권한, 로그인을 점검하고, 안전하게 고칠 수 있는 문제는 고칩니다.

## 직접 써 보기

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add
```

ccam은 오픈소스 비공식 도구로, Anthropic과 제휴 관계가 없으며 Anthropic의 보증을 받지 않았습니다. 여러 계정을 사용해도 되는지는 각 계정의 약관에 따라 다릅니다. 의견이나 번역 기여는 [GitHub](https://github.com/jhyunwoo/ccam)에서 환영합니다.
