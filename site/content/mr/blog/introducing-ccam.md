ccam हे एकाच कॉम्प्युटरवर एकापेक्षा जास्त Claude Code खाती वापरणाऱ्या लोकांसाठी छोटे कमांड-लाइन टूल आहे: एक वैयक्तिक आणि एक कामाचे खाते, किंवा एका मोठ्या प्रोजेक्टसाठी अनेक खाती.

## समस्या

Claude Code `CLAUDE_CONFIG_DIR` द्वारे अनेक खात्यांना समर्थन देते: प्रत्येक खात्यासाठी एक फोल्डर. प्रत्यक्षात प्रत्येक फोल्डर एक बेट असतो. सेटिंग्ज, `CLAUDE.md`, MCP सर्व्हर, agents आणि skills प्रत्येक फोल्डरमध्ये पुन्हा सेट कराव्या लागतात आणि हाताने एकसारख्या ठेवाव्या लागतात. संभाषणे जिथे सुरू झाली तिथेच राहतात. आणि एखादे खाते वापर मर्यादेला पोहोचले हे तुम्हाला प्रयत्न केल्यावरच कळते.

## ccam काय करते

- `ccam add` फोल्डर तयार करते, लॉगिन चालवते आणि खात्याला शॉर्टकट देते: `claude1`, `claude2` वगैरे.
- `ccs work` आणि `claude2` त्या खात्याने Claude Code सुरू करतात आणि प्रत्येक आर्ग्युमेंट जसेच्या तसे पुढे पाठवतात.
- MCP सर्व्हर, सेटिंग्ज, `CLAUDE.md` आणि एक्स्टेंशन्स लिंक्सद्वारे, आयटमनुसार आणि खात्यानुसार शेअर होतात. लॉगिन कधीच शेअर होत नाहीत.
- `ccs usage` सर्व खात्यांचा 5 तासांचा आणि साप्ताहिक वापर दाखवते; `ccs next --continue` संभाषण पुढच्या खात्यात पुढे सुरू करते.

## अडथळा न आणणे

प्रत्येक session पूर्वी चालवले जाणारे टूल तुमच्या लक्षात येईल इतका वेळ घेऊ नये. ccam एक configuration फाइल वाचते, प्रत्येक शेअर केलेली लिंक एकाच system call ने तपासते, आणि नंतर स्वतःच्या जागी `claude` ठेवते. ते सुमारे 4 मिलिसेकंद वाढवते, आणि तुम्ही काम करत असताना ते चालू नसते.

ते तुमच्या फाइल्सचीही काळजी घेते. शेअरिंगमधील प्रत्येक बदल सुरू होण्यापूर्वी योजना प्रिंट करतो आणि मूळ फाइल्स बॅकअप फोल्डरमध्ये ठेवतो. `ccam doctor` लिंक्स, परवानग्या आणि लॉगिन तपासते, आणि सुरक्षितपणे जे दुरुस्त करता येते ते दुरुस्त करते.

## वापरून पाहा

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add
```

ccam ओपन सोर्स आणि अनधिकृत आहे: त्याचा Anthropic शी संबंध नाही आणि Anthropic त्याला मान्यता देत नाही. तुम्ही अनेक खाती वापरू शकता की नाही हे प्रत्येक खात्याच्या अटींवर अवलंबून आहे. अभिप्राय आणि भाषांतरांचे [GitHub](https://github.com/jhyunwoo/ccam) वर स्वागत आहे.
