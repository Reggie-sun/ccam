## ccam हे Anthropic चे अधिकृत टूल आहे का?

नाही. ccam हा अनधिकृत ओपन-सोर्स प्रकल्प आहे. त्याचा Anthropic शी संबंध नाही आणि Anthropic त्याला मान्यता देत नाही. अनेक खाती शेजारी शेजारी चालवण्यासाठी Claude Code ने [दस्तऐवजात दिलेली](https://code.claude.com/docs/en/env-vars) `CLAUDE_CONFIG_DIR` सेटिंग ते वापरते.

## मला अनेक Claude Code खाती वापरण्याची परवानगी आहे का?

ते प्रत्येक खात्याच्या अटींवर आणि कामाच्या खात्यांसाठी तुमच्या संस्थेच्या धोरणावर अवलंबून आहे. अनेक खाती वापरण्यापूर्वी त्या तपासा. ccam फक्त तुमच्याकडे आधीपासून असलेल्या खात्यांमध्ये बदल करणे सोपे करते.

## ccam वापर मर्यादा टाळते का?

नाही. प्रत्येक खात्याच्या स्वतःच्या मर्यादा कायम राहतात. ccam त्या दाखवते, आणि एखाद्या खात्याची मर्यादा संपली की तुमच्या मालकीच्या दुसऱ्या खात्यावर पुढे चालू ठेवू देते.

## एका कॉम्प्युटरवर दोन Claude Code खाती कशी वापरायची?

प्रत्येक खात्याला `CLAUDE_CONFIG_DIR` द्वारे त्याचा स्वतःचा configuration फोल्डर द्या. ccam हे तुमच्यासाठी करते: प्रत्येक खात्यासाठी `ccam add` चालवा, नंतर ती `ccam personal` आणि `ccam work` ने, किंवा तुम्ही स्वतः नाव दिलेल्या शॉर्टकटने, जसे `ccwork`, सुरू करा. हे हाताने कसे करायचे तेही [मार्गदर्शकात](/guides/multiple-claude-code-accounts) दाखवले आहे.

## दुसऱ्या खात्यावर संभाषण पुढे कसे चालू ठेवायचे?

`ccam group set default --add history` ने (किंवा त्यांच्या स्वतःच्या गटाने: `ccam group add pair --items history --members work,side`) खात्यांमध्ये संभाषण इतिहास शेअर करा, नंतर `ccam next --continue` चालवा. Claude Code पुढच्या खात्यात चालू फोल्डरमधील सर्वात अलीकडचे संभाषण उघडते.

## ccam माझे लॉगिन पाहते किंवा पाठवते का?

ccam तुमचे Claude लॉगिन खात्यांमध्ये कधीही शेअर करत नाही. तुम्ही `ccam usage`, `ccam next --auto` किंवा `ccam doctor` चालवता तेव्हा, त्या खात्याचा वापर Anthropic च्या usage endpoint कडून विचारण्यासाठीच ते खात्याचे access token वाचते. `ccam migrate` MCP सर्व्हरची सेव्ह केलेली साइन-इन्स `~/.claude` मधून त्याच कॉम्प्युटरवरील तुमच्या खात्यांच्या स्वतःच्या लॉगिन फाइल्समध्ये कॉपी करते. ccam मध्ये कोणतीही telemetry नाही आणि ते इतर कुठेही काहीही पाठवत नाही.

## रिमोट सर्व्हरवर साइन इन कसे करायचे?

SSH सेशनमध्ये नेहमीप्रमाणे `ccam add` किंवा `ccam login <name>` चालवा. Claude Code सर्व्हरवर साइन-इनची वाट पाहते, म्हणून तुमच्या कॉम्प्युटरवरील ब्राउझर शेवटी लोड न होणाऱ्या `http://localhost:<port>/callback?code=…` पेजवर थांबतो. तो पत्ता ब्राउझरमधून कॉपी करून टर्मिनलमध्ये पेस्ट करा: ccam तो सर्व्हरवरील Claude Code ला देते, जे साइन-इन पूर्ण करते. या पत्त्यात एकदाच वापरता येणारा कोड असतो, म्हणून तो कोणाशीही शेअर करू नका.

## माझी खाती कुठे साठवली जातात?

`~/.local/share/ccam/profiles/<name>/` मध्ये, प्रत्येक खात्यासाठी एक फोल्डर. macOS वर Claude Code लॉगिन स्वतः Keychain मध्ये, त्या फोल्डरवरून बनवलेल्या नावाखाली ठेवते.

## माझ्या आधीच्या ~/.claude चे काय होते?

तुम्ही `ccam import` किंवा `ccam migrate` चालवल्याशिवाय काहीच नाही. Import फोल्डर आहे तिथेच नोंदवते, त्यामुळे साधे `claude` आणि `ccam <name>` तेच खाते आणि सेटिंग्ज वापरत राहतात. `ccam migrate` त्याची सेटिंग्ज, `CLAUDE.md`, एक्स्टेंशन्स आणि MCP सर्व्हर शेअर केलेल्या सेटिंग्जमध्ये कॉपी करते आणि फोल्डर फक्त वाचते.

## ccam कोणत्या सिस्टिम्सना समर्थन देते?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine आणि इतर), macOS आणि Windows 10 व 11, थेट किंवा WSL मध्ये. Windows वर `settings.json` सारख्या फाइल्स शेअर करण्यासाठी Developer Mode लागतो; शेअर केलेले फोल्डर त्याशिवाय चालतात ([Windows वर शेअरिंग](/features/share#on-windows)).

## एखादा MCP सर्व्हर फक्त एकाच खात्यात का दिसतो?

session मध्ये `claude mcp add` ने जोडलेले सर्व्हर फक्त त्याच खात्यासाठी साठवले जातात. पुढच्या वेळी तुम्ही ते खाते सुरू कराल तेव्हा ccam तुम्हाला सांगते; `ccam mcp import <account> <server>` ने तो सर्व्हर शेअर केलेल्या गटात हलवा.

## ccam मुळे Claude Code धीमे होते का?

ccam मार्फत Claude Code सुरू केल्याने सुमारे 4 मिलिसेकंद वाढतात, हे एका लॅपटॉपवर `scripts/perf-check.sh` ने मोजले आहे. ccam एक छोटी फाइल वाचते, शेअर केलेल्या लिंक्स तपासते आणि नंतर स्वतःच्या जागी `claude` ठेवते, त्यामुळे तुम्ही काम करत असताना ते चालू नसते. Windows process बदलू शकत नाही, त्यामुळे तिथे ccam Claude Code सुरू करते आणि त्याची वाट पाहते, आणि दुसरे काहीही करत नाही.

## ccam अपडेट कसे करायचे?

`ccam update` चालवा. ते नवीनतम रिलीज डाउनलोड करते, त्याचा checksum तपासते आणि `ccam` फाइल बदलते; `ccam update --check` फक्त नवीन रिलीज उपलब्ध आहे का ते सांगते. ccam स्वतःहून कधीही अपडेट होत नाही. तुम्ही `.deb` पॅकेज इन्स्टॉल केले असेल, तर त्याऐवजी नवीन `.deb` apt ने इन्स्टॉल करा. तपशीलासाठी [अपडेट](/docs/install#update) पाहा.

## ccam अनइन्स्टॉल कसे करायचे?

प्रत्येक खात्याचा शॉर्टकट `ccam shortcut <account> --remove` ने काढा, `~/.local/bin` मधून `ccam` हटवा, नंतर खाती आता लागत नसतील तर `~/.config/ccam`, `~/.local/share/ccam` आणि `~/.local/state/ccam` काढा. [इन्स्टॉल](/docs/install#uninstall) पाहा.
