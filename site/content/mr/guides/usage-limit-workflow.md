एखादे खाते वापर मर्यादेला पोहोचले की तेच संभाषण तुमच्या मालकीच्या दुसऱ्या खात्यात पुढे चालू ठेवा: एकदा संभाषण इतिहास शेअर करा, नंतर `ccam next --continue` चालवा. तुमच्याकडे एकच खाते असेल, तर Claude Code दाखवत असलेल्या रीसेट वेळेपर्यंत थांबा.

## हे होण्यापूर्वी

खाती अशी सेट करा की खाते बदलणे एका कमांडमध्ये होईल:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

आता तुम्ही काम करत असताना स्टेटस लाइन खाते आणि त्याचा 5 तासांचा वापर दाखवते, त्यामुळे मर्यादा अचानक येत नाही.

## मर्यादा गाठल्यावर

Claude Code मधून बाहेर पडा (`/exit`), नंतर:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

सर्वात जास्त जागा असलेल्या खात्यात संभाषण उघडा:

```sh
ccam next --auto --continue
```

Claude Code `work` म्हणून सुरू होते, चालू फोल्डरमधील सर्वात अलीकडच्या संभाषणासह, आतापर्यंत बोललेल्या सर्व गोष्टींसह.

## लक्षात ठेवण्याच्या गोष्टी

- तुम्ही ज्या फोल्डरमध्ये काम केले त्याच फोल्डरमध्ये `ccam next --continue` चालवा; संभाषणे प्रत्येक प्रोजेक्ट फोल्डरनुसार साठवली जातात.
- एकाच संभाषणावर एकाच वेळी दोन खाती चालवणे टाळा. तुम्ही तसा प्रयत्न केल्यास ccam तुम्हाला सावध करते.
- दुसऱ्या खात्यानेही त्याच गटात संभाषण इतिहास शेअर केलेला असणे आवश्यक आहे.
- अशा प्रकारे खाती बदलण्याची परवानगी आहे की नाही हे प्रत्येक खात्याच्या अटींवर अवलंबून आहे.

`ccam usage` आणि `ccam next` च्या प्रत्येक पर्यायासाठी [वापर मर्यादा](/docs/usage-limits) पाहा.
