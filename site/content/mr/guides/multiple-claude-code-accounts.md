एका कॉम्प्युटरवर दोन Claude Code खाती वापरण्यासाठी प्रत्येक खात्याला स्वतःचा configuration फोल्डर द्या. Claude Code हा फोल्डर `CLAUDE_CONFIG_DIR` environment variable मधून वाचते, आणि प्रत्येक फोल्डरमध्ये स्वतःचे लॉगिन, सेटिंग्ज आणि इतिहास असतो. हे तुम्ही शेल alias ने हाताने सेट करू शकता, किंवा ccam ला करू देऊ शकता.

## हाताने, alias वापरून

Claude Code च्या दस्तऐवजात हीच पद्धत सांगितली आहे. प्रत्येक अतिरिक्त खात्यासाठी `~/.bashrc` किंवा `~/.zshrc` मध्ये एक ओळ जोडा:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

नवीन टर्मिनल उघडा आणि `claude-work` चालवा. फोल्डर नवीन असल्यामुळे Claude Code तुम्हाला लॉगिन करायला सांगते. त्यानंतर `claude` हे तुमचे पहिले खाते आणि `claude-work` दुसरे खाते असते.

दोन खात्यांसाठी हे चांगले काम करते. लक्षात ठेवण्यासारख्या गोष्टी:

- प्रत्येक फोल्डर रिकामा सुरू होतो: सेटिंग्ज नाहीत, `CLAUDE.md` नाही, MCP सर्व्हर नाहीत, agents किंवा skills नाहीत. जे लागते ते तुम्ही कॉपी किंवा लिंक करता, आणि त्या प्रती एकसारख्या ठेवण्याचे काम स्वतः करता.
- Aliases फक्त interactive शेलमध्ये असतात. स्क्रिप्ट्स, Makefiles आणि इतर प्रोग्राम्सना ते दिसत नाहीत.
- MCP सर्व्हर लॉगिनच्या शेजारी `.claude.json` मध्ये असतात, त्यामुळे ते फोल्डर्समध्ये सहज लिंक करता येत नाहीत.
- संभाषणे ज्या खात्यात सुरू झाली त्याच खात्यात राहतात, त्यामुळे ती दुसऱ्या खात्यात पुढे चालू ठेवता येत नाहीत.
- सर्व खात्यांचा वापर एकाच वेळी दाखवणारे काहीही नाही.

## ccam वापरून

ccam हीच कल्पना स्वयंचलित करते आणि उणिवा भरून काढते:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

आता `ccam personal` आणि `ccam work` ही दोन खाती सुरू करतात, आणि `ccwork` सुद्धा, जो शॉर्टकट तुम्ही work खात्याला दिला. ते aliases नसून खरे प्रोग्राम आहेत, त्यामुळे scripts मध्येही चालतात. सेटिंग्ज, `CLAUDE.md`, MCP सर्व्हर आणि एक्स्टेंशन्स सुरुवातीपासून शेअर होतात, आणि शेअर केलेला संभाषण इतिहास चालू करून तुम्ही `ccam next --continue` ने दुसऱ्या खात्यात संभाषण पुढे चालू ठेवू शकता.

तुम्ही आधीच `~/.claude` वापरत असाल, तर ते खाते पुन्हा जोडण्याऐवजी `ccam import` चालवा, किंवा त्याची सेटिंग्ज, MCP सर्व्हर आणि एक्स्टेंशन्स शेअर केलेल्या सेटिंग्जमध्ये कॉपी करण्यासाठी `ccam migrate` चालवा.

## कोणते निवडायचे

दोन खाती आणि काहीही शेअर न करण्यासाठी alias पुरेसा आहे. शेअर केलेल्या सेटिंग्ज आणि MCP सर्व्हर, जास्त खाती, एका नजरेत वापर किंवा संभाषणे पुढे चालू ठेवणे हवे असेल, तेव्हा ccam ही हिशोबाची कामे वाचवते. [तुलना](/compare/aliases) फरक शेजारी शेजारी दाखवते.
