Claude Code खाती बदलणारी टूल्स दोनपैकी एक पद्धत वापरतात. बहुतेक टूल्स एकाच `~/.claude` फोल्डरमध्ये लॉगिन बदलतात, त्यामुळे एका वेळी एकच खाते सक्रिय असते. इतर टूल्स, ज्यात ccam सुद्धा आहे, `CLAUDE_CONFIG_DIR` ने प्रत्येक खात्याला स्वतःचा फोल्डर देतात, त्यामुळे प्रत्येक खाते लॉगिन राहते आणि अनेक खाती एकाच वेळी चालू शकतात. ccam यात शेअर केलेल्या सेटिंग्ज आणि MCP सर्व्हर जोडते, आणि संभाषण दुसऱ्या खात्याच्या फोल्डरमध्ये पुढे चालू ठेवते.

## एकच लॉगिन बदलायचे की वेगळे फोल्डर?

**लॉगिन बदलताना** सेटिंग्ज, MCP सर्व्हर आणि इतिहासाचा एकच संच असतो, कारण फोल्डर एकच असतो. खाते बदलणे जलद होते, आणि चालू सत्र नवीन लॉगिन घेऊ शकते. पण एका वेळी एकच खाते सक्रिय असते, सर्व टर्मिनल्स आणि editors साठी एकाच वेळी.

**वेगळे फोल्डर** ही [Claude Code च्या दस्तऐवजात सांगितलेली पद्धत आहे](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts). प्रत्येक खाते लॉगिन राहते, आणि तुम्ही work आणि personal सत्रे शेजारी शेजारी चालवू शकता. याची किंमत म्हणजे, एखादे टूल शेअर करत नसेल तर प्रत्येक फोल्डर स्वतःच्या सेटिंग्ज, MCP सर्व्हर आणि इतिहासासह सुरू होतो.

## टूल्सची तुलना

2026-10-19 रोजी प्रत्येक प्रकल्पाच्या स्वतःच्या दस्तऐवजातून घेतले. "दस्तऐवजात नाही" म्हणजे प्रकल्प त्याबद्दल काही सांगत नाही, वैशिष्ट्य नाही असा अर्थ नाही.

ccswap हा claude-swap चा fork आहे, जो Codex लॉगिनही सांभाळतो. यांपैकी अनेक टूल्स Codex किंवा Gemini सारखे इतर coding agents सुद्धा सांभाळतात.

## ccam कशावर लक्ष देते

- प्रत्येक खाते लॉगिन राहते. खाते बदलल्याने कोणतेही खाते लॉगआउट होत नाही, आणि `ccam work` आणि `ccam personal` दोन टर्मिनल्समध्ये एकाच वेळी चालू शकतात.
- MCP सर्व्हर, `settings.json`, `CLAUDE.md`, agents, skills आणि plugins फोल्डर्समध्ये links द्वारे शेअर होतात, प्रत्येक आयटम आणि प्रत्येक खात्यानुसार. लॉगिन कधीही शेअर होत नाहीत.
- शेअर केलेल्या इतिहासासह एक कमांड, `ccam next --auto --continue`, तेच संभाषण सर्वात जास्त जागा असलेल्या खात्याच्या फोल्डरमध्ये उघडते.
- ccam Claude Code सुरू करते आणि स्वतःची जागा त्याला देते, त्यामुळे background मध्ये काहीही चालत नाही. ते तुमच्या वापरावर लक्ष ठेवत नाही किंवा आपोआप खाते बदलत नाही; कधी बदलायचे ते तुम्ही ठरवता.

## इतर टूल्स जिथे जास्त करतात

- claude-swap, CCS, clauth, CAAM आणि cux, WSL शिवाय Windows वर चालतात. ccam चालत नाही.
- claude-swap, clauth आणि cux एखाद्या खात्याचा वापर ठरावीक पातळी ओलांडला की आपोआप खाते बदलतात. ccam हा निर्णय तुमच्यावर सोडते.
- CCSwitcher, Claude Switcher आणि claude-swap वापर macOS menu bar मध्ये दाखवतात.
- CCS, CAAM, ccswap आणि Claude Switcher, Codex आणि इतर coding agents सुद्धा सांभाळतात.

## कोणते योग्य ठरेल?

तुम्ही एका वेळी एकच खाते वापरत असाल, खाते आपोआप बदलावे असे हवे असेल, किंवा WSL शिवाय Windows वर असाल, तर लॉगिन बदलणारे टूल निवडा. खाती शेजारी शेजारी, एकच शेअर केलेला सेटअप आणि पुढच्या खात्यात तेच संभाषण हवे असेल, तर ccam निवडा. काहीही शेअर करायचे नसेल, तर [साधे शेल aliases](/compare/aliases) पुरेसे आहेत.

अनेक खाती वापरण्याची परवानगी आहे की नाही, हे प्रत्येक खात्याच्या अटींवर अवलंबून आहे. वापरण्यापूर्वी त्या तपासा.
