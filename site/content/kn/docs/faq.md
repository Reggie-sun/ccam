## ccam, Anthropic ನ ಅಧಿಕೃತ ಟೂಲ್ ಆಗಿದೆಯೇ?

ಇಲ್ಲ. ccam ಒಂದು ಅನಧಿಕೃತ ಓಪನ್-ಸೋರ್ಸ್ ಪ್ರಾಜೆಕ್ಟ್. ಇದು Anthropic ಜೊತೆ ಸಂಬಂಧ ಹೊಂದಿಲ್ಲ ಮತ್ತು Anthropic ಇದನ್ನು ಅನುಮೋದಿಸಿಲ್ಲ. ಹಲವು ಖಾತೆಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ರನ್ ಮಾಡಲು Claude Code ದಸ್ತಾವೇಜಿನಲ್ಲಿ ವಿವರಿಸಿರುವ `CLAUDE_CONFIG_DIR` ಸೆಟ್ಟಿಂಗ್ ಅನ್ನು ಇದು ಬಳಸುತ್ತದೆ.

## ನಾನು ಹಲವು Claude Code ಖಾತೆಗಳನ್ನು ಬಳಸಲು ಅನುಮತಿ ಇದೆಯೇ?

ಅದು ಪ್ರತಿ ಖಾತೆಯ ನಿಯಮಗಳನ್ನು, ಮತ್ತು ಕೆಲಸದ ಖಾತೆಗಳಾದರೆ ನಿಮ್ಮ ಸಂಸ್ಥೆಯ ನೀತಿಯನ್ನು ಅವಲಂಬಿಸಿದೆ. ಹಲವು ಖಾತೆಗಳನ್ನು ಬಳಸುವ ಮೊದಲು ಅವುಗಳನ್ನು ಪರಿಶೀಲಿಸಿ. ನಿಮ್ಮ ಬಳಿ ಈಗಾಗಲೇ ಇರುವ ಖಾತೆಗಳ ನಡುವೆ ಬದಲಾಯಿಸುವುದನ್ನು ccam ಸುಲಭಗೊಳಿಸುತ್ತದೆ, ಅಷ್ಟೇ.

## ccam ಬಳಕೆಯ ಮಿತಿಗಳನ್ನು ತಪ್ಪಿಸುತ್ತದೆಯೇ?

ಇಲ್ಲ. ಪ್ರತಿ ಖಾತೆಗೂ ಅದರದೇ ಮಿತಿಗಳು ಇರುತ್ತವೆ. ccam ಅವುಗಳನ್ನು ತೋರಿಸುತ್ತದೆ, ಮತ್ತು ಒಂದು ಖಾತೆಯ ಮಿತಿ ಮುಗಿದಾಗ ನಿಮ್ಮದೇ ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸಲು ಅವಕಾಶ ನೀಡುತ್ತದೆ.

## ಒಂದೇ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಎರಡು Claude Code ಖಾತೆಗಳನ್ನು ಹೇಗೆ ಬಳಸುವುದು?

`CLAUDE_CONFIG_DIR` ಮೂಲಕ ಪ್ರತಿ ಖಾತೆಗೂ ಅದರದೇ ಕಾನ್ಫಿಗರೇಶನ್ ಫೋಲ್ಡರ್ ನೀಡಿ. ccam ಇದನ್ನು ನಿಮಗಾಗಿ ಮಾಡುತ್ತದೆ: ಪ್ರತಿ ಖಾತೆಗೂ `ccam add` ರನ್ ಮಾಡಿ, ನಂತರ `claude1` ಮತ್ತು `claude2` ಮೂಲಕ ಅವುಗಳನ್ನು ಆರಂಭಿಸಿ. ಇದನ್ನು ಕೈಯಾರೆ ಹೇಗೆ ಮಾಡುವುದು ಎಂಬುದನ್ನೂ [ಮಾರ್ಗದರ್ಶಿ](/guides/multiple-claude-code-accounts) ತೋರಿಸುತ್ತದೆ.

## ಸಂಭಾಷಣೆಯನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಹೇಗೆ ಮುಂದುವರಿಸುವುದು?

`ccam share <name> --history on` ಮೂಲಕ ಎರಡು ಖಾತೆಗಳ ನಡುವೆ ಸಂಭಾಷಣೆಯ ಇತಿಹಾಸವನ್ನು ಹಂಚಿಕೊಳ್ಳಿ, ನಂತರ `ccam next --continue` ರನ್ ಮಾಡಿ. Claude Code ಈಗಿನ ಫೋಲ್ಡರ್‌ನ ಇತ್ತೀಚಿನ ಸಂಭಾಷಣೆಯನ್ನು ಮುಂದಿನ ಖಾತೆಯಲ್ಲಿ ತೆರೆಯುತ್ತದೆ.

## ccam ನನ್ನ ಲಾಗಿನ್ ಅನ್ನು ನೋಡುತ್ತದೆಯೇ ಅಥವಾ ಕಳುಹಿಸುತ್ತದೆಯೇ?

ccam ಎಂದಿಗೂ ಲಾಗಿನ್ ಅನ್ನು ನಕಲಿಸುವುದಿಲ್ಲ ಅಥವಾ ಹಂಚಿಕೊಳ್ಳುವುದಿಲ್ಲ. ನೀವು `ccam usage`, `ccam next --auto` ಅಥವಾ `ccam doctor` ರನ್ ಮಾಡಿದಾಗ ಮಾತ್ರ, ಆ ಖಾತೆಯ ಬಳಕೆಯನ್ನು Anthropic ನ ಬಳಕೆಯ ಎಂಡ್‌ಪಾಯಿಂಟ್‌ನಿಂದ ಕೇಳಲು, ಅದು ಖಾತೆಯ ಆಕ್ಸೆಸ್ ಟೋಕನ್ ಅನ್ನು ಓದುತ್ತದೆ. ccam ನಲ್ಲಿ ಯಾವುದೇ ಟೆಲಿಮೆಟ್ರಿ ಇಲ್ಲ ಮತ್ತು ಅದು ಬೇರೆ ಎಲ್ಲಿಗೂ ಏನನ್ನೂ ಕಳುಹಿಸುವುದಿಲ್ಲ.

## ನನ್ನ ಖಾತೆಗಳು ಎಲ್ಲಿ ಸಂಗ್ರಹವಾಗಿವೆ?

`~/.local/share/ccam/profiles/<name>/` ನಲ್ಲಿ, ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಫೋಲ್ಡರ್. macOS ನಲ್ಲಿ, Claude Code ಲಾಗಿನ್ ಅನ್ನು Keychain ನಲ್ಲಿ ಇರಿಸುತ್ತದೆ, ಆ ಫೋಲ್ಡರ್‌ನಿಂದ ಪಡೆದ ಒಂದು ಹೆಸರಿನಡಿ.

## ನನ್ನ ಈಗಿರುವ ~/.claude ಗೆ ಏನಾಗುತ್ತದೆ?

ನೀವು `ccam import` ರನ್ ಮಾಡದ ಹೊರತು ಏನೂ ಆಗುವುದಿಲ್ಲ. Import ಫೋಲ್ಡರ್ ಅನ್ನು ಅದು ಇರುವಲ್ಲೇ ನೋಂದಾಯಿಸುತ್ತದೆ. ಹೀಗಾಗಿ ಸಾಮಾನ್ಯ `claude` ಮತ್ತು `ccam <name>` ಎರಡೂ ಅದೇ ಖಾತೆ ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳನ್ನು ಬಳಸುತ್ತಲೇ ಇರುತ್ತವೆ.

## ccam ಯಾವ ಸಿಸ್ಟಮ್‌ಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine ಮತ್ತು ಇತರವು) ಮತ್ತು macOS. Windows ನಲ್ಲಿ, ಇದನ್ನು WSL ಒಳಗೆ ಬಳಸಿ.

## ಒಂದು MCP ಸರ್ವರ್ ಒಂದೇ ಖಾತೆಯಲ್ಲಿ ಮಾತ್ರ ಏಕೆ ಕಾಣಿಸುತ್ತದೆ?

ಸೆಷನ್‌ನೊಳಗೆ `claude mcp add` ಮೂಲಕ ಸೇರಿಸಿದ ಸರ್ವರ್‌ಗಳು ಆ ಖಾತೆಗೆ ಮಾತ್ರ ಸಂಗ್ರಹವಾಗುತ್ತವೆ. ಮುಂದಿನ ಬಾರಿ ನೀವು ಆ ಖಾತೆಯನ್ನು ಆರಂಭಿಸಿದಾಗ ccam ಇದನ್ನು ನಿಮಗೆ ತಿಳಿಸುತ್ತದೆ; `ccam mcp import <account> <server>` ಮೂಲಕ ಸರ್ವರ್ ಅನ್ನು ಹಂಚಿಕೆಯ ಗುಂಪಿಗೆ ಸ್ಥಳಾಂತರಿಸಿ.

## ccam, Claude Code ಅನ್ನು ನಿಧಾನಗೊಳಿಸುತ್ತದೆಯೇ?

ccam ಮೂಲಕ Claude Code ಆರಂಭಿಸುವುದರಿಂದ ಸುಮಾರು 4 ಮಿಲಿಸೆಕೆಂಡ್ ಹೆಚ್ಚಾಗುತ್ತದೆ. ಇದನ್ನು ಒಂದು ಲ್ಯಾಪ್‌ಟಾಪ್‌ನಲ್ಲಿ `scripts/perf-check.sh` ಬಳಸಿ ಅಳೆಯಲಾಗಿದೆ. ccam ಒಂದು ಚಿಕ್ಕ ಫೈಲ್ ಓದುತ್ತದೆ, ಹಂಚಿಕೊಂಡ ಲಿಂಕ್‌ಗಳನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ ಮತ್ತು ನಂತರ ತನ್ನನ್ನು `claude` ನಿಂದ ಬದಲಾಯಿಸಿಕೊಳ್ಳುತ್ತದೆ. ಹೀಗಾಗಿ ನೀವು ಕೆಲಸ ಮಾಡುತ್ತಿರುವಾಗ ಅದು ರನ್ ಆಗುತ್ತಿರುವುದಿಲ್ಲ.

## ccam ಅನ್ನು ಅನ್‌ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುವುದು ಹೇಗೆ?

`~/.local/bin` ನಿಂದ `ccam` ಮತ್ತು `claude1`… ಲಿಂಕ್‌ಗಳನ್ನು ಅಳಿಸಿ. ನಿಮಗೆ ಖಾತೆಗಳು ಇನ್ನು ಬೇಡವಾದರೆ, ನಂತರ `~/.config/ccam`, `~/.local/share/ccam` ಮತ್ತು `~/.local/state/ccam` ಅನ್ನೂ ಅಳಿಸಿ. [ಇನ್‌ಸ್ಟಾಲ್](/docs/install#uninstall) ನೋಡಿ.
