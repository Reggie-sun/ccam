`ccam usage` ಪ್ರತಿ ಖಾತೆಯು 5 ಗಂಟೆಯ ಮತ್ತು ವಾರದ ಬಳಕೆಯ ಮಿತಿಗಳಲ್ಲಿ ಎಷ್ಟನ್ನು ಬಳಸಿದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ. `ccam next --auto` ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯನ್ನು ತೆರೆಯುತ್ತದೆ, ಮತ್ತು `--continue` ಈಗಿನ ಸಂಭಾಷಣೆಯನ್ನು ಅಲ್ಲಿಗೆ ಕೊಂಡೊಯ್ಯುತ್ತದೆ.

```console
$ ccam usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccam next --auto 로 바로 열기)
```

ಕಾಲಮ್‌ಗಳು ಹೀಗಿವೆ: ಖಾತೆ, 5 ಗಂಟೆಯ ಬಳಕೆ, ಅದು ರೀಸೆಟ್ ಆಗಲು ಉಳಿದ ಸಮಯ, ವಾರದ ಬಳಕೆ, ಅದು ರೀಸೆಟ್ ಆಗಲು ಉಳಿದ ಸಮಯ, ಮತ್ತು ಸಂಖ್ಯೆಗಳು ಎಷ್ಟು ಹಳೆಯವು.

## ಸಂಖ್ಯೆಗಳು ಎಲ್ಲಿಂದ ಬರುತ್ತವೆ

ccam ಪ್ರತಿ ಖಾತೆಯ ಸ್ವಂತ ಲಾಗಿನ್ ಬಳಸಿ, ಎಲ್ಲಾ ಖಾತೆಗಳಿಗಾಗಿ ಒಂದೇ ಸಮಯದಲ್ಲಿ Anthropic ನ ಬಳಕೆಯ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಅನ್ನು ಕೇಳುತ್ತದೆ. ಪ್ರತಿ ಖಾತೆಗೆ ಗರಿಷ್ಠ 3 ಸೆಕೆಂಡ್ ಕಾಯುತ್ತದೆ ಮತ್ತು ಪ್ರತಿ ಖಾತೆಯ ಉತ್ತರ ಬಂದ ತಕ್ಷಣ ಅದನ್ನು ತೋರಿಸುತ್ತದೆ.

ಈ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಸಾರ್ವಜನಿಕವಾಗಿ ದಾಖಲಾಗಿಲ್ಲ ಮತ್ತು ಬದಲಾಗಬಹುದು. ವಿನಂತಿ ವಿಫಲವಾದಾಗ, ccam ಕೊನೆಯದಾಗಿ ತಿಳಿದಿದ್ದ ಸಂಖ್ಯೆಗಳನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಅವುಗಳನ್ನು ಕ್ಯಾಶ್ ಎಂದು ಗುರುತಿಸುತ್ತದೆ. ಉತ್ತರದ ಸ್ವರೂಪ ಬದಲಾಗಿದ್ದರೆ `ccam doctor` ನಿಮಗೆ ತಿಳಿಸುತ್ತದೆ.

60 ಸೆಕೆಂಡ್‌ಗಳಿಗಿಂತ ಕಡಿಮೆ ಸಮಯದ ಹಿಂದೆ ಪಡೆದ ಸಂಖ್ಯೆಗಳನ್ನು ಮತ್ತೆ ಬಳಸಲಾಗುತ್ತದೆ. ಆಯ್ಕೆಗಳು:

| ಆಯ್ಕೆ | ಪರಿಣಾಮ |
| --- | --- |
| `--watch [seconds]` | ನಿರಂತರವಾಗಿ ರಿಫ್ರೆಶ್ ಮಾಡುತ್ತದೆ, ಡೀಫಾಲ್ಟ್ ಆಗಿ ಪ್ರತಿ 60 ಸೆಕೆಂಡ್‌ಗೆ |
| `--json` | ಯಂತ್ರಗಳು ಓದಬಲ್ಲ ಔಟ್‌ಪುಟ್ |
| `-v` | ಮಾಡೆಲ್‌ವಾರು ವಾರದ ಮಿತಿಗಳನ್ನು ಮತ್ತು ಪ್ರತಿ ಸಂಖ್ಯೆ ಎಲ್ಲಿಂದ ಬಂತು ಎಂಬುದನ್ನೂ ತೋರಿಸುತ್ತದೆ |
| `--no-cache` | ಯಾವಾಗಲೂ ಮತ್ತೆ ಕೇಳುತ್ತದೆ |
| `--source cache` | ಎಂದಿಗೂ ಕೇಳುವುದಿಲ್ಲ; ಉಳಿಸಿದ ಸಂಖ್ಯೆಗಳನ್ನು ಮಾತ್ರ ತೋರಿಸುತ್ತದೆ |

## ಅವಧಿ ಮುಗಿದ ಲಾಗಿನ್‌ಗಳು

ಒಂದು ಖಾತೆಯ ಆಕ್ಸೆಸ್ ಟೋಕನ್‌ನ ಅವಧಿ ಮುಗಿದಾಗ, ccam ಅದನ್ನು ನವೀಕರಿಸುವುದಿಲ್ಲ. ಏಕೆಂದರೆ ಅದೇ ಲಾಗಿನ್ ಅನ್ನು ಒಂದು Claude Code ಸೆಷನ್ ಬಳಸುತ್ತಿರುವಾಗ ಅದನ್ನು ನವೀಕರಿಸಿದರೆ, ಆ ಸೆಷನ್ ಸೈನ್ ಔಟ್ ಆಗಬಹುದು. ಖಾತೆಯನ್ನು `ccam <name>` ಮೂಲಕ ಒಮ್ಮೆ ಆರಂಭಿಸಿ; Claude Code ಅದನ್ನು ನವೀಕರಿಸುತ್ತದೆ.

`ccam usage --refresh` ಅವಧಿ ಮುಗಿದ ಟೋಕನ್‌ಗಳನ್ನು ತಾನೇ ನವೀಕರಿಸುತ್ತದೆ, ಆದರೆ ರನ್ ಆಗುತ್ತಿಲ್ಲದ ಖಾತೆಗಳಿಗೆ ಮಾತ್ರ. macOS Keychain ನಲ್ಲಿ ಅಥವಾ ಇಂಪೋರ್ಟ್ ಮಾಡಿದ `~/.claude` ನಲ್ಲಿ ಸಂಗ್ರಹವಾಗಿರುವ ಲಾಗಿನ್‌ಗಳನ್ನು ಅದು ಎಂದಿಗೂ ನವೀಕರಿಸುವುದಿಲ್ಲ.

## ಸ್ಟೇಟಸ್ ಲೈನ್‌ನಲ್ಲಿ ಬಳಕೆ

```sh
ccam statusline install
```

ಆಗ Claude Code ಸ್ಟೇಟಸ್ ಲೈನ್‌ನಲ್ಲಿ ಖಾತೆಯ ಹೆಸರು ಮತ್ತು ಅದರ ಬಳಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ `[work] · Opus · 5h 24% · 7d 41%`. ನೀವು ಈಗಾಗಲೇ ಸ್ಟೇಟಸ್ ಲೈನ್ ಕಮಾಂಡ್ ಹೊಂದಿದ್ದರೆ, ccam ಅದನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ಅದರ ಮುಂದೆ ಖಾತೆಯ ಹೆಸರನ್ನು ಇರಿಸುತ್ತದೆ. ಸ್ಟೇಟಸ್ ಲೈನ್ ತನ್ನ ಸಂಖ್ಯೆಗಳನ್ನೂ ಉಳಿಸುತ್ತದೆ; ಎಂಡ್‌ಪಾಯಿಂಟ್ ಉತ್ತರಿಸದಿದ್ದಾಗ `ccam usage` ಅವುಗಳನ್ನು ಬಳಸುತ್ತದೆ.

## ಬದಲಾಯಿಸುವುದು

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # the next account that shares your conversation history
```

`ccam next` ಲಾಗಿನ್ ಆಗಿರದ ಖಾತೆಗಳನ್ನು ಬಿಟ್ಟುಬಿಡುತ್ತದೆ, ಮತ್ತು `--auto` 100% ತಲುಪಿರುವ ಖಾತೆಗಳನ್ನು ಬಿಟ್ಟುಬಿಡುತ್ತದೆ. ಸಂಭಾಷಣೆಯನ್ನು ಮುಂದುವರಿಸಲು, ಎರಡೂ ಖಾತೆಗಳು ಸಂಭಾಷಣೆಯ ಇತಿಹಾಸವನ್ನು ಹಂಚಿಕೊಳ್ಳಬೇಕು; [ಹಂಚಿಕೆ](/docs/sharing) ನೋಡಿ.

[ಬಳಕೆಯ ಮಿತಿಯ ಕಾರ್ಯವಿಧಾನ ಮಾರ್ಗದರ್ಶಿ](/guides/usage-limit-workflow) ಒಂದು ಸಂಪೂರ್ಣ ಉದಾಹರಣೆಯನ್ನು ಹಂತ ಹಂತವಾಗಿ ತೋರಿಸುತ್ತದೆ.
