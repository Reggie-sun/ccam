`ccam usage` ಪ್ರತಿ ಖಾತೆಗೂ, ಪ್ರತಿ ಮಿತಿಯಲ್ಲಿ ಎಷ್ಟು ಬಳಕೆಯಾಗಿದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ: 5 ಗಂಟೆಯ ಮಿತಿ, ವಾರದ ಮಿತಿ ಮತ್ತು ಪ್ರತಿ ಮಾಡೆಲ್‌ನ ಸ್ವಂತ ವಾರದ ಮಿತಿ (ಉದಾಹರಣೆಗೆ Fable). `ccam next --auto` ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯನ್ನು ತೆರೆಯುತ್ತದೆ, ಮತ್ತು `--continue` ಈಗಿನ ಸಂಭಾಷಣೆಯನ್ನು ಅಲ್ಲಿಗೆ ಕೊಂಡೊಯ್ಯುತ್ತದೆ.

ಪ್ರತಿ ಖಾತೆಗೆ ಅದರ ಸಂಖ್ಯೆಗಳು ಎಷ್ಟು ಹಳೆಯವು ಎಂದು ತೋರಿಸುವ ಒಂದು ಸಾಲು ಇರುತ್ತದೆ, ನಂತರ ಪ್ರತಿ ಮಿತಿಗೆ ಒಂದು ಬಾರ್ ಮತ್ತು ಅದು ರೀಸೆಟ್ ಆಗಲು ಉಳಿದ ಸಮಯ: 5 ಗಂಟೆಯ ಅವಧಿ, ಎಲ್ಲಾ ಮಾಡೆಲ್‌ಗಳ ವಾರದ ಅವಧಿ, ಮತ್ತು ಪ್ರತಿ ಮಾಡೆಲ್‌ನ ಸ್ವಂತ ವಾರದ ಅವಧಿ, ಉದಾಹರಣೆಗೆ Fable. ಬಾರ್ 80% ನಲ್ಲಿ ಹಳದಿ ಮತ್ತು 100% ನಲ್ಲಿ ಕೆಂಪು ಆಗುತ್ತದೆ. ಕೊನೆಯ ಸಾಲು `ccam next --auto` ತೆರೆಯುವ ಖಾತೆಯನ್ನು ಹೆಸರಿಸುತ್ತದೆ; `auto_strategy = "expiring"` ಅಥವಾ `"balance"` ಇದ್ದರೆ, ಬದಲಿಗೆ ಅದು `→ next --auto picks <name>: <reason>` ಎಂದು ಇರುತ್ತದೆ.

**Team ಮತ್ತು Enterprise ಸೀಟುಗಳು.** ಸ್ವಯಂಚಾಲಿತ ಖಾತೆ ಆಯ್ಕೆ (`ccam next`, `--fallback`, `ccam pick`, ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನ `n` ಮತ್ತು, ನೀವು ಆನ್ ಮಾಡಿದ ನಂತರ, [`auto_switch`](/features/next#auto-switch)) ಒಂದೇ Claude Team ಅಥವಾ Enterprise ಸಂಸ್ಥೆಯ ಸೀಟುಗಳ ನಡುವೆಯೂ ಬದಲಾಯಿಸುತ್ತದೆ, ಇದು Anthropic ನ ನಿಯಮಗಳನ್ನು ಉಲ್ಲಂಘಿಸಬಹುದು. ಇದನ್ನು ಅವಲಂಬಿಸುವ ಮೊದಲು [ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳನ್ನು](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) ಓದಿ ಮತ್ತು ನಿಮ್ಮ ಸಂಸ್ಥೆ ಹಾಗೂ Anthropic ಬಳಿ ವಿಚಾರಿಸಿ.

## ಸಂಖ್ಯೆಗಳು ಎಲ್ಲಿಂದ ಬರುತ್ತವೆ

ccam ಪ್ರತಿ ಖಾತೆಯ ಸ್ವಂತ ಲಾಗಿನ್ ಬಳಸಿ, ಎಲ್ಲಾ ಖಾತೆಗಳಿಗಾಗಿ ಒಂದೇ ಸಮಯದಲ್ಲಿ Anthropic ನ ಬಳಕೆಯ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಅನ್ನು ಕೇಳುತ್ತದೆ. ಪ್ರತಿ ಖಾತೆಗೆ ಗರಿಷ್ಠ 3 ಸೆಕೆಂಡ್ ಕಾಯುತ್ತದೆ ಮತ್ತು ಪ್ರತಿ ಖಾತೆಯ ಉತ್ತರ ಬಂದ ತಕ್ಷಣ ಅದನ್ನು ತೋರಿಸುತ್ತದೆ.

ಈ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಸಾರ್ವಜನಿಕವಾಗಿ ದಾಖಲಾಗಿಲ್ಲ ಮತ್ತು ಬದಲಾಗಬಹುದು. ವಿನಂತಿ ವಿಫಲವಾದಾಗ, ccam ಕೊನೆಯದಾಗಿ ತಿಳಿದಿದ್ದ ಸಂಖ್ಯೆಗಳನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಅವುಗಳನ್ನು ಕ್ಯಾಶ್ ಎಂದು ಗುರುತಿಸುತ್ತದೆ. ಆ ಸಂಖ್ಯೆಗಳನ್ನು ಉಳಿಸಿದ ನಂತರ ರೀಸೆಟ್ ಆಗಿರುವ ಅವಧಿಯು 0% ತೋರಿಸುತ್ತದೆ. ಉತ್ತರದ ಸ್ವರೂಪ ಬದಲಾಗಿದ್ದರೆ `ccam doctor` ನಿಮಗೆ ತಿಳಿಸುತ್ತದೆ.

Claude Code ಒಂದು ಸೆಷನ್ ಅನ್ನು ಬಳಕೆಯ ಮಿತಿಯಲ್ಲಿ ನಿಲ್ಲಿಸಿದಾಗ, [ccam ಪ್ಲಗಿನ್](/docs/install#claude-code-plugin) ಯಾವ ಅವಧಿ ತುಂಬಿತ್ತು ಮತ್ತು ಅದು ಯಾವಾಗ ರೀಸೆಟ್ ಆಗುತ್ತದೆ ಎಂಬುದನ್ನು ದಾಖಲಿಸುತ್ತದೆ. ಅಲ್ಲಿಯವರೆಗೆ, ಇತರ ಸಂಖ್ಯೆಗಳು ಏನೇ ಹೇಳಿದರೂ ಆ ಅವಧಿ 100% ತೋರಿಸುತ್ತದೆ, ಹೀಗಾಗಿ `ccam next --auto` ಮತ್ತು `--fallback` ಆ ಖಾತೆಯನ್ನು ತೀರಾ ಬೇಗನೆ ಮತ್ತೆ ಆಯ್ಕೆಮಾಡುವುದಿಲ್ಲ.

60 ಸೆಕೆಂಡ್‌ಗಳಿಗಿಂತ ಕಡಿಮೆ ಸಮಯದ ಹಿಂದೆ ಪಡೆದ ಸಂಖ್ಯೆಗಳನ್ನು ಮತ್ತೆ ಬಳಸಲಾಗುತ್ತದೆ. ಆಯ್ಕೆಗಳು:

| ಆಯ್ಕೆ | ಪರಿಣಾಮ |
| --- | --- |
| `--watch[=seconds]` | ನಿರಂತರವಾಗಿ ರಿಫ್ರೆಶ್ ಮಾಡುತ್ತದೆ, ಡೀಫಾಲ್ಟ್ ಆಗಿ ಪ್ರತಿ 60 ಸೆಕೆಂಡ್‌ಗೆ |
| `--json` | ಯಂತ್ರಗಳು ಓದಬಲ್ಲ ಔಟ್‌ಪುಟ್ |
| `-v` | ಪ್ರತಿ ಖಾತೆಯ ಸಂಖ್ಯೆಗಳು ಎಲ್ಲಿಂದ ಬಂದವು ಎಂಬುದನ್ನೂ ತೋರಿಸುತ್ತದೆ |
| `--no-cache` | ಯಾವಾಗಲೂ ಮತ್ತೆ ಕೇಳುತ್ತದೆ |
| `--source cache` | ಎಂದಿಗೂ ಕೇಳುವುದಿಲ್ಲ; ಉಳಿಸಿದ ಸಂಖ್ಯೆಗಳನ್ನು ಮಾತ್ರ ತೋರಿಸುತ್ತದೆ |

## ಅವಧಿ ಮುಗಿದ ಲಾಗಿನ್‌ಗಳು

ಒಂದು ಖಾತೆಯ ಆಕ್ಸೆಸ್ ಟೋಕನ್‌ನ ಅವಧಿ ಮುಗಿದಾಗ, ccam ಅದನ್ನು ನವೀಕರಿಸುವುದಿಲ್ಲ. ಏಕೆಂದರೆ ಅದೇ ಲಾಗಿನ್ ಅನ್ನು ಒಂದು Claude Code ಸೆಷನ್ ಬಳಸುತ್ತಿರುವಾಗ ಅದನ್ನು ನವೀಕರಿಸಿದರೆ, ಆ ಸೆಷನ್ ಸೈನ್ ಔಟ್ ಆಗಬಹುದು. ಖಾತೆಯು ``access token expired; `ccam <name>` renews it when it starts`` ಎಂದು ತೋರಿಸುತ್ತದೆ: ಅದನ್ನು `ccam <name>` ಮೂಲಕ ಒಮ್ಮೆ ಆರಂಭಿಸಿ, Claude Code ಅದನ್ನು ನವೀಕರಿಸುತ್ತದೆ. ಸಂಪೂರ್ಣವಾಗಿ ಅವಧಿ ಮುಗಿದ ಲಾಗಿನ್, ಅಥವಾ Claude Code ತೆರವುಗೊಳಿಸಿದ ಲಾಗಿನ್, `` login expired → `ccam login <name>` `` ಎಂದು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಅದಕ್ಕೆ ಹೊಸ ಲಾಗಿನ್ ಬೇಕು.

`ccam usage --refresh` ಅವಧಿ ಮುಗಿದ ಟೋಕನ್‌ಗಳನ್ನು ತಾನೇ ನವೀಕರಿಸುತ್ತದೆ, ಆದರೆ ಯಾವುದೇ Claude Code ಸೆಷನ್ ರನ್ ಆಗುತ್ತಿಲ್ಲದ ಖಾತೆಗಳಿಗೆ ಮಾತ್ರ (ಆ ಸೆಷನ್ ಅನ್ನು ಹೇಗೆ ಆರಂಭಿಸಿದ್ದರೂ ಸರಿ). macOS Keychain ನಲ್ಲಿ ಅಥವಾ ಇಂಪೋರ್ಟ್ ಮಾಡಿದ `~/.claude` ನಲ್ಲಿ ಸಂಗ್ರಹವಾಗಿರುವ ಲಾಗಿನ್‌ಗಳನ್ನು ಅದು ಎಂದಿಗೂ ನವೀಕರಿಸುವುದಿಲ್ಲ, ಮತ್ತು ಒಂದು ನವೀಕರಣಕ್ಕೆ 30 ಸೆಕೆಂಡ್‌ಗಳವರೆಗೆ ಹಿಡಿಯಬಹುದು.

## ಸ್ಟೇಟಸ್ ಲೈನ್‌ನಲ್ಲಿ ಬಳಕೆ

```sh
ccam statusline install
```

ಆಗ Claude Code ಸ್ಟೇಟಸ್ ಲೈನ್‌ನಲ್ಲಿ ಖಾತೆಯ ಹೆಸರು ಮತ್ತು ಅದರ ಬಳಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ `[work] · Opus · 5h 24% · 7d 41%`. 90% ನಿಂದ ಮುಂದೆ, ಈ ಸಾಲು `ccam next --auto --continue` ಅನ್ನೂ ಸೂಚಿಸುತ್ತದೆ. ನೀವು ಈಗಾಗಲೇ ಸ್ಟೇಟಸ್ ಲೈನ್ ಕಮಾಂಡ್ ಹೊಂದಿದ್ದರೆ, ccam ಅದನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ಅದರ ಮುಂದೆ ಖಾತೆಯ ಹೆಸರನ್ನು ಇರಿಸುತ್ತದೆ. ಸ್ಟೇಟಸ್ ಲೈನ್ ತನ್ನ ಸಂಖ್ಯೆಗಳನ್ನೂ ಉಳಿಸುತ್ತದೆ; ಎಂಡ್‌ಪಾಯಿಂಟ್ ಉತ್ತರಿಸದಿದ್ದಾಗ `ccam usage` ಅವುಗಳನ್ನು ಬಳಸುತ್ತದೆ.

## ಬದಲಾಯಿಸುವುದು

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # continue this folder's conversation on the next account
```

`ccam next` ಲಾಗಿನ್ ಆಗಿರದ ಖಾತೆಗಳನ್ನು ಬಿಟ್ಟುಬಿಡುತ್ತದೆ, ಮತ್ತು `--auto` 100% ತಲುಪಿರುವ ಖಾತೆಗಳನ್ನು (Claude Code ತುಂಬಿದೆ ಎಂದು ವರದಿ ಮಾಡಿದ ಅವಧಿಯೂ ಸೇರಿದಂತೆ, ಅದರ ರೀಸೆಟ್‌ವರೆಗೆ) ಹಾಗೂ ಬೇರೆ ಸಂಸ್ಥೆಯ ಖಾತೆಗಳನ್ನು ಬಿಟ್ಟುಬಿಡುತ್ತದೆ. ಎರಡು ಖಾತೆಗಳು ಸಂಭಾಷಣೆಯ ಇತಿಹಾಸವನ್ನು ಹಂಚಿಕೊಂಡಿದ್ದರೆ, `--continue` ಅದೇ ಸಂಭಾಷಣೆಯನ್ನು ತೆರೆಯುತ್ತದೆ; ಇಲ್ಲದಿದ್ದರೆ Claude Code ಅದನ್ನು ಹೊಸ ಖಾತೆಗೆ ನಕಲಿಸುತ್ತದೆ. [ಹಂಚಿಕೆ](/docs/sharing) ಮತ್ತು [ಮುಂದಿನ ಖಾತೆಗೆ ಬದಲಾಯಿಸುವುದು](/features/next#continue) ನೋಡಿ.

`config.toml` ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ `auto_switch = true` ಇದ್ದರೆ (Linux ಮತ್ತು macOS; ಡೀಫಾಲ್ಟ್ ಆಗಿ ಆಫ್), Claude Code ಇಂಟರ್‌ಆಕ್ಟಿವ್ ಸೆಷನ್ ಅನ್ನು ಅದರ ಮಿತಿಯಲ್ಲಿ ನಿಲ್ಲಿಸಿದಾಗ ಮತ್ತು ಅದೇ ಬಗೆಯ ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ (ಅದೇ ಸಂಸ್ಥೆಯ ಸೀಟು, ಅಥವಾ ಇನ್ನೊಂದು ವೈಯಕ್ತಿಕ ಪ್ಲಾನ್) ಅವಕಾಶ ಇದ್ದಾಗ, ccam ಈ ಬದಲಾವಣೆಯನ್ನು ತಾನೇ ಮಾಡುತ್ತದೆ. ಅದು ಯಾವಾಗ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ ಮತ್ತು ಏನನ್ನು ಎಂದಿಗೂ ಮಾಡುವುದಿಲ್ಲ ಎಂಬುದಕ್ಕೆ [`auto_switch`](/features/next#auto-switch) ನೋಡಿ.

`claude -p` ರನ್ ಮಾಡುವ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು ಮತ್ತು ನಿಗದಿತ ಕೆಲಸಗಳಿಗಾಗಿ, ಖಾತೆಯ ಹೆಸರಿನ ಮುಂದೆ `--fallback` ಹಾಕಿ. ಆ ಖಾತೆ ತನ್ನ ಮಿತಿ ತಲುಪಿದಾಗ, ccam ಅದೇ ಕಮಾಂಡ್ ಅನ್ನು ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯಾಗಿ ಮತ್ತೆ ರನ್ ಮಾಡುತ್ತದೆ, ಮತ್ತು ಪೂರ್ಣಗೊಂಡ ರನ್‌ನ ಔಟ್‌ಪುಟ್ ಮಾತ್ರ ಮುದ್ರಿತವಾಗುತ್ತದೆ:

```sh
ccam --fallback work -p "review the diff" --output-format json
```

ccam ಹೇಗೆ ನಿರ್ಧರಿಸುತ್ತದೆ ಎಂಬುದಕ್ಕೆ [ಮಿತಿಯಲ್ಲಿ ಮತ್ತೆ ರನ್ ಮಾಡುವುದು](/features/next#run-again-at-the-limit) ನೋಡಿ.

[ಬಳಕೆಯ ಮಿತಿಯ ಕಾರ್ಯವಿಧಾನ ಮಾರ್ಗದರ್ಶಿ](/guides/usage-limit-workflow) ಒಂದು ಸಂಪೂರ್ಣ ಉದಾಹರಣೆಯನ್ನು ಹಂತ ಹಂತವಾಗಿ ತೋರಿಸುತ್ತದೆ.
