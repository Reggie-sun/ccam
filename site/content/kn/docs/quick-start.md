ಪ್ರತಿ ಖಾತೆಯನ್ನು `ccam add` ಮೂಲಕ ಸೇರಿಸಿ, ನಂತರ `claude1`, `claude2` ಅಥವಾ `ccs <name>` ಮೂಲಕ Claude Code ಆರಂಭಿಸಿ. ಹೆಚ್ಚಿನವರಿಗೆ ಬೇಕಾಗಿರುವುದು ಇಷ್ಟೇ.

## 1. ನಿಮ್ಮ ಮೊದಲ ಖಾತೆಯನ್ನು ಸೇರಿಸಿ

```sh
ccam add
```

ವಿಜಾರ್ಡ್ `personal` ಅಥವಾ `work` ನಂತಹ ಒಂದು ಹೆಸರನ್ನು ಕೇಳುತ್ತದೆ, ಮತ್ತು ಈ ಖಾತೆ ನಿಮ್ಮ ಇತರ ಖಾತೆಗಳೊಂದಿಗೆ ಯಾವ ಐಟಂಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳಬೇಕು ಎಂದು ಕೇಳುತ್ತದೆ. ನಂತರ ಅದು `claude auth login` ರನ್ ಮಾಡುತ್ತದೆ. ಇದು ಬ್ರೌಸರ್ ತೆರೆಯುತ್ತದೆ, ಅಲ್ಲಿ ನೀವು ಸೈನ್ ಇನ್ ಮಾಡಬಹುದು. ಮುಗಿದಾಗ ನಿಮಗೆ ಇದು ಕಾಣುತ್ತದೆ:

```console
✓ personal (me@example.com) 추가됨 — 단축 명령: claude1
```

ಸದ್ಯಕ್ಕೆ ccam ತನ್ನ ಸಂದೇಶಗಳನ್ನು ಕೊರಿಯನ್ ಭಾಷೆಯಲ್ಲಿ ಮುದ್ರಿಸುತ್ತದೆ; ಕಮಾಂಡ್‌ಗಳು ಮತ್ತು ಆಯ್ಕೆಗಳು ಎಲ್ಲಾ ಭಾಷೆಗಳಲ್ಲೂ ಒಂದೇ.

## 2. ಎರಡನೇ ಖಾತೆಯನ್ನು ಸೇರಿಸಿ

```sh
ccam add work
```

ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಇನ್ನೊಂದು ಖಾತೆಯಿಂದ ಸೈನ್ ಇನ್ ಮಾಡಿ. ಅದು `claude2` ಆಗುತ್ತದೆ.

## 3. ಬದಲಾಯಿಸಿ

ಇವುಗಳಲ್ಲಿ ಯಾವುದಾದರೂ ಒಂದು Claude Code ಅನ್ನು work ಖಾತೆಯಾಗಿ ಆರಂಭಿಸುತ್ತದೆ:

```sh
claude2
ccs work
ccs 2
```

ಖಾತೆಯ ಹೆಸರಿನ ನಂತರದ ಎಲ್ಲವೂ ಯಾವುದೇ ಬದಲಾವಣೆ ಇಲ್ಲದೆ Claude Code ಗೆ ಹೋಗುತ್ತದೆ. ಹೀಗಾಗಿ ನಿಮಗೆ ಗೊತ್ತಿರುವ ಆಯ್ಕೆಗಳನ್ನೇ ಬಳಸುತ್ತಿರಬಹುದು:

```sh
ccs work --resume
ccs work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

`ccs` ಅನ್ನು ಮಾತ್ರ ರನ್ ಮಾಡಿದರೆ ಒಂದು ಆಯ್ಕೆ ಪಟ್ಟಿ ತೆರೆಯುತ್ತದೆ: ಬಾಣದ ಕೀಲಿಗಳು ಮತ್ತು Enter ಬಳಸಿ, ಅಥವಾ ಖಾತೆಯ ಸಂಖ್ಯೆಯನ್ನು ಒತ್ತಿ.

## 4. ಏನನ್ನು ಹಂಚಿಕೊಳ್ಳಬೇಕು ಎಂದು ಆಯ್ಕೆಮಾಡಿ

ಡೀಫಾಲ್ಟ್ ಆಗಿ MCP ಸರ್ವರ್‌ಗಳು, `settings.json`, ಜಾಗತಿಕ `CLAUDE.md`, ಹಾಗೂ agents, commands, skills ಮತ್ತು plugins ಖಾತೆಗಳ ನಡುವೆ ಹಂಚಿಕೆಯಾಗುತ್ತವೆ. ಸಂಭಾಷಣೆಯ ಇತಿಹಾಸ ಹಂಚಿಕೆಯಾಗುವುದಿಲ್ಲ. ಖಾತೆಗಳ ನಡುವೆ ಸಂಭಾಷಣೆಗಳನ್ನು ಮುಂದುವರಿಸಬೇಕಿದ್ದರೆ, ಎರಡೂ ಖಾತೆಗಳಿಗೆ ಅದನ್ನು ಆನ್ ಮಾಡಿ:

```sh
ccam share personal --history on
ccam share work --history on
```

ಯಾವುದನ್ನಾದರೂ ಬದಲಾಯಿಸುವ ಮೊದಲು, ccam ತಾನು ಏನನ್ನು ಸ್ಥಳಾಂತರಿಸಲಿದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ. ವಿವರಗಳಿಗೆ [ಹಂಚಿಕೆ](/docs/sharing) ನೋಡಿ.

## 5. ಖಾತೆ ತನ್ನ ಮಿತಿ ತಲುಪಿದಾಗ

```sh
ccs usage
ccs next --continue
```

`ccs usage` ಎಲ್ಲಾ ಖಾತೆಗಳ 5 ಗಂಟೆಯ ಮತ್ತು ವಾರದ ಬಳಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ. `ccs next --continue` ಅದೇ ಸಂಭಾಷಣೆಯನ್ನು ಮುಂದಿನ ಖಾತೆಯಲ್ಲಿ ತೆರೆಯುತ್ತದೆ. [ಬಳಕೆಯ ಮಿತಿಗಳು](/docs/usage-limits) ನೋಡಿ.

## ಈಗಾಗಲೇ ~/.claude ಬಳಸುತ್ತಿದ್ದೀರಾ?

ಮತ್ತೆ ಸೈನ್ ಇನ್ ಮಾಡುವ ಬದಲು ಅದನ್ನು ನೋಂದಾಯಿಸಿ:

```sh
ccam import
```

ಫೋಲ್ಡರ್ ಇದ್ದಲ್ಲೇ ಉಳಿಯುತ್ತದೆ, ಮತ್ತು ಸಾಮಾನ್ಯ `claude` ಮೊದಲಿನಂತೆಯೇ ಕೆಲಸ ಮಾಡುತ್ತದೆ.
