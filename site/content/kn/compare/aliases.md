ಹಲವು Claude Code ಖಾತೆಗಳನ್ನು ರನ್ ಮಾಡಲು ಅತ್ಯಂತ ಸರಳ ವಿಧಾನವೆಂದರೆ ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಶೆಲ್ ಅಲಿಯಾಸ್. ccam ಒಳಗೆ ಇದನ್ನೇ ಮಾಡುತ್ತದೆ, ಮತ್ತು ಹಂಚಿಕೆ, ಖಾತೆ ಬದಲಾವಣೆ ಹಾಗೂ ಬಳಕೆಯ ಮೇಲ್ವಿಚಾರಣೆಯನ್ನು ಸೇರಿಸುತ್ತದೆ.

| | ಶೆಲ್ ಅಲಿಯಾಸ್ | ccam |
| --- | --- | --- |
| ಪ್ರತ್ಯೇಕ ಲಾಗಿನ್‌ಗಳು | ಹೌದು | ಹೌದು |
| ಪ್ರತಿ ಖಾತೆಯ ಸೆಟಪ್ | `~/.bashrc` ಸಂಪಾದಿಸಿ, ಲಾಗಿನ್ ಮಾಡಿ | `ccam add` |
| ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು ಮತ್ತು ಇತರ ಪ್ರೋಗ್ರಾಂಗಳಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ | ಇಲ್ಲ, ಅಲಿಯಾಸ್‌ಗಳು ಶೆಲ್‌ನಲ್ಲಿ ಮಾತ್ರ | ಹೌದು, `claude2` ಒಂದು ನಿಜವಾದ ಕಮಾಂಡ್ |
| ಹಂಚಿಕೊಂಡ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, `CLAUDE.md`, ವಿಸ್ತರಣೆಗಳು | ಕೈಯಾರೆ ನಕಲಿಸಿ ಅಥವಾ ಲಿಂಕ್ ಮಾಡಿ | ಐಟಂವಾರು, ಬ್ಯಾಕಪ್‌ಗಳೊಂದಿಗೆ |
| ಹಂಚಿಕೊಂಡ MCP ಸರ್ವರ್‌ಗಳು | ಕೈಯಾರೆ, ಪ್ರತಿ ಖಾತೆಗೂ | ಒಮ್ಮೆ `ccam mcp add` |
| ಸಂಭಾಷಣೆಯನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸುವುದು | ಇಲ್ಲ | `ccs next --continue` |
| ಎಲ್ಲಾ ಖಾತೆಗಳ ಬಳಕೆ | ಇಲ್ಲ | `ccs usage` |
| ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯ ಆಯ್ಕೆ | ಇಲ್ಲ | `ccs next --auto` |
| ಸ್ಟೇಟಸ್ ಲೈನ್‌ನಲ್ಲಿ ಖಾತೆಯ ಹೆಸರು | ಇಲ್ಲ | `ccam statusline install` |
| ಮುರಿದ ಲಿಂಕ್‌ಗಳ ದುರಸ್ತಿ | ಕೈಯಾರೆ | `ccam doctor --fix` |
| ಹೆಚ್ಚುವರಿ ಸಾಫ್ಟ್‌ವೇರ್ | ಏನೂ ಇಲ್ಲ | ಒಂದು ಸ್ಟ್ಯಾಟಿಕ್ ಬೈನರಿ |

ನಿಮ್ಮ ಬಳಿ ಎರಡು ಖಾತೆಗಳಿದ್ದು ಅವುಗಳ ನಡುವೆ ಏನನ್ನೂ ಹಂಚಿಕೊಳ್ಳಬೇಕಿಲ್ಲದಿದ್ದರೆ ಅಲಿಯಾಸ್‌ಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ. ಖಾತೆಗಳು ಒಂದೇ ಸೆಟಪ್‌ನಂತೆ ಅನಿಸಬೇಕಿದ್ದರೆ ccam ಆಯ್ಕೆಮಾಡಿ. ನೀವು ಅಲಿಯಾಸ್‌ಗಳಿಂದ ಆರಂಭಿಸಿ ನಂತರ ccam ಗೆ ಬದಲಾಯಿಸಬಹುದು: `ccam import` ಈಗಿರುವ `~/.claude-*` ಫೋಲ್ಡರ್‌ಗಳನ್ನು ಅವು ಇರುವಲ್ಲೇ ನೋಂದಾಯಿಸುತ್ತದೆ.

[ಒಂದೇ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಎರಡು ಖಾತೆಗಳನ್ನು ಬಳಸುವುದು ಹೇಗೆ](/guides/multiple-claude-code-accounts) ಎರಡೂ ವಿಧಾನಗಳನ್ನು ಹಂತ ಹಂತವಾಗಿ ವಿವರಿಸುತ್ತದೆ.
