ಹಲವು Claude Code ಖಾತೆಗಳನ್ನು ರನ್ ಮಾಡಲು ಅತ್ಯಂತ ಸರಳ ವಿಧಾನವೆಂದರೆ ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಶೆಲ್ ಅಲಿಯಾಸ್. ccam ಒಳಗೆ ಇದನ್ನೇ ಮಾಡುತ್ತದೆ, ಮತ್ತು ಹಂಚಿಕೆ, ಖಾತೆ ಬದಲಾವಣೆ ಹಾಗೂ ಬಳಕೆಯ ಮೇಲ್ವಿಚಾರಣೆಯನ್ನು ಸೇರಿಸುತ್ತದೆ.

## ಅಲಿಯಾಸ್ ಸೆಟಪ್

ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಖಾತೆಗೆ `~/.bashrc` ಅಥವಾ `~/.zshrc` ಗೆ ಒಂದು ಸಾಲು ಸೇರಿಸಿ, ಹೊಸ ಟರ್ಮಿನಲ್ ತೆರೆಯಿರಿ ಮತ್ತು ಲಾಗಿನ್ ಮಾಡಲು ಅಲಿಯಾಸ್ ಅನ್ನು ಒಮ್ಮೆ ರನ್ ಮಾಡಿ:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

`claude` ನಿಮ್ಮ ಮೊದಲ ಖಾತೆಯಾಗಿಯೇ ಉಳಿಯುತ್ತದೆ ಮತ್ತು `claude-work` ಎರಡನೆಯ ಖಾತೆಯನ್ನು ಆರಂಭಿಸುತ್ತದೆ. ಇದು [Claude Code ದಸ್ತಾವೇಜು ವಿವರಿಸುವ](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) ವಿಧಾನವೇ ಆಗಿದೆ.

## ccam ಸೆಟಪ್

ccam ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ ಮತ್ತು ಖಾತೆಯನ್ನು ಸೇರಿಸಿ, ಇಲ್ಲಿ ಅದರದೇ ಆದ ಶಾರ್ಟ್‌ಕಟ್ ಕಮಾಂಡ್ ಜೊತೆಗೆ:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add work --shortcut ccwork
```

`ccam work` ಮತ್ತು `ccwork` ಖಾತೆಯನ್ನು ಆರಂಭಿಸುತ್ತವೆ, ಮತ್ತು ಎರಡೂ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳಲ್ಲೂ ಕೆಲಸ ಮಾಡುತ್ತವೆ.

## ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ

| | ಶೆಲ್ ಅಲಿಯಾಸ್ | ccam |
| --- | --- | --- |
| ಪ್ರತ್ಯೇಕ ಲಾಗಿನ್‌ಗಳು | ಹೌದು | ಹೌದು |
| ಪ್ರತಿ ಖಾತೆಯ ಸೆಟಪ್ | `~/.bashrc` ಸಂಪಾದಿಸಿ, ಲಾಗಿನ್ ಮಾಡಿ | `ccam add` |
| ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು ಮತ್ತು ಇತರ ಪ್ರೋಗ್ರಾಂಗಳಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ | ಇಲ್ಲ, ಅಲಿಯಾಸ್‌ಗಳು ಶೆಲ್‌ನಲ್ಲಿ ಮಾತ್ರ | ಹೌದು, `ccam work` ಮತ್ತು `ccwork` ನಂತಹ ಶಾರ್ಟ್‌ಕಟ್‌ಗಳು ನಿಜವಾದ ಕಮಾಂಡ್‌ಗಳು |
| ಹಂಚಿಕೊಂಡ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, `CLAUDE.md`, ವಿಸ್ತರಣೆಗಳು | ಕೈಯಾರೆ ನಕಲಿಸಿ ಅಥವಾ ಲಿಂಕ್ ಮಾಡಿ | ಹೌದು, ಐಟಂವಾರು ಆಯ್ಕೆ, ಬ್ಯಾಕಪ್‌ಗಳೊಂದಿಗೆ |
| ಹಂಚಿಕೊಂಡ MCP ಸರ್ವರ್‌ಗಳು | ಕೈಯಾರೆ, ಪ್ರತಿ ಖಾತೆಗೂ | ಒಮ್ಮೆ `ccam mcp add` |
| ಸಂಭಾಷಣೆಯನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸುವುದು | ಇಲ್ಲ | `ccam next --continue` |
| ಎಲ್ಲಾ ಖಾತೆಗಳ ಬಳಕೆ | ಇಲ್ಲ | `ccam usage` |
| ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯ ಆಯ್ಕೆ | ಇಲ್ಲ | `ccam next --auto` |
| ಮಿತಿಯಲ್ಲಿ `-p` ಕೆಲಸವನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಾಗಿ ಮತ್ತೆ ರನ್ ಮಾಡುವುದು | ಇಲ್ಲ | `ccam --fallback` |
| ಪ್ರತಿ ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ಗೆ ಒಂದು ಖಾತೆ | ಇಲ್ಲ | `ccam folder` |
| ಸ್ಟೇಟಸ್ ಲೈನ್‌ನಲ್ಲಿ ಖಾತೆಯ ಹೆಸರು | ಇಲ್ಲ | `ccam statusline install` |
| ಮುರಿದ ಲಿಂಕ್‌ಗಳ ದುರಸ್ತಿ | ಕೈಯಾರೆ | `ccam doctor --fix` |
| ಹೆಚ್ಚುವರಿ ಸಾಫ್ಟ್‌ವೇರ್ | ಏನೂ ಇಲ್ಲ | ಒಂದು ಸ್ಟ್ಯಾಟಿಕ್ ಬೈನರಿ |

ನಿಮ್ಮ ಬಳಿ ಎರಡು ಖಾತೆಗಳಿದ್ದು ಅವುಗಳ ನಡುವೆ ಏನನ್ನೂ ಹಂಚಿಕೊಳ್ಳಬೇಕಿಲ್ಲದಿದ್ದರೆ ಅಲಿಯಾಸ್‌ಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ. ಖಾತೆಗಳು ಒಂದೇ ಸೆಟಪ್‌ನಂತೆ ಅನಿಸಬೇಕಿದ್ದರೆ ccam ಆಯ್ಕೆಮಾಡಿ. ನೀವು ಅಲಿಯಾಸ್‌ಗಳಿಂದ ಆರಂಭಿಸಿ ನಂತರ ccam ಗೆ ಬದಲಾಯಿಸಬಹುದು: `ccam import` ಈಗಿರುವ `~/.claude-*` ಫೋಲ್ಡರ್‌ಗಳನ್ನು ಅವು ಇರುವಲ್ಲೇ ನೋಂದಾಯಿಸುತ್ತದೆ.

[ಒಂದೇ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಹಲವು ಖಾತೆಗಳನ್ನು ಬಳಸುವುದು ಹೇಗೆ](/guides/multiple-claude-code-accounts) ಎರಡೂ ವಿಧಾನಗಳನ್ನು ಹಂತ ಹಂತವಾಗಿ ವಿವರಿಸುತ್ತದೆ, ಮತ್ತು [ccam ಮತ್ತು ಇತರ ಖಾತೆ ಸ್ವಿಚರ್‌ಗಳು](/compare/account-switchers) ಒಂದೇ ಲಾಗಿನ್ ಬದಲಾಯಿಸುವ ಟೂಲ್‌ಗಳೊಂದಿಗೆ ccam ಅನ್ನು ಹೋಲಿಸುತ್ತದೆ.
