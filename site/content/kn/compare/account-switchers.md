Claude Code ಖಾತೆ ಬದಲಾಯಿಸುವ ಟೂಲ್‌ಗಳು ಎರಡರಲ್ಲಿ ಒಂದು ವಿಧಾನ ಅನುಸರಿಸುತ್ತವೆ. ಹೆಚ್ಚಿನವು ಒಂದೇ `~/.claude` ಫೋಲ್ಡರ್‌ನೊಳಗೆ ಲಾಗಿನ್ ಅನ್ನು ಬದಲಾಯಿಸುತ್ತವೆ, ಆದ್ದರಿಂದ ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದೇ ಖಾತೆ ಸಕ್ರಿಯವಾಗಿರುತ್ತದೆ. ccam ಸೇರಿದಂತೆ ಇತರವು `CLAUDE_CONFIG_DIR` ಮೂಲಕ ಪ್ರತಿ ಖಾತೆಗೂ ಅದರದೇ ಫೋಲ್ಡರ್ ನೀಡುತ್ತವೆ, ಆದ್ದರಿಂದ ಪ್ರತಿ ಖಾತೆಯೂ ಲಾಗಿನ್ ಆಗಿಯೇ ಇರುತ್ತದೆ ಮತ್ತು ಹಲವನ್ನು ಒಮ್ಮೆಗೇ ರನ್ ಮಾಡಬಹುದು. ccam ಹಂಚಿಕೆಯ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು MCP ಸರ್ವರ್‌ಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ, ಮತ್ತು ಸಂಭಾಷಣೆಯನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಮುಂದುವರಿಸುತ್ತದೆ.

## ಒಂದೇ ಲಾಗಿನ್ ಬದಲಾಯಿಸುವುದೇ ಅಥವಾ ಪ್ರತ್ಯೇಕ ಫೋಲ್ಡರ್‌ಗಳೇ?

**ಲಾಗಿನ್ ಬದಲಾಯಿಸುವ ವಿಧಾನದಲ್ಲಿ** ಒಂದೇ ಫೋಲ್ಡರ್ ಇರುವುದರಿಂದ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, MCP ಸರ್ವರ್‌ಗಳು ಮತ್ತು ಇತಿಹಾಸ ಒಂದೇ ಸೆಟ್ ಆಗಿರುತ್ತವೆ. ಬದಲಾವಣೆ ವೇಗವಾಗಿರುತ್ತದೆ, ಮತ್ತು ರನ್ ಆಗುತ್ತಿರುವ ಸೆಷನ್ ಹೊಸ ಲಾಗಿನ್ ಅನ್ನು ಪಡೆದುಕೊಳ್ಳಬಹುದು. ಆದರೆ ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದೇ ಖಾತೆ ಸಕ್ರಿಯವಾಗಿರುತ್ತದೆ, ಎಲ್ಲಾ ಟರ್ಮಿನಲ್‌ಗಳು ಮತ್ತು ಎಡಿಟರ್‌ಗಳಿಗೂ ಒಮ್ಮೆಗೇ.

**ಪ್ರತ್ಯೇಕ ಫೋಲ್ಡರ್‌ಗಳು** [Claude Code ನ ದಸ್ತಾವೇಜು ವಿವರಿಸುವ](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) ವಿಧಾನ. ಪ್ರತಿ ಖಾತೆಯೂ ಲಾಗಿನ್ ಆಗಿಯೇ ಇರುತ್ತದೆ, ಮತ್ತು ಕೆಲಸದ ಹಾಗೂ ವೈಯಕ್ತಿಕ ಸೆಷನ್‌ಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ರನ್ ಮಾಡಬಹುದು. ಇದರ ಬೆಲೆ ಎಂದರೆ, ಯಾವುದಾದರೂ ಟೂಲ್ ಹಂಚದಿದ್ದರೆ, ಪ್ರತಿ ಫೋಲ್ಡರ್ ತನ್ನದೇ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, MCP ಸರ್ವರ್‌ಗಳು ಮತ್ತು ಇತಿಹಾಸದೊಂದಿಗೆ ಆರಂಭವಾಗುತ್ತದೆ.

## ccam ಯಾವುದರ ಮೇಲೆ ಗಮನ ನೀಡುತ್ತದೆ

- ಪ್ರತಿ ಖಾತೆಯೂ ಲಾಗಿನ್ ಆಗಿಯೇ ಇರುತ್ತದೆ. ಬದಲಾಯಿಸುವುದರಿಂದ ಯಾವ ಖಾತೆಯೂ ಲಾಗ್‌ಔಟ್ ಆಗುವುದಿಲ್ಲ, ಮತ್ತು `ccam work` ಹಾಗೂ `ccam personal` ಎರಡು ಟರ್ಮಿನಲ್‌ಗಳಲ್ಲಿ ಒಮ್ಮೆಗೇ ರನ್ ಆಗಬಹುದು.
- MCP ಸರ್ವರ್‌ಗಳು, `settings.json`, `CLAUDE.md`, agents, skills ಮತ್ತು ಪ್ಲಗಿನ್‌ಗಳನ್ನು ಲಿಂಕ್‌ಗಳ ಮೂಲಕ ಫೋಲ್ಡರ್‌ಗಳ ನಡುವೆ ಐಟಂವಾರು ಮತ್ತು ಖಾತೆವಾರು ಹಂಚಲಾಗುತ್ತದೆ. ಲಾಗಿನ್‌ಗಳನ್ನು ಎಂದಿಗೂ ಹಂಚುವುದಿಲ್ಲ.
- ಹಂಚಿಕೆಯ ಇತಿಹಾಸದೊಂದಿಗೆ, ಒಂದೇ ಕಮಾಂಡ್ `ccam next --auto --continue` ಅದೇ ಸಂಭಾಷಣೆಯನ್ನು ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ತೆರೆಯುತ್ತದೆ.
- ccam Claude Code ಅನ್ನು ಆರಂಭಿಸಿ ತನ್ನ ಜಾಗವನ್ನು ಅದಕ್ಕೆ ಬಿಟ್ಟುಕೊಡುತ್ತದೆ, ಆದ್ದರಿಂದ ಹಿನ್ನೆಲೆಯಲ್ಲಿ ಏನೂ ರನ್ ಆಗುವುದಿಲ್ಲ. ಅದು ನಿಮ್ಮ ಬಳಕೆಯನ್ನು ಗಮನಿಸುವುದಿಲ್ಲ ಅಥವಾ ತಾನಾಗಿಯೇ ಬದಲಾಯಿಸುವುದಿಲ್ಲ; ಯಾವಾಗ ಎಂದು ನೀವೇ ನಿರ್ಧರಿಸುತ್ತೀರಿ.

## ಇತರ ಟೂಲ್‌ಗಳು ಎಲ್ಲಿ ಹೆಚ್ಚು ಮಾಡುತ್ತವೆ

- claude-swap, CCS, clauth, CAAM ಮತ್ತು cux, WSL ಇಲ್ಲದೆ Windows ನಲ್ಲಿ ರನ್ ಆಗುತ್ತವೆ. ccam ಆಗುವುದಿಲ್ಲ.
- claude-swap, clauth ಮತ್ತು cux, ಒಂದು ಖಾತೆ ಬಳಕೆಯ ಮಿತಿಯನ್ನು ದಾಟಿದಾಗ ತಾವಾಗಿಯೇ ಬದಲಾಯಿಸುತ್ತವೆ. ccam ಬದಲಾವಣೆಯನ್ನು ನಿಮಗೆ ಬಿಡುತ್ತದೆ.
- CCSwitcher, Claude Switcher ಮತ್ತು claude-swap ಬಳಕೆಯನ್ನು macOS ಮೆನು ಬಾರ್‌ನಲ್ಲಿ ತೋರಿಸುತ್ತವೆ.
- CCS, CAAM, ccswap ಮತ್ತು Claude Switcher, Codex ಮತ್ತು ಇತರ ಕೋಡಿಂಗ್ ಏಜೆಂಟ್‌ಗಳನ್ನೂ ನಿರ್ವಹಿಸುತ್ತವೆ.

## ಯಾವುದು ಸೂಕ್ತ?

ನೀವು ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದೇ ಖಾತೆ ಬಳಸುತ್ತಿದ್ದರೆ, ಬದಲಾವಣೆ ತಾನಾಗಿಯೇ ಆಗಬೇಕಿದ್ದರೆ, ಅಥವಾ WSL ಇಲ್ಲದ Windows ನಲ್ಲಿದ್ದರೆ, ಲಾಗಿನ್ ಬದಲಾಯಿಸುವ ಟೂಲ್ ಆಯ್ಕೆಮಾಡಿ. ಖಾತೆಗಳು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ, ಒಂದೇ ಹಂಚಿಕೆಯ ಸೆಟಪ್ ಮತ್ತು ಮುಂದಿನ ಖಾತೆಯಲ್ಲಿ ಅದೇ ಸಂಭಾಷಣೆ ಬೇಕಿದ್ದರೆ ccam ಆಯ್ಕೆಮಾಡಿ. ಏನನ್ನೂ ಹಂಚಿಕೊಳ್ಳಬೇಕಿಲ್ಲದಿದ್ದರೆ, [ಸಾಮಾನ್ಯ ಶೆಲ್ ಅಲಿಯಾಸ್‌ಗಳು](/compare/aliases) ಸಾಕು.

ನೀವು ಹಲವು ಖಾತೆಗಳನ್ನು ಬಳಸಬಹುದೇ ಎಂಬುದು ಪ್ರತಿ ಖಾತೆಯ ನಿಯಮಗಳನ್ನು ಅವಲಂಬಿಸಿದೆ. ಬಳಸುವ ಮೊದಲು ಅವುಗಳನ್ನು ಪರಿಶೀಲಿಸಿ.
