ಒಂದೇ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಎರಡು Claude Code ಖಾತೆಗಳನ್ನು ಬಳಸಲು, ಪ್ರತಿ ಖಾತೆಗೂ ಅದರದೇ ಕಾನ್ಫಿಗರೇಶನ್ ಫೋಲ್ಡರ್ ನೀಡಿ. Claude Code ಆ ಫೋಲ್ಡರ್ ಅನ್ನು `CLAUDE_CONFIG_DIR` ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ವೇರಿಯೇಬಲ್‌ನಿಂದ ಓದುತ್ತದೆ, ಮತ್ತು ಪ್ರತಿ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಅದರದೇ ಲಾಗಿನ್, ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ಇತಿಹಾಸ ಇರುತ್ತದೆ. ಇದನ್ನು ನೀವು ಶೆಲ್ ಅಲಿಯಾಸ್ ಮೂಲಕ ಕೈಯಾರೆ ಹೊಂದಿಸಬಹುದು, ಅಥವಾ ccam ಗೆ ಬಿಡಬಹುದು.

## ಕೈಯಾರೆ, ಅಲಿಯಾಸ್ ಮೂಲಕ

Claude Code ನ ದಸ್ತಾವೇಜು ವಿವರಿಸುವ ವಿಧಾನ ಇದು. ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಖಾತೆಗೆ `~/.bashrc` ಅಥವಾ `~/.zshrc` ನಲ್ಲಿ ಒಂದು ಸಾಲು ಸೇರಿಸಿ:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

ಹೊಸ ಟರ್ಮಿನಲ್ ತೆರೆದು `claude-work` ರನ್ ಮಾಡಿ. ಫೋಲ್ಡರ್ ಹೊಸದಾಗಿರುವುದರಿಂದ Claude Code ನಿಮ್ಮನ್ನು ಲಾಗಿನ್ ಮಾಡಲು ಕೇಳುತ್ತದೆ. ಅಲ್ಲಿಂದ ಮುಂದೆ, `claude` ನಿಮ್ಮ ಮೊದಲ ಖಾತೆ ಮತ್ತು `claude-work` ಎರಡನೆಯದು.

ಎರಡು ಖಾತೆಗಳಿಗೆ ಇದು ಚೆನ್ನಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ತಿಳಿದಿರಬೇಕಾದ ವಿಷಯಗಳು:

- ಪ್ರತಿ ಫೋಲ್ಡರ್ ಖಾಲಿಯಾಗಿ ಆರಂಭವಾಗುತ್ತದೆ: ಸೆಟ್ಟಿಂಗ್‌ಗಳಿಲ್ಲ, `CLAUDE.md` ಇಲ್ಲ, MCP ಸರ್ವರ್‌ಗಳಿಲ್ಲ, agents ಅಥವಾ skills ಇಲ್ಲ. ನಿಮಗೆ ಬೇಕಾದುದನ್ನು ನೀವೇ ನಕಲಿಸಬೇಕು ಅಥವಾ ಲಿಂಕ್ ಮಾಡಬೇಕು, ಮತ್ತು ಆ ಪ್ರತಿಗಳನ್ನು ನೀವೇ ಹೊಂದಾಣಿಕೆಯಲ್ಲಿಡಬೇಕು.
- ಅಲಿಯಾಸ್‌ಗಳು ಇಂಟರಾಕ್ಟಿವ್ ಶೆಲ್‌ಗಳಲ್ಲಿ ಮಾತ್ರ ಇರುತ್ತವೆ. ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು, Makefile ಗಳು ಮತ್ತು ಇತರ ಪ್ರೋಗ್ರಾಂಗಳಿಗೆ ಅವು ಕಾಣುವುದಿಲ್ಲ.
- MCP ಸರ್ವರ್‌ಗಳು ಲಾಗಿನ್‌ನ ಪಕ್ಕದಲ್ಲೇ `.claude.json` ನಲ್ಲಿ ಇರುತ್ತವೆ. ಆದ್ದರಿಂದ ಅವುಗಳನ್ನು ಫೋಲ್ಡರ್‌ಗಳ ನಡುವೆ ಸುಮ್ಮನೆ ಲಿಂಕ್ ಮಾಡಲು ಸಾಧ್ಯವಿಲ್ಲ.
- ಸಂಭಾಷಣೆಗಳು ಅವು ಆರಂಭವಾದ ಖಾತೆಯಲ್ಲೇ ಉಳಿಯುತ್ತವೆ. ಆದ್ದರಿಂದ ಒಂದು ಸಂಭಾಷಣೆಯನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ.
- ಎಲ್ಲಾ ಖಾತೆಗಳ ಬಳಕೆಯನ್ನು ಒಂದೇ ಬಾರಿಗೆ ತೋರಿಸುವ ಯಾವುದೂ ಇಲ್ಲ.

## ccam ಮೂಲಕ

ccam ಇದೇ ಕಲ್ಪನೆಯನ್ನು ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ಕೊರತೆಯಿರುವ ಭಾಗಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

ಈಗ `ccam personal` ಮತ್ತು `ccam work` ಎರಡು ಖಾತೆಗಳನ್ನು ಆರಂಭಿಸುತ್ತವೆ, ಮತ್ತು work ಖಾತೆಗೆ ನೀವು ನೀಡಿದ ಶಾರ್ಟ್‌ಕಟ್ `ccwork` ಕೂಡ ಹಾಗೆಯೇ ಮಾಡುತ್ತದೆ. ಇವು ಅಲಿಯಾಸ್‌ಗಳಲ್ಲ, ನಿಜವಾದ ಪ್ರೋಗ್ರಾಂಗಳು; ಆದ್ದರಿಂದ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳಲ್ಲೂ ಕೆಲಸ ಮಾಡುತ್ತವೆ. ಸೆಟ್ಟಿಂಗ್‌ಗಳು, `CLAUDE.md`, MCP ಸರ್ವರ್‌ಗಳು ಮತ್ತು ವಿಸ್ತರಣೆಗಳು ಆರಂಭದಿಂದಲೇ ಹಂಚಿಕೆಯಾಗುತ್ತವೆ. ಸಂಭಾಷಣೆಯ ಇತಿಹಾಸದ ಹಂಚಿಕೆಯನ್ನು ಆನ್ ಮಾಡಿದರೆ, `ccam next --continue` ಮೂಲಕ ಒಂದು ಸಂಭಾಷಣೆಯನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸಬಹುದು.

ನೀವು ಈಗಾಗಲೇ `~/.claude` ಬಳಸುತ್ತಿದ್ದರೆ, ಆ ಖಾತೆಯನ್ನು ಮತ್ತೆ ಸೇರಿಸುವ ಬದಲು `ccam import` ರನ್ ಮಾಡಿ, ಅಥವಾ ಅದರ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, MCP ಸರ್ವರ್‌ಗಳು ಮತ್ತು ವಿಸ್ತರಣೆಗಳನ್ನು ಹಂಚಿಕೆಯ ಸೆಟ್ಟಿಂಗ್‌ಗಳಿಗೆ ನಕಲಿಸಲು `ccam migrate` ರನ್ ಮಾಡಿ.

## ಯಾವುದನ್ನು ಆಯ್ಕೆ ಮಾಡಬೇಕು

ಎರಡು ಖಾತೆಗಳಿದ್ದು ಏನನ್ನೂ ಹಂಚಿಕೊಳ್ಳಬೇಕಿಲ್ಲದಿದ್ದರೆ, ಅಲಿಯಾಸ್ ಸಾಕು. ಹಂಚಿಕೊಂಡ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು MCP ಸರ್ವರ್‌ಗಳು, ಹೆಚ್ಚು ಖಾತೆಗಳು, ಒಂದೇ ನೋಟದಲ್ಲಿ ಬಳಕೆ, ಅಥವಾ ಸಂಭಾಷಣೆಗಳನ್ನು ಮುಂದುವರಿಸುವುದು ಬೇಕಿದ್ದರೆ, ccam ಆ ನಿರ್ವಹಣೆಯ ಕೆಲಸವನ್ನು ಉಳಿಸುತ್ತದೆ. [ಹೋಲಿಕೆ](/compare/aliases) ವ್ಯತ್ಯಾಸಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ.
