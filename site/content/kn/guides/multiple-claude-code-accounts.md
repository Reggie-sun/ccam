ಪ್ರತಿ ಖಾತೆಗೂ ಅದರದೇ ಕಾನ್ಫಿಗರೇಶನ್ ಫೋಲ್ಡರ್ ನೀಡಿ. Claude Code ಆ ಫೋಲ್ಡರ್ ಅನ್ನು `CLAUDE_CONFIG_DIR` ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ವೇರಿಯೇಬಲ್‌ನಿಂದ ಓದುತ್ತದೆ. ಪ್ರತಿ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಅದರದೇ ಲಾಗಿನ್, ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ಇತಿಹಾಸ ಇರುತ್ತದೆ, ಆದ್ದರಿಂದ ಪ್ರತಿ ಖಾತೆಯೂ ಲಾಗಿನ್ ಆಗಿಯೇ ಇರುತ್ತದೆ ಮತ್ತು ನೀವು ಅವುಗಳನ್ನು ಒಂದೇ ಸಮಯದಲ್ಲಿ ರನ್ ಮಾಡಬಹುದು. ಇದನ್ನು ಶೆಲ್ ಅಲಿಯಾಸ್ ಮೂಲಕ ಕೈಯಾರೆ ಹೊಂದಿಸಬಹುದು, ಅಥವಾ ccam ಗೆ ಬಿಡಬಹುದು.

## ಕೈಯಾರೆ ಹೇಗೆ ಹೊಂದಿಸುವುದು?

[Claude Code ನ ದಸ್ತಾವೇಜು ವಿವರಿಸುವ](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) ವಿಧಾನ ಇದು. ಪ್ರತಿ ಹೆಚ್ಚುವರಿ ಖಾತೆಗೆ `~/.bashrc` ಅಥವಾ `~/.zshrc` ನಲ್ಲಿ ಒಂದು ಸಾಲು ಸೇರಿಸಿ:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

ಹೊಸ ಟರ್ಮಿನಲ್ ತೆರೆದು `claude-work` ರನ್ ಮಾಡಿ. ಫೋಲ್ಡರ್ ಹೊಸದಾಗಿರುವುದರಿಂದ Claude Code ಲಾಗಿನ್ ಮಾಡಲು ಕೇಳುತ್ತದೆ. ಅಲ್ಲಿಂದ ಮುಂದೆ `claude` ನಿಮ್ಮ ಮೊದಲ ಖಾತೆ ಮತ್ತು `claude-work` ಎರಡನೆಯದು.

WSL ಇಲ್ಲದ Windows ನಲ್ಲಿ, ನಿಮ್ಮ ಪ್ರೊಫೈಲ್‌ನಲ್ಲಿರುವ (`notepad $PROFILE`) ಒಂದು PowerShell ಫಂಕ್ಷನ್ ಇದೇ ಕೆಲಸ ಮಾಡುತ್ತದೆ:

```powershell
function claude-work { $env:CLAUDE_CONFIG_DIR = "$HOME\.claude-work"; try { claude @args } finally { Remove-Item Env:CLAUDE_CONFIG_DIR } }
```

## ಅಲಿಯಾಸ್ ವಿಧಾನದಲ್ಲಿ ಏನು ಇರುವುದಿಲ್ಲ?

ಎರಡು ಖಾತೆಗಳಿಗೆ ಇದು ಚೆನ್ನಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ತಿಳಿದಿರಬೇಕಾದ ವಿಷಯಗಳು:

- ಪ್ರತಿ ಫೋಲ್ಡರ್ ಖಾಲಿಯಾಗಿ ಆರಂಭವಾಗುತ್ತದೆ: ಸೆಟ್ಟಿಂಗ್‌ಗಳಿಲ್ಲ, `CLAUDE.md` ಇಲ್ಲ, MCP ಸರ್ವರ್‌ಗಳಿಲ್ಲ, agents ಅಥವಾ skills ಇಲ್ಲ. ಬೇಕಾದುದನ್ನು ನೀವೇ ನಕಲಿಸಬೇಕು ಅಥವಾ ಲಿಂಕ್ ಮಾಡಬೇಕು, ಮತ್ತು ನಕಲುಗಳನ್ನು ನೀವೇ ಒಂದೇ ರೀತಿ ಇಡಬೇಕು.
- ಅಲಿಯಾಸ್‌ಗಳು ಇಂಟರ್‌ಆಕ್ಟಿವ್ ಶೆಲ್‌ಗಳಲ್ಲಿ ಮಾತ್ರ ಇರುತ್ತವೆ. ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳು, Makefile ಗಳು ಮತ್ತು ಇತರ ಪ್ರೋಗ್ರಾಂಗಳಿಗೆ ಅವು ಕಾಣುವುದಿಲ್ಲ.
- MCP ಸರ್ವರ್‌ಗಳು ಲಾಗಿನ್‌ನ ಪಕ್ಕದಲ್ಲೇ `.claude.json` ನಲ್ಲಿ ಇರುತ್ತವೆ, ಆದ್ದರಿಂದ ಅವುಗಳನ್ನು ಫೋಲ್ಡರ್‌ಗಳ ನಡುವೆ ಸುಲಭವಾಗಿ ಲಿಂಕ್ ಮಾಡಲು ಆಗುವುದಿಲ್ಲ.
- ಸಂಭಾಷಣೆಗಳು ಅವು ಆರಂಭವಾದ ಖಾತೆಯಲ್ಲೇ ಉಳಿಯುತ್ತವೆ, ಆದ್ದರಿಂದ ಒಂದನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸಲು ಆಗುವುದಿಲ್ಲ.
- ಎಲ್ಲಾ ಖಾತೆಗಳ ಬಳಕೆಯನ್ನು ಒಮ್ಮೆಗೇ ತೋರಿಸುವ ಯಾವುದೂ ಇಲ್ಲ.

## ಬದಲಿಗೆ /login ಮೂಲಕ ಖಾತೆ ಬದಲಾಯಿಸಬಹುದೇ?

ಹೌದು, ನೀವು ಅಪರೂಪಕ್ಕೆ ಮಾತ್ರ ಬದಲಾಯಿಸುತ್ತಿದ್ದರೆ. Claude Code ಒಳಗೆ `/login` ಟೈಪ್ ಮಾಡಿದರೆ ನೀವು ಇರುವ ಫೋಲ್ಡರ್‌ನ [ಖಾತೆ ಬದಲಾಗುತ್ತದೆ](https://code.claude.com/docs/en/quickstart). ಒಂದು ಸಮಯದಲ್ಲಿ ಒಂದೇ ಖಾತೆ ಲಾಗಿನ್ ಆಗಿರುತ್ತದೆ, ಆದ್ದರಿಂದ ಪ್ರತಿ ಬಾರಿ ಬದಲಾಯಿಸುವಾಗ ಮತ್ತೆ ಲಾಗಿನ್ ಮಾಡಬೇಕು, ಮತ್ತು ಎರಡು ಖಾತೆಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ರನ್ ಮಾಡಲು ಆಗುವುದಿಲ್ಲ. ಪ್ರತ್ಯೇಕ ಫೋಲ್ಡರ್‌ಗಳು ಈ ಎರಡೂ ತೊಂದರೆಗಳನ್ನು ತಪ್ಪಿಸುತ್ತವೆ.

## ccam ಮೂಲಕ ಹೇಗೆ ಹೊಂದಿಸುವುದು?

ccam ಇದೇ ಆಲೋಚನೆಯನ್ನು ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸುತ್ತದೆ ಮತ್ತು ಕೊರತೆಯಿರುವ ಭಾಗಗಳನ್ನು ಸೇರಿಸುತ್ತದೆ:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

ಈಗ `ccam personal` ಮತ್ತು `ccam work` ಎರಡು ಖಾತೆಗಳನ್ನು ಆರಂಭಿಸುತ್ತವೆ, ಮತ್ತು ಕೆಲಸದ ಖಾತೆಗೆ ನೀವು ನೀಡಿದ ಶಾರ್ಟ್‌ಕಟ್ `ccwork` ಕೂಡ ಅದನ್ನೇ ಮಾಡುತ್ತದೆ. ಇವು ಅಲಿಯಾಸ್‌ಗಳಲ್ಲ, ನಿಜವಾದ ಪ್ರೋಗ್ರಾಂಗಳು, ಆದ್ದರಿಂದ ಸ್ಕ್ರಿಪ್ಟ್‌ಗಳಲ್ಲೂ ಕೆಲಸ ಮಾಡುತ್ತವೆ. ಪಟ್ಟಿಯಿಂದ ಖಾತೆ ಆಯ್ಕೆಮಾಡಲು `ccam` ಅನ್ನು ಮಾತ್ರ ರನ್ ಮಾಡಿ, ಮತ್ತು ಒಂದನ್ನು ಡೀಫಾಲ್ಟ್ ಮಾಡಲು `ccam use work` ರನ್ ಮಾಡಿ.

ಸೆಟ್ಟಿಂಗ್‌ಗಳು, `CLAUDE.md`, MCP ಸರ್ವರ್‌ಗಳು ಮತ್ತು ವಿಸ್ತರಣೆಗಳು ಆರಂಭದಿಂದಲೇ ಹಂಚಿಕೆಯಾಗಿರುತ್ತವೆ. `ccam next --continue` ಸಂಭಾಷಣೆಯನ್ನು ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸುತ್ತದೆ. ನೀವು ಹಂಚಿಕೆಯ ಸಂಭಾಷಣೆ ಇತಿಹಾಸವನ್ನು ಆನ್ ಮಾಡಿದರೆ, ಎರಡೂ ಖಾತೆಗಳು ನಕಲಿನ ಬದಲು ಅದೇ ಸಂಭಾಷಣೆಯಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತವೆ. `ccam usage` ಎಲ್ಲಾ ಖಾತೆಗಳ 5 ಗಂಟೆಯ ಮತ್ತು ವಾರದ ಬಳಕೆಯನ್ನು ಒಮ್ಮೆಗೇ ತೋರಿಸುತ್ತದೆ.

ನೀವು ಈಗಾಗಲೇ `~/.claude` ಬಳಸುತ್ತಿದ್ದರೆ, ಆ ಖಾತೆಯನ್ನು ಮತ್ತೆ ಸೇರಿಸುವ ಬದಲು `ccam import` ರನ್ ಮಾಡಿ, ಅಥವಾ ಅದರ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, MCP ಸರ್ವರ್‌ಗಳು ಮತ್ತು ವಿಸ್ತರಣೆಗಳನ್ನು ಹಂಚಿಕೆಯ `default` ಗುಂಪಿಗೆ ನಕಲಿಸಲು `ccam migrate` ರನ್ ಮಾಡಿ.

## ಯಾವ ಖಾತೆ ರನ್ ಆಗುತ್ತಿದೆ ಎಂದು ಹೇಗೆ ತಿಳಿಯುವುದು?

Claude Code ಒಳಗೆ, `/status` ನೀವು ಲಾಗಿನ್ ಆಗಿರುವ ಖಾತೆಯನ್ನು ತೋರಿಸುತ್ತದೆ. ccam ಜೊತೆ, ಒಮ್ಮೆ `ccam statusline install` ರನ್ ಮಾಡಿದರೆ ಸ್ಟೇಟಸ್ ಲೈನ್ ಸದಾ ಖಾತೆಯ ಹೆಸರು ಮತ್ತು ಅದರ ಬಳಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ `[work] · Opus · 5h 24% · 7d 41%`.

## ಇದು Windows ಮತ್ತು WSL ನಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆಯೇ?

Claude Code [Windows ನಲ್ಲಿ ನೇರವಾಗಿ ಮತ್ತು WSL ಒಳಗೆ](https://code.claude.com/docs/en/setup) ರನ್ ಆಗುತ್ತದೆ. `CLAUDE_CONFIG_DIR` ಎರಡರಲ್ಲೂ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಆದ್ದರಿಂದ ನೇರ Windows ನಲ್ಲಿ ಮೇಲಿನ ಅಲಿಯಾಸ್ ಅಥವಾ PowerShell ಫಂಕ್ಷನ್ ಸಾಕು. ccam ಕೂಡ Windows ನಲ್ಲಿ ನೇರವಾಗಿ ರನ್ ಆಗುತ್ತದೆ: ಅದನ್ನು PowerShell ನಲ್ಲಿ `irm https://ccam.dev/install.ps1 | iex` ಮೂಲಕ, ಅಥವಾ WSL ಒಳಗೆ Linux ಕಮಾಂಡ್ ಮೂಲಕ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ. ಶಾರ್ಟ್‌ಕಟ್‌ಗಳು `ccwork.exe` ಆಗುತ್ತವೆ, ಮತ್ತು `settings.json` ನಂತಹ ಫೈಲ್‌ಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳಲು Developer Mode ಬೇಕು ([ccam ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ](/docs/install)).

## ಸಮಸ್ಯೆ ಪರಿಹಾರ

**Claude Code ಪ್ರತಿ ಬಾರಿ ಲಾಗಿನ್ ಮಾಡಲು ಕೇಳುತ್ತದೆ.** ಹೊಸ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಮೊದಲ ಬಾರಿ ಆರಂಭಿಸಿದಾಗ ಯಾವಾಗಲೂ ಕೇಳುತ್ತದೆ. ಪದೇ ಪದೇ ಕೇಳುತ್ತಿದ್ದರೆ, ಲಾಗಿನ್ ಅವಧಿ ಮುಗಿದಿದೆ ಅಥವಾ ಅಳಿಸಲಾಗಿದೆ: `ccam login work` ರನ್ ಮಾಡಿ (ಅಥವಾ ಅಲಿಯಾಸ್ ಅನ್ನು ಒಮ್ಮೆ ಆರಂಭಿಸಿ ಲಾಗಿನ್ ಮಾಡಿ).

**ಒಂದು MCP ಸರ್ವರ್ ಒಂದೇ ಖಾತೆಯಲ್ಲಿ ಕಾಣಿಸುತ್ತದೆ.** ಸೆಷನ್ ಒಳಗೆ `claude mcp add` ಮೂಲಕ ಸೇರಿಸಿದ ಸರ್ವರ್‌ಗಳು ಆ ಖಾತೆಗೆ ಮಾತ್ರ ಸೇರಿರುತ್ತವೆ, ಮತ್ತು `-s user` ಇಲ್ಲದಿದ್ದರೆ ಆ ಫೋಲ್ಡರ್‌ಗೆ ಮಾತ್ರ. ಒಂದನ್ನು ಎಲ್ಲಾ ಖಾತೆಗಳಿಗೆ ಸರಿಸಲು `ccam mcp import work <server>` ಬಳಸಿ.

**ಖಾತೆಗಳ ನಡುವೆ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಬೇರೆ ಬೇರೆಯಾಗಿವೆ.** `ccam share work` ಆ ಖಾತೆ ಏನನ್ನು, ಯಾವ ಗುಂಪಿನ ಮೂಲಕ ಹಂಚಿಕೊಳ್ಳುತ್ತದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ; `ccam group join default work` ಏನು ಬದಲಾಗುತ್ತದೆ ಎಂದು ತೋರಿಸಿದ ನಂತರ, `default` ಹಂಚಿಕೊಳ್ಳುವುದನ್ನು ಅದೂ ಹಂಚಿಕೊಳ್ಳುವಂತೆ ಮಾಡುತ್ತದೆ. `ccam doctor --fix` ಮುರಿದ ಲಿಂಕ್‌ಗಳನ್ನು ಸರಿಪಡಿಸುತ್ತದೆ ಮತ್ತು ಅದು ಬದಲಾಯಿಸುವ ಪ್ರತಿ ಫೈಲ್‌ನ ಬ್ಯಾಕಪ್ ಇಡುತ್ತದೆ.

**ಎರಡು ಖಾತೆಗಳು ಒಂದೇ ಸಂಭಾಷಣೆಯನ್ನು ತೆರೆಯುತ್ತವೆ.** ಒಂದೇ ಸಂಭಾಷಣೆಯಲ್ಲಿ ಎರಡು ಖಾತೆಗಳಿಂದ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಕೆಲಸ ಮಾಡಬೇಡಿ. ನೀವು ಹಾಗೆ ಪ್ರಯತ್ನಿಸಿದರೆ ccam ಎಚ್ಚರಿಸುತ್ತದೆ.

## ಯಾವುದನ್ನು ಆಯ್ಕೆಮಾಡಬೇಕು?

ಎರಡು ಖಾತೆಗಳಿದ್ದು ಏನನ್ನೂ ಹಂಚಿಕೊಳ್ಳಬೇಕಿಲ್ಲದಿದ್ದರೆ, ಅಲಿಯಾಸ್ ಸಾಕು. ಹಂಚಿಕೆಯ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು MCP ಸರ್ವರ್‌ಗಳು, ಹೆಚ್ಚು ಖಾತೆಗಳು, ಬಳಕೆಯ ಒಂದು ನೋಟ ಅಥವಾ ಸಂಭಾಷಣೆಗಳನ್ನು ಮುಂದುವರಿಸುವುದು ಬೇಕಿದ್ದರೆ, ccam ನಿಮಗೆ ಆ ಲೆಕ್ಕಾಚಾರದ ಕೆಲಸವನ್ನು ಉಳಿಸುತ್ತದೆ. [ಅಲಿಯಾಸ್‌ಗಳೊಂದಿಗಿನ ಹೋಲಿಕೆ](/compare/aliases) ವ್ಯತ್ಯಾಸಗಳನ್ನು ಅಕ್ಕಪಕ್ಕದಲ್ಲಿ ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ, ಮತ್ತು [ccam ಮತ್ತು ಇತರ ಖಾತೆ ಸ್ವಿಚರ್‌ಗಳು](/compare/account-switchers) ಒಂದೇ ಲಾಗಿನ್ ಅನ್ನು ಬದಲಾಯಿಸುವ ಟೂಲ್‌ಗಳ ಬಗ್ಗೆ ವಿವರಿಸುತ್ತದೆ.

ನೀವು ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು ಖಾತೆಗಳನ್ನು ಬಳಸಬಹುದೇ ಎಂಬುದು ಪ್ರತಿ ಖಾತೆಗೆ ಅನ್ವಯಿಸುವ ನಿಯಮಗಳನ್ನು ಅವಲಂಬಿಸಿದೆ. ಆರಂಭಿಸುವ ಮೊದಲು ಆ ನಿಯಮಗಳನ್ನು ಓದಿ.

**Team ಮತ್ತು Enterprise ಸೀಟುಗಳು.** ಸ್ವಯಂಚಾಲಿತ ಖಾತೆ ಆಯ್ಕೆ (`ccam next`, `--fallback`, `ccam pick`, ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನ `n` ಮತ್ತು, ನೀವು ಆನ್ ಮಾಡಿದ ನಂತರ, [`auto_switch`](/features/next#auto-switch)) ಒಂದೇ Claude Team ಅಥವಾ Enterprise ಸಂಸ್ಥೆಯ ಸೀಟುಗಳ ನಡುವೆಯೂ ಬದಲಾಯಿಸುತ್ತದೆ, ಇದು Anthropic ನ ನಿಯಮಗಳನ್ನು ಉಲ್ಲಂಘಿಸಬಹುದು. ಇದನ್ನು ಅವಲಂಬಿಸುವ ಮೊದಲು [ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳನ್ನು](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) ಓದಿ ಮತ್ತು ನಿಮ್ಮ ಸಂಸ್ಥೆ ಹಾಗೂ Anthropic ಬಳಿ ವಿಚಾರಿಸಿ.
