ಒಂದು ಖಾತೆ ತನ್ನ ಬಳಕೆಯ ಮಿತಿ (ಅನೇಕರು ಇದನ್ನು rate limit ಎನ್ನುತ್ತಾರೆ) ತಲುಪಿದಾಗ, ನಿಮಗೆ ಎರಡು ಆಯ್ಕೆಗಳಿವೆ: ಮಿತಿ ರೀಸೆಟ್ ಆಗುವವರೆಗೆ ಕಾಯುವುದು, ಅಥವಾ ಅದೇ ಸಂಭಾಷಣೆಯನ್ನು ಈಗಲೇ ನಿಮ್ಮದೇ ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸುವುದು. ccam ಜೊತೆ ಎರಡನೆಯದಕ್ಕೆ ಒಂದೇ ಕಮಾಂಡ್ ಸಾಕು: `ccam next --auto --continue`.

## Claude Code ನಲ್ಲಿ ಯಾವ ಮಿತಿಗಳಿವೆ?

Pro ಮತ್ತು Max ಪ್ಲಾನ್‌ಗಳಲ್ಲಿ, Claude Code ಗೆ [5 ಗಂಟೆಯ ಸೆಷನ್ ಮಿತಿ ಮತ್ತು ವಾರದ ಮಿತಿ](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan) ಇವೆ. ಎರಡನ್ನೂ ವೆಬ್ ಮತ್ತು ಆ್ಯಪ್‌ಗಳಲ್ಲಿನ Claude ಜೊತೆ ಹಂಚಿಕೊಳ್ಳಲಾಗುತ್ತದೆ, ಮತ್ತು ಬಳಕೆ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಎರಡಕ್ಕೂ ಎಣಿಕೆಯಾಗುತ್ತದೆ. ಒಂದು ಮುಗಿದಾಗ, Claude Code "You've hit your session limit · resets 3:45pm" ನಂತಹ [ಸಂದೇಶವನ್ನು ತೋರಿಸುತ್ತದೆ](https://code.claude.com/docs/en/errors#youve-hit-your-session-limit). ಮಾಡೆಲ್ ಬದಲಾಯಿಸುವುದರಿಂದ ಪ್ರಯೋಜನವಿಲ್ಲ, ಏಕೆಂದರೆ ಮಿತಿಗಳು ಎಲ್ಲಾ ಮಾಡೆಲ್‌ಗಳಿಗೂ ಅನ್ವಯಿಸುತ್ತವೆ.

## ಆಯ್ಕೆ 1: ರೀಸೆಟ್‌ವರೆಗೆ ಕಾಯಿರಿ

ನಿಮ್ಮ ಬಳಿ ಒಂದೇ ಖಾತೆ ಇದ್ದರೆ, ಕಾಯಿರಿ. Claude Code ನ ಇತ್ತೀಚಿನ ಆವೃತ್ತಿಗಳು [ತೆರೆದ ಸೆಷನ್‌ನಲ್ಲೇ ಕಾಯುತ್ತವೆ](https://code.claude.com/docs/en/interactive-mode#wait-for-a-usage-limit-to-reset) ಮತ್ತು ಮಿತಿ ರೀಸೆಟ್ ಆದ ನಂತರ ತಾವಾಗಿಯೇ ಕೆಲಸವನ್ನು ಮುಂದುವರಿಸುತ್ತವೆ. ನಿಮ್ಮ ಪ್ಲಾನ್‌ನ ಮಿತಿಗಳಲ್ಲಿ ಎಷ್ಟು ಬಳಸಿದ್ದೀರಿ ಎಂದು Claude Code ಒಳಗೆ `/usage` ತೋರಿಸುತ್ತದೆ.

## ಆಯ್ಕೆ 2: ಈಗಲೇ ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸಿ

ನಿಮ್ಮ ಬಳಿ ಎರಡನೇ ಖಾತೆ ಇದ್ದರೆ, ಅದೇ ಸಂಭಾಷಣೆಯೊಂದಿಗೆ ತಕ್ಷಣ ಮುಂದುವರಿಯಬಹುದು. ಇದನ್ನು ಒಮ್ಮೆ ಹೊಂದಿಸಿ:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
ccam group set default --add history
ccam statusline install
```

ಈಗ ನೀವು ಕೆಲಸ ಮಾಡುತ್ತಿರುವಾಗ ಸ್ಟೇಟಸ್ ಲೈನ್ ಖಾತೆಯನ್ನು ಮತ್ತು ಅದರ 5 ಗಂಟೆಯ ಬಳಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ. ಹೀಗಾಗಿ ಮಿತಿ ಅನಿರೀಕ್ಷಿತವಾಗಿ ಬರುವುದಿಲ್ಲ.

ಮಿತಿ ತಲುಪಿದಾಗ, Claude Code ನಿಂದ ಹೊರಬನ್ನಿ (`/exit`), ನಂತರ:

```sh
ccam usage
```

```console
 1 personal  just now
   5-hour   ████████████████████ 100%  resets in 22m
   Weekly   ██████████████░░░░░░  68%  resets in 1d 9h
 2 work      just now
   5-hour   ██░░░░░░░░░░░░░░░░░░   8%  resets in 4h 12m
   Weekly   ████░░░░░░░░░░░░░░░░  19%  resets in 5d 2h
→ Most headroom: work   (open it with ccam next --auto)
```

ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯಲ್ಲಿ ಸಂಭಾಷಣೆಯನ್ನು ತೆರೆಯಿರಿ:

```sh
ccam next --auto --continue
```

Claude Code `work` ಆಗಿ ಆರಂಭವಾಗುತ್ತದೆ, ಈಗಿನ ಫೋಲ್ಡರ್‌ನ ಇತ್ತೀಚಿನ ಸಂಭಾಷಣೆಯೊಂದಿಗೆ, ಇಲ್ಲಿಯವರೆಗೆ ಹೇಳಿದ ಎಲ್ಲವನ್ನೂ ಒಳಗೊಂಡಂತೆ. ಇತಿಹಾಸ ಹಂಚಿಕೊಳ್ಳುವುದು (ಮೇಲಿನ `ccam group set default --add history`) ಅದನ್ನು ಒಂದೇ ಸಂಭಾಷಣೆಯಾಗಿ ಉಳಿಸುತ್ತದೆ; ಅದಿಲ್ಲದೆ, Claude Code ಸಂಭಾಷಣೆಯನ್ನು `work` ಗೆ ನಕಲಿಸುತ್ತದೆ, ಮತ್ತು ಆ ಮೊದಲ ಉತ್ತರ ಎಷ್ಟು ಟೋಕನ್‌ಗಳನ್ನು ಮತ್ತೆ ಓದುತ್ತದೆ ಎಂದು ccam ತಿಳಿಸುತ್ತದೆ.

Claude Code ನಲ್ಲಿ [ccam ಪ್ಲಗಿನ್](/docs/install#claude-code-plugin) ಇದ್ದರೆ, ಮಿತಿಯಲ್ಲಿ ನಿಂತ ಸೆಷನ್ ಅಧಿಸೂಚನೆಯನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ತುಂಬಿದ ಅವಧಿಯನ್ನು ದಾಖಲಿಸುತ್ತದೆ, ಹೀಗಾಗಿ ರೀಸೆಟ್‌ಗೆ ಮೊದಲು `ccam next --auto` ಆ ಖಾತೆಯನ್ನು ಮತ್ತೆ ಆಯ್ಕೆಮಾಡುವುದಿಲ್ಲ, ಮತ್ತು `/ccam:switch` (ಅಥವಾ `/ccam:switch work`) ಊಹಿಸಲು ಏನನ್ನೂ ಬಿಡದೆ `ccam next --continue` ಗಾಗಿ ಸಂಭಾಷಣೆಯನ್ನು ಗುರುತಿಸಿಡುತ್ತದೆ.

**Team ಮತ್ತು Enterprise ಸೀಟುಗಳು.** ಸ್ವಯಂಚಾಲಿತ ಆಯ್ಕೆ (`ccam next`, `--fallback`, `ccam pick`, ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನ `n`, ಮತ್ತು ನೀವು ಆನ್ ಮಾಡಿದಾಗ [`auto_switch`](/features/next#auto-switch)) ಒಂದೇ Claude Team ಅಥವಾ Enterprise ಸಂಸ್ಥೆಯ ಸೀಟುಗಳ ನಡುವೆಯೂ ಬದಲಾಯಿಸುತ್ತದೆ. Anthropic ನ ಸಹಾಯ ಕೇಂದ್ರವು "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (Team ಪ್ಲಾನ್‌ನ ಪ್ರತಿ ಸೀಟನ್ನು ಹೆಸರಿಸಲಾದ ಒಬ್ಬ ವ್ಯಕ್ತಿಗೆ ನಿಯೋಜಿಸಲಾಗುತ್ತದೆ, ಮತ್ತು ಆ ವ್ಯಕ್ತಿ ಮಾತ್ರ ಅದನ್ನು ಬಳಸಬಹುದು) ಮತ್ತು "Users can't route their work through another user's account to use that user's remaining usage" (ಬಳಕೆದಾರರು ಇನ್ನೊಬ್ಬ ಬಳಕೆದಾರರ ಉಳಿದಿರುವ ಬಳಕೆಯನ್ನು ಉಪಯೋಗಿಸಿಕೊಳ್ಳಲು ತಮ್ಮ ಕೆಲಸವನ್ನು ಅವರ ಖಾತೆಯ ಮೂಲಕ ನಡೆಸುವಂತಿಲ್ಲ) ಎಂದು ಹೇಳುತ್ತದೆ ([Team ಪ್ಲಾನ್‌ಗಳು](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129); [Enterprise ಪ್ಲಾನ್‌ಗಳಿಗೂ](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) ಇದೇ ಅನ್ವಯಿಸುತ್ತದೆ). ಆದ್ದರಿಂದ ಸೀಟುಗಳ ನಡುವೆ ಸ್ವಯಂಚಾಲಿತ ಆಯ್ಕೆಯನ್ನು ಬಳಸುವುದು Anthropic ನ ನಿಯಮಗಳನ್ನು ಉಲ್ಲಂಘಿಸಬಹುದು. ಅಲ್ಲಿ ಇದನ್ನು ಬಳಸಬೇಕೆ ಎಂಬುದು ನಿಮ್ಮ ನಿರ್ಧಾರ: ಇದನ್ನು ಅವಲಂಬಿಸುವ ಮೊದಲು ನಿಮ್ಮ ಸಂಸ್ಥೆ ಮತ್ತು Anthropic ಬಳಿ ವಿಚಾರಿಸಿ ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ವೈಯಕ್ತಿಕ ಪ್ಲಾನ್‌ಗಳ (Pro, Max) ಬಗ್ಗೆ [ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳಲ್ಲಿನ ನಿಯಮಗಳ ಟಿಪ್ಪಣಿ](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) ತಿಳಿಸುತ್ತದೆ.

## ccam ತಾನಾಗಿಯೇ ಖಾತೆ ಬದಲಾಯಿಸುತ್ತದೆಯೇ?

ನೀವು ಆನ್ ಮಾಡಿದರೆ ಮಾತ್ರ. ಡೀಫಾಲ್ಟ್ ಆಗಿ ನೀವು ಕೆಲಸ ಮಾಡುತ್ತಿರುವಾಗ ccam ರನ್ ಆಗುತ್ತಿರುವುದಿಲ್ಲ: ಅದು Claude Code ಅನ್ನು ಆರಂಭಿಸಿ ತನ್ನ ಜಾಗವನ್ನು ಅದಕ್ಕೆ ಬಿಟ್ಟುಕೊಡುತ್ತದೆ, ಹೀಗಾಗಿ ಯಾವಾಗ ಬದಲಾಯಿಸಬೇಕು ಎಂದು ನೀವೇ ನಿರ್ಧರಿಸುತ್ತೀರಿ, ಮತ್ತು `ccam next --auto` ಅತಿ ಕಡಿಮೆ 5 ಗಂಟೆಯ ಬಳಕೆ ಇರುವ ಖಾತೆಯನ್ನು ಆಯ್ಕೆಮಾಡುತ್ತದೆ, 100% ತಲುಪಿದ ಅಥವಾ ಲಾಗಿನ್ ಆಗಿಲ್ಲದ ಖಾತೆಗಳನ್ನು ಬಿಟ್ಟುಬಿಡುತ್ತದೆ, ಮತ್ತು ಒಂದೇ Team ಅಥವಾ Enterprise ಸಂಸ್ಥೆಯೊಳಗೆ, ಅಥವಾ ವೈಯಕ್ತಿಕ ಪ್ಲಾನ್‌ಗಳ ನಡುವೆಯೇ ಉಳಿಯುತ್ತದೆ. `config.toml` ನಲ್ಲಿ `relay = true` ಇದ್ದರೆ, ccam ಬದಲಿಗೆ ಸೆಷನ್‌ನ ಪಕ್ಕದಲ್ಲಿ ಕಾಯುತ್ತದೆ, ಹೀಗಾಗಿ `/ccam:switch` ಸೆಷನ್‌ನ ಆಯ್ಕೆಗಳು, ಅನುಮತಿ ಮೋಡ್ ಮತ್ತು effort ಮಟ್ಟವನ್ನು ಉಳಿಸಿಕೊಂಡು, ತಾನಾಗಿಯೇ ಮುಂದುವರಿಯುತ್ತದೆ. `auto_switch = true` ಇದ್ದರೆ (Linux ಮತ್ತು macOS; ಪ್ರಾಯೋಗಿಕ), ccam ಬದಲಾವಣೆಯನ್ನೂ ತಾನೇ ಮಾಡುತ್ತದೆ: Claude Code ಸೆಷನ್ ಅನ್ನು ಅದರ ಮಿತಿಯಲ್ಲಿ ನಿಲ್ಲಿಸಿದಾಗ ಮತ್ತು ಅದರಂತಹ ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಅವಕಾಶ ಇದ್ದಾಗ, ccam ಸೆಷನ್ ಅನ್ನು ಕೊನೆಗೊಳಿಸಿ ಸಂಭಾಷಣೆಯನ್ನು ಅಲ್ಲಿ ಮುಂದುವರಿಸುತ್ತದೆ ([ಷರತ್ತುಗಳು ಮತ್ತು ವೆಚ್ಚಗಳು](/features/next#auto-switch)). ಕೆಲವು ಇತರ ಟೂಲ್‌ಗಳು ಬದಲಿಗೆ ರನ್ ಆಗುತ್ತಿರುವ ಸೆಷನ್‌ನ ಲಾಗಿನ್ ಅನ್ನು ಬದಲಾಯಿಸುತ್ತವೆ; [ccam ಮತ್ತು ಇತರ ಖಾತೆ ಸ್ವಿಚರ್‌ಗಳು](/compare/account-switchers) ಈ ವ್ಯತ್ಯಾಸವನ್ನು ವಿವರಿಸುತ್ತದೆ.

## ನೆನಪಿನಲ್ಲಿಡಬೇಕಾದ ವಿಷಯಗಳು

- ನೀವು ಕೆಲಸ ಮಾಡಿದ ಅದೇ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ `ccam next --continue` ರನ್ ಮಾಡಿ; ಸಂಭಾಷಣೆಗಳು ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ವಾರು ಸಂಗ್ರಹವಾಗುತ್ತವೆ.
- ಒಂದೇ ಸಂಭಾಷಣೆಯಲ್ಲಿ ಎರಡು ಖಾತೆಗಳನ್ನು ಒಂದೇ ಸಮಯದಲ್ಲಿ ರನ್ ಮಾಡಬೇಡಿ. ನೀವು ಹಾಗೆ ಪ್ರಯತ್ನಿಸಿದರೆ ccam ಎಚ್ಚರಿಸುತ್ತದೆ.
- ಹಂಚಿಕೊಂಡ ಇತಿಹಾಸ ಇಲ್ಲದಿದ್ದರೆ, ಸಂಭಾಷಣೆ ಇನ್ನೊಂದು ಖಾತೆಗೆ ನಕಲಾಗುತ್ತದೆ ಮತ್ತು ಎರಡು ಪ್ರತಿಗಳು ತಮ್ಮದೇ ದಾರಿಯಲ್ಲಿ ಸಾಗುತ್ತವೆ; `/rewind` ಕೋಡ್ ಅನ್ನು ಮರುಸ್ಥಾಪಿಸುವ ಚೆಕ್‌ಪಾಯಿಂಟ್‌ಗಳು ಮೊದಲ ಖಾತೆಯಲ್ಲೇ ಉಳಿಯುತ್ತವೆ.
- ಹೊಸ ಖಾತೆಯಲ್ಲಿನ ಮೊದಲ ಸಂದೇಶ ಸಾಮಾನ್ಯಕ್ಕಿಂತ ಹೆಚ್ಚು ಮಿತಿಯನ್ನು ಬಳಸಬಹುದು, ಏಕೆಂದರೆ ಆ ಖಾತೆ ಇನ್ನೂ ಸಂಭಾಷಣೆಯನ್ನು ಕ್ಯಾಶ್ ಮಾಡಿರುವುದಿಲ್ಲ. `ccam next --continue --brief` ಬದಲಿಗೆ ಅದನ್ನು ಒಂದು ಚಿಕ್ಕ ಸಾರಾಂಶದಿಂದ ಆರಂಭಿಸುತ್ತದೆ.
- ಈ ರೀತಿ ಖಾತೆಗಳ ನಡುವೆ ಬದಲಾಯಿಸಲು ನಿಮಗೆ ಅನುಮತಿ ಇದೆಯೇ ಎಂಬುದು ಪ್ರತಿ ಖಾತೆಯ ನಿಯಮಗಳನ್ನು ಅವಲಂಬಿಸಿದೆ.

`ccam usage` ಮತ್ತು `ccam next` ನ ಎಲ್ಲಾ ಆಯ್ಕೆಗಳಿಗಾಗಿ [ಬಳಕೆಯ ಮಿತಿಗಳು](/docs/usage-limits) ನೋಡಿ.
