ಒಂದು ಖಾತೆ ತನ್ನ ಬಳಕೆಯ ಮಿತಿ ತಲುಪಿದಾಗ, ಅದೇ ಸಂಭಾಷಣೆಯನ್ನು ನಿಮ್ಮದೇ ಇನ್ನೊಂದು ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸಿ: ಸಂಭಾಷಣೆಯ ಇತಿಹಾಸವನ್ನು ಒಮ್ಮೆ ಹಂಚಿಕೊಳ್ಳಿ, ನಂತರ `ccs next --continue` ರನ್ ಮಾಡಿ. ನಿಮ್ಮ ಬಳಿ ಒಂದೇ ಖಾತೆ ಇದ್ದರೆ, Claude Code ತೋರಿಸುವ ರೀಸೆಟ್ ಸಮಯದವರೆಗೆ ಕಾಯಿರಿ.

## ಅದು ಸಂಭವಿಸುವ ಮೊದಲು

ಬದಲಾವಣೆಗೆ ಒಂದೇ ಕಮಾಂಡ್ ಸಾಕಾಗುವಂತೆ ಖಾತೆಗಳನ್ನು ಹೊಂದಿಸಿ:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

ಈಗ ನೀವು ಕೆಲಸ ಮಾಡುತ್ತಿರುವಾಗ ಸ್ಟೇಟಸ್ ಲೈನ್ ಖಾತೆಯನ್ನು ಮತ್ತು ಅದರ 5 ಗಂಟೆಯ ಬಳಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ. ಹೀಗಾಗಿ ಮಿತಿ ಅನಿರೀಕ್ಷಿತವಾಗಿ ಬರುವುದಿಲ್ಲ.

## ಮಿತಿ ತಲುಪಿದಾಗ

Claude Code ನಿಂದ ಹೊರಬನ್ನಿ (`/exit`), ನಂತರ:

```sh
ccs usage
```

```console
 1 personal  ████████ 100% 22분        █████░░░  68% 1일 9시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
```

ಹೆಚ್ಚು ಅವಕಾಶ ಇರುವ ಖಾತೆಯಲ್ಲಿ ಸಂಭಾಷಣೆಯನ್ನು ತೆರೆಯಿರಿ:

```sh
ccs next --auto --continue
```

Claude Code `work` ಆಗಿ ಆರಂಭವಾಗುತ್ತದೆ, ಈಗಿನ ಫೋಲ್ಡರ್‌ನ ಇತ್ತೀಚಿನ ಸಂಭಾಷಣೆಯೊಂದಿಗೆ, ಇಲ್ಲಿಯವರೆಗೆ ಹೇಳಿದ ಎಲ್ಲವನ್ನೂ ಒಳಗೊಂಡಂತೆ.

## ನೆನಪಿನಲ್ಲಿಡಬೇಕಾದ ವಿಷಯಗಳು

- ನೀವು ಕೆಲಸ ಮಾಡಿದ ಅದೇ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ `ccs next --continue` ರನ್ ಮಾಡಿ; ಸಂಭಾಷಣೆಗಳು ಪ್ರಾಜೆಕ್ಟ್ ಫೋಲ್ಡರ್‌ವಾರು ಸಂಗ್ರಹವಾಗುತ್ತವೆ.
- ಒಂದೇ ಸಂಭಾಷಣೆಯಲ್ಲಿ ಎರಡು ಖಾತೆಗಳನ್ನು ಒಂದೇ ಸಮಯದಲ್ಲಿ ರನ್ ಮಾಡಬೇಡಿ. ನೀವು ಹಾಗೆ ಪ್ರಯತ್ನಿಸಿದರೆ ccam ಎಚ್ಚರಿಸುತ್ತದೆ.
- ಇನ್ನೊಂದು ಖಾತೆಯೂ ಅದೇ ಗುಂಪಿನಲ್ಲಿ ಸಂಭಾಷಣೆಯ ಇತಿಹಾಸವನ್ನು ಹಂಚಿಕೊಳ್ಳಬೇಕು.
- ಈ ರೀತಿ ಖಾತೆಗಳ ನಡುವೆ ಬದಲಾಯಿಸಲು ನಿಮಗೆ ಅನುಮತಿ ಇದೆಯೇ ಎಂಬುದು ಪ್ರತಿ ಖಾತೆಯ ನಿಯಮಗಳನ್ನು ಅವಲಂಬಿಸಿದೆ.

`ccs usage` ಮತ್ತು `ccs next` ನ ಎಲ್ಲಾ ಆಯ್ಕೆಗಳಿಗಾಗಿ [ಬಳಕೆಯ ಮಿತಿಗಳು](/docs/usage-limits) ನೋಡಿ.
