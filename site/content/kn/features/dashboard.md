ಆರ್ಗ್ಯುಮೆಂಟ್‌ಗಳಿಲ್ಲದ `ccam`, ಸ್ಟ್ಯಾಂಡರ್ಡ್ ಇನ್‌ಪುಟ್ ಮತ್ತು ಔಟ್‌ಪುಟ್ ಟರ್ಮಿನಲ್ ಆಗಿದ್ದಾಗ ಪೂರ್ಣ ಪರದೆಯ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಅನ್ನು ತೆರೆಯುತ್ತದೆ; ಇಲ್ಲದಿದ್ದರೆ ಅದು `ccam list` ಅನ್ನು ಮುದ್ರಿಸುತ್ತದೆ. ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಪ್ರತಿ ಖಾತೆಯನ್ನು ಅದರ ಬಳಕೆ ಮತ್ತು ಗುಂಪುಗಳೊಂದಿಗೆ ತೋರಿಸುತ್ತದೆ, ಮತ್ತು ಕಮಾಂಡ್‌ಗಳು ಮಾಡುವುದನ್ನೇ ಮಾಡುತ್ತದೆ: ಆರಂಭಿಸುವುದು, ಸೇರಿಸುವುದು, ಲಾಗಿನ್ ಮಾಡುವುದು, ಗುಂಪುಗಳನ್ನು ಬದಲಾಯಿಸುವುದು, ಫೋಲ್ಡರ್ ನಿಯಮಗಳನ್ನು ಹೊಂದಿಸುವುದು, ಪರಿಶೀಲಿಸುವುದು ಮತ್ತು ದುರಸ್ತಿ ಮಾಡುವುದು. ಆರಂಭಿಸಿದಾಗ ಅದು ಮುಚ್ಚುತ್ತದೆ; ಖಾತೆ ಸೇರಿಸುವಾಗ ಅಥವಾ ಲಾಗಿನ್ ಮಾಡುವಾಗ ಅದು ಟರ್ಮಿನಲ್‌ಗೆ ಜಾಗ ಬಿಟ್ಟು ನಂತರ ಮರಳುತ್ತದೆ.

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

ಟ್ಯಾಬ್ ಹೆಸರುಗಳ ಕೆಳಗಿನ ಸಾಲು ಈಗಿನ ಟ್ಯಾಬ್ ಯಾವುದಕ್ಕಾಗಿ ಎಂದು ಒಂದು ವಾಕ್ಯದಲ್ಲಿ ಹೇಳುತ್ತದೆ. ಅಗಲವಾದ ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ Accounts ಟ್ಯಾಬ್ ಪ್ರತಿ ಖಾತೆಯ ಇಮೇಲ್ ಅನ್ನೂ ತೋರಿಸುತ್ತದೆ.

ತೆರೆದ ಪ್ರತಿ ಬಾರಿ, ಹೊಸ ccam ಬಿಡುಗಡೆ ಇದೆಯೇ ಎಂದು ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಹಿನ್ನೆಲೆಯಲ್ಲಿ GitHub ಗೆ ಕೇಳುತ್ತದೆ; ಮೊದಲ ಚೌಕಟ್ಟು ಅದಕ್ಕಾಗಿ ಎಂದಿಗೂ ಕಾಯುವುದಿಲ್ಲ, ಮತ್ತು ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಏನನ್ನೂ ತೋರಿಸುವುದಿಲ್ಲ. ಹೊಸ ಬಿಡುಗಡೆ ಇದ್ದಾಗ, ಶೀರ್ಷಿಕೆಯ ಕೆಳಗಿನ ಒಂದು ಸಾಲು ಅದನ್ನು ಶಿಫಾರಸು ಮಾಡುತ್ತದೆ:

```console
 ● ccam 0.10.2 is available (you have 0.10.1) · press U to update
```

`U` ಮೊದಲು ಕೇಳುತ್ತದೆ, ನಂತರ [`ccam update`](/features/update) ಮಾಡುವ ರೀತಿಯಲ್ಲೇ ಅಪ್‌ಡೇಟ್ ಮಾಡುತ್ತದೆ: ಬಿಡುಗಡೆಯನ್ನು ಅದರ SHA-256 checksums ಜೊತೆ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಅದು ಒಂದೇ ಹಂತದಲ್ಲಿ ccam ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ. ನೀವು ಇರುವ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಇನ್ನೂ ಹಳೆಯ ಆವೃತ್ತಿಯೇ, ಹೀಗಾಗಿ ಹೊರಬಂದು `ccam` ಅನ್ನು ಮತ್ತೆ ಪ್ರಾರಂಭಿಸಿ. ಅಪ್‌ಡೇಟ್ ಅನ್ನು ಇಲ್ಲಿ ಮಾಡಲು ಸಾಧ್ಯವಾಗದಿದ್ದಾಗ, ಉದಾಹರಣೆಗೆ `.deb` ಪ್ಯಾಕೇಜ್‌ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿದ ccam ಗೆ, ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ `ccam update` ನೀಡುವ ಅದೇ ಸಲಹೆಯನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಕೊಡುಗೆಯನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ.

ಮೊದಲ ಚೌಕಟ್ಟು `config.toml` ಒಂದರಿಂದಲೇ, 100 ms ಗಿಂತ ತುಂಬಾ ಕಡಿಮೆ ಸಮಯದಲ್ಲಿ ಮೂಡುತ್ತದೆ; ಪ್ರತಿ ಖಾತೆ ಉತ್ತರಿಸಿದಂತೆ ಬಳಕೆ ತುಂಬಿಕೊಳ್ಳುತ್ತದೆ. ಪ್ರತಿ ಮಿತಿಗೆ ತನ್ನದೇ ಬಾರ್ ಇದೆ: 5 ಗಂಟೆಯ ಅವಧಿ, ಎಲ್ಲಾ ಮಾಡೆಲ್‌ಗಳ ವಾರದ ಅವಧಿ, ಮತ್ತು Fable ನ ಸ್ವಂತ ವಾರದ ಅವಧಿ; `-` ಎಂದರೆ ಖಾತೆಗೆ ಅಂತಹ ಅವಧಿ ಇಲ್ಲ. ಶೇಕಡಾವಾರು 80% ನಿಂದ ಹಳದಿ ಮತ್ತು 100% ನಲ್ಲಿ ಕೆಂಪು ಆಗುತ್ತದೆ, ಮತ್ತು ವಿಫಲವಾದ ಹುಡುಕಾಟದ ನಂತರ ಕ್ಯಾಶ್‌ನಿಂದ ಬಂದ ಮೌಲ್ಯಗಳನ್ನು ಮಸುಕಾಗಿ ತೋರಿಸಲಾಗುತ್ತದೆ.

| ಟ್ಯಾಬ್ | ಏನನ್ನು ತೋರಿಸುತ್ತದೆ | ಕೀಗಳು |
| --- | --- | --- |
| Accounts | ಸಂಖ್ಯೆ, ಹೆಸರು, ಇಮೇಲ್, 5 ಗಂಟೆಯ, ವಾರದ ಮತ್ತು Fable ಬಾರ್‌ಗಳು, ಕೊನೆಯ ಬಳಕೆ, ಗುಂಪುಗಳು; `✔` ಡೀಫಾಲ್ಟ್, `▸` ಈ ಫೋಲ್ಡರ್‌ನ ಖಾತೆ, `•` ಚಾಲನೆಯಲ್ಲಿದೆ | ಕೆಳಗೆ |
| Groups | ಪ್ರತಿ ಗುಂಪು, ಅದು ಏನನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ಅದರ ಖಾತೆಗಳು, ಹಾಗೂ ಯಾವ ಗುಂಪಿನಲ್ಲೂ ಇಲ್ಲದ ಖಾತೆಗಳು | `enter` ಸಂಪಾದನೆ, `n` ಹೊಸದು, `e` ಮರುಹೆಸರು, `x` ತೆಗೆದುಹಾಕು |
| Folders | [`ccam folder`](/features/folder) ನಿಯಮಗಳು ಮತ್ತು ಇಲ್ಲಿ ಅನ್ವಯವಾಗುವ ನಿಯಮ | `n` ಇಲ್ಲಿ ಒಂದು ಖಾತೆ ಬಳಸು, `enter` ಬದಲಾಯಿಸು, `x` ತೆಗೆದುಹಾಕು |
| Extensions | [`ccam ext`](/features/ext) ತೋರಿಸುವುದು, ಪ್ರತಿ ವಿಸ್ತರಣೆಯನ್ನು ಒಮ್ಮೆ, ಅದು ಬರುವ ಗುಂಪುಗಳೊಂದಿಗೆ | `r` ಮತ್ತೆ ಲೋಡ್ |
| Health | [`ccam doctor`](/features/doctor) ವರದಿ ಮಾಡುವುದು, ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಬಾಕ್ಸ್ ಆಗಿ (ಕೆಳಗೆ) | `f` ಆಯ್ಕೆಮಾಡಿದ ಬಾಕ್ಸ್ ದುರಸ್ತಿ, `F` ಎಲ್ಲವನ್ನೂ ದುರಸ್ತಿ (`doctor --fix`), `↑`/`↓` ಬಾಕ್ಸ್‌ಗಳ ನಡುವೆ ಸರಿಸುತ್ತದೆ |

`←`/`→` ಅಥವಾ `Tab` ಟ್ಯಾಬ್‌ಗಳನ್ನು ಬದಲಾಯಿಸುತ್ತವೆ, `?` ಈಗಿನ ಟ್ಯಾಬ್‌ನ ಕೀಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ, `r` ಅಲ್ಪಾವಧಿ ಕ್ಯಾಶ್ ಇಲ್ಲದೆ ಬಳಕೆಯನ್ನು ಮತ್ತೆ ಹುಡುಕುತ್ತದೆ, ಮತ್ತು `q` ಅಥವಾ `Esc` ನಿರ್ಗಮಿಸುತ್ತದೆ.

## Health ಟ್ಯಾಬ್

ನೀವು Health ಟ್ಯಾಬ್ ತೆರೆದಾಗ ಅದು [`ccam doctor`](/features/doctor) ನ ಪರಿಶೀಲನೆಗಳನ್ನು ನಡೆಸುತ್ತದೆ ಮತ್ತು ಅದೇ ನೋಟವನ್ನು ತೋರಿಸುತ್ತದೆ: ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಗುರುತು ಇರುವ ಮೊದಲ ಸಾಲು, ನಂತರ ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಬಾಕ್ಸ್. ಬಾಕ್ಸ್‌ನ ಪ್ರತಿ ಸಾಲು ಪರಿಶೀಲಿಸಿದ ಒಂದು ಕ್ಷೇತ್ರ, ಮೊದಲು `Folder`, `Login` ಮತ್ತು `Share links`, ಗುರುತುಗಳೊಂದಿಗೆ: `✔` ಸರಿ, `ℹ` ಮಾಹಿತಿ, `⚠` ಎಚ್ಚರಿಕೆ ಅಥವಾ `✘` ದೋಷ; ಹೀಗಾಗಿ ಯಾವ ಖಾತೆಗೆ ಸಮಸ್ಯೆ ಇದೆ ಮತ್ತು ಎಲ್ಲಿ ಎಂದು ನೀವು ತಕ್ಷಣ ನೋಡುತ್ತೀರಿ. ಯಾವುದೇ ಖಾತೆಗೆ ಸೇರದ ಫಲಿತಾಂಶಗಳು `General` ಬಾಕ್ಸ್‌ಗೆ ಹೋಗುತ್ತವೆ.

```console
 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` ಒಂದು ಬಾಕ್ಸ್‌ನಿಂದ ಇನ್ನೊಂದಕ್ಕೆ ಸರಿಸುತ್ತವೆ, ಮತ್ತು ಆಯ್ಕೆಮಾಡಿದ ಬಾಕ್ಸ್‌ಗೆ ಆಕ್ಸೆಂಟ್ ಬಣ್ಣದ ಅಂಚು ಇರುತ್ತದೆ. `f` ಆಯ್ಕೆಮಾಡಿದ ಬಾಕ್ಸ್ ಅನ್ನು ಮಾತ್ರ ದುರಸ್ತಿ ಮಾಡುತ್ತದೆ, `ccam doctor --fix` ಮಾಡುವ ರೀತಿಯಲ್ಲೇ: ಒಂದು ಖಾತೆಯ ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಅದು ಆ ಖಾತೆಯನ್ನು ಮಾತ್ರ ದುರಸ್ತಿ ಮಾಡುತ್ತದೆ, ಮತ್ತು `General` ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಯಾವುದೇ ಖಾತೆಗೆ ಸೇರದ ಫಲಿತಾಂಶಗಳನ್ನು (ಪ್ಲಗಿನ್ ಪಾತ್‌ಗಳು ಮತ್ತು ಶಾರ್ಟ್‌ಕಟ್‌ಗಳು); ಉಳಿದ ಪ್ರತಿ ಖಾತೆಯನ್ನು ಮತ್ತೆ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ ಅಷ್ಟೇ. ಅದು ಮೊದಲು ಕೇಳುತ್ತದೆ, ಮತ್ತು ದುರಸ್ತಿ ಮಾಡಲು ಏನೂ ಇಲ್ಲದ ಬಾಕ್ಸ್ `nothing to repair in <name>` ಎಂದು ಮಾತ್ರ ಹೇಳುತ್ತದೆ. `F` ಎಲ್ಲವನ್ನೂ ಒಮ್ಮೆಗೇ ದುರಸ್ತಿ ಮಾಡುತ್ತದೆ, `ccam doctor --fix` ನಂತೆ, ಮತ್ತು `r` ಮತ್ತೆ ಪರಿಶೀಲಿಸುತ್ತದೆ.

## ಗುಂಪುಗಳನ್ನು ಬದಲಾಯಿಸುವುದು

Groups ಟ್ಯಾಬ್‌ನಲ್ಲಿ, `Enter` ಸಂಪಾದಕವನ್ನು ತೆರೆಯುತ್ತದೆ: ಎಡಕ್ಕೆ ಐಟಂಗಳು, ಬಲಕ್ಕೆ ಖಾತೆಗಳು, ಬದಲಾಯಿಸಲು `Tab`, ಆನ್/ಆಫ್ ಮಾಡಲು `Space`. ಖಾತೆಗಳಲ್ಲಿ ಒಂದು ಈಗಾಗಲೇ ಇನ್ನೊಂದು ಗುಂಪಿನಿಂದ ಪಡೆಯುತ್ತಿರುವ ಐಟಂ ಅನ್ನು ಕಾರಣದೊಂದಿಗೆ ಬೂದು ಬಣ್ಣದಲ್ಲಿ ತೋರಿಸಲಾಗುತ್ತದೆ, ಒಂದು ಐಟಂ ಅನ್ನು ಎರಡು ಬಾರಿ ಪಡೆಯಲಿರುವ ಖಾತೆಯನ್ನೂ ಹಾಗೆಯೇ; ಒಂದು ಐಟಂ ಒಂದೇ ಗುಂಪಿನಿಂದ ಬರಬಹುದು. `Enter` ಯೋಜನೆಯನ್ನು ತೋರಿಸುತ್ತದೆ:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

ಗುಂಪಿನ ಪ್ರತಿಗಿಂತ ಬೇರೆಯಾಗಿರುವ ಫೈಲ್ ಬಗ್ಗೆ ಮೊದಲು ಕೇಳಲಾಗುತ್ತದೆ (ಗುಂಪಿನದನ್ನು ಉಳಿಸುವುದು, ನನ್ನದನ್ನು ಬಳಸುವುದು, ಅಥವಾ ವಿಲೀನಗೊಳಿಸುವುದು). ನಂತರ ಬದಲಾವಣೆ [`ccam group`](/features/share) ನ ಅದೇ ಕೋಡ್‌ನೊಂದಿಗೆ ಹಿನ್ನೆಲೆಯಲ್ಲಿ ರನ್ ಆಗುತ್ತದೆ: ಕಾನ್ಫಿಗ್ ಅನ್ನು ಮೊದಲು ಉಳಿಸಲಾಗುತ್ತದೆ, ಪ್ರತಿ ಖಾತೆಯ ಡೇಟಾ ಕ್ರಮವಾಗಿ ಸ್ಥಳಾಂತರಗೊಳ್ಳುತ್ತದೆ, ಮತ್ತು ಮೂಲ ಫೈಲ್‌ಗಳು `.ccam-backup/` ಗೆ ಹೋಗುತ್ತವೆ. ಚಾಲನೆಯಲ್ಲಿರುವ ಖಾತೆಯ ಡೇಟಾವನ್ನು ಸ್ಥಳಾಂತರಿಸಲಿರುವ ಬದಲಾವಣೆಯನ್ನು ಆ ಖಾತೆಯ ಹೆಸರಿನೊಂದಿಗೆ ನಿರಾಕರಿಸಲಾಗುತ್ತದೆ.

## ಖಾತೆ ಸೇರಿಸುವುದು

`a` ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ `ccam add` ಕೂಡ ಬಳಸುವ ವಿಜಾರ್ಡ್ ಅನ್ನು ತೆರೆಯುತ್ತದೆ:

1. ಖಾತೆಯ ಹೆಸರು.
2. ಅದು ಹೇಗೆ ಸೈನ್ ಇನ್ ಆಗುತ್ತದೆ: ಈಗಲೇ Claude ಚಂದಾದಾರಿಕೆ (ಬ್ರೌಸರ್‌ನಲ್ಲಿ), [API ಕೀ](/features/api), ಅಥವಾ ನಂತರ Claude ಚಂದಾದಾರಿಕೆ.
3. API ಕೀಗಾಗಿ: ಪ್ರತಿ ಆರಂಭದಲ್ಲಿ ccam ಕೀಯನ್ನು ಎಲ್ಲಿಂದ ಓದುತ್ತದೆ (`env:NAME` ಅಥವಾ `command:COMMAND`), ಎಂಡ್‌ಪಾಯಿಂಟ್, ಕೀಯನ್ನು ಹೇಗೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಮಾಡೆಲ್.
4. ಸೇರಬೇಕಾದ ಗುಂಪುಗಳು, `default` ಗುರುತಿಸಿದ ಸ್ಥಿತಿಯಲ್ಲಿ; ಗುಂಪುಗಳು ಇನ್ನೂ ಇಲ್ಲದಿದ್ದರೆ, `default` ಗುಂಪು ಏನನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತದೆ ಎಂಬುದು.
5. ನಿಮಗೆ ಬೇಕಿದ್ದರೆ, ಒಂದು ಶಾರ್ಟ್‌ಕಟ್ ಕಮಾಂಡ್.
6. ಖಚಿತಪಡಿಸಲು ಒಂದು ಸಾರಾಂಶ.

`Esc` ಒಂದು ಹಂತ ಹಿಂದಕ್ಕೆ ಹೋಗುತ್ತದೆ, ಮತ್ತು ಮೊದಲ ಹಂತದಲ್ಲಿ ವಿಜಾರ್ಡ್ ಅನ್ನು ಮುಚ್ಚುತ್ತದೆ.

## ಬಣ್ಣಗಳು

ಬಣ್ಣಗಳು Claude Code ನ ಟರ್ಮಿನಲ್ UI ನ ಪಾತ್ರಗಳನ್ನು ಅನುಸರಿಸುತ್ತವೆ, ಹೀಗಾಗಿ ccam ಅದರ ಪಕ್ಕದಲ್ಲಿ ಸಹಜವಾಗಿ ಕಾಣುತ್ತದೆ; ಗುಂಪಿನ ಹೆಸರುಗಳಿಗೆ ಅವುಗಳ ಹೆಸರಿನಿಂದಲೇ ಒಂದು ಬಣ್ಣ ಸಿಗುತ್ತದೆ. ccam ಟರ್ಮಿನಲ್‌ನಿಂದ ಅದರ ಹಿನ್ನೆಲೆಯನ್ನು ಕೇಳಿ ತಿಳಿ ಅಥವಾ ಗಾಢ ಥೀಮ್ ಆಯ್ಕೆಮಾಡುತ್ತದೆ. `config.toml` ನಲ್ಲಿ ನೀವೇ ಒಂದನ್ನು ಹೊಂದಿಸಿ:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` ಥೀಮ್‌ಗಳು ಕೆಂಪು-ಹಸಿರು ಬಣ್ಣಗುರುಡುತನಕ್ಕಾಗಿ, ಮತ್ತು `-ansi` ಥೀಮ್‌ಗಳು ಟರ್ಮಿನಲ್‌ನ ಸ್ವಂತ 16 ಬಣ್ಣಗಳನ್ನು ಬಳಸುತ್ತವೆ. `NO_COLOR` ಬಣ್ಣಗಳನ್ನು ಆಫ್ ಮಾಡುತ್ತದೆ.

## ಸುರಕ್ಷತೆ ಮತ್ತು ವಿಶೇಷ ಸಂದರ್ಭಗಳು

- ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಕಮಾಂಡ್‌ಗಳ ಅದೇ ಫಂಕ್ಷನ್‌ಗಳನ್ನು ಕರೆಯುತ್ತದೆ, ಹೀಗಾಗಿ ಪ್ರತಿ ನಿಯಮವೂ ಅನ್ವಯಿಸುತ್ತದೆ: ಡೇಟಾ ಸ್ಥಳಾಂತರಕ್ಕೆ ಮೊದಲು ಯೋಜನೆಗಳು, ಚಾಲನೆಯಲ್ಲಿರುವ ಖಾತೆಗಳಿಗೆ ನಿರಾಕರಣೆ, ಬ್ಯಾಕಪ್‌ಗಳು, ಮತ್ತು ಖಾತೆಯಿಂದ ಎಂದಿಗೂ ಹೊರಹೋಗದ ಲಾಗಿನ್ ಟೋಕನ್‌ಗಳು.
- ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ ಡ್ರೈ ರನ್ ಇಲ್ಲ: ಹೆಸರಿಲ್ಲದ `ccam --dry-run` ಈ ಫೋಲ್ಡರ್‌ನ ಖಾತೆ ಹೇಗೆ ಆರಂಭವಾಗುತ್ತದೆ ಎಂಬುದನ್ನು ಮುದ್ರಿಸುತ್ತದೆ, ಮತ್ತು ಒಂದು ಖಾತೆಯ ಮೇಲೆ `o` ಆ ಒಂದು ಆರಂಭದ ಡ್ರೈ ರನ್ ಅನ್ನು ನೀಡುತ್ತದೆ.
- Claude Code ಆರಂಭವಾಗುವ ಅಥವಾ ಲಾಗಿನ್ ತೆರೆಯುವ ಮೊದಲು ಟರ್ಮಿನಲ್ ಮೊದಲಿನ ಸ್ಥಿತಿಗೆ ಮರಳುತ್ತದೆ.
- ಡೈಲಾಗ್‌ಗೆ ತುಂಬಾ ಚಿಕ್ಕದಾದ ಪರದೆಯಲ್ಲಿ ಮೊದಲು ಟ್ಯಾಬ್‌ನ ಸಾಲುಗಳನ್ನು ಬಿಡಲಾಗುತ್ತದೆ; ಸಾಲುಗಳನ್ನು ಸುತ್ತುವ ಬದಲು `…` ಮೂಲಕ ಕತ್ತರಿಸಲಾಗುತ್ತದೆ.
