ಆರ್ಗ್ಯುಮೆಂಟ್‌ಗಳಿಲ್ಲದ `ccam`, ಸ್ಟ್ಯಾಂಡರ್ಡ್ ಇನ್‌ಪುಟ್ ಮತ್ತು ಔಟ್‌ಪುಟ್ ಟರ್ಮಿನಲ್ ಆಗಿದ್ದಾಗ ಪೂರ್ಣ ಪರದೆಯ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಅನ್ನು ತೆರೆಯುತ್ತದೆ; ಇಲ್ಲದಿದ್ದರೆ ಅದು `ccam list` ಅನ್ನು ಮುದ್ರಿಸುತ್ತದೆ. ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಪ್ರತಿ ಖಾತೆಯನ್ನು ಅದರ ಬಳಕೆ ಮತ್ತು ಗುಂಪುಗಳೊಂದಿಗೆ ತೋರಿಸುತ್ತದೆ, ಮತ್ತು ಕಮಾಂಡ್‌ಗಳು ಮಾಡುವುದನ್ನೇ ಮಾಡುತ್ತದೆ: ಆರಂಭಿಸುವುದು, ಸೇರಿಸುವುದು, ಲಾಗಿನ್ ಮಾಡುವುದು, ಗುಂಪುಗಳನ್ನು ಬದಲಾಯಿಸುವುದು, ಫೋಲ್ಡರ್ ನಿಯಮಗಳನ್ನು ಹೊಂದಿಸುವುದು, ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುವುದು, ಪರಿಶೀಲಿಸುವುದು ಮತ್ತು ದುರಸ್ತಿ ಮಾಡುವುದು. ಆರಂಭಿಸಿದಾಗ, ಅಥವಾ ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ಗೆ ಅಟ್ಯಾಚ್ ಆದಾಗ, ಅದು ಮುಚ್ಚುತ್ತದೆ; ಖಾತೆ ಸೇರಿಸುವಾಗ ಅಥವಾ ಲಾಗಿನ್ ಮಾಡುವಾಗ ಅದು ಟರ್ಮಿನಲ್‌ಗೆ ಜಾಗ ಬಿಟ್ಟು ನಂತರ ಮರಳುತ್ತದೆ.

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Agents   Groups   Folders   Extensions   Health
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

ಟ್ಯಾಬ್ ಹೆಸರುಗಳ ಕೆಳಗಿನ ಸಾಲು ಈಗಿನ ಟ್ಯಾಬ್ ಯಾವುದಕ್ಕಾಗಿ ಎಂದು ಒಂದು ವಾಕ್ಯದಲ್ಲಿ ಹೇಳುತ್ತದೆ. ಅಗಲವಾದ ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ Accounts ಟ್ಯಾಬ್ ಪ್ರತಿ ಖಾತೆಯ ಇಮೇಲ್ ಅನ್ನೂ ತೋರಿಸುತ್ತದೆ.

ತೆರೆದ ಪ್ರತಿ ಬಾರಿ, ಹೊಸ ccam ಬಿಡುಗಡೆ ಇದೆಯೇ ಎಂದು ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಹಿನ್ನೆಲೆಯಲ್ಲಿ GitHub ಗೆ ಕೇಳುತ್ತದೆ; ಮೊದಲ ಚೌಕಟ್ಟು ಅದಕ್ಕಾಗಿ ಎಂದಿಗೂ ಕಾಯುವುದಿಲ್ಲ, ಮತ್ತು ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಏನನ್ನೂ ತೋರಿಸುವುದಿಲ್ಲ. ಹೊಸ ಬಿಡುಗಡೆ ಇದ್ದಾಗ, ಶೀರ್ಷಿಕೆಯ ಕೆಳಗಿನ ಒಂದು ಸಾಲು ಅದನ್ನು ಶಿಫಾರಸು ಮಾಡುತ್ತದೆ:

```console
 ● ccam 0.10.2 is available (you have 0.10.1) · press U to update
```

`U` ಮೊದಲು ಕೇಳುತ್ತದೆ, ನಂತರ [`ccam update`](/features/update) ಮಾಡುವ ರೀತಿಯಲ್ಲೇ ಅಪ್‌ಡೇಟ್ ಮಾಡುತ್ತದೆ: ಬಿಡುಗಡೆಯನ್ನು ಅದರ SHA-256 checksums ಜೊತೆ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಅದು ಒಂದೇ ಹಂತದಲ್ಲಿ ccam ಅನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ. ನೀವು ಇರುವ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಇನ್ನೂ ಹಳೆಯ ಆವೃತ್ತಿಯೇ, ಹೀಗಾಗಿ ಹೊರಬಂದು `ccam` ಅನ್ನು ಮತ್ತೆ ಪ್ರಾರಂಭಿಸಿ. ಅಪ್‌ಡೇಟ್ ಅನ್ನು ಇಲ್ಲಿ ಮಾಡಲು ಸಾಧ್ಯವಾಗದಿದ್ದಾಗ, ಉದಾಹರಣೆಗೆ `.deb` ಪ್ಯಾಕೇಜ್‌ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿದ ccam ಗೆ, ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ `ccam update` ನೀಡುವ ಅದೇ ಸಲಹೆಯನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಕೊಡುಗೆಯನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ.

ಮೊದಲ ಚೌಕಟ್ಟು `config.toml` ಒಂದರಿಂದಲೇ, 100 ms ಗಿಂತ ತುಂಬಾ ಕಡಿಮೆ ಸಮಯದಲ್ಲಿ ಮೂಡುತ್ತದೆ; ಪ್ರತಿ ಖಾತೆ ಉತ್ತರಿಸಿದಂತೆ ಬಳಕೆ ತುಂಬಿಕೊಳ್ಳುತ್ತದೆ. ಪ್ರತಿ ಮಿತಿಗೆ ತನ್ನದೇ ಬಾರ್ ಇದೆ: 5 ಗಂಟೆಯ ಅವಧಿ, ಎಲ್ಲಾ ಮಾಡೆಲ್‌ಗಳ ವಾರದ ಅವಧಿ, ಮತ್ತು Fable ನ ಸ್ವಂತ ವಾರದ ಅವಧಿ; `-` ಎಂದರೆ ಖಾತೆಗೆ ಅಂತಹ ಅವಧಿ ಇಲ್ಲ. ಶೇಕಡಾವಾರು 80% ನಿಂದ ಹಳದಿ ಮತ್ತು 100% ನಲ್ಲಿ ಕೆಂಪು ಆಗುತ್ತದೆ, ಮತ್ತು ವಿಫಲವಾದ ಹುಡುಕಾಟದ ನಂತರ ಕ್ಯಾಶ್‌ನಿಂದ ಬಂದ ಮೌಲ್ಯಗಳನ್ನು ಮಸುಕಾಗಿ ತೋರಿಸಲಾಗುತ್ತದೆ. Claude Code ತುಂಬಿದೆ ಎಂದು ವರದಿ ಮಾಡಿದ ಅವಧಿ ಅದರ ರೀಸೆಟ್‌ವರೆಗೆ 100% ತೋರಿಸುತ್ತದೆ. ಅವಧಿ ಮುಗಿದ ಆಕ್ಸೆಸ್ ಟೋಕನ್ ಮಸುಕಾದ `⚠ token expired` ತೋರಿಸುತ್ತದೆ (ಮುಂದಿನ ಆರಂಭದಲ್ಲಿ Claude Code ಅದನ್ನು ನವೀಕರಿಸುತ್ತದೆ), ಆದರೆ `⚠ login expired` ಎಂದರೆ ಖಾತೆಗೆ `ccam login` ಬೇಕು.

## ಟ್ಯಾಬ್‌ಗಳು

| ಟ್ಯಾಬ್ | ಏನನ್ನು ತೋರಿಸುತ್ತದೆ | ಕೀಗಳು |
| --- | --- | --- |
| Accounts | ಸಂಖ್ಯೆ, ಹೆಸರು, ಇಮೇಲ್, 5 ಗಂಟೆಯ, ವಾರದ ಮತ್ತು Fable ಬಾರ್‌ಗಳು, ಕೊನೆಯ ಬಳಕೆ, ಗುಂಪುಗಳು; `✔` ಡೀಫಾಲ್ಟ್, `▸` ಈ ಫೋಲ್ಡರ್‌ನ ಖಾತೆ, `•` ಚಾಲನೆಯಲ್ಲಿದೆ (ccam ಇಲ್ಲದೆ ಆರಂಭಿಸಿದ Claude Code ಕೂಡ: ಸಾಮಾನ್ಯ `claude`, IDE, ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ಗಳು ಮತ್ತು ಅವುಗಳ daemon) | ಕೆಳಗೆ |
| Agents | [`ccam agents`](/features/agents) ಪಟ್ಟಿ ಮಾಡುವುದು: ಪ್ರತಿ ಖಾತೆಯ ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ಗಳು ಮತ್ತು ತೆರೆದ ಸೆಷನ್‌ಗಳು, ಅವುಗಳ ಸ್ಥಿತಿ, ಫೋಲ್ಡರ್ ಮತ್ತು ಆರಂಭದ ಸಮಯದೊಂದಿಗೆ (ಕೆಳಗೆ) | `enter` ಅಟ್ಯಾಚ್ (`ccam attach` ನಂತೆ), `x` ನಿಲ್ಲಿಸು, `r` ಮತ್ತೆ ಲೋಡ್ |
| Groups | ಪ್ರತಿ ಗುಂಪು, ಅದು ಏನನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತದೆ ಮತ್ತು ಅದರ ಖಾತೆಗಳು, ಹಾಗೂ ಯಾವ ಗುಂಪಿನಲ್ಲೂ ಇಲ್ಲದ ಖಾತೆಗಳು | `enter` ಸಂಪಾದನೆ, `n` ಹೊಸದು, `e` ಮರುಹೆಸರು, `x` ತೆಗೆದುಹಾಕು |
| Folders | [`ccam folder`](/features/folder) ನಿಯಮಗಳು ಮತ್ತು ಇಲ್ಲಿ ಅನ್ವಯವಾಗುವ ನಿಯಮ, ನೀವು ಸಿಂಬಾಲಿಕ್ ಲಿಂಕ್ ಮೂಲಕ ಫೋಲ್ಡರ್ ತಲುಪಿದ್ದರೂ ಸಹ (ಹೊಸ ನಿಯಮಗಳನ್ನು ಲಿಂಕ್‌ಗಳನ್ನು ಪರಿಹರಿಸಿದ ಪಾತ್‌ನೊಂದಿಗೆ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ) | `n` ಇಲ್ಲಿ ಒಂದು ಖಾತೆ ಬಳಸು, `enter` ಬದಲಾಯಿಸು, `x` ತೆಗೆದುಹಾಕು |
| Extensions | [`ccam ext`](/features/ext) ತೋರಿಸುವುದು: ಪ್ರತಿ ವಿಸ್ತರಣೆಯನ್ನು ಒಮ್ಮೆ ಅದು ಬರುವ ಗುಂಪುಗಳೊಂದಿಗೆ, `off:` ಪ್ಲಗಿನ್ ಆನ್ ಆಗಿರದ ಖಾತೆಗಳು, ಖಾತೆಯ ಸ್ವಂತ ಸರ್ವರ್‌ಗಳಲ್ಲಿ ಈ ಫೋಲ್ಡರ್‌ಗೆ ಮಾತ್ರ ಇರುವವು, `This folder's project`, ಮತ್ತು ಯಾವುದೇ ಖಾತೆಗೆ ಸೇರದ ಸಮಸ್ಯೆಗಳು | `r` ಮತ್ತೆ ಲೋಡ್ |
| Health | [`ccam doctor`](/features/doctor) ವರದಿ ಮಾಡುವುದು, ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಬಾಕ್ಸ್ ಆಗಿ (ಕೆಳಗೆ) | `f` ಆಯ್ಕೆಮಾಡಿದ ಬಾಕ್ಸ್ ದುರಸ್ತಿ, `F` ಎಲ್ಲವನ್ನೂ ದುರಸ್ತಿ (`doctor --fix`), `↑`/`↓` ಬಾಕ್ಸ್‌ಗಳ ನಡುವೆ ಸರಿಸುತ್ತದೆ |

`←`/`→` ಅಥವಾ `Tab` ಟ್ಯಾಬ್‌ಗಳನ್ನು ಬದಲಾಯಿಸುತ್ತವೆ, `?` ಈಗಿನ ಟ್ಯಾಬ್‌ನ ಕೀಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ, `r` ಅಲ್ಪಾವಧಿ ಕ್ಯಾಶ್ ಇಲ್ಲದೆ ಬಳಕೆಯನ್ನು ಮತ್ತೆ ಹುಡುಕುತ್ತದೆ ಮತ್ತು Agents, Extensions ಹಾಗೂ Health ಟ್ಯಾಬ್‌ಗಳನ್ನು ಮತ್ತೆ ಲೋಡ್ ಮಾಡುತ್ತದೆ, ಮತ್ತು `q` ಅಥವಾ `Esc` ನಿರ್ಗಮಿಸುತ್ತದೆ.

## Accounts ಟ್ಯಾಬ್‌ನ ಕೀಗಳು

| ಕೀ | ಏನು ಮಾಡುತ್ತದೆ |
| --- | --- |
| `Enter` | ಆಯ್ಕೆಮಾಡಿದ ಖಾತೆಯಾಗಿ Claude Code ಆರಂಭಿಸುತ್ತದೆ |
| `1`–`9` | ಆ ಸಂಖ್ಯೆಯ ಖಾತೆಗೆ ಹೋಗುತ್ತದೆ; 12 ಕ್ಕಾಗಿ `1` `2` ಅನ್ನು ಬೇಗ ಟೈಪ್ ಮಾಡಿ. `Enter` ಮಾತ್ರ ಆರಂಭಿಸುತ್ತದೆ |
| `↑`/`↓`, `k`/`j` | ಸರಿಸುತ್ತದೆ |
| `n` | [`ccam next --auto`](/features/next) ಆಯ್ಕೆಮಾಡುವ ಖಾತೆಯನ್ನು ಆರಂಭಿಸುತ್ತದೆ |
| `o` | ಆಯ್ಕೆಗಳೊಂದಿಗೆ ಆರಂಭಿಸುತ್ತದೆ: `--continue`, `--resume`, ಇತರ ಆರ್ಗ್ಯುಮೆಂಟ್‌ಗಳು, ಅಥವಾ ಡ್ರೈ ರನ್ |
| `u` | ಬಳಕೆಯ ವಿವರಗಳು: 5 ಗಂಟೆಯ, ವಾರದ ಮತ್ತು ಮಾಡೆಲ್ ವಿಂಡೋಗಳು, ಅವುಗಳ ರೀಸೆಟ್‌ಗಳು ಮತ್ತು ಸಂಖ್ಯೆಗಳು ಎಲ್ಲಿಂದ ಬರುತ್ತವೆ |
| `a` | ಖಾತೆ ಸೇರಿಸುತ್ತದೆ (ಕೆಳಗಿನ ವಿಜಾರ್ಡ್) |
| `l` | ಮತ್ತೆ ಲಾಗಿನ್ ಮಾಡುತ್ತದೆ |
| `s` | ಖಾತೆಯ ಗುಂಪುಗಳನ್ನು ಆಯ್ಕೆಮಾಡುತ್ತದೆ |
| `d` | ಅದನ್ನು ಡೀಫಾಲ್ಟ್ ಖಾತೆ ಮಾಡುತ್ತದೆ |
| `f` | ಅದನ್ನು ಈಗಿನ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಬಳಸುತ್ತದೆ |
| `e` | ಅದನ್ನು ಮರುಹೆಸರಿಸುತ್ತದೆ |
| `c` | ಅದರ ಶಾರ್ಟ್‌ಕಟ್ ಕಮಾಂಡ್ ಅನ್ನು ಹೊಂದಿಸುತ್ತದೆ ಅಥವಾ ತೆಗೆದುಹಾಕುತ್ತದೆ |
| `x` | ಅದನ್ನು ತೆಗೆದುಹಾಕುತ್ತದೆ (ಮೊದಲು ಕೇಳುತ್ತದೆ, No ಮೇಲೆ ಆರಂಭಿಸಿ) |

**Team ಮತ್ತು Enterprise ಸೀಟುಗಳು.** ಸ್ವಯಂಚಾಲಿತ ಆಯ್ಕೆ (`ccam next`, `--fallback`, `ccam pick`, ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನ `n`, ಮತ್ತು ನೀವು ಆನ್ ಮಾಡಿದಾಗ [`auto_switch`](/features/next#auto-switch)) ಒಂದೇ Claude Team ಅಥವಾ Enterprise ಸಂಸ್ಥೆಯ ಸೀಟುಗಳ ನಡುವೆಯೂ ಬದಲಾಯಿಸುತ್ತದೆ. Anthropic ನ ಸಹಾಯ ಕೇಂದ್ರವು "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (Team ಪ್ಲಾನ್‌ನ ಪ್ರತಿ ಸೀಟನ್ನು ಹೆಸರಿಸಲಾದ ಒಬ್ಬ ವ್ಯಕ್ತಿಗೆ ನಿಯೋಜಿಸಲಾಗುತ್ತದೆ, ಮತ್ತು ಆ ವ್ಯಕ್ತಿ ಮಾತ್ರ ಅದನ್ನು ಬಳಸಬಹುದು) ಮತ್ತು "Users can't route their work through another user's account to use that user's remaining usage" (ಬಳಕೆದಾರರು ಇನ್ನೊಬ್ಬ ಬಳಕೆದಾರರ ಉಳಿದಿರುವ ಬಳಕೆಯನ್ನು ಉಪಯೋಗಿಸಿಕೊಳ್ಳಲು ತಮ್ಮ ಕೆಲಸವನ್ನು ಅವರ ಖಾತೆಯ ಮೂಲಕ ನಡೆಸುವಂತಿಲ್ಲ) ಎಂದು ಹೇಳುತ್ತದೆ ([Team ಪ್ಲಾನ್‌ಗಳು](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129); [Enterprise ಪ್ಲಾನ್‌ಗಳಿಗೂ](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) ಇದೇ ಅನ್ವಯಿಸುತ್ತದೆ). ಆದ್ದರಿಂದ ಸೀಟುಗಳ ನಡುವೆ ಸ್ವಯಂಚಾಲಿತ ಆಯ್ಕೆಯನ್ನು ಬಳಸುವುದು Anthropic ನ ನಿಯಮಗಳನ್ನು ಉಲ್ಲಂಘಿಸಬಹುದು. ಅಲ್ಲಿ ಇದನ್ನು ಬಳಸಬೇಕೆ ಎಂಬುದು ನಿಮ್ಮ ನಿರ್ಧಾರ: ಇದನ್ನು ಅವಲಂಬಿಸುವ ಮೊದಲು ನಿಮ್ಮ ಸಂಸ್ಥೆ ಮತ್ತು Anthropic ಬಳಿ ವಿಚಾರಿಸಿ ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ. ವೈಯಕ್ತಿಕ ಪ್ಲಾನ್‌ಗಳ (Pro, Max) ಬಗ್ಗೆ [ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳಲ್ಲಿನ ನಿಯಮಗಳ ಟಿಪ್ಪಣಿ](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) ತಿಳಿಸುತ್ತದೆ.

## Health ಟ್ಯಾಬ್

ನೀವು Health ಟ್ಯಾಬ್ ತೆರೆದಾಗ ಅದು [`ccam doctor`](/features/doctor) ನ ಪರಿಶೀಲನೆಗಳನ್ನು ನಡೆಸುತ್ತದೆ ಮತ್ತು ಅದೇ ನೋಟವನ್ನು ತೋರಿಸುತ್ತದೆ: ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಗುರುತು ಇರುವ ಮೊದಲ ಸಾಲು, ನಂತರ ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಬಾಕ್ಸ್. ಬಾಕ್ಸ್‌ನ ಪ್ರತಿ ಸಾಲು ಪರಿಶೀಲಿಸಿದ ಒಂದು ಕ್ಷೇತ್ರ, ಮೊದಲು `Folder`, `Login` ಮತ್ತು `Share links`, ಗುರುತುಗಳೊಂದಿಗೆ: `✔` ಸರಿ, `ℹ` ಮಾಹಿತಿ, `⚠` ಎಚ್ಚರಿಕೆ ಅಥವಾ `✘` ದೋಷ; ಹೀಗಾಗಿ ಯಾವ ಖಾತೆಗೆ ಸಮಸ್ಯೆ ಇದೆ ಮತ್ತು ಎಲ್ಲಿ ಎಂದು ನೀವು ತಕ್ಷಣ ನೋಡುತ್ತೀರಿ. ಯಾವುದೇ ಖಾತೆಗೆ ಸೇರದ ಫಲಿತಾಂಶಗಳು `General` ಬಾಕ್ಸ್‌ಗೆ ಹೋಗುತ್ತವೆ.

```console
 ✘ personal   ⚠ work

 ╭─ ✘ personal · 3 problems ─────────────────────────────────────────────────╮
 │ ⚠ Folder       folder permissions are 755 (should be 0700)                │
 │ ℹ              unknown entries (ccam knows the folder layout of Claude    │
 │                Code 2.1.309; it may have changed): newthing               │
 │ ⚠ Login        .credentials.json permissions are 644 (should be 0600)     │
 │ ✔              login valid (me@example.com, Claude Team · Acme)           │
 │ ✘ Share links  /home/me/.local/share/ccam/profiles/personal/settings.json │
 │                : set to shared but is a real file, not a link             │
 │ ✔ Usage        usage lookup OK                                            │
 ╰───────────────────────────────────────────────────────────────────────────╯
 ╭─ ⚠ work · 1 problem ──────────────────────────────────────────────────────╮
 │ ✔ Folder       OK                                                         │
 │ ⚠ Login        not logged in → `ccam login work`                          │
 │ ✔ Share links  share links OK                                             │
 ╰───────────────────────────────────────────────────────────────────────────╯

 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` ಒಂದು ಬಾಕ್ಸ್‌ನಿಂದ ಇನ್ನೊಂದಕ್ಕೆ ಸರಿಸುತ್ತವೆ, ಮತ್ತು ಆಯ್ಕೆಮಾಡಿದ ಬಾಕ್ಸ್‌ಗೆ ಆಕ್ಸೆಂಟ್ ಬಣ್ಣದ ಅಂಚು ಇರುತ್ತದೆ. `f` ಆಯ್ಕೆಮಾಡಿದ ಬಾಕ್ಸ್ ಅನ್ನು ಮಾತ್ರ ದುರಸ್ತಿ ಮಾಡುತ್ತದೆ, `ccam doctor --fix` ಮಾಡುವ ರೀತಿಯಲ್ಲೇ: ಒಂದು ಖಾತೆಯ ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಅದು ಆ ಖಾತೆಯನ್ನು ಮಾತ್ರ ದುರಸ್ತಿ ಮಾಡುತ್ತದೆ, ಮತ್ತು `General` ಬಾಕ್ಸ್‌ನಲ್ಲಿ ಯಾವುದೇ ಖಾತೆಗೆ ಸೇರದ ಫಲಿತಾಂಶಗಳನ್ನು (ಪ್ಲಗಿನ್ ಪಾತ್‌ಗಳು ಮತ್ತು ಶಾರ್ಟ್‌ಕಟ್‌ಗಳು); ಉಳಿದ ಪ್ರತಿ ಖಾತೆಯನ್ನು ಮತ್ತೆ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ ಅಷ್ಟೇ. ಅದು ಮೊದಲು ಕೇಳುತ್ತದೆ (``Like `ccam doctor --fix`: missing links and group folders are made, and a real file where a link belongs is backed up first; where the group has its own copy, the account then sees the group's. Nothing is lost.``), ಮತ್ತು ದುರಸ್ತಿ ಮಾಡಲು ಏನೂ ಇಲ್ಲದ ಬಾಕ್ಸ್ `nothing to repair in <name>` ಎಂದು ಮಾತ್ರ ಹೇಳುತ್ತದೆ. `F` ಎಲ್ಲವನ್ನೂ ಒಮ್ಮೆಗೇ ದುರಸ್ತಿ ಮಾಡುತ್ತದೆ, `ccam doctor --fix` ನಂತೆ, ಮತ್ತು `r` ಮತ್ತೆ ಪರಿಶೀಲಿಸುತ್ತದೆ.

## Agents ಟ್ಯಾಬ್

Agents ಟ್ಯಾಬ್ [`ccam agents`](/features/agents) ಮುದ್ರಿಸುವುದನ್ನು ತೋರಿಸುತ್ತದೆ: ಪ್ರತಿ ಖಾತೆಯ ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ಗಳು ಮತ್ತು ತೆರೆದ ಸೆಷನ್‌ಗಳು, ಪ್ರತಿಯೊಂದೂ ಸೇರಿರುವ ಖಾತೆಯೊಂದಿಗೆ. ನೀವು ಟ್ಯಾಬ್ ಅನ್ನು ಮೊದಲ ಬಾರಿ ತೆರೆದಾಗ, `r` ಒತ್ತಿದಾಗ, ಒಂದು ಸೆಷನ್ ನಿಲ್ಲಿಸಿದ ನಂತರ, ಮತ್ತು ಕಾನ್ಫಿಗ್ ಬದಲಾದ ನಂತರ ಅದು ಪ್ರತಿ ಖಾತೆಯ Claude Code ಅನ್ನು ಒಮ್ಮೆಗೇ ಕೇಳುತ್ತದೆ (`claude agents --json`, ಪ್ರತಿಯೊಂದಕ್ಕೂ 15 ಸೆಕೆಂಡ್‌ಗಳವರೆಗೆ), ಮತ್ತು ಎಲ್ಲವೂ ಉತ್ತರಿಸುವವರೆಗೆ `Asking every account's Claude Code for its sessions…` ಎಂದು ಹೇಳುತ್ತದೆ.

```console
  Accounts   Agents   Groups   Folders   Extensions   Health
 Background agents and open sessions of every account; enter attaches to one.

    Account   ID        Name   State          Folder      Started
 ❯  work      -         -      open (busy)    ~/code/web  now
    personal  49ec0028  probe  blocked, idle  ~/code/app  12m

 ✘ lab: could not list its sessions: exit status 1 'claude agents --json' is
   not available in this environment.

 enter to attach · x to stop · r to reload · ? for shortcuts
```

`State` ಎಂದರೆ ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ನ ಸ್ಥಿತಿ ಮತ್ತು ಅದರ ಪ್ರೊಸೆಸ್ ಏನು ಮಾಡುತ್ತಿದೆ ಎಂಬುದು, ಅಥವಾ ಇಂಟರ್‌ಆಕ್ಟಿವ್ ಸೆಷನ್‌ಗೆ `open`, `ccam agents` ನಲ್ಲಿರುವಂತೆ. ಕೇಳಲು ಸಾಧ್ಯವಾಗದ ಖಾತೆಗೆ ಪಟ್ಟಿಯ ಕೆಳಗೆ Claude Code ಹೇಳಿದ್ದನ್ನು ಒಳಗೊಂಡ `✘` ಸಾಲು ಸಿಗುತ್ತದೆ, ಮೇಲಿನ `lab` ನಂತೆ, ಅದರ agent view ಆಫ್ ಆಗಿದೆ. ಮುಗಿದ ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ಗಳನ್ನು ಬಿಡಲಾಗುತ್ತದೆ (`ccam agents --all` ಅವನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ), ಮತ್ತು ಎಲ್ಲಾ ಖಾತೆಗಳು ಉತ್ತರಿಸಿ ಯಾವುದಕ್ಕೂ ಸೆಷನ್ ಇಲ್ಲದಿದ್ದಾಗ, ಟ್ಯಾಬ್ ``No sessions. Start one in the background with `ccam <account> --bg "…"`.`` ಎಂದು ಹೇಳುತ್ತದೆ. ಕಿರಿದಾದ ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ಟ್ಯಾಬ್ ಮೊದಲು `Started`, ನಂತರ `Name`, ನಂತರ `Folder` ಅನ್ನು ಕೈಬಿಡುತ್ತದೆ, ಮತ್ತು ಉದ್ದವಾದ ಫೋಲ್ಡರ್ ಅನ್ನು ಎಡದಿಂದ ಕತ್ತರಿಸುತ್ತದೆ.

ಹಿನ್ನೆಲೆ ಸೆಷನ್‌ನ ಮೇಲೆ `Enter` ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಅನ್ನು ಮುಚ್ಚಿ, ಸೆಷನ್ ಅನ್ನು ಈ ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ಅದರ ಖಾತೆಯಾಗಿ ತೆರೆಯುತ್ತದೆ, `ccam attach <id>` ಮಾಡುವಂತೆಯೇ; ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಮರಳುವುದಿಲ್ಲ (Claude Code ನಲ್ಲಿ, `←` ಅದರ agent view ಗೆ ಮತ್ತು `Ctrl+Z` ಶೆಲ್‌ಗೆ ಕರೆದೊಯ್ಯುತ್ತದೆ). ತೆರೆದ ಸೆಷನ್‌ಗೆ id ಇಲ್ಲ, ಆದ್ದರಿಂದ `Enter` ಮತ್ತು `x` ಹಿನ್ನೆಲೆ ಸೆಷನ್ ಬೇಕು ಎಂದು ಮಾತ್ರ ಹೇಳುತ್ತವೆ. `x` ಮೊದಲು ಕೇಳುತ್ತದೆ, `No, keep it` ನಿಂದ ಆರಂಭಿಸಿ: ``It runs as personal. Like `ccam personal stop 49ec0028`, Claude Code stops it and keeps its conversation, which `ccam attach 49ec0028` opens again.`` ಹೌದು ಎಂದರೆ, ccam ಆ ಖಾತೆಯಾಗಿ `claude stop <id>` ರನ್ ಮಾಡುತ್ತದೆ, ``49ec0028 (personal) stopped; `ccam attach 49ec0028` opens it again`` ಅಥವಾ ಏಕೆ ಸಾಧ್ಯವಾಗಲಿಲ್ಲ ಎಂದು ಹೇಳುತ್ತದೆ, ಮತ್ತು ಪಟ್ಟಿಯನ್ನು ಮತ್ತೆ ಓದುತ್ತದೆ.

## ಗುಂಪುಗಳನ್ನು ಬದಲಾಯಿಸುವುದು

Groups ಟ್ಯಾಬ್‌ನಲ್ಲಿ, `Enter` ಸಂಪಾದಕವನ್ನು ತೆರೆಯುತ್ತದೆ: ಎಡಕ್ಕೆ ಐಟಂಗಳು, ಬಲಕ್ಕೆ ಖಾತೆಗಳು, ಬದಲಾಯಿಸಲು `Tab`, ಆನ್/ಆಫ್ ಮಾಡಲು `Space`. ಖಾತೆಗಳಲ್ಲಿ ಒಂದು ಈಗಾಗಲೇ ಇನ್ನೊಂದು ಗುಂಪಿನಿಂದ ಪಡೆಯುತ್ತಿರುವ ಐಟಂ ಅನ್ನು ಕಾರಣದೊಂದಿಗೆ ಬೂದು ಬಣ್ಣದಲ್ಲಿ ತೋರಿಸಲಾಗುತ್ತದೆ, ಒಂದು ಐಟಂ ಅನ್ನು ಎರಡು ಬಾರಿ ಪಡೆಯಲಿರುವ ಖಾತೆಯನ್ನೂ ಹಾಗೆಯೇ; ಒಂದು ಐಟಂ ಒಂದೇ ಗುಂಪಿನಿಂದ ಬರಬಹುದು. `Enter` ಯೋಜನೆಯನ್ನು ತೋರಿಸುತ್ತದೆ:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

ಗುಂಪಿನ ಪ್ರತಿಗಿಂತ ಬೇರೆಯಾಗಿರುವ ಫೈಲ್ ಬಗ್ಗೆ ಮೊದಲು ಕೇಳಲಾಗುತ್ತದೆ (ಗುಂಪಿನದನ್ನು ಉಳಿಸುವುದು, ನನ್ನದನ್ನು ಬಳಸುವುದು, ಅಥವಾ ವಿಲೀನಗೊಳಿಸುವುದು). ನಂತರ ಬದಲಾವಣೆ [`ccam group`](/features/share) ನ ಅದೇ ಕೋಡ್‌ನೊಂದಿಗೆ ಹಿನ್ನೆಲೆಯಲ್ಲಿ ರನ್ ಆಗುತ್ತದೆ: ಕಾನ್ಫಿಗ್ ಅನ್ನು ಮೊದಲು ಉಳಿಸಲಾಗುತ್ತದೆ, ಪ್ರತಿ ಖಾತೆಯ ಡೇಟಾ ಕ್ರಮವಾಗಿ ಸ್ಥಳಾಂತರಗೊಳ್ಳುತ್ತದೆ, ಮತ್ತು ಮೂಲ ಫೈಲ್‌ಗಳು `.ccam-backup/` ಗೆ ಹೋಗುತ್ತವೆ; MCP ಹಂಚಿಕೆಯನ್ನು ಬಿಡುವ ಖಾತೆ ಗುಂಪಿನ ಸರ್ವರ್‌ಗಳನ್ನು ತನ್ನ `.claude.json` ನಲ್ಲಿ ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ. ಚಾಲನೆಯಲ್ಲಿರುವ ಖಾತೆಯ ಡೇಟಾವನ್ನು ಸ್ಥಳಾಂತರಿಸಲಿರುವ ಬದಲಾವಣೆಯನ್ನು ಆ ಖಾತೆಯ ಹೆಸರಿನೊಂದಿಗೆ ನಿರಾಕರಿಸಲಾಗುತ್ತದೆ, ಯೋಜನೆ ತೆರೆದಿದ್ದಾಗ ಖಾತೆ ಆರಂಭವಾದರೂ ಸಹ; ಮತ್ತು ಇನ್ನೊಂದು ccam ನ ಗುಂಪುಗಳ ಬದಲಾವಣೆಯಿಂದ ಹಳತಾದ ಯೋಜನೆಯನ್ನು `the groups changed while this plan waited; nothing was moved, make the change again` ಎಂದು ನಿರಾಕರಿಸಲಾಗುತ್ತದೆ. ಇನ್ನೊಂದು ccam ಗುಂಪುಗಳನ್ನು ಬದಲಾಯಿಸುತ್ತಿರುವಾಗ, ಹೊಸ ಬದಲಾವಣೆ, ಮರುಹೆಸರು ಅಥವಾ ತೆಗೆದುಹಾಕುವಿಕೆ `another ccam is changing the groups right now` ಎಂದು ಹೇಳುತ್ತದೆ; ಅರ್ಧದಲ್ಲಿ ನಿಂತ ಬದಲಾವಣೆಯ ನಂತರ, Health ಟ್ಯಾಬ್‌ನಲ್ಲಿನ `F` (ಅಥವಾ `ccam doctor --fix`) ಅದನ್ನು ಪೂರ್ಣಗೊಳಿಸುವವರೆಗೆ ಅವು ಕಾಯುತ್ತವೆ.

## ಖಾತೆ ಸೇರಿಸುವುದು

`a` ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ `ccam add` ಕೂಡ ಬಳಸುವ ವಿಜಾರ್ಡ್ ಅನ್ನು ತೆರೆಯುತ್ತದೆ:

1. ಖಾತೆಯ ಹೆಸರು.
2. ಅದು ಹೇಗೆ ಸೈನ್ ಇನ್ ಆಗುತ್ತದೆ: ಈಗಲೇ Claude ಚಂದಾದಾರಿಕೆ (ಬ್ರೌಸರ್‌ನಲ್ಲಿ), [API ಕೀ](/features/api), ಅಥವಾ ನಂತರ Claude ಚಂದಾದಾರಿಕೆ.
3. API ಕೀಗಾಗಿ: ಪ್ರತಿ ಆರಂಭದಲ್ಲಿ ccam ಕೀಯನ್ನು ಎಲ್ಲಿಂದ ಓದುತ್ತದೆ (`env:NAME` ಅಥವಾ `command:COMMAND`), ಎಂಡ್‌ಪಾಯಿಂಟ್, ಕೀಯನ್ನು ಹೇಗೆ ಕಳುಹಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಮಾಡೆಲ್.
4. ಸೇರಬೇಕಾದ ಗುಂಪುಗಳು, `default` ಗುರುತಿಸಿದ ಸ್ಥಿತಿಯಲ್ಲಿ; ಗುಂಪುಗಳು ಇನ್ನೂ ಇಲ್ಲದಿದ್ದರೆ, `default` ಗುಂಪು ಏನನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತದೆ ಎಂಬುದು.
5. ನಿಮಗೆ ಬೇಕಿದ್ದರೆ, ಒಂದು ಶಾರ್ಟ್‌ಕಟ್ ಕಮಾಂಡ್.
6. ಖಚಿತಪಡಿಸಲು ಒಂದು ಸಾರಾಂಶ.

`Esc` ಒಂದು ಹಂತ ಹಿಂದಕ್ಕೆ ಹೋಗುತ್ತದೆ, ಮತ್ತು ಮೊದಲ ಹಂತದಲ್ಲಿ ವಿಜಾರ್ಡ್ ಅನ್ನು ಮುಚ್ಚುತ್ತದೆ.

## ಖಾತೆ ತೆಗೆದುಹಾಕುವುದು

ಏನಾದರೂ ಆಗುವ ಮೊದಲು `x` ಕೇಳುತ್ತದೆ, No ಮೇಲೆ ಆರಂಭಿಸಿ, ಮತ್ತು ತೆಗೆದುಹಾಕುವಿಕೆ ಏನು ಮಾಡುತ್ತದೆ ಎಂದು ತಿಳಿಸುತ್ತದೆ: `It is logged out first (its login is revoked), then its folder goes to ccam's trash; the groups' shared files stay.` API ಕೀ ಖಾತೆಗೆ ರದ್ದುಗೊಳಿಸಲು ಲಾಗಿನ್ ಇಲ್ಲ, ಮತ್ತು ಇನ್ನೊಂದು ಖಾತೆ ಅದೇ ಲಾಗಿನ್ ಹೊಂದಿದ್ದಾಗ ಖಾತೆಯನ್ನು ಲಾಗ್ ಔಟ್ ಮಾಡಲಾಗುವುದಿಲ್ಲ. ಇಂಪೋರ್ಟ್ ಮಾಡಿದ ಖಾತೆ ತನ್ನ ಫೋಲ್ಡರ್ ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ: `It was imported, so its folder /home/me/.claude stays where it is: it leaves its groups first and keeps a copy of what they share, then ccam forgets it.`

## ಬಣ್ಣಗಳು

ಬಣ್ಣಗಳು Claude Code ನ ಟರ್ಮಿನಲ್ UI ನ ಪಾತ್ರಗಳನ್ನು ಅನುಸರಿಸುತ್ತವೆ, ಹೀಗಾಗಿ ccam ಅದರ ಪಕ್ಕದಲ್ಲಿ ಸಹಜವಾಗಿ ಕಾಣುತ್ತದೆ; ಗುಂಪಿನ ಹೆಸರುಗಳಿಗೆ ಅವುಗಳ ಹೆಸರಿನಿಂದಲೇ ಒಂದು ಬಣ್ಣ ಸಿಗುತ್ತದೆ. ccam ಟರ್ಮಿನಲ್‌ನಿಂದ ಅದರ ಹಿನ್ನೆಲೆಯನ್ನು ಕೇಳಿ ತಿಳಿ ಅಥವಾ ಗಾಢ ಥೀಮ್ ಆಯ್ಕೆಮಾಡುತ್ತದೆ. `config.toml` ನ ಮೇಲ್ಭಾಗದಲ್ಲಿ, ಮೊದಲ `[[group]]`, `[[profile]]` ಅಥವಾ `[[folder]]` ಗಿಂತ ಮೇಲೆ, ನೀವೇ ಒಂದನ್ನು ಹೊಂದಿಸಿ:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` ಥೀಮ್‌ಗಳು ಕೆಂಪು-ಹಸಿರು ಬಣ್ಣಗುರುಡುತನಕ್ಕಾಗಿ, ಮತ್ತು `-ansi` ಥೀಮ್‌ಗಳು ಟರ್ಮಿನಲ್‌ನ ಸ್ವಂತ 16 ಬಣ್ಣಗಳನ್ನು ಬಳಸುತ್ತವೆ. `NO_COLOR` ಬಣ್ಣಗಳನ್ನು ಆಫ್ ಮಾಡುತ್ತದೆ.

## ಸುರಕ್ಷತೆ ಮತ್ತು ವಿಶೇಷ ಸಂದರ್ಭಗಳು

- ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಕಮಾಂಡ್‌ಗಳ ಅದೇ ಫಂಕ್ಷನ್‌ಗಳನ್ನು ಕರೆಯುತ್ತದೆ, ಹೀಗಾಗಿ ಪ್ರತಿ ನಿಯಮವೂ ಅನ್ವಯಿಸುತ್ತದೆ: ಡೇಟಾ ಸ್ಥಳಾಂತರಕ್ಕೆ ಮೊದಲು ಯೋಜನೆಗಳು, ಚಾಲನೆಯಲ್ಲಿರುವ ಖಾತೆಗಳಿಗೆ ನಿರಾಕರಣೆ, ಬ್ಯಾಕಪ್‌ಗಳು, ಮತ್ತು ಖಾತೆಯಿಂದ ಎಂದಿಗೂ ಹೊರಹೋಗದ ಲಾಗಿನ್ ಟೋಕನ್‌ಗಳು.
- ಡ್ಯಾಶ್‌ಬೋರ್ಡ್‌ನಲ್ಲಿ ಡ್ರೈ ರನ್ ಇಲ್ಲ: ಹೆಸರಿಲ್ಲದ `ccam --dry-run` ಈ ಫೋಲ್ಡರ್‌ನ ಖಾತೆ ಹೇಗೆ ಆರಂಭವಾಗುತ್ತದೆ ಎಂಬುದನ್ನು ಮುದ್ರಿಸುತ್ತದೆ, ಮತ್ತು ಒಂದು ಖಾತೆಯ ಮೇಲೆ `o` ಆ ಒಂದು ಆರಂಭದ ಡ್ರೈ ರನ್ ಅನ್ನು ನೀಡುತ್ತದೆ.
- Claude Code ಆರಂಭವಾಗುವ ಅಥವಾ ಲಾಗಿನ್ ತೆರೆಯುವ ಮೊದಲು ಟರ್ಮಿನಲ್ ಮೊದಲಿನ ಸ್ಥಿತಿಗೆ ಮರಳುತ್ತದೆ.
- ಡೈಲಾಗ್‌ಗೆ ತುಂಬಾ ಚಿಕ್ಕದಾದ ಪರದೆಯಲ್ಲಿ ಮೊದಲು ಟ್ಯಾಬ್‌ನ ಸಾಲುಗಳನ್ನು ಬಿಡಲಾಗುತ್ತದೆ; ಸಾಲುಗಳನ್ನು ಸುತ್ತುವ ಬದಲು `…` ಮೂಲಕ ಕತ್ತರಿಸಲಾಗುತ್ತದೆ. ಕಡಿಮೆ ಎತ್ತರದ ಪರದೆಯಲ್ಲಿ ನಂತರ ಖಾಲಿ ಸಾಲುಗಳು ಮತ್ತು ಟ್ಯಾಬ್ ವಿವರಣೆ ಹೋಗುತ್ತವೆ, ಹೀಗಾಗಿ ಕೀಗಳ ಸಾಲು ಉಳಿಯುತ್ತದೆ. 40 ಕಾಲಮ್ ಅಥವಾ 8 ಸಾಲುಗಳಿಗಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ `Too small: ccam needs 40x8 (now 36x7)` ಅನ್ನು ಮಾತ್ರ ತೋರಿಸುತ್ತದೆ.
- ಬದಲಾವಣೆ, ತೆಗೆದುಹಾಕುವಿಕೆ, ಅಪ್‌ಡೇಟ್ ಅಥವಾ ದುರಸ್ತಿ ಅನ್ವಯವಾಗುತ್ತಿರುವಾಗ `Ctrl+C` ಅದು ಮುಗಿಯುವವರೆಗೆ ಕಾಯುತ್ತದೆ: ಸ್ಥಿತಿ ಸಾಲು `ccam quits when it is done.` ಎಂದು ಹೇಳುತ್ತದೆ.
- `U` ccam ಅನ್ನು ಅಪ್‌ಡೇಟ್ ಮಾಡಿದ ನಂತರ, ಖಾತೆ ಸೇರಿಸುವಿಕೆ ಅಥವಾ ಲಾಗಿನ್‌ನಿಂದ ಡ್ಯಾಶ್‌ಬೋರ್ಡ್ ಮರಳಿದಾಗ ಆ ಕೊಡುಗೆ ಮತ್ತೆ ಬರುವುದಿಲ್ಲ.
