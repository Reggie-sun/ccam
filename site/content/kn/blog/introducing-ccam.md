ccam ಒಂದು ಚಿಕ್ಕ ಕಮಾಂಡ್-ಲೈನ್ ಟೂಲ್. ಒಂದೇ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಒಂದಕ್ಕಿಂತ ಹೆಚ್ಚು Claude Code ಖಾತೆಗಳನ್ನು ಬಳಸುವವರಿಗಾಗಿ ಇದು: ಒಂದು ವೈಯಕ್ತಿಕ ಮತ್ತು ಒಂದು ಕೆಲಸದ ಖಾತೆ, ಅಥವಾ ಒಂದು ದೀರ್ಘ ಪ್ರಾಜೆಕ್ಟ್‌ಗಾಗಿ ಹಲವು ಖಾತೆಗಳು.

## ಸಮಸ್ಯೆ

Claude Code `CLAUDE_CONFIG_DIR` ಮೂಲಕ ಹಲವು ಖಾತೆಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ: ಪ್ರತಿ ಖಾತೆಗೆ ಒಂದು ಫೋಲ್ಡರ್. ಆದರೆ ಪ್ರಾಯೋಗಿಕವಾಗಿ ಪ್ರತಿ ಫೋಲ್ಡರ್ ಒಂದು ದ್ವೀಪದಂತೆ. ಸೆಟ್ಟಿಂಗ್‌ಗಳು, `CLAUDE.md`, MCP ಸರ್ವರ್‌ಗಳು, agents ಮತ್ತು skills ಅನ್ನು ಪ್ರತಿ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಮತ್ತೆ ಹೊಂದಿಸಬೇಕು ಮತ್ತು ಕೈಯಾರೆ ಹೊಂದಾಣಿಕೆಯಲ್ಲಿಡಬೇಕು. ಸಂಭಾಷಣೆಗಳು ಅವು ಆರಂಭವಾದಲ್ಲೇ ಉಳಿಯುತ್ತವೆ. ಮತ್ತು ಒಂದು ಖಾತೆ ತನ್ನ ಬಳಕೆಯ ಮಿತಿ ತಲುಪಿದೆ ಎಂಬುದು ಪ್ರಯತ್ನಿಸಿದಾಗಲೇ ನಿಮಗೆ ತಿಳಿಯುತ್ತದೆ.

## ccam ಏನು ಮಾಡುತ್ತದೆ

- `ccam add` ಫೋಲ್ಡರ್ ರಚಿಸುತ್ತದೆ, ಲಾಗಿನ್ ರನ್ ಮಾಡುತ್ತದೆ ಮತ್ತು ಖಾತೆಗೆ ಒಂದು ಶಾರ್ಟ್‌ಕಟ್ ನೀಡುತ್ತದೆ: `claude1`, `claude2`, ಹೀಗೆ.
- `ccs work` ಮತ್ತು `claude2` ಆ ಖಾತೆಯಾಗಿ Claude Code ಅನ್ನು ಆರಂಭಿಸುತ್ತವೆ ಮತ್ತು ಪ್ರತಿ ಆರ್ಗ್ಯುಮೆಂಟ್ ಅನ್ನು ಬದಲಾವಣೆ ಇಲ್ಲದೆ ರವಾನಿಸುತ್ತವೆ.
- MCP ಸರ್ವರ್‌ಗಳು, ಸೆಟ್ಟಿಂಗ್‌ಗಳು, `CLAUDE.md` ಮತ್ತು ವಿಸ್ತರಣೆಗಳು ಲಿಂಕ್‌ಗಳ ಮೂಲಕ, ಐಟಂವಾರು ಮತ್ತು ಖಾತೆವಾರು ಹಂಚಿಕೆಯಾಗುತ್ತವೆ. ಲಾಗಿನ್‌ಗಳು ಎಂದಿಗೂ ಹಂಚಿಕೆಯಾಗುವುದಿಲ್ಲ.
- `ccs usage` ಎಲ್ಲಾ ಖಾತೆಗಳ 5 ಗಂಟೆಯ ಮತ್ತು ವಾರದ ಬಳಕೆಯನ್ನು ತೋರಿಸುತ್ತದೆ; `ccs next --continue` ಸಂಭಾಷಣೆಯನ್ನು ಮುಂದಿನ ಖಾತೆಯಲ್ಲಿ ಮುಂದುವರಿಸುತ್ತದೆ.

## ಕೆಲಸಕ್ಕೆ ಅಡ್ಡಿಯಾಗದೆ

ಪ್ರತಿ ಸೆಷನ್‌ಗೂ ಮೊದಲು ರನ್ ಮಾಡುವ ಟೂಲ್ ನಿಮಗೆ ಗಮನಕ್ಕೆ ಬರುವಷ್ಟು ಯಾವುದೇ ವೆಚ್ಚ ಉಂಟುಮಾಡಬಾರದು. ccam ಒಂದು ಕಾನ್ಫಿಗರೇಶನ್ ಫೈಲ್ ಓದುತ್ತದೆ, ಹಂಚಿಕೊಂಡ ಪ್ರತಿ ಲಿಂಕ್ ಅನ್ನು ಒಂದೇ ಸಿಸ್ಟಮ್ ಕಾಲ್ ಮೂಲಕ ಪರಿಶೀಲಿಸುತ್ತದೆ, ಮತ್ತು ನಂತರ ತನ್ನನ್ನು `claude` ನಿಂದ ಬದಲಾಯಿಸಿಕೊಳ್ಳುತ್ತದೆ. ಇದು ಸುಮಾರು 4 ಮಿಲಿಸೆಕೆಂಡ್ ಸೇರಿಸುತ್ತದೆ, ಮತ್ತು ನೀವು ಕೆಲಸ ಮಾಡುತ್ತಿರುವಾಗ ಅದು ರನ್ ಆಗುತ್ತಿರುವುದಿಲ್ಲ.

ಇದು ನಿಮ್ಮ ಫೈಲ್‌ಗಳ ಬಗ್ಗೆಯೂ ಎಚ್ಚರಿಕೆ ವಹಿಸುತ್ತದೆ. ಹಂಚಿಕೆಯಲ್ಲಿನ ಪ್ರತಿ ಬದಲಾವಣೆಯು ಆರಂಭವಾಗುವ ಮೊದಲು ಒಂದು ಯೋಜನೆಯನ್ನು ಮುದ್ರಿಸುತ್ತದೆ ಮತ್ತು ಮೂಲ ಫೈಲ್‌ಗಳನ್ನು ಬ್ಯಾಕಪ್ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಇರಿಸುತ್ತದೆ. `ccam doctor` ಲಿಂಕ್‌ಗಳು, ಅನುಮತಿಗಳು ಮತ್ತು ಲಾಗಿನ್‌ಗಳನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ ಮತ್ತು ಸುರಕ್ಷಿತವಾಗಿ ಸರಿಪಡಿಸಬಹುದಾದುದನ್ನು ಸರಿಪಡಿಸುತ್ತದೆ.
