ccam เป็นเครื่องมือบรรทัดคำสั่งขนาดเล็กสำหรับผู้ที่ใช้บัญชี Claude Code มากกว่าหนึ่งบัญชีบนคอมพิวเตอร์เครื่องเดียวกัน เช่น บัญชีส่วนตัวกับบัญชีงาน หรือหลายบัญชีสำหรับโปรเจกต์ใหญ่โปรเจกต์เดียว

## ปัญหา

Claude Code รองรับหลายบัญชีผ่าน [`CLAUDE_CONFIG_DIR`](/guides/claude-config-dir) โดยใช้หนึ่งโฟลเดอร์ต่อหนึ่งบัญชี แต่ในทางปฏิบัติ แต่ละโฟลเดอร์แยกขาดจากกัน การตั้งค่า `CLAUDE.md` เซิร์ฟเวอร์ MCP เอเจนต์ และสกิลต้องตั้งค่าใหม่ในทุกโฟลเดอร์ และต้องคอยทำให้ตรงกันด้วยตัวเอง การสนทนาก็อยู่แค่ในบัญชีที่เริ่มต้น และเมื่อบัญชีหนึ่งใช้งานถึงขีดจำกัด คุณจะรู้ก็ต่อเมื่อลองใช้งานแล้วเท่านั้น

## สิ่งที่ ccam ทำ

- `ccam add` สร้างโฟลเดอร์ รันขั้นตอนเข้าสู่ระบบ และหากคุณต้องการ ก็ให้คำสั่งลัดที่คุณตั้งชื่อเองแก่บัญชี เช่น `ccwork`
- `ccam work` และ `ccwork` เริ่ม Claude Code ในชื่อบัญชีนั้น และส่งต่อทุกอาร์กิวเมนต์โดยไม่เปลี่ยนแปลง
- เซิร์ฟเวอร์ MCP การตั้งค่า `CLAUDE.md` และส่วนขยายใช้ร่วมกันผ่านลิงก์ ทีละรายการและทีละบัญชี การเข้าสู่ระบบไม่มีวันถูกใช้ร่วมกัน
- `ccam usage` แสดงการใช้งานแบบ 5 ชั่วโมงและรายสัปดาห์ของทุกบัญชี ส่วน `ccam next --continue` จะทำการสนทนาต่อในบัญชีถัดไป

## ไม่เข้าไปรบกวนการทำงาน

เครื่องมือที่คุณรันก่อนทุกเซสชันไม่ควรสร้างภาระที่คุณรู้สึกได้ ccam อ่านไฟล์การตั้งค่าหนึ่งไฟล์ ตรวจสอบลิงก์ที่ใช้ร่วมกันด้วย system call เพียงครั้งเดียวต่อลิงก์ แล้วแทนที่ตัวเองด้วย `claude` ccam ใช้เวลาเพิ่มประมาณ 4 มิลลิวินาที และไม่ได้ทำงานอยู่ระหว่างที่คุณทำงาน

ccam ยังดูแลไฟล์ของคุณอย่างระมัดระวัง ทุกการเปลี่ยนแปลงด้านการใช้ร่วมกันจะพิมพ์แผนการออกมาก่อนเริ่ม และเก็บไฟล์ต้นฉบับไว้ในโฟลเดอร์สำรอง `ccam doctor` ตรวจสอบลิงก์ สิทธิ์ และการเข้าสู่ระบบ แล้วซ่อมส่วนที่ซ่อมได้อย่างปลอดภัย

## ลองใช้งาน

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add
```

[เริ่มต้นใช้งาน](/docs/quick-start) จะพาคุณเพิ่มสองบัญชี และ[วิธีใช้ Claude Code หลายบัญชี](/guides/multiple-claude-code-accounts) อธิบายแนวทางทั้งแบบที่ใช้และไม่ใช้ ccam

ccam เป็นโอเพนซอร์สและไม่เป็นทางการ: ไม่ได้มีส่วนเกี่ยวข้องหรือได้รับการรับรองจาก Anthropic การที่คุณจะใช้หลายบัญชีได้หรือไม่ขึ้นอยู่กับข้อกำหนดของแต่ละบัญชี ยินดีรับความคิดเห็นและคำแปลบน [GitHub](https://github.com/jhyunwoo/ccam)
