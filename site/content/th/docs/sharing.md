แต่ละบัญชีเก็บการเข้าสู่ระบบของตัวเองไว้ ส่วนอย่างอื่นทั้งหมดใช้ร่วมกันได้ผ่าน**กลุ่ม**: กลุ่มหนึ่งระบุรายการที่ใช้ร่วมกันและบัญชีที่อยู่ในกลุ่ม แล้ว ccam จะลิงก์ไฟล์ของบัญชีเหล่านั้นไปยังโฟลเดอร์ของกลุ่ม ดังนั้นการเปลี่ยนแปลงที่ทำในบัญชีหนึ่งจะปรากฏในทุกบัญชี

## สิ่งที่ใช้ร่วมกันได้

| รายการ | สิ่งที่ใช้ร่วมกัน |
| --- | --- |
| `mcp` | เซิร์ฟเวอร์ MCP: `mcp.json` ของกลุ่ม ซึ่งส่งให้ Claude Code ตอนเริ่มทำงาน |
| `settings` | `settings.json`: สิทธิ์ hook โมเดล แถบสถานะ |
| `memory` | `CLAUDE.md` ระดับ global |
| `extensions` | `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/` |
| `history` | ประวัติการสนทนา: `projects/` และ `history.jsonl` |

บัญชีแรกของคุณจะสร้างกลุ่ม `default` ซึ่งใช้ทุกอย่างร่วมกันยกเว้นประวัติการสนทนา และบัญชีที่เพิ่มภายหลังจะเข้าร่วมกลุ่มนี้

ไฟล์การเข้าสู่ระบบ `.credentials.json` และ `.claude.json` จะไม่มีวันถูกใช้ร่วมกัน ccam ลิงก์เฉพาะพาธที่อยู่ในรายการที่กำหนดไว้ตายตัว และสองไฟล์นี้ไม่อยู่ในรายการนั้น

หน้านี้ครอบคลุมงานที่ทำเป็นประจำ ตัวเลือกทั้งหมดอธิบายไว้ในหน้าฟีเจอร์: [การใช้ร่วมกันด้วยกลุ่ม](/features/share) [เซิร์ฟเวอร์ MCP ที่ใช้ร่วมกัน](/features/mcp) และ[การคัดลอกการตั้งค่าที่มีอยู่](/features/migrate)

## กลุ่ม

```sh
ccam group                                   # the groups, what they share, their accounts
ccam group set default --add history         # every account in default shares history
ccam group add team --items history --members work,side
```

บัญชีหนึ่งอยู่ได้หลายกลุ่ม แต่แต่ละรายการมาจากกลุ่มเดียวเท่านั้น ดังนั้นหากต้องการใช้ประวัติร่วมกันระหว่าง `work` และ `side` แต่ไม่ใช้ร่วมกับบัญชีอื่นของคุณ ให้เอาประวัติออกจาก `default` และให้สองบัญชีนี้มีกลุ่มของตัวเองตามตัวอย่างด้านบน `ccam share work` แสดงสิ่งที่บัญชีใช้ร่วมกันและใช้ร่วมกันผ่านกลุ่มใด ส่วน[แดชบอร์ด](/features/dashboard)แสดงแบบเดียวกันในแท็บ Groups

## เมื่อบัญชีเริ่มใช้ร่วมกัน

เมื่อบัญชีเริ่มใช้รายการหนึ่งร่วมกัน (บัญชีเข้าร่วมกลุ่ม หรือกลุ่มของบัญชีเพิ่มรายการนั้น) ccam จะ:

1. พิมพ์แผนของทุกไฟล์ที่จะย้าย คัดลอก หรือลิงก์สำหรับแต่ละบัญชี และถามคุณก่อนเริ่ม
2. ย้ายไฟล์ของบัญชีเข้าไปในโฟลเดอร์ของกลุ่มหากกลุ่มยังว่างอยู่ หรือเพิ่มไฟล์ที่กลุ่มยังไม่มี
3. เมื่อไฟล์เดียวกันมีเนื้อหาต่างกัน จะถามว่าจะเก็บเวอร์ชันของกลุ่ม ใช้เวอร์ชันของคุณ หรือรวม JSON เข้าด้วยกัน
4. เก็บต้นฉบับของคุณไว้ใน `.ccam-backup/<time>/` ภายในโฟลเดอร์ของบัญชี
5. แทนที่ต้นฉบับด้วยลิงก์ไปยังกลุ่ม

ไฟล์การสนทนาตั้งชื่อตาม session ID ดังนั้นประวัติจากหลายบัญชีจึงรวมกันได้โดยไม่ขัดแย้งกัน

ccam จะไม่เปลี่ยนแปลงบัญชีในขณะที่ Claude Code กำลังทำงานด้วยบัญชีนั้น ไม่ว่า Claude Code จะถูกเริ่มด้วยวิธีใด (รวมถึงเซสชันเบื้องหลัง) เพราะเซสชันยังคงเขียนลงไฟล์ที่กำลังถูกย้าย ให้ออกจากเซสชันก่อน ccam จะตรวจสอบอีกครั้งก่อนบันทึก ดังนั้นเซสชันที่เริ่มขึ้นระหว่างที่แผนรออยู่ก็จะถูกตรวจพบเช่นกัน

## เมื่อบัญชีเลิกใช้ร่วมกัน

```sh
ccam group leave team work                   # work leaves the group
ccam group set default --remove history      # nobody in default shares history any more
```

ลิงก์จะถูกลบออก และบัญชีจะได้รับสำเนาของเนื้อหาปัจจุบันของกลุ่มเป็นของตัวเอง โดยเซิร์ฟเวอร์ MCP ของกลุ่มจะไปอยู่ใน `.claude.json` ของบัญชีเอง ข้างเซิร์ฟเวอร์ของบัญชีนั้น เพิ่ม `--fresh` หากต้องการเริ่มต้นแบบว่างเปล่าแทน แผนจะแสดงรายการเซิร์ฟเวอร์ MCP ที่จะหยุดโหลด โฟลเดอร์ที่นำเข้าอย่าง `~/.claude` จะเก็บสำเนาไว้เสมอ กลุ่มยังคงเก็บเนื้อหาไว้สำหรับบัญชีอื่น

## คัดลอกการตั้งค่าที่มีอยู่

หากคุณเคยใช้ Claude Code ก่อนใช้ ccam การตั้งค่าของคุณจะอยู่ใน `~/.claude` คำสั่ง `ccam migrate` จะคัดลอกการตั้งค่าเหล่านั้นไปยังกลุ่ม เพื่อให้ทุกบัญชีที่ใช้รายการเหล่านั้นร่วมกันได้รับด้วย:

```sh
ccam migrate
```

บนเทอร์มินัล ccam จะแสดงรายการตรวจสอบ (checklist) ของรายการต่าง ๆ ก่อน ทุกอย่างถูกเลือกไว้ยกเว้นประวัติการสนทนา กด Space เพื่อเปลี่ยนรายการ และกด Enter เพื่อดูแผน รายการที่โฟลเดอร์ไม่มีข้อมูลจะมีเครื่องหมาย `not found`

สิ่งที่คัดลอก:

- `settings.json` และ `CLAUDE.md` ระดับ global
- ส่วนขยาย `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/` และ `rules/`
- เซิร์ฟเวอร์ MCP ของผู้ใช้ ซึ่งก็คือรายการ `mcpServers` ใน `~/.claude.json` โดยคัดลอกไปไว้ใน `mcp.json` ของกลุ่ม
- ประวัติการสนทนา (`projects/` และ `history.jsonl`) แต่เฉพาะเมื่อคุณเพิ่ม `--history`

โฟลเดอร์ต้นทางจะถูกอ่านอย่างเดียว: ไม่มีสิ่งใดในโฟลเดอร์ถูกย้าย ลิงก์ หรือเปลี่ยนแปลง และ `claude` แบบปกติยังทำงานได้เหมือนเดิม ไฟล์เข้าสู่ระบบ `.credentials.json` และ `.claude.json` จะไม่ถูกคัดลอกไปยังกลุ่มเลย

เซิร์ฟเวอร์ MCP ที่ลงชื่อเข้าใช้ด้วย OAuth จะเก็บโทเค็นไว้ในการเข้าสู่ระบบ ไม่ได้อยู่ในรายการเซิร์ฟเวอร์ ccam ไม่คัดลอกการลงชื่อเข้าใช้เหล่านั้น: การลงชื่อเข้าใช้ที่ถูกคัดลอกจะถือ refresh token เดียวกัน และการต่ออายุครั้งแรกจะทำให้ผู้ถือรายอื่นทั้งหมดหลุดจากเซิร์ฟเวอร์นั้น รวมถึง `~/.claude` ด้วย แผนและสรุปผลจะระบุชื่อบัญชีที่ต้องลงชื่อเข้าใช้เซิร์ฟเวอร์เองด้วย `/mcp`

ccam จะพิมพ์แผนและถามก่อนคัดลอกสิ่งใด:

```console
$ ccam migrate
Copy from /home/me/.claude into group default (/home/me/.local/share/ccam/groups/default):
  mcp         ~/.claude.json  new: context7, fs
  settings    settings.json   new: 80 B
  memory      CLAUDE.md       new: 31 B
  extensions  agents/         add 1 file the group lacks (17 B)
              commands/       add 1 file the group lacks (15 B)
              skills/         add 1 file the group lacks (32 B)
              not found, skipped: plugins/, output-styles/, rules/
  Conversation history (projects/, history.jsonl) is not included; add --history to copy it.
Copy these into group default? [y/N] y
✓ Copied into group default: 2 MCP servers, settings.json, CLAUDE.md, agents/, commands/, skills/
Group default: personal
To share them:
  ccam group join default work
```

ในตอนท้าย ccam จะแสดงรายชื่อบัญชีของกลุ่ม หากกลุ่มยังไม่ได้ใช้รายการใดร่วมกัน หรือบางบัญชีไม่ได้อยู่ในกลุ่ม ccam จะพิมพ์คำสั่ง `ccam group` สำหรับเปลี่ยนสิ่งนั้น

เมื่อกลุ่มมีสำเนาของไฟล์ที่เนื้อหาต่างกันอยู่แล้ว ccam จะถามคุณเหมือนตอนเปิดใช้งานการใช้ร่วมกัน: จะเก็บสำเนาของกลุ่มไว้ หรือใช้ของคุณ นอกจากนี้ `settings.json` และไฟล์ JSON อื่น ๆ ยังรวมเข้าด้วยกันได้ และ `history.jsonl` รวมกันทีละบรรทัดได้ สำเนาเดิมของกลุ่มจะถูกเก็บไว้ใน `.ccam-backup/<time>/` ภายในโฟลเดอร์ของกลุ่ม

| ตัวเลือก | ผล |
| --- | --- |
| `--settings`, `--memory`, `--extensions`, `--mcp`, `--history` | คัดลอกเฉพาะรายการที่คุณระบุ โดยไม่แสดงรายการตรวจสอบ หากไม่ระบุและไม่ได้อยู่บนเทอร์มินัล จะคัดลอกทุกอย่างยกเว้นประวัติการสนทนา |
| `-g`, `--group <group>` | คัดลอกไปยังกลุ่มนี้แทน `default` |
| `-y`, `--yes` | คัดลอกโดยไม่ถาม เมื่อไฟล์ไม่ตรงกันจะเก็บสำเนาของกลุ่มไว้ |

ใส่ `--dry-run` ไว้หน้าคำสั่ง เช่น `ccam --dry-run migrate` เพื่อดูแผนโดยไม่คัดลอกสิ่งใด หากต้องการคัดลอกจากโฟลเดอร์อื่น ให้ระบุโฟลเดอร์นั้น: `ccam migrate ~/.claude-work --group work`

## เซิร์ฟเวอร์ MCP

Claude Code เก็บเซิร์ฟเวอร์ MCP ไว้ใน `.claude.json` ร่วมกับการเข้าสู่ระบบ จึงใช้ไฟล์นั้นร่วมกันไม่ได้ ccam เก็บเซิร์ฟเวอร์ที่ใช้ร่วมกันไว้ใน `mcp.json` ของกลุ่ม และเริ่ม Claude Code ด้วย `--mcp-config=<group>/mcp.json` ตัวเลือก `--mcp-config` ของคุณเองยังมีผลซ้อนทับอยู่ด้านบน

```sh
ccam mcp add fs -- npx -y @modelcontextprotocol/server-filesystem ~/code
ccam mcp list
```

เซิร์ฟเวอร์ที่คุณเพิ่มภายในเซสชันด้วย `claude mcp add` จะถูกบันทึกไว้สำหรับบัญชีนั้นเท่านั้น และสำหรับโฟลเดอร์ที่คุณอยู่ (ขอบเขต local ของ Claude Code ส่วน `-s user` จะทำให้เป็นของบัญชีในทุกโฟลเดอร์) ครั้งถัดไปที่คุณเริ่มบัญชีนั้น ccam จะบอกชื่อเซิร์ฟเวอร์พร้อมโฟลเดอร์ของเซิร์ฟเวอร์ และคำสั่งที่ใช้ย้ายเซิร์ฟเวอร์ไปยังกลุ่ม:

```sh
ccam mcp import work gh
```

หากกลุ่มมีเซิร์ฟเวอร์อื่นที่ใช้ชื่อนั้นอยู่แล้ว ccam จะข้ามเซิร์ฟเวอร์นั้นและแจ้งให้คุณทราบ `--force` จะแทนที่เซิร์ฟเวอร์ของกลุ่มและเก็บ `mcp.json` เดิมไว้ในโฟลเดอร์ `.ccam-backup/` ของกลุ่ม

เซิร์ฟเวอร์ MCP ที่ลงชื่อเข้าใช้ด้วย OAuth จะเก็บโทเค็นไว้กับการเข้าสู่ระบบของบัญชี ดังนั้นให้อนุญาตเซิร์ฟเวอร์เหล่านั้นหนึ่งครั้งในแต่ละบัญชีด้วย `/mcp` ส่วน `ccam ext` และ `ccam doctor` จะระบุเซิร์ฟเวอร์ที่บัญชีหนึ่งยังไม่ได้ลงชื่อเข้าใช้ ขณะที่อีกบัญชีหนึ่งลงชื่อเข้าใช้แล้ว

หากคุณต้องการให้เซิร์ฟเวอร์ปรากฏใน `claude mcp list` และ `/mcp` เป็นเซิร์ฟเวอร์ผู้ใช้ทั่วไป ให้ตั้งค่า `mcp_strategy = "sync"` ที่ด้านบนสุดของ `~/.config/ccam/config.toml` เหนือ `[[group]]`, `[[profile]]` หรือ `[[folder]]` ตัวแรก จากนั้น ccam จะเขียนเซิร์ฟเวอร์ลงใน `.claude.json` ของแต่ละบัญชีก่อนเริ่มทำงาน โดยใช้การล็อกไฟล์ของ Claude Code เองและสร้างข้อมูลสำรองไว้ เซิร์ฟเวอร์ที่บัญชีมีเป็นของตัวเองภายใต้ชื่อเดียวกันจะยังเป็นของบัญชีนั้น และ ccam จะแจ้งให้ทราบ

## สองบัญชีในโฟลเดอร์เดียวกัน

บัญชีที่ใช้ประวัติการสนทนาร่วมกันจะเขียนลงไฟล์เดียวกัน หากคุณเริ่ม Claude Code ตัวที่สองในโฟลเดอร์ที่มีอีกบัญชีหนึ่งในกลุ่มเดียวกันทำงานอยู่แล้ว ccam จะเตือนคุณและถามว่าจะดำเนินการต่อหรือไม่

## เมื่อมีบางอย่างเสียหาย

```sh
ccam doctor
ccam doctor --fix
```

หากพาธที่ใช้ร่วมกันกลายเป็นไฟล์ธรรมดา เช่น หลังจากที่คุณกู้คืนข้อมูลสำรองด้วยตัวเอง ccam จะหยุดก่อนเริ่ม Claude Code และแนะนำให้ใช้ `ccam doctor --fix` ซึ่งจะลิงก์พาธนั้นกับกลุ่มอีกครั้ง: ไฟล์จะกลายเป็นสำเนาของกลุ่มเมื่อกลุ่มยังไม่มี มิฉะนั้นกลุ่มจะเก็บของตัวเองไว้และไฟล์ของคุณจะไปอยู่ในข้อมูลสำรอง ซึ่ง `--fix` จะบอกชื่อไว้ การเปลี่ยนกลุ่มที่หยุดกลางคันก็จะถูกทำให้เสร็จด้วย `ccam doctor --fix` เช่นกัน
