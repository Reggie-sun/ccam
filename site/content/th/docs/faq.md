## ccam เป็นเครื่องมืออย่างเป็นทางการของ Anthropic หรือไม่?

ไม่ใช่ ccam เป็นโปรเจกต์โอเพนซอร์สที่ไม่เป็นทางการ และไม่ได้มีส่วนเกี่ยวข้องหรือได้รับการรับรองจาก Anthropic ccam ใช้การตั้งค่า `CLAUDE_CONFIG_DIR` ที่ Claude Code ระบุไว้ในเอกสารสำหรับการใช้หลายบัญชีควบคู่กัน

## ฉันใช้บัญชี Claude Code หลายบัญชีได้หรือไม่?

ขึ้นอยู่กับข้อกำหนดของแต่ละบัญชี และสำหรับบัญชีงาน ขึ้นอยู่กับนโยบายขององค์กรของคุณด้วย โปรดตรวจสอบก่อนใช้หลายบัญชี ccam เพียงทำให้การสลับระหว่างบัญชีที่คุณมีอยู่แล้วง่ายขึ้นเท่านั้น

## ccam ช่วยหลบเลี่ยงขีดจำกัดการใช้งานได้หรือไม่?

ไม่ได้ แต่ละบัญชียังคงมีขีดจำกัดของตัวเอง ccam แสดงขีดจำกัดเหล่านั้น และให้คุณทำงานต่อในอีกบัญชีหนึ่งที่คุณเป็นเจ้าของเมื่อบัญชีหนึ่งใช้โควตาหมด

## จะใช้บัญชี Claude Code สองบัญชีบนคอมพิวเตอร์เครื่องเดียวได้อย่างไร?

ให้แต่ละบัญชีมีโฟลเดอร์การตั้งค่าของตัวเองด้วย `CLAUDE_CONFIG_DIR` ccam ทำส่วนนี้ให้คุณ: รัน `ccam add` สำหรับแต่ละบัญชี แล้วเริ่มใช้งานด้วย `ccam personal` และ `ccam work` หรือด้วยคำสั่งลัดที่คุณตั้งชื่อเอง เช่น `ccwork` [คู่มือ](/guides/multiple-claude-code-accounts) ยังแสดงวิธีทำด้วยตัวเองด้วย

## จะสนทนาต่อในอีกบัญชีหนึ่งได้อย่างไร?

ใช้ประวัติการสนทนาร่วมกันระหว่างสองบัญชีด้วย `ccam share <name> --history on` แล้วรัน `ccam next --continue` Claude Code จะเปิดการสนทนาล่าสุดของโฟลเดอร์ปัจจุบันในบัญชีถัดไป

## ccam มองเห็นหรือส่งข้อมูลการเข้าสู่ระบบของฉันหรือไม่?

ccam ไม่เคยแชร์การเข้าสู่ระบบ Claude ของคุณระหว่างบัญชี ccam อ่านโทเค็นการเข้าถึงของบัญชีเพื่อใช้สอบถามการใช้งานของบัญชีนั้นจาก endpoint การใช้งานของ Anthropic เท่านั้น เมื่อคุณรัน `ccam usage`, `ccam next --auto` หรือ `ccam doctor` ส่วน `ccam migrate` จะคัดลอกการลงชื่อเข้าใช้ที่บันทึกไว้ของเซิร์ฟเวอร์ MCP จาก `~/.claude` ไปยังไฟล์เข้าสู่ระบบของบัญชีคุณเองบนคอมพิวเตอร์เครื่องเดียวกัน ccam ไม่มีระบบเก็บข้อมูลการใช้งาน (telemetry) และไม่ส่งข้อมูลใดไปที่อื่น

## จะลงชื่อเข้าใช้บนเซิร์ฟเวอร์ระยะไกลได้อย่างไร?

รัน `ccam add` หรือ `ccam login <name>` ในเซสชัน SSH ตามปกติ Claude Code จะรอการลงชื่อเข้าใช้อยู่บนเซิร์ฟเวอร์ ดังนั้นเบราว์เซอร์บนคอมพิวเตอร์ของคุณจะไปจบที่หน้า `http://localhost:<port>/callback?code=…` ที่โหลดไม่ขึ้น ให้คัดลอกที่อยู่นั้นจากเบราว์เซอร์แล้ววางลงในเทอร์มินัล: ccam จะส่งต่อให้ Claude Code บนเซิร์ฟเวอร์ ซึ่งจะลงชื่อเข้าใช้ให้เสร็จ ที่อยู่นี้มีรหัสที่ใช้ได้ครั้งเดียว จึงไม่ควรแชร์ให้ผู้อื่น

## บัญชีของฉันถูกเก็บไว้ที่ไหน?

ใน `~/.local/share/ccam/profiles/<name>/` หนึ่งโฟลเดอร์ต่อหนึ่งบัญชี บน macOS นั้น Claude Code เก็บข้อมูลเข้าสู่ระบบไว้ในพวงกุญแจ (Keychain) ภายใต้ชื่อที่สร้างจากโฟลเดอร์นั้น

## จะเกิดอะไรขึ้นกับ ~/.claude ที่ฉันมีอยู่แล้ว?

ไม่มีอะไรเกิดขึ้น เว้นแต่คุณจะรัน `ccam import` หรือ `ccam migrate` การนำเข้าจะลงทะเบียนโฟลเดอร์ไว้ในตำแหน่งเดิม ดังนั้น `claude` แบบปกติและ `ccam <name>` จะยังใช้บัญชีและการตั้งค่าเดียวกัน ส่วน `ccam migrate` จะคัดลอกการตั้งค่า `CLAUDE.md` ส่วนขยาย และเซิร์ฟเวอร์ MCP ของโฟลเดอร์นั้นไปยังการตั้งค่าที่ใช้ร่วมกัน โดยอ่านโฟลเดอร์อย่างเดียว

## ccam รองรับระบบใดบ้าง?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine และอื่น ๆ) และ macOS บน Windows ให้ใช้งานภายใน WSL

## ทำไมเซิร์ฟเวอร์ MCP จึงแสดงอยู่ในบัญชีเดียวเท่านั้น?

เซิร์ฟเวอร์ที่เพิ่มภายในเซสชันด้วย `claude mcp add` จะถูกเก็บไว้สำหรับบัญชีนั้นเท่านั้น ccam จะแจ้งให้คุณทราบในครั้งถัดไปที่คุณเริ่มบัญชีนั้น ย้ายเซิร์ฟเวอร์ไปยังกลุ่มที่ใช้ร่วมกันได้ด้วย `ccam mcp import <account> <server>`

## ccam ทำให้ Claude Code ช้าลงหรือไม่?

การเริ่ม Claude Code ผ่าน ccam ใช้เวลาเพิ่มประมาณ 4 มิลลิวินาที ซึ่งวัดด้วย `scripts/perf-check.sh` บนแล็ปท็อป ccam อ่านไฟล์ขนาดเล็กหนึ่งไฟล์ ตรวจสอบลิงก์ที่ใช้ร่วมกัน แล้วแทนที่ตัวเองด้วย `claude` จึงไม่ได้ทำงานอยู่ระหว่างที่คุณทำงาน

## จะอัปเดต ccam ได้อย่างไร?

รัน `ccam update` คำสั่งนี้จะดาวน์โหลดรุ่นล่าสุด ตรวจสอบ checksum แล้วแทนที่ไฟล์ `ccam` ส่วน `ccam update --check` จะบอกเพียงว่ามีรุ่นที่ใหม่กว่าหรือไม่ ccam ไม่อัปเดตตัวเองโดยอัตโนมัติ หากคุณติดตั้งจากแพ็กเกจ `.deb` ให้ติดตั้ง `.deb` รุ่นใหม่ด้วย apt แทน ดูที่ [การอัปเดต](/docs/install#update)

## จะถอนการติดตั้ง ccam ได้อย่างไร?

ลบคำสั่งลัดของแต่ละบัญชีด้วย `ccam shortcut <account> --remove` ลบ `ccam` ออกจาก `~/.local/bin` จากนั้นลบ `~/.config/ccam`, `~/.local/share/ccam` และ `~/.local/state/ccam` หากคุณไม่ต้องการบัญชีเหล่านั้นอีกต่อไป ดูที่ [การติดตั้ง](/docs/install#uninstall)
