## ccam เป็นเครื่องมืออย่างเป็นทางการของ Anthropic หรือไม่?

ไม่ใช่ ccam เป็นโปรเจกต์โอเพนซอร์สที่ไม่เป็นทางการ และไม่ได้มีส่วนเกี่ยวข้องหรือได้รับการรับรองจาก Anthropic ccam ใช้การตั้งค่า `CLAUDE_CONFIG_DIR` ที่ Claude Code [ระบุไว้ในเอกสาร](https://code.claude.com/docs/en/env-vars)สำหรับการใช้หลายบัญชีควบคู่กัน

## ฉันใช้บัญชี Claude Code หลายบัญชีได้หรือไม่?

ขึ้นอยู่กับข้อกำหนดของแต่ละบัญชี และสำหรับบัญชีงาน ขึ้นอยู่กับนโยบายขององค์กรของคุณด้วย โปรดตรวจสอบก่อนใช้หลายบัญชี ccam เพียงทำให้การสลับระหว่างบัญชีที่คุณมีอยู่แล้วง่ายขึ้นเท่านั้น

**ที่นั่ง (seat) ของ Team และ Enterprise** การเลือกอัตโนมัติ (`ccam next`, `--fallback`, `ccam pick` และปุ่ม `n` ในแดชบอร์ด) จะสลับระหว่างที่นั่งต่าง ๆ ในองค์กร Claude Team หรือ Enterprise เดียวกันด้วย ศูนย์ช่วยเหลือของ Anthropic ระบุว่า "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (แต่ละที่นั่งในแพ็กเกจ Team จะกำหนดให้กับบุคคลที่ระบุชื่อเพียงคนเดียว และมีเพียงบุคคลนั้นที่ใช้ได้) และ "Users can't route their work through another user's account to use that user's remaining usage" (ผู้ใช้ไม่สามารถส่งงานของตนผ่านบัญชีของผู้ใช้คนอื่นเพื่อใช้ปริมาณการใช้งานที่เหลืออยู่ของผู้ใช้คนนั้นได้) ([แพ็กเกจ Team](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129) ส่วน [แพ็กเกจ Enterprise](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) ก็เช่นเดียวกัน) ดังนั้น การใช้การเลือกอัตโนมัติระหว่างที่นั่งต่าง ๆ จึงอาจละเมิดข้อกำหนดของ Anthropic โปรดสอบถามองค์กรของคุณและ Anthropic ก่อนที่จะพึ่งพาการเลือกอัตโนมัติ สำหรับแพ็กเกจส่วนตัว (Pro, Max) ดูที่ย่อหน้าด้านบน

## ccam ช่วยหลบเลี่ยงขีดจำกัดการใช้งานได้หรือไม่?

ไม่ได้ แต่ละบัญชียังคงมีขีดจำกัดของตัวเอง ccam แสดงขีดจำกัดเหล่านั้น และให้คุณทำงานต่อในอีกบัญชีหนึ่งที่คุณเป็นเจ้าของเมื่อบัญชีหนึ่งใช้โควตาหมด

## จะใช้บัญชี Claude Code สองบัญชีบนคอมพิวเตอร์เครื่องเดียวได้อย่างไร?

ให้แต่ละบัญชีมีโฟลเดอร์การตั้งค่าของตัวเองด้วย `CLAUDE_CONFIG_DIR` ccam ทำส่วนนี้ให้คุณ: รัน `ccam add` สำหรับแต่ละบัญชี แล้วเริ่มใช้งานด้วย `ccam personal` และ `ccam work` หรือด้วยคำสั่งลัดที่คุณตั้งชื่อเอง เช่น `ccwork` [คู่มือ](/guides/multiple-claude-code-accounts) ยังแสดงวิธีทำด้วยตัวเองด้วย

## จะสนทนาต่อในอีกบัญชีหนึ่งได้อย่างไร?

รัน `ccam next --continue` ในโฟลเดอร์นั้น: คำสั่งนี้จะพาการสนทนาล่าสุดของโฟลเดอร์ไปยังบัญชีถัดไป (`--auto` สำหรับบัญชีที่เหลือโควตามากที่สุด) ภายใน Claude Code `/ccam:switch` จาก[ปลั๊กอิน ccam](/docs/install#claude-code-plugin) ทำแบบเดียวกันให้กับเซสชันที่คุณอยู่ เมื่อสองบัญชีใช้ประวัติการสนทนาร่วมกัน (`ccam group set default --add history` หรือใช้กลุ่มของบัญชีเหล่านั้นเอง: `ccam group add pair --items history --members work,side`) บัญชีใหม่จะเปิดการสนทนานั้นเลย มิฉะนั้น Claude Code จะคัดลอกการสนทนาไปยังประวัติของบัญชีใหม่

## ccam มองเห็นหรือส่งข้อมูลการเข้าสู่ระบบของฉันหรือไม่?

ccam ไม่เคยแชร์หรือคัดลอกการเข้าสู่ระบบ Claude ของคุณระหว่างบัญชี และไม่เคยคัดลอกการลงชื่อเข้าใช้ของเซิร์ฟเวอร์ MCP ccam อ่านโทเค็นการเข้าถึงของบัญชีเพื่อใช้สอบถามการใช้งานของบัญชีนั้นจาก endpoint การใช้งานของ Anthropic เท่านั้น เมื่อคุณรัน `ccam usage`, `ccam next --auto` หรือ `ccam doctor` และต่ออายุโทเค็นที่หมดอายุเฉพาะด้วย `ccam usage --refresh` เท่านั้น เมื่อตั้ง `usage_source = "claude"` ccam จะไม่อ่านโทเค็นเลย `ccam ext` และ `ccam doctor` อ่านเพียงชื่อการลงชื่อเข้าใช้ MCP ของบัญชี ไม่เคยอ่านโทเค็นของการลงชื่อเข้าใช้เหล่านั้น ccam ไม่มีระบบเก็บข้อมูลการใช้งาน (telemetry) นอกจากการสอบถามเหล่านั้น คำขอเดียวที่ ccam ส่งเองคือการที่แดชบอร์ดถาม GitHub ถึงรุ่นล่าสุดของ ccam ซึ่งไม่มีข้อมูลใดเกี่ยวกับตัวคุณหรือบัญชีของคุณ

## จะลงชื่อเข้าใช้บนเซิร์ฟเวอร์ระยะไกลได้อย่างไร?

รัน `ccam add` หรือ `ccam login <name>` ในเซสชัน SSH ตามปกติ Claude Code จะรอการลงชื่อเข้าใช้อยู่บนเซิร์ฟเวอร์ ดังนั้นเบราว์เซอร์บนคอมพิวเตอร์ของคุณจะไปจบที่หน้า `http://localhost:<port>/callback?code=…` ที่โหลดไม่ขึ้น ให้คัดลอกที่อยู่นั้นจากเบราว์เซอร์แล้ววางลงในเทอร์มินัล: ccam จะส่งต่อให้ Claude Code บนเซิร์ฟเวอร์ ซึ่งจะลงชื่อเข้าใช้ให้เสร็จ ที่อยู่นี้มีรหัสที่ใช้ได้ครั้งเดียว จึงไม่ควรแชร์ให้ผู้อื่น

## บัญชีของฉันถูกเก็บไว้ที่ไหน?

ใน `~/.local/share/ccam/profiles/<name>/` หนึ่งโฟลเดอร์ต่อหนึ่งบัญชี บน macOS นั้น Claude Code เก็บข้อมูลเข้าสู่ระบบไว้ในพวงกุญแจ (Keychain) ภายใต้ชื่อที่สร้างจากโฟลเดอร์นั้น ดังนั้น `ccam rename` จึงคงชื่อเดิมของโฟลเดอร์ไว้ที่นั่น

## จะเกิดอะไรขึ้นกับ ~/.claude ที่ฉันมีอยู่แล้ว?

ไม่มีอะไรเกิดขึ้น เว้นแต่คุณจะรัน `ccam import` หรือ `ccam migrate` การนำเข้าจะลงทะเบียนโฟลเดอร์ไว้ในตำแหน่งเดิม ดังนั้น `claude` แบบปกติและ `ccam <name>` จะยังใช้บัญชีและการตั้งค่าเดียวกัน ส่วน `ccam migrate` จะคัดลอกการตั้งค่า `CLAUDE.md` ส่วนขยาย และเซิร์ฟเวอร์ MCP ของโฟลเดอร์นั้นไปยังการตั้งค่าที่ใช้ร่วมกัน โดยอ่านโฟลเดอร์อย่างเดียว

## ccam รองรับระบบใดบ้าง?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine และอื่น ๆ), macOS และ Windows 10 และ 11 ทั้งแบบเนทีฟและภายใน WSL บน Windows การใช้ไฟล์อย่าง `settings.json` ร่วมกันต้องเปิด Developer Mode ส่วนโฟลเดอร์ที่ใช้ร่วมกันทำงานได้โดยไม่ต้องเปิด และหากไม่ได้เปิด `ccam add` ครั้งแรกจะสร้างกลุ่ม `default` ที่มีเฉพาะเซิร์ฟเวอร์ MCP และส่วนขยาย ([การใช้ร่วมกันบน Windows](/features/share#on-windows))

## ทำไมเซิร์ฟเวอร์ MCP จึงแสดงอยู่ในบัญชีเดียวเท่านั้น?

เซิร์ฟเวอร์ที่เพิ่มภายในเซสชันด้วย `claude mcp add` จะถูกเก็บไว้สำหรับบัญชีนั้นเท่านั้น และหากไม่มี `-s user` จะเป็นของโฟลเดอร์ปัจจุบันเท่านั้น ccam จะแจ้งให้คุณทราบในครั้งถัดไปที่คุณเริ่มบัญชีนั้น และ `ccam mcp list` กับ `ccam ext` จะแสดงเซิร์ฟเวอร์เหล่านี้ ย้ายเซิร์ฟเวอร์ไปยังกลุ่มที่ใช้ร่วมกันได้ด้วย `ccam mcp import <account> <server>`

## ccam ทำให้ Claude Code ช้าลงหรือไม่?

การเริ่ม Claude Code ผ่าน ccam ใช้เวลาเพิ่มประมาณ 4 มิลลิวินาที ซึ่งวัดด้วย `scripts/perf-check.sh` บนแล็ปท็อป ccam อ่านไฟล์ขนาดเล็กหนึ่งไฟล์ ตรวจสอบลิงก์ที่ใช้ร่วมกัน แล้วแทนที่ตัวเองด้วย `claude` จึงไม่ได้ทำงานอยู่ระหว่างที่คุณทำงาน Windows แทนที่โปรเซสไม่ได้ บน Windows ccam จึงเริ่ม Claude Code และรอให้มันจบ โดยไม่ทำอย่างอื่น

## จะอัปเดต ccam ได้อย่างไร?

รัน `ccam update` คำสั่งนี้จะดาวน์โหลดรุ่นล่าสุด ตรวจสอบ checksum แล้วแทนที่ไฟล์ `ccam` ส่วน `ccam update --check` จะบอกเพียงว่ามีรุ่นที่ใหม่กว่าหรือไม่ แดชบอร์ดก็บอกเช่นกันเมื่อมีรุ่นที่ใหม่กว่า และ `U` จะติดตั้งรุ่นนั้นหลังจากถามก่อน ccam ไม่อัปเดตตัวเองโดยอัตโนมัติ หากคุณติดตั้งจากแพ็กเกจ `.deb` ให้ติดตั้ง `.deb` รุ่นใหม่ด้วย apt แทน ดูที่ [การอัปเดต](/docs/install#update)

## จะถอนการติดตั้ง ccam ได้อย่างไร?

ลบคำสั่งลัดของแต่ละบัญชีด้วย `ccam shortcut <account> --remove` หากคุณนำเข้า `~/.claude` และโฟลเดอร์นั้นอยู่ในกลุ่ม ให้รัน `ccam remove <name>` กับบัญชีนั้นก่อน เพื่อให้ได้สำเนาของสิ่งที่ใช้ร่วมกันกลับคืนมา จากนั้นลบ `ccam` ออกจาก `~/.local/bin` แล้วลบ `~/.config/ccam`, `~/.local/share/ccam` และ `~/.local/state/ccam` หากคุณไม่ต้องการบัญชีเหล่านั้นอีกต่อไป ดูที่ [การติดตั้ง](/docs/install#uninstall)
