เพิ่มแต่ละบัญชีด้วย `ccam add` จากนั้นเริ่ม Claude Code ด้วย `claude1`, `claude2` หรือ `ccs <name>` เท่านี้ก็เพียงพอสำหรับผู้ใช้ส่วนใหญ่

## 1. เพิ่มบัญชีแรก

```sh
ccam add
```

ตัวช่วยตั้งค่าจะถามชื่อบัญชี เช่น `personal` หรือ `work` และถามว่าบัญชีนี้ควรใช้รายการใดร่วมกับบัญชีอื่นของคุณ จากนั้นจะรัน `claude auth login` ซึ่งเปิดเบราว์เซอร์ให้คุณลงชื่อเข้าใช้ เมื่อเสร็จแล้วคุณจะเห็น:

```console
✓ personal (me@example.com) 추가됨 — 단축 명령: claude1
```

ขณะนี้ ccam แสดงข้อความของตัวเองเป็นภาษาเกาหลี ส่วนคำสั่งและตัวเลือกเหมือนกันในทุกภาษา

## 2. เพิ่มบัญชีที่สอง

```sh
ccam add work
```

ลงชื่อเข้าใช้ด้วยอีกบัญชีหนึ่งในเบราว์เซอร์ บัญชีนี้จะกลายเป็น `claude2`

## 3. สลับบัญชี

คำสั่งใดคำสั่งหนึ่งต่อไปนี้จะเริ่ม Claude Code ในชื่อบัญชีงาน:

```sh
claude2
ccs work
ccs 2
```

ทุกอย่างที่อยู่หลังชื่อบัญชีจะส่งต่อให้ Claude Code โดยไม่เปลี่ยนแปลง คุณจึงใช้ตัวเลือกที่คุ้นเคยต่อไปได้:

```sh
ccs work --resume
ccs work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

การรัน `ccs` อย่างเดียวจะเปิดตัวเลือกบัญชี: ใช้ปุ่มลูกศรและ Enter หรือกดหมายเลขของบัญชี

## 4. เลือกสิ่งที่จะใช้ร่วมกัน

โดยค่าเริ่มต้น เซิร์ฟเวอร์ MCP, `settings.json`, `CLAUDE.md` ระดับ global รวมถึงเอเจนต์ คำสั่ง สกิล และปลั๊กอินจะใช้ร่วมกันระหว่างบัญชี แต่ประวัติการสนทนาไม่ได้ใช้ร่วมกัน หากคุณต้องการสนทนาต่อข้ามบัญชี ให้เปิดใช้สำหรับทั้งสองบัญชี:

```sh
ccam share personal --history on
ccam share work --history on
```

ccam จะแสดงสิ่งที่จะย้ายก่อนเปลี่ยนแปลงสิ่งใด ดูรายละเอียดได้ที่ [การใช้ร่วมกัน](/docs/sharing)

## 5. เมื่อบัญชีถึงขีดจำกัด

```sh
ccs usage
ccs next --continue
```

`ccs usage` แสดงการใช้งานแบบ 5 ชั่วโมงและรายสัปดาห์ของทุกบัญชี `ccs next --continue` เปิดการสนทนาเดิมในบัญชีถัดไป ดูที่ [ขีดจำกัดการใช้งาน](/docs/usage-limits)

## ใช้ ~/.claude อยู่แล้วใช่ไหม?

ลงทะเบียนโฟลเดอร์นั้นแทนการลงชื่อเข้าใช้ใหม่:

```sh
ccam import
```

โฟลเดอร์จะอยู่ในตำแหน่งเดิม และ `claude` แบบปกติยังทำงานได้เหมือนเดิม
