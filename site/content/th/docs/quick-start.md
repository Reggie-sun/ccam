เพิ่มแต่ละบัญชีด้วย `ccam add` จากนั้นเริ่ม Claude Code ด้วย `ccam <name>` หรือด้วยคำสั่งลัดที่คุณตั้งชื่อเอง เช่น `ccwork` เท่านี้ก็เพียงพอสำหรับผู้ใช้ส่วนใหญ่

ใช้ Claude Code อยู่แล้วใช่ไหม? อ่าน[ใช้ ~/.claude อยู่แล้วใช่ไหม?](#already-using-claude) ที่ท้ายหน้านี้ก่อนเริ่ม

## 1. เพิ่มบัญชีแรก

```sh
ccam add
```

ตัวช่วยตั้งค่าจะถามชื่อบัญชี เช่น `personal` หรือ `work` ถามว่าบัญชีนี้ควรใช้รายการใดร่วมกับบัญชีอื่นของคุณ และถามว่าจะสร้างคำสั่งลัดหรือไม่ (ดูขั้นตอนที่ 3) จากนั้นจะรัน `claude auth login` ซึ่งเปิดเบราว์เซอร์ให้คุณลงชื่อเข้าใช้ บนเครื่องระยะไกล เบราว์เซอร์ของคุณอาจไปจบที่หน้า `http://localhost:…/callback` ที่โหลดไม่ขึ้น ให้วางที่อยู่นั้นลงในเทอร์มินัล แล้ว ccam จะลงชื่อเข้าใช้ให้เสร็จ เมื่อลงชื่อเข้าใช้เสร็จแล้ว คุณจะเห็น:

```console
✓ personal (me@example.com) added
  no shortcut (add one with `ccam shortcut personal ccpersonal`)
```

## 2. นำการตั้งค่าเดิมมาใช้

หากคุณเคยใช้ Claude Code มาก่อน การตั้งค่า `CLAUDE.md` และส่วนขยายของคุณจะอยู่ใน `~/.claude` และเซิร์ฟเวอร์ MCP ของคุณจะอยู่ใน `~/.claude.json` คัดลอกสิ่งเหล่านี้ไปไว้ในกลุ่ม `default` ที่ใช้ร่วมกัน เพื่อให้ทุกบัญชีได้รับด้วย:

```sh
ccam migrate
```

ccam จะแสดงสิ่งที่จะคัดลอกและถามก่อน โดยจะอ่าน `~/.claude` อย่างเดียว ไม่คัดลอกข้อมูลเข้าสู่ระบบใด ๆ และไม่รวมประวัติการสนทนา เว้นแต่คุณจะเพิ่ม `--history` ดูรายละเอียดได้ที่ [การคัดลอกการตั้งค่าที่มีอยู่](/docs/sharing#copy-an-existing-setup)

## 3. เพิ่มบัญชีที่สอง

```sh
ccam add work
```

ตัวช่วยตั้งค่าจะข้ามการถามชื่อ เพราะคุณระบุไว้ในบรรทัดคำสั่งแล้ว และแสดงกลุ่มที่จะเข้าร่วมโดยเลือก `default` ไว้ ครั้งนี้ให้ตั้งคำสั่งลัดเฉพาะให้บัญชี เช่น `ccwork` เพื่อให้เริ่มบัญชีได้ด้วยคำเดียว หลังจากเลือกกลุ่มแล้ว ตัวช่วยตั้งค่าจะถามว่า:

```console
 Create a shortcut command for work? [y/N]
 A command such as ccwork that opens Claude Code as this account.
```

กด `y` แล้วพิมพ์ชื่อ หรือกด Enter เพื่อใช้ชื่อที่แนะนำ:

```console
 Shortcut name [ccwork]: █
 a-z, 0-9, '.', '-' and '_'; Enter alone uses ccwork
```

จากนั้นลงชื่อเข้าใช้ด้วยอีกบัญชีหนึ่งในเบราว์เซอร์ ccam จะยืนยันบัญชีและคำสั่งลัดของบัญชีนั้น:

```console
✓ work (work@example.com) added
  shortcut: ccwork
```

## 4. สลับบัญชี

`ccam work` จะเริ่ม Claude Code ในชื่อบัญชีงาน หากคุณข้ามคำถามเรื่องคำสั่งลัดไป ก็เพิ่มคำสั่งลัดได้ทุกเมื่อ:

```console
$ ccam shortcut work ccwork
✓ shortcut for work: ccwork
```

ตอนนี้คำสั่งแต่ละคำสั่งต่อไปนี้จะเริ่ม Claude Code ในชื่อบัญชีงาน (`2` คือหมายเลขของบัญชีใน `ccam list`):

```sh
ccwork
ccam work
ccam 2
```

การรัน `ccam` อย่างเดียวจะเปิด[แดชบอร์ด](/features/dashboard): เลื่อนไปที่บัญชีด้วยปุ่มลูกศรหรือหมายเลขของบัญชี แล้วกด Enter

ทุกอย่างที่อยู่หลังคำสั่งลัดหรือชื่อบัญชีจะส่งต่อให้ Claude Code โดยไม่เปลี่ยนแปลง คุณจึงใช้ตัวเลือกที่คุ้นเคยต่อไปได้:

```sh
ccwork --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | ccwork -p "what caused this?"
```

## 5. เลือกสิ่งที่จะใช้ร่วมกัน

โดยค่าเริ่มต้น เซิร์ฟเวอร์ MCP, `settings.json`, `CLAUDE.md` ระดับ global และส่วนขยาย (เอเจนต์ คำสั่ง สกิล และปลั๊กอิน) จะใช้ร่วมกันระหว่างบัญชีผ่านกลุ่ม `default` แต่ประวัติการสนทนาไม่ได้ใช้ร่วมกัน หากคุณต้องการสนทนาต่อข้ามบัญชี ให้เพิ่มประวัติการสนทนาลงในกลุ่ม:

```sh
ccam group set default --add history
```

ccam จะแสดงสิ่งที่จะย้ายสำหรับแต่ละบัญชีก่อนเปลี่ยนแปลงสิ่งใด ดูรายละเอียดได้ที่ [การใช้ร่วมกันด้วยกลุ่ม](/features/share)

## 6. เมื่อบัญชีถึงขีดจำกัด

```sh
ccam usage
ccam next --continue
```

`ccam usage` แสดงการใช้งานแบบ 5 ชั่วโมงและรายสัปดาห์ของทุกบัญชี `ccam next --continue` เปิดการสนทนาเดิมในบัญชีถัดไป ในสคริปต์ `ccam --fallback work -p "…"` จะสลับบัญชีให้เอง ดูที่ [ขีดจำกัดการใช้งาน](/docs/usage-limits)

**ที่นั่ง (seat) ของ Team และ Enterprise** การเลือกบัญชีอัตโนมัติ (`ccam next`, `--fallback`, `ccam pick`, ปุ่ม `n` ในแดชบอร์ด และ [`auto_switch`](/features/next#auto-switch) เมื่อคุณเปิดใช้) จะสลับระหว่างที่นั่งต่าง ๆ ในองค์กร Claude Team หรือ Enterprise เดียวกันด้วย ซึ่งอาจละเมิดข้อกำหนดของ Anthropic โปรดอ่าน[คำถามที่พบบ่อย](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) และสอบถามองค์กรของคุณและ Anthropic ก่อนที่จะพึ่งพาการเลือกอัตโนมัติ

## ใช้ ~/.claude อยู่แล้วใช่ไหม?

ลงทะเบียนโฟลเดอร์นั้นแทนการลงชื่อเข้าใช้ใหม่:

```sh
ccam import
```

โฟลเดอร์จะอยู่ในตำแหน่งเดิม และ `claude` แบบปกติยังทำงานได้เหมือนเดิม
