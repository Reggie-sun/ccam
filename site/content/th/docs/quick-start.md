เพิ่มแต่ละบัญชีด้วย `ccam add` จากนั้นเริ่ม Claude Code ด้วย `ccam <name>` หรือด้วยคำสั่งลัดที่คุณตั้งชื่อเอง เช่น `ccwork` เท่านี้ก็เพียงพอสำหรับผู้ใช้ส่วนใหญ่

## 1. เพิ่มบัญชีแรก

```sh
ccam add
```

ตัวช่วยตั้งค่าจะถามชื่อบัญชี เช่น `personal` หรือ `work` ถามว่าบัญชีนี้ควรใช้รายการใดร่วมกับบัญชีอื่นของคุณ และถามว่าจะสร้างคำสั่งลัดหรือไม่ (ดูขั้นตอนที่ 4) จากนั้นจะรัน `claude auth login` ซึ่งเปิดเบราว์เซอร์ให้คุณลงชื่อเข้าใช้ เมื่อเสร็จแล้วคุณจะเห็น:

```console
✓ personal (me@example.com) added
  no shortcut (add one with `ccam shortcut personal ccpersonal`)
```

ccam แสดงข้อความของตัวเองเป็นภาษาอังกฤษ ส่วนคำสั่งและตัวเลือกเหมือนกันในทุกภาษา

## 2. นำการตั้งค่าเดิมมาใช้

หากคุณเคยใช้ Claude Code มาก่อน การตั้งค่า `CLAUDE.md` ส่วนขยาย และเซิร์ฟเวอร์ MCP ของคุณจะอยู่ใน `~/.claude` คัดลอกสิ่งเหล่านี้ไปไว้ในการตั้งค่าที่ใช้ร่วมกัน เพื่อให้ทุกบัญชีได้รับด้วย:

```sh
ccam migrate
```

ccam จะแสดงสิ่งที่จะคัดลอกและถามก่อน โดยจะอ่าน `~/.claude` อย่างเดียว ไม่คัดลอกข้อมูลเข้าสู่ระบบใด ๆ และไม่รวมประวัติการสนทนา เว้นแต่คุณจะเพิ่ม `--history` ดูรายละเอียดได้ที่ [การคัดลอกการตั้งค่าที่มีอยู่](/docs/sharing#copy-an-existing-setup)

## 3. เพิ่มบัญชีที่สอง

```sh
ccam add work
```

ลงชื่อเข้าใช้ด้วยอีกบัญชีหนึ่งในเบราว์เซอร์

## 4. สลับบัญชี

`ccam work` จะเริ่ม Claude Code ในชื่อบัญชีงาน หากต้องการคำสั่งที่สั้นกว่านี้ ให้ตั้งคำสั่งลัดเฉพาะให้บัญชี เช่น `ccwork` หลังจากเลือกรายการที่ใช้ร่วมกันแล้ว ตัวช่วยตั้งค่าจะถามว่า:

```console
 Create a shortcut command for work? [y/N]
 A command such as ccwork that opens Claude Code as this account.
```

กด `y` แล้วพิมพ์ชื่อ หรือกด Enter เพื่อใช้ชื่อที่แนะนำ:

```console
 Shortcut name [ccwork]: █
 a-z, 0-9, '.', '-' and '_'; Enter alone uses ccwork
```

หลังจากเข้าสู่ระบบแล้ว ccam จะยืนยันดังนี้:

```console
✓ work (work@example.com) added
  shortcut: ccwork
```

หากคุณข้ามคำถามนี้ไป ก็เพิ่มคำสั่งลัดได้ทุกเมื่อ:

```console
$ ccam shortcut work ccwork
✓ shortcut for work: ccwork
```

ตอนนี้คำสั่งใดคำสั่งหนึ่งต่อไปนี้จะเริ่ม Claude Code ในชื่อบัญชีงาน:

```sh
ccwork
ccam work
ccam 2
```

การรัน `ccam` อย่างเดียวจะเปิดตัวเลือกบัญชี: ใช้ปุ่มลูกศรและ Enter หรือกดหมายเลขของบัญชี

ทุกอย่างที่อยู่หลังคำสั่งลัดหรือชื่อบัญชีจะส่งต่อให้ Claude Code โดยไม่เปลี่ยนแปลง คุณจึงใช้ตัวเลือกที่คุ้นเคยต่อไปได้:

```sh
ccwork --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | ccwork -p "what caused this?"
```

## 5. เลือกสิ่งที่จะใช้ร่วมกัน

โดยค่าเริ่มต้น เซิร์ฟเวอร์ MCP, `settings.json`, `CLAUDE.md` ระดับ global รวมถึงเอเจนต์ คำสั่ง สกิล และปลั๊กอินจะใช้ร่วมกันระหว่างบัญชี แต่ประวัติการสนทนาไม่ได้ใช้ร่วมกัน หากคุณต้องการสนทนาต่อข้ามบัญชี ให้เปิดใช้สำหรับทั้งสองบัญชี:

```sh
ccam share personal --history on
ccam share work --history on
```

ccam จะแสดงสิ่งที่จะย้ายก่อนเปลี่ยนแปลงสิ่งใด ดูรายละเอียดได้ที่ [การใช้ร่วมกัน](/docs/sharing)

## 6. เมื่อบัญชีถึงขีดจำกัด

```sh
ccam usage
ccam next --continue
```

`ccam usage` แสดงการใช้งานแบบ 5 ชั่วโมงและรายสัปดาห์ของทุกบัญชี `ccam next --continue` เปิดการสนทนาเดิมในบัญชีถัดไป ดูที่ [ขีดจำกัดการใช้งาน](/docs/usage-limits)

## ใช้ ~/.claude อยู่แล้วใช่ไหม?

ลงทะเบียนโฟลเดอร์นั้นแทนการลงชื่อเข้าใช้ใหม่:

```sh
ccam import
```

โฟลเดอร์จะอยู่ในตำแหน่งเดิม และ `claude` แบบปกติยังทำงานได้เหมือนเดิม
