`ccs usage` แสดงว่าแต่ละบัญชีใช้ขีดจำกัดแบบ 5 ชั่วโมงและรายสัปดาห์ไปแล้วเท่าไร `ccs next --auto` เปิดบัญชีที่เหลือโควตามากที่สุด และ `--continue` จะนำการสนทนาปัจจุบันไปต่อด้วย

```console
$ ccs usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccs next --auto 로 바로 열기)
```

คอลัมน์ต่าง ๆ ได้แก่ บัญชี การใช้งานแบบ 5 ชั่วโมง เวลาที่เหลือจนถึงการรีเซ็ต การใช้งานรายสัปดาห์ เวลาที่เหลือจนถึงการรีเซ็ต และอายุของตัวเลข

## ตัวเลขมาจากไหน

ccam สอบถาม endpoint การใช้งานของ Anthropic สำหรับทุกบัญชีพร้อมกัน โดยใช้การเข้าสู่ระบบของแต่ละบัญชีเอง ccam รอไม่เกิน 3 วินาทีต่อบัญชี และแสดงแต่ละบัญชีทันทีที่ได้รับคำตอบ

endpoint นี้ไม่มีเอกสารเผยแพร่สู่สาธารณะและอาจเปลี่ยนแปลงได้ เมื่อคำขอล้มเหลว ccam จะแสดงตัวเลขล่าสุดที่ทราบและระบุว่าเป็นข้อมูลจากแคช `ccam doctor` จะแจ้งให้คุณทราบหากรูปแบบของคำตอบเปลี่ยนไป

ตัวเลขที่ดึงมาเมื่อไม่ถึง 60 วินาทีที่แล้วจะถูกนำกลับมาใช้ซ้ำ ตัวเลือก:

| ตัวเลือก | ผลลัพธ์ |
| --- | --- |
| `--watch [seconds]` | รีเฟรชต่อเนื่อง ทุก 60 วินาทีโดยค่าเริ่มต้น |
| `--json` | ผลลัพธ์ที่เครื่องอ่านได้ |
| `-v` | แสดงขีดจำกัดรายสัปดาห์แยกตามโมเดล และแหล่งที่มาของตัวเลขแต่ละตัวด้วย |
| `--no-cache` | สอบถามใหม่ทุกครั้ง |
| `--source cache` | ไม่สอบถามเลย แสดงเฉพาะตัวเลขที่บันทึกไว้ |

## การเข้าสู่ระบบที่หมดอายุ

เมื่อโทเค็นการเข้าถึงของบัญชีหมดอายุ ccam จะไม่ต่ออายุให้ เพราะการต่ออายุขณะที่เซสชัน Claude Code กำลังใช้การเข้าสู่ระบบเดียวกันอยู่ อาจทำให้เซสชันนั้นถูกออกจากระบบ ให้เริ่มบัญชีนั้นหนึ่งครั้งด้วย `ccs <name>` แล้ว Claude Code จะต่ออายุให้

`ccs usage --refresh` ต่ออายุโทเค็นที่หมดอายุด้วยตัวเอง แต่เฉพาะบัญชีที่ไม่ได้ทำงานอยู่เท่านั้น และจะไม่ต่ออายุการเข้าสู่ระบบที่เก็บไว้ในพวงกุญแจ (Keychain) ของ macOS หรือใน `~/.claude` ที่นำเข้ามา

## การใช้งานในแถบสถานะ

```sh
ccam statusline install
```

จากนั้น Claude Code จะแสดงชื่อบัญชีและการใช้งานของบัญชีในแถบสถานะ เช่น `[work] · Opus · 5h 24% · 7d 41%` หากคุณมีคำสั่งแถบสถานะอยู่แล้ว ccam จะเก็บคำสั่งนั้นไว้และใส่ชื่อบัญชีไว้ด้านหน้า แถบสถานะยังบันทึกตัวเลขของตัวเองไว้ด้วย ซึ่ง `ccs usage` จะนำมาใช้เมื่อ endpoint ไม่ตอบกลับ

## การสลับบัญชี

```sh
ccs next              # the account after the one you used last
ccs next --auto       # the account with the lowest 5-hour usage
ccs next --continue   # the next account that shares your conversation history
```

`ccs next` จะข้ามบัญชีที่ยังไม่ได้เข้าสู่ระบบ และ `--auto` จะข้ามบัญชีที่ใช้ไปถึง 100% แล้ว การสนทนาต่อได้นั้น ทั้งสองบัญชีต้องใช้ประวัติการสนทนาร่วมกัน ดูที่ [การใช้ร่วมกัน](/docs/sharing)
