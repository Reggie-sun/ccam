`ccam usage` แสดงว่าแต่ละบัญชีใช้ขีดจำกัดแบบ 5 ชั่วโมงและรายสัปดาห์ไปแล้วเท่าไร `ccam next --auto` เปิดบัญชีที่เหลือโควตามากที่สุด และ `--continue` จะนำการสนทนาปัจจุบันไปต่อด้วย

```console
$ ccam usage
 Account     5-hour        Resets    Weekly        Resets    As of
 1 personal  ██████░░  72% 1h 40m    ███░░░░░  41% 3d 6h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
 3 side      ████████ 100% 22m       █████░░░  68% 1d 9h     12m ago (cached)
→ Most headroom: work   (open it with ccam next --auto)
```

คอลัมน์ต่าง ๆ ได้แก่ บัญชี การใช้งานแบบ 5 ชั่วโมง เวลาที่เหลือจนถึงการรีเซ็ต การใช้งานรายสัปดาห์ เวลาที่เหลือจนถึงการรีเซ็ต และอายุของตัวเลข

## ตัวเลขมาจากไหน

ccam สอบถาม endpoint การใช้งานของ Anthropic สำหรับทุกบัญชีพร้อมกัน โดยใช้การเข้าสู่ระบบของแต่ละบัญชีเอง ccam รอไม่เกิน 3 วินาทีต่อบัญชี และแสดงแต่ละบัญชีทันทีที่ได้รับคำตอบ

endpoint นี้ไม่มีเอกสารเผยแพร่สู่สาธารณะและอาจเปลี่ยนแปลงได้ เมื่อคำขอล้มเหลว ccam จะแสดงตัวเลขล่าสุดที่ทราบและระบุว่าเป็นข้อมูลจากแคช ช่วงเวลาที่รีเซ็ตไปแล้วหลังจากบันทึกตัวเลขเหล่านั้นจะแสดงเป็น 0% `ccam doctor` จะแจ้งให้คุณทราบหากรูปแบบของคำตอบเปลี่ยนไป

ตัวเลขที่ดึงมาเมื่อไม่ถึง 60 วินาทีที่แล้วจะถูกนำกลับมาใช้ซ้ำ ตัวเลือก:

| ตัวเลือก | ผลลัพธ์ |
| --- | --- |
| `--watch [seconds]` | รีเฟรชต่อเนื่อง ทุก 60 วินาทีโดยค่าเริ่มต้น |
| `--json` | ผลลัพธ์ที่เครื่องอ่านได้ |
| `-v` | แสดงขีดจำกัดรายสัปดาห์แยกตามโมเดล และแหล่งที่มาของตัวเลขแต่ละตัวด้วย |
| `--no-cache` | สอบถามใหม่ทุกครั้ง |
| `--source cache` | ไม่สอบถามเลย แสดงเฉพาะตัวเลขที่บันทึกไว้ |

## การเข้าสู่ระบบที่หมดอายุ

เมื่อโทเค็นการเข้าถึงของบัญชีหมดอายุ ccam จะไม่ต่ออายุให้ เพราะการต่ออายุขณะที่เซสชัน Claude Code กำลังใช้การเข้าสู่ระบบเดียวกันอยู่ อาจทำให้เซสชันนั้นถูกออกจากระบบ ให้เริ่มบัญชีนั้นหนึ่งครั้งด้วย `ccam <name>` แล้ว Claude Code จะต่ออายุให้

`ccam usage --refresh` ต่ออายุโทเค็นที่หมดอายุด้วยตัวเอง แต่เฉพาะบัญชีที่ไม่ได้ทำงานอยู่เท่านั้น และจะไม่ต่ออายุการเข้าสู่ระบบที่เก็บไว้ในพวงกุญแจ (Keychain) ของ macOS หรือใน `~/.claude` ที่นำเข้ามา

## การใช้งานในแถบสถานะ

```sh
ccam statusline install
```

จากนั้น Claude Code จะแสดงชื่อบัญชีและการใช้งานของบัญชีในแถบสถานะ เช่น `[work] · Opus · 5h 24% · 7d 41%` ตั้งแต่ 90% ขึ้นไป แถบสถานะจะแนะนำ `ccam next --auto --continue` ด้วย หากคุณมีคำสั่งแถบสถานะอยู่แล้ว ccam จะเก็บคำสั่งนั้นไว้และใส่ชื่อบัญชีไว้ด้านหน้า แถบสถานะยังบันทึกตัวเลขของตัวเองไว้ด้วย ซึ่ง `ccam usage` จะนำมาใช้เมื่อ endpoint ไม่ตอบกลับ

## การสลับบัญชี

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # carry this folder's conversation on as the next account
```

`ccam next` จะข้ามบัญชีที่ยังไม่ได้เข้าสู่ระบบ และ `--auto` จะข้ามบัญชีที่ใช้ไปถึง 100% แล้วและบัญชีขององค์กรอื่น เมื่อสองบัญชีใช้ประวัติการสนทนาร่วมกัน `--continue` จะเปิดการสนทนาเดียวกัน หากไม่ได้ใช้ร่วมกัน Claude Code จะคัดลอกการสนทนานั้นไปยังบัญชีใหม่ ดูที่ [การใช้ร่วมกัน](/docs/sharing) และ [การสลับไปยังบัญชีถัดไป](/features/next#continue)

สำหรับสคริปต์และงานตามกำหนดเวลาที่รัน `claude -p` ให้ใส่ `--fallback` ไว้หน้าชื่อบัญชี เมื่อบัญชีนั้นถึงขีดจำกัด ccam จะรันคำสั่งเดิมอีกครั้งด้วยบัญชีที่เหลือโควตามากที่สุด และพิมพ์เฉพาะผลลัพธ์ของการรันที่ทำงานจนจบ:

```sh
ccam --fallback work -p "review the diff" --output-format json
```
