เมื่อบัญชีหนึ่งใช้งานถึงขีดจำกัด ให้สนทนาเดิมต่อในอีกบัญชีหนึ่งที่คุณเป็นเจ้าของ: ตั้งค่าใช้ประวัติการสนทนาร่วมกันหนึ่งครั้ง แล้วรัน `ccs next --continue` หากคุณมีบัญชีเดียว ให้รอจนถึงเวลารีเซ็ตที่ Claude Code แสดง

## ก่อนที่จะเกิดขึ้น

ตั้งค่าบัญชีให้การสลับใช้เพียงคำสั่งเดียว:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

ตอนนี้แถบสถานะจะแสดงบัญชีและการใช้งานแบบ 5 ชั่วโมงระหว่างที่คุณทำงาน การถึงขีดจำกัดจึงไม่ใช่เรื่องที่เกิดขึ้นโดยไม่ทันตั้งตัว

## เมื่อถึงขีดจำกัด

ออกจาก Claude Code (`/exit`) แล้ว:

```sh
ccs usage
```

```console
 1 personal  ████████ 100% 22분        █████░░░  68% 1일 9시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
```

เปิดการสนทนาในบัญชีที่เหลือโควตามากที่สุด:

```sh
ccs next --auto --continue
```

Claude Code จะเริ่มในชื่อบัญชี `work` พร้อมการสนทนาล่าสุดของโฟลเดอร์ปัจจุบัน รวมถึงทุกอย่างที่คุยกันมาจนถึงตอนนี้

## สิ่งที่ควรจำไว้

- รัน `ccs next --continue` ในโฟลเดอร์เดียวกับที่คุณทำงานอยู่ เพราะการสนทนาถูกเก็บแยกตามโฟลเดอร์โปรเจกต์
- หลีกเลี่ยงการใช้สองบัญชีกับการสนทนาเดียวกันในเวลาเดียวกัน ccam จะเตือนคุณหากคุณพยายามทำเช่นนั้น
- อีกบัญชีหนึ่งต้องใช้ประวัติการสนทนาร่วมกันด้วย และต้องอยู่ในกลุ่มเดียวกัน
- การที่คุณจะสลับระหว่างบัญชีแบบนี้ได้หรือไม่ขึ้นอยู่กับข้อกำหนดของแต่ละบัญชี

ดู[ขีดจำกัดการใช้งาน](/docs/usage-limits)สำหรับทุกตัวเลือกของ `ccs usage` และ `ccs next`
