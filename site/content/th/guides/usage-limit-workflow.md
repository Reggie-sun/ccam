เมื่อบัญชีใช้งานถึงขีดจำกัด (มักเรียกว่า rate limit) คุณมีสองทางเลือก คือรอจนขีดจำกัดรีเซ็ต หรือสนทนาเดิมต่อทันทีในอีกบัญชีที่คุณมี เมื่อเปิดใช้ประวัติการสนทนาร่วมกันระหว่างบัญชีแล้ว ทางที่สองใช้ ccam เพียงคำสั่งเดียวคือ `ccam next --auto --continue`

## Claude Code มีขีดจำกัดอะไรบ้าง?

ในแพ็กเกจ Pro และ Max นั้น Claude Code มี[ขีดจำกัดเซสชัน 5 ชั่วโมงและขีดจำกัดรายสัปดาห์](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan) ทั้งสองใช้ร่วมกับ Claude บนเว็บและในแอป และการใช้งานจะนับรวมในทั้งสองขีดจำกัดพร้อมกัน เมื่ออันใดอันหนึ่งหมด Claude Code จะ[แสดงข้อความ](https://code.claude.com/docs/en/errors#youve-hit-your-session-limit) เช่น "You've hit your session limit · resets 3:45pm" การเปลี่ยนโมเดลไม่ช่วย เพราะขีดจำกัดครอบคลุมทุกโมเดล

## ทางเลือกที่ 1: รอให้รีเซ็ต

หากคุณมีบัญชีเดียว ให้รอ Claude Code รุ่นล่าสุดจะ[รออยู่ในเซสชันที่เปิดอยู่](https://code.claude.com/docs/en/interactive-mode#wait-for-a-usage-limit-to-reset) และทำงานต่อเองเมื่อขีดจำกัดรีเซ็ต คำสั่ง `/usage` ใน Claude Code แสดงว่าคุณใช้ขีดจำกัดของแพ็กเกจไปเท่าไรแล้ว

## ทางเลือกที่ 2: สนทนาต่อในอีกบัญชีทันที

หากคุณมีบัญชีที่สอง คุณทำงานต่อได้ทันทีด้วยการสนทนาเดิม ตั้งค่าครั้งเดียว:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

ตอนนี้แถบสถานะจะแสดงบัญชีและการใช้งาน 5 ชั่วโมงขณะที่คุณทำงาน การถึงขีดจำกัดจึงไม่ใช่เรื่องที่ไม่ทันตั้งตัวอีกต่อไป

เมื่อถึงขีดจำกัด ให้ออกจาก Claude Code (`/exit`) แล้วรัน:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

เปิดการสนทนาในบัญชีที่เหลือโควตามากที่สุด:

```sh
ccam next --auto --continue
```

Claude Code จะเริ่มเป็นบัญชี `work` พร้อมการสนทนาล่าสุดของโฟลเดอร์ปัจจุบัน รวมทุกอย่างที่คุยกันมาจนถึงตอนนี้

## ccam สลับบัญชีให้อัตโนมัติไหม?

ไม่ ccam ไม่ได้ทำงานอยู่ระหว่างที่คุณทำงาน: ccam เริ่ม Claude Code แล้วแทนที่ตัวเองด้วย Claude Code คุณเป็นผู้ตัดสินใจว่าจะสลับเมื่อไร และ `ccam next --auto` จะเลือกบัญชีที่มีการใช้งาน 5 ชั่วโมงต่ำที่สุด โดยข้ามบัญชีที่ถึง 100% แล้วหรือยังไม่ได้เข้าสู่ระบบ เครื่องมืออื่นบางตัวสลับการเข้าสู่ระบบของเซสชันที่กำลังทำงานแทน [ccam กับเครื่องมือสลับบัญชีอื่น ๆ](/compare/account-switchers) อธิบายความแตกต่างนี้

## สิ่งที่ควรรู้

- รัน `ccam next --continue` ในโฟลเดอร์เดียวกับที่คุณทำงานอยู่ เพราะการสนทนาถูกเก็บแยกตามโฟลเดอร์โปรเจกต์
- หลีกเลี่ยงการรันสองบัญชีในการสนทนาเดียวกันพร้อมกัน ccam จะเตือนเมื่อคุณพยายามทำเช่นนั้น
- อีกบัญชีหนึ่งต้องใช้ประวัติการสนทนาร่วมกันด้วย ในกลุ่มเดียวกัน
- ข้อความแรกในบัญชีใหม่อาจใช้ขีดจำกัดมากกว่าปกติ เพราะบัญชีนั้นยังไม่ได้แคชการสนทนาไว้
- การสลับบัญชีแบบนี้ได้หรือไม่ขึ้นอยู่กับข้อกำหนดของแต่ละบัญชี

ดู[ขีดจำกัดการใช้งาน](/docs/usage-limits)สำหรับทุกตัวเลือกของ `ccam usage` และ `ccam next`
