เมื่อบัญชีใช้งานถึงขีดจำกัด (มักเรียกว่า rate limit) คุณมีสองทางเลือก คือรอจนขีดจำกัดรีเซ็ต หรือสนทนาเดิมต่อทันทีในอีกบัญชีที่คุณมี ด้วย ccam ทางที่สองใช้เพียงคำสั่งเดียวคือ `ccam next --auto --continue`

## Claude Code มีขีดจำกัดอะไรบ้าง?

ในแพ็กเกจ Pro และ Max นั้น Claude Code มี[ขีดจำกัดเซสชัน 5 ชั่วโมงและขีดจำกัดรายสัปดาห์](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan) ทั้งสองใช้ร่วมกับ Claude บนเว็บและในแอป และการใช้งานจะนับรวมในทั้งสองขีดจำกัดพร้อมกัน เมื่ออันใดอันหนึ่งหมด Claude Code จะ[แสดงข้อความ](https://code.claude.com/docs/en/errors#youve-hit-your-session-limit) เช่น "You've hit your session limit · resets 3:45pm" การเปลี่ยนโมเดลไม่ช่วย เพราะขีดจำกัดครอบคลุมทุกโมเดล

## ทางเลือกที่ 1: รอให้รีเซ็ต

หากคุณมีบัญชีเดียว ให้รอ Claude Code รุ่นล่าสุดจะ[รออยู่ในเซสชันที่เปิดอยู่](https://code.claude.com/docs/en/interactive-mode#wait-for-a-usage-limit-to-reset) และทำงานต่อเองเมื่อขีดจำกัดรีเซ็ต คำสั่ง `/usage` ใน Claude Code แสดงว่าคุณใช้ขีดจำกัดของแพ็กเกจไปเท่าไรแล้ว

## ทางเลือกที่ 2: สนทนาต่อในอีกบัญชีทันที

หากคุณมีบัญชีที่สอง คุณทำงานต่อได้ทันทีด้วยการสนทนาเดิม ตั้งค่าครั้งเดียว:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
ccam group set default --add history
ccam statusline install
```

ตอนนี้แถบสถานะจะแสดงบัญชีและการใช้งาน 5 ชั่วโมงขณะที่คุณทำงาน การถึงขีดจำกัดจึงไม่ใช่เรื่องที่ไม่ทันตั้งตัวอีกต่อไป

เมื่อถึงขีดจำกัด ให้ออกจาก Claude Code (`/exit`) แล้วรัน:

```sh
ccam usage
```

```console
 1 personal  just now
   5-hour   ████████████████████ 100%  resets in 22m
   Weekly   ██████████████░░░░░░  68%  resets in 1d 9h
 2 work      just now
   5-hour   ██░░░░░░░░░░░░░░░░░░   8%  resets in 4h 12m
   Weekly   ████░░░░░░░░░░░░░░░░  19%  resets in 5d 2h
→ Most headroom: work   (open it with ccam next --auto)
```

เปิดการสนทนาในบัญชีที่เหลือโควตามากที่สุด:

```sh
ccam next --auto --continue
```

Claude Code จะเริ่มเป็นบัญชี `work` พร้อมการสนทนาล่าสุดของโฟลเดอร์ปัจจุบัน รวมทุกอย่างที่คุยกันมาจนถึงตอนนี้ การใช้ประวัติร่วมกัน (`ccam group set default --add history` ด้านบน) ทำให้ยังเป็นการสนทนาเดียวกัน หากไม่ได้ใช้ร่วมกัน Claude Code จะคัดลอกการสนทนาไปยัง `work` และ ccam จะบอกคุณว่าคำตอบแรกนั้นต้องอ่านซ้ำกี่โทเค็น

เมื่อติดตั้ง[ปลั๊กอิน ccam](/docs/install#claude-code-plugin)ใน Claude Code แล้ว เซสชันที่หยุดเพราะถึงขีดจำกัดจะแสดงการแจ้งเตือนและบันทึกช่วงที่เต็มไว้ `ccam next --auto` จึงไม่เลือกบัญชีนั้นอีกก่อนรีเซ็ต และ `/ccam:switch` (หรือ `/ccam:switch work`) จะจดการสนทนานั้นไว้ให้ `ccam next --continue` โดยไม่ต้องเดาอะไรเลย

**ที่นั่ง (seat) ของ Team และ Enterprise** การเลือกอัตโนมัติ (`ccam next`, `--fallback`, `ccam pick`, ปุ่ม `n` ในแดชบอร์ด และ [`auto_switch`](/features/next#auto-switch) เมื่อคุณเปิดใช้) จะสลับระหว่างที่นั่งต่าง ๆ ในองค์กร Claude Team หรือ Enterprise เดียวกันด้วย ศูนย์ช่วยเหลือของ Anthropic ระบุว่า "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (แต่ละที่นั่งในแพ็กเกจ Team จะกำหนดให้กับบุคคลที่ระบุชื่อเพียงคนเดียว และมีเพียงบุคคลนั้นที่ใช้ได้) และ "Users can't route their work through another user's account to use that user's remaining usage" (ผู้ใช้ไม่สามารถส่งงานของตนผ่านบัญชีของผู้ใช้คนอื่นเพื่อใช้ปริมาณการใช้งานที่เหลืออยู่ของผู้ใช้คนนั้นได้) ([แพ็กเกจ Team](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129) ส่วน [แพ็กเกจ Enterprise](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) ก็เช่นเดียวกัน) ดังนั้น การใช้การเลือกอัตโนมัติระหว่างที่นั่งต่าง ๆ จึงอาจละเมิดข้อกำหนดของ Anthropic จะใช้การเลือกอัตโนมัติในกรณีนี้หรือไม่เป็นการตัดสินใจของคุณ: โปรดสอบถามองค์กรของคุณและ Anthropic ก่อนที่จะพึ่งพาการเลือกอัตโนมัติ สำหรับแพ็กเกจส่วนตัว (Pro, Max) ดูที่ [หมายเหตุเรื่องข้อกำหนดในคำถามที่พบบ่อย](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts)

## ccam สลับบัญชีให้อัตโนมัติไหม?

เฉพาะเมื่อคุณเปิดใช้เท่านั้น โดยค่าเริ่มต้น ccam ไม่ได้ทำงานอยู่ระหว่างที่คุณทำงาน: ccam เริ่ม Claude Code แล้วแทนที่ตัวเองด้วย Claude Code คุณจึงเป็นผู้ตัดสินใจว่าจะสลับเมื่อไร และ `ccam next --auto` จะเลือกบัญชีที่มีการใช้งาน 5 ชั่วโมงต่ำที่สุด ข้ามบัญชีที่ถึง 100% แล้วหรือยังไม่ได้เข้าสู่ระบบ และอยู่ภายในองค์กร Team หรือ Enterprise เดียว หรือในบรรดาแพ็กเกจส่วนตัว เมื่อตั้ง `relay = true` ใน `config.toml` ccam จะรออยู่ข้างเซสชันแทน `/ccam:switch` จึงทำงานต่อได้เอง โดยคงตัวเลือกของเซสชัน โหมดสิทธิ์ และระดับ effort ไว้ เมื่อตั้ง `auto_switch = true` (Linux และ macOS ยังเป็นแบบทดลอง) ccam จะสลับให้เองด้วย: เมื่อ Claude Code หยุดเซสชันเพราะถึงขีดจำกัด และมีอีกบัญชีหนึ่งที่เป็นแบบเดียวกันซึ่งยังมีโควตาเหลือ ccam จะจบเซสชันแล้วสนทนาต่อที่บัญชีนั้น ([เงื่อนไขและค่าใช้จ่าย](/features/next#auto-switch)) เครื่องมืออื่นบางตัวสลับการเข้าสู่ระบบของเซสชันที่กำลังทำงานแทน [ccam กับเครื่องมือสลับบัญชีอื่น ๆ](/compare/account-switchers) อธิบายความแตกต่างนี้

## สิ่งที่ควรรู้

- รัน `ccam next --continue` ในโฟลเดอร์เดียวกับที่คุณทำงานอยู่ เพราะการสนทนาถูกเก็บแยกตามโฟลเดอร์โปรเจกต์
- หลีกเลี่ยงการรันสองบัญชีในการสนทนาเดียวกันพร้อมกัน ccam จะเตือนเมื่อคุณพยายามทำเช่นนั้น
- หากไม่ได้ใช้ประวัติร่วมกัน การสนทนาจะถูกคัดลอกไปยังอีกบัญชีหนึ่งและสองสำเนาจะแยกทางกันไป checkpoint ที่ `/rewind` ใช้กู้คืนโค้ดจะยังอยู่กับบัญชีแรก
- ข้อความแรกในบัญชีใหม่อาจใช้ขีดจำกัดมากกว่าปกติ เพราะบัญชีนั้นยังไม่ได้แคชการสนทนาไว้ `ccam next --continue --brief` จะเริ่มบัญชีใหม่ด้วยสรุปสั้น ๆ แทน
- การสลับบัญชีแบบนี้ได้หรือไม่ขึ้นอยู่กับข้อกำหนดของแต่ละบัญชี

ดู[ขีดจำกัดการใช้งาน](/docs/usage-limits)สำหรับทุกตัวเลือกของ `ccam usage` และ `ccam next`
