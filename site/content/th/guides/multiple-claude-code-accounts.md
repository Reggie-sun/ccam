ให้แต่ละบัญชีมีโฟลเดอร์การตั้งค่าของตัวเอง Claude Code อ่านโฟลเดอร์จากตัวแปรสภาพแวดล้อม `CLAUDE_CONFIG_DIR` และแต่ละโฟลเดอร์เก็บการเข้าสู่ระบบ การตั้งค่า และประวัติของตัวเองไว้ คุณตั้งค่านี้เองได้ด้วย shell alias หรือให้ ccam จัดการให้ก็ได้

## ทำเองด้วย alias

นี่คือแนวทางที่เอกสารของ Claude Code อธิบายไว้ เพิ่มหนึ่งบรรทัดต่อบัญชีเพิ่มเติมแต่ละบัญชีลงใน `~/.bashrc` หรือ `~/.zshrc`:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

เปิดเทอร์มินัลใหม่แล้วรัน `claude-work` Claude Code จะขอให้คุณเข้าสู่ระบบ เพราะโฟลเดอร์นั้นเป็นโฟลเดอร์ใหม่ ต่อจากนี้ `claude` คือบัญชีแรกของคุณ และ `claude-work` คือบัญชีที่สอง

วิธีนี้ใช้ได้ดีสำหรับสองบัญชี สิ่งที่ควรรู้:

- แต่ละโฟลเดอร์เริ่มต้นแบบว่างเปล่า: ไม่มีการตั้งค่า ไม่มี `CLAUDE.md` ไม่มีเซิร์ฟเวอร์ MCP ไม่มีเอเจนต์หรือสกิล คุณต้องคัดลอกหรือลิงก์สิ่งที่ต้องการ และคอยทำให้สำเนาตรงกันด้วยตัวเอง
- alias มีอยู่เฉพาะใน shell แบบโต้ตอบเท่านั้น สคริปต์ Makefile และโปรแกรมอื่นมองไม่เห็น alias
- เซิร์ฟเวอร์ MCP อยู่ใน `.claude.json` ข้างกับการเข้าสู่ระบบ จึงลิงก์ระหว่างโฟลเดอร์แบบง่าย ๆ ไม่ได้
- การสนทนาอยู่ในบัญชีที่เริ่มต้นเท่านั้น คุณจึงสนทนาต่อในอีกบัญชีหนึ่งไม่ได้
- ไม่มีอะไรแสดงการใช้งานของทุกบัญชีในคราวเดียว

## ใช้ ccam

ccam ทำแนวคิดเดียวกันนี้ให้เป็นอัตโนมัติ และเพิ่มส่วนที่ขาดหายไป:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

ตอนนี้ `ccam personal` และ `ccam work` จะเริ่มทั้งสองบัญชี และ `ccwork` ซึ่งเป็นคำสั่งลัดที่คุณตั้งให้บัญชีงานก็เช่นกัน เพราะคำสั่งเหล่านี้เป็นโปรแกรมจริงไม่ใช่ alias จึงใช้ในสคริปต์ได้ด้วย การตั้งค่า `CLAUDE.md` เซิร์ฟเวอร์ MCP และส่วนขยายใช้ร่วมกันตั้งแต่แรก และคุณเปิดใช้ประวัติการสนทนาร่วมกันได้ เพื่อสนทนาต่อในอีกบัญชีหนึ่งด้วย `ccam next --continue`

หากคุณใช้ `~/.claude` อยู่แล้ว ให้รัน `ccam import` แทนการเพิ่มบัญชีนั้นใหม่ หรือรัน `ccam migrate` เพื่อคัดลอกการตั้งค่า เซิร์ฟเวอร์ MCP และส่วนขยายของโฟลเดอร์นั้นไปยังการตั้งค่าที่ใช้ร่วมกัน

## ควรเลือกแบบไหน

สำหรับสองบัญชีที่ไม่ใช้อะไรร่วมกัน alias ก็เพียงพอ เมื่อคุณต้องการใช้การตั้งค่าและเซิร์ฟเวอร์ MCP ร่วมกัน ใช้บัญชีมากขึ้น ดูการใช้งานได้ในพริบตา หรือสนทนาต่อข้ามบัญชี ccam จะช่วยลดงานจัดการเหล่านี้ [การเปรียบเทียบ](/compare/aliases) แสดงความแตกต่างแบบเทียบกันทีละข้อ
