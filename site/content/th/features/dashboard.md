`ccam` ที่ไม่มีอาร์กิวเมนต์จะเปิดแดชบอร์ดเต็มหน้าจอเมื่ออินพุตและเอาต์พุตมาตรฐานเป็นเทอร์มินัล ในกรณีอื่นจะพิมพ์ `ccam list` แดชบอร์ดแสดงทุกบัญชีพร้อมการใช้งานและกลุ่ม และทำสิ่งเดียวกับที่คำสั่งต่าง ๆ ทำได้: เริ่ม เพิ่ม เข้าสู่ระบบ เปลี่ยนกลุ่ม ตั้งกฎของโฟลเดอร์ ตรวจสอบ และซ่อมแซม การเริ่มบัญชีจะปิดแดชบอร์ด ส่วนการเพิ่มบัญชีหรือการเข้าสู่ระบบจะออกจากแดชบอร์ดไปใช้เทอร์มินัลชั่วคราวแล้วกลับมา

```console
 ccam v0.9.0 · 3 accounts · 2 groups         ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health

    # Account     Email             5-hour         7-day Last  Groups
 ❯ 1. personal ✔   me@example.com    █████▊░░  72%   41% 2h    default
   2. work      ▸• dev@company.com   ██░░░░░░  25%  100% now   default team
   3. side         -                 ✘ not logged in         -     no group

 ✔ personal is the default account
 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

เฟรมแรกวาดจาก `config.toml` เพียงไฟล์เดียว ใช้เวลาน้อยกว่า 100 ms มาก ตัวเลขการใช้งานจะปรากฏขึ้นเมื่อแต่ละบัญชีได้รับคำตอบ เปอร์เซ็นต์จะเปลี่ยนเป็นสีเหลืองตั้งแต่ 80% และเป็นสีแดงที่ 100% ส่วนค่าที่มาจากแคชหลังการสอบถามล้มเหลวจะแสดงเป็นสีจาง

## แท็บ

| แท็บ | สิ่งที่แสดง | ปุ่ม |
| --- | --- | --- |
| Accounts | หมายเลข ชื่อ อีเมล แถบ 5 ชั่วโมง การใช้งาน 7 วัน เวลาที่ใช้ล่าสุด กลุ่ม โดย `✔` คือบัญชีเริ่มต้น `▸` คือบัญชีของโฟลเดอร์นี้ และ `•` คือกำลังทำงาน | ดูด้านล่าง |
| Groups | แต่ละกลุ่ม สิ่งที่กลุ่มใช้ร่วมกัน และบัญชีในกลุ่ม รวมถึงบัญชีที่ไม่อยู่ในกลุ่มใด | `enter` แก้ไข, `n` สร้างใหม่, `e` เปลี่ยนชื่อ, `x` ลบ |
| Folders | กฎของ [`ccam folder`](/features/folder) และกฎที่มีผลในโฟลเดอร์นี้ | `n` ใช้บัญชีหนึ่งที่นี่, `enter` เปลี่ยน, `x` ลบ |
| Extensions | สิ่งที่ [`ccam ext`](/features/ext) แสดง โดยแสดงแต่ละส่วนขยายครั้งเดียวพร้อมกลุ่มที่ส่วนขยายนั้นมาจาก | `r` โหลดใหม่ |
| Health | สิ่งที่ [`ccam doctor`](/features/doctor) รายงาน | `f` ซ่อมแซม (`doctor --fix`) |

`←`/`→` หรือ `Tab` ใช้สลับแท็บ `?` แสดงปุ่มของแท็บปัจจุบัน `r` สอบถามการใช้งานใหม่โดยไม่ใช้แคชระยะสั้น และ `q` หรือ `Esc` ใช้ออก

## ปุ่มในแท็บ Accounts

| ปุ่ม | สิ่งที่ทำ |
| --- | --- |
| `Enter` | เริ่ม Claude Code ในชื่อบัญชีที่เลือก |
| `1`–`9` | เลื่อนไปที่บัญชีที่มีหมายเลขนั้น พิมพ์ `1` `2` ติดกันเร็ว ๆ เพื่อไปที่ 12 มีเพียง `Enter` ที่เริ่มบัญชี |
| `↑`/`↓`, `k`/`j` | เลื่อน |
| `n` | เริ่มบัญชีที่ [`ccam next --auto`](/features/next) จะเลือก |
| `o` | เริ่มพร้อมตัวเลือก: `--continue`, `--resume`, อาร์กิวเมนต์อื่น หรือการทดลองรัน |
| `u` | รายละเอียดการใช้งาน: ช่วง 5 ชั่วโมง 7 วัน และของแต่ละโมเดล พร้อมเวลารีเซ็ตและแหล่งที่มาของตัวเลข |
| `a` | เพิ่มบัญชี (ตัวช่วยตั้งค่าด้านล่าง) |
| `l` | เข้าสู่ระบบอีกครั้ง |
| `s` | เลือกกลุ่มของบัญชี |
| `d` | ตั้งเป็นบัญชีเริ่มต้น |
| `f` | ใช้บัญชีนี้ในโฟลเดอร์ปัจจุบัน |
| `e` | เปลี่ยนชื่อ |
| `c` | ตั้งหรือลบคำสั่งลัดของบัญชี |
| `x` | ลบบัญชี (ถามก่อน โดยเริ่มที่ No) |

## การเปลี่ยนกลุ่ม

ในแท็บ Groups `Enter` จะเปิดตัวแก้ไข: รายการอยู่ทางซ้าย บัญชีอยู่ทางขวา `Tab` ใช้สลับฝั่ง และ `Space` ใช้สลับเปิดปิด รายการที่บัญชีใดบัญชีหนึ่งได้รับจากกลุ่มอื่นอยู่แล้วจะแสดงเป็นสีเทาพร้อมเหตุผล เช่นเดียวกับบัญชีที่จะได้รับรายการเดียวกันซ้ำสองครั้ง รายการหนึ่งมาจากกลุ่มเดียวได้เท่านั้น `Enter` จะแสดงแผน:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

ไฟล์ที่ต่างจากสำเนาของกลุ่มจะถูกถามก่อน (เก็บของกลุ่มไว้ ใช้ของฉัน หรือรวมกัน) จากนั้นการเปลี่ยนแปลงจะทำงานเบื้องหลังด้วยโค้ดเดียวกับ [`ccam group`](/features/share): การตั้งค่าจะถูกบันทึกก่อน ข้อมูลของแต่ละบัญชีจะถูกย้ายตามลำดับ และต้นฉบับจะไปอยู่ที่ `.ccam-backup/` การเปลี่ยนแปลงที่จะย้ายข้อมูลของบัญชีที่กำลังทำงานจะถูกปฏิเสธพร้อมระบุชื่อบัญชีนั้น

## การเพิ่มบัญชี

`a` จะเปิดตัวช่วยตั้งค่าเดียวกับที่ `ccam add` ใช้บนเทอร์มินัล:

1. ชื่อบัญชี
2. วิธีลงชื่อเข้าใช้: การสมัครสมาชิก Claude ตอนนี้ (ในเบราว์เซอร์) [API key](/features/api) หรือการสมัครสมาชิก Claude ภายหลัง
3. สำหรับ API key: ตำแหน่งที่ ccam อ่านคีย์ทุกครั้งที่เริ่ม (`env:NAME` หรือ `command:COMMAND`) endpoint วิธีส่งคีย์ และโมเดล
4. กลุ่มที่จะเข้าร่วม โดยเลือก `default` ไว้ หากยังไม่มีกลุ่มใด จะเป็นสิ่งที่กลุ่ม `default` จะใช้ร่วมกัน
5. คำสั่งลัด หากคุณต้องการ
6. สรุปให้ยืนยัน

`Esc` ใช้ย้อนกลับหนึ่งขั้น และในขั้นแรกจะปิดตัวช่วยตั้งค่า

## สี

สีเป็นไปตามบทบาทสีในอินเทอร์เฟซเทอร์มินัลของ Claude Code ccam จึงดูกลมกลืนเมื่ออยู่ข้างกัน ชื่อกลุ่มได้สีตามชื่อของกลุ่ม ccam ถามเทอร์มินัลว่าพื้นหลังเป็นสีอะไรแล้วเลือกธีมสว่างหรือมืด คุณตั้งธีมเองได้ใน `config.toml`:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

ธีม `-daltonized` มีไว้สำหรับผู้ที่ตาบอดสีแดงเขียว และธีม `-ansi` ใช้ 16 สีของเทอร์มินัลเอง `NO_COLOR` จะปิดสี

## ความปลอดภัยและกรณีพิเศษ

- แดชบอร์ดเรียกฟังก์ชันเดียวกับคำสั่ง ทุกกฎจึงยังมีผล: แสดงแผนก่อนย้ายข้อมูล ปฏิเสธเมื่อบัญชีกำลังทำงาน มีการสำรอง และโทเค็นการเข้าสู่ระบบไม่เคยออกจากบัญชี
- แดชบอร์ดไม่มีการทดลองรัน: `ccam --dry-run` ที่ไม่ระบุชื่อจะพิมพ์ว่าบัญชีของโฟลเดอร์นี้จะเริ่มอย่างไร และการกด `o` บนบัญชีหนึ่งจะเสนอการทดลองรันสำหรับการเริ่มครั้งนั้นครั้งเดียว
- เทอร์มินัลจะกลับสู่สภาพเดิมก่อนที่ Claude Code จะเริ่มหรือการเข้าสู่ระบบจะเปิดขึ้น
- หน้าจอที่เล็กเกินกว่าจะแสดงกล่องโต้ตอบจะตัดแถวของแท็บออกก่อน และบรรทัดจะถูกตัดด้วย `…` แทนการขึ้นบรรทัดใหม่
