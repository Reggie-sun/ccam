เครื่องมือสลับบัญชี Claude Code ใช้แนวทางใดแนวทางหนึ่งจากสองแบบ ส่วนใหญ่สลับการเข้าสู่ระบบภายในโฟลเดอร์ `~/.claude` เพียงโฟลเดอร์เดียว จึงใช้งานได้ทีละบัญชี ส่วนเครื่องมืออื่นรวมถึง ccam ให้แต่ละบัญชีมีโฟลเดอร์ของตัวเองด้วย `CLAUDE_CONFIG_DIR` ทุกบัญชีจึงยังเข้าสู่ระบบอยู่และรันหลายบัญชีพร้อมกันได้ ccam ยังเพิ่มการใช้การตั้งค่าและเซิร์ฟเวอร์ MCP ร่วมกัน และสนทนาต่อในโฟลเดอร์ของอีกบัญชีหนึ่งได้

## สลับการเข้าสู่ระบบชุดเดียว หรือแยกโฟลเดอร์?

**การสลับการเข้าสู่ระบบ** มีการตั้งค่า เซิร์ฟเวอร์ MCP และประวัติเพียงชุดเดียว เพราะมีโฟลเดอร์เดียว การสลับทำได้เร็ว และเซสชันที่กำลังทำงานอยู่ก็รับการเข้าสู่ระบบใหม่ได้ แต่ใช้งานได้ทีละบัญชีเท่านั้น สำหรับทุกเทอร์มินัลและทุกเอดิเตอร์พร้อมกัน

**การแยกโฟลเดอร์** เป็นวิธีที่[เอกสารของ Claude Code อธิบายไว้](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) ทุกบัญชียังเข้าสู่ระบบอยู่ และคุณรันเซสชันงานกับเซสชันส่วนตัวควบคู่กันได้ ข้อแลกเปลี่ยนคือแต่ละโฟลเดอร์เริ่มต้นด้วยการตั้งค่า เซิร์ฟเวอร์ MCP และประวัติของตัวเอง เว้นแต่จะมีเครื่องมือช่วยให้ใช้ร่วมกัน

## เปรียบเทียบเครื่องมือ

ข้อมูลจากเอกสารของแต่ละโปรเจกต์ ณ วันที่ 2026-10-19 "ไม่ได้ระบุในเอกสาร" หมายถึงโปรเจกต์ไม่ได้กล่าวถึง ไม่ได้หมายความว่าไม่มีฟีเจอร์นั้น

| เครื่องมือ | แนวทาง | หลายบัญชีพร้อมกัน | การใช้งาน 5 ชั่วโมงและรายสัปดาห์ | เมื่อถึงขีดจำกัด | แพลตฟอร์ม |
| --- | --- | --- | --- | --- | --- |
| ccam | แยกโฟลเดอร์ | ได้ | ได้ `ccam usage` | คุณรัน `ccam next --auto --continue` เพื่อสนทนาต่อในบัญชีที่เหลือโควตามากที่สุด | Linux, macOS, WSL |
| [claude-swap](https://github.com/realiti4/claude-swap) | สลับการเข้าสู่ระบบ; แยกโฟลเดอร์ด้วย `cswap run` | ได้ เมื่อใช้ `cswap run` | ได้ | `cswap auto` สลับการเข้าสู่ระบบเมื่อถึงเกณฑ์ เซสชันที่ทำงานอยู่ยังทำงานต่อ | Linux, macOS, Windows |
| [CCS](https://github.com/kaitranntt/ccs) | แยกโฟลเดอร์ | ได้ | บางส่วน ในแอปแถบเมนูของ macOS | กลุ่มบัญชีส่งคำขอต่อไปยังบัญชีถัดไปผ่านพร็อกซีในเครื่อง | Linux, macOS, Windows |
| [clauth](https://github.com/uwuclxdy/clauth) | สลับการเข้าสู่ระบบ; แยกโฟลเดอร์ด้วย `clauth start` | ได้ เมื่อใช้ `clauth start` | ได้ | สลับไล่ตามลำดับบัญชีสำรอง | Linux, macOS, Windows |
| [CAAM](https://github.com/Dicklesworthstone/coding_agent_account_manager) | สลับการเข้าสู่ระบบ หรือโปรไฟล์ที่แยกขาดจากกัน | ได้ เมื่อใช้โปรไฟล์ที่แยกขาดจากกัน | ได้ | `caam run` ลองรันคำสั่งแบบไม่โต้ตอบอีกครั้งในบัญชีอื่น | Linux, macOS, Windows |
| [cux](https://github.com/inulute/cux) | สลับการเข้าสู่ระบบและครอบ `claude` | ไม่ได้ระบุในเอกสาร | ได้ | สลับการเข้าสู่ระบบและสนทนาเดิมต่อ | Linux, macOS, Windows |
| [CCSwitcher](https://github.com/XueshiQiao/CCSwitcher) | สลับการเข้าสู่ระบบ | ไม่ได้ | ได้ | ไม่ได้ระบุในเอกสาร | macOS |
| [Claude Switcher](https://github.com/Symbioose/claude-account-switcher) | สลับการเข้าสู่ระบบ | ไม่ได้ | ได้ | สลับเมื่อถึง 100% (เลือกเปิดได้) | macOS |

ccswap เป็น fork ของ claude-swap ที่จัดการการเข้าสู่ระบบ Codex ด้วย เครื่องมือหลายตัวในนี้รองรับ coding agent อื่นด้วย เช่น Codex หรือ Gemini

## สิ่งที่ ccam ให้ความสำคัญ

- ทุกบัญชียังเข้าสู่ระบบอยู่เสมอ การสลับไม่เคยทำให้บัญชีใดออกจากระบบ และ `ccam work` กับ `ccam personal` รันพร้อมกันในสองเทอร์มินัลได้
- เซิร์ฟเวอร์ MCP, `settings.json`, `CLAUDE.md`, เอเจนต์ สกิล และปลั๊กอินใช้ร่วมกันระหว่างโฟลเดอร์ผ่านลิงก์ เลือกได้ทีละรายการและทีละบัญชี การเข้าสู่ระบบไม่เคยถูกใช้ร่วมกัน
- เมื่อใช้ประวัติร่วมกัน คำสั่งเดียว `ccam next --auto --continue` จะเปิดการสนทนาเดิมในโฟลเดอร์ของบัญชีที่เหลือโควตามากที่สุด
- ccam เริ่ม Claude Code แล้วแทนที่ตัวเองด้วย Claude Code จึงไม่มีอะไรทำงานอยู่เบื้องหลัง ccam ไม่เฝ้าดูการใช้งานหรือสลับเอง คุณเป็นผู้ตัดสินใจว่าจะสลับเมื่อไร

## สิ่งที่เครื่องมืออื่นทำได้มากกว่า

- claude-swap, CCS, clauth, CAAM และ cux ทำงานบน Windows ได้โดยไม่ต้องใช้ WSL แต่ ccam ทำไม่ได้
- claude-swap, clauth และ cux สลับเองเมื่อบัญชีใช้งานเกินเกณฑ์ ส่วน ccam ปล่อยให้คุณเป็นผู้สลับ
- CCSwitcher, Claude Switcher และ claude-swap แสดงการใช้งานในแถบเมนูของ macOS
- CCS, CAAM, ccswap และ Claude Switcher จัดการ Codex และ coding agent อื่นด้วย

## แบบไหนเหมาะกับคุณ?

เลือกเครื่องมือที่สลับการเข้าสู่ระบบ หากคุณใช้ทีละบัญชี ต้องการให้สลับอัตโนมัติ หรือใช้ Windows โดยไม่มี WSL เลือก ccam หากคุณต้องการใช้หลายบัญชีควบคู่กัน มีการตั้งค่าชุดเดียวที่ใช้ร่วมกัน และสนทนาเดิมต่อในบัญชีถัดไป หากไม่ต้องใช้อะไรร่วมกันเลย [shell alias ธรรมดา](/compare/aliases) ก็เพียงพอ

การใช้หลายบัญชีได้หรือไม่ขึ้นอยู่กับข้อกำหนดของแต่ละบัญชี โปรดตรวจสอบก่อนใช้งาน
