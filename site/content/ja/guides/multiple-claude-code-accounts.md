Claude Codeで複数アカウントを使うには、各アカウントに専用の設定フォルダーを割り当てます。Claude Codeは`CLAUDE_CONFIG_DIR`環境変数からフォルダーを読み取り、各フォルダーにはそれぞれのログイン、設定、履歴が保存されます。シェルエイリアスを使って手動で設定することも、ccamに任せることもできます。

## 手動で、エイリアスを使う

これはClaude Codeのドキュメントで説明されている方法です。追加するアカウントごとに1行を`~/.bashrc`または`~/.zshrc`に追加します。

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

新しいターミナルを開き、`claude-work`を実行します。フォルダーが新しいので、Claude Codeからログインを求められます。それ以降は、`claude`が1つ目のアカウント、`claude-work`が2つ目のアカウントになります。

アカウントが2つならこの方法で十分です。知っておくべき点は次のとおりです。

- 各フォルダーは空の状態から始まります。設定も、`CLAUDE.md`も、MCPサーバーも、エージェントやスキルもありません。必要なものをコピーまたはリンクし、コピーの内容を自分でそろえ続ける必要があります。
- エイリアスは対話型シェルの中にしか存在しません。スクリプト、Makefile、その他のプログラムからは見えません。
- MCPサーバーはログインと同じ`.claude.json`に保存されるため、単純にフォルダー間でリンクすることはできません。
- 会話は開始したアカウントに残るため、別のアカウントで続けることはできません。
- すべてのアカウントの使用量を一度に表示する手段はありません。

## ccamを使う

ccamは同じ考え方を自動化し、足りない部分を補います。

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
```

これで、`claude1`と`claude2`、または`ccam personal`と`ccam work`で2つのアカウントを起動できます。これらはエイリアスではなく実際のプログラムなので、スクリプトの中でも動作します。設定、`CLAUDE.md`、MCPサーバー、拡張機能は最初から共有されます。会話履歴の共有を有効にすれば、`ccam next --continue`でもう一方のアカウントに切り替えて会話を続けられます。

すでに`~/.claude`を使っている場合は、そのアカウントを改めて追加する代わりに`ccam import`を実行してください。

## どちらを選ぶか

アカウントが2つで何も共有しないなら、エイリアスで十分です。設定やMCPサーバーを共有したい場合、アカウントがもっと多い場合、使用量をひと目で確認したい場合、会話を続けたい場合は、ccamを使えば管理の手間が省けます。違いは[比較](/compare/aliases)のページで並べて紹介しています。
