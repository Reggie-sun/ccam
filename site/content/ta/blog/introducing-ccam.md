ccam என்பது ஒரே கணினியில் ஒன்றுக்கு மேற்பட்ட Claude Code கணக்குகளைப் பயன்படுத்துபவர்களுக்கான சிறிய கட்டளை வரி கருவி: ஒரு தனிப்பட்ட கணக்கும் ஒரு வேலைக் கணக்கும், அல்லது ஒரு நீண்ட திட்டத்துக்குப் பல கணக்குகள்.

## சிக்கல்

Claude Code, `CLAUDE_CONFIG_DIR` மூலம் பல கணக்குகளை ஆதரிக்கிறது: ஒவ்வொரு கணக்குக்கும் ஒரு கோப்புறை. நடைமுறையில், ஒவ்வொரு கோப்புறையும் ஒரு தனித் தீவு. அமைப்புகள், `CLAUDE.md`, MCP சர்வர்கள், agents, skills ஆகியவற்றை ஒவ்வொரு கோப்புறையிலும் மீண்டும் அமைத்து, கையால் ஒத்திசைவில் வைக்க வேண்டும். உரையாடல்கள் தொடங்கிய இடத்திலேயே இருக்கும். ஒரு கணக்கு அதன் பயன்பாட்டு வரம்பை அடைந்ததை, முயற்சி செய்து பார்த்துத்தான் தெரிந்துகொள்வீர்கள்.

## ccam என்ன செய்கிறது

- `ccam add` கோப்புறையை உருவாக்கி, உள்நுழைவை இயக்கி, கணக்குக்கு ஒரு குறுக்குவழியைக் கொடுக்கிறது: `claude1`, `claude2` என்று தொடரும்.
- `ccam work` மற்றும் `claude2` அந்தக் கணக்காக Claude Code-ஐத் தொடங்கி, ஒவ்வொரு argument-ஐயும் மாற்றமின்றி அனுப்புகின்றன.
- MCP சர்வர்கள், அமைப்புகள், `CLAUDE.md`, நீட்டிப்புகள் ஆகியவை இணைப்புகள் மூலம், உருப்படி வாரியாகவும் கணக்கு வாரியாகவும் பகிரப்படுகின்றன. உள்நுழைவுகள் ஒருபோதும் பகிரப்படாது.
- `ccam usage` எல்லாக் கணக்குகளின் 5 மணி நேர மற்றும் வாராந்திரப் பயன்பாட்டைக் காட்டுகிறது; `ccam next --continue` உரையாடலை அடுத்த கணக்கில் தொடர்கிறது.

## குறுக்கிடாமல் இருப்பது

ஒவ்வொரு அமர்வுக்கும் முன் இயக்கும் கருவி, நீங்கள் கவனிக்கும் அளவுக்கு எந்தச் செலவையும் ஏற்படுத்தக் கூடாது. ccam ஒரு config கோப்பைப் படிக்கிறது, பகிரப்பட்ட ஒவ்வொரு இணைப்பையும் ஒரே system call மூலம் சரிபார்க்கிறது, பிறகு தன்னை `claude` ஆக மாற்றிக்கொள்கிறது. இது சுமார் 4 மில்லிவினாடிகள் சேர்க்கிறது, நீங்கள் வேலை செய்யும்போது இயங்குவதில்லை.

இது உங்கள் கோப்புகளிலும் கவனமாக இருக்கிறது. பகிர்வில் செய்யும் ஒவ்வொரு மாற்றமும், தொடங்கும் முன் ஒரு திட்டத்தை அச்சிட்டு, அசல் கோப்புகளை ஒரு காப்புப்பிரதி கோப்புறையில் வைக்கிறது. `ccam doctor` இணைப்புகள், அனுமதிகள், உள்நுழைவுகளைச் சரிபார்த்து, பாதுகாப்பாகச் சரிசெய்யக்கூடியவற்றைச் சரிசெய்கிறது.
