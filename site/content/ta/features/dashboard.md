standard input-உம் output-உம் டெர்மினலாக இருக்கும்போது, arguments இல்லாத `ccam` ஒரு முழுத்திரை டாஷ்போர்டைத் திறக்கிறது; இல்லையெனில் அது `ccam list`-ஐ அச்சிடுகிறது. டாஷ்போர்டு ஒவ்வொரு கணக்கையும் அதன் பயன்பாடு, குழுக்களுடன் காட்டுகிறது, கட்டளைகள் செய்வதையே செய்கிறது: தொடங்குதல், சேர்த்தல், உள்நுழைதல், குழுக்களை மாற்றுதல், கோப்புறை விதிகளை அமைத்தல், பின்னணி அமர்வுகளைப் பட்டியலிடுதல், சரிபார்த்தல், பழுதுநீக்குதல். ஒரு கணக்கைத் தொடங்கினாலோ, ஒரு பின்னணி அமர்வுடன் இணைந்தாலோ டாஷ்போர்டு மூடப்படும்; கணக்கைச் சேர்க்கும்போதும் உள்நுழையும்போதும் அது டெர்மினலுக்கு வழிவிட்டு, பிறகு திரும்பி வரும்.

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Agents   Groups   Folders   Extensions   Health    auto_switch off
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

தாவல் பெயர்களுக்குக் கீழே உள்ள வரி, தற்போதைய தாவல் எதற்கானது என்று ஒரே வாக்கியத்தில் சொல்கிறது. அகலமான டெர்மினலில் Accounts தாவல் ஒவ்வொரு கணக்கின் மின்னஞ்சலையும் காட்டுகிறது. [`auto_switch`](/features/next#auto-switch) இயக்கத்தில் உள்ளதா என்பதைத் தாவல் வரியின் முடிவு ஒவ்வொரு தாவலிலும் சொல்கிறது (Linux, macOS; Windows-இல் அது புறக்கணிக்கப்படுகிறது); அது இயக்கத்தில் இருக்கும்போது, அதற்கு இன்னும் என்ன தேவை என்பதை Health தாவல் சொல்கிறது: Claude subscription மூலம் உள்நுழையும் ஒவ்வொரு கணக்கிலும் இயக்கத்தில் உள்ள ccam plugin, மற்றும் Claude Code 2.1.214 அல்லது பிந்தையது.

ஒவ்வொரு முறை திறக்கும்போதும், புதிய ccam வெளியீடு உள்ளதா என்று டாஷ்போர்டு பின்னணியில் GitHub-இடம் கேட்கிறது; முதல் frame அதற்காக ஒருபோதும் காத்திருக்காது, இணையம் இல்லாதபோது எதுவும் காட்டப்படாது. புதிய வெளியீடு இருந்தால், தலைப்புக்குக் கீழே ஒரு வரி அதைப் பரிந்துரைக்கும்:

```console
 ● ccam 0.10.2 is available (you have 0.10.1) · press U to update
```

`U` முதலில் கேட்டு, பிறகு [`ccam update`](/features/update) செய்வது போலவே புதுப்பிக்கிறது: வெளியீடு அதன் SHA-256 checksums-உடன் சரிபார்க்கப்பட்டு, ஒரே படியில் ccam-ஐ மாற்றுகிறது. நீங்கள் இருக்கும் டாஷ்போர்டு இன்னும் பழைய பதிப்புதான், அதனால் வெளியேறி `ccam`-ஐ மீண்டும் தொடங்குங்கள். புதுப்பிப்பை இங்கே செய்ய முடியாதபோது, உதாரணமாக `.deb` தொகுப்பிலிருந்து நிறுவிய ccam-க்கு, டாஷ்போர்டு `ccam update` தரும் அதே ஆலோசனையைக் காட்டி, வழங்கலைத் தொடர்ந்து வைத்திருக்கும்.

முதல் frame `config.toml`-இலிருந்து மட்டுமே, 100 ms-க்கும் வெகு குறைவான நேரத்தில் வரையப்படுகிறது; ஒவ்வொரு கணக்கும் பதிலளிக்கும்போது பயன்பாட்டு எண்கள் நிரம்புகின்றன. ஒவ்வொரு வரம்புக்கும் தனிப் பட்டை உண்டு: 5 மணி நேர கால அளவு, எல்லா model-களுக்குமான வாராந்திர கால அளவு, Fable-இன் சொந்த வாராந்திர கால அளவு; `-` என்றால் கணக்குக்கு அத்தகைய கால அளவு இல்லை. ஒரு சதவீதம் 80%-இலிருந்து மஞ்சளாகவும் 100%-இல் சிவப்பாகவும் மாறும்; தேடல் தோல்வியடைந்த பிறகு cache-இலிருந்து வரும் மதிப்புகள் மங்கலாக வரையப்படும். Claude Code நிரம்பியதாகத் தெரிவித்த கால அளவு அதன் மீட்டமைப்பு வரை 100% எனக் காட்டும். காலாவதியான access token மங்கலான `⚠ token expired` எனக் காட்டும் (அடுத்த தொடக்கத்தில் Claude Code அதைப் புதுப்பிக்கும்); `⚠ login expired` என்றால் கணக்குக்கு `ccam login` தேவை.

| தாவல் | என்ன காட்டும் | விசைகள் |
| --- | --- | --- |
| Accounts | எண், பெயர், மின்னஞ்சல், 5 மணி நேர, வாராந்திர, Fable பட்டைகள், கடைசிப் பயன்பாடு, குழுக்கள்; `✔` இயல்புநிலைக் கணக்கு, `▸` இந்தக் கோப்புறையின் கணக்கு, `•` இயங்குகிறது (ccam இல்லாமல் தொடங்கிய Claude Code-உம்: வெறும் `claude`, ஒரு IDE, பின்னணி அமர்வுகள், அவற்றின் daemon) | கீழே |
| Agents | [`ccam agents`](/features/agents) பட்டியலிடுவது: எல்லாக் கணக்குகளின் பின்னணி அமர்வுகளும் திறந்த அமர்வுகளும், அவற்றின் நிலை, கோப்புறை, தொடங்கிய நேரத்துடன் (கீழே) | `enter` இணை (`ccam attach` போல), `x` நிறுத்து, `r` மீண்டும் ஏற்று |
| Groups | ஒவ்வொரு குழுவும், அது பகிர்வதும் அதன் கணக்குகளும், எந்தக் குழுவிலும் இல்லாத கணக்குகளும் | `enter` திருத்து, `n` புதியது, `e` மறுபெயரிடு, `x` நீக்கு |
| Folders | [`ccam folder`](/features/folder) விதிகளும், இங்கே பொருந்தும் விதியும், symbolic link வழியாக அந்தக் கோப்புறையை அடைந்திருந்தாலும் கூட (புதிய விதிகள் links தீர்க்கப்பட்ட நிலையில் சேமிக்கப்படும்) | `n` இங்கே ஒரு கணக்கைப் பயன்படுத்து, `enter` மாற்று, `x` நீக்கு |
| Extensions | [`ccam ext`](/features/ext) காட்டுவது; ஒவ்வொரு extension-உம் ஒருமுறை, அது வரும் குழுக்களுடன், ஒரு plugin இயக்கப்படாத கணக்குகள் `off:` ஆக, ஒரு கணக்கு இந்தக் கோப்புறைக்கு மட்டும் வைத்திருக்கும் சர்வர்கள் அதன் சொந்த சர்வர்களுக்கு இடையே, `This folder's project`, எந்தக் கணக்கையும் சாராத சிக்கல்கள் | `r` மீண்டும் ஏற்று |
| Health | [`ccam doctor`](/features/doctor) தெரிவிப்பது, ஒவ்வொரு கணக்குக்கும் ஒரு பெட்டியாக (கீழே) | `f` தேர்ந்தெடுத்த பெட்டியைப் பழுதுநீக்கு, `F` எல்லாவற்றையும் பழுதுநீக்கு (`doctor --fix`), `↑`/`↓` பெட்டிகளுக்கு இடையே நகரும் |

`←`/`→` அல்லது `Tab` தாவல்களை மாற்றும், `?` தற்போதைய தாவலின் விசைகளைப் பட்டியலிடும், `r` குறுகிய cache இல்லாமல் பயன்பாட்டை மீண்டும் பார்த்து, Agents, Extensions, Health தாவல்களை மீண்டும் ஏற்றும், `q` அல்லது `Esc` வெளியேறும்.

| `f` | தற்போதைய கோப்புறையில் அதைப் பயன்படுத்தும் |

**Team மற்றும் Enterprise இருக்கைகள்.** தானியங்கித் தேர்வு (`ccam next`, `--fallback`, `ccam pick`, டாஷ்போர்டின் `n`, நீங்கள் இயக்கும்போது [`auto_switch`](/features/next#auto-switch)) ஒரே Claude Team அல்லது Enterprise நிறுவனத்தின் இருக்கைகளுக்கு இடையேயும் மாறுகிறது. Anthropic-இன் உதவி மையம் "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (Team திட்டத்தின் ஒவ்வொரு இருக்கையும் பெயர் குறிப்பிடப்பட்ட ஒரு நபருக்கு ஒதுக்கப்படுகிறது, அந்த நபர் மட்டுமே அதைப் பயன்படுத்தலாம்) என்றும், "Users can't route their work through another user's account to use that user's remaining usage" (மற்றொரு பயனரின் மீதமுள்ள பயன்பாட்டைப் பயன்படுத்திக்கொள்ள, பயனர்கள் தங்கள் வேலையை அந்தப் பயனரின் கணக்கு வழியாக அனுப்ப முடியாது) என்றும் கூறுகிறது ([Team திட்டங்கள்](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129); இதேபோல் [Enterprise திட்டங்களுக்கும்](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0)). எனவே, இருக்கைகளுக்கு இடையே தானியங்கித் தேர்வைப் பயன்படுத்துவது Anthropic-இன் விதிமுறைகளை மீறக்கூடும். அங்கே அதைப் பயன்படுத்துவதா என்பது உங்கள் முடிவு: அதை நம்பியிருக்கும் முன், உங்கள் நிறுவனத்திடமும் Anthropic-இடமும் கேட்டு உறுதிசெய்துகொள்ளுங்கள். தனிப்பட்ட திட்டங்கள் (Pro, Max) பற்றி [அடிக்கடி கேட்கப்படும் கேள்விகளில் உள்ள விதிமுறைக் குறிப்பு](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) விளக்குகிறது.

## Health தாவல்

Health தாவலைத் திறக்கும்போது அது [`ccam doctor`](/features/doctor)-இன் சரிபார்ப்புகளை இயக்கி, அதே காட்சியை வரைகிறது: ஒவ்வொரு கணக்குக்கும் ஒரு குறியுடன் முதல் வரி, பிறகு ஒவ்வொரு கணக்குக்கும் ஒரு பெட்டி. பெட்டியில் உள்ள ஒவ்வொரு வரிசையும் சரிபார்க்கப்பட்ட ஒரு பகுதி, முதலில் `Folder`, `Login`, `Share links`, ஒவ்வொன்றும் `✔` சரி, `ℹ` தகவல், `⚠` எச்சரிக்கை அல்லது `✘` பிழை எனக் குறிக்கப்படும்; அதனால் எந்தக் கணக்கில் சிக்கல் உள்ளது, எங்கே என்று உடனே பார்க்கலாம். எந்தக் கணக்கையும் சாராத கண்டுபிடிப்புகள் ஒரு `General` பெட்டியில் செல்கின்றன.

```console
 ✘ personal   ⚠ work

 ╭─ ✘ personal · 3 problems ─────────────────────────────────────────────────╮
 │ ⚠ Folder       folder permissions are 755 (should be 0700)                │
 │ ℹ              unknown entries (ccam knows the folder layout of Claude    │
 │                Code 2.1.309; it may have changed): newthing               │
 │ ⚠ Login        .credentials.json permissions are 644 (should be 0600)     │
 │ ✔              login valid (me@example.com, Claude Team · Acme)           │
 │ ✘ Share links  /home/me/.local/share/ccam/profiles/personal/settings.json │
 │                : set to shared but is a real file, not a link             │
 │ ✔ Usage        usage lookup OK                                            │
 ╰───────────────────────────────────────────────────────────────────────────╯
 ╭─ ⚠ work · 1 problem ──────────────────────────────────────────────────────╮
 │ ✔ Folder       OK                                                         │
 │ ⚠ Login        not logged in → `ccam login work`                          │
 │ ✔ Share links  share links OK                                             │
 ╰───────────────────────────────────────────────────────────────────────────╯

 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` பெட்டியிலிருந்து பெட்டிக்கு நகரும், தேர்ந்தெடுத்த பெட்டிக்கு accent நிற எல்லை இருக்கும். `f` தேர்ந்தெடுத்த பெட்டியை மட்டும் பழுதுநீக்கும், `ccam doctor --fix` செய்வது போலவே: ஒரு கணக்கின் பெட்டியில் அந்தக் கணக்கை மட்டும் பழுதுநீக்கும், `General` பெட்டியில் எந்தக் கணக்கையும் சாராத கண்டுபிடிப்புகளை (plugin பாதைகள், shortcuts); மற்ற ஒவ்வொரு கணக்கும் மீண்டும் சரிபார்க்கப்படும், அவ்வளவுதான். அது முதலில் கேட்கும் (``Like `ccam doctor --fix`: missing links and group folders are made, and a real file where a link belongs is backed up first; where the group has its own copy, the account then sees the group's. Nothing is lost.``), பழுதுநீக்க எதுவும் இல்லாத பெட்டி `nothing to repair in <name>` என்று மட்டும் சொல்லும். `F` எல்லாவற்றையும் ஒரே நேரத்தில் பழுதுநீக்கும், `ccam doctor --fix` போல; `r` மீண்டும் சரிபார்க்கும்.

## Agents தாவல்

Agents தாவல் [`ccam agents`](/features/agents) அச்சிடுவதைக் காட்டுகிறது: எல்லாக் கணக்குகளின் பின்னணி அமர்வுகளும் திறந்த அமர்வுகளும், ஒவ்வொன்றும் எந்தக் கணக்குக்கு உரியது என்பதுடன். நீங்கள் முதன்முதலில் தாவலைத் திறக்கும்போதும், `r`-இலும், ஒரு நிறுத்தத்துக்குப் பிறகும், config மாற்றத்துக்குப் பிறகும், அது எல்லாக் கணக்குகளின் Claude Code-இடமும் ஒரே நேரத்தில் கேட்கிறது (`claude agents --json`, ஒவ்வொன்றுக்கும் 15 வினாடிகள் வரை); எல்லாம் பதில் அளிக்கும் வரை `Asking every account's Claude Code for its sessions…` என்று சொல்கிறது.

```console
  Accounts   Agents   Groups   Folders   Extensions   Health    auto_switch off
 Background agents and open sessions of every account; enter attaches to one.

    Account   ID        Name   State          Folder      Started
 ❯  work      -         -      open (busy)    ~/code/web  now
    personal  49ec0028  probe  blocked, idle  ~/code/app  12m

 ✘ lab: could not list its sessions: exit status 1 'claude agents --json' is
   not available in this environment.

 enter to attach · x to stop · r to reload · ? for shortcuts
```

`State` என்பது பின்னணி அமர்வின் நிலையும் அதன் process என்ன செய்கிறது என்பதும், அல்லது interactive அமர்வுக்கு `open`, `ccam agents`-இல் உள்ளது போலவே. கேட்க முடியாத கணக்குக்கு, Claude Code சொன்னதுடன் பட்டியலுக்குக் கீழே ஒரு `✘` வரி கிடைக்கிறது, மேலே உள்ள `lab` போல; அதன் agent view அணைக்கப்பட்டுள்ளது. முடிந்த பின்னணி அமர்வுகள் விலக்கப்படுகின்றன (`ccam agents --all` அவற்றைப் பட்டியலிடுகிறது); எல்லாக் கணக்குகளும் பதில் அளித்து, எதற்கும் அமர்வு இல்லாதபோது, தாவல் ``No sessions. Start one in the background with `ccam <account> --bg "…"`.`` என்று சொல்கிறது. குறுகிய டெர்மினலில் தாவல் முதலில் `Started`, பிறகு `Name`, பிறகு `Folder`-ஐ விடுகிறது, நீண்ட கோப்புறையை இடப்பக்கத்திலிருந்து வெட்டுகிறது.

பின்னணி அமர்வின் மீது `Enter` டாஷ்போர்டை மூடி, `ccam attach <id>` செய்வது போலவே, அந்த அமர்வை அதன் கணக்காக இந்த டெர்மினலில் திறக்கிறது; டாஷ்போர்டு திரும்பி வராது (Claude Code-இல், `←` அதன் agent view-க்கும் `Ctrl+Z` shell-க்கும் செல்லும்). திறந்த அமர்வுக்கு id இல்லை, அதனால் `Enter`-உம் `x`-உம் பின்னணி அமர்வு தேவை என்று மட்டும் சொல்கின்றன. `x` முதலில் கேட்கிறது, `No, keep it`-இல் தொடங்கி: ``It runs as personal. Like `ccam personal stop 49ec0028`, Claude Code stops it and keeps its conversation, which `ccam attach 49ec0028` opens again.`` ஆம் என்றால், ccam அந்தக் கணக்காக `claude stop <id>`-ஐ இயக்கி, ``49ec0028 (personal) stopped; `ccam attach 49ec0028` opens it again`` அல்லது ஏன் முடியவில்லை என்று சொல்லி, பட்டியலை மீண்டும் படிக்கிறது.

## குழுக்களை மாற்றுதல்

Groups தாவலில், `Enter` திருத்தியைத் திறக்கும்: இடப்பக்கம் உருப்படிகள், வலப்பக்கம் கணக்குகள்; மாற `Tab`, இயக்க அல்லது அணைக்க `Space`. கணக்குகளில் ஒன்று ஏற்கெனவே வேறொரு குழுவிலிருந்து பெறும் உருப்படி காரணத்துடன் சாம்பல் நிறமாக்கப்படும்; ஓர் உருப்படியை இருமுறை பெறக்கூடிய கணக்கும் அப்படியே. ஓர் உருப்படி ஒரே ஒரு குழுவிலிருந்து மட்டுமே வர முடியும். `Enter` திட்டத்தைக் காட்டும்:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

குழுவின் நகலிலிருந்து வேறுபடும் கோப்பைப் பற்றி முதலில் கேட்கப்படும் (குழுவுடையதை வைத்திருத்தல், என்னுடையதைப் பயன்படுத்துதல், அல்லது ஒன்றிணைத்தல்). பிறகு [`ccam group`](/features/share)-இன் அதே code உடன் மாற்றம் பின்னணியில் இயங்கும்: முதலில் config சேமிக்கப்படும், ஒவ்வொரு கணக்கின் தரவும் வரிசையாக நகரும், மூலக் கோப்புகள் `.ccam-backup/`-க்குச் செல்லும்; MCP பகிர்விலிருந்து விலகும் கணக்கு குழுவின் சர்வர்களைத் தன் `.claude.json`-இல் வைத்துக்கொள்ளும். இயங்கிக்கொண்டிருக்கும் கணக்கின் தரவை நகர்த்தக்கூடிய மாற்றம், திட்டம் திறந்திருந்தபோது அந்தக் கணக்கு தொடங்கியிருந்தாலும், அந்தக் கணக்கின் பெயருடன் மறுக்கப்படும்; மற்றொரு ccam-இன் குழு மாற்றத்தால் பழையதாகிவிட்ட திட்டம் `the groups changed while this plan waited; nothing was moved, make the change again` என்று மறுக்கப்படும். மற்றொரு ccam குழுக்களை மாற்றிக்கொண்டிருக்கும்போது, புதிய மாற்றம், மறுபெயரிடுதல் அல்லது நீக்குதல் `another ccam is changing the groups right now` என்று சொல்லும்; பாதியில் நின்ற மாற்றத்துக்குப் பிறகு, Health தாவலில் `F` (அல்லது `ccam doctor --fix`) அதை முடிக்கும் வரை அவை காத்திருக்கும்.

## ஒரு கணக்கைச் சேர்த்தல்

`a`, டெர்மினலில் `ccam add`-உம் பயன்படுத்தும் wizard-ஐத் திறக்கும்:

1. கணக்கின் பெயர்.
2. அது எப்படி உள்நுழைகிறது: இப்போதே ஒரு Claude subscription (browser-இல்), ஒரு [API key](/features/api), அல்லது பின்னர் ஒரு Claude subscription.
3. API key-க்கு: ஒவ்வொரு தொடக்கத்திலும் ccam key-ஐ எங்கிருந்து படிக்கிறது (`env:NAME` அல்லது `command:COMMAND`), endpoint, key எப்படி அனுப்பப்படுகிறது, model.
4. சேர வேண்டிய குழுக்கள், `default` ஏற்கெனவே தேர்வு செய்யப்பட்டிருக்கும்; குழுக்கள் எதுவும் இல்லாதபோது, `default` குழு எதைப் பகிர்கிறது என்பது.
5. விரும்பினால், ஒரு குறுக்குவழிக் கட்டளை.
6. உறுதிப்படுத்த ஒரு சுருக்கம்.

`Esc` ஒரு படி பின்னால் செல்லும்; முதல் படியில் அது wizard-ஐ மூடும்.

## ஒரு கணக்கை நீக்குதல்

`x` எதுவும் நடப்பதற்கு முன், No-இல் தொடங்கி, கேட்கும், நீக்கம் என்ன செய்யும் என்றும் சொல்லும்: `It is logged out first (its login is revoked), then its folder goes to ccam's trash; the groups' shared files stay.` API key கணக்குக்கு ரத்துசெய்ய உள்நுழைவு இல்லை; அதே உள்நுழைவை மற்றொரு கணக்கு வைத்திருக்கும்போது அது வெளியேற்றப்படுவதில்லை. இறக்குமதி செய்யப்பட்ட கணக்கு தன் கோப்புறையை வைத்திருக்கும்: `It was imported, so its folder /home/me/.claude stays where it is: it leaves its groups first and keeps a copy of what they share, then ccam forgets it.`

## நிறங்கள்

நிறங்கள் Claude Code-இன் டெர்மினல் UI-இல் உள்ள பாத்திரங்களைப் பின்பற்றுகின்றன, அதனால் ccam அதன் அருகில் இயல்பாகப் பொருந்துகிறது; குழுப் பெயர்கள் தங்கள் பெயரிலிருந்தே ஒரு நிறத்தைப் பெறுகின்றன. ccam டெர்மினலிடம் அதன் பின்னணி நிறத்தைக் கேட்டு, ஒளிர்வான அல்லது இருண்ட theme-ஐத் தேர்ந்தெடுக்கிறது. `config.toml`-இன் மேற்பகுதியில், முதல் `[[group]]`, `[[profile]]` அல்லது `[[folder]]`-க்கு மேலே, நீங்களே ஒன்றை அமைக்கலாம்:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` themes சிவப்பு-பச்சை நிறக்குருடு உள்ளவர்களுக்கானவை, `-ansi` themes டெர்மினலின் சொந்த 16 நிறங்களைப் பயன்படுத்துகின்றன. `NO_COLOR` நிறங்களை அணைக்கிறது.

## பாதுகாப்பும் விளிம்பு நிலைகளும்

- டாஷ்போர்டு கட்டளைகள் அழைக்கும் அதே functions-ஐ அழைக்கிறது, அதனால் ஒவ்வொரு விதியும் பொருந்தும்: தரவு நகர்வதற்கு முன் திட்டங்கள், இயங்கும் கணக்குகளுக்கு மறுப்புகள், காப்புப்பிரதிகள், ஒரு கணக்கை விட்டு ஒருபோதும் வெளியேறாத உள்நுழைவு tokens.
- டாஷ்போர்டில் dry run இல்லை: பெயர் இல்லாமல் `ccam --dry-run` இந்தக் கோப்புறையின் கணக்கு எப்படித் தொடங்கும் என்பதை அச்சிடுகிறது, ஒரு கணக்கில் `o` அந்த ஒரு தொடக்கத்துக்கு மட்டும் ஒரு dry run-ஐ வழங்குகிறது.
- Claude Code தொடங்குவதற்கு அல்லது உள்நுழைவு திறப்பதற்கு முன் டெர்மினல் மீட்டமைக்கப்படுகிறது.
- ஒரு dialog-க்குத் திரை மிகச் சிறியதாக இருந்தால், முதலில் தாவலின் வரிசைகள் விடப்படுகின்றன; வரிகள் மடிக்கப்படுவதற்குப் பதிலாக `…` உடன் வெட்டப்படுகின்றன. உயரம் குறைந்த திரையில் அடுத்து வெற்று வரிகளும் தாவல் விளக்கமும் விடப்படுகின்றன, அதனால் விசைகளின் வரி அப்படியே இருக்கும். 40 நெடுவரிசைகள் அல்லது 8 வரிசைகளுக்குக் கீழே, டாஷ்போர்டு `Too small: ccam needs 40x8 (now 36x7)` என்பதை மட்டுமே காட்டும்.
- ஒரு மாற்றம், நீக்கம், புதுப்பிப்பு அல்லது பழுதுநீக்கம் பொருத்தப்பட்டுக்கொண்டிருக்கும்போது அழுத்தும் `Ctrl+C` அது முடியும் வரை காத்திருக்கும்: நிலை வரி `ccam quits when it is done.` என்று சொல்லும்.
- `U` ccam-ஐப் புதுப்பித்த பிறகு, கணக்கைச் சேர்த்த பின்போ உள்நுழைவுக்குப் பின்போ டாஷ்போர்டு திரும்பும்போது, வழங்கல் மீண்டும் வராது.
