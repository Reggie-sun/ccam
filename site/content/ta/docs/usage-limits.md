ஒவ்வொரு கணக்கும் 5 மணி நேர மற்றும் வாராந்திர வரம்புகளில் எவ்வளவு பயன்படுத்தியுள்ளது என்று `ccam usage` காட்டுகிறது. `ccam next --auto` அதிக இடம் உள்ள கணக்கைத் திறக்கிறது, `--continue` தற்போதைய உரையாடலை அதற்குக் கொண்டு செல்கிறது.

```console
$ ccam usage
 Account     5-hour        Resets    Weekly        Resets    As of
 1 personal  ██████░░  72% 1h 40m    ███░░░░░  41% 3d 6h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
 3 side      ████████ 100% 22m       █████░░░  68% 1d 9h     12m ago (cached)
→ Most headroom: work   (open it with ccam next --auto)
```

நெடுவரிசைகள்: கணக்கு, 5 மணி நேரப் பயன்பாடு, அது மீட்டமைக்கப்படும் வரையிலான நேரம், வாராந்திரப் பயன்பாடு, அது மீட்டமைக்கப்படும் வரையிலான நேரம், எண்கள் எவ்வளவு பழையவை.

## எண்கள் எங்கிருந்து வருகின்றன

ccam ஒவ்வொரு கணக்கின் சொந்த உள்நுழைவைப் பயன்படுத்தி, எல்லாக் கணக்குகளுக்கும் ஒரே நேரத்தில் Anthropic-இன் usage endpoint-இடம் கேட்கிறது. ஒவ்வொரு கணக்குக்கும் அதிகபட்சம் 3 வினாடிகள் காத்திருந்து, ஒவ்வொரு கணக்கும் பதில் அளித்தவுடன் அதைக் காட்டுகிறது.

இந்த endpoint பொதுவில் ஆவணப்படுத்தப்படவில்லை, மாறக்கூடும். ஒரு கோரிக்கை தோல்வியடைந்தால், ccam கடைசியாகத் தெரிந்த எண்களைக் காட்டி, அவற்றை cache என்று குறிக்கிறது. பதிலின் வடிவம் மாறியிருந்தால் `ccam doctor` உங்களுக்குச் சொல்லும்.

60 வினாடிகளுக்குள் பெறப்பட்ட எண்கள் மீண்டும் பயன்படுத்தப்படும். Options:

| Option | விளைவு |
| --- | --- |
| `--watch [seconds]` | தொடர்ந்து புதுப்பிக்கும், இயல்பாக ஒவ்வொரு 60 வினாடிக்கும் |
| `--json` | இயந்திரம் படிக்கக்கூடிய வெளியீடு |
| `-v` | model-வாரியான வாராந்திர வரம்புகளையும், ஒவ்வொரு எண்ணும் எங்கிருந்து வந்தது என்பதையும் காட்டும் |
| `--no-cache` | எப்போதும் மீண்டும் கேட்கும் |
| `--source cache` | ஒருபோதும் கேட்காது; சேமித்த எண்களை மட்டும் காட்டும் |

## காலாவதியான உள்நுழைவுகள்

ஒரு கணக்கின் access token காலாவதியானால், ccam அதைப் புதுப்பிப்பதில்லை. ஏனெனில், ஒரு Claude Code அமர்வு அதே உள்நுழைவைப் பயன்படுத்தும்போது அதைப் புதுப்பித்தால், அந்த அமர்வு வெளியேற்றப்படக்கூடும். `ccam <name>` மூலம் அந்தக் கணக்கை ஒருமுறை தொடங்குங்கள், Claude Code அதைப் புதுப்பிக்கும்.

`ccam usage --refresh` காலாவதியான tokens-ஐத் தானே புதுப்பிக்கிறது, ஆனால் இயங்காத கணக்குகளுக்கு மட்டுமே. macOS Keychain-இல் அல்லது இறக்குமதி செய்யப்பட்ட `~/.claude`-இல் சேமிக்கப்பட்ட உள்நுழைவுகளை அது ஒருபோதும் புதுப்பிப்பதில்லை.

## நிலை வரியில் பயன்பாடு

```sh
ccam statusline install
```

அதன் பிறகு Claude Code, கணக்கின் பெயரையும் அதன் பயன்பாட்டையும் நிலை வரியில் காட்டும், எடுத்துக்காட்டாக `[work] · Opus · 5h 24% · 7d 41%`. உங்களிடம் ஏற்கெனவே ஒரு status line கட்டளை இருந்தால், ccam அதை வைத்துக்கொண்டு, அதற்கு முன் கணக்கின் பெயரைச் சேர்க்கும். நிலை வரி தன் எண்களைச் சேமிக்கவும் செய்கிறது; endpoint பதில் அளிக்காதபோது `ccam usage` அவற்றைப் பயன்படுத்தும்.

## கணக்கு மாற்றம்

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # the next account that shares your conversation history
```

`ccam next` உள்நுழையாத கணக்குகளைத் தவிர்க்கிறது, `--auto` 100%-இல் உள்ள கணக்குகளைத் தவிர்க்கிறது. ஓர் உரையாடலைத் தொடர, இரண்டு கணக்குகளும் உரையாடல் வரலாற்றைப் பகிர வேண்டும்; [பகிர்வு](/docs/sharing) பக்கத்தைப் பாருங்கள்.

[பயன்பாட்டு வரம்பு வழிகாட்டி](/guides/usage-limit-workflow) ஒரு முழு எடுத்துக்காட்டை விளக்குகிறது.
