ஒவ்வொரு கணக்கையும் `ccam add` மூலம் சேருங்கள், பிறகு `claude1`, `claude2` அல்லது `ccs <name>` மூலம் Claude Code-ஐத் தொடங்குங்கள். பெரும்பாலானவர்களுக்கு இவ்வளவுதான் தேவை.

## 1. உங்கள் முதல் கணக்கைச் சேருங்கள்

```sh
ccam add
```

wizard, `personal` அல்லது `work` போன்ற ஒரு பெயரையும், கணக்கு உங்கள் மற்ற கணக்குகளுடன் எந்த உருப்படிகளைப் பகிர வேண்டும் என்பதையும் கேட்கும். பிறகு அது `claude auth login` இயக்கும், அது நீங்கள் உள்நுழைய உலாவியைத் திறக்கும். முடிந்ததும் இதைக் காண்பீர்கள்:

```console
✓ personal (me@example.com) 추가됨 — 단축 명령: claude1
```

ccam தற்போது தன் செய்திகளைக் கொரிய மொழியில் அச்சிடுகிறது; கட்டளைகளும் options-உம் எல்லா மொழிகளிலும் ஒன்றே.

## 2. இரண்டாவது கணக்கைச் சேருங்கள்

```sh
ccam add work
```

உலாவியில் மற்றொரு கணக்கில் உள்நுழையுங்கள். அது `claude2` ஆகும்.

## 3. மாறுங்கள்

இவற்றில் எதுவும் Claude Code-ஐ work கணக்காகத் தொடங்கும்:

```sh
claude2
ccs work
ccs 2
```

கணக்குப் பெயருக்குப் பின் வரும் அனைத்தும் மாற்றமின்றி Claude Code-க்குச் செல்லும், அதனால் உங்களுக்குத் தெரிந்த options-ஐயே தொடர்ந்து பயன்படுத்தலாம்:

```sh
ccs work --resume
ccs work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

`ccs`-ஐ மட்டும் இயக்கினால் ஒரு தேர்வி திறக்கும்: அம்புக்குறி விசைகளையும் Enter-ஐயும் பயன்படுத்துங்கள், அல்லது கணக்கின் எண்ணை அழுத்துங்கள்.

## 4. எதைப் பகிர வேண்டும் என்று தேர்ந்தெடுங்கள்

இயல்பாக, MCP சர்வர்கள், `settings.json`, உலகளாவிய `CLAUDE.md`, மற்றும் agents, commands, skills, plugins ஆகியவை கணக்குகளுக்கு இடையே பகிரப்படும். உரையாடல் வரலாறு பகிரப்படாது. கணக்குகளுக்கு இடையே உரையாடல்களைத் தொடர விரும்பினால், இரண்டு கணக்குகளுக்கும் அதை இயக்குங்கள்:

```sh
ccam share personal --history on
ccam share work --history on
```

எதையும் மாற்றும் முன், ccam எதை நகர்த்தப் போகிறது என்று காட்டும். விவரங்களுக்கு [பகிர்வு](/docs/sharing) பக்கத்தைப் பாருங்கள்.

## 5. ஒரு கணக்கு அதன் வரம்பை அடையும்போது

```sh
ccs usage
ccs next --continue
```

`ccs usage` எல்லாக் கணக்குகளின் 5 மணி நேர மற்றும் வாராந்திரப் பயன்பாட்டைக் காட்டுகிறது. `ccs next --continue` அதே உரையாடலை அடுத்த கணக்கில் திறக்கிறது. [பயன்பாட்டு வரம்புகள்](/docs/usage-limits) பக்கத்தைப் பாருங்கள்.

## ஏற்கெனவே ~/.claude பயன்படுத்துகிறீர்களா?

மீண்டும் உள்நுழைவதற்குப் பதிலாக அதைப் பதிவு செய்யுங்கள்:

```sh
ccam import
```

கோப்புறை அது இருக்கும் இடத்திலேயே இருக்கும், வெறும் `claude` முன்பு போலவே வேலை செய்யும்.
