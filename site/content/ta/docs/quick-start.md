ஒவ்வொரு கணக்கையும் `ccam add` மூலம் சேருங்கள், பிறகு `ccam <name>` மூலமோ, `ccwork` போல நீங்களே பெயரிடும் குறுக்குவழி மூலமோ Claude Code-ஐத் தொடங்குங்கள். பெரும்பாலானவர்களுக்கு இவ்வளவுதான் தேவை.

## 1. உங்கள் முதல் கணக்கைச் சேருங்கள்

```sh
ccam add
```

wizard, `personal` அல்லது `work` போன்ற ஒரு பெயரையும், கணக்கு உங்கள் மற்ற கணக்குகளுடன் எந்த உருப்படிகளைப் பகிர வேண்டும் என்பதையும், ஒரு குறுக்குவழிக் கட்டளையை உருவாக்க வேண்டுமா என்பதையும் (படி 4-ஐப் பாருங்கள்) கேட்கும். பிறகு அது `claude auth login` இயக்கும், அது நீங்கள் உள்நுழைய உலாவியைத் திறக்கும். தொலைநிலைக் கணினியில், உலாவி ஏற்றப்படாத ஒரு `http://localhost:…/callback` பக்கத்தில் நின்றுவிடலாம்; அந்த முகவரியை டெர்மினலில் ஒட்டுங்கள், ccam உள்நுழைவை முடிக்கும். முடிந்ததும் இதைக் காண்பீர்கள்:

```console
✓ personal (me@example.com) added
  no shortcut (add one with `ccam shortcut personal ccpersonal`)
```

## 2. ஏற்கெனவே உள்ள அமைப்புகளைக் கொண்டு வாருங்கள்

நீங்கள் முன்பே Claude Code பயன்படுத்தியிருந்தால், உங்கள் அமைப்புகள், `CLAUDE.md`, நீட்டிப்புகள், MCP சர்வர்கள் ஆகியவை `~/.claude`-இல் இருக்கும். ஒவ்வொரு கணக்குக்கும் அவை கிடைக்கும்படி, அவற்றைப் பகிரப்பட்ட அமைப்புகளுக்குள் நகலெடுங்கள்:

```sh
ccam migrate
```

ccam எதை நகலெடுக்கப் போகிறது என்று காட்டி, முதலில் உங்களிடம் கேட்கும். அது `~/.claude`-ஐப் படிக்க மட்டுமே செய்யும், எந்த உள்நுழைவையும் நகலெடுக்காது, நீங்கள் `--history` சேர்க்காதவரை உரையாடல் வரலாற்றை விட்டுவிடும். விவரங்களுக்கு [ஏற்கெனவே உள்ள அமைப்பை நகலெடுத்தல்](/docs/sharing#copy-an-existing-setup) பகுதியைப் பாருங்கள்.

## 3. இரண்டாவது கணக்கைச் சேருங்கள்

```sh
ccam add work
```

உலாவியில் மற்றொரு கணக்கில் உள்நுழையுங்கள்.

## 4. கணக்குகளுக்கு இடையே மாறுங்கள்

`ccam work` Claude Code-ஐ work கணக்காகத் தொடங்கும். இன்னும் சுருக்கமாக வேண்டுமென்றால், `ccwork` போல கணக்குக்கென ஒரு குறுக்குவழிக் கட்டளையைக் கொடுங்கள். பகிரும் உருப்படிகளுக்குப் பிறகு wizard இதைக் கேட்கும்:

```console
 Create a shortcut command for work? [y/N]
 A command such as ccwork that opens Claude Code as this account.
```

`y` அழுத்தி, ஒரு பெயரைத் தட்டச்சு செய்யுங்கள், அல்லது பரிந்துரைக்கப்பட்ட பெயரைப் பயன்படுத்த Enter அழுத்துங்கள்:

```console
 Shortcut name [ccwork]: █
 a-z, 0-9, '.', '-' and '_'; Enter alone uses ccwork
```

உள்நுழைவுக்குப் பிறகு ccam அதை உறுதிப்படுத்தும்:

```console
✓ work (work@example.com) added
  shortcut: ccwork
```

அந்தக் கேள்வியைத் தவிர்த்திருந்தால், எப்போது வேண்டுமானாலும் குறுக்குவழியைச் சேர்க்கலாம்:

```console
$ ccam shortcut work ccwork
✓ shortcut for work: ccwork
```

இப்போது இவற்றில் எதுவும் Claude Code-ஐ work கணக்காகத் தொடங்கும்:

```sh
ccwork
ccam work
ccam 2
```

`ccam`-ஐ மட்டும் இயக்கினால் ஒரு தேர்வி திறக்கும்: அம்புக்குறி விசைகளையும் Enter-ஐயும் பயன்படுத்துங்கள், அல்லது கணக்கின் எண்ணை அழுத்துங்கள்.

குறுக்குவழி அல்லது கணக்குப் பெயருக்குப் பின் வரும் அனைத்தும் மாற்றமின்றி Claude Code-க்குச் செல்லும், அதனால் உங்களுக்குத் தெரிந்த options-ஐயே தொடர்ந்து பயன்படுத்தலாம்:

```sh
ccwork --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | ccwork -p "what caused this?"
```

## 5. எதைப் பகிர வேண்டும் என்று தேர்ந்தெடுங்கள்

இயல்பாக, MCP சர்வர்கள், `settings.json`, உலகளாவிய `CLAUDE.md`, மற்றும் agents, commands, skills, plugins ஆகியவை கணக்குகளுக்கு இடையே பகிரப்படும். உரையாடல் வரலாறு பகிரப்படாது. கணக்குகளுக்கு இடையே உரையாடல்களைத் தொடர விரும்பினால், இரண்டு கணக்குகளுக்கும் அதை இயக்குங்கள்:

```sh
ccam share personal --history on
ccam share work --history on
```

எதையும் மாற்றும் முன், ccam எதை நகர்த்தப் போகிறது என்று காட்டும். விவரங்களுக்கு [பகிர்வு](/docs/sharing) பக்கத்தைப் பாருங்கள்.

## 6. ஒரு கணக்கு அதன் வரம்பை அடையும்போது

```sh
ccam usage
ccam next --continue
```

`ccam usage` எல்லாக் கணக்குகளின் 5 மணி நேர மற்றும் வாராந்திரப் பயன்பாட்டைக் காட்டுகிறது. `ccam next --continue` அதே உரையாடலை அடுத்த கணக்கில் திறக்கிறது. [பயன்பாட்டு வரம்புகள்](/docs/usage-limits) பக்கத்தைப் பாருங்கள்.

## ஏற்கெனவே ~/.claude பயன்படுத்துகிறீர்களா?

மீண்டும் உள்நுழைவதற்குப் பதிலாக அதைப் பதிவு செய்யுங்கள்:

```sh
ccam import
```

கோப்புறை அது இருக்கும் இடத்திலேயே இருக்கும், வெறும் `claude` முன்பு போலவே வேலை செய்யும்.
