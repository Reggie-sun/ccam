ஒவ்வொரு கணக்கும் தன் சொந்த உள்நுழைவை வைத்திருக்கும். மற்ற அனைத்தையும் **குழுக்கள்** மூலம் பகிரலாம்: ஒரு குழு தான் பகிரும் உருப்படிகளையும் அதிலுள்ள கணக்குகளையும் குறிப்பிடுகிறது, ccam அந்தக் கணக்குகள் ஒவ்வொன்றின் கோப்புகளையும் குழுவின் கோப்புறையுடன் இணைக்கிறது, அதனால் ஒரு கணக்கில் செய்யும் மாற்றம் அவை அனைத்திலும் தெரியும்.

## எதைப் பகிரலாம்

| உருப்படி | பகிரப்படுவது |
| --- | --- |
| `mcp` | MCP சர்வர்கள்: குழுவின் `mcp.json`, தொடக்கத்தில் Claude Code-க்கு அனுப்பப்படும் |
| `settings` | `settings.json`: அனுமதிகள், hooks, model, நிலை வரி |
| `memory` | உலகளாவிய `CLAUDE.md` |
| `extensions` | `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/` |
| `history` | உரையாடல் வரலாறு: `projects/` மற்றும் `history.jsonl` |

உங்கள் முதல் கணக்கு `default` என்ற குழுவை உருவாக்குகிறது, அது உரையாடல் வரலாற்றைத் தவிர மற்ற அனைத்தையும் பகிர்கிறது; பின்னர் சேர்க்கும் கணக்குகள் அதில் இணைகின்றன.

உள்நுழைவுக் கோப்புகளான `.credentials.json` மற்றும் `.claude.json` ஒருபோதும் பகிரப்படாது. ccam ஒரு நிலையான பட்டியலில் உள்ள பாதைகளை மட்டுமே இணைக்கிறது, இந்த இரண்டும் அந்தப் பட்டியலில் இல்லை.

இந்தப் பக்கம் அன்றாடப் பணிகளை விளக்குகிறது. ஒவ்வொரு option-உம் அம்சப் பக்கங்களில் விவரிக்கப்பட்டுள்ளது: [குழுக்கள் மூலம் பகிர்தல்](/features/share), [பகிரப்பட்ட MCP சர்வர்கள்](/features/mcp), [ஏற்கெனவே உள்ள அமைப்பை நகலெடுத்தல்](/features/migrate).

## குழுக்கள்

```sh
ccam group                                   # the groups, what they share, their accounts
ccam group set default --add history         # every account in default shares history
ccam group add team --items history --members work,side
```

ஒரு கணக்கு பல குழுக்களில் இருக்கலாம், ஆனால் ஒவ்வோர் உருப்படியும் ஒரே ஒரு குழுவிலிருந்து மட்டுமே வரும். ஆகவே `work` மற்றும் `side` இடையே மட்டும் வரலாற்றைப் பகிர, உங்கள் மற்ற கணக்குகளுடன் அல்லாமல், மேலே உள்ளது போல வரலாற்றை `default`-இலிருந்து விலக்கி, அந்த இரண்டுக்கும் தனிக் குழு ஒன்றைக் கொடுங்கள். ஒரு கணக்கு எதைப் பகிர்கிறது, எந்தக் குழு வழியாக என்பதை `ccam share work` காட்டும். [டாஷ்போர்டு](/features/dashboard) தன் Groups தாவலில் இதையே செய்கிறது.

## ஒரு கணக்கு பகிரத் தொடங்கும்போது

ஒரு கணக்கு ஓர் உருப்படியைப் பகிரத் தொடங்கும்போது (அது ஒரு குழுவில் இணையும்போது, அல்லது அதன் குழு அந்த உருப்படியைச் சேர்க்கும்போது), ccam:

1. ஒவ்வொரு கணக்குக்கும், அது நகர்த்த, நகலெடுக்க அல்லது இணைக்கப் போகும் ஒவ்வொரு கோப்பின் திட்டத்தையும் அச்சிட்டு, தொடங்கும் முன் உங்களிடம் கேட்கும்;
2. குழு இன்னும் காலியாக இருந்தால் கணக்கின் கோப்புகளைக் குழுக் கோப்புறைக்கு நகர்த்தும், இல்லையென்றால் குழுவிடம் இன்னும் இல்லாத கோப்புகளைச் சேர்க்கும்;
3. ஒரே கோப்பு வேறுபட்டால், குழுவின் பதிப்பை வைத்துக்கொள்வதா, உங்களுடையதைப் பயன்படுத்துவதா, அல்லது JSON-ஐ ஒன்றிணைப்பதா என்று கேட்கும்;
4. உங்கள் அசல் கோப்பைக் கணக்குக் கோப்புறைக்குள் `.ccam-backup/<time>/`-இல் வைத்திருக்கும்;
5. அசல் கோப்பைக் குழுவுக்கான இணைப்பால் மாற்றும்.

உரையாடல் கோப்புகள் அவற்றின் session ID-யின் பெயரில் உள்ளன, அதனால் பல கணக்குகளின் வரலாறுகள் முரண்பாடின்றி ஒன்றிணையும்.

ஒரு கணக்காக Claude Code இயங்கிக்கொண்டிருக்கும்போது, Claude Code எப்படித் தொடங்கப்பட்டிருந்தாலும் (பின்னணி அமர்வுகளும் உட்பட), ccam அந்தக் கணக்கை மாற்றாது, ஏனெனில் நகர்த்தப்படும் கோப்புகளில் அமர்வு தொடர்ந்து எழுதிக்கொண்டிருக்கும். முதலில் அதை முடியுங்கள். சேமிப்பதற்குச் சற்று முன் ccam மீண்டும் சரிபார்க்கிறது, அதனால் திட்டம் காத்திருந்தபோது தொடங்கிய அமர்வும் கண்டுபிடிக்கப்படும்.

## ஒரு கணக்கு பகிர்வதை நிறுத்தும்போது

```sh
ccam group leave team work                   # work leaves the group
ccam group set default --remove history      # nobody in default shares history any more
```

இணைப்பு நீக்கப்பட்டு, குழுவின் தற்போதைய உள்ளடக்கத்தின் சொந்த நகல் கணக்குக்குக் கிடைக்கும்; குழுவின் MCP சர்வர்கள், கணக்கின் சொந்த சர்வர்களுக்கு அருகில், அதன் சொந்த `.claude.json`-க்குள் செல்கின்றன. அதற்குப் பதிலாகக் காலியாகத் தொடங்க `--fresh` சேருங்கள்; அப்போது இனி ஏற்றப்படாத MCP சர்வர்களைத் திட்டம் பட்டியலிடும். `~/.claude` போன்ற இறக்குமதி செய்யப்பட்ட கோப்புறை எப்போதும் ஒரு நகலை வைத்துக்கொள்ளும். மற்ற கணக்குகளுக்காகக் குழு அதன் உள்ளடக்கத்தை வைத்திருக்கும்.

## ஏற்கெனவே உள்ள அமைப்பை நகலெடுங்கள்

ccam-க்கு முன்பே நீங்கள் Claude Code பயன்படுத்தியிருந்தால், உங்கள் அமைப்புகள் `~/.claude`-இல் இருக்கும். `ccam migrate` அவற்றை ஒரு குழுவுக்குள் நகலெடுக்கிறது, அதனால் அந்த உருப்படிகளைப் பகிரும் ஒவ்வொரு கணக்குக்கும் அவை கிடைக்கும்:

```sh
ccam migrate
```

டெர்மினலில், ccam முதலில் உருப்படிகளின் ஒரு தேர்வுப் பட்டியலைக் காட்டும். உரையாடல் வரலாற்றைத் தவிர அனைத்தும் தேர்வுசெய்யப்பட்டிருக்கும்; ஓர் உருப்படியை மாற்ற Space-ஐயும், திட்டத்தைப் பார்க்க Enter-ஐயும் அழுத்துங்கள். கோப்புறையில் எதுவும் இல்லாத உருப்படிகள் `not found` எனக் குறிக்கப்படும்.

அது நகலெடுப்பவை:

- `settings.json` மற்றும் உலகளாவிய `CLAUDE.md`;
- நீட்டிப்புகள் `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/`;
- உங்கள் பயனர் MCP சர்வர்கள், அதாவது `~/.claude.json`-இன் `mcpServers` பதிவு, குழுவின் `mcp.json`-க்குள்;
- உரையாடல் வரலாறு (`projects/` மற்றும் `history.jsonl`), ஆனால் நீங்கள் `--history` சேர்த்தால் மட்டுமே.

மூலக் கோப்புறை படிக்கப்பட மட்டுமே செய்யும்: அதிலுள்ள எதுவும் நகர்த்தப்படவோ, இணைக்கப்படவோ, மாற்றப்படவோ மாட்டாது, வெறும் `claude` முன்பு போலவே வேலை செய்யும். உள்நுழைவுக் கோப்புகளான `.credentials.json` மற்றும் `.claude.json` ஒருபோதும் குழுவுக்குள் நகலெடுக்கப்படாது.

OAuth மூலம் உள்நுழையும் MCP சர்வர்கள் தங்கள் tokens-ஐ சர்வர் பட்டியலில் அல்ல, உள்நுழைவில் வைத்திருக்கின்றன. ccam அந்த உள்நுழைவுகளை நகலெடுப்பதில்லை: நகலெடுத்த உள்நுழைவில் அதே refresh token இருக்கும், முதல் புதுப்பிப்பு அதை வைத்திருக்கும் மற்ற அனைவரையும், `~/.claude` உட்பட, அந்தச் சர்வரிலிருந்து வெளியேற்றிவிடும். `/mcp` மூலம் சர்வர்களில் தாங்களே உள்நுழைய வேண்டிய கணக்குகளைத் திட்டமும் சுருக்கமும் பெயரிடுகின்றன.

எதையும் நகலெடுக்கும் முன், ccam திட்டத்தை அச்சிட்டு உங்களிடம் கேட்கும்:

```console
$ ccam migrate
Copy from /home/me/.claude into group default (/home/me/.local/share/ccam/groups/default):
  mcp         ~/.claude.json  new: context7, fs
  settings    settings.json   new: 80 B
  memory      CLAUDE.md       new: 31 B
  extensions  agents/         add 1 file the group lacks (17 B)
              commands/       add 1 file the group lacks (15 B)
              skills/         add 1 file the group lacks (32 B)
              not found, skipped: plugins/, output-styles/, rules/
  Conversation history (projects/, history.jsonl) is not included; add --history to copy it.
Copy these into group default? [y/N] y
✓ Copied into group default: 2 MCP servers, settings.json, CLAUDE.md, agents/, commands/, skills/
Group default: personal
To share them:
  ccam group join default work
```

இறுதியில், ccam குழுவின் கணக்குகளைப் பட்டியலிடும். குழு அந்த உருப்படிகளில் ஒன்றை இன்னும் பகிரவில்லை என்றாலோ, சில கணக்குகள் அதில் இல்லை என்றாலோ, அதை மாற்றும் `ccam group` கட்டளைகளை அது அச்சிடும்.

குழுவிடம் ஏற்கெனவே ஒரு கோப்பின் வேறுபட்ட நகல் இருந்தால், பகிர்வை இயக்கும்போது கேட்பது போலவே ccam கேட்கும்: குழுவின் நகலை வைத்துக்கொள்வதா, உங்களுடையதைப் பயன்படுத்துவதா. `settings.json` மற்றும் பிற JSON கோப்புகளை ஒன்றிணைக்கவும் முடியும், `history.jsonl`-ஐ வரி வரியாக ஒன்றிணைக்கலாம். குழுவின் முந்தைய நகல்கள் குழுக் கோப்புறைக்குள் `.ccam-backup/<time>/`-இல் சேமிக்கப்படும்.

| Option | விளைவு |
| --- | --- |
| `--settings`, `--memory`, `--extensions`, `--mcp`, `--history` | தேர்வுப் பட்டியல் இல்லாமல், நீங்கள் குறிப்பிடும் உருப்படிகளை மட்டும் நகலெடுக்கும்; அவை இல்லாமலும் டெர்மினலுக்கு வெளியேயும், உரையாடல் வரலாற்றைத் தவிர அனைத்தும் |
| `-g`, `--group <group>` | `default`-க்குப் பதிலாக இந்தக் குழுவுக்குள் நகலெடுக்கும் |
| `-y`, `--yes` | கேட்காமல் நகலெடுக்கும்; ஒரு கோப்பு வேறுபட்டால், குழுவின் நகலை வைத்திருக்கும் |

எதையும் நகலெடுக்காமல் திட்டத்தை மட்டும் பார்க்க, `ccam --dry-run migrate` என்பதில் உள்ளது போல, கட்டளைக்கு முன் `--dry-run` வையுங்கள். வேறொரு கோப்புறையிலிருந்து நகலெடுக்க, அதன் பெயரைக் கொடுங்கள்: `ccam migrate ~/.claude-work --group work`.

## MCP சர்வர்கள்

Claude Code, MCP சர்வர்களை உள்நுழைவுடன் சேர்த்து `.claude.json`-இல் சேமிக்கிறது, அதனால் அந்தக் கோப்பைப் பகிர முடியாது. ccam பகிரப்பட்ட சர்வர்களைக் குழுவின் `mcp.json`-இல் வைத்து, Claude Code-ஐ `--mcp-config=<group>/mcp.json` உடன் தொடங்குகிறது. உங்கள் சொந்த `--mcp-config` options அதற்கு மேல் தொடர்ந்து செயல்படும்.

```sh
ccam mcp add fs -- npx -y @modelcontextprotocol/server-filesystem ~/code
ccam mcp list
```

ஓர் அமர்வுக்குள் `claude mcp add` மூலம் நீங்கள் சேர்க்கும் சர்வர் அந்தக் கணக்குக்கு மட்டுமே, நீங்கள் இருந்த கோப்புறைக்கு மட்டுமே சேமிக்கப்படும் (Claude Code-இன் local scope; `-s user` அதை எல்லாக் கோப்புறைகளிலும் அந்தக் கணக்குக்கு உரியதாக்குகிறது). அடுத்த முறை அந்தக் கணக்கைத் தொடங்கும்போது, ccam அந்தச் சர்வரின் பெயரை அதன் கோப்புறையுடன் சொல்லி, அதைக் குழுவுக்கு நகர்த்தும் கட்டளையையும் சொல்லும்:

```sh
ccam mcp import work gh
```

அதே பெயரில் வேறொரு சர்வர் குழுவில் ஏற்கெனவே இருந்தால், ccam அதைத் தவிர்த்து, அதைப் பற்றிச் சொல்லும். `--force` குழுவின் சர்வரை மாற்றி, பழைய `mcp.json`-ஐக் குழுவின் `.ccam-backup/` கோப்புறையில் வைத்திருக்கும்.

OAuth மூலம் உள்நுழையும் MCP சர்வர்கள் தங்கள் tokens-ஐக் கணக்கின் உள்நுழைவுடன் சேமிக்கின்றன, அதனால் ஒவ்வொரு கணக்கிலும் `/mcp` மூலம் அவற்றை ஒருமுறை அங்கீகரியுங்கள். மற்றொரு கணக்கு உள்நுழைந்திருக்கும், ஆனால் ஒரு கணக்கு உள்நுழையாத சர்வர்களை `ccam ext`, `ccam doctor` ஆகியவை பெயரிடுகின்றன.

சர்வர்கள் `claude mcp list` மற்றும் `/mcp`-இல் சாதாரண user சர்வர்களாகத் தெரிய வேண்டும் என்று விரும்பினால், `~/.config/ccam/config.toml`-இன் மேற்பகுதியில், முதல் `[[group]]`, `[[profile]]` அல்லது `[[folder]]`-க்கு மேலே, `mcp_strategy = "sync"` அமையுங்கள். அப்போது ccam, தொடங்கும் முன் Claude Code-இன் சொந்த file lock-இன் கீழ், காப்புப்பிரதியுடன், அவற்றை ஒவ்வொரு கணக்கின் `.claude.json`-இலும் எழுதும். அதே பெயரில் கணக்குக்குச் சொந்தமாக ஒரு சர்வர் இருந்தால், அது கணக்குடையதாகவே இருக்கும், ccam அதைச் சொல்லும்.

## ஒரே கோப்புறையில் இரண்டு கணக்குகள்

உரையாடல் வரலாற்றைப் பகிரும் கணக்குகள் ஒரே கோப்புகளில் எழுதுகின்றன. அதே குழுவின் மற்றொரு கணக்கு ஏற்கெனவே இயங்கும் கோப்புறையில் இரண்டாவது Claude Code-ஐத் தொடங்கினால், ccam உங்களை எச்சரித்து, தொடரலாமா என்று கேட்கும்.

## ஏதாவது உடைந்தால்

```sh
ccam doctor
ccam doctor --fix
```

ஒரு பகிரப்பட்ட பாதை சாதாரண கோப்பாக மாறிவிட்டால், எடுத்துக்காட்டாக நீங்கள் கையால் ஒரு காப்புப்பிரதியை மீட்டெடுத்த பிறகு, ccam Claude Code-ஐத் தொடங்கும் முன் நின்று `ccam doctor --fix`-ஐச் சுட்டிக்காட்டும். அது அதை மீண்டும் குழுவுடன் இணைக்கிறது: குழுவிடம் நகல் இல்லையென்றால் அந்தக் கோப்பே குழுவின் நகலாகிறது; இல்லையென்றால் குழு தன் நகலை வைத்துக்கொள்ளும், உங்களுடையது ஒரு காப்புப்பிரதிக்குச் செல்லும், அதை `--fix` பெயரிடும். பாதியில் நின்றுபோன குழு மாற்றத்தையும் `ccam doctor --fix` முடிக்கிறது.
