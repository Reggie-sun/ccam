ஒவ்வொரு கணக்கும் தன் சொந்த உள்நுழைவை வைத்திருக்கும். மற்ற அனைத்தையும் உருப்படி வாரியாகப் பகிரலாம்: ccam கணக்கின் கோப்பையோ கோப்புறையையோ ஒரு பகிரப்பட்ட குழுக் கோப்புறையுடன் இணைக்கிறது, அதனால் ஒரு கணக்கில் செய்யும் மாற்றம் அந்தக் குழுவின் எல்லாக் கணக்குகளிலும் தெரியும்.

## எதைப் பகிரலாம்

| உருப்படி | Option | பகிரப்படுவது |
| --- | --- | --- |
| MCP சர்வர்கள் | `--mcp` | குழுவின் `mcp.json`, தொடக்கத்தில் Claude Code-க்கு அனுப்பப்படும் |
| அமைப்புகள் | `--settings` | `settings.json`: அனுமதிகள், hooks, model, நிலை வரி |
| உலகளாவிய நினைவகம் | `--memory` | `CLAUDE.md` |
| நீட்டிப்புகள் | `--extensions` | `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/` |
| உரையாடல் வரலாறு | `--history` | `projects/` மற்றும் `history.jsonl` |

புதிய கணக்குகள் உரையாடல் வரலாற்றைத் தவிர மற்ற அனைத்தையும் பகிரும்.

உள்நுழைவுக் கோப்புகளான `.credentials.json` மற்றும் `.claude.json` ஒருபோதும் பகிரப்படாது. ccam ஒரு நிலையான பட்டியலில் உள்ள பாதைகளை மட்டுமே இணைக்கிறது, இந்த இரண்டும் அந்தப் பட்டியலில் இல்லை.

## குழுக்கள்

`on` என்றால் `default` குழு. சில கணக்குகள் மட்டும் ஓர் உருப்படியைப் பகிரும்படி, ஒரு பெயரையும் கொடுக்கலாம்:

```sh
ccam share work --history team
ccam share side --history team
```

இப்போது `work` மற்றும் `side` ஒன்றுக்கொன்று உரையாடல்களைப் பகிர்கின்றன, ஆனால் உங்கள் மற்ற கணக்குகளுடன் பகிர்வதில்லை.

## பகிர்வை இயக்குதல்

ஒரு கணக்கு ஓர் உருப்படியைப் பகிரத் தொடங்கும்போது, ccam:

1. அது நகர்த்த, நகலெடுக்க அல்லது இணைக்கப் போகும் ஒவ்வொரு கோப்பின் திட்டத்தையும் அச்சிட்டு, தொடங்கும் முன் உங்களிடம் கேட்கும்;
2. குழு இன்னும் காலியாக இருந்தால் கணக்கின் கோப்புகளைக் குழுக் கோப்புறைக்கு நகர்த்தும், இல்லையென்றால் குழுவிடம் இன்னும் இல்லாத கோப்புகளைச் சேர்க்கும்;
3. ஒரே கோப்பு வேறுபட்டால், குழுவின் பதிப்பை வைத்துக்கொள்வதா, உங்களுடையதைப் பயன்படுத்துவதா, அல்லது JSON-ஐ ஒன்றிணைப்பதா என்று கேட்கும்;
4. உங்கள் அசல் கோப்பைக் கணக்குக் கோப்புறைக்குள் `.ccam-backup/<time>/`-இல் வைத்திருக்கும்;
5. அசல் கோப்பைக் குழுவுக்கான இணைப்பால் மாற்றும்.

உரையாடல் கோப்புகள் அவற்றின் session ID-யின் பெயரில் உள்ளன, அதனால் பல கணக்குகளின் வரலாறுகள் முரண்பாடின்றி ஒன்றிணையும்.

## பகிர்வை நிறுத்துதல்

```sh
ccam share work --history off
```

இணைப்பு நீக்கப்பட்டு, குழுவின் தற்போதைய உள்ளடக்கத்தின் சொந்த நகல் கணக்குக்குக் கிடைக்கும். அதற்குப் பதிலாகக் காலியாகத் தொடங்க `--fresh` சேருங்கள். மற்ற கணக்குகளுக்காகக் குழு அதன் உள்ளடக்கத்தை வைத்திருக்கும்.

## ஏற்கெனவே உள்ள அமைப்பை நகலெடுங்கள்

ccam-க்கு முன்பே நீங்கள் Claude Code பயன்படுத்தியிருந்தால், உங்கள் அமைப்புகள் `~/.claude`-இல் இருக்கும். `ccam migrate` அவற்றை ஒரு குழுவுக்குள் நகலெடுக்கிறது, அதனால் அந்த உருப்படிகளைப் பகிரும் ஒவ்வொரு கணக்குக்கும் அவை கிடைக்கும்:

```sh
ccam migrate
```

அது நகலெடுப்பவை:

- `settings.json` மற்றும் உலகளாவிய `CLAUDE.md`;
- நீட்டிப்புகள் `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/`;
- உங்கள் பயனர் MCP சர்வர்கள், அதாவது `~/.claude.json`-இன் `mcpServers` பதிவு, குழுவின் `mcp.json`-க்குள்;
- உரையாடல் வரலாறு (`projects/` மற்றும் `history.jsonl`), ஆனால் நீங்கள் `--history` சேர்த்தால் மட்டுமே.

மூலக் கோப்புறை படிக்கப்பட மட்டுமே செய்யும்: அதிலுள்ள எதுவும் நகர்த்தப்படவோ, இணைக்கப்படவோ, மாற்றப்படவோ மாட்டாது, வெறும் `claude` முன்பு போலவே வேலை செய்யும். உள்நுழைவுக் கோப்புகளான `.credentials.json` மற்றும் `.claude.json` ஒருபோதும் நகலெடுக்கப்படாது.

எதையும் நகலெடுக்கும் முன், ccam திட்டத்தை அச்சிட்டு உங்களிடம் கேட்கும்:

```console
$ ccam migrate
Copy from /home/me/.claude into group default (/home/me/.local/share/ccam/groups/default):
  mcp         ~/.claude.json  new: context7, fs
  settings    settings.json   new: 80 B
  memory      CLAUDE.md       new: 31 B
  extensions  agents/         add 1 file the group lacks (17 B)
              commands/       add 1 file the group lacks (15 B)
              skills/         add 1 file the group lacks (32 B)
              not found, skipped: plugins/, output-styles/, rules/
  Conversation history (projects/, history.jsonl) is not included; add --history to copy it.
Copy these into group default? [y/N] y
✓ Copied into group default: 2 MCP servers, settings.json, CLAUDE.md, agents/, commands/, skills/
Accounts that share these through group default:
  mcp         personal
  settings    personal
  memory      personal
  extensions  personal
```

இறுதியில், குழு வழியாக ஒவ்வொரு உருப்படியையும் பகிரும் கணக்குகளை ccam பட்டியலிடும். சில கணக்குகள் பகிரவில்லை என்றால், அவற்றுக்குப் பகிர்வை இயக்கும் `ccam share` கட்டளைகளை அது அச்சிடும்.

குழுவிடம் ஏற்கெனவே ஒரு கோப்பின் வேறுபட்ட நகல் இருந்தால், பகிர்வை இயக்கும்போது கேட்பது போலவே ccam கேட்கும்: குழுவின் நகலை வைத்துக்கொள்வதா, உங்களுடையதைப் பயன்படுத்துவதா. `settings.json` மற்றும் பிற JSON கோப்புகளை ஒன்றிணைக்கவும் முடியும், `history.jsonl`-ஐ வரி வரியாக ஒன்றிணைக்கலாம். குழுவின் முந்தைய நகல்கள் குழுக் கோப்புறைக்குள் `.ccam-backup/<time>/`-இல் சேமிக்கப்படும்.

| Option | விளைவு |
| --- | --- |
| `--settings`, `--memory`, `--extensions`, `--mcp`, `--history` | நீங்கள் குறிப்பிடும் உருப்படிகளை மட்டும் நகலெடுக்கும்; அவை இல்லாவிட்டால், உரையாடல் வரலாற்றைத் தவிர அனைத்தும் |
| `-g`, `--group <group>` | `default`-க்குப் பதிலாக இந்தக் குழுவுக்குள் நகலெடுக்கும் |
| `-y`, `--yes` | கேட்காமல் நகலெடுக்கும்; ஒரு கோப்பு வேறுபட்டால், குழுவின் நகலை வைத்திருக்கும் |

எதையும் நகலெடுக்காமல் திட்டத்தை மட்டும் பார்க்க, `ccam --dry-run migrate` என்பதில் உள்ளது போல, கட்டளைக்கு முன் `--dry-run` வையுங்கள். வேறொரு கோப்புறையிலிருந்து நகலெடுக்க, அதன் பெயரைக் கொடுங்கள்: `ccam migrate ~/.claude-work --group work`.

## MCP சர்வர்கள்

Claude Code, MCP சர்வர்களை உள்நுழைவுடன் சேர்த்து `.claude.json`-இல் சேமிக்கிறது, அதனால் அந்தக் கோப்பைப் பகிர முடியாது. ccam பகிரப்பட்ட சர்வர்களைக் குழுவின் `mcp.json`-இல் வைத்து, Claude Code-ஐ `--mcp-config=<group>/mcp.json` உடன் தொடங்குகிறது. உங்கள் சொந்த `--mcp-config` options அதற்கு மேல் தொடர்ந்து செயல்படும்.

```sh
ccam mcp add fs -- npx -y @modelcontextprotocol/server-filesystem ~/code
ccam mcp list
```

ஓர் அமர்வுக்குள் `claude mcp add` மூலம் நீங்கள் சேர்க்கும் சர்வர் அந்தக் கணக்குக்கு மட்டுமே சேமிக்கப்படும். அடுத்த முறை அந்தக் கணக்கைத் தொடங்கும்போது, ccam அந்தச் சர்வரின் பெயரையும் அதைக் குழுவுக்கு நகர்த்தும் கட்டளையையும் சொல்லும்:

```sh
ccam mcp import work gh
```

OAuth மூலம் உள்நுழையும் MCP சர்வர்கள் தங்கள் tokens-ஐக் கணக்கின் உள்நுழைவுடன் சேமிக்கின்றன, அதனால் ஒவ்வொரு கணக்கிலும் அவற்றை ஒருமுறை அங்கீகரியுங்கள்.

சர்வர்கள் `claude mcp list` மற்றும் `/mcp`-இல் சாதாரண user சர்வர்களாகத் தெரிய வேண்டும் என்று விரும்பினால், `~/.config/ccam/config.toml`-இல் `mcp_strategy = "sync"` அமையுங்கள். அப்போது ccam, தொடங்கும் முன் Claude Code-இன் சொந்த file lock-இன் கீழ், காப்புப்பிரதியுடன், அவற்றை ஒவ்வொரு கணக்கின் `.claude.json`-இலும் எழுதும்.

## ஒரே கோப்புறையில் இரண்டு கணக்குகள்

உரையாடல் வரலாற்றைப் பகிரும் கணக்குகள் ஒரே கோப்புகளில் எழுதுகின்றன. அதே குழுவின் மற்றொரு கணக்கு ஏற்கெனவே இயங்கும் கோப்புறையில் இரண்டாவது Claude Code-ஐத் தொடங்கினால், ccam உங்களை எச்சரித்து, தொடரலாமா என்று கேட்கும்.

## ஏதாவது உடைந்தால்

```sh
ccam doctor
ccam doctor --fix
```

ஒரு பகிரப்பட்ட பாதை சாதாரண கோப்பாக மாறிவிட்டால், எடுத்துக்காட்டாக நீங்கள் கையால் ஒரு காப்புப்பிரதியை மீட்டெடுத்த பிறகு, ccam Claude Code-ஐத் தொடங்கும் முன் நின்று `ccam doctor --fix`-ஐச் சுட்டிக்காட்டும். அது அந்தக் கோப்பைக் குழுவுடன் ஒன்றிணைத்து, ஒரு காப்புப்பிரதியையும் வைக்கும்.
