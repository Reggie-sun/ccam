## ccam, Anthropic-இன் அதிகாரப்பூர்வ கருவியா?

இல்லை. ccam ஓர் அதிகாரப்பூர்வமற்ற திறந்த மூல திட்டம். இது Anthropic உடன் இணைக்கப்படவில்லை, Anthropic இதை அங்கீகரிக்கவும் இல்லை. பல கணக்குகளைப் பக்கம் பக்கமாக இயக்க Claude Code ஆவணப்படுத்தியுள்ள `CLAUDE_CONFIG_DIR` அமைப்பை இது பயன்படுத்துகிறது.

## பல Claude Code கணக்குகளைப் பயன்படுத்த எனக்கு அனுமதி உண்டா?

அது ஒவ்வொரு கணக்கின் விதிமுறைகளையும், வேலைக் கணக்குகளுக்கு உங்கள் நிறுவனத்தின் கொள்கையையும் பொறுத்தது. பல கணக்குகளைப் பயன்படுத்தும் முன் அவற்றைச் சரிபாருங்கள். உங்களிடம் ஏற்கெனவே உள்ள கணக்குகளுக்கு இடையே மாறுவதை மட்டுமே ccam எளிதாக்குகிறது.

## ccam பயன்பாட்டு வரம்புகளைத் தவிர்க்க உதவுமா?

இல்லை. ஒவ்வொரு கணக்கும் அதன் சொந்த வரம்புகளை வைத்திருக்கும். ccam அவற்றைக் காட்டுகிறது, ஒரு கணக்கின் வரம்பு தீர்ந்தால் உங்களுக்குச் சொந்தமான வேறொரு கணக்கில் தொடர உதவுகிறது.

## ஒரே கணினியில் இரண்டு Claude Code கணக்குகளை எப்படிப் பயன்படுத்துவது?

`CLAUDE_CONFIG_DIR` மூலம் ஒவ்வொரு கணக்குக்கும் தனி config கோப்புறையைக் கொடுங்கள். ccam இதை உங்களுக்காகச் செய்கிறது: ஒவ்வொரு கணக்குக்கும் `ccam add` இயக்கி, பிறகு அவற்றை `ccam personal`, `ccam work` மூலமோ, `ccwork` போல நீங்களே பெயரிடும் குறுக்குவழிகள் மூலமோ தொடங்குங்கள். இதைக் கையால் செய்வது எப்படி என்றும் [வழிகாட்டி](/guides/multiple-claude-code-accounts) காட்டுகிறது.

## ஓர் உரையாடலை வேறொரு கணக்கில் எப்படித் தொடர்வது?

`ccam share <name> --history on` மூலம் இரண்டு கணக்குகளுக்கு இடையே உரையாடல் வரலாற்றைப் பகிருங்கள், பிறகு `ccam next --continue` இயக்குங்கள். Claude Code, தற்போதைய கோப்புறையின் மிகச் சமீபத்திய உரையாடலை அடுத்த கணக்கில் திறக்கும்.

## ccam என் உள்நுழைவைப் பார்க்கிறதா அல்லது அனுப்புகிறதா?

ccam ஒருபோதும் உள்நுழைவை நகலெடுப்பதோ பகிர்வதோ இல்லை. நீங்கள் `ccam usage`, `ccam next --auto` அல்லது `ccam doctor` இயக்கும்போது, ஒரு கணக்கின் பயன்பாட்டை Anthropic-இன் usage endpoint-இடம் கேட்பதற்காக மட்டுமே அந்தக் கணக்கின் access token-ஐப் படிக்கிறது. ccam-இல் telemetry இல்லை, வேறு எங்கும் எதையும் அனுப்புவதில்லை.

## என் கணக்குகள் எங்கே சேமிக்கப்படுகின்றன?

`~/.local/share/ccam/profiles/<name>/`-இல், ஒவ்வொரு கணக்குக்கும் ஒரு கோப்புறை. macOS-இல், Claude Code உள்நுழைவை Keychain-இல், அந்தக் கோப்புறையிலிருந்து பெறப்பட்ட ஒரு பெயரில் வைத்திருக்கும்.

## ஏற்கெனவே உள்ள என் ~/.claude-க்கு என்ன ஆகும்?

நீங்கள் `ccam import` அல்லது `ccam migrate` இயக்காதவரை எதுவும் ஆகாது. Import அந்தக் கோப்புறையை அது இருக்கும் இடத்திலேயே பதிவு செய்கிறது, அதனால் வெறும் `claude`-உம் `ccam <name>`-உம் அதே கணக்கையும் அமைப்புகளையும் தொடர்ந்து பயன்படுத்தும். `ccam migrate` அதன் அமைப்புகள், `CLAUDE.md`, நீட்டிப்புகள், MCP சர்வர்கள் ஆகியவற்றைப் பகிரப்பட்ட அமைப்புகளுக்குள் நகலெடுக்கிறது, அந்தக் கோப்புறையைப் படிக்க மட்டுமே செய்கிறது.

## ccam எந்தக் கணினி அமைப்புகளை ஆதரிக்கிறது?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine மற்றும் பிற) மற்றும் macOS. Windows-இல், WSL-க்குள் பயன்படுத்துங்கள்.

## ஒரு MCP சர்வர் ஏன் ஒரே ஒரு கணக்கில் மட்டும் தெரிகிறது?

ஓர் அமர்வுக்குள் `claude mcp add` மூலம் சேர்க்கப்படும் சர்வர்கள் அந்தக் கணக்குக்கு மட்டுமே சேமிக்கப்படும். அடுத்த முறை அந்தக் கணக்கைத் தொடங்கும்போது ccam உங்களுக்குச் சொல்லும்; `ccam mcp import <account> <server>` மூலம் சர்வரைப் பகிரப்பட்ட குழுவுக்கு நகர்த்துங்கள்.

## ccam, Claude Code-ஐ மெதுவாக்குமா?

ccam மூலம் Claude Code-ஐத் தொடங்குவது சுமார் 4 மில்லிவினாடிகள் சேர்க்கிறது; இது ஒரு laptop-இல் `scripts/perf-check.sh` மூலம் அளவிடப்பட்டது. ccam ஒரு சிறிய கோப்பைப் படித்து, பகிரப்பட்ட இணைப்புகளைச் சரிபார்த்து, பிறகு தன்னை `claude` ஆக மாற்றிக்கொள்கிறது, அதனால் நீங்கள் வேலை செய்யும்போது அது இயங்குவதில்லை.

## ccam-ஐ எப்படி நீக்குவது?

ஒவ்வொரு கணக்கின் குறுக்குவழியையும் `ccam shortcut <account> --remove` மூலம் நீக்கி, `~/.local/bin`-இலிருந்து `ccam`-ஐ நீக்குங்கள். கணக்குகள் இனி தேவையில்லை என்றால், பிறகு `~/.config/ccam`, `~/.local/share/ccam`, `~/.local/state/ccam` ஆகியவற்றையும் நீக்குங்கள். [நிறுவல்](/docs/install#uninstall) பக்கத்தைப் பாருங்கள்.
