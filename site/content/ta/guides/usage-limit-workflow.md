ஒரு கணக்கு அதன் பயன்பாட்டு வரம்பை (பெரும்பாலும் rate limit என்று அழைக்கப்படுகிறது) அடையும்போது, உங்களுக்கு இரண்டு வழிகள் உள்ளன: வரம்பு மீட்டமைக்கப்படும் வரை காத்திருக்கலாம், அல்லது உங்களுக்குச் சொந்தமான வேறொரு கணக்கில் அதே உரையாடலை இப்போதே தொடரலாம். கணக்குகளுக்கு இடையே உரையாடல் வரலாறு பகிரப்பட்ட பிறகு, ccam உடன் இரண்டாவது வழிக்கு `ccam next --auto --continue` என்ற ஒரே கட்டளை போதும்.

## Claude Code-க்கு என்னென்ன வரம்புகள் உள்ளன?

Pro, Max திட்டங்களில் Claude Code-க்கு [ஐந்து மணி நேர session வரம்பும் வாராந்திர வரம்பும்](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan) உள்ளன. இரண்டும் இணையத்திலும் apps-இலும் உள்ள Claude உடன் பகிரப்படுகின்றன, பயன்பாடு இரண்டிலும் ஒரே நேரத்தில் கணக்கிடப்படுகிறது. ஒன்று தீர்ந்தால், Claude Code "You've hit your session limit · resets 3:45pm" போன்ற ஒரு [செய்தியைக் காட்டுகிறது](https://code.claude.com/docs/en/errors#youve-hit-your-session-limit). மாடலை மாற்றுவது உதவாது, ஏனெனில் வரம்புகள் எல்லா மாடல்களுக்கும் பொருந்தும்.

## வழி 1: மீட்டமைப்புக்குக் காத்திருங்கள்

உங்களிடம் ஒரே ஒரு கணக்கு இருந்தால், காத்திருங்கள். Claude Code-இன் சமீபத்திய பதிப்புகள் [திறந்த session-இலேயே காத்திருந்து](https://code.claude.com/docs/en/interactive-mode#wait-for-a-usage-limit-to-reset), வரம்பு மீட்டமைக்கப்பட்டதும் தாமாகவே பணியைத் தொடர்கின்றன. உங்கள் திட்டத்தின் வரம்புகளில் எவ்வளவு பயன்படுத்தியுள்ளீர்கள் என்று Claude Code-க்குள் `/usage` காட்டுகிறது.

## வழி 2: இப்போதே வேறொரு கணக்கில் தொடருங்கள்

உங்களிடம் இரண்டாவது கணக்கு இருந்தால், அதே உரையாடலை உடனே தொடரலாம். இதை ஒருமுறை அமையுங்கள்:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
ccam group set default --add history
ccam statusline install
```

இப்போது நீங்கள் வேலை செய்யும்போது status line கணக்கையும் அதன் 5 மணி நேரப் பயன்பாட்டையும் காட்டுகிறது, அதனால் வரம்பு திடீரென்று வந்து அதிர்ச்சி தராது.

வரம்பை அடைந்ததும், Claude Code-இலிருந்து வெளியேறுங்கள் (`/exit`), பிறகு:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

அதிக இடம் உள்ள கணக்கில் உரையாடலைத் திறங்கள்:

```sh
ccam next --auto --continue
```

தற்போதைய கோப்புறையின் மிகச் சமீபத்திய உரையாடலுடன், இதுவரை பேசிய அனைத்தையும் சேர்த்து, Claude Code `work` கணக்காகத் தொடங்குகிறது. வரலாற்றைப் பகிர்வது (மேலே உள்ள `ccam group set default --add history`) அதை ஒரே உரையாடலாக வைத்திருக்கும்; அது இல்லாவிட்டால், Claude Code உரையாடலை `work`-க்குள் நகலெடுக்கும், அந்த முதல் பதில் எத்தனை tokens-ஐ மீண்டும் படிக்கும் என்று ccam சொல்லும்.

Claude Code-இல் [ccam plugin](/docs/install#claude-code-plugin) இருந்தால், தன் வரம்பில் நிற்கும் அமர்வு ஓர் அறிவிப்பைக் காட்டும், `/ccam:switch` (அல்லது `/ccam:switch work`) எதையும் ஊகிக்க விடாமல் `ccam next --continue`-க்காக உரையாடலைக் குறித்து வைக்கும்.

## ccam தானாகக் கணக்குகளை மாற்றுமா?

இல்லை. நீங்கள் வேலை செய்யும்போது ccam இயங்குவதில்லை: அது Claude Code-ஐத் தொடங்கி, தன் இடத்தில் அதை இயக்குகிறது. எப்போது மாற வேண்டும் என்று நீங்களே முடிவு செய்கிறீர்கள்; `ccam next --auto` 5 மணி நேரப் பயன்பாடு மிகக் குறைவாக உள்ள கணக்கைத் தேர்ந்தெடுத்து, 100%-இல் உள்ள, உள்நுழையாத, அல்லது வேறொரு நிறுவனத்தின் கணக்குகளைத் தவிர்க்கிறது. `config.toml`-இல் `relay = true` இருந்தால், ccam அதற்குப் பதிலாக அமர்வின் அருகிலேயே காத்திருக்கும், அதனால் `/ccam:switch` தானாகவே தொடரும். வேறு சில கருவிகள் இயங்கும் session-இன் உள்நுழைவை மாற்றுகின்றன; அந்த வேறுபாட்டை [ccam மற்றும் பிற கணக்கு மாற்றும் கருவிகள்](/compare/account-switchers) விளக்குகிறது.

## நினைவில் வைக்க வேண்டியவை

- நீங்கள் வேலை செய்த அதே கோப்புறையில் `ccam next --continue` இயக்குங்கள்; உரையாடல்கள் திட்டக் கோப்புறை வாரியாகச் சேமிக்கப்படுகின்றன.
- ஒரே உரையாடலில் இரண்டு கணக்குகளை ஒரே நேரத்தில் இயக்குவதைத் தவிருங்கள். நீங்கள் முயன்றால் ccam எச்சரிக்கும்.
- பகிரப்பட்ட வரலாறு இல்லாவிட்டால், உரையாடல் மற்ற கணக்குக்கு நகலெடுக்கப்படும், இரண்டு நகல்களும் தனித்தனி வழியில் செல்லும்; `/rewind` code-ஐ மீட்டெடுக்கும் checkpoints முதல் கணக்கிடமே இருக்கும்.
- புதிய கணக்கில் முதல் செய்தி வழக்கத்தைவிட அதிக வரம்பைப் பயன்படுத்தலாம், ஏனெனில் அந்தக் கணக்கு இன்னும் உரையாடலை cache செய்யவில்லை.
- இப்படிக் கணக்குகளுக்கு இடையே மாற உங்களுக்கு அனுமதி உள்ளதா என்பது ஒவ்வொரு கணக்கின் விதிமுறைகளைப் பொறுத்தது.

`ccam usage`, `ccam next` ஆகியவற்றின் எல்லா options-க்கும் [பயன்பாட்டு வரம்புகள்](/docs/usage-limits) பக்கத்தைப் பாருங்கள்.
