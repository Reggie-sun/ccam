ஒரு கணக்கு Claude Code பயன்பாட்டு வரம்பை அடையும்போது, உங்களுக்குச் சொந்தமான வேறொரு கணக்கில் அதே உரையாடலைத் தொடருங்கள்: உரையாடல் வரலாற்றை ஒருமுறை பகிருங்கள், பிறகு `ccs next --continue` இயக்குங்கள். உங்களிடம் ஒரே ஒரு கணக்கு இருந்தால், Claude Code காட்டும் மீட்டமைப்பு நேரம் வரை காத்திருங்கள்.

## அது நடப்பதற்கு முன்

கணக்கு மாற்றம் ஒரே கட்டளையில் நடக்கும்படி கணக்குகளை அமையுங்கள்:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

இப்போது நீங்கள் வேலை செய்யும்போது நிலை வரி கணக்கையும் அதன் 5 மணி நேரப் பயன்பாட்டையும் காட்டும், அதனால் வரம்பு திடீரென்று வராது.

## வரம்பை அடைந்ததும்

Claude Code-இலிருந்து வெளியேறுங்கள் (`/exit`), பிறகு:

```sh
ccs usage
```

```console
 1 personal  ████████ 100% 22분        █████░░░  68% 1일 9시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
```

அதிக இடம் உள்ள கணக்கில் உரையாடலைத் திறங்கள்:

```sh
ccs next --auto --continue
```

Claude Code, தற்போதைய கோப்புறையின் மிகச் சமீபத்திய உரையாடலுடன், இதுவரை சொல்லப்பட்ட அனைத்தையும் சேர்த்து, `work` ஆகத் தொடங்கும்.

## நினைவில் கொள்ள வேண்டியவை

- நீங்கள் வேலை செய்த அதே கோப்புறையில் `ccs next --continue` இயக்குங்கள்; உரையாடல்கள் திட்டக் கோப்புறை வாரியாகச் சேமிக்கப்படுகின்றன.
- ஒரே உரையாடலில் ஒரே நேரத்தில் இரண்டு கணக்குகளை இயக்குவதைத் தவிருங்கள். நீங்கள் முயன்றால் ccam எச்சரிக்கும்.
- மற்றொரு கணக்கும் அதே குழுவில் உரையாடல் வரலாற்றைப் பகிர வேண்டும்.
- இப்படிக் கணக்குகளுக்கு இடையே மாற உங்களுக்கு அனுமதி உள்ளதா என்பது ஒவ்வொரு கணக்கின் விதிமுறைகளைப் பொறுத்தது.

`ccs usage` மற்றும் `ccs next`-இன் ஒவ்வொரு option-க்கும் [பயன்பாட்டு வரம்புகள்](/docs/usage-limits) பக்கத்தைப் பாருங்கள்.
