`CLAUDE_CONFIG_DIR`, `~/.claude`-க்குப் பதிலாக எந்தக் கோப்புறையைப் பயன்படுத்த வேண்டும் என்று Claude Code-க்குச் சொல்கிறது. கணக்கு சார்ந்த அனைத்தும் அங்கே இருக்கும்: உள்நுழைவு, அமைப்புகள், MCP சர்வர்கள், plugins, உரையாடல் வரலாறு. அதை வெவ்வேறு கோப்புறைகளுக்குச் சுட்டினால் தனித்தனி கணக்குகள் கிடைக்கும்.

```sh
CLAUDE_CONFIG_DIR=~/.claude-work claude
```

## CLAUDE_CONFIG_DIR அதிகாரப்பூர்வமாக ஆதரிக்கப்படுகிறதா?

ஆம். Claude Code இதைத் தன் [சூழல் மாறிகளில்](https://code.claude.com/docs/en/env-vars) config கோப்புறையை மாற்றும் வழியாகப் பட்டியலிட்டு, "பல கணக்குகளைப் பக்கம் பக்கமாக இயக்கப் பயனுள்ளது" என்று குறிப்பிடுகிறது. அதன் [அங்கீகார வழிகாட்டியும்](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) பல கணக்குகளுடன் உள்நுழைய இதையே பயன்படுத்துகிறது. இதை உங்கள் shell-இலோ பயனர் அமைப்புகளிலோ அமைக்கலாம், ஆனால் ஒரு திட்டத்தின் அமைப்புகளில் அமைக்க முடியாது.

## கோப்புறைக்குள் என்ன இருக்கிறது?

Claude Code 2.1.302 உடன் சரிபார்க்கப்பட்டது:

| பாதை | உள்ளடக்கம் | பகிரலாமா |
| --- | --- | --- |
| `.credentials.json` | உள்நுழைவு tokens (Linux, Windows), MCP OAuth tokens | இல்லை |
| `.claude.json` | கணக்கு விவரங்கள், பயனர் MCP சர்வர்கள், திட்ட வாரியான நிலை | இல்லை (MCP சர்வர்கள் தனியாக) |
| `settings.json` | அனுமதிகள், hooks, மாடல், status line, plugins | ஆம் |
| `CLAUDE.md` | பொது வழிமுறைகள் | ஆம் |
| `agents/`, `commands/`, `skills/`, `plugins/` | Extensions | ஆம் |
| `projects/` | `.jsonl` கோப்புகளாக உரையாடல்கள், திட்ட வாரியான நினைவகம் | ஆம் |
| `history.jsonl` | Prompt வரலாறு | ஆம் |
| `sessions/`, `shell-snapshots/`, `cache/` மற்றும் பிற | இயக்க நேர நிலை | இல்லை |

## பலர் எதில் தடுமாறுகிறார்கள்?

**`CLAUDE_CONFIG_DIR` இல்லாமல், `.claude.json` `~/.claude`-க்குள் இருக்காது.** அப்போது Claude Code அதைக் கோப்புறைக்கு அருகில் `~/.claude.json`-இல் வைக்கிறது. நீங்கள் `CLAUDE_CONFIG_DIR=~/.claude` பயன்படுத்தத் தொடங்கினால், Claude Code அதற்குப் பதிலாக `~/.claude/.claude.json`-ஐத் தேடும், உங்கள் கணக்கைக் கண்டுபிடிக்காது. `ccam import` இவ்விரண்டையும் இணைத்து இதைக் கையாள்கிறது.

**macOS-இல் உள்நுழைவு கோப்புறையில் அல்ல, Keychain-இல் இருக்கிறது.** Claude Code அதை `Claude Code-credentials` என்ற பெயரில் சேமிக்கிறது; `CLAUDE_CONFIG_DIR` அமைக்கப்பட்டிருந்தால், அதன் பின்னால் கோப்புறைப் பாதையின் ஒரு சிறிய hash சேர்க்கப்படும். அதனால் தனித்தனி கோப்புறைகளுக்குத் தனித்தனி Keychain பதிவுகள் கிடைக்கின்றன. Keychain எழுத மறுத்தால், [அதன் ஆவணங்கள்](https://code.claude.com/docs/en/authentication#credential-management) விவரிப்பது போல Claude Code கோப்புறையில் உள்ள `.credentials.json`-ஐப் பயன்படுத்துகிறது.

**எல்லா உள்நுழைவுகளும் கோப்புறையில் இருப்பதில்லை.** API key இல்லாத Claude Console உள்நுழைவு கோப்புறைக்கு வெளியே சேமிக்கப்படுகிறது, அதனால் தனித்தனி கோப்புறைகள் அப்படிப்பட்ட இரண்டு உள்நுழைவுகளைப் பிரித்து வைக்காது. claude.ai உள்நுழைவுகளும் API keys-உம் கோப்புறை வாரியாக வைக்கப்படுகின்றன.

## Windows-இல் கோப்புறை எங்கே இருக்கிறது?

இயல்பாக `%USERPROFILE%\.claude`, உள்நுழைவு அதற்குள் `.credentials.json`-இல் இருக்கும். Linux, macOS-இல் போலவே, ஒவ்வொரு கூடுதல் கணக்குக்கும் `CLAUDE_CONFIG_DIR`-ஐ வேறொரு கோப்புறைக்கு அமையுங்கள்.

## கோப்புறைகள் கோப்புகளைப் பகிர முடியுமா?

Symbolic links வேலை செய்கின்றன: இணைக்கப்பட்ட `settings.json` அல்லது `projects/` கோப்புறை வழியாக Claude Code படிக்கிறது, எழுதுகிறது, இணைப்பையும் அப்படியே வைத்திருக்கிறது. MCP சர்வர்கள் விதிவிலக்கு, ஏனெனில் அவை உள்நுழைவுடன் `.claude.json`-ஐப் பகிர்கின்றன; அவற்றை `--mcp-config` மூலம் கொடுங்கள்.

ccam சரியாக இந்த விதிகளின் மேல் கட்டப்பட்டுள்ளது. அது கோப்புறைகளை எப்படி இணைக்கிறது என்பதற்கு [பகிர்வு](/docs/sharing) பக்கத்தையும், முழுப் படத்துக்கு [பல கணக்குகள் வழிகாட்டியையும்](/guides/multiple-claude-code-accounts) பாருங்கள்.
