`~/.claude`-க்குப் பதிலாக எந்தக் கோப்புறையைப் பயன்படுத்த வேண்டும் என்று `CLAUDE_CONFIG_DIR` Claude Code-க்குச் சொல்கிறது. கணக்கு சார்ந்த அனைத்தும் அங்கே இருக்கும்: உள்நுழைவு, அமைப்புகள், MCP சர்வர்கள், plugins, உரையாடல் வரலாறு. அதை வெவ்வேறு கோப்புறைகளுக்குச் சுட்டினால் தனித்தனி கணக்குகள் கிடைக்கும்.

```sh
CLAUDE_CONFIG_DIR=~/.claude-work claude
```

## கோப்புறைக்குள் என்ன உள்ளது

Claude Code 2.1.302 உடன் சரிபார்க்கப்பட்டது:

| பாதை | உள்ளடக்கம் | பகிரலாமா |
| --- | --- | --- |
| `.credentials.json` | உள்நுழைவு tokens (Linux), MCP OAuth tokens | இல்லை |
| `.claude.json` | கணக்கு விவரங்கள், user MCP சர்வர்கள், திட்ட வாரியான நிலை | இல்லை (MCP சர்வர்கள் தனியாக) |
| `settings.json` | அனுமதிகள், hooks, model, நிலை வரி, plugins | ஆம் |
| `CLAUDE.md` | உலகளாவிய வழிமுறைகள் | ஆம் |
| `agents/`, `commands/`, `skills/`, `plugins/` | நீட்டிப்புகள் | ஆம் |
| `projects/` | `.jsonl` கோப்புகளாக உரையாடல்கள், திட்ட வாரியான நினைவகம் | ஆம் |
| `history.jsonl` | Prompt வரலாறு | ஆம் |
| `sessions/`, `shell-snapshots/`, `cache/` மற்றும் பிற | இயக்க நேர நிலை | இல்லை |

## பலரைக் குழப்பும் இரண்டு விவரங்கள்

**`CLAUDE_CONFIG_DIR` இல்லாமல், `.claude.json` `~/.claude`-க்குள் இருக்காது.** அப்போது Claude Code அதைக் கோப்புறைக்கு அருகில், `~/.claude.json`-இல் வைக்கிறது. நீங்கள் `CLAUDE_CONFIG_DIR=~/.claude` பயன்படுத்தத் தொடங்கினால், Claude Code அதற்குப் பதிலாக `~/.claude/.claude.json`-ஐத் தேடும், உங்கள் கணக்கைக் கண்டுபிடிக்காது. `ccam import` இந்த இரண்டையும் இணைப்பதன் மூலம் இதைக் கையாள்கிறது.

**macOS-இல் உள்நுழைவு கோப்புறையில் இல்லை, Keychain-இல் உள்ளது.** Claude Code அதை `Claude Code-credentials` என்ற பெயரில் சேமிக்கிறது; `CLAUDE_CONFIG_DIR` அமைக்கப்பட்டிருந்தால், அதைத் தொடர்ந்து கோப்புறைப் பாதையின் சிறிய hash வரும். அதனால் தனித்தனி கோப்புறைகளுக்குத் தனித்தனி Keychain பதிவுகள் கிடைக்கும். Keychain எழுதுவதை மறுத்தால், Claude Code கோப்புறையில் உள்ள `.credentials.json`-ஐப் பயன்படுத்தும்.

## கோப்புறைகளுக்கு இடையே பகிர்தல்

Symbolic links வேலை செய்கின்றன: இணைக்கப்பட்ட `settings.json` அல்லது `projects/` கோப்புறை வழியாக Claude Code படிக்கவும் எழுதவும் செய்கிறது, இணைப்பையும் அப்படியே வைத்திருக்கிறது. MCP சர்வர்கள் விதிவிலக்கு, ஏனெனில் அவை உள்நுழைவுடன் `.claude.json`-ஐப் பகிர்கின்றன; அவற்றுக்குப் பதிலாக `--mcp-config` மூலம் அனுப்புங்கள்.

ccam சரியாக இந்த விதிகளின் மேல் கட்டப்பட்டுள்ளது. அது கோப்புறைகளை எப்படி இணைக்கிறது என்பதற்கு [பகிர்வு](/docs/sharing) பக்கத்தையும், முழுப் படத்துக்கு [பல கணக்குகளுக்கான வழிகாட்டியையும்](/guides/multiple-claude-code-accounts) பாருங்கள்.
