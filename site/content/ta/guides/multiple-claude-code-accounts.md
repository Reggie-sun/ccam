ஒவ்வொரு கணக்குக்கும் அதன் சொந்த config கோப்புறையைக் கொடுங்கள். Claude Code அந்தக் கோப்புறையை `CLAUDE_CONFIG_DIR` சூழல் மாறியிலிருந்து படிக்கிறது. ஒவ்வொரு கோப்புறையும் தன் சொந்த உள்நுழைவு, அமைப்புகள், வரலாற்றை வைத்திருக்கும், அதனால் ஒவ்வொரு கணக்கும் உள்நுழைந்த நிலையிலேயே இருக்கும், அவற்றை ஒரே நேரத்தில் இயக்கலாம். இதை ஒரு shell alias மூலம் கையால் அமைக்கலாம், அல்லது ccam-ஐச் செய்ய விடலாம்.

## இதைக் கையால் அமைப்பது எப்படி?

இது [Claude Code ஆவணங்கள் விவரிக்கும்](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) அணுகுமுறை. கூடுதல் கணக்கு ஒவ்வொன்றுக்கும் `~/.bashrc` அல்லது `~/.zshrc`-இல் ஒரு வரியைச் சேருங்கள்:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

புதிய டெர்மினலைத் திறந்து `claude-work` இயக்குங்கள். கோப்புறை புதியது என்பதால் Claude Code உள்நுழையச் சொல்லும். அதன் பிறகு `claude` உங்கள் முதல் கணக்கு, `claude-work` இரண்டாவது கணக்கு.

WSL இல்லாத Windows-இல், உங்கள் profile-இல் (`notepad $PROFILE`) ஒரு PowerShell function இதையே செய்கிறது:

```powershell
function claude-work { $env:CLAUDE_CONFIG_DIR = "$HOME\.claude-work"; try { claude @args } finally { Remove-Item Env:CLAUDE_CONFIG_DIR } }
```

## alias அணுகுமுறையில் என்ன விடுபடுகிறது?

இரண்டு கணக்குகளுக்கு இது நன்றாக வேலை செய்கிறது. தெரிந்துகொள்ள வேண்டியவை:

- ஒவ்வொரு கோப்புறையும் காலியாகத் தொடங்குகிறது: அமைப்புகள், `CLAUDE.md`, MCP சர்வர்கள், agents, skills எதுவும் இல்லை. தேவையானதை நீங்களே நகலெடுக்க அல்லது இணைக்க வேண்டும், நகல்களை ஒத்திசைவில் வைப்பதும் உங்கள் வேலை.
- Aliases ஊடாடும் (interactive) shell-களில் மட்டுமே இருக்கும். Scripts, Makefiles, பிற நிரல்கள் அவற்றைப் பார்ப்பதில்லை.
- MCP சர்வர்கள் உள்நுழைவுக்கு அருகில் `.claude.json`-இல் இருக்கின்றன, அதனால் அவற்றைக் கோப்புறைகளுக்கு இடையே எளிதாக இணைக்க முடியாது.
- உரையாடல்கள் அவை தொடங்கிய கணக்கிலேயே இருக்கும், அதனால் ஓர் உரையாடலை வேறொரு கணக்கில் தொடர முடியாது.
- எல்லாக் கணக்குகளின் பயன்பாட்டையும் ஒரே நேரத்தில் காட்டும் வசதி எதுவும் இல்லை.

## அதற்குப் பதிலாக /login மூலம் கணக்கை மாற்றலாமா?

ஆம், எப்போதாவது மட்டும் மாற்றினால். Claude Code-க்குள் `/login` தட்டச்சு செய்தால், நீங்கள் இருக்கும் கோப்புறையின் [கணக்கு மாறுகிறது](https://code.claude.com/docs/en/quickstart). ஒரு நேரத்தில் ஒரு கணக்கு மட்டுமே உள்நுழைந்திருக்கும், அதனால் ஒவ்வொரு மாற்றத்திலும் மீண்டும் உள்நுழைய வேண்டும், இரண்டு கணக்குகளைப் பக்கம் பக்கமாக இயக்கவும் முடியாது. தனித்தனி கோப்புறைகள் இவ்விரண்டையும் தவிர்க்கின்றன.

## ccam மூலம் இதை அமைப்பது எப்படி?

ccam அதே யோசனையைத் தானியக்கமாக்கி, விடுபட்ட பகுதிகளைச் சேர்க்கிறது:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

இப்போது `ccam personal`, `ccam work` இரண்டு கணக்குகளையும் தொடங்குகின்றன; work கணக்குக்கு நீங்கள் கொடுத்த குறுக்குவழியான `ccwork`-உம் அதையே செய்கிறது. இவை aliases அல்ல, உண்மையான நிரல்கள் என்பதால் scripts-இலும் வேலை செய்கின்றன. பட்டியலிலிருந்து ஒரு கணக்கைத் தேர்ந்தெடுக்க `ccam`-ஐ மட்டும் இயக்குங்கள்; ஒன்றை இயல்புநிலைக் கணக்காக்க `ccam use work` இயக்குங்கள்.

அமைப்புகள், `CLAUDE.md`, MCP சர்வர்கள், extensions தொடக்கத்திலிருந்தே பகிரப்படுகின்றன. `ccam next --continue` ஓர் உரையாடலை மற்றொரு கணக்கில் தொடர்கிறது. பகிரப்பட்ட உரையாடல் வரலாற்றை இயக்கினால், இரண்டு கணக்குகளும் ஒரு நகலில் அல்ல, அதே உரையாடலில் வேலை செய்கின்றன. `ccam usage` எல்லாக் கணக்குகளின் 5 மணி நேர, வாராந்திரப் பயன்பாட்டை ஒரே நேரத்தில் காட்டுகிறது.

ஏற்கெனவே `~/.claude`-ஐப் பயன்படுத்தினால், அந்தக் கணக்கை மீண்டும் சேர்ப்பதற்குப் பதிலாக `ccam import` இயக்குங்கள்; அல்லது அதன் அமைப்புகள், MCP சர்வர்கள், extensions-ஐப் பகிரப்பட்ட `default` குழுவுக்குள் நகலெடுக்க `ccam migrate` இயக்குங்கள்.

## எந்தக் கணக்கு இயங்குகிறது என்று எப்படித் தெரிந்துகொள்வது?

Claude Code-க்குள், நீங்கள் உள்நுழைந்துள்ள கணக்கை `/status` காட்டுகிறது. ccam உடன் `ccam statusline install`-ஐ ஒருமுறை இயக்கினால், status line எப்போதும் கணக்கின் பெயரையும் அதன் பயன்பாட்டையும் காட்டும், எடுத்துக்காட்டாக `[work] · Opus · 5h 24% · 7d 41%`.

## இது Windows, WSL-இல் வேலை செய்யுமா?

Claude Code [Windows-இல் நேரடியாகவும் WSL-க்குள்ளும்](https://code.claude.com/docs/en/setup) இயங்குகிறது. `CLAUDE_CONFIG_DIR` இரண்டிலும் வேலை செய்கிறது, அதனால் நேரடி Windows-இல் மேலே உள்ள alias அல்லது PowerShell function போதும். ccam-உம் Windows-இல் நேரடியாக இயங்குகிறது: அதை PowerShell-இல் `irm https://ccam.dev/install.ps1 | iex` மூலம், அல்லது WSL-க்குள் Linux கட்டளை மூலம் நிறுவுங்கள். குறுக்குவழிகள் `ccwork.exe` ஆகின்றன, `settings.json` போன்ற கோப்புகளைப் பகிர Developer Mode தேவை ([ccam-ஐ நிறுவுதல்](/docs/install)).

## சிக்கல் தீர்வு

**Claude Code ஒவ்வொரு முறையும் உள்நுழையச் சொல்கிறது.** புதிய கோப்புறையில் முதல் முறை தொடங்கும்போது எப்போதும் கேட்கும். தொடர்ந்து கேட்டால், உள்நுழைவு காலாவதியாகியிருக்கும் அல்லது நீக்கப்பட்டிருக்கும்: `ccam login work` இயக்குங்கள் (அல்லது alias-ஐ ஒருமுறை தொடங்கி உள்நுழையுங்கள்).

**ஒரு MCP சர்வர் ஒரே ஒரு கணக்கில் மட்டும் தெரிகிறது.** ஒரு session-க்குள் `claude mcp add` மூலம் சேர்த்த சர்வர்கள் அந்தக் கணக்குக்கு மட்டுமே சொந்தம், `-s user` இல்லாமல் சேர்த்தால் அந்தக் கோப்புறைக்கு மட்டுமே. ஒன்றை எல்லாக் கணக்குகளுக்கும் நகர்த்த `ccam mcp import work <server>` இயக்குங்கள்.

**கணக்குகளுக்கு இடையே அமைப்புகள் வேறுபடுகின்றன.** கணக்கு எதை, எந்தக் குழு வழியாகப் பகிர்கிறது என்று `ccam share work` காட்டுகிறது; `ccam group join default work` என்ன மாறும் என்று காட்டிய பிறகு, `default` பகிர்வதை அந்தக் கணக்கும் பகிரச் செய்கிறது. `ccam doctor --fix` உடைந்த இணைப்புகளைச் சரிசெய்து, அது மாற்றும் ஒவ்வொரு கோப்புக்கும் காப்புப் பிரதி வைக்கிறது.

**இரண்டு கணக்குகள் ஒரே உரையாடலைத் திறக்கின்றன.** ஒரே உரையாடலில் இரண்டு கணக்குகளில் ஒரே நேரத்தில் வேலை செய்வதைத் தவிருங்கள். நீங்கள் முயன்றால் ccam எச்சரிக்கும்.

## எதைத் தேர்ந்தெடுப்பது?

இரண்டு கணக்குகள், எதுவும் பகிர வேண்டாம் என்றால் ஒரு alias போதும். பகிரப்பட்ட அமைப்புகள், MCP சர்வர்கள், அதிகக் கணக்குகள், ஒரே பார்வையில் பயன்பாடு அல்லது உரையாடல்களைத் தொடர்வது வேண்டுமென்றால், ccam உங்களுக்கு இந்தப் பராமரிப்பு வேலையை மிச்சப்படுத்துகிறது. [aliases உடனான ஒப்பீடு](/compare/aliases) வேறுபாடுகளைப் பக்கம் பக்கமாகப் பட்டியலிடுகிறது; ஒரே உள்நுழைவை மாற்றும் கருவிகளைப் பற்றி [ccam மற்றும் பிற கணக்கு மாற்றும் கருவிகள்](/compare/account-switchers) விளக்குகிறது.

ஒன்றுக்கு மேற்பட்ட கணக்குகளைப் பயன்படுத்தலாமா என்பது ஒவ்வொரு கணக்குக்கும் பொருந்தும் விதிமுறைகளைப் பொறுத்தது. தொடங்கும் முன் அந்த விதிமுறைகளைப் படியுங்கள்.

**Team மற்றும் Enterprise இருக்கைகள்.** தானியங்கிக் கணக்குத் தேர்வு (`ccam next`, `--fallback`, `ccam pick`, டாஷ்போர்டின் `n`, நீங்கள் இயக்கிய பிறகு [`auto_switch`](/features/next#auto-switch)) ஒரே Claude Team அல்லது Enterprise நிறுவனத்தின் இருக்கைகளுக்கு இடையேயும் மாறுகிறது, இது Anthropic-இன் விதிமுறைகளை மீறக்கூடும். அதை நம்பியிருக்கும் முன், [அடிக்கடி கேட்கப்படும் கேள்விகளைப்](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) படித்து, உங்கள் நிறுவனத்திடமும் Anthropic-இடமும் கேட்டு உறுதிசெய்துகொள்ளுங்கள்.
