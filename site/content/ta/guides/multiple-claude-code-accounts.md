ஒரே கணினியில் இரண்டு Claude Code கணக்குகளைப் பயன்படுத்த, ஒவ்வொரு கணக்குக்கும் அதன் சொந்த config கோப்புறையைக் கொடுங்கள். Claude Code அந்தக் கோப்புறையை `CLAUDE_CONFIG_DIR` சூழல் மாறியிலிருந்து படிக்கிறது, ஒவ்வொரு கோப்புறையும் தன் சொந்த உள்நுழைவு, அமைப்புகள், வரலாற்றை வைத்திருக்கும். இதை ஒரு shell alias மூலம் கையால் அமைக்கலாம், அல்லது ccam-ஐச் செய்ய விடலாம்.

## கையால், ஒரு alias மூலம்

இது Claude Code-இன் ஆவணங்கள் விவரிக்கும் அணுகுமுறை. ஒவ்வொரு கூடுதல் கணக்குக்கும் `~/.bashrc` அல்லது `~/.zshrc`-இல் ஒரு வரியைச் சேருங்கள்:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

புதிய டெர்மினலைத் திறந்து `claude-work` இயக்குங்கள். கோப்புறை புதியது என்பதால், Claude Code உங்களை உள்நுழையச் சொல்லும். அதன் பிறகு, `claude` உங்கள் முதல் கணக்கு, `claude-work` இரண்டாவது.

இரண்டு கணக்குகளுக்கு இது நன்றாக வேலை செய்யும். தெரிந்துகொள்ள வேண்டியவை:

- ஒவ்வொரு கோப்புறையும் காலியாகத் தொடங்கும்: அமைப்புகள் இல்லை, `CLAUDE.md` இல்லை, MCP சர்வர்கள் இல்லை, agents அல்லது skills இல்லை. தேவையானதை நீங்களே நகலெடுக்கவோ இணைக்கவோ வேண்டும், நகல்களை நீங்களே ஒத்திசைவில் வைக்க வேண்டும்.
- Aliases ஊடாடும் shells-இல் மட்டுமே இருக்கும். Scripts, Makefiles மற்றும் பிற நிரல்கள் அவற்றைப் பார்ப்பதில்லை.
- MCP சர்வர்கள் உள்நுழைவுக்கு அருகில் `.claude.json`-இல் இருக்கின்றன, அதனால் அவற்றைக் கோப்புறைகளுக்கு இடையே எளிதாக இணைக்க முடியாது.
- உரையாடல்கள் தொடங்கிய கணக்கிலேயே இருக்கும், அதனால் ஓர் உரையாடலை வேறொரு கணக்கில் தொடர முடியாது.
- எல்லாக் கணக்குகளின் பயன்பாட்டையும் ஒரே நேரத்தில் காட்டும் எதுவும் இல்லை.

## ccam மூலம்

ccam அதே யோசனையைத் தானியக்கமாக்கி, விடுபட்ட பகுதிகளைச் சேர்க்கிறது:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

இப்போது `ccam personal` மற்றும் `ccam work` இரண்டு கணக்குகளையும் தொடங்கும், work கணக்குக்கு நீங்கள் கொடுத்த குறுக்குவழியான `ccwork`-உம் அப்படியே. இவை aliases அல்ல, உண்மையான நிரல்கள் என்பதால், scripts-இலும் வேலை செய்யும். அமைப்புகள், `CLAUDE.md`, MCP சர்வர்கள், நீட்டிப்புகள் தொடக்கத்திலிருந்தே பகிரப்படும். `ccam next --continue` மூலம் ஓர் உரையாடலை மற்றொரு கணக்கில் தொடர, பகிரப்பட்ட உரையாடல் வரலாற்றை இயக்கலாம்.

நீங்கள் ஏற்கெனவே `~/.claude` பயன்படுத்தினால், அந்தக் கணக்கை மீண்டும் சேர்ப்பதற்குப் பதிலாக `ccam import` இயக்குங்கள், அல்லது அதன் அமைப்புகள், MCP சர்வர்கள், நீட்டிப்புகளைப் பகிரப்பட்ட அமைப்புகளுக்குள் நகலெடுக்க `ccam migrate` இயக்குங்கள்.

## எதைத் தேர்ந்தெடுப்பது

இரண்டு கணக்குகள், எதுவும் பகிர வேண்டாம் என்றால், ஒரு alias போதும். பகிரப்பட்ட அமைப்புகளும் MCP சர்வர்களும், அதிகக் கணக்குகள், ஒரே பார்வையில் பயன்பாடு, அல்லது உரையாடல்களைத் தொடர்வது வேண்டுமென்றால், ccam அந்தக் கணக்கு வழக்கு வேலையைக் குறைக்கிறது. [ஒப்பீடு](/compare/aliases) வேறுபாடுகளைப் பக்கம் பக்கமாகப் பட்டியலிடுகிறது.
