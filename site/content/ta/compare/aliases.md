பல Claude Code கணக்குகளை இயக்க எளிய வழி, ஒவ்வொரு கணக்குக்கும் ஒரு shell alias. ccam அடிப்படையில் அதையே செய்கிறது, அதோடு பகிர்வு, கணக்கு மாற்றம், பயன்பாட்டுக் கண்காணிப்பு ஆகியவற்றைச் சேர்க்கிறது.

| | Shell alias | ccam |
| --- | --- | --- |
| தனித்தனி உள்நுழைவுகள் | ஆம் | ஆம் |
| ஒவ்வொரு கணக்குக்குமான அமைப்பு | `~/.bashrc`-ஐத் திருத்தி, உள்நுழைதல் | `ccam add` |
| scripts மற்றும் பிற நிரல்களில் வேலை செய்யுமா | இல்லை, aliases shell-இல் மட்டுமே | ஆம், `claude2` ஓர் உண்மையான கட்டளை |
| பகிரப்பட்ட அமைப்புகள், `CLAUDE.md`, நீட்டிப்புகள் | கையால் நகலெடுத்தல் அல்லது இணைத்தல் | உருப்படி வாரியாக, காப்புப்பிரதிகளுடன் |
| பகிரப்பட்ட MCP சர்வர்கள் | கையால், ஒவ்வொரு கணக்குக்கும் | `ccam mcp add` ஒருமுறை |
| உரையாடலை வேறொரு கணக்கில் தொடர்தல் | இல்லை | `ccs next --continue` |
| எல்லாக் கணக்குகளின் பயன்பாடு | இல்லை | `ccs usage` |
| அதிக இடம் உள்ள கணக்கைத் தேர்ந்தெடுத்தல் | இல்லை | `ccs next --auto` |
| நிலை வரியில் கணக்கின் பெயர் | இல்லை | `ccam statusline install` |
| உடைந்த இணைப்புகளைச் சரிசெய்தல் | கையால் | `ccam doctor --fix` |
| கூடுதல் மென்பொருள் | எதுவுமில்லை | ஒரு static binary |

உங்களிடம் இரண்டு கணக்குகள் இருந்து, அவற்றுக்கு இடையே எதுவும் பகிரப்பட வேண்டாம் என்றால் aliases-ஐத் தேர்ந்தெடுங்கள். கணக்குகள் ஒரே அமைப்பு போல உணர வேண்டும் என்றால் ccam-ஐத் தேர்ந்தெடுங்கள். aliases-இல் தொடங்கி, பின்னர் ccam-க்கு மாறலாம்: `ccam import` ஏற்கெனவே உள்ள `~/.claude-*` கோப்புறைகளை அவை இருக்கும் இடத்திலேயே பதிவு செய்கிறது.
