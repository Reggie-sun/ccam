Claude Code கணக்குகளை மாற்றும் கருவிகள் இரண்டு அணுகுமுறைகளில் ஒன்றைப் பின்பற்றுகின்றன. பெரும்பாலானவை ஒரே `~/.claude` கோப்புறைக்குள் உள்நுழைவை மாற்றுகின்றன, அதனால் ஒரு நேரத்தில் ஒரு கணக்கு மட்டுமே செயலில் இருக்கும். ccam உட்படச் சில கருவிகள் `CLAUDE_CONFIG_DIR` மூலம் ஒவ்வொரு கணக்குக்கும் தனிக் கோப்புறையைக் கொடுக்கின்றன, அதனால் ஒவ்வொரு கணக்கும் உள்நுழைந்த நிலையிலேயே இருக்கும், பல கணக்குகள் ஒரே நேரத்தில் இயங்கலாம். ccam பகிரப்பட்ட அமைப்புகளையும் MCP சர்வர்களையும் சேர்க்கிறது, ஓர் உரையாடலை வேறொரு கணக்கின் கோப்புறையில் தொடரவும் உதவுகிறது.

## ஒரே உள்நுழைவை மாற்றுவதா, தனித்தனி கோப்புறைகளா?

**உள்நுழைவை மாற்றுவதில்** ஒரே ஒரு கோப்புறைதான் இருப்பதால், அமைப்புகள், MCP சர்வர்கள், வரலாறு ஆகியவை ஒரே தொகுப்பாக இருக்கும். மாற்றம் வேகமானது, இயங்கும் session புதிய உள்நுழைவை எடுத்துக்கொள்ளலாம். ஆனால் ஒரு நேரத்தில் ஒரு கணக்கு மட்டுமே செயலில் இருக்கும், அதுவும் எல்லா டெர்மினல்களுக்கும் editors-க்கும் ஒரே நேரத்தில்.

**தனித்தனி கோப்புறைகள்** என்பது [Claude Code ஆவணங்கள் விவரிக்கும்](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) முறை. ஒவ்வொரு கணக்கும் உள்நுழைந்த நிலையிலேயே இருக்கும், ஒரு வேலை session-ஐயும் ஒரு தனிப்பட்ட session-ஐயும் பக்கம் பக்கமாக இயக்கலாம். இதன் விலை: ஏதாவது ஒரு கருவி பகிராவிட்டால், ஒவ்வொரு கோப்புறையும் தன் சொந்த அமைப்புகள், MCP சர்வர்கள், வரலாற்றுடன் தொடங்குகிறது.

## ccam எதில் கவனம் செலுத்துகிறது

- ஒவ்வொரு கணக்கும் உள்நுழைந்த நிலையிலேயே இருக்கும். கணக்கை மாற்றுவது எந்தக் கணக்கையும் வெளியேற்றாது, `ccam work`, `ccam personal` இரண்டையும் இரண்டு டெர்மினல்களில் ஒரே நேரத்தில் இயக்கலாம்.
- MCP சர்வர்கள், `settings.json`, `CLAUDE.md`, agents, skills, plugins ஆகியவை இணைப்புகள் வழியாக, உருப்படி வாரியாகவும் கணக்கு வாரியாகவும் கோப்புறைகளுக்கு இடையே பகிரப்படுகின்றன. உள்நுழைவுகள் ஒருபோதும் பகிரப்படுவதில்லை.
- பகிரப்பட்ட வரலாற்றுடன், `ccam next --auto --continue` என்ற ஒரே கட்டளை அதிக இடம் உள்ள கணக்கின் கோப்புறையில் அதே உரையாடலைத் திறக்கிறது.
- ccam Claude Code-ஐத் தொடங்கி, தன் இடத்தில் அதை இயக்குகிறது, அதனால் பின்னணியில் எதுவும் இயங்குவதில்லை. அது உங்கள் பயன்பாட்டைக் கண்காணிப்பதோ தானாக மாற்றுவதோ இல்லை; எப்போது மாற்றுவது என்று நீங்களே முடிவு செய்கிறீர்கள்.

## பிற கருவிகள் எதில் அதிகம் செய்கின்றன

- claude-swap, CCS, clauth, CAAM, cux ஆகியவை WSL இல்லாமல் Windows-இல் இயங்குகின்றன. ccam இயங்காது.
- ஒரு கணக்கு குறிப்பிட்ட பயன்பாட்டு அளவைத் தாண்டும்போது claude-swap, clauth, cux தாமாகவே மாற்றுகின்றன. ccam அந்த மாற்றத்தை உங்களிடம் விடுகிறது.
- CCSwitcher, Claude Switcher, claude-swap ஆகியவை macOS menu bar-இல் பயன்பாட்டைக் காட்டுகின்றன.
- CCS, CAAM, ccswap, Claude Switcher ஆகியவை Codex-ஐயும் பிற coding agents-ஐயும் நிர்வகிக்கின்றன.

## எது பொருந்தும்?

ஒரு நேரத்தில் ஒரு கணக்கைப் பயன்படுத்தினால், மாற்றம் தானாக நடக்க வேண்டுமென்றால், அல்லது WSL இல்லாத Windows-இல் இருந்தால், உள்நுழைவை மாற்றும் கருவியைத் தேர்ந்தெடுங்கள். கணக்குகளைப் பக்கம் பக்கமாக இயக்கவும், ஒரே பகிரப்பட்ட அமைப்பு வேண்டுமென்றும், அடுத்த கணக்கில் அதே உரையாடலைத் தொடரவும் விரும்பினால் ccam-ஐத் தேர்ந்தெடுங்கள். எதுவும் பகிர வேண்டாம் என்றால், [எளிய shell aliases](/compare/aliases) போதும்.

பல கணக்குகளைப் பயன்படுத்த உங்களுக்கு அனுமதி உள்ளதா என்பது ஒவ்வொரு கணக்கின் விதிமுறைகளைப் பொறுத்தது. அதற்கு முன் அவற்றைச் சரிபாருங்கள்.
