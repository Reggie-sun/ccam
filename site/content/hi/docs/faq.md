## क्या ccam, Anthropic का आधिकारिक टूल है?

नहीं। ccam एक अनौपचारिक ओपन-सोर्स प्रोजेक्ट है। यह Anthropic से संबद्ध नहीं है और Anthropic इसका समर्थन नहीं करता। यह `CLAUDE_CONFIG_DIR` सेटिंग इस्तेमाल करता है, जिसे Claude Code कई अकाउंट साथ-साथ चलाने के लिए [अपने दस्तावेज़ में बताता है](https://code.claude.com/docs/en/env-vars)।

## क्या मुझे कई Claude Code अकाउंट इस्तेमाल करने की अनुमति है?

यह हर अकाउंट की शर्तों पर निर्भर करता है, और work अकाउंट के लिए आपके संगठन की नीति पर भी। कई अकाउंट इस्तेमाल करने से पहले उन्हें जाँच लें। ccam केवल उन अकाउंट्स के बीच स्विच करना आसान बनाता है जो आपके पास पहले से हैं।

## क्या ccam उपयोग सीमाओं से बचने का तरीका है?

नहीं। हर अकाउंट की अपनी सीमाएँ बनी रहती हैं। ccam उन्हें दिखाता है, और जब एक अकाउंट की सीमा ख़त्म हो जाए, तो आपको अपने ही किसी दूसरे अकाउंट पर जारी रखने देता है।

## एक कंप्यूटर पर दो Claude Code अकाउंट कैसे इस्तेमाल करें?

हर अकाउंट को `CLAUDE_CONFIG_DIR` के ज़रिए उसका अपना कॉन्फ़िगरेशन फ़ोल्डर दें। ccam यह आपके लिए करता है: हर अकाउंट के लिए `ccam add` चलाएँ, फिर उन्हें `ccam personal` और `ccam work` से, या अपने रखे नाम वाले शॉर्टकट, जैसे `ccwork`, से शुरू करें। [गाइड](/guides/multiple-claude-code-accounts) यह भी दिखाती है कि इसे हाथ से कैसे करें।

## किसी बातचीत को दूसरे अकाउंट में कैसे जारी रखें?

`ccam share <name> --history on` से दोनों अकाउंट्स के बीच बातचीत का इतिहास साझा करें, फिर `ccam next --continue` चलाएँ। Claude Code मौजूदा फ़ोल्डर की सबसे हाल की बातचीत अगले अकाउंट में खोलता है।

## क्या ccam मेरा लॉगिन देखता या भेजता है?

ccam आपका Claude लॉगिन कभी अकाउंट्स के बीच साझा नहीं करता। यह किसी अकाउंट का access token केवल तब पढ़ता है जब उस अकाउंट का उपयोग Anthropic के usage endpoint से पूछना हो, यानी जब आप `ccam usage`, `ccam next --auto` या `ccam doctor` चलाते हैं। `ccam migrate` MCP सर्वरों के सहेजे गए साइन-इन `~/.claude` से उसी कंप्यूटर पर आपके अकाउंट्स की अपनी लॉगिन फ़ाइलों में कॉपी करता है। ccam में कोई telemetry नहीं है और यह कहीं और कुछ नहीं भेजता।

## रिमोट सर्वर पर साइन इन कैसे करें?

SSH सेशन में हमेशा की तरह `ccam add` या `ccam login <name>` चलाएँ। Claude Code सर्वर पर साइन-इन का इंतज़ार करता है, इसलिए आपके कंप्यूटर का ब्राउज़र आख़िर में `http://localhost:<port>/callback?code=…` पेज पर पहुँचता है, जो लोड नहीं होता। वह पता ब्राउज़र से कॉपी करें और टर्मिनल में पेस्ट करें: ccam उसे सर्वर पर Claude Code को देता है, जो साइन-इन पूरा करता है। इस पते में एक बार इस्तेमाल होने वाला कोड होता है, इसलिए इसे किसी के साथ साझा न करें।

## मेरे अकाउंट कहाँ रखे जाते हैं?

`~/.local/share/ccam/profiles/<name>/` में, हर अकाउंट के लिए एक फ़ोल्डर। macOS पर Claude Code लॉगिन को ख़ुद कीचेन में रखता है, उस फ़ोल्डर से बने नाम के तहत।

## मेरे मौजूदा ~/.claude का क्या होगा?

कुछ नहीं, जब तक आप `ccam import` या `ccam migrate` न चलाएँ। Import फ़ोल्डर को उसी जगह रजिस्टर करता है जहाँ वह है, इसलिए सादा `claude` और `ccam <name>` एक ही अकाउंट और सेटिंग्स इस्तेमाल करते रहते हैं। `ccam migrate` उसकी सेटिंग्स, `CLAUDE.md`, एक्सटेंशन और MCP सर्वर साझा सेटिंग्स में कॉपी करता है और फ़ोल्डर को केवल पढ़ता है।

## ccam किन सिस्टम पर चलता है?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine और दूसरे) और macOS। Windows पर इसे WSL के अंदर इस्तेमाल करें।

## कोई MCP सर्वर केवल एक अकाउंट में क्यों दिखता है?

Session के अंदर `claude mcp add` से जोड़े गए सर्वर केवल उसी अकाउंट के लिए सेव होते हैं। अगली बार जब आप वह अकाउंट शुरू करते हैं, तो ccam आपको बताता है; `ccam mcp import <account> <server>` से सर्वर को साझा ग्रुप में move करें।

## क्या ccam से Claude Code धीमा होता है?

ccam के ज़रिए Claude Code शुरू करने में लगभग 4 मिलीसेकंड जुड़ते हैं, जिसे एक लैपटॉप पर `scripts/perf-check.sh` से मापा गया है। ccam एक छोटी फ़ाइल पढ़ता है, साझा लिंक जाँचता है और फिर ख़ुद की जगह `claude` चला देता है, इसलिए आपके काम करते समय यह चल नहीं रहा होता।

## ccam को अपडेट कैसे करें?

`ccam update` चलाएँ। यह नवीनतम रिलीज़ डाउनलोड करता है, उसका checksum जाँचता है और `ccam` फ़ाइल को बदल देता है; `ccam update --check` केवल यह बताता है कि कोई नई रिलीज़ है या नहीं। ccam कभी अपने आप अपडेट नहीं होता। अगर आपने `.deb` पैकेज इंस्टॉल किया था, तो इसके बजाय नया `.deb` apt से इंस्टॉल करें। [अपडेट](/docs/install#update) देखें।

## ccam को अनइंस्टॉल कैसे करें?

हर अकाउंट का शॉर्टकट `ccam shortcut <account> --remove` से हटाएँ, `ccam` को `~/.local/bin` से मिटाएँ, फिर अगर अब अकाउंट्स की ज़रूरत नहीं है तो `~/.config/ccam`, `~/.local/share/ccam` और `~/.local/state/ccam` हटाएँ। [इंस्टॉल](/docs/install#uninstall) देखें।
