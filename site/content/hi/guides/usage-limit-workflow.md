जब एक अकाउंट अपनी सीमा तक पहुँच जाए, तो वही बातचीत अपने किसी दूसरे अकाउंट में जारी रखें: एक बार बातचीत का इतिहास साझा करें, फिर `ccam next --continue` चलाएँ। अगर आपके पास केवल एक अकाउंट है, तो Claude Code जो रीसेट समय दिखाता है, उसका इंतज़ार करें।

## ऐसा होने से पहले

अकाउंट्स को इस तरह सेट करें कि स्विच करने में एक ही कमांड लगे:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

अब काम करते समय स्टेटस लाइन अकाउंट और उसका 5 घंटे का उपयोग दिखाती है, इसलिए सीमा अचानक नहीं आती।

## जब सीमा पूरी हो जाए

Claude Code से बाहर निकलें (`/exit`), फिर:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

सबसे ज़्यादा गुंजाइश वाले अकाउंट में बातचीत खोलें:

```sh
ccam next --auto --continue
```

Claude Code `work` के रूप में शुरू होता है, मौजूदा फ़ोल्डर की सबसे हाल की बातचीत के साथ, जिसमें अब तक कही गई हर बात शामिल है।

## ध्यान रखने वाली बातें

- `ccam next --continue` उसी फ़ोल्डर में चलाएँ जिसमें आप काम कर रहे थे; बातचीत हर प्रोजेक्ट फ़ोल्डर के हिसाब से रखी जाती है।
- एक ही बातचीत पर एक ही समय में दो अकाउंट चलाने से बचें। अगर आप ऐसा करने की कोशिश करते हैं, तो ccam चेतावनी देता है।
- दूसरे अकाउंट को भी उसी ग्रुप में बातचीत का इतिहास साझा करना होगा।
- आप इस तरह अकाउंट्स के बीच स्विच कर सकते हैं या नहीं, यह हर अकाउंट की शर्तों पर निर्भर करता है।

`ccam usage` और `ccam next` के हर विकल्प के लिए [उपयोग सीमाएँ](/docs/usage-limits) देखें।
