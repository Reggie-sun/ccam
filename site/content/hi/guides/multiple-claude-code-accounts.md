हर अकाउंट को उसका अपना configuration फ़ोल्डर दें। Claude Code यह फ़ोल्डर `CLAUDE_CONFIG_DIR` environment variable से पढ़ता है, और हर फ़ोल्डर में उसका अपना लॉगिन, सेटिंग्स और इतिहास रहता है। Claude Code multiple accounts का यह सेटअप आप shell alias से हाथ से कर सकते हैं, या ccam को करने दे सकते हैं।

## हाथ से, alias के साथ

यही तरीका Claude Code के दस्तावेज़ में बताया गया है। हर अतिरिक्त अकाउंट के लिए `~/.bashrc` या `~/.zshrc` में एक लाइन जोड़ें:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

नया terminal खोलें और `claude-work` चलाएँ। Claude Code आपसे लॉगिन करने को कहता है, क्योंकि फ़ोल्डर नया है। इसके बाद `claude` आपका पहला अकाउंट है और `claude-work` दूसरा।

दो अकाउंट्स के लिए यह अच्छी तरह काम करता है। ध्यान रखने वाली बातें:

- हर फ़ोल्डर ख़ाली शुरू होता है: कोई सेटिंग्स नहीं, कोई `CLAUDE.md` नहीं, कोई MCP सर्वर नहीं, कोई agents या skills नहीं। जो चाहिए उसे आप copy या link करते हैं, और copies को ख़ुद एक जैसा बनाए रखते हैं।
- Aliases केवल interactive shells में होते हैं। Scripts, Makefiles और दूसरे प्रोग्राम उन्हें नहीं देखते।
- MCP सर्वर लॉगिन के साथ `.claude.json` में रहते हैं, इसलिए उन्हें फ़ोल्डरों के बीच सीधे लिंक नहीं किया जा सकता।
- बातचीत उसी अकाउंट में रहती है जहाँ वह शुरू हुई थी, इसलिए आप उसे दूसरे अकाउंट में जारी नहीं रख सकते।
- ऐसा कुछ नहीं है जो सभी अकाउंट्स का उपयोग एक साथ दिखाए।

## ccam के साथ

ccam इसी विचार को स्वचालित करता है और छूटे हुए हिस्से जोड़ता है:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
```

अब `claude1` और `claude2`, या `ccam personal` और `ccam work`, दोनों अकाउंट शुरू करते हैं। क्योंकि ये aliases नहीं, असली प्रोग्राम हैं, ये scripts में भी काम करते हैं। सेटिंग्स, `CLAUDE.md`, MCP सर्वर और एक्सटेंशन शुरू से साझा होते हैं, और आप साझा बातचीत का इतिहास चालू करके `ccam next --continue` से किसी बातचीत को दूसरे अकाउंट पर जारी रख सकते हैं।

अगर आप पहले से `~/.claude` इस्तेमाल करते हैं, तो वह अकाउंट फिर से जोड़ने की बजाय `ccam import` चलाएँ।

## कौन-सा चुनें

दो अकाउंट्स के लिए, जिनमें कुछ भी साझा नहीं करना है, alias काफ़ी है। जब आप साझा सेटिंग्स और MCP सर्वर, ज़्यादा अकाउंट, एक नज़र में उपयोग, या बातचीत जारी रखना चाहते हैं, तो ccam यह सारा हिसाब-किताब आपसे बचाता है। [तुलना](/compare/aliases) में अंतर साथ-साथ दिए गए हैं।
