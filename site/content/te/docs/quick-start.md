`ccam add` తో ప్రతి ఖాతాను జోడించండి, తర్వాత `claude1`, `claude2` లేదా `ccam <name>` తో Claude Code ను ప్రారంభించండి. చాలా మందికి కావలసింది ఇంతే.

## 1. మీ మొదటి ఖాతాను జోడించండి

```sh
ccam add
```

విజార్డ్ `personal` లేదా `work` వంటి ఒక పేరును, ఈ ఖాతా మీ ఇతర ఖాతాలతో ఏ అంశాలను షేర్ చేయాలో అడుగుతుంది. తర్వాత అది `claude auth login` ను రన్ చేస్తుంది, ఇది మీరు సైన్ ఇన్ చేయడానికి బ్రౌజర్‌ను తెరుస్తుంది. పూర్తయినప్పుడు మీకు ఇది కనిపిస్తుంది:

```console
✓ personal (me@example.com) added — shortcut: claude1
```

ccam తన సందేశాలను ఇంగ్లీష్‌లో ప్రింట్ చేస్తుంది; కమాండ్‌లు, ఆప్షన్లు ప్రతి భాషలోనూ ఒకటే.

## 2. రెండో ఖాతాను జోడించండి

```sh
ccam add work
```

బ్రౌజర్‌లో మరో ఖాతాతో సైన్ ఇన్ చేయండి. అది `claude2` అవుతుంది.

## 3. మారండి

వీటిలో ఏదైనా work ఖాతాగా Claude Code ను ప్రారంభిస్తుంది:

```sh
claude2
ccam work
ccam 2
```

ఖాతా పేరు తర్వాత ఉన్నదంతా మార్పు లేకుండా Claude Code కు వెళ్తుంది, కాబట్టి మీకు తెలిసిన ఆప్షన్లనే ఉపయోగిస్తూ ఉండవచ్చు:

```sh
ccam work --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

`ccam` ను ఒక్కటే రన్ చేస్తే ఎంపిక మెనూ తెరుచుకుంటుంది: యారో కీలు, Enter ఉపయోగించండి, లేదా ఖాతా సంఖ్యను నొక్కండి.

## 4. ఏమి షేర్ చేయాలో ఎంచుకోండి

డిఫాల్ట్‌గా, MCP సర్వర్లు, `settings.json`, గ్లోబల్ `CLAUDE.md`, ఏజెంట్లు, కమాండ్‌లు, స్కిల్స్, ప్లగిన్లు ఖాతాల మధ్య షేర్ అవుతాయి. సంభాషణ చరిత్ర షేర్ కాదు. ఖాతాల మధ్య సంభాషణలను కొనసాగించాలనుకుంటే, రెండు ఖాతాలకూ దాన్ని ఆన్ చేయండి:

```sh
ccam share personal --history on
ccam share work --history on
```

ఏదైనా మార్చే ముందు ccam తాను ఏమి తరలిస్తుందో చూపిస్తుంది. వివరాల కోసం [షేరింగ్](/docs/sharing) చూడండి.

## 5. ఒక ఖాతా పరిమితిని చేరినప్పుడు

```sh
ccam usage
ccam next --continue
```

`ccam usage` అన్ని ఖాతాల 5 గంటల, వారపు వినియోగాన్ని చూపిస్తుంది. `ccam next --continue` అదే సంభాషణను తర్వాతి ఖాతాలో తెరుస్తుంది. [వినియోగ పరిమితులు](/docs/usage-limits) చూడండి.

## ఇప్పటికే ~/.claude ఉపయోగిస్తున్నారా?

మళ్లీ సైన్ ఇన్ చేయడానికి బదులు దాన్ని నమోదు చేయండి:

```sh
ccam import
```

ఫోల్డర్ ఉన్న చోటే ఉంటుంది, సాధారణ `claude` మునుపటిలాగే పనిచేస్తుంది.
