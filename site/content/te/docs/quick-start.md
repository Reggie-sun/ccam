`ccam add` తో ప్రతి ఖాతాను జోడించండి, తర్వాత `ccam <name>` తో లేదా `ccwork` వంటి మీరే పేరు పెట్టిన షార్ట్‌కట్‌తో Claude Code ను ప్రారంభించండి. చాలా మందికి కావలసింది ఇంతే.

ఇప్పటికే Claude Code ఉపయోగిస్తున్నారా? మొదలుపెట్టే ముందు ఈ పేజీ చివరలో ఉన్న [ఇప్పటికే ~/.claude ఉపయోగిస్తున్నారా?](#already-using-claude) చదవండి.

## 1. మీ మొదటి ఖాతాను జోడించండి

```sh
ccam add
```

విజార్డ్ `personal` లేదా `work` వంటి ఒక పేరును, ఈ ఖాతా మీ ఇతర ఖాతాలతో ఏ అంశాలను షేర్ చేయాలో, ఒక షార్ట్‌కట్ కమాండ్ సృష్టించాలా వద్దా (దశ 3 చూడండి) అని అడుగుతుంది. తర్వాత అది `claude auth login` ను రన్ చేస్తుంది, ఇది మీరు సైన్ ఇన్ చేయడానికి బ్రౌజర్‌ను తెరుస్తుంది. రిమోట్ మెషీన్‌లో, మీ బ్రౌజర్ లోడ్ కాని `http://localhost:…/callback` పేజీ వద్ద ఆగిపోవచ్చు; ఆ అడ్రస్‌ను టెర్మినల్‌లో పేస్ట్ చేస్తే ccam సైన్-ఇన్‌ను పూర్తి చేస్తుంది. సైన్-ఇన్ పూర్తయినప్పుడు మీకు ఇది కనిపిస్తుంది:

```console
✓ personal (me@example.com) added
  no shortcut (add one with `ccam shortcut personal ccpersonal`)
```

## 2. మీ ప్రస్తుత సెట్టింగ్‌లను తీసుకురండి

మీరు ఇంతకు ముందు Claude Code ఉపయోగించి ఉంటే, మీ సెట్టింగ్‌లు, `CLAUDE.md`, ఎక్స్‌టెన్షన్లు `~/.claude` లో, మీ MCP సర్వర్లు `~/.claude.json` లో ఉంటాయి. ప్రతి ఖాతాకు అవి అందేలా వాటిని షేర్డ్ `default` గ్రూప్‌లోకి కాపీ చేయండి:

```sh
ccam migrate
```

ccam తాను ఏమి కాపీ చేస్తుందో చూపించి, ముందుగా అడుగుతుంది. ఇది `~/.claude` ను చదువుతుంది మాత్రమే, ఏ లాగిన్‌నూ కాపీ చేయదు, మీరు `--history` జోడిస్తే తప్ప సంభాషణ చరిత్రను వదిలేస్తుంది. వివరాల కోసం [ఇప్పటికే ఉన్న సెటప్‌ను కాపీ చేయడం](/docs/sharing#copy-an-existing-setup) చూడండి.

## 3. రెండో ఖాతాను జోడించండి

```sh
ccam add work
```

పేరును మీరు కమాండ్ లైన్‌లోనే ఇచ్చారు కాబట్టి విజార్డ్ దాన్ని అడగదు, `default` టిక్ చేసి ఉన్న, చేరాల్సిన గ్రూప్‌లను చూపిస్తుంది. ఈసారి, ఖాతాను ఒకే పదంతో ప్రారంభించగలిగేలా దానికి `ccwork` వంటి సొంత షార్ట్‌కట్ కమాండ్ ఇవ్వండి. గ్రూప్‌ల తర్వాత విజార్డ్ ఇలా అడుగుతుంది:

```console
 Create a shortcut command for work? [y/N]
 A command such as ccwork that opens Claude Code as this account.
```

`y` నొక్కి, ఒక పేరు టైప్ చేయండి, లేదా సూచించిన పేరునే ఉపయోగించడానికి Enter నొక్కండి:

```console
 Shortcut name [ccwork]: █
 a-z, 0-9, '.', '-' and '_'; Enter alone uses ccwork
```

తర్వాత బ్రౌజర్‌లో మరో ఖాతాతో సైన్ ఇన్ చేయండి. ccam ఖాతాను, దాని షార్ట్‌కట్‌ను నిర్ధారిస్తుంది:

```console
✓ work (work@example.com) added
  shortcut: ccwork
```

## 4. ఖాతాలు మార్చండి

`ccam work` Claude Code ను work ఖాతాగా ప్రారంభిస్తుంది. మీరు షార్ట్‌కట్ ప్రశ్నను దాటవేసి ఉంటే, ఎప్పుడైనా షార్ట్‌కట్‌ను జోడించవచ్చు:

```console
$ ccam shortcut work ccwork
✓ shortcut for work: ccwork
```

ఇప్పుడు ఈ కమాండ్‌లలో ప్రతి ఒక్కటీ work ఖాతాగా Claude Code ను ప్రారంభిస్తుంది (`ccam list` లో దాని నంబర్ `2`):

```sh
ccwork
ccam work
ccam 2
```

`ccam` ను ఒక్కటే రన్ చేస్తే [డాష్‌బోర్డ్](/features/dashboard) తెరుచుకుంటుంది: యారో కీలతో లేదా ఖాతా సంఖ్యతో ఒక ఖాతాకు వెళ్లి, Enter నొక్కండి.

షార్ట్‌కట్ లేదా ఖాతా పేరు తర్వాత ఉన్నదంతా మార్పు లేకుండా Claude Code కు వెళ్తుంది, కాబట్టి మీకు తెలిసిన ఆప్షన్లనే ఉపయోగిస్తూ ఉండవచ్చు:

```sh
ccwork --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | ccwork -p "what caused this?"
```

## 5. ఏమి షేర్ చేయాలో ఎంచుకోండి

డిఫాల్ట్‌గా, MCP సర్వర్లు, `settings.json`, గ్లోబల్ `CLAUDE.md`, ఎక్స్‌టెన్షన్లు (ఏజెంట్లు, కమాండ్‌లు, స్కిల్స్, ప్లగిన్లు) `default` గ్రూప్ ద్వారా ఖాతాల మధ్య షేర్ అవుతాయి. సంభాషణ చరిత్ర షేర్ కాదు. ఖాతాల మధ్య సంభాషణలను కొనసాగించాలనుకుంటే, దాన్ని గ్రూప్‌కు జోడించండి:

```sh
ccam group set default --add history
```

ఏదైనా మార్చే ముందు ccam ప్రతి ఖాతా కోసం తాను ఏమి తరలిస్తుందో చూపిస్తుంది. వివరాల కోసం [గ్రూప్‌లతో షేరింగ్](/features/share) చూడండి.

## 6. ఒక ఖాతా పరిమితిని చేరినప్పుడు

```sh
ccam usage
ccam next --continue
```

`ccam usage` అన్ని ఖాతాల 5 గంటల, వారపు వినియోగాన్ని చూపిస్తుంది. `ccam next --continue` అదే సంభాషణను తర్వాతి ఖాతాలో తెరుస్తుంది. స్క్రిప్ట్‌లలో `ccam --fallback work -p "…"` తనంతట తానే మారుస్తుంది. [వినియోగ పరిమితులు](/docs/usage-limits) చూడండి.

**Team, Enterprise సీట్లు.** ఆటోమేటిక్ ఖాతా ఎంపిక (`ccam next`, `--fallback`, `ccam pick`, డాష్‌బోర్డ్‌లోని `n`, మీరు ఆన్ చేసిన తర్వాత [`auto_switch`](/features/next#auto-switch)) ఒకే Claude Team లేదా Enterprise సంస్థలోని సీట్ల మధ్య కూడా మారుస్తుంది, ఇది Anthropic నిబంధనల ఉల్లంఘన కావచ్చు. దానిపై ఆధారపడే ముందు [తరచుగా అడిగే ప్రశ్నలు](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) చదివి, మీ సంస్థను, Anthropic ను సంప్రదించి నిర్ధారించుకోండి.

## ఇప్పటికే ~/.claude ఉపయోగిస్తున్నారా?

మళ్లీ సైన్ ఇన్ చేయడానికి బదులు దాన్ని నమోదు చేయండి:

```sh
ccam import
```

ఫోల్డర్ ఉన్న చోటే ఉంటుంది, సాధారణ `claude` మునుపటిలాగే పనిచేస్తుంది.
