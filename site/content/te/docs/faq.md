## ccam అనేది Anthropic యొక్క అధికారిక టూలా?

కాదు. ccam ఒక అనధికారిక ఓపెన్-సోర్స్ ప్రాజెక్ట్. దీనికి Anthropic తో ఎలాంటి సంబంధం లేదు, Anthropic దీన్ని ఆమోదించలేదు. అనేక ఖాతాలను పక్కపక్కనే రన్ చేయడానికి [Claude Code డాక్యుమెంట్ చేసిన](https://code.claude.com/docs/en/env-vars) `CLAUDE_CONFIG_DIR` సెట్టింగ్‌ను ఇది ఉపయోగిస్తుంది.

## నేను అనేక Claude Code ఖాతాలను ఉపయోగించవచ్చా?

అది ప్రతి ఖాతా నిబంధనలపై, work ఖాతాల విషయంలో మీ సంస్థ విధానంపై ఆధారపడి ఉంటుంది. అనేక ఖాతాలను ఉపయోగించే ముందు వాటిని తనిఖీ చేయండి. మీకు ఇప్పటికే ఉన్న ఖాతాల మధ్య మారడాన్ని మాత్రమే ccam సులభం చేస్తుంది.

**Team, Enterprise సీట్లు.** ఆటోమేటిక్ ఎంపిక (`ccam next`, `--fallback`, `ccam pick`, డాష్‌బోర్డ్‌లోని `n`) ఒకే Claude Team లేదా Enterprise సంస్థలోని సీట్ల మధ్య కూడా మారుస్తుంది. Anthropic సహాయ కేంద్రం "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (Team ప్లాన్‌లోని ప్రతి సీటు పేరుతో నిర్దేశించిన ఒక వ్యక్తికి కేటాయించబడుతుంది, ఆ వ్యక్తి మాత్రమే దాన్ని ఉపయోగించవచ్చు) అని, "Users can't route their work through another user's account to use that user's remaining usage" (యూజర్లు మరో యూజర్‌కు మిగిలి ఉన్న వినియోగాన్ని వాడుకోవడానికి తమ పనిని ఆ యూజర్ ఖాతా ద్వారా మళ్లించకూడదు) అని చెబుతుంది ([Team ప్లాన్‌లు](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129); [Enterprise ప్లాన్‌లకు](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) కూడా ఇదే వర్తిస్తుంది). కాబట్టి సీట్ల మధ్య ఆటోమేటిక్ ఎంపికను ఉపయోగించడం Anthropic నిబంధనల ఉల్లంఘన కావచ్చు. దానిపై ఆధారపడే ముందు మీ సంస్థను, Anthropic ను సంప్రదించి నిర్ధారించుకోండి. వ్యక్తిగత ప్లాన్‌ల (Pro, Max) గురించి పై పేరా చెబుతుంది.

## ccam వినియోగ పరిమితులను దాటవేస్తుందా?

లేదు. ప్రతి ఖాతా తన సొంత పరిమితులను కలిగి ఉంటుంది. ccam వాటిని చూపిస్తుంది, ఒక ఖాతా పరిమితి అయిపోయినప్పుడు మీకు చెందిన మరో ఖాతాలో కొనసాగనిస్తుంది.

## ఒకే కంప్యూటర్‌లో రెండు Claude Code ఖాతాలను ఎలా ఉపయోగించాలి?

`CLAUDE_CONFIG_DIR` తో ప్రతి ఖాతాకు దాని సొంత కాన్ఫిగరేషన్ ఫోల్డర్ ఇవ్వండి. ccam ఇది మీ కోసం చేస్తుంది: ప్రతి ఖాతాకు `ccam add` రన్ చేయండి, తర్వాత వాటిని `ccam personal`, `ccam work` తో, లేదా `ccwork` వంటి మీరే పేరు పెట్టిన షార్ట్‌కట్‌లతో ప్రారంభించండి. దీన్ని చేతితో ఎలా చేయాలో కూడా [గైడ్](/guides/multiple-claude-code-accounts) చూపిస్తుంది.

## మరో ఖాతాలో సంభాషణను ఎలా కొనసాగించాలి?

ఆ ఫోల్డర్‌లో `ccam next --continue` రన్ చేయండి: అది ఫోల్డర్ యొక్క చివరి సంభాషణను తర్వాతి ఖాతాకు తీసుకువెళ్తుంది (ఎక్కువ అవకాశం ఉన్న ఖాతా కోసం `--auto`). Claude Code లోపల, [ccam ప్లగిన్](/docs/install#claude-code-plugin) నుంచి వచ్చే `/ccam:switch` మీరు ఉన్న సెషన్ కోసం అదే పని చేస్తుంది. రెండు ఖాతాలు సంభాషణ చరిత్రను షేర్ చేసుకుంటే (`ccam group set default --add history`, లేదా వాటికే ప్రత్యేకమైన గ్రూప్‌తో: `ccam group add pair --items history --members work,side`), కొత్త ఖాతా అదే సంభాషణను తెరుస్తుంది; లేకపోతే Claude Code దాన్ని కొత్త ఖాతా చరిత్రలోకి కాపీ చేస్తుంది.

## ccam నా లాగిన్‌ను చూస్తుందా లేదా పంపుతుందా?

ccam మీ Claude లాగిన్‌ను ఖాతాల మధ్య ఎప్పుడూ షేర్ చేయదు, కాపీ చేయదు, MCP సర్వర్ల సైన్-ఇన్‌లను కూడా ఎప్పుడూ కాపీ చేయదు. మీరు `ccam usage`, `ccam next --auto` లేదా `ccam doctor` రన్ చేసినప్పుడు, ఆ ఖాతా వినియోగం కోసం Anthropic యొక్క వినియోగ ఎండ్‌పాయింట్‌ను అడగడానికి మాత్రమే అది ఖాతా యాక్సెస్ టోకెన్‌ను చదువుతుంది, గడువు ముగిసిన టోకెన్‌ను `ccam usage --refresh` తో మాత్రమే రెన్యూ చేస్తుంది; `usage_source = "claude"` తో అది టోకెన్‌ను అసలు చదవదు. `ccam ext`, `ccam doctor` ఒక ఖాతా MCP సైన్-ఇన్‌ల పేర్లను చదువుతాయి, వాటి టోకెన్‌లను ఎప్పుడూ చదవవు. ccam లో టెలిమెట్రీ లేదు. ఈ లుకప్‌లు కాకుండా, అది తనంతట తానుగా చేసే ఏకైక అభ్యర్థన తాజా ccam రిలీజ్ గురించి డాష్‌బోర్డ్ GitHub ను అడిగే ప్రశ్న మాత్రమే, అందులో మీ గురించి గానీ మీ ఖాతాల గురించి గానీ ఏమీ ఉండదు.

## రిమోట్ సర్వర్‌లో ఎలా సైన్ ఇన్ చేయాలి?

SSH సెషన్‌లో ఎప్పటిలాగే `ccam add` లేదా `ccam login <name>` రన్ చేయండి. Claude Code సర్వర్‌లో సైన్-ఇన్ కోసం ఎదురుచూస్తుంది, కాబట్టి మీ కంప్యూటర్‌లోని బ్రౌజర్ లోడ్ కాని `http://localhost:<port>/callback?code=…` పేజీ వద్ద ఆగిపోతుంది. ఆ అడ్రస్‌ను బ్రౌజర్ నుంచి కాపీ చేసి టెర్మినల్‌లో పేస్ట్ చేయండి: ccam దాన్ని సర్వర్‌లోని Claude Code కు అందిస్తుంది, అది సైన్-ఇన్‌ను పూర్తి చేస్తుంది. ఆ అడ్రస్‌లో ఒక్కసారి మాత్రమే పనిచేసే కోడ్ ఉంటుంది, కాబట్టి దాన్ని ఎవరితోనూ షేర్ చేయకండి.

## నా ఖాతాలు ఎక్కడ నిల్వ అవుతాయి?

`~/.local/share/ccam/profiles/<name>/` లో, ఒక్కో ఖాతాకు ఒక ఫోల్డర్. macOS లో, Claude Code లాగిన్‌ను Keychain లో, ఆ ఫోల్డర్ నుంచి తీసుకున్న పేరుతో ఉంచుతుంది, కాబట్టి `ccam rename` అక్కడ ఫోల్డర్ పాత పేరును అలాగే ఉంచుతుంది.

## నా ప్రస్తుత ~/.claude కు ఏమవుతుంది?

మీరు `ccam import` లేదా `ccam migrate` రన్ చేయకపోతే ఏమీ కాదు. ఇంపోర్ట్ ఫోల్డర్‌ను అది ఉన్న చోటే నమోదు చేస్తుంది, కాబట్టి సాధారణ `claude`, `ccam <name>` రెండూ అదే ఖాతాను, సెట్టింగ్‌లను ఉపయోగిస్తూనే ఉంటాయి. `ccam migrate` దాని సెట్టింగ్‌లు, `CLAUDE.md`, ఎక్స్‌టెన్షన్లు, MCP సర్వర్లను షేర్డ్ సెట్టింగ్‌లలోకి కాపీ చేస్తుంది, ఆ ఫోల్డర్‌ను చదువుతుంది మాత్రమే.

## ccam ఏ సిస్టమ్‌లకు మద్దతు ఇస్తుంది?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine, ఇతరాలు), macOS, Windows 10, 11, నేరుగా లేదా WSL లోపల. Windows లో `settings.json` వంటి ఫైల్‌లను షేర్ చేయడానికి Developer Mode అవసరం; షేర్డ్ ఫోల్డర్‌లు అది లేకుండానే పనిచేస్తాయి, అది లేనప్పుడు మొదటి `ccam add` MCP సర్వర్లు, ఎక్స్‌టెన్షన్లతో మాత్రమే `default` గ్రూప్‌ను సృష్టిస్తుంది ([Windows లో షేరింగ్](/features/share#on-windows)).

## ఒక MCP సర్వర్ ఒకే ఖాతాలో ఎందుకు కనిపిస్తుంది?

సెషన్ లోపల `claude mcp add` తో జోడించిన సర్వర్లు ఆ ఖాతాకు మాత్రమే నిల్వ అవుతాయి, `-s user` లేకుండా అయితే ప్రస్తుత ఫోల్డర్‌కు మాత్రమే. తర్వాతిసారి మీరు ఆ ఖాతాను ప్రారంభించినప్పుడు ccam మీకు చెబుతుంది, `ccam mcp list`, `ccam ext` వాటిని చూపిస్తాయి; `ccam mcp import <account> <server>` తో సర్వర్‌ను షేర్డ్ గ్రూప్‌కు తరలించండి.

## ccam వల్ల Claude Code నెమ్మదిస్తుందా?

ccam ద్వారా Claude Code ను ప్రారంభిస్తే సుమారు 4 మిల్లీసెకన్లు పెరుగుతాయి, ఇది ఒక ల్యాప్‌టాప్‌పై `scripts/perf-check.sh` తో కొలిచినది. ccam ఒక చిన్న ఫైల్‌ను చదివి, షేర్డ్ లింక్‌లను తనిఖీ చేసి, తర్వాత తన స్థానంలో `claude` ను పెడుతుంది, కాబట్టి మీరు పనిచేస్తున్నప్పుడు అది రన్ అవ్వదు. Windows ఒక ప్రాసెస్‌ను మార్చలేదు, కాబట్టి అక్కడ ccam Claude Code ను ప్రారంభించి దాని కోసం వేచి ఉంటుంది, ఇంకేమీ చేయదు.

## ccam ను ఎలా అప్‌డేట్ చేయాలి?

`ccam update` రన్ చేయండి. ఇది తాజా రిలీజ్‌ను డౌన్‌లోడ్ చేసి, దాని చెక్‌సమ్‌ను తనిఖీ చేసి, `ccam` ఫైల్‌ను మారుస్తుంది; `ccam update --check` కొత్త రిలీజ్ ఉందో లేదో మాత్రమే చెబుతుంది. కొత్త రిలీజ్ ఉన్నప్పుడు డాష్‌బోర్డ్ కూడా చెబుతుంది, `U` అడిగిన తర్వాత దాన్ని ఇన్‌స్టాల్ చేస్తుంది; ccam తనంతట తానుగా ఎప్పుడూ అప్‌డేట్ అవ్వదు. మీరు `.deb` ప్యాకేజీని ఇన్‌స్టాల్ చేసి ఉంటే, దానికి బదులుగా కొత్త `.deb` ను apt తో ఇన్‌స్టాల్ చేయండి. వివరాల కోసం [అప్‌డేట్ చేయడం](/docs/install#update) చూడండి.

## ccam ను ఎలా అన్‌ఇన్‌స్టాల్ చేయాలి?

ప్రతి ఖాతా షార్ట్‌కట్‌ను `ccam shortcut <account> --remove` తో తీసివేయండి. మీరు `~/.claude` ను ఇంపోర్ట్ చేసి, అది ఒక గ్రూప్‌లో ఉంటే, ముందుగా దాని కోసం `ccam remove <name>` రన్ చేయండి, అప్పుడు అది షేర్ చేసే వాటి కాపీ దానికి తిరిగి అందుతుంది. తర్వాత `~/.local/bin` నుంచి `ccam` ను తొలగించండి, ఖాతాలు ఇక అవసరం లేకపోతే `~/.config/ccam`, `~/.local/share/ccam`, `~/.local/state/ccam` ను కూడా తొలగించండి. [ఇన్‌స్టాల్](/docs/install#uninstall) చూడండి.
