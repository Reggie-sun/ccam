## ccam అనేది Anthropic యొక్క అధికారిక టూలా?

కాదు. ccam ఒక అనధికారిక ఓపెన్-సోర్స్ ప్రాజెక్ట్. దీనికి Anthropic తో ఎలాంటి సంబంధం లేదు, Anthropic దీన్ని ఆమోదించలేదు. అనేక ఖాతాలను పక్కపక్కనే రన్ చేయడానికి Claude Code డాక్యుమెంట్ చేసిన `CLAUDE_CONFIG_DIR` సెట్టింగ్‌ను ఇది ఉపయోగిస్తుంది.

## నేను అనేక Claude Code ఖాతాలను ఉపయోగించవచ్చా?

అది ప్రతి ఖాతా నిబంధనలపై, work ఖాతాల విషయంలో మీ సంస్థ విధానంపై ఆధారపడి ఉంటుంది. అనేక ఖాతాలను ఉపయోగించే ముందు వాటిని తనిఖీ చేయండి. మీకు ఇప్పటికే ఉన్న ఖాతాల మధ్య మారడాన్ని మాత్రమే ccam సులభం చేస్తుంది.

## ccam వినియోగ పరిమితులను దాటవేస్తుందా?

లేదు. ప్రతి ఖాతా తన సొంత పరిమితులను కలిగి ఉంటుంది. ccam వాటిని చూపిస్తుంది, ఒక ఖాతా పరిమితి అయిపోయినప్పుడు మీకు చెందిన మరో ఖాతాలో కొనసాగనిస్తుంది.

## ఒకే కంప్యూటర్‌లో రెండు Claude Code ఖాతాలను ఎలా ఉపయోగించాలి?

`CLAUDE_CONFIG_DIR` తో ప్రతి ఖాతాకు దాని సొంత కాన్ఫిగరేషన్ ఫోల్డర్ ఇవ్వండి. ccam ఇది మీ కోసం చేస్తుంది: ప్రతి ఖాతాకు `ccam add` రన్ చేయండి, తర్వాత వాటిని `ccam personal`, `ccam work` తో, లేదా `ccwork` వంటి మీరే పేరు పెట్టిన షార్ట్‌కట్‌లతో ప్రారంభించండి. దీన్ని చేతితో ఎలా చేయాలో కూడా [గైడ్](/guides/multiple-claude-code-accounts) చూపిస్తుంది.

## మరో ఖాతాలో సంభాషణను ఎలా కొనసాగించాలి?

`ccam share <name> --history on` తో రెండు ఖాతాల మధ్య సంభాషణ చరిత్రను షేర్ చేయండి, తర్వాత `ccam next --continue` రన్ చేయండి. Claude Code ప్రస్తుత ఫోల్డర్ యొక్క అత్యంత ఇటీవలి సంభాషణను తర్వాతి ఖాతాలో తెరుస్తుంది.

## ccam నా లాగిన్‌ను చూస్తుందా లేదా పంపుతుందా?

ccam ఎప్పుడూ లాగిన్‌ను కాపీ చేయదు, షేర్ చేయదు. మీరు `ccam usage`, `ccam next --auto` లేదా `ccam doctor` రన్ చేసినప్పుడు, ఆ ఖాతా వినియోగం కోసం Anthropic యొక్క వినియోగ ఎండ్‌పాయింట్‌ను అడగడానికి మాత్రమే అది ఖాతా యాక్సెస్ టోకెన్‌ను చదువుతుంది. ccam లో టెలిమెట్రీ లేదు, అది వేరే ఎక్కడికీ ఏమీ పంపదు.

## నా ఖాతాలు ఎక్కడ నిల్వ అవుతాయి?

`~/.local/share/ccam/profiles/<name>/` లో, ఒక్కో ఖాతాకు ఒక ఫోల్డర్. macOS లో, Claude Code లాగిన్‌ను Keychain లో, ఆ ఫోల్డర్ నుంచి తీసుకున్న పేరుతో ఉంచుతుంది.

## నా ప్రస్తుత ~/.claude కు ఏమవుతుంది?

మీరు `ccam import` లేదా `ccam migrate` రన్ చేయకపోతే ఏమీ కాదు. ఇంపోర్ట్ ఫోల్డర్‌ను అది ఉన్న చోటే నమోదు చేస్తుంది, కాబట్టి సాధారణ `claude`, `ccam <name>` రెండూ అదే ఖాతాను, సెట్టింగ్‌లను ఉపయోగిస్తూనే ఉంటాయి. `ccam migrate` దాని సెట్టింగ్‌లు, `CLAUDE.md`, ఎక్స్‌టెన్షన్లు, MCP సర్వర్లను షేర్డ్ సెట్టింగ్‌లలోకి కాపీ చేస్తుంది, ఆ ఫోల్డర్‌ను చదువుతుంది మాత్రమే.

## ccam ఏ సిస్టమ్‌లకు మద్దతు ఇస్తుంది?

Linux (Ubuntu, Debian, Fedora, Arch, Alpine, ఇతరాలు), macOS. Windows లో, దాన్ని WSL లోపల ఉపయోగించండి.

## ఒక MCP సర్వర్ ఒకే ఖాతాలో ఎందుకు కనిపిస్తుంది?

సెషన్ లోపల `claude mcp add` తో జోడించిన సర్వర్లు ఆ ఖాతాకు మాత్రమే నిల్వ అవుతాయి. తర్వాతిసారి మీరు ఆ ఖాతాను ప్రారంభించినప్పుడు ccam మీకు చెబుతుంది; `ccam mcp import <account> <server>` తో సర్వర్‌ను షేర్డ్ గ్రూప్‌కు తరలించండి.

## ccam వల్ల Claude Code నెమ్మదిస్తుందా?

ccam ద్వారా Claude Code ను ప్రారంభిస్తే సుమారు 4 మిల్లీసెకన్లు పెరుగుతాయి, ఇది ఒక ల్యాప్‌టాప్‌పై `scripts/perf-check.sh` తో కొలిచినది. ccam ఒక చిన్న ఫైల్‌ను చదివి, షేర్డ్ లింక్‌లను తనిఖీ చేసి, తర్వాత తన స్థానంలో `claude` ను పెడుతుంది, కాబట్టి మీరు పనిచేస్తున్నప్పుడు అది రన్ అవ్వదు.

## ccam ను ఎలా అన్‌ఇన్‌స్టాల్ చేయాలి?

ప్రతి ఖాతా షార్ట్‌కట్‌ను `ccam shortcut <account> --remove` తో తీసివేసి, `~/.local/bin` నుంచి `ccam` ను తొలగించండి. ఖాతాలు ఇక అవసరం లేకపోతే, తర్వాత `~/.config/ccam`, `~/.local/share/ccam`, `~/.local/state/ccam` ను కూడా తొలగించండి. [ఇన్‌స్టాల్](/docs/install#uninstall) చూడండి.
