ప్రతి ఖాతా 5 గంటల, వారపు పరిమితులలో ఎంత ఉపయోగించిందో `ccam usage` చూపిస్తుంది. `ccam next --auto` ఎక్కువ అవకాశం మిగిలి ఉన్న ఖాతాను తెరుస్తుంది, `--continue` ప్రస్తుత సంభాషణను దానికి తీసుకువెళ్తుంది.

```console
$ ccam usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccam next --auto 로 바로 열기)
```

కాలమ్‌లు ఇవి: ఖాతా, 5 గంటల వినియోగం, అది రీసెట్ అయ్యే వరకు సమయం, వారపు వినియోగం, అది రీసెట్ అయ్యే వరకు సమయం, సంఖ్యలు ఎంత పాతవి.

## సంఖ్యలు ఎక్కడి నుంచి వస్తాయి

ccam ప్రతి ఖాతా సొంత లాగిన్‌ను ఉపయోగించి, అన్ని ఖాతాల కోసం ఒకేసారి Anthropic యొక్క వినియోగ ఎండ్‌పాయింట్‌ను అడుగుతుంది. ఒక్కో ఖాతాకు గరిష్ఠంగా 3 సెకన్లు వేచి ఉంటుంది, ప్రతి ఖాతా సమాధానం ఇచ్చిన వెంటనే దాన్ని చూపిస్తుంది.

ఈ ఎండ్‌పాయింట్ బహిరంగంగా డాక్యుమెంట్ చేయబడలేదు, మారవచ్చు. ఒక అభ్యర్థన విఫలమైతే, ccam చివరిగా తెలిసిన సంఖ్యలను చూపించి వాటిని కాష్ చేసినవిగా గుర్తిస్తుంది. రెస్పాన్స్ ఫార్మాట్ మారితే `ccam doctor` మీకు చెబుతుంది.

60 సెకన్ల కంటే తక్కువ క్రితం తెచ్చిన సంఖ్యలు మళ్లీ ఉపయోగించబడతాయి. ఆప్షన్లు:

| ఆప్షన్ | ప్రభావం |
| --- | --- |
| `--watch [seconds]` | నిరంతరం రిఫ్రెష్ చేస్తుంది, డిఫాల్ట్‌గా ప్రతి 60 సెకన్లకు |
| `--json` | మెషీన్ చదవగలిగే అవుట్‌పుట్ |
| `-v` | మోడల్‌కు ప్రత్యేకమైన వారపు పరిమితులను, ప్రతి సంఖ్య ఎక్కడి నుంచి వచ్చిందో కూడా చూపిస్తుంది |
| `--no-cache` | ఎప్పుడూ మళ్లీ అడుగుతుంది |
| `--source cache` | ఎప్పుడూ అడగదు; సేవ్ చేసిన సంఖ్యలను మాత్రమే చూపిస్తుంది |

## గడువు ముగిసిన లాగిన్‌లు

ఒక ఖాతా యాక్సెస్ టోకెన్ గడువు ముగిసినప్పుడు, ccam దాన్ని పునరుద్ధరించదు. ఎందుకంటే అదే లాగిన్‌ను ఒక Claude Code సెషన్ ఉపయోగిస్తున్నప్పుడు దాన్ని పునరుద్ధరిస్తే, ఆ సెషన్ సైన్ అవుట్ కావచ్చు. ఆ ఖాతాను `ccam <name>` తో ఒక్కసారి ప్రారంభించండి, Claude Code దాన్ని పునరుద్ధరిస్తుంది.

`ccam usage --refresh` గడువు ముగిసిన టోకెన్‌లను తానే పునరుద్ధరిస్తుంది, కానీ రన్ అవ్వని ఖాతాలకు మాత్రమే. macOS Keychain లో లేదా ఇంపోర్ట్ చేసిన `~/.claude` లో నిల్వ ఉన్న లాగిన్‌లను అది ఎప్పుడూ పునరుద్ధరించదు.

## స్టేటస్ లైన్‌లో వినియోగం

```sh
ccam statusline install
```

అప్పుడు Claude Code స్టేటస్ లైన్‌లో ఖాతా పేరును, దాని వినియోగాన్ని చూపిస్తుంది, ఉదాహరణకు `[work] · Opus · 5h 24% · 7d 41%`. మీకు ఇప్పటికే స్టేటస్ లైన్ కమాండ్ ఉంటే, ccam దాన్ని ఉంచి ముందు ఖాతా పేరును పెడుతుంది. స్టేటస్ లైన్ తన సంఖ్యలను కూడా సేవ్ చేస్తుంది, ఎండ్‌పాయింట్ సమాధానం ఇవ్వనప్పుడు `ccam usage` వాటిని ఉపయోగిస్తుంది.

## ఖాతా మార్చడం

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # the next account that shares your conversation history
```

`ccam next` లాగిన్ కాని ఖాతాలను వదిలేస్తుంది, `--auto` 100% వద్ద ఉన్న ఖాతాలను వదిలేస్తుంది. ఒక సంభాషణను కొనసాగించాలంటే, రెండు ఖాతాలూ సంభాషణ చరిత్రను షేర్ చేయాలి; [షేరింగ్](/docs/sharing) చూడండి.

[వినియోగ పరిమితి వర్క్‌ఫ్లో గైడ్](/guides/usage-limit-workflow) పూర్తి ఉదాహరణను దశలవారీగా చూపిస్తుంది.
