`ccam usage` ప్రతి ఖాతాకు, ప్రతి పరిమితిలో ఎంత ఉపయోగించబడిందో చూపిస్తుంది: 5 గంటల పరిమితి, వారపు పరిమితి, ప్రతి మోడల్ సొంత వారపు పరిమితి (Fable వంటిది). `ccam next --auto` ఎక్కువ అవకాశం మిగిలి ఉన్న ఖాతాను తెరుస్తుంది, `--continue` ప్రస్తుత సంభాషణను దానికి తీసుకువెళ్తుంది.

```console
$ ccam usage

   Weekly   ████████░░░░░░░░░░░░  41%  resets in 3d 6h
   Fable    ██████████████████░░  88%  resets in 1d 6h
 2 work      just now
   5-hour   ██░░░░░░░░░░░░░░░░░░   8%  resets in 4h 12m
   Weekly   ████░░░░░░░░░░░░░░░░  19%  resets in 5d 2h
   Fable    █░░░░░░░░░░░░░░░░░░░   3%  resets in 5d 2h

   5-hour   ████████████████████ 100%  resets in 22m
   Weekly   ██████████████░░░░░░  68%  resets in 1d 9h
```

ప్రతి ఖాతాకు దాని సంఖ్యలు ఎంత పాతవో చెప్పే ఒక లైన్ ఉంటుంది, తర్వాత ప్రతి పరిమితికి రీసెట్ అయ్యే వరకు సమయంతో ఒక బార్: 5 గంటల విండో, అన్ని మోడళ్ల వారపు విండో, Fable వంటి ప్రతి మోడల్ సొంత వారపు విండో. బార్ 80% వద్ద పసుపు రంగులోకి, 100% వద్ద ఎరుపు రంగులోకి మారుతుంది. చివరి లైన్ `ccam next --auto` తెరిచే ఖాతా పేరును చెబుతుంది; `auto_strategy = "expiring"` లేదా `"balance"` తో అది బదులుగా `→ next --auto picks <name>: <reason>` అని చూపిస్తుంది.

**Team, Enterprise సీట్లు.** ఆటోమేటిక్ ఖాతా ఎంపిక (`ccam next`, `--fallback`, `ccam pick`, డాష్‌బోర్డ్‌లోని `n`, మీరు ఆన్ చేసిన తర్వాత [`auto_switch`](/features/next#auto-switch)) ఒకే Claude Team లేదా Enterprise సంస్థలోని సీట్ల మధ్య కూడా మారుస్తుంది, ఇది Anthropic నిబంధనల ఉల్లంఘన కావచ్చు. దానిపై ఆధారపడే ముందు [తరచుగా అడిగే ప్రశ్నలు](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) చదివి, మీ సంస్థను, Anthropic ను సంప్రదించి నిర్ధారించుకోండి.

## సంఖ్యలు ఎక్కడి నుంచి వస్తాయి

ccam ప్రతి ఖాతా సొంత లాగిన్‌ను ఉపయోగించి, అన్ని ఖాతాల కోసం ఒకేసారి Anthropic యొక్క వినియోగ ఎండ్‌పాయింట్‌ను అడుగుతుంది. ఒక్కో ఖాతాకు గరిష్ఠంగా 3 సెకన్లు వేచి ఉంటుంది, ప్రతి ఖాతా సమాధానం ఇచ్చిన వెంటనే దాన్ని చూపిస్తుంది.

ఈ ఎండ్‌పాయింట్ బహిరంగంగా డాక్యుమెంట్ చేయబడలేదు, మారవచ్చు. ఒక అభ్యర్థన విఫలమైతే, ccam చివరిగా తెలిసిన సంఖ్యలను చూపించి వాటిని కాష్ చేసినవిగా గుర్తిస్తుంది. ఆ సంఖ్యలు సేవ్ అయినప్పటి నుంచి రీసెట్ అయిన విండో 0% చూపిస్తుంది. రెస్పాన్స్ ఫార్మాట్ మారితే `ccam doctor` మీకు చెబుతుంది.

Claude Code ఒక సెషన్‌ను వినియోగ పరిమితి వద్ద ఆపినప్పుడు, ఏ విండో నిండిందో, అది ఎప్పుడు రీసెట్ అవుతుందో [ccam ప్లగిన్](/docs/install#claude-code-plugin) నమోదు చేస్తుంది. అప్పటి వరకు, మిగతా సంఖ్యలు ఏమి చెప్పినా ఆ విండో 100% చూపిస్తుంది, కాబట్టి `ccam next --auto`, `--fallback` ఆ ఖాతాను మరీ ముందుగా మళ్లీ ఎంచుకోవు.

60 సెకన్ల కంటే తక్కువ క్రితం తెచ్చిన సంఖ్యలు మళ్లీ ఉపయోగించబడతాయి. ఆప్షన్లు:

| ఆప్షన్ | ప్రభావం |
| --- | --- |
| `--watch[=seconds]` | నిరంతరం రిఫ్రెష్ చేస్తుంది, డిఫాల్ట్‌గా ప్రతి 60 సెకన్లకు |
| `--json` | మెషీన్ చదవగలిగే అవుట్‌పుట్ |
| `-v` | ప్రతి ఖాతా సంఖ్యలు ఎక్కడి నుంచి వచ్చాయో కూడా చూపిస్తుంది |
| `--no-cache` | ఎప్పుడూ మళ్లీ అడుగుతుంది |
| `--source cache` | ఎప్పుడూ అడగదు; సేవ్ చేసిన సంఖ్యలను మాత్రమే చూపిస్తుంది |

## గడువు ముగిసిన లాగిన్‌లు

ఒక ఖాతా యాక్సెస్ టోకెన్ గడువు ముగిసినప్పుడు, ccam దాన్ని పునరుద్ధరించదు. ఎందుకంటే అదే లాగిన్‌ను ఒక Claude Code సెషన్ ఉపయోగిస్తున్నప్పుడు దాన్ని పునరుద్ధరిస్తే, ఆ సెషన్ సైన్ అవుట్ కావచ్చు. ఆ ఖాతా ``access token expired; `ccam <name>` renews it when it starts`` అని చూపిస్తుంది: దాన్ని `ccam <name>` తో ఒక్కసారి ప్రారంభించండి, Claude Code దాన్ని పునరుద్ధరిస్తుంది. పూర్తిగా గడువు ముగిసిన లాగిన్, లేదా Claude Code క్లియర్ చేసిన లాగిన్, `` login expired → `ccam login <name>` `` అని చూపిస్తుంది, దానికి కొత్త లాగిన్ అవసరం.

`ccam usage --refresh` గడువు ముగిసిన టోకెన్‌లను తానే పునరుద్ధరిస్తుంది, కానీ రన్ అవుతున్న Claude Code సెషన్ లేని ఖాతాలకు మాత్రమే, ఆ సెషన్ ఎలా ప్రారంభించబడినా సరే. macOS Keychain లో లేదా ఇంపోర్ట్ చేసిన `~/.claude` లో నిల్వ ఉన్న లాగిన్‌లను అది ఎప్పుడూ పునరుద్ధరించదు, ఒక పునరుద్ధరణకు 30 సెకన్ల వరకు పట్టవచ్చు.

## స్టేటస్ లైన్‌లో వినియోగం

```sh
ccam statusline install
```

అప్పుడు Claude Code స్టేటస్ లైన్‌లో ఖాతా పేరును, దాని వినియోగాన్ని చూపిస్తుంది, ఉదాహరణకు `[work] · Opus · 5h 24% · 7d 41%`. 90% నుంచి, ఆ లైన్ `ccam next --auto --continue` ను కూడా సూచిస్తుంది. మీకు ఇప్పటికే స్టేటస్ లైన్ కమాండ్ ఉంటే, ccam దాన్ని ఉంచి ముందు ఖాతా పేరును పెడుతుంది. స్టేటస్ లైన్ తన సంఖ్యలను కూడా సేవ్ చేస్తుంది, ఎండ్‌పాయింట్ సమాధానం ఇవ్వనప్పుడు `ccam usage` వాటిని ఉపయోగిస్తుంది.

## ఖాతా మార్చడం

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # continue this folder's conversation on the next account
```

`ccam next` లాగిన్ కాని ఖాతాలను వదిలేస్తుంది, `--auto` 100% వద్ద ఉన్న ఖాతాలను (Claude Code నిండిందని నివేదించిన విండో ఉన్నవాటితో సహా, అది రీసెట్ అయ్యే వరకు), మరో సంస్థకు చెందిన ఖాతాలను వదిలేస్తుంది. రెండు ఖాతాలూ సంభాషణ చరిత్రను షేర్ చేస్తే, `--continue` అదే సంభాషణను తెరుస్తుంది; లేకపోతే Claude Code దాన్ని కొత్త ఖాతాలోకి కాపీ చేస్తుంది. [షేరింగ్](/docs/sharing), [తర్వాతి ఖాతాకు మారడం](/features/next#continue) చూడండి.

`config.toml` పైభాగంలో `auto_switch = true` తో (Linux, macOS; డిఫాల్ట్‌గా ఆఫ్), Claude Code ఒక ఇంటరాక్టివ్ సెషన్‌ను దాని పరిమితి వద్ద ఆపినప్పుడు, అదే రకమైన మరో ఖాతాలో (అదే సంస్థలోని సీటు, లేదా మరో వ్యక్తిగత ప్లాన్) అవకాశం ఉంటే, ccam ఈ మార్పును తానే చేస్తుంది. అది ఎప్పుడు పని చేస్తుందో, ఏం ఎప్పుడూ చేయదో తెలుసుకోవడానికి [`auto_switch`](/features/next#auto-switch) చూడండి.

`claude -p` రన్ చేసే స్క్రిప్ట్‌లు, షెడ్యూల్ చేసిన jobs కోసం, ఖాతా పేరుకు ముందు `--fallback` పెట్టండి. ఆ ఖాతా తన పరిమితిని చేరినప్పుడు, ccam అదే కమాండ్‌ను ఎక్కువ అవకాశం ఉన్న ఖాతాగా మళ్లీ రన్ చేస్తుంది, పూర్తయిన రన్ output మాత్రమే ప్రింట్ అవుతుంది:

```sh
ccam --fallback work -p "review the diff" --output-format json
```

ccam ఎలా నిర్ణయిస్తుందో తెలుసుకోవడానికి [పరిమితి వద్ద మళ్లీ రన్ చేయడం](/features/next#run-again-at-the-limit) చూడండి.

[వినియోగ పరిమితి వర్క్‌ఫ్లో గైడ్](/guides/usage-limit-workflow) పూర్తి ఉదాహరణను దశలవారీగా చూపిస్తుంది.
