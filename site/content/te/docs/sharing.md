ప్రతి ఖాతా తన సొంత లాగిన్‌ను ఉంచుకుంటుంది. మిగతా అన్నింటినీ అంశం వారీగా షేర్ చేయవచ్చు: ccam ఖాతా ఫైల్‌ను లేదా ఫోల్డర్‌ను ఒక షేర్డ్ గ్రూప్ ఫోల్డర్‌కు లింక్ చేస్తుంది, కాబట్టి ఒక ఖాతాలో చేసిన మార్పు ఆ గ్రూప్‌లోని అన్ని ఖాతాలలో కనిపిస్తుంది.

## ఏవి షేర్ చేయవచ్చు

| అంశం | ఆప్షన్ | ఏమి షేర్ అవుతుంది |
| --- | --- | --- |
| MCP సర్వర్లు | `--mcp` | గ్రూప్ యొక్క `mcp.json`, ప్రారంభంలో Claude Code కు పంపబడుతుంది |
| సెట్టింగ్‌లు | `--settings` | `settings.json`: అనుమతులు, హుక్స్, మోడల్, స్టేటస్ లైన్ |
| గ్లోబల్ మెమరీ | `--memory` | `CLAUDE.md` |
| ఎక్స్‌టెన్షన్లు | `--extensions` | `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/` |
| సంభాషణ చరిత్ర | `--history` | `projects/`, `history.jsonl` |

కొత్త ఖాతాలు సంభాషణ చరిత్ర తప్ప మిగతా అన్నింటినీ షేర్ చేస్తాయి.

లాగిన్ ఫైళ్లు `.credentials.json`, `.claude.json` ఎప్పుడూ షేర్ కావు. ccam ఒక స్థిరమైన జాబితాలోని పాత్‌లను మాత్రమే లింక్ చేస్తుంది, ఈ రెండూ ఆ జాబితాలో లేవు.

## గ్రూప్‌లు

`on` అంటే `default` గ్రూప్. మీరు ఒక పేరు కూడా ఇవ్వవచ్చు, అప్పుడు కొన్ని ఖాతాలు మాత్రమే ఒక అంశాన్ని షేర్ చేస్తాయి:

```sh
ccam share work --history team
ccam share side --history team
```

ఇప్పుడు `work`, `side` ఒకదానితో ఒకటి సంభాషణలను షేర్ చేస్తాయి, కానీ మీ ఇతర ఖాతాలతో కాదు.

## షేరింగ్ ఆన్ చేయడం

ఒక ఖాతా ఒక అంశాన్ని షేర్ చేయడం మొదలుపెట్టినప్పుడు, ccam:

1. తాను తరలించే, కాపీ చేసే లేదా లింక్ చేసే ప్రతి ఫైల్ యొక్క ప్రణాళికను ప్రింట్ చేసి, మొదలుపెట్టే ముందు అడుగుతుంది;
2. గ్రూప్ ఇంకా ఖాళీగా ఉంటే ఖాతా ఫైళ్లను గ్రూప్ ఫోల్డర్‌కు తరలిస్తుంది, లేదా గ్రూప్‌లో ఇంకా లేని ఫైళ్లను జోడిస్తుంది;
3. ఒకే ఫైల్ వేరుగా ఉన్నప్పుడు, గ్రూప్ వెర్షన్‌ను ఉంచాలా, మీ వెర్షన్‌ను ఉపయోగించాలా, లేదా JSON ను మెర్జ్ చేయాలా అని అడుగుతుంది;
4. మీ అసలు ఫైల్‌ను ఖాతా ఫోల్డర్‌లోని `.ccam-backup/<time>/` లో ఉంచుతుంది;
5. అసలు ఫైల్ స్థానంలో గ్రూప్‌కు లింక్‌ను పెడుతుంది.

సంభాషణ ఫైళ్లకు వాటి సెషన్ ID పేరు ఉంటుంది, కాబట్టి అనేక ఖాతాల చరిత్రలు ఘర్షణ లేకుండా కలిసిపోతాయి.

## షేరింగ్ ఆఫ్ చేయడం

```sh
ccam share work --history off
```

లింక్ తీసివేయబడుతుంది, ఖాతాకు గ్రూప్ ప్రస్తుత కంటెంట్ యొక్క సొంత కాపీ లభిస్తుంది. బదులుగా ఖాళీగా మొదలుపెట్టడానికి `--fresh` జోడించండి. ఇతర ఖాతాల కోసం గ్రూప్ తన కంటెంట్‌ను ఉంచుకుంటుంది.

## ఇప్పటికే ఉన్న సెటప్‌ను కాపీ చేయండి

ccam కంటే ముందు మీరు Claude Code ఉపయోగించి ఉంటే, మీ సెట్టింగ్‌లు `~/.claude` లో ఉంటాయి. `ccam migrate` వాటిని ఒక గ్రూప్‌లోకి కాపీ చేస్తుంది, కాబట్టి ఆ అంశాలను షేర్ చేసే ప్రతి ఖాతాకు అవి అందుతాయి:

```sh
ccam migrate
```

ఇది కాపీ చేసేవి:

- `settings.json`, గ్లోబల్ `CLAUDE.md`;
- ఎక్స్‌టెన్షన్లు `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/`;
- మీ యూజర్ MCP సర్వర్లు, అంటే `~/.claude.json` లోని `mcpServers` ఎంట్రీ, గ్రూప్ యొక్క `mcp.json` లోకి;
- సంభాషణ చరిత్ర (`projects/`, `history.jsonl`), కానీ మీరు `--history` జోడించినప్పుడు మాత్రమే.

మూల ఫోల్డర్ చదవబడుతుంది మాత్రమే: అందులోని ఏదీ తరలించబడదు, లింక్ చేయబడదు, మార్చబడదు, సాధారణ `claude` మునుపటిలాగే పనిచేస్తుంది. లాగిన్ ఫైళ్లు `.credentials.json`, `.claude.json` ఎప్పుడూ కాపీ కావు.

ఏదైనా కాపీ చేసే ముందు ccam ప్రణాళికను ప్రింట్ చేసి అడుగుతుంది:

```console
$ ccam migrate
Copy from /home/me/.claude into group default (/home/me/.local/share/ccam/groups/default):
  mcp         ~/.claude.json  new: context7, fs
  settings    settings.json   new: 80 B
  memory      CLAUDE.md       new: 31 B
  extensions  agents/         add 1 file the group lacks (17 B)
              commands/       add 1 file the group lacks (15 B)
              skills/         add 1 file the group lacks (32 B)
              not found, skipped: plugins/, output-styles/, rules/
  Conversation history (projects/, history.jsonl) is not included; add --history to copy it.
Copy these into group default? [y/N] y
✓ Copied into group default: 2 MCP servers, settings.json, CLAUDE.md, agents/, commands/, skills/
Accounts that share these through group default:
  mcp         personal
  settings    personal
  memory      personal
  extensions  personal
```

చివర్లో, గ్రూప్ ద్వారా ప్రతి అంశాన్ని షేర్ చేసే ఖాతాలను ccam జాబితాగా చూపిస్తుంది. కొన్ని ఖాతాలు షేర్ చేయకపోతే, వాటికి షేరింగ్ ఆన్ చేసే `ccam share` కమాండ్‌లను అది ప్రింట్ చేస్తుంది.

గ్రూప్‌లో ఇప్పటికే ఒక ఫైల్ యొక్క వేరే కాపీ ఉంటే, షేరింగ్ ఆన్ చేసేటప్పుడు లాగే ccam అడుగుతుంది: గ్రూప్ కాపీని ఉంచాలా, మీదాన్ని ఉపయోగించాలా. `settings.json`, ఇతర JSON ఫైళ్లను మెర్జ్ కూడా చేయవచ్చు, `history.jsonl` ను లైన్ వారీగా మెర్జ్ చేయవచ్చు. గ్రూప్ యొక్క మునుపటి కాపీలు గ్రూప్ ఫోల్డర్‌లోని `.ccam-backup/<time>/` లో సేవ్ అవుతాయి.

| ఆప్షన్ | ప్రభావం |
| --- | --- |
| `--settings`, `--memory`, `--extensions`, `--mcp`, `--history` | మీరు పేర్కొన్న అంశాలను మాత్రమే కాపీ చేస్తుంది; అవి లేకపోతే, సంభాషణ చరిత్ర తప్ప అన్నీ |
| `-g`, `--group <group>` | `default` కు బదులు ఈ గ్రూప్‌లోకి కాపీ చేస్తుంది |
| `-y`, `--yes` | అడగకుండా కాపీ చేస్తుంది; ఫైల్ వేరుగా ఉన్నప్పుడు, గ్రూప్ కాపీని ఉంచుతుంది |

ఏదీ కాపీ చేయకుండా ప్రణాళికను మాత్రమే చూడటానికి, `ccam --dry-run migrate` లాగా కమాండ్ ముందు `--dry-run` పెట్టండి. మరో ఫోల్డర్ నుంచి కాపీ చేయడానికి, దాని పేరు ఇవ్వండి: `ccam migrate ~/.claude-work --group work`.

## MCP సర్వర్లు

Claude Code MCP సర్వర్లను లాగిన్‌తో పాటు `.claude.json` లో నిల్వ చేస్తుంది, కాబట్టి ఆ ఫైల్‌ను షేర్ చేయలేము. ccam షేర్ చేసిన సర్వర్లను గ్రూప్ యొక్క `mcp.json` లో ఉంచి, Claude Code ను `--mcp-config=<group>/mcp.json` తో ప్రారంభిస్తుంది. మీ సొంత `--mcp-config` ఆప్షన్లు దానిపై అదనంగా వర్తిస్తాయి.

```sh
ccam mcp add fs -- npx -y @modelcontextprotocol/server-filesystem ~/code
ccam mcp list
```

సెషన్ లోపల `claude mcp add` తో మీరు జోడించిన సర్వర్ ఆ ఖాతాకు మాత్రమే సేవ్ అవుతుంది. తర్వాతిసారి మీరు ఆ ఖాతాను ప్రారంభించినప్పుడు, ccam ఆ సర్వర్ పేరును, దాన్ని గ్రూప్‌కు తరలించే కమాండ్‌ను చూపిస్తుంది:

```sh
ccam mcp import work gh
```

OAuth తో సైన్ ఇన్ అయ్యే MCP సర్వర్లు తమ టోకెన్‌లను ఖాతా లాగిన్‌తో పాటు నిల్వ చేస్తాయి, కాబట్టి ప్రతి ఖాతాలో వాటిని ఒక్కసారి అనుమతించండి.

సర్వర్లు `claude mcp list`, `/mcp` లో సాధారణ యూజర్ సర్వర్లుగా కనిపించాలని మీరు కోరుకుంటే, `~/.config/ccam/config.toml` లో `mcp_strategy = "sync"` ను సెట్ చేయండి. అప్పుడు ccam ప్రారంభానికి ముందు, Claude Code సొంత ఫైల్ లాక్ కింద, బ్యాకప్‌తో, వాటిని ప్రతి ఖాతా `.claude.json` లో రాస్తుంది.

## ఒకే ఫోల్డర్‌లో రెండు ఖాతాలు

సంభాషణ చరిత్రను షేర్ చేసే ఖాతాలు ఒకే ఫైళ్లలో రాస్తాయి. అదే గ్రూప్‌లోని మరో ఖాతా ఇప్పటికే రన్ అవుతున్న ఫోల్డర్‌లో మీరు రెండో Claude Code ను ప్రారంభిస్తే, ccam మిమ్మల్ని హెచ్చరించి కొనసాగించాలా అని అడుగుతుంది.

## ఏదైనా పాడైనప్పుడు

```sh
ccam doctor
ccam doctor --fix
```

ఒక షేర్డ్ పాత్ సాధారణ ఫైల్‌గా మారితే, ఉదాహరణకు మీరు బ్యాకప్‌ను చేతితో పునరుద్ధరించిన తర్వాత, ccam Claude Code ను ప్రారంభించే ముందు ఆగి `ccam doctor --fix` ను సూచిస్తుంది. అది ఆ ఫైల్‌ను గ్రూప్‌లో మెర్జ్ చేసి, బ్యాకప్‌ను ఉంచుతుంది.
