ప్రతి ఖాతా తన సొంత లాగిన్‌ను ఉంచుకుంటుంది. మిగతా అన్నింటినీ **గ్రూప్‌ల** ద్వారా షేర్ చేయవచ్చు: ఒక గ్రూప్ తాను షేర్ చేసే అంశాలను, తనలోని ఖాతాలను పేర్కొంటుంది, ccam ఆ ఖాతాల ఫైళ్లను గ్రూప్ ఫోల్డర్‌కు లింక్ చేస్తుంది, కాబట్టి ఒక ఖాతాలో చేసిన మార్పు అన్నింటిలోనూ కనిపిస్తుంది.

## ఏవి షేర్ చేయవచ్చు

| అంశం | ఏమి షేర్ అవుతుంది |
| --- | --- |
| `mcp` | MCP సర్వర్లు: గ్రూప్ యొక్క `mcp.json`, ప్రారంభంలో Claude Code కు పంపబడుతుంది |
| `settings` | `settings.json`: అనుమతులు, హుక్స్, మోడల్, స్టేటస్ లైన్ |
| `memory` | గ్లోబల్ `CLAUDE.md` |
| `extensions` | `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/` |
| `history` | సంభాషణ చరిత్ర: `projects/`, `history.jsonl` |

మీ మొదటి ఖాతా `default` గ్రూప్‌ను సృష్టిస్తుంది, అది సంభాషణ చరిత్ర తప్ప మిగతా అన్నింటినీ షేర్ చేస్తుంది, తర్వాతి ఖాతాలు అందులో చేరతాయి.

లాగిన్ ఫైళ్లు `.credentials.json`, `.claude.json` ఎప్పుడూ షేర్ కావు. ccam ఒక స్థిరమైన జాబితాలోని పాత్‌లను మాత్రమే లింక్ చేస్తుంది, ఈ రెండూ ఆ జాబితాలో లేవు.

ఈ పేజీ రోజువారీ పనులను వివరిస్తుంది. ప్రతి ఆప్షన్ ఫీచర్ పేజీలలో వివరించబడింది: [గ్రూప్‌లతో షేరింగ్](/features/share), [షేర్ చేసిన MCP సర్వర్లు](/features/mcp), [ఉన్న సెటప్‌ను కాపీ చేయడం](/features/migrate).

## గ్రూప్‌లు

```sh
ccam group                                   # the groups, what they share, their accounts
ccam group set default --add history         # every account in default shares history
ccam group add team --items history --members work,side
```

ఒక ఖాతా అనేక గ్రూప్‌లలో ఉండవచ్చు, కానీ ప్రతి అంశం ఒకే గ్రూప్ నుంచి వస్తుంది. కాబట్టి `work`, `side` మధ్య చరిత్రను షేర్ చేసి, మీ ఇతర ఖాతాలతో కాకుండా ఉంచాలంటే, చరిత్రను `default` బయట ఉంచి, పైన చూపినట్లుగా ఆ రెండింటికీ వాటి సొంత గ్రూప్ ఇవ్వండి. ఒక ఖాతా ఏమి షేర్ చేస్తుందో, ఏ గ్రూప్ ద్వారా షేర్ చేస్తుందో `ccam share work` చూపిస్తుంది. [డాష్‌బోర్డ్](/features/dashboard) తన Groups ట్యాబ్‌లో అదే చూపిస్తుంది.

## ఒక ఖాతా షేర్ చేయడం మొదలుపెట్టినప్పుడు

ఒక ఖాతా ఒక అంశాన్ని షేర్ చేయడం మొదలుపెట్టినప్పుడు (అది ఒక గ్రూప్‌లో చేరినప్పుడు, లేదా దాని గ్రూప్ ఆ అంశాన్ని జోడించినప్పుడు), ccam:

1. ప్రతి ఖాతా కోసం తాను తరలించే, కాపీ చేసే లేదా లింక్ చేసే ప్రతి ఫైల్ యొక్క ప్రణాళికను ప్రింట్ చేసి, మొదలుపెట్టే ముందు అడుగుతుంది;
2. గ్రూప్ ఇంకా ఖాళీగా ఉంటే ఖాతా ఫైళ్లను గ్రూప్ ఫోల్డర్‌కు తరలిస్తుంది, లేదా గ్రూప్‌లో ఇంకా లేని ఫైళ్లను జోడిస్తుంది;
3. ఒకే ఫైల్ వేరుగా ఉన్నప్పుడు, గ్రూప్ వెర్షన్‌ను ఉంచాలా, మీ వెర్షన్‌ను ఉపయోగించాలా, లేదా JSON ను మెర్జ్ చేయాలా అని అడుగుతుంది;
4. మీ అసలు ఫైల్‌ను ఖాతా ఫోల్డర్‌లోని `.ccam-backup/<time>/` లో ఉంచుతుంది;
5. అసలు ఫైల్ స్థానంలో గ్రూప్‌కు లింక్‌ను పెడుతుంది.

సంభాషణ ఫైళ్లకు వాటి సెషన్ ID పేరు ఉంటుంది, కాబట్టి అనేక ఖాతాల చరిత్రలు ఘర్షణ లేకుండా కలిసిపోతాయి.

Claude Code ఒక ఖాతాగా రన్ అవుతున్నప్పుడు, అది ఎలా ప్రారంభమైనా సరే (బ్యాక్‌గ్రౌండ్ సెషన్‌లతో సహా), ccam ఆ ఖాతాను మార్చదు, ఎందుకంటే సెషన్ తరలిస్తున్న ఫైళ్లలోనే రాస్తూ ఉంటుంది. ముందుగా దాని నుంచి నిష్క్రమించండి. సేవ్ చేయడానికి సరిగ్గా ముందు ccam మళ్లీ తనిఖీ చేస్తుంది, కాబట్టి ccam మీ సమాధానం కోసం వేచి ఉన్నప్పుడు ప్రారంభమైన సెషన్‌ను కూడా అది గుర్తిస్తుంది.

## ఒక ఖాతా షేర్ చేయడం ఆపినప్పుడు

```sh
ccam group leave team work                   # work leaves the group
ccam group set default --remove history      # nobody in default shares history any more
```

లింక్ తీసివేయబడుతుంది, ఖాతాకు గ్రూప్ ప్రస్తుత కంటెంట్ యొక్క సొంత కాపీ లభిస్తుంది; గ్రూప్ MCP సర్వర్లు ఆ ఖాతా సొంత `.claude.json` లోకి, దాని సొంత సర్వర్ల పక్కన చేరతాయి. బదులుగా ఖాళీగా మొదలుపెట్టడానికి `--fresh` జోడించండి; అప్పుడు లోడ్ అవ్వడం ఆగిపోయే MCP సర్వర్లను ప్లాన్ జాబితాగా చూపిస్తుంది. `~/.claude` వంటి ఇంపోర్ట్ చేసిన ఫోల్డర్ ఎప్పుడూ ఒక కాపీని ఉంచుకుంటుంది. ఇతర ఖాతాల కోసం గ్రూప్ తన కంటెంట్‌ను ఉంచుకుంటుంది.

## ఇప్పటికే ఉన్న సెటప్‌ను కాపీ చేయండి

ccam కంటే ముందు మీరు Claude Code ఉపయోగించి ఉంటే, మీ సెట్టింగ్‌లు `~/.claude` లో ఉంటాయి. `ccam migrate` వాటిని ఒక గ్రూప్‌లోకి కాపీ చేస్తుంది, కాబట్టి ఆ అంశాలను షేర్ చేసే ప్రతి ఖాతాకు అవి అందుతాయి:

```sh
ccam migrate
```

టెర్మినల్‌లో, ccam ముందుగా అంశాల చెక్‌లిస్ట్‌ను చూపిస్తుంది. సంభాషణ చరిత్ర తప్ప అన్నీ టిక్ చేసి ఉంటాయి; ఒక అంశాన్ని మార్చడానికి Space, ప్లాన్ చూడటానికి Enter నొక్కండి. ఫోల్డర్‌లో ఏమీ లేని అంశాలకు `not found` అని గుర్తు ఉంటుంది.

ఇది కాపీ చేసేవి:

- `settings.json`, గ్లోబల్ `CLAUDE.md`;
- ఎక్స్‌టెన్షన్లు `agents/`, `commands/`, `skills/`, `plugins/`, `output-styles/`, `rules/`;
- మీ యూజర్ MCP సర్వర్లు, అంటే `~/.claude.json` లోని `mcpServers` ఎంట్రీ, గ్రూప్ యొక్క `mcp.json` లోకి;
- సంభాషణ చరిత్ర (`projects/`, `history.jsonl`), కానీ మీరు `--history` జోడించినప్పుడు మాత్రమే.

మూల ఫోల్డర్ చదవబడుతుంది మాత్రమే: అందులోని ఏదీ తరలించబడదు, లింక్ చేయబడదు, మార్చబడదు, సాధారణ `claude` మునుపటిలాగే పనిచేస్తుంది. లాగిన్ ఫైళ్లు `.credentials.json`, `.claude.json` ఎప్పుడూ గ్రూప్‌లోకి కాపీ కావు.

OAuth తో సైన్ ఇన్ అయ్యే MCP సర్వర్లు తమ టోకెన్‌లను సర్వర్ జాబితాలో కాకుండా లాగిన్‌లో ఉంచుతాయి. ccam ఆ సైన్-ఇన్‌లను కాపీ చేయదు: కాపీ చేసిన సైన్-ఇన్‌లో అదే refresh token ఉంటుంది, మొదటి రెన్యూవల్ ఆ సర్వర్ నుంచి మిగతా ప్రతి హోల్డర్‌ను, `~/.claude` తో సహా, లాగ్ అవుట్ చేస్తుంది. `/mcp` తో ఆ సర్వర్లకు తామే సైన్ ఇన్ చేయాల్సిన ఖాతాలను ప్లాన్, సారాంశం పేర్కొంటాయి.

ఏదైనా కాపీ చేసే ముందు ccam ప్రణాళికను ప్రింట్ చేసి అడుగుతుంది:

```console
$ ccam migrate
Copy from /home/me/.claude into group default (/home/me/.local/share/ccam/groups/default):
  mcp         ~/.claude.json  new: context7, fs
  settings    settings.json   new: 80 B
  memory      CLAUDE.md       new: 31 B
  extensions  agents/         add 1 file the group lacks (17 B)
              commands/       add 1 file the group lacks (15 B)
              skills/         add 1 file the group lacks (32 B)
              not found, skipped: plugins/, output-styles/, rules/
  Conversation history (projects/, history.jsonl) is not included; add --history to copy it.
Copy these into group default? [y/N] y
✓ Copied into group default: 2 MCP servers, settings.json, CLAUDE.md, agents/, commands/, skills/
Group default: personal
To share them:
  ccam group join default work
```

చివర్లో, ccam గ్రూప్ ఖాతాలను జాబితాగా చూపిస్తుంది. గ్రూప్ ఇంకా ఆ అంశాల్లో ఒకదాన్ని షేర్ చేయకపోతే, లేదా కొన్ని ఖాతాలు అందులో లేకపోతే, దాన్ని మార్చే `ccam group` కమాండ్‌లను అది ప్రింట్ చేస్తుంది.

గ్రూప్‌లో ఇప్పటికే ఒక ఫైల్ యొక్క వేరే కాపీ ఉంటే, షేరింగ్ ఆన్ చేసేటప్పుడు లాగే ccam అడుగుతుంది: గ్రూప్ కాపీని ఉంచాలా, మీదాన్ని ఉపయోగించాలా. `settings.json`, ఇతర JSON ఫైళ్లను మెర్జ్ కూడా చేయవచ్చు, `history.jsonl` ను లైన్ వారీగా మెర్జ్ చేయవచ్చు. గ్రూప్ యొక్క మునుపటి కాపీలు గ్రూప్ ఫోల్డర్‌లోని `.ccam-backup/<time>/` లో సేవ్ అవుతాయి.

| ఆప్షన్ | ప్రభావం |
| --- | --- |
| `--settings`, `--memory`, `--extensions`, `--mcp`, `--history` | పేర్కొన్న అంశాలను మాత్రమే, చెక్‌లిస్ట్ లేకుండా కాపీ చేస్తుంది. టెర్మినల్ బయట, అంశాల ఫ్లాగ్‌లు ఏవీ లేకపోతే, ccam సంభాషణ చరిత్ర తప్ప అన్నీ కాపీ చేస్తుంది. |
| `-g`, `--group <group>` | `default` కు బదులు ఈ గ్రూప్‌లోకి కాపీ చేస్తుంది |
| `-y`, `--yes` | అడగకుండా కాపీ చేస్తుంది; ఫైల్ వేరుగా ఉన్నప్పుడు, గ్రూప్ కాపీని ఉంచుతుంది |

ఏదీ కాపీ చేయకుండా ప్రణాళికను మాత్రమే చూడటానికి, `ccam --dry-run migrate` లాగా కమాండ్ ముందు `--dry-run` పెట్టండి. మరో ఫోల్డర్ నుంచి కాపీ చేయడానికి, దాని పేరు ఇవ్వండి: `ccam migrate ~/.claude-work --group work`.

## MCP సర్వర్లు

Claude Code MCP సర్వర్లను లాగిన్‌తో పాటు `.claude.json` లో నిల్వ చేస్తుంది, కాబట్టి ఆ ఫైల్‌ను షేర్ చేయలేము. ccam షేర్ చేసిన సర్వర్లను గ్రూప్ యొక్క `mcp.json` లో ఉంచి, Claude Code ను `--mcp-config=<group>/mcp.json` తో ప్రారంభిస్తుంది. మీ సొంత `--mcp-config` ఆప్షన్లు దానిపై అదనంగా వర్తిస్తాయి.

```sh
ccam mcp add fs -- npx -y @modelcontextprotocol/server-filesystem ~/code
ccam mcp list
```

సెషన్ లోపల `claude mcp add` తో మీరు జోడించిన సర్వర్ ఆ ఖాతాకు మాత్రమే, మీరు ఉన్న ఫోల్డర్ కోసం మాత్రమే సేవ్ అవుతుంది (Claude Code యొక్క local scope; `-s user` దాన్ని ప్రతి ఫోల్డర్‌లోనూ ఆ ఖాతాకు అందుబాటులో ఉంచుతుంది). తర్వాతిసారి మీరు ఆ ఖాతాను ప్రారంభించినప్పుడు, ccam ఆ సర్వర్ పేరును దాని ఫోల్డర్‌తో పాటు, దాన్ని గ్రూప్‌కు తరలించే కమాండ్‌ను చూపిస్తుంది:

```sh
ccam mcp import work gh
```

గ్రూప్‌లో ఇప్పటికే అదే పేరుతో వేరే సర్వర్ ఉంటే, ccam దాన్ని వదిలేసి ఆ విషయం చెబుతుంది. `--force` గ్రూప్ సర్వర్‌ను భర్తీ చేసి, పాత `mcp.json` ను గ్రూప్ యొక్క `.ccam-backup/` ఫోల్డర్‌లో ఉంచుతుంది.

OAuth తో సైన్ ఇన్ అయ్యే MCP సర్వర్లు తమ టోకెన్‌లను ఖాతా లాగిన్‌తో పాటు నిల్వ చేస్తాయి, కాబట్టి ప్రతి ఖాతాలో `/mcp` తో వాటికి ఒక్కసారి సైన్ ఇన్ చేయండి. మరో ఖాతా సైన్ ఇన్ అయి ఉండగా ఒక ఖాతా సైన్ ఇన్ కాని సర్వర్లను `ccam ext`, `ccam doctor` పేర్కొంటాయి.

సర్వర్లు `claude mcp list`, `/mcp` లో సాధారణ యూజర్ సర్వర్లుగా కనిపించాలని మీరు కోరుకుంటే, `~/.config/ccam/config.toml` పైభాగంలో, మొదటి `[[group]]`, `[[profile]]` లేదా `[[folder]]` కంటే పైన, `mcp_strategy = "sync"` ను సెట్ చేయండి. అప్పుడు ccam ప్రారంభానికి ముందు, Claude Code సొంత ఫైల్ లాక్ కింద, బ్యాకప్‌తో, వాటిని ప్రతి ఖాతా `.claude.json` లో రాస్తుంది. ఒక గ్రూప్ సర్వర్ పేరుతోనే ఖాతాకు సొంత సర్వర్ ఉంటే, ccam ఖాతా సర్వర్‌నే ఉంచి, ఆ విషయం చెబుతుంది.

## ఒకే ఫోల్డర్‌లో రెండు ఖాతాలు

సంభాషణ చరిత్రను షేర్ చేసే ఖాతాలు ఒకే ఫైళ్లలో రాస్తాయి. అదే గ్రూప్‌లోని మరో ఖాతా ఇప్పటికే రన్ అవుతున్న ఫోల్డర్‌లో మీరు రెండో Claude Code సెషన్‌ను ప్రారంభిస్తే, ccam మిమ్మల్ని హెచ్చరించి కొనసాగించాలా అని అడుగుతుంది.

## ఏదైనా పాడైనప్పుడు

```sh
ccam doctor
ccam doctor --fix
```

ఒక షేర్డ్ పాత్ సాధారణ ఫైల్‌గా మారితే, ఉదాహరణకు మీరు బ్యాకప్‌ను చేతితో పునరుద్ధరించిన తర్వాత, ccam Claude Code ను ప్రారంభించే ముందు ఆగి `ccam doctor --fix` ను సూచిస్తుంది. ఆ సవరణ పాత్‌ను మళ్లీ గ్రూప్‌కు లింక్ చేస్తుంది: గ్రూప్ దగ్గర కాపీ లేకపోతే ఆ ఫైల్ గ్రూప్ కాపీ అవుతుంది; లేకపోతే గ్రూప్ తన సొంత కాపీని ఉంచుకుంటుంది, మీది `--fix` పేర్కొనే ఒక బ్యాకప్‌కు వెళ్తుంది. మధ్యలో ఆగిపోయిన గ్రూప్ మార్పును కూడా `ccam doctor --fix` పూర్తి చేస్తుంది.
