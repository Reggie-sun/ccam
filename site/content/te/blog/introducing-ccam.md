ccam అనేది ఒకే కంప్యూటర్‌లో ఒకటి కంటే ఎక్కువ Claude Code ఖాతాలను ఉపయోగించేవారి కోసం ఒక చిన్న కమాండ్-లైన్ టూల్: ఒక వ్యక్తిగత ఖాతా, ఒక work ఖాతా, లేదా ఒక పెద్ద ప్రాజెక్ట్ కోసం అనేక ఖాతాలు.

## సమస్య

Claude Code [`CLAUDE_CONFIG_DIR`](/guides/claude-config-dir) ద్వారా అనేక ఖాతాలకు మద్దతు ఇస్తుంది: ఒక్కో ఖాతాకు ఒక ఫోల్డర్. ఆచరణలో, ప్రతి ఫోల్డర్ ఒక ద్వీపం. సెట్టింగ్‌లు, `CLAUDE.md`, MCP సర్వర్లు, ఏజెంట్లు, స్కిల్స్ ప్రతి ఫోల్డర్‌లో మళ్లీ సెటప్ చేయాలి, చేతితో సమకాలీకరించాలి. సంభాషణలు అవి మొదలైన చోటే ఉంటాయి. ఒక ఖాతా వినియోగ పరిమితిని చేరిందని, ప్రయత్నించినప్పుడే మీకు తెలుస్తుంది.

## ccam ఏమి చేస్తుంది

- `ccam add` ఫోల్డర్‌ను సృష్టిస్తుంది, లాగిన్‌ను రన్ చేస్తుంది, మీకు కావాలంటే, `ccwork` వంటి మీరే పేరు పెట్టిన షార్ట్‌కట్‌ను ఖాతాకు ఇస్తుంది.
- `ccam work`, `ccwork` ఆ ఖాతాగా Claude Code ను ప్రారంభిస్తాయి, ప్రతి ఆర్గ్యుమెంట్‌ను మార్పు లేకుండా పంపుతాయి.
- MCP సర్వర్లు, సెట్టింగ్‌లు, `CLAUDE.md`, ఎక్స్‌టెన్షన్లు లింక్‌ల ద్వారా, అంశం వారీగా, ఖాతా వారీగా షేర్ అవుతాయి. లాగిన్‌లు ఎప్పుడూ షేర్ కావు.
- `ccam usage` ప్రతి ఖాతా యొక్క 5 గంటల, వారపు వినియోగాన్ని చూపిస్తుంది; `ccam next --continue` సంభాషణను తర్వాతి ఖాతాలో కొనసాగిస్తుంది.

## అడ్డు రాకుండా ఉండటం

ప్రతి సెషన్‌కు ముందు మీరు రన్ చేసే టూల్ వల్ల మీరు గమనించేంత ఖర్చు ఉండకూడదు. ccam ఒక కాన్ఫిగరేషన్ ఫైల్‌ను చదువుతుంది, ప్రతి షేర్డ్ లింక్‌ను ఒక్కో సిస్టమ్ కాల్‌తో తనిఖీ చేస్తుంది, తర్వాత తన స్థానంలో `claude` ను పెడుతుంది. ఇది సుమారు 4 మిల్లీసెకన్లు జోడిస్తుంది, మీరు పనిచేస్తున్నప్పుడు రన్ అవ్వదు.

ఇది మీ ఫైళ్ల విషయంలో కూడా జాగ్రత్తగా ఉంటుంది. షేరింగ్‌లో ప్రతి మార్పు మొదలుపెట్టే ముందు ఒక ప్రణాళికను ప్రింట్ చేస్తుంది, అసలు ఫైళ్లను ఒక బ్యాకప్ ఫోల్డర్‌లో ఉంచుతుంది. `ccam doctor` లింక్‌లు, అనుమతులు, లాగిన్‌లను తనిఖీ చేస్తుంది, సురక్షితంగా సరిచేయగలిగినవి సరిచేస్తుంది.

## ప్రయత్నించండి

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add
```

[క్విక్ స్టార్ట్](/docs/quick-start) రెండు ఖాతాలను జోడించే దశలను చూపిస్తుంది, [అనేక Claude Code ఖాతాలను ఎలా ఉపయోగించాలి](/guides/multiple-claude-code-accounts) ccam తో, ccam లేకుండా ఈ పద్ధతిని వివరిస్తుంది.

ccam ఓపెన్ సోర్స్, అనధికారికం: దీనికి Anthropic తో ఎలాంటి సంబంధం లేదు, Anthropic దీన్ని ఆమోదించలేదు. మీరు అనేక ఖాతాలను ఉపయోగించవచ్చా అనేది ప్రతి ఖాతా నిబంధనలపై ఆధారపడి ఉంటుంది. అభిప్రాయాలకు, అనువాదాలకు [GitHub](https://github.com/jhyunwoo/ccam) లో స్వాగతం.
