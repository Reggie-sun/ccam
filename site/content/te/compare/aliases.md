అనేక Claude Code ఖాతాలను రన్ చేయడానికి ప్రతి ఖాతాకు ఒక షెల్ అలియాస్ అత్యంత సులభమైన మార్గం. ccam లోపల అదే పని చేస్తుంది, దానికి షేరింగ్, ఖాతా మార్చడం, వినియోగ ట్రాకింగ్ జోడిస్తుంది.

## అలియాస్ సెటప్

ప్రతి అదనపు ఖాతాకు `~/.bashrc` లేదా `~/.zshrc` లో ఒక లైన్ జోడించండి, కొత్త టెర్మినల్ తెరిచి, లాగిన్ చేయడానికి అలియాస్‌ను ఒకసారి రన్ చేయండి:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

`claude` మీ మొదటి ఖాతాగానే ఉంటుంది, `claude-work` రెండో ఖాతాను ప్రారంభిస్తుంది. [Claude Code డాక్యుమెంటేషన్ వివరించే](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) పద్ధతి ఇదే.

## ccam సెటప్

ccam ను ఇన్‌స్టాల్ చేసి ఖాతాను జోడించండి, ఇక్కడ దానికంటూ ఒక షార్ట్‌కట్ కమాండ్‌తో:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add work --shortcut ccwork
```

`ccam work`, `ccwork` ఖాతాను ప్రారంభిస్తాయి, రెండూ స్క్రిప్ట్‌లలో కూడా పనిచేస్తాయి.

## పక్కపక్కనే

| | షెల్ అలియాస్ | ccam |
| --- | --- | --- |
| వేర్వేరు లాగిన్‌లు | అవును | అవును |
| ప్రతి ఖాతాకు సెటప్ | `~/.bashrc` ను సవరించండి, లాగిన్ అవ్వండి | `ccam add` |
| స్క్రిప్ట్‌లు, ఇతర ప్రోగ్రామ్‌లలో పనిచేస్తుంది | లేదు, అలియాస్‌లు షెల్‌లో మాత్రమే | అవును, `ccam work`, `ccwork` వంటి షార్ట్‌కట్‌లు నిజమైన కమాండ్‌లు |
| షేర్డ్ సెట్టింగ్‌లు, `CLAUDE.md`, ఎక్స్‌టెన్షన్లు | చేతితో కాపీ లేదా లింక్ | అంశం వారీగా, బ్యాకప్‌లతో |

| మరో ఖాతాలో సంభాషణను కొనసాగించడం | లేదు | `ccam next --continue` |
| ప్రతి ఖాతా వినియోగం | లేదు | `ccam usage` |
| ఎక్కువ అవకాశం ఉన్న ఖాతాను ఎంచుకోవడం | లేదు | `ccam next --auto` |
| పరిమితి చేరినప్పుడు ఒక `-p` job ను మరో ఖాతాగా మళ్లీ రన్ చేయడం | లేదు | `ccam --fallback` |
| ప్రతి ప్రాజెక్ట్ ఫోల్డర్‌కు ఒక ఖాతా | లేదు | `ccam folder` |
| స్టేటస్ లైన్‌లో ఖాతా పేరు | లేదు | `ccam statusline install` |

మీకు రెండు ఖాతాలు ఉండి, వాటి మధ్య ఏమీ షేర్ చేయనవసరం లేకపోతే అలియాస్‌లను ఎంచుకోండి. ఖాతాలు ఒకే సెటప్‌లా అనిపించాలంటే ccam ను ఎంచుకోండి. మీరు అలియాస్‌లతో మొదలుపెట్టి తర్వాత ccam కు మారవచ్చు: `ccam import` ఉన్న `~/.claude-*` ఫోల్డర్‌లను అవి ఉన్న చోటే నమోదు చేస్తుంది.

[ఒకే కంప్యూటర్‌లో అనేక ఖాతాలను ఎలా ఉపయోగించాలి](/guides/multiple-claude-code-accounts) రెండు పద్ధతులనూ దశలవారీగా వివరిస్తుంది. ఒకే లాగిన్‌ను మార్చే టూల్స్‌తో ccam ను [ccam, ఇతర ఖాతా స్విచర్లు](/compare/account-switchers) పోల్చి చూపిస్తుంది.
