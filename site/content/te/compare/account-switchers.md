Claude Code ఖాతాలను మార్చే టూల్స్ రెండు పద్ధతుల్లో ఒకదాన్ని అనుసరిస్తాయి. చాలావరకు ఒకే `~/.claude` ఫోల్డర్ లోపల లాగిన్‌ను మారుస్తాయి, కాబట్టి ఒకేసారి ఒక ఖాతా మాత్రమే యాక్టివ్‌గా ఉంటుంది. ccam తో సహా మరికొన్ని, `CLAUDE_CONFIG_DIR` తో ప్రతి ఖాతాకు దాని సొంత ఫోల్డర్ ఇస్తాయి, కాబట్టి ప్రతి ఖాతా సైన్ ఇన్ అయ్యే ఉంటుంది, అనేక ఖాతాలు ఒకేసారి రన్ కాగలవు. ccam షేర్డ్ సెట్టింగ్‌లు, MCP సర్వర్లను జోడిస్తుంది, ఒక సంభాషణను మరో ఖాతా ఫోల్డర్‌లో కొనసాగిస్తుంది.

## ఒకే లాగిన్‌ను మార్చడమా, వేర్వేరు ఫోల్డర్‌లా?

**లాగిన్‌ను మార్చడం** ఒకే సెట్ సెట్టింగ్‌లు, MCP సర్వర్లు, చరిత్రను ఉంచుతుంది, ఎందుకంటే ఫోల్డర్ ఒక్కటే. మారడం వేగంగా ఉంటుంది, రన్ అవుతున్న సెషన్ కొత్త లాగిన్‌ను అందుకోగలదు. కానీ ఒకేసారి ఒక ఖాతా మాత్రమే యాక్టివ్‌గా ఉంటుంది, అన్ని టెర్మినల్‌లు, ఎడిటర్‌లకు ఒకేసారి.

**వేర్వేరు ఫోల్డర్‌లు** అనేది [Claude Code డాక్యుమెంటేషన్ వివరించే](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) పద్ధతి. ప్రతి ఖాతా లాగిన్ అయ్యే ఉంటుంది, work, personal సెషన్‌లను పక్కపక్కనే రన్ చేయవచ్చు. దీనికి చెల్లించే మూల్యం: ఏదైనా టూల్ షేర్ చేయకపోతే, ప్రతి ఫోల్డర్ దాని సొంత సెట్టింగ్‌లు, MCP సర్వర్లు, చరిత్రతో మొదలవుతుంది.

## ccam దేనిపై దృష్టి పెడుతుంది

- ప్రతి ఖాతా లాగిన్ అయ్యే ఉంటుంది. మారడం ఎప్పుడూ ఒక ఖాతాను లాగ్ అవుట్ చేయదు, `ccam work`, `ccam personal` రెండు టెర్మినల్‌లలో ఒకేసారి రన్ కాగలవు.
- MCP సర్వర్లు, `settings.json`, `CLAUDE.md`, ఏజెంట్లు, స్కిల్స్, ప్లగిన్‌లు లింక్‌ల ద్వారా ఫోల్డర్‌ల మధ్య, ఒక్కో అంశం, ఒక్కో ఖాతా వారీగా షేర్ అవుతాయి. లాగిన్‌లు ఎప్పుడూ షేర్ అవ్వవు.
- షేర్డ్ చరిత్రతో, `ccam next --auto --continue` అనే ఒకే కమాండ్ ఎక్కువ అవకాశం ఉన్న ఖాతా ఫోల్డర్‌లో అదే సంభాషణను తెరుస్తుంది.
- ccam Claude Code ను ప్రారంభించి, తన స్థానాన్ని దానికి ఇస్తుంది, కాబట్టి బ్యాక్‌గ్రౌండ్‌లో ఏదీ రన్ అవ్వదు. అది మీ వినియోగాన్ని గమనించదు, తనంతట తానే మారదు; ఎప్పుడు మారాలో మీరే నిర్ణయిస్తారు.

## ఇతర టూల్స్ ఎక్కడ ఎక్కువ చేస్తాయి

- claude-swap, CCS, clauth, CAAM, cux WSL లేకుండా Windows లో రన్ అవుతాయి. ccam అలా రన్ అవ్వదు.
- ఒక ఖాతా వినియోగ పరిమితిని దాటినప్పుడు claude-swap, clauth, cux తామే మారుతాయి. ccam మారే నిర్ణయాన్ని మీకే వదిలేస్తుంది.
- CCSwitcher, Claude Switcher, claude-swap macOS మెనూ బార్‌లో వినియోగాన్ని చూపిస్తాయి.
- CCS, CAAM, ccswap, Claude Switcher Codex ను, ఇతర కోడింగ్ ఏజెంట్లను కూడా నిర్వహిస్తాయి.

## ఏది సరిపోతుంది?

మీరు ఒకేసారి ఒక ఖాతా మాత్రమే ఉపయోగిస్తుంటే, మారడం ఆటోమేటిక్‌గా జరగాలనుకుంటే, లేదా WSL లేని Windows లో ఉంటే, లాగిన్‌ను మార్చే టూల్‌ను ఎంచుకోండి. ఖాతాలను పక్కపక్కనే, ఒకే షేర్డ్ సెటప్‌తో, తదుపరి ఖాతాలో అదే సంభాషణతో కావాలంటే ccam ను ఎంచుకోండి. ఏమీ షేర్ చేయనవసరం లేకపోతే, [సాధారణ షెల్ అలియాస్‌లు](/compare/aliases) సరిపోతాయి.

అనేక ఖాతాలను ఉపయోగించవచ్చా అనేది ప్రతి ఖాతా నిబంధనలపై ఆధారపడి ఉంటుంది. ఉపయోగించే ముందు వాటిని తనిఖీ చేయండి.
