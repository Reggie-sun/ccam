ఒక ఖాతా తన వినియోగ పరిమితిని (తరచుగా rate limit అని పిలుస్తారు) చేరినప్పుడు మీకు రెండు మార్గాలు ఉన్నాయి: పరిమితి రీసెట్ అయ్యే వరకు ఆగడం, లేదా అదే సంభాషణను ఇప్పుడే మీ మరో ఖాతాలో కొనసాగించడం. ccam తో రెండో మార్గానికి ఒకే కమాండ్ చాలు: `ccam next --auto --continue`.

## Claude Code కు ఏ పరిమితులు ఉన్నాయి?

Pro, Max ప్లాన్‌లలో Claude Code కు [5 గంటల సెషన్ పరిమితి, వారపు పరిమితి](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan) ఉన్నాయి. రెండూ వెబ్‌లోని, యాప్‌లలోని Claude తో షేర్ అవుతాయి, వినియోగం రెండింటి నుంచీ ఒకేసారి లెక్కించబడుతుంది. ఒకటి అయిపోయినప్పుడు, Claude Code "You've hit your session limit · resets 3:45pm" వంటి [సందేశాన్ని చూపిస్తుంది](https://code.claude.com/docs/en/errors#youve-hit-your-session-limit). మోడల్ మార్చడం సహాయపడదు, ఎందుకంటే పరిమితులు అన్ని మోడల్‌లకూ వర్తిస్తాయి.

## మార్గం 1: రీసెట్ కోసం ఆగండి

మీకు ఒకే ఖాతా ఉంటే, ఆగండి. Claude Code యొక్క ఇటీవలి వెర్షన్‌లు [తెరిచి ఉన్న సెషన్‌లోనే ఆగి](https://code.claude.com/docs/en/interactive-mode#wait-for-a-usage-limit-to-reset), పరిమితి రీసెట్ అయ్యాక పనిని తామే కొనసాగిస్తాయి. Claude Code లోపల `/usage` మీ ప్లాన్ పరిమితుల్లో ఎంత ఉపయోగించారో చూపిస్తుంది.

## మార్గం 2: ఇప్పుడే మరో ఖాతాలో కొనసాగించండి

మీకు రెండో ఖాతా ఉంటే, అదే సంభాషణతో వెంటనే కొనసాగవచ్చు. ఒకసారి సెటప్ చేయండి:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
ccam group set default --add history
ccam statusline install
```

ఇప్పుడు మీరు పని చేస్తున్నప్పుడు స్టేటస్ లైన్ ఖాతాను, దాని 5 గంటల వినియోగాన్ని చూపిస్తుంది, కాబట్టి పరిమితి ఆశ్చర్యంగా రాదు.

పరిమితి చేరినప్పుడు, Claude Code నుంచి బయటకు రండి (`/exit`), తర్వాత:

```sh
ccam usage
```

```console
 1 personal  just now
   5-hour   ████████████████████ 100%  resets in 22m
   Weekly   ██████████████░░░░░░  68%  resets in 1d 9h
 2 work      just now
   5-hour   ██░░░░░░░░░░░░░░░░░░   8%  resets in 4h 12m
   Weekly   ████░░░░░░░░░░░░░░░░  19%  resets in 5d 2h
→ Most headroom: work   (open it with ccam next --auto)
```

ఎక్కువ అవకాశం మిగిలి ఉన్న ఖాతాలో సంభాషణను తెరవండి:

```sh
ccam next --auto --continue
```

Claude Code `work` గా ప్రారంభమై, ప్రస్తుత ఫోల్డర్ యొక్క తాజా సంభాషణను, ఇప్పటివరకు చెప్పిన ప్రతిదానితో సహా తెరుస్తుంది. చరిత్రను షేర్ చేయడం (పైన ఉన్న `ccam group set default --add history`) దాన్ని ఒకే సంభాషణగా ఉంచుతుంది; అది లేకపోతే, Claude Code సంభాషణను `work` లోకి కాపీ చేస్తుంది, ఆ మొదటి సమాధానం ఎన్ని టోకెన్‌లను మళ్లీ చదువుతుందో ccam మీకు చెబుతుంది.

Claude Code లో [ccam ప్లగిన్](/docs/install#claude-code-plugin) ఉంటే, పరిమితి వద్ద ఆగిన సెషన్ ఒక నోటిఫికేషన్ చూపించి, నిండిన విండోను నమోదు చేస్తుంది, కాబట్టి `ccam next --auto` ఆ ఖాతాను దాని రీసెట్‌కు ముందు మళ్లీ ఎంచుకోదు; `/ccam:switch` (లేదా `/ccam:switch work`) `ccam next --continue` కోసం సంభాషణను గుర్తుపెడుతుంది, ఊహించాల్సింది ఏదీ వదలకుండా.

**Team, Enterprise సీట్లు.** ఆటోమేటిక్ ఎంపిక (`ccam next`, `--fallback`, `ccam pick`, డాష్‌బోర్డ్‌లోని `n`, మీరు ఆన్ చేసినప్పుడు [`auto_switch`](/features/next#auto-switch)) ఒకే Claude Team లేదా Enterprise సంస్థలోని సీట్ల మధ్య కూడా మారుస్తుంది. Anthropic సహాయ కేంద్రం "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (Team ప్లాన్‌లోని ప్రతి సీటు పేరుతో నిర్దేశించిన ఒక వ్యక్తికి కేటాయించబడుతుంది, ఆ వ్యక్తి మాత్రమే దాన్ని ఉపయోగించవచ్చు) అని, "Users can't route their work through another user's account to use that user's remaining usage" (యూజర్లు మరో యూజర్‌కు మిగిలి ఉన్న వినియోగాన్ని వాడుకోవడానికి తమ పనిని ఆ యూజర్ ఖాతా ద్వారా మళ్లించకూడదు) అని చెబుతుంది ([Team ప్లాన్‌లు](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129); [Enterprise ప్లాన్‌లకు](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) కూడా ఇదే వర్తిస్తుంది). కాబట్టి సీట్ల మధ్య ఆటోమేటిక్ ఎంపికను ఉపయోగించడం Anthropic నిబంధనల ఉల్లంఘన కావచ్చు. అక్కడ దాన్ని ఉపయోగించాలా వద్దా అనేది మీ నిర్ణయం: దానిపై ఆధారపడే ముందు మీ సంస్థను, Anthropic ను సంప్రదించి నిర్ధారించుకోండి. వ్యక్తిగత ప్లాన్‌ల (Pro, Max) గురించి [తరచుగా అడిగే ప్రశ్నలలోని నిబంధనల గమనిక](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) చెబుతుంది.

## ccam ఖాతాలను ఆటోమేటిక్‌గా మారుస్తుందా?

మీరు ఆన్ చేస్తేనే. డిఫాల్ట్‌గా మీరు పని చేస్తున్నప్పుడు ccam రన్ అవ్వదు: అది Claude Code ను ప్రారంభించి, తన స్థానాన్ని దానికి ఇస్తుంది, కాబట్టి ఎప్పుడు మారాలో మీరే నిర్ణయిస్తారు. `ccam next --auto` అత్యల్ప 5 గంటల వినియోగం ఉన్న ఖాతాను ఎంచుకుంటుంది, 100% వద్ద ఉన్న లేదా లాగిన్ కాని ఖాతాలను వదిలేస్తుంది, ఒకే Team లేదా Enterprise సంస్థలోనే, లేదా వ్యక్తిగత ప్లాన్‌ల మధ్యనే ఉంటుంది. `config.toml` లో `relay = true` తో, ccam బదులుగా సెషన్ పక్కన వేచి ఉంటుంది, కాబట్టి `/ccam:switch` సెషన్ ఆప్షన్లు, permission mode, effort level ను ఉంచుతూ తనంతట తానే కొనసాగుతుంది. `auto_switch = true` తో (Linux, macOS; ప్రయోగాత్మకం), ccam మార్పును కూడా తానే చేస్తుంది: Claude Code సెషన్‌ను దాని పరిమితి వద్ద ఆపినప్పుడు, దాని లాంటి మరో ఖాతాలో అవకాశం ఉంటే, ccam సెషన్‌ను ముగించి సంభాషణను అక్కడ కొనసాగిస్తుంది ([షరతులు, ఖర్చులు](/features/next#auto-switch)). మరికొన్ని టూల్స్ బదులుగా రన్ అవుతున్న సెషన్ యొక్క లాగిన్‌ను మారుస్తాయి; ఆ తేడాను [ccam, ఇతర ఖాతా స్విచర్లు](/compare/account-switchers) వివరిస్తుంది.

## గుర్తుంచుకోవలసినవి

- మీరు పని చేసిన అదే ఫోల్డర్‌లో `ccam next --continue` రన్ చేయండి; సంభాషణలు ప్రాజెక్ట్ ఫోల్డర్ వారీగా నిల్వ అవుతాయి.
- ఒకే సంభాషణపై రెండు ఖాతాలను ఒకేసారి రన్ చేయకండి. మీరు అలా ప్రయత్నిస్తే ccam హెచ్చరిస్తుంది.
- షేర్డ్ చరిత్ర లేకపోతే, సంభాషణ మరో ఖాతాకు కాపీ అవుతుంది, ఆ రెండు కాపీలు వేర్వేరు దారుల్లో సాగుతాయి; `/rewind` కోడ్‌ను పునరుద్ధరించే checkpoints మొదటి ఖాతా దగ్గరే ఉంటాయి.
- కొత్త ఖాతాలో మొదటి సందేశం సాధారణం కంటే ఎక్కువ పరిమితిని ఉపయోగించవచ్చు, ఎందుకంటే ఆ ఖాతా ఇంకా సంభాషణను క్యాష్ చేయలేదు. `ccam next --continue --brief` బదులుగా దాన్ని ఒక చిన్న సారాంశంతో ప్రారంభిస్తుంది.
- ఇలా ఖాతాల మధ్య మారవచ్చా అనేది ప్రతి ఖాతా నిబంధనలపై ఆధారపడి ఉంటుంది.

`ccam usage`, `ccam next` యొక్క ప్రతి ఆప్షన్ కోసం [వినియోగ పరిమితులు](/docs/usage-limits) చూడండి.
