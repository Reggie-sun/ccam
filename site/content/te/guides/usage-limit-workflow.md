ఒక ఖాతా Claude Code వినియోగ పరిమితిని చేరినప్పుడు, మీకు చెందిన మరో ఖాతాలో అదే సంభాషణను కొనసాగించండి: సంభాషణ చరిత్రను ఒక్కసారి షేర్ చేసి, తర్వాత `ccam next --continue` రన్ చేయండి. మీకు ఒకే ఖాతా ఉంటే, Claude Code చూపించే రీసెట్ సమయం వరకు వేచి ఉండండి.

## అది జరగక ముందే

ఖాతా మార్చడానికి ఒకే కమాండ్ సరిపోయేలా ఖాతాలను సెటప్ చేయండి:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

ఇప్పుడు మీరు పనిచేస్తున్నప్పుడు స్టేటస్ లైన్ ఖాతాను, దాని 5 గంటల వినియోగాన్ని చూపిస్తుంది, కాబట్టి పరిమితి మిమ్మల్ని ఆశ్చర్యపరచదు.

## పరిమితిని చేరినప్పుడు

Claude Code నుంచి బయటకు రండి (`/exit`), తర్వాత:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

ఎక్కువ అవకాశం ఉన్న ఖాతాలో సంభాషణను తెరవండి:

```sh
ccam next --auto --continue
```

Claude Code `work` గా ప్రారంభమవుతుంది, ప్రస్తుత ఫోల్డర్ యొక్క అత్యంత ఇటీవలి సంభాషణతో, ఇప్పటివరకు చెప్పినదంతా సహా.

## గుర్తుంచుకోవలసిన విషయాలు

- మీరు పనిచేసిన అదే ఫోల్డర్‌లో `ccam next --continue` రన్ చేయండి; సంభాషణలు ప్రతి ప్రాజెక్ట్ ఫోల్డర్ వారీగా నిల్వ అవుతాయి.
- ఒకే సంభాషణపై ఒకే సమయంలో రెండు ఖాతాలను రన్ చేయకండి. మీరు ప్రయత్నిస్తే ccam హెచ్చరిస్తుంది.
- మరో ఖాతా కూడా అదే గ్రూప్‌లో సంభాషణ చరిత్రను షేర్ చేయాలి.
- ఈ విధంగా ఖాతాల మధ్య మారవచ్చా అనేది ప్రతి ఖాతా నిబంధనలపై ఆధారపడి ఉంటుంది.

`ccam usage`, `ccam next` యొక్క ప్రతి ఆప్షన్ కోసం [వినియోగ పరిమితులు](/docs/usage-limits) చూడండి.
