ప్రతి ఖాతాకు దాని సొంత కాన్ఫిగరేషన్ ఫోల్డర్ ఇవ్వండి. Claude Code ఫోల్డర్‌ను `CLAUDE_CONFIG_DIR` ఎన్విరాన్‌మెంట్ వేరియబుల్ నుంచి చదువుతుంది. ప్రతి ఫోల్డర్‌లో దాని సొంత లాగిన్, సెట్టింగ్‌లు, చరిత్ర ఉంటాయి, కాబట్టి ప్రతి ఖాతా సైన్ ఇన్ అయ్యే ఉంటుంది, వాటిని ఒకేసారి రన్ చేయవచ్చు. దీన్ని షెల్ అలియాస్‌తో చేతితో సెటప్ చేయవచ్చు, లేదా ccam కు వదిలేయవచ్చు.

## చేతితో ఎలా సెటప్ చేయాలి?

[Claude Code డాక్యుమెంటేషన్ వివరించే](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts) పద్ధతి ఇదే. ప్రతి అదనపు ఖాతాకు `~/.bashrc` లేదా `~/.zshrc` లో ఒక లైన్ జోడించండి:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

కొత్త టెర్మినల్ తెరిచి `claude-work` రన్ చేయండి. ఫోల్డర్ కొత్తది కాబట్టి Claude Code మిమ్మల్ని లాగిన్ అవ్వమని అడుగుతుంది. అప్పటి నుంచి `claude` మీ మొదటి ఖాతా, `claude-work` రెండో ఖాతా.

WSL లేని Windows లో, మీ ప్రొఫైల్‌లోని (`notepad $PROFILE`) ఒక PowerShell ఫంక్షన్ ఇదే పని చేస్తుంది:

```powershell
function claude-work { $env:CLAUDE_CONFIG_DIR = "$HOME\.claude-work"; try { claude @args } finally { Remove-Item Env:CLAUDE_CONFIG_DIR } }
```

## అలియాస్ పద్ధతిలో ఏమి లేదు?

రెండు ఖాతాలకు ఇది బాగా పనిచేస్తుంది. తెలుసుకోవలసిన విషయాలు:

- ప్రతి ఫోల్డర్ ఖాళీగా మొదలవుతుంది: సెట్టింగ్‌లు లేవు, `CLAUDE.md` లేదు, MCP సర్వర్లు లేవు, ఏజెంట్లు లేదా స్కిల్స్ లేవు. మీకు కావలసినవి మీరే కాపీ చేయాలి లేదా లింక్ చేయాలి, కాపీలను మీరే ఒకేలా ఉంచాలి.
- అలియాస్‌లు ఇంటరాక్టివ్ షెల్‌లలో మాత్రమే ఉంటాయి. స్క్రిప్ట్‌లు, Makefile లు, ఇతర ప్రోగ్రామ్‌లు వాటిని చూడలేవు.
- MCP సర్వర్లు లాగిన్ పక్కన `.claude.json` లో ఉంటాయి, కాబట్టి వాటిని ఫోల్డర్‌ల మధ్య నేరుగా లింక్ చేయడం కుదరదు.
- సంభాషణలు అవి మొదలైన ఖాతాలోనే ఉంటాయి, కాబట్టి ఒక సంభాషణను మరో ఖాతాలో కొనసాగించలేరు.
- అన్ని ఖాతాల వినియోగాన్ని ఒకేసారి చూపించేది ఏదీ లేదు.

## బదులుగా /login తో ఖాతా మార్చవచ్చా?

అప్పుడప్పుడు మాత్రమే మారుతుంటే, అవును. Claude Code లోపల `/login` టైప్ చేస్తే మీరు ఉన్న ఫోల్డర్ యొక్క [ఖాతా మారుతుంది](https://code.claude.com/docs/en/quickstart). ఒకేసారి ఒక ఖాతా మాత్రమే సైన్ ఇన్ అయి ఉంటుంది, కాబట్టి ప్రతిసారి మారినప్పుడు మళ్లీ లాగిన్ అవ్వాలి, రెండు ఖాతాలను పక్కపక్కనే రన్ చేయలేరు. వేర్వేరు ఫోల్డర్‌లు ఈ రెండు సమస్యలనూ నివారిస్తాయి.

## ccam తో ఎలా సెటప్ చేయాలి?

ccam అదే ఆలోచనను ఆటోమేట్ చేసి, లేని భాగాలను జోడిస్తుంది:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

ఇప్పుడు `ccam personal`, `ccam work` ఈ రెండు ఖాతాలను ప్రారంభిస్తాయి, work ఖాతాకు మీరు ఇచ్చిన షార్ట్‌కట్ `ccwork` కూడా అలాగే చేస్తుంది. ఇవి అలియాస్‌లు కాకుండా నిజమైన ప్రోగ్రామ్‌లు కాబట్టి, స్క్రిప్ట్‌లలో కూడా పనిచేస్తాయి. జాబితా నుంచి ఖాతాను ఎంచుకోవడానికి `ccam` ను ఒక్కటే రన్ చేయండి, ఒక ఖాతాను డిఫాల్ట్‌గా చేయడానికి `ccam use work` రన్ చేయండి.

సెట్టింగ్‌లు, `CLAUDE.md`, MCP సర్వర్లు, ఎక్స్‌టెన్షన్లు మొదటి నుంచే షేర్ అవుతాయి. `ccam next --continue` ఒక సంభాషణను మరో ఖాతాలో కొనసాగిస్తుంది. మీరు షేర్డ్ సంభాషణ చరిత్రను ఆన్ చేస్తే, రెండు ఖాతాలు కాపీపై కాకుండా ఒకే సంభాషణపై పనిచేస్తాయి. `ccam usage` ప్రతి ఖాతా యొక్క 5 గంటల, వారపు వినియోగాన్ని ఒకేసారి చూపిస్తుంది.

మీరు ఇప్పటికే `~/.claude` ఉపయోగిస్తుంటే, ఆ ఖాతాను మళ్లీ జోడించడానికి బదులు `ccam import` రన్ చేయండి, లేదా దాని సెట్టింగ్‌లు, MCP సర్వర్లు, ఎక్స్‌టెన్షన్లను షేర్డ్ `default` గ్రూప్‌లోకి కాపీ చేయడానికి `ccam migrate` రన్ చేయండి.

## ఏ ఖాతా రన్ అవుతోందో ఎలా తెలుస్తుంది?

Claude Code లోపల `/status` మీరు సైన్ ఇన్ అయిన ఖాతాను చూపిస్తుంది. ccam తో ఒకసారి `ccam statusline install` రన్ చేస్తే, స్టేటస్ లైన్ ఖాతా పేరును, దాని వినియోగాన్ని ఎప్పుడూ చూపిస్తుంది, ఉదాహరణకు `[work] · Opus · 5h 24% · 7d 41%`.

## ఇది Windows, WSL లో పనిచేస్తుందా?

Claude Code [Windows లో నేరుగా, WSL లోపల కూడా](https://code.claude.com/docs/en/setup) రన్ అవుతుంది. `CLAUDE_CONFIG_DIR` రెండింటిలోనూ పనిచేస్తుంది, కాబట్టి నేటివ్ Windows లో పైన చెప్పిన అలియాస్ లేదా PowerShell ఫంక్షన్ సరిపోతుంది. ccam కూడా Windows లో నేరుగా రన్ అవుతుంది: దాన్ని PowerShell లో `irm https://ccam.dev/install.ps1 | iex` తో, లేదా WSL లోపల Linux కమాండ్‌తో ఇన్‌స్టాల్ చేయండి. షార్ట్‌కట్‌లు `ccwork.exe` అవుతాయి, `settings.json` వంటి ఫైల్‌లను షేర్ చేయడానికి Developer Mode అవసరం ([ccam ను ఇన్‌స్టాల్ చేయండి](/docs/install)).

## సమస్యల పరిష్కారం

**Claude Code ప్రతిసారీ లాగిన్ అవ్వమని అడుగుతోంది.** కొత్త ఫోల్డర్‌లో మొదటిసారి ప్రారంభించినప్పుడు ఎప్పుడూ అడుగుతుంది. అలాగే అడుగుతూ ఉంటే, లాగిన్ గడువు ముగిసింది లేదా తొలగించబడింది: `ccam login work` రన్ చేయండి (లేదా అలియాస్‌ను ఒకసారి ప్రారంభించి లాగిన్ అవ్వండి).

**ఒక MCP సర్వర్ ఒక ఖాతాలో మాత్రమే కనిపిస్తోంది.** సెషన్ లోపల `claude mcp add` తో జోడించిన సర్వర్లు ఆ ఖాతాకే చెందుతాయి, `-s user` లేకుండా అయితే ఆ ఫోల్డర్‌కు మాత్రమే. `ccam mcp import work <server>` తో దాన్ని అన్ని ఖాతాలకు తరలించండి.

**ఖాతాల మధ్య సెట్టింగ్‌లు వేరుగా ఉన్నాయి.** `ccam share work` ఆ ఖాతా ఏమి షేర్ చేస్తుందో, ఏ గ్రూప్ ద్వారా షేర్ చేస్తుందో చూపిస్తుంది; `ccam group join default work` ఏమి మారుతుందో చూపించిన తర్వాత, `default` షేర్ చేసేదాన్నే ఆ ఖాతా కూడా షేర్ చేసేలా చేస్తుంది. `ccam doctor --fix` విరిగిన లింక్‌లను సరిచేస్తుంది, తాను మార్చే ప్రతి ఫైల్‌కు బ్యాకప్ ఉంచుతుంది.

**రెండు ఖాతాలు ఒకే సంభాషణను తెరుస్తున్నాయి.** ఒకే సంభాషణపై రెండు ఖాతాలలో ఒకేసారి పని చేయకండి. మీరు అలా ప్రయత్నిస్తే ccam హెచ్చరిస్తుంది.

## దేన్ని ఎంచుకోవాలి?

రెండు ఖాతాలకు, ఏమీ షేర్ చేయనవసరం లేకపోతే, అలియాస్ సరిపోతుంది. షేర్డ్ సెట్టింగ్‌లు, MCP సర్వర్లు, ఎక్కువ ఖాతాలు, ఒక్క చూపులో వినియోగం లేదా సంభాషణలను కొనసాగించడం కావాలంటే, ccam ఆ నిర్వహణ పనిని మీకు తప్పిస్తుంది. [అలియాస్‌లతో పోలిక](/compare/aliases) తేడాలను పక్కపక్కనే చూపిస్తుంది, ఒకే లాగిన్‌ను మార్చే టూల్స్ గురించి [ccam, ఇతర ఖాతా స్విచర్లు](/compare/account-switchers) వివరిస్తుంది.

మీరు ఒకటి కంటే ఎక్కువ ఖాతాలను ఉపయోగించవచ్చా అనేది ప్రతి ఖాతాకు వర్తించే నిబంధనలపై ఆధారపడి ఉంటుంది. మొదలుపెట్టే ముందు ఆ నిబంధనలను చదవండి.

**Team, Enterprise సీట్లు.** ఆటోమేటిక్ ఖాతా ఎంపిక (`ccam next`, `--fallback`, `ccam pick`, డాష్‌బోర్డ్‌లోని `n`, మీరు ఆన్ చేసిన తర్వాత [`auto_switch`](/features/next#auto-switch)) ఒకే Claude Team లేదా Enterprise సంస్థలోని సీట్ల మధ్య కూడా మారుస్తుంది, ఇది Anthropic నిబంధనల ఉల్లంఘన కావచ్చు. దానిపై ఆధారపడే ముందు [తరచుగా అడిగే ప్రశ్నలు](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) చదివి, మీ సంస్థను, Anthropic ను సంప్రదించి నిర్ధారించుకోండి.
