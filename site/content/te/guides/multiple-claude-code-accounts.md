ప్రతి ఖాతాకు దాని సొంత కాన్ఫిగరేషన్ ఫోల్డర్ ఇవ్వండి. Claude Code ఫోల్డర్‌ను `CLAUDE_CONFIG_DIR` ఎన్విరాన్‌మెంట్ వేరియబుల్ నుంచి చదువుతుంది, ప్రతి ఫోల్డర్‌లో దాని సొంత లాగిన్, సెట్టింగ్‌లు, చరిత్ర ఉంటాయి. ఒకే కంప్యూటర్‌లో రెండు Claude Code ఖాతాల కోసం దీన్ని షెల్ అలియాస్‌తో చేతితో సెటప్ చేయవచ్చు, లేదా ccam కు వదిలేయవచ్చు.

## చేతితో, అలియాస్‌తో

Claude Code డాక్యుమెంటేషన్ వివరించే పద్ధతి ఇదే. ప్రతి అదనపు ఖాతాకు `~/.bashrc` లేదా `~/.zshrc` లో ఒక లైన్ జోడించండి:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

కొత్త టెర్మినల్ తెరిచి `claude-work` రన్ చేయండి. ఫోల్డర్ కొత్తది కాబట్టి Claude Code మిమ్మల్ని లాగిన్ అవ్వమని అడుగుతుంది. అప్పటి నుంచి, `claude` మీ మొదటి ఖాతా, `claude-work` రెండో ఖాతా.

రెండు ఖాతాలకు ఇది బాగా పనిచేస్తుంది. తెలుసుకోవలసిన విషయాలు:

- ప్రతి ఫోల్డర్ ఖాళీగా మొదలవుతుంది: సెట్టింగ్‌లు లేవు, `CLAUDE.md` లేదు, MCP సర్వర్లు లేవు, ఏజెంట్లు లేదా స్కిల్స్ లేవు. మీకు కావలసినవి మీరే కాపీ చేయాలి లేదా లింక్ చేయాలి, కాపీలను మీరే సమకాలీకరించాలి.
- అలియాస్‌లు ఇంటరాక్టివ్ షెల్‌లలో మాత్రమే ఉంటాయి. స్క్రిప్ట్‌లు, Makefile లు, ఇతర ప్రోగ్రామ్‌లు వాటిని చూడలేవు.
- MCP సర్వర్లు లాగిన్ పక్కన `.claude.json` లో ఉంటాయి, కాబట్టి వాటిని ఫోల్డర్‌ల మధ్య నేరుగా లింక్ చేయడం కుదరదు.
- సంభాషణలు అవి మొదలైన ఖాతాలోనే ఉంటాయి, కాబట్టి ఒక సంభాషణను మరో ఖాతాలో కొనసాగించలేరు.
- అన్ని ఖాతాల వినియోగాన్ని ఒకేసారి చూపించేది ఏదీ లేదు.

## ccam తో

ccam అదే ఆలోచనను ఆటోమేట్ చేసి, లేని భాగాలను జోడిస్తుంది:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

ఇప్పుడు `ccam personal`, `ccam work` ఈ రెండు ఖాతాలను ప్రారంభిస్తాయి, work ఖాతాకు మీరు ఇచ్చిన షార్ట్‌కట్ `ccwork` కూడా అలాగే చేస్తుంది. ఇవి అలియాస్‌లు కాకుండా నిజమైన ప్రోగ్రామ్‌లు కాబట్టి, స్క్రిప్ట్‌లలో కూడా పనిచేస్తాయి. సెట్టింగ్‌లు, `CLAUDE.md`, MCP సర్వర్లు, ఎక్స్‌టెన్షన్లు మొదటి నుంచే షేర్ అవుతాయి. షేర్డ్ సంభాషణ చరిత్రను ఆన్ చేసి, `ccam next --continue` తో ఒక సంభాషణను మరో ఖాతాలో కొనసాగించవచ్చు.

మీరు ఇప్పటికే `~/.claude` ఉపయోగిస్తుంటే, ఆ ఖాతాను మళ్లీ జోడించడానికి బదులు `ccam import` రన్ చేయండి, లేదా దాని సెట్టింగ్‌లు, MCP సర్వర్లు, ఎక్స్‌టెన్షన్లను షేర్డ్ సెట్టింగ్‌లలోకి కాపీ చేయడానికి `ccam migrate` రన్ చేయండి.

## దేన్ని ఎంచుకోవాలి

రెండు ఖాతాలకు, ఏమీ షేర్ చేయనవసరం లేకపోతే, అలియాస్ సరిపోతుంది. షేర్డ్ సెట్టింగ్‌లు, MCP సర్వర్లు, ఎక్కువ ఖాతాలు, ఒక్క చూపులో వినియోగం లేదా సంభాషణలను కొనసాగించడం కావాలంటే, ccam ఆ నిర్వహణ పనిని తగ్గిస్తుంది. తేడాలను [పోలిక](/compare/aliases) పక్కపక్కనే చూపిస్తుంది.
