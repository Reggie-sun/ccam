`~/.claude` కు బదులుగా ఏ ఫోల్డర్‌ను ఉపయోగించాలో `CLAUDE_CONFIG_DIR` Claude Code కు చెబుతుంది. ఖాతాకు సంబంధించినవన్నీ అక్కడే ఉంటాయి: లాగిన్, సెట్టింగ్‌లు, MCP సర్వర్లు, ప్లగిన్లు, సంభాషణ చరిత్ర. దీన్ని వేర్వేరు ఫోల్డర్‌లకు సూచిస్తే మీకు వేర్వేరు ఖాతాలు లభిస్తాయి.

```sh
CLAUDE_CONFIG_DIR=~/.claude-work claude
```

## ఫోల్డర్ లోపల ఏమి ఉంటుంది

Claude Code 2.1.302 తో తనిఖీ చేయబడింది:

| పాత్ | విషయాలు | షేర్ చేయవచ్చా |
| --- | --- | --- |
| `.credentials.json` | లాగిన్ టోకెన్‌లు (Linux), MCP OAuth టోకెన్‌లు | లేదు |
| `.claude.json` | ఖాతా వివరాలు, యూజర్ MCP సర్వర్లు, ప్రతి ప్రాజెక్ట్ స్థితి | లేదు (MCP సర్వర్లు వేరుగా) |
| `settings.json` | అనుమతులు, హుక్స్, మోడల్, స్టేటస్ లైన్, ప్లగిన్లు | అవును |
| `CLAUDE.md` | గ్లోబల్ సూచనలు | అవును |
| `agents/`, `commands/`, `skills/`, `plugins/` | ఎక్స్‌టెన్షన్లు | అవును |
| `projects/` | `.jsonl` ఫైళ్లుగా సంభాషణలు, ప్రతి ప్రాజెక్ట్ మెమరీ | అవును |
| `history.jsonl` | ప్రాంప్ట్ చరిత్ర | అవును |
| `sessions/`, `shell-snapshots/`, `cache/`, ఇతరాలు | రన్‌టైమ్ స్థితి | లేదు |

## చాలా మందిని తికమకపెట్టే రెండు విషయాలు

**`CLAUDE_CONFIG_DIR` లేకపోతే, `.claude.json` అనేది `~/.claude` లోపల ఉండదు.** అప్పుడు Claude Code దాన్ని ఫోల్డర్ పక్కన, `~/.claude.json` వద్ద ఉంచుతుంది. మీరు `CLAUDE_CONFIG_DIR=~/.claude` ఉపయోగించడం మొదలుపెడితే, Claude Code బదులుగా `~/.claude/.claude.json` కోసం వెతుకుతుంది, మీ ఖాతా దానికి కనబడదు. `ccam import` ఈ రెండింటినీ లింక్ చేసి దీన్ని పరిష్కరిస్తుంది.

**macOS లో లాగిన్ ఫోల్డర్‌లో కాదు, Keychain లో ఉంటుంది.** Claude Code దాన్ని `Claude Code-credentials` అనే పేరుతో నిల్వ చేస్తుంది; `CLAUDE_CONFIG_DIR` సెట్ చేసి ఉంటే, ఆ పేరు తర్వాత ఫోల్డర్ పాత్ యొక్క చిన్న హాష్ వస్తుంది. కాబట్టి వేర్వేరు ఫోల్డర్‌లకు వేర్వేరు Keychain ఎంట్రీలు ఉంటాయి. Keychain రాయడాన్ని నిరాకరిస్తే, Claude Code బదులుగా ఫోల్డర్‌లోని `.credentials.json` ను ఉపయోగిస్తుంది.

## ఫోల్డర్‌ల మధ్య షేర్ చేయడం

సింబాలిక్ లింక్‌లు పనిచేస్తాయి: Claude Code లింక్ చేసిన `settings.json` లేదా `projects/` ఫోల్డర్ ద్వారా చదువుతుంది, రాస్తుంది, లింక్‌ను అలాగే ఉంచుతుంది. MCP సర్వర్లు దీనికి మినహాయింపు, ఎందుకంటే అవి లాగిన్‌తో పాటు `.claude.json` ను పంచుకుంటాయి; బదులుగా వాటిని `--mcp-config` తో పంపండి.

ccam సరిగ్గా ఈ నియమాలపైనే ఆధారపడి నిర్మించబడింది. అది ఫోల్డర్‌లను ఎలా లింక్ చేస్తుందో [షేరింగ్](/docs/sharing) లో, పూర్తి చిత్రం కోసం [అనేక ఖాతాల గైడ్](/guides/multiple-claude-code-accounts) చూడండి.
