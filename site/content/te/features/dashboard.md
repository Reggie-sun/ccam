స్టాండర్డ్ ఇన్‌పుట్, అవుట్‌పుట్ టెర్మినల్ అయినప్పుడు ఆర్గ్యుమెంట్‌లు లేని `ccam` పూర్తి స్క్రీన్ డాష్‌బోర్డ్‌ను తెరుస్తుంది; లేకపోతే `ccam list` ను ప్రింట్ చేస్తుంది. డాష్‌బోర్డ్ ప్రతి ఖాతాను దాని వినియోగం, గ్రూప్‌లతో చూపిస్తుంది, కమాండ్‌లు చేసే పనులనే చేస్తుంది: ప్రారంభించడం, జోడించడం, లాగిన్ చేయడం, గ్రూప్‌లను మార్చడం, ఫోల్డర్ నియమాలను సెట్ చేయడం, బ్యాక్‌గ్రౌండ్ సెషన్‌లను జాబితా చేయడం, తనిఖీ చేయడం, సరిచేయడం. ప్రారంభించడం, లేదా బ్యాక్‌గ్రౌండ్ సెషన్‌కు అటాచ్ అవ్వడం, దాన్ని మూసివేస్తుంది; ఖాతాను జోడించడం లేదా లాగిన్ చేయడం టెర్మినల్ కోసం దాన్ని వదిలి, తర్వాత తిరిగి వస్తుంది.

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Agents   Groups   Folders   Extensions   Health    auto_switch off
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

ట్యాబ్ పేర్ల కింది లైన్ ప్రస్తుత ట్యాబ్ దేనికోసమో ఒక వాక్యంలో చెబుతుంది. వెడల్పైన టెర్మినల్‌లో Accounts ట్యాబ్ ప్రతి ఖాతా ఇమెయిల్‌ను కూడా చూపిస్తుంది. [`auto_switch`](/features/next#auto-switch) ఆన్‌లో ఉందో లేదో ట్యాబ్ లైన్ చివర ప్రతి ట్యాబ్‌లోనూ చెబుతుంది (Linux, macOS; Windows లో అది విస్మరించబడుతుంది); అది ఆన్‌లో ఉన్నప్పుడు, దానికి ఇంకా ఏమి కావాలో Health ట్యాబ్ చెబుతుంది: Claude సబ్‌స్క్రిప్షన్‌తో లాగిన్ అయ్యే ప్రతి ఖాతాలో ఆన్‌లో ఉన్న ccam ప్లగిన్, అలాగే Claude Code 2.1.214 లేదా తర్వాతి వెర్షన్.

తెరుచుకున్న ప్రతిసారీ, కొత్త ccam రిలీజ్ ఉందో లేదో డాష్‌బోర్డ్ బ్యాక్‌గ్రౌండ్‌లో GitHub ను అడుగుతుంది; మొదటి ఫ్రేమ్ దాని కోసం ఎప్పుడూ ఆగదు, ఆఫ్‌లైన్‌లో ఏమీ చూపించదు. కొత్త రిలీజ్ ఉంటే, శీర్షిక కింద ఒక లైన్ దాన్ని సిఫార్సు చేస్తుంది:

```console
 ● ccam 0.10.2 is available (you have 0.10.1) · press U to update
```

`U` ముందుగా అడిగి, తర్వాత [`ccam update`](/features/update) చేసే విధంగానే అప్‌డేట్ చేస్తుంది: రిలీజ్‌ను దాని SHA-256 checksums తో తనిఖీ చేసి, ఒకే దశలో ccam ను భర్తీ చేస్తుంది. మీరు ఉన్న డాష్‌బోర్డ్ ఇంకా పాత వెర్షనే, కాబట్టి నిష్క్రమించి `ccam` ను మళ్లీ ప్రారంభించండి. అప్‌డేట్ ఇక్కడ చేయలేనప్పుడు, ఉదాహరణకు `.deb` ప్యాకేజీ నుంచి ఇన్‌స్టాల్ చేసిన ccam కు, డాష్‌బోర్డ్ `ccam update` ఇచ్చే అదే సలహాను చూపించి, ఆఫర్‌ను అలాగే ఉంచుతుంది.

మొదటి ఫ్రేమ్ `config.toml` నుంచి మాత్రమే, 100 ms కంటే చాలా తక్కువ సమయంలో గీయబడుతుంది; ప్రతి ఖాతా సమాధానం ఇచ్చినప్పుడు వినియోగం నిండుతుంది. ప్రతి పరిమితికి సొంత బార్ ఉంటుంది: 5 గంటల విండో, అన్ని మోడళ్ల వారపు విండో, Fable సొంత వారపు విండో; `-` అంటే ఖాతాకు అలాంటి విండో లేదు. శాతం 80% నుంచి పసుపు రంగులోకి, 100% వద్ద ఎరుపు రంగులోకి మారుతుంది, విఫలమైన లుకప్ తర్వాత కాష్ నుంచి వచ్చిన విలువలు మసకగా గీయబడతాయి. Claude Code నిండిందని నివేదించిన విండో దాని రీసెట్ వరకు 100% చూపిస్తుంది. గడువు ముగిసిన యాక్సెస్ టోకెన్ మసకగా `⚠ token expired` అని చూపిస్తుంది (తదుపరి ప్రారంభంలో Claude Code దాన్ని రెన్యూ చేస్తుంది), అయితే `⚠ login expired` అంటే ఆ ఖాతాకు `ccam login` అవసరం.

## ట్యాబ్‌లు

| ట్యాబ్ | ఏమి చూపిస్తుంది | కీలు |
| --- | --- | --- |
| Accounts | నంబర్, పేరు, ఇమెయిల్, 5 గంటల, వారపు, Fable బార్‌లు, చివరి వినియోగం, గ్రూప్‌లు; `✔` డిఫాల్ట్, `▸` ఈ ఫోల్డర్ ఖాతా, `•` రన్ అవుతున్నది (ccam లేకుండా ప్రారంభించిన Claude Code కూడా: సాధారణ `claude`, ఒక IDE, బ్యాక్‌గ్రౌండ్ సెషన్‌లు, వాటి daemon) | కింద చూడండి |
| Agents | [`ccam agents`](/features/agents) జాబితా చేసేది: ప్రతి ఖాతా బ్యాక్‌గ్రౌండ్ సెషన్‌లు, తెరిచి ఉన్న సెషన్‌లు, వాటి స్థితి, ఫోల్డర్, ప్రారంభ సమయంతో (కింద చూడండి) | `enter` అటాచ్ (`ccam attach` లాగా), `x` ఆపడం, `r` మళ్లీ లోడ్ |
| Groups | ప్రతి గ్రూప్, అది ఏమి షేర్ చేస్తుంది, దాని ఖాతాలు, ఏ గ్రూప్‌లోనూ లేని ఖాతాలు | `enter` ఎడిట్, `n` కొత్తది, `e` పేరు మార్పు, `x` తీసివేత |
| Folders | [`ccam folder`](/features/folder) నియమాలు, ఇక్కడ వర్తించే నియమం, మీరు సింబాలిక్ లింక్ ద్వారా ఫోల్డర్‌కు చేరుకున్నప్పుడు కూడా (కొత్త నియమాలు లింక్‌లను పరిష్కరించి నిల్వ అవుతాయి) | `n` ఇక్కడ ఒక ఖాతాను ఉపయోగించు, `enter` మార్పు, `x` తీసివేత |
| Extensions | [`ccam ext`](/features/ext) చూపించేది, ప్రతి ఎక్స్‌టెన్షన్ ఒక్కసారి, అది వచ్చే గ్రూప్‌లతో, `off:` ఒక ప్లగిన్ ఆన్ చేయని ఖాతాలు, ఒక ఖాతా సొంత సర్వర్లలో ఈ ఫోల్డర్ కోసం మాత్రమే ఉన్నవి, `This folder's project`, ఏ ఖాతాకూ చెందని సమస్యలు | `r` మళ్లీ లోడ్ |
| Health | [`ccam doctor`](/features/doctor) నివేదించేది, ప్రతి ఖాతాకు ఒక బాక్స్‌గా (కింద చూడండి) | `f` ఎంచుకున్న బాక్స్‌ను సరిచేయడం, `F` అన్నింటినీ సరిచేయడం (`doctor --fix`), `↑`/`↓` బాక్స్‌ల మధ్య కదలిక |

`←`/`→` లేదా `Tab` ట్యాబ్‌లను మారుస్తాయి, `?` ప్రస్తుత ట్యాబ్ కీలను జాబితా చేస్తుంది, `r` చిన్న కాష్ లేకుండా వినియోగాన్ని మళ్లీ చూస్తుంది, Agents, Extensions, Health ట్యాబ్‌లను మళ్లీ లోడ్ చేస్తుంది, `q` లేదా `Esc` నిష్క్రమిస్తుంది.

| --- | --- |

| `1`–`9` | ఆ నంబర్ ఉన్న ఖాతాకు వెళ్తుంది; 12 కోసం `1` `2` ను వేగంగా టైప్ చేయండి. `Enter` మాత్రమే ప్రారంభిస్తుంది |
| `↑`/`↓`, `k`/`j` | కదిలిస్తుంది |
| `n` | [`ccam next --auto`](/features/next) ఎంచుకునే ఖాతాను ప్రారంభిస్తుంది |
| `o` | ఆప్షన్లతో ప్రారంభిస్తుంది: `--continue`, `--resume`, ఇతర ఆర్గ్యుమెంట్‌లు, లేదా డ్రై రన్ |
| `u` | వినియోగ వివరాలు: 5 గంటల, వారపు, మోడల్ విండోలు, వాటి రీసెట్‌లు, సంఖ్యలు ఎక్కడి నుంచి వచ్చాయో |
| `a` | ఒక ఖాతాను జోడిస్తుంది (కింద ఉన్న విజార్డ్) |
| `l` | మళ్లీ లాగిన్ చేస్తుంది |
| `s` | ఖాతా గ్రూప్‌లను ఎంచుకుంటుంది |
| `d` | దాన్ని డిఫాల్ట్ ఖాతాగా చేస్తుంది |
| `f` | దాన్ని ప్రస్తుత ఫోల్డర్‌లో ఉపయోగిస్తుంది |
| `e` | దాని పేరు మారుస్తుంది |
| `c` | దాని షార్ట్‌కట్ కమాండ్‌ను సెట్ చేస్తుంది లేదా తీసివేస్తుంది |
| `x` | దాన్ని తీసివేస్తుంది (ముందుగా అడుగుతుంది, No పై మొదలవుతుంది) |

**Team, Enterprise సీట్లు.** ఆటోమేటిక్ ఎంపిక (`ccam next`, `--fallback`, `ccam pick`, డాష్‌బోర్డ్‌లోని `n`, మీరు ఆన్ చేసినప్పుడు [`auto_switch`](/features/next#auto-switch)) ఒకే Claude Team లేదా Enterprise సంస్థలోని సీట్ల మధ్య కూడా మారుస్తుంది. Anthropic సహాయ కేంద్రం "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (Team ప్లాన్‌లోని ప్రతి సీటు పేరుతో నిర్దేశించిన ఒక వ్యక్తికి కేటాయించబడుతుంది, ఆ వ్యక్తి మాత్రమే దాన్ని ఉపయోగించవచ్చు) అని, "Users can't route their work through another user's account to use that user's remaining usage" (యూజర్లు మరో యూజర్‌కు మిగిలి ఉన్న వినియోగాన్ని వాడుకోవడానికి తమ పనిని ఆ యూజర్ ఖాతా ద్వారా మళ్లించకూడదు) అని చెబుతుంది ([Team ప్లాన్‌లు](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129); [Enterprise ప్లాన్‌లకు](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) కూడా ఇదే వర్తిస్తుంది). కాబట్టి సీట్ల మధ్య ఆటోమేటిక్ ఎంపికను ఉపయోగించడం Anthropic నిబంధనల ఉల్లంఘన కావచ్చు. అక్కడ దాన్ని ఉపయోగించాలా వద్దా అనేది మీ నిర్ణయం: దానిపై ఆధారపడే ముందు మీ సంస్థను, Anthropic ను సంప్రదించి నిర్ధారించుకోండి. వ్యక్తిగత ప్లాన్‌ల (Pro, Max) గురించి [తరచుగా అడిగే ప్రశ్నలలోని నిబంధనల గమనిక](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) చెబుతుంది.

## Health ట్యాబ్

Health ట్యాబ్ మీరు దాన్ని తెరిచినప్పుడు [`ccam doctor`](/features/doctor) తనిఖీలను రన్ చేసి అదే వీక్షణను గీస్తుంది: ప్రతి ఖాతాకు ఒక గుర్తుతో మొదటి లైన్, తర్వాత ప్రతి ఖాతాకు ఒక బాక్స్. బాక్స్‌లోని ప్రతి వరుస తనిఖీ చేసిన ఒక విభాగం, ముందుగా `Folder`, `Login`, `Share links`, `✔` సరే, `ℹ` సమాచారం, `⚠` హెచ్చరిక లేదా `✘` ఎర్రర్‌తో గుర్తించబడి ఉంటుంది, కాబట్టి ఏ ఖాతాకు సమస్య ఉందో, ఎక్కడ ఉందో మీకు వెంటనే కనిపిస్తుంది. ఏ ఖాతాకూ చెందని ఫలితాలు ఒక `General` బాక్స్‌లోకి వెళ్తాయి.

```console
 ✘ personal   ⚠ work

 ╭─ ✘ personal · 3 problems ─────────────────────────────────────────────────╮
 │ ⚠ Folder       folder permissions are 755 (should be 0700)                │
 │ ℹ              unknown entries (ccam knows the folder layout of Claude    │
 │                Code 2.1.309; it may have changed): newthing               │
 │ ⚠ Login        .credentials.json permissions are 644 (should be 0600)     │
 │ ✔              login valid (me@example.com, Claude Team · Acme)           │
 │ ✘ Share links  /home/me/.local/share/ccam/profiles/personal/settings.json │
 │                : set to shared but is a real file, not a link             │
 │ ✔ Usage        usage lookup OK                                            │
 ╰───────────────────────────────────────────────────────────────────────────╯
 ╭─ ⚠ work · 1 problem ──────────────────────────────────────────────────────╮
 │ ✔ Folder       OK                                                         │
 │ ⚠ Login        not logged in → `ccam login work`                          │
 │ ✔ Share links  share links OK                                             │
 ╰───────────────────────────────────────────────────────────────────────────╯

 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` ఒక బాక్స్ నుంచి మరో బాక్స్‌కు కదిలిస్తాయి, ఎంచుకున్న బాక్స్‌కు యాక్సెంట్ రంగు అంచు ఉంటుంది. `f` ఎంచుకున్న బాక్స్‌ను మాత్రమే సరిచేస్తుంది, `ccam doctor --fix` చేసే విధంగానే: ఒక ఖాతా బాక్స్‌పై ఆ ఖాతాను మాత్రమే సరిచేస్తుంది, `General` బాక్స్‌పై ఏ ఖాతాకూ చెందని ఫలితాలను (ప్లగిన్ పాత్‌లు, షార్ట్‌కట్‌లు); మిగతా ప్రతి ఖాతా మళ్లీ తనిఖీ మాత్రమే అవుతుంది. ఇది ముందుగా అడుగుతుంది (``Like `ccam doctor --fix`: missing links and group folders are made, and a real file where a link belongs is backed up first; where the group has its own copy, the account then sees the group's. Nothing is lost.``), సరిచేయాల్సింది ఏమీ లేని బాక్స్ కేవలం `nothing to repair in <name>` అని చెబుతుంది. `F` అన్నింటినీ ఒకేసారి సరిచేస్తుంది, `ccam doctor --fix` లాగా; `r` మళ్లీ తనిఖీ చేస్తుంది.

## Agents ట్యాబ్

Agents ట్యాబ్ [`ccam agents`](/features/agents) ప్రింట్ చేసేదాన్ని చూపిస్తుంది: ప్రతి ఖాతా బ్యాక్‌గ్రౌండ్ సెషన్‌లు, తెరిచి ఉన్న సెషన్‌లు, ఒక్కొక్కటి ఏ ఖాతాకు చెందినదో దానితో సహా. మీరు ట్యాబ్‌ను మొదటిసారి తెరిచినప్పుడు, `r` నొక్కినప్పుడు, ఒక సెషన్‌ను ఆపిన తర్వాత, config మారిన తర్వాత అది ప్రతి ఖాతా Claude Code ను ఒకేసారి అడుగుతుంది (`claude agents --json`, ఒక్కోదానికి గరిష్ఠంగా 15 సెకన్లు), అన్నీ సమాధానం ఇచ్చే వరకు `Asking every account's Claude Code for its sessions…` అని చూపిస్తుంది.

```console
  Accounts   Agents   Groups   Folders   Extensions   Health    auto_switch off
 Background agents and open sessions of every account; enter attaches to one.

    Account   ID        Name   State          Folder      Started
 ❯  work      -         -      open (busy)    ~/code/web  now
    personal  49ec0028  probe  blocked, idle  ~/code/app  12m

 ✘ lab: could not list its sessions: exit status 1 'claude agents --json' is
   not available in this environment.

 enter to attach · x to stop · r to reload · ? for shortcuts
```

`ccam agents` లో లాగే, `State` అనేది బ్యాక్‌గ్రౌండ్ సెషన్ స్థితి, దాని ప్రాసెస్ ఏమి చేస్తోందో, లేదా ఇంటరాక్టివ్ సెషన్‌కు `open`. అడగలేకపోయిన ఖాతాకు జాబితా కింద Claude Code చెప్పినదానితో ఒక `✘` లైన్ వస్తుంది, పైన ఉన్న `lab` లాగా, దాని agent view ఆఫ్‌లో ఉంది. పూర్తయిన బ్యాక్‌గ్రౌండ్ సెషన్‌లు వదిలేయబడతాయి (`ccam agents --all` వాటిని జాబితా చేస్తుంది), ప్రతి ఖాతా సమాధానం ఇచ్చి, దేనికీ సెషన్ లేనప్పుడు ట్యాబ్ ``No sessions. Start one in the background with `ccam <account> --bg "…"`.`` అని చెబుతుంది. ఇరుకైన టెర్మినల్‌లో ట్యాబ్ ముందుగా `Started` ను, తర్వాత `Name` ను, తర్వాత `Folder` ను తీసేస్తుంది, పొడవైన ఫోల్డర్‌ను ఎడమ వైపు నుంచి కత్తిరిస్తుంది.

బ్యాక్‌గ్రౌండ్ సెషన్‌పై `Enter` డాష్‌బోర్డ్‌ను మూసివేసి, `ccam attach <id>` లాగే, ఆ సెషన్‌ను దాని ఖాతాగా ఈ టెర్మినల్‌లో తెరుస్తుంది; డాష్‌బోర్డ్ తిరిగి రాదు (Claude Code లో, `←` దాని agent view కు, `Ctrl+Z` షెల్‌కు వెళ్తాయి). తెరిచి ఉన్న సెషన్‌కు id ఉండదు, కాబట్టి `Enter`, `x` బ్యాక్‌గ్రౌండ్ సెషన్ అవసరమని మాత్రమే చెబుతాయి. `x` ముందుగా అడుగుతుంది, `No, keep it` పై మొదలవుతుంది: ``It runs as personal. Like `ccam personal stop 49ec0028`, Claude Code stops it and keeps its conversation, which `ccam attach 49ec0028` opens again.`` అవును అంటే, ccam ఆ ఖాతాగా `claude stop <id>` ను రన్ చేసి, ``49ec0028 (personal) stopped; `ccam attach 49ec0028` opens it again`` అని లేదా ఎందుకు ఆపలేకపోయిందో చెప్పి, జాబితాను మళ్లీ చదువుతుంది.

## గ్రూప్‌లను మార్చడం

Groups ట్యాబ్‌లో, `Enter` ఎడిటర్‌ను తెరుస్తుంది: ఎడమవైపు అంశాలు, కుడివైపు ఖాతాలు, మారడానికి `Tab`, టిక్ మార్చడానికి `Space`. ఖాతాలలో ఒకదానికి ఇప్పటికే మరో గ్రూప్ నుంచి అందుతున్న అంశం కారణంతో సహా బూడిద రంగులో చూపబడుతుంది, ఒక అంశాన్ని రెండుసార్లు పొందే ఖాతా కూడా అలాగే; ఒక అంశం ఒకే గ్రూప్ నుంచి మాత్రమే రాగలదు. `Enter` ప్రణాళికను చూపిస్తుంది:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

గ్రూప్ కాపీ నుంచి వేరుగా ఉన్న ఫైల్ గురించి ముందుగా అడుగుతుంది (గ్రూప్‌దాన్ని ఉంచడం, నాదాన్ని ఉపయోగించడం, లేదా మెర్జ్ చేయడం). ఆపై మార్పు [`ccam group`](/features/share) ఉపయోగించే అదే కోడ్‌తో బ్యాక్‌గ్రౌండ్‌లో రన్ అవుతుంది: ముందుగా కాన్ఫిగ్ సేవ్ అవుతుంది, ప్రతి ఖాతా డేటా క్రమంగా తరలుతుంది, అసలు ఫైళ్లు `.ccam-backup/` కు వెళ్తాయి; MCP షేరింగ్ నుంచి బయటకు వెళ్లే ఖాతా గ్రూప్ సర్వర్లను తన `.claude.json` లో ఉంచుకుంటుంది. రన్ అవుతున్న ఖాతా డేటాను తరలించే మార్పు ఆ ఖాతా పేరుతో తిరస్కరించబడుతుంది, ప్లాన్ తెరిచి ఉన్నప్పుడు ఖాతా ప్రారంభమైనా కూడా; మరో ccam చేసిన గ్రూప్‌ల మార్పు వల్ల పాతబడిన ప్లాన్ `the groups changed while this plan waited; nothing was moved, make the change again` తో తిరస్కరించబడుతుంది. మరో ccam గ్రూప్‌లను మారుస్తున్నప్పుడు, కొత్త మార్పు, పేరు మార్పు లేదా తీసివేత `another ccam is changing the groups right now` అని చెబుతాయి; మధ్యలో ఆగిపోయిన మార్పు తర్వాత, Health ట్యాబ్‌లోని `F` (లేదా `ccam doctor --fix`) దాన్ని పూర్తి చేసే వరకు అవి వేచి ఉంటాయి.

## ఖాతాను జోడించడం

`a` టెర్మినల్‌లో `ccam add` కూడా ఉపయోగించే విజార్డ్‌ను తెరుస్తుంది:

1. ఖాతా పేరు.
2. అది ఎలా సైన్ ఇన్ అవుతుంది: ఇప్పుడే Claude సబ్‌స్క్రిప్షన్ (బ్రౌజర్‌లో), ఒక [API కీ](/features/api), లేదా తర్వాత Claude సబ్‌స్క్రిప్షన్.
3. API కీ కోసం: ప్రతి ప్రారంభంలో ccam కీని ఎక్కడి నుంచి చదువుతుంది (`env:NAME` లేదా `command:COMMAND`), ఎండ్‌పాయింట్, కీ ఎలా పంపబడుతుంది, మోడల్.
4. చేరాల్సిన గ్రూప్‌లు, `default` టిక్ చేసి; గ్రూప్‌లు ఇంకా లేకపోతే, `default` గ్రూప్ ఏమి షేర్ చేస్తుందో.
5. మీకు కావాలంటే, ఒక షార్ట్‌కట్ కమాండ్.
6. నిర్ధారించడానికి ఒక సారాంశం.

`Esc` ఒక దశ వెనక్కి వెళ్తుంది, మొదటి దశలో విజార్డ్‌ను మూసివేస్తుంది.

## ఖాతాను తీసివేయడం

`x` ఏదైనా జరిగే ముందు అడుగుతుంది, No పై మొదలవుతుంది, తీసివేత ఏమి చేస్తుందో చెబుతుంది: `It is logged out first (its login is revoked), then its folder goes to ccam's trash; the groups' shared files stay.` API కీ ఖాతాకు రద్దు చేయడానికి లాగిన్ ఉండదు, మరో ఖాతా అదే లాగిన్‌ను కలిగి ఉన్నప్పుడు అది లాగ్ అవుట్ అవ్వదు. ఇంపోర్ట్ చేసిన ఖాతా తన ఫోల్డర్‌ను ఉంచుకుంటుంది: `It was imported, so its folder /home/me/.claude stays where it is: it leaves its groups first and keeps a copy of what they share, then ccam forgets it.`

## రంగులు

రంగులు Claude Code టెర్మినల్ UI పాత్రలను అనుసరిస్తాయి, కాబట్టి ccam దాని పక్కన సహజంగా కనిపిస్తుంది; గ్రూప్ పేర్లకు వాటి పేరు నుంచి ఒక రంగు వస్తుంది. ccam టెర్మినల్‌ను దాని బ్యాక్‌గ్రౌండ్ గురించి అడిగి, లైట్ లేదా డార్క్ థీమ్‌ను ఎంచుకుంటుంది. `config.toml` పైభాగంలో, మొదటి `[[group]]`, `[[profile]]` లేదా `[[folder]]` కంటే పైన, మీరే ఒకటి సెట్ చేయండి:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` థీమ్‌లు ఎరుపు-ఆకుపచ్చ వర్ణాంధత్వం కోసం, `-ansi` థీమ్‌లు టెర్మినల్ సొంత 16 రంగులను ఉపయోగిస్తాయి. `NO_COLOR` రంగులను ఆపివేస్తుంది.

## భద్రత, ప్రత్యేక సందర్భాలు

- డాష్‌బోర్డ్ కమాండ్‌లు పిలిచే అవే ఫంక్షన్‌లను పిలుస్తుంది, కాబట్టి ప్రతి నియమం వర్తిస్తుంది: డేటా తరలే ముందు ప్రణాళికలు, రన్ అవుతున్న ఖాతాలకు తిరస్కరణలు, బ్యాకప్‌లు, ఖాతాను ఎప్పుడూ విడిచిపెట్టని లాగిన్ టోకెన్‌లు.
- డాష్‌బోర్డ్‌కు డ్రై రన్ లేదు: పేరు లేకుండా `ccam --dry-run` ఈ ఫోల్డర్ ఖాతా ఎలా ప్రారంభమవుతుందో ప్రింట్ చేస్తుంది, ఒక ఖాతాపై `o` ఆ ఒక్క ప్రారంభానికి డ్రై రన్‌ను అందిస్తుంది.
- Claude Code ప్రారంభమయ్యే ముందు లేదా లాగిన్ తెరుచుకునే ముందు టెర్మినల్ పునరుద్ధరించబడుతుంది.
- డైలాగ్‌కు సరిపడని చిన్న స్క్రీన్ ముందుగా ట్యాబ్ వరుసలను వదిలేస్తుంది; లైన్లు చుట్టబడకుండా `…` తో కత్తిరించబడతాయి. తక్కువ ఎత్తు ఉన్న స్క్రీన్‌పై ఆ తర్వాత ఖాళీ లైన్లు, ట్యాబ్ వివరణ పోతాయి, కాబట్టి కీల లైన్ అలాగే ఉంటుంది. 40 కాలమ్‌లు లేదా 8 వరుసల కంటే తక్కువ ఉంటే డాష్‌బోర్డ్ `Too small: ccam needs 40x8 (now 36x7)` మాత్రమే చూపిస్తుంది.
- ఒక మార్పు, తీసివేత, అప్‌డేట్ లేదా రిపేర్ వర్తింపజేయబడుతున్నప్పుడు `Ctrl+C` అది పూర్తయ్యే వరకు వేచి ఉంటుంది: స్టేటస్ లైన్ `ccam quits when it is done.` అని చెబుతుంది.
- `U` ccam ను అప్‌డేట్ చేసిన తర్వాత, ఖాతాను జోడించడం లేదా లాగిన్ నుంచి డాష్‌బోర్డ్ తిరిగి వచ్చినప్పుడు ఆఫర్ మళ్లీ రాదు.
