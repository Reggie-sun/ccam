స్టాండర్డ్ ఇన్‌పుట్, అవుట్‌పుట్ టెర్మినల్ అయినప్పుడు ఆర్గ్యుమెంట్‌లు లేని `ccam` పూర్తి స్క్రీన్ డాష్‌బోర్డ్‌ను తెరుస్తుంది; లేకపోతే `ccam list` ను ప్రింట్ చేస్తుంది. డాష్‌బోర్డ్ ప్రతి ఖాతాను దాని వినియోగం, గ్రూప్‌లతో చూపిస్తుంది, కమాండ్‌లు చేసే పనులనే చేస్తుంది: ప్రారంభించడం, జోడించడం, లాగిన్ చేయడం, గ్రూప్‌లను మార్చడం, ఫోల్డర్ నియమాలను సెట్ చేయడం, తనిఖీ చేయడం, సరిచేయడం. ప్రారంభించడం దాన్ని మూసివేస్తుంది; ఖాతాను జోడించడం లేదా లాగిన్ చేయడం టెర్మినల్ కోసం దాన్ని వదిలి, తర్వాత తిరిగి వస్తుంది.

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

ట్యాబ్ పేర్ల కింది లైన్ ప్రస్తుత ట్యాబ్ దేనికోసమో ఒక వాక్యంలో చెబుతుంది. వెడల్పైన టెర్మినల్‌లో Accounts ట్యాబ్ ప్రతి ఖాతా ఇమెయిల్‌ను కూడా చూపిస్తుంది.

తెరుచుకున్న ప్రతిసారీ, కొత్త ccam రిలీజ్ ఉందో లేదో డాష్‌బోర్డ్ బ్యాక్‌గ్రౌండ్‌లో GitHub ను అడుగుతుంది; మొదటి ఫ్రేమ్ దాని కోసం ఎప్పుడూ ఆగదు, ఆఫ్‌లైన్‌లో ఏమీ చూపించదు. కొత్త రిలీజ్ ఉంటే, శీర్షిక కింద ఒక లైన్ దాన్ని సిఫార్సు చేస్తుంది:

```console
 ● ccam 0.10.2 is available (you have 0.10.1) · press U to update
```

`U` ముందుగా అడిగి, తర్వాత [`ccam update`](/features/update) చేసే విధంగానే అప్‌డేట్ చేస్తుంది: రిలీజ్‌ను దాని SHA-256 checksums తో తనిఖీ చేసి, ఒకే దశలో ccam ను భర్తీ చేస్తుంది. మీరు ఉన్న డాష్‌బోర్డ్ ఇంకా పాత వెర్షనే, కాబట్టి నిష్క్రమించి `ccam` ను మళ్లీ ప్రారంభించండి. అప్‌డేట్ ఇక్కడ చేయలేనప్పుడు, ఉదాహరణకు `.deb` ప్యాకేజీ నుంచి ఇన్‌స్టాల్ చేసిన ccam కు, డాష్‌బోర్డ్ `ccam update` ఇచ్చే అదే సలహాను చూపించి, ఆఫర్‌ను అలాగే ఉంచుతుంది.

మొదటి ఫ్రేమ్ `config.toml` నుంచి మాత్రమే, 100 ms కంటే చాలా తక్కువ సమయంలో గీయబడుతుంది; ప్రతి ఖాతా సమాధానం ఇచ్చినప్పుడు వినియోగం నిండుతుంది. ప్రతి పరిమితికి సొంత బార్ ఉంటుంది: 5 గంటల విండో, అన్ని మోడళ్ల వారపు విండో, Fable సొంత వారపు విండో; `-` అంటే ఖాతాకు అలాంటి విండో లేదు. శాతం 80% నుంచి పసుపు రంగులోకి, 100% వద్ద ఎరుపు రంగులోకి మారుతుంది, విఫలమైన లుకప్ తర్వాత కాష్ నుంచి వచ్చిన విలువలు మసకగా గీయబడతాయి.

## Health ట్యాబ్

Health ట్యాబ్ మీరు దాన్ని తెరిచినప్పుడు [`ccam doctor`](/features/doctor) తనిఖీలను రన్ చేసి అదే వీక్షణను గీస్తుంది: ప్రతి ఖాతాకు ఒక గుర్తుతో మొదటి లైన్, తర్వాత ప్రతి ఖాతాకు ఒక బాక్స్. బాక్స్‌లోని ప్రతి వరుస తనిఖీ చేసిన ఒక విభాగం, ముందుగా `Folder`, `Login`, `Share links`, `✔` సరే, `ℹ` సమాచారం, `⚠` హెచ్చరిక లేదా `✘` ఎర్రర్‌తో గుర్తించబడి ఉంటుంది, కాబట్టి ఏ ఖాతాకు సమస్య ఉందో, ఎక్కడ ఉందో మీకు వెంటనే కనిపిస్తుంది. ఏ ఖాతాకూ చెందని ఫలితాలు ఒక `General` బాక్స్‌లోకి వెళ్తాయి.

```console
 ✘ personal   ⚠ work

 ╭─ ✘ personal · 3 problems ──────────────────────────────────────────────────╮
 │ ⚠ Folder       folder permissions are 755 (should be 0700)                 │
 │ ℹ              unknown entries (Claude Code layout may have changed):      │
 │                newthing                                                    │
 │ ⚠ Login        .credentials.json permissions are 644 (should be 0600)      │
 │ ✔              login valid (me@example.com)                                │
 │ ✘ Share links  /home/me/.local/share/ccam/profiles/personal/settings.json: │
 │                set to shared but is a real file, not a link                │
 ╰────────────────────────────────────────────────────────────────────────────╯
 ╭─ ⚠ work · 1 problem ───────────────────────────────────────────────────────╮
 │ ✔ Folder       OK                                                          │
 │ ⚠ Login        not logged in → `ccam login work`                           │
 │ ✔ Share links  share links OK                                              │
 ╰────────────────────────────────────────────────────────────────────────────╯

 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` ఒక బాక్స్ నుంచి మరో బాక్స్‌కు కదిలిస్తాయి, ఎంచుకున్న బాక్స్‌కు యాక్సెంట్ రంగు అంచు ఉంటుంది. `f` ఎంచుకున్న బాక్స్‌ను మాత్రమే సరిచేస్తుంది, `ccam doctor --fix` చేసే విధంగానే: ఒక ఖాతా బాక్స్‌పై ఆ ఖాతాను మాత్రమే సరిచేస్తుంది, `General` బాక్స్‌పై ఏ ఖాతాకూ చెందని ఫలితాలను (ప్లగిన్ పాత్‌లు, షార్ట్‌కట్‌లు); మిగతా ప్రతి ఖాతా మళ్లీ తనిఖీ మాత్రమే అవుతుంది. ఇది ముందుగా అడుగుతుంది, సరిచేయాల్సింది ఏమీ లేని బాక్స్ కేవలం `nothing to repair in <name>` అని చెబుతుంది. `F` అన్నింటినీ ఒకేసారి సరిచేస్తుంది, `ccam doctor --fix` లాగా; `r` మళ్లీ తనిఖీ చేస్తుంది.

## గ్రూప్‌లను మార్చడం

Groups ట్యాబ్‌లో, `Enter` ఎడిటర్‌ను తెరుస్తుంది: ఎడమవైపు అంశాలు, కుడివైపు ఖాతాలు, మారడానికి `Tab`, టిక్ మార్చడానికి `Space`. ఖాతాలలో ఒకదానికి ఇప్పటికే మరో గ్రూప్ నుంచి అందుతున్న అంశం కారణంతో సహా బూడిద రంగులో చూపబడుతుంది, ఒక అంశాన్ని రెండుసార్లు పొందే ఖాతా కూడా అలాగే; ఒక అంశం ఒకే గ్రూప్ నుంచి మాత్రమే రాగలదు. `Enter` ప్రణాళికను చూపిస్తుంది:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

గ్రూప్ కాపీ నుంచి వేరుగా ఉన్న ఫైల్ గురించి ముందుగా అడుగుతుంది (గ్రూప్‌దాన్ని ఉంచడం, నాదాన్ని ఉపయోగించడం, లేదా మెర్జ్ చేయడం). ఆపై మార్పు [`ccam group`](/features/share) ఉపయోగించే అదే కోడ్‌తో బ్యాక్‌గ్రౌండ్‌లో రన్ అవుతుంది: ముందుగా కాన్ఫిగ్ సేవ్ అవుతుంది, ప్రతి ఖాతా డేటా క్రమంగా తరలుతుంది, అసలు ఫైళ్లు `.ccam-backup/` కు వెళ్తాయి. రన్ అవుతున్న ఖాతా డేటాను తరలించే మార్పు ఆ ఖాతా పేరుతో తిరస్కరించబడుతుంది.

## ఖాతాను జోడించడం

`a` టెర్మినల్‌లో `ccam add` కూడా ఉపయోగించే విజార్డ్‌ను తెరుస్తుంది:

1. ఖాతా పేరు.
2. అది ఎలా సైన్ ఇన్ అవుతుంది: ఇప్పుడే Claude సబ్‌స్క్రిప్షన్ (బ్రౌజర్‌లో), ఒక [API కీ](/features/api), లేదా తర్వాత Claude సబ్‌స్క్రిప్షన్.
3. API కీ కోసం: ప్రతి ప్రారంభంలో ccam కీని ఎక్కడి నుంచి చదువుతుంది (`env:NAME` లేదా `command:COMMAND`), ఎండ్‌పాయింట్, కీ ఎలా పంపబడుతుంది, మోడల్.
4. చేరాల్సిన గ్రూప్‌లు, `default` టిక్ చేసి; గ్రూప్‌లు ఇంకా లేకపోతే, `default` గ్రూప్ ఏమి షేర్ చేస్తుందో.
5. మీకు కావాలంటే, ఒక షార్ట్‌కట్ కమాండ్.
6. నిర్ధారించడానికి ఒక సారాంశం.

`Esc` ఒక దశ వెనక్కి వెళ్తుంది, మొదటి దశలో విజార్డ్‌ను మూసివేస్తుంది.

## రంగులు

రంగులు Claude Code టెర్మినల్ UI పాత్రలను అనుసరిస్తాయి, కాబట్టి ccam దాని పక్కన సహజంగా కనిపిస్తుంది; గ్రూప్ పేర్లకు వాటి పేరు నుంచి ఒక రంగు వస్తుంది. ccam టెర్మినల్‌ను దాని బ్యాక్‌గ్రౌండ్ గురించి అడిగి, లైట్ లేదా డార్క్ థీమ్‌ను ఎంచుకుంటుంది. `config.toml` లో మీరే ఒకటి సెట్ చేయండి:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` థీమ్‌లు ఎరుపు-ఆకుపచ్చ వర్ణాంధత్వం కోసం, `-ansi` థీమ్‌లు టెర్మినల్ సొంత 16 రంగులను ఉపయోగిస్తాయి. `NO_COLOR` రంగులను ఆపివేస్తుంది.

## భద్రత, ప్రత్యేక సందర్భాలు

- డాష్‌బోర్డ్ కమాండ్‌లు పిలిచే అవే ఫంక్షన్‌లను పిలుస్తుంది, కాబట్టి ప్రతి నియమం వర్తిస్తుంది: డేటా తరలే ముందు ప్రణాళికలు, రన్ అవుతున్న ఖాతాలకు తిరస్కరణలు, బ్యాకప్‌లు, ఖాతాను ఎప్పుడూ విడిచిపెట్టని లాగిన్ టోకెన్‌లు.
- డాష్‌బోర్డ్‌కు డ్రై రన్ లేదు: పేరు లేకుండా `ccam --dry-run` ఈ ఫోల్డర్ ఖాతా ఎలా ప్రారంభమవుతుందో ప్రింట్ చేస్తుంది, ఒక ఖాతాపై `o` ఆ ఒక్క ప్రారంభానికి డ్రై రన్‌ను అందిస్తుంది.
- Claude Code ప్రారంభమయ్యే ముందు లేదా లాగిన్ తెరుచుకునే ముందు టెర్మినల్ పునరుద్ధరించబడుతుంది.
- డైలాగ్‌కు సరిపడని చిన్న స్క్రీన్ ముందుగా ట్యాబ్ వరుసలను వదిలేస్తుంది; లైన్లు చుట్టబడకుండా `…` తో కత్తిరించబడతాయి.
