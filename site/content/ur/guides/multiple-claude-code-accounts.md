Claude Code کے ایک سے زیادہ اکاؤنٹس کے لیے ہر اکاؤنٹ کو اس کا اپنا کنفیگریشن فولڈر دیں۔ Claude Code یہ فولڈر `CLAUDE_CONFIG_DIR` انوائرنمنٹ ویری ایبل سے پڑھتا ہے، اور ہر فولڈر میں اس کا اپنا لاگ اِن، سیٹنگز اور ہسٹری ہوتی ہے۔ آپ اسے شیل ایلیاس کے ذریعے ہاتھ سے سیٹ اپ کر سکتے ہیں، یا یہ کام ccam پر چھوڑ سکتے ہیں۔

## ہاتھ سے، ایلیاس کے ذریعے

Claude Code کی دستاویزات میں یہی طریقہ بیان کیا گیا ہے۔ ہر اضافی اکاؤنٹ کے لیے `~/.bashrc` یا `~/.zshrc` میں ایک لائن شامل کریں:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

نیا ٹرمینل کھولیں اور `claude-work` چلائیں۔ Claude Code آپ سے لاگ اِن کرنے کو کہتا ہے، کیونکہ فولڈر نیا ہے۔ اس کے بعد سے `claude` آپ کا پہلا اکاؤنٹ ہے اور `claude-work` دوسرا۔

دو اکاؤنٹس کے لیے یہ طریقہ اچھا کام کرتا ہے۔ چند باتیں جاننا ضروری ہیں:

- ہر فولڈر خالی شروع ہوتا ہے: نہ سیٹنگز، نہ `CLAUDE.md`، نہ MCP سرورز، نہ ایجنٹس یا اسکلز۔ جو کچھ آپ کو چاہیے اسے کاپی یا لنک کرتے ہیں، اور کاپیوں کو خود آپس میں ہم آہنگ رکھتے ہیں۔
- ایلیاسز صرف انٹرایکٹو شیلز میں موجود ہوتے ہیں۔ اسکرپٹس، Makefiles اور دوسرے پروگرام انہیں نہیں دیکھ سکتے۔
- MCP سرورز لاگ اِن کے ساتھ `.claude.json` میں رہتے ہیں، اس لیے انہیں فولڈرز کے درمیان آسانی سے لنک نہیں کیا جا سکتا۔
- گفتگو اسی اکاؤنٹ میں رہتی ہے جہاں وہ شروع ہوئی تھی، اس لیے آپ اسے دوسرے اکاؤنٹ میں جاری نہیں رکھ سکتے۔
- ایسی کوئی چیز نہیں جو تمام اکاؤنٹس کا استعمال ایک ساتھ دکھائے۔

## ccam کے ساتھ

ccam اسی طریقے کو خودکار بناتا ہے اور جو حصے کم ہیں وہ شامل کرتا ہے:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
```

اب `claude1` اور `claude2`، یا `ccam personal` اور `ccam work`، دونوں اکاؤنٹس کو شروع کرتے ہیں۔ چونکہ یہ ایلیاسز نہیں بلکہ حقیقی پروگرام ہیں، اس لیے یہ اسکرپٹس میں بھی کام کرتے ہیں۔ سیٹنگز، `CLAUDE.md`، MCP سرورز اور ایکسٹینشنز شروع سے شیئر ہوتے ہیں، اور آپ شیئر شدہ گفتگو کی ہسٹری آن کر کے `ccam next --continue` سے دوسرے اکاؤنٹ پر گفتگو جاری رکھ سکتے ہیں۔

اگر آپ پہلے سے `~/.claude` استعمال کر رہے ہیں تو وہ اکاؤنٹ دوبارہ شامل کرنے کے بجائے `ccam import` چلائیں۔

## کون سا طریقہ چنیں

اگر دو اکاؤنٹس ہوں اور ان میں کچھ بھی شیئر نہ کرنا ہو تو ایلیاس کافی ہے۔ جب آپ شیئر شدہ سیٹنگز اور MCP سرورز، زیادہ اکاؤنٹس، ایک نظر میں استعمال دیکھنے کی سہولت یا گفتگو جاری رکھنا چاہیں تو ccam آپ کو یہ سارا حساب کتاب خود رکھنے سے بچاتا ہے۔ [موازنے](/compare/aliases) میں دونوں کے فرق آمنے سامنے دیے گئے ہیں۔
