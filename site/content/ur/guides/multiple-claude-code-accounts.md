ہر اکاؤنٹ کو اس کا اپنا کنفیگریشن فولڈر دیں۔ Claude Code یہ فولڈر `CLAUDE_CONFIG_DIR` انوائرنمنٹ ویری ایبل سے پڑھتا ہے، اور ہر فولڈر میں اس کا اپنا لاگ اِن، سیٹنگز اور ہسٹری ہوتی ہے، اس لیے ہر اکاؤنٹ لاگ اِن رہتا ہے اور آپ انہیں بیک وقت چلا سکتے ہیں۔ آپ اسے شیل ایلیاس کے ذریعے ہاتھ سے سیٹ اپ کر سکتے ہیں، یا یہ کام ccam پر چھوڑ سکتے ہیں۔

## میں اسے ہاتھ سے کیسے سیٹ اپ کروں؟

[Claude Code کی دستاویزات میں یہی طریقہ بیان کیا گیا ہے](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts)۔ ہر اضافی اکاؤنٹ کے لیے `~/.bashrc` یا `~/.zshrc` میں ایک لائن شامل کریں:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

نیا ٹرمینل کھولیں اور `claude-work` چلائیں۔ Claude Code آپ سے لاگ اِن کرنے کو کہتا ہے، کیونکہ فولڈر نیا ہے۔ اس کے بعد سے `claude` آپ کا پہلا اکاؤنٹ ہے اور `claude-work` دوسرا۔ ہر اکاؤنٹ کے لیے ایک ایلیاس شامل کریں، اور ہر ایک کا اپنا فولڈر ہو۔

WSL کے بغیر Windows پر، آپ کی پروفائل (`notepad $PROFILE`) میں ایک PowerShell فنکشن یہی کام کرتا ہے:

```powershell
function claude-work { $env:CLAUDE_CONFIG_DIR = "$HOME\.claude-work"; try { claude @args } finally { Remove-Item Env:CLAUDE_CONFIG_DIR } }
```

## ایلیاس والے طریقے میں کیا کمی رہ جاتی ہے؟

دو اکاؤنٹس کے لیے یہ طریقہ اچھا کام کرتا ہے۔ چند باتیں جاننا ضروری ہیں:

- ہر فولڈر خالی شروع ہوتا ہے: نہ سیٹنگز، نہ `CLAUDE.md`، نہ MCP سرورز، نہ ایجنٹس یا اسکلز۔ جو کچھ آپ کو چاہیے اسے کاپی یا لنک کرتے ہیں، اور کاپیوں کو خود آپس میں ہم آہنگ رکھتے ہیں۔
- ایلیاسز صرف انٹرایکٹو شیلز میں موجود ہوتے ہیں۔ اسکرپٹس، Makefiles اور دوسرے پروگرام انہیں نہیں دیکھ سکتے۔
- MCP سرورز لاگ اِن کے ساتھ `.claude.json` میں رہتے ہیں، اس لیے انہیں فولڈرز کے درمیان آسانی سے لنک نہیں کیا جا سکتا۔
- گفتگو اسی اکاؤنٹ میں رہتی ہے جہاں وہ شروع ہوئی تھی، اس لیے آپ اسے دوسرے اکاؤنٹ میں جاری نہیں رکھ سکتے۔
- ایسی کوئی چیز نہیں جو تمام اکاؤنٹس کا استعمال ایک ساتھ دکھائے۔

## کیا میں اس کی بجائے /login سے اکاؤنٹ تبدیل کر سکتا ہوں؟

ہاں، اگر آپ کبھی کبھار ہی اکاؤنٹ بدلتے ہیں۔ Claude Code کے اندر `/login` ٹائپ کرنے سے اس فولڈر کا [اکاؤنٹ تبدیل ہو جاتا ہے](https://code.claude.com/docs/en/quickstart) جس میں آپ ہیں۔ ایک وقت میں صرف ایک اکاؤنٹ لاگ اِن ہوتا ہے، اس لیے ہر بار اکاؤنٹ بدلنے پر دوبارہ لاگ اِن کرنا پڑتا ہے، اور آپ دو اکاؤنٹس ساتھ ساتھ نہیں چلا سکتے۔ الگ فولڈرز ان دونوں مسائل سے بچاتے ہیں۔

## میں اسے ccam کے ساتھ کیسے سیٹ اپ کروں؟

ccam اسی طریقے کو خودکار بناتا ہے اور جو حصے کم ہیں وہ شامل کرتا ہے:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work --shortcut ccwork
```

اب `ccam personal` اور `ccam work` دونوں اکاؤنٹس شروع کرتے ہیں، اور `ccwork` بھی، یعنی وہ شارٹ کٹ جو آپ نے ورک اکاؤنٹ کو دیا۔ چونکہ یہ ایلیاسز نہیں بلکہ حقیقی پروگرام ہیں، اس لیے یہ اسکرپٹس میں بھی کام کرتے ہیں۔ فہرست سے اکاؤنٹ چننے کے لیے صرف `ccam` چلائیں، اور کسی اکاؤنٹ کو ڈیفالٹ بنانے کے لیے `ccam use work`۔

سیٹنگز، `CLAUDE.md`، MCP سرورز اور ایکسٹینشنز شروع سے ہی شیئر ہوتے ہیں، اور آپ شیئر شدہ گفتگو کی ہسٹری آن کر کے `ccam next --continue` سے دوسرے اکاؤنٹ پر گفتگو جاری رکھ سکتے ہیں۔ `ccam usage` تمام اکاؤنٹس کا 5 گھنٹے اور ہفتہ وار استعمال ایک ساتھ دکھاتا ہے۔

اگر آپ پہلے سے `~/.claude` استعمال کرتے ہیں تو وہ اکاؤنٹ دوبارہ شامل کرنے کی بجائے `ccam import` چلائیں، یا اس کی سیٹنگز، MCP سرورز اور ایکسٹینشنز کو شیئر شدہ سیٹنگز میں کاپی کرنے کے لیے `ccam migrate` چلائیں۔

## مجھے کیسے پتا چلے کہ کون سا اکاؤنٹ چل رہا ہے؟

Claude Code کے اندر `/status` وہ اکاؤنٹ دکھاتا ہے جس سے آپ لاگ اِن ہیں۔ ccam کے ساتھ، ایک بار `ccam statusline install` چلائیں تو اسٹیٹس لائن ہر وقت اکاؤنٹ کا نام اور اس کا استعمال دکھاتی ہے، مثلاً `[work] · Opus · 5h 24% · 7d 41%`۔

## کیا یہ Windows اور WSL پر کام کرتا ہے؟

Claude Code [Windows پر براہِ راست اور WSL کے اندر](https://code.claude.com/docs/en/setup) چلتا ہے۔ `CLAUDE_CONFIG_DIR` دونوں میں کام کرتا ہے، اس لیے براہِ راست Windows پر اوپر والا ایلیاس یا PowerShell فنکشن کافی ہے۔ ccam بھی Windows پر براہِ راست چلتا ہے: اسے PowerShell میں `irm https://ccam.dev/install.ps1 | iex` سے انسٹال کریں، یا WSL کے اندر Linux والی کمانڈ سے۔ شارٹ کٹس `ccwork.exe` بن جاتے ہیں، اور `settings.json` جیسی فائلیں شیئر کرنے کے لیے Developer Mode درکار ہے ([ccam انسٹال کریں](/docs/install))۔

## مسائل کا حل

**Claude Code ہر بار مجھ سے لاگ اِن کرنے کو کہتا ہے۔** نئے فولڈر میں پہلی بار شروع کرنے پر یہ ہمیشہ لاگ اِن مانگتا ہے۔ اگر بار بار مانگے تو لاگ اِن کی میعاد ختم ہو گئی ہے یا وہ ہٹا دیا گیا ہے: `ccam login work` چلائیں (یا ایلیاس ایک بار چلا کر لاگ اِن کریں)۔

**کوئی MCP سرور صرف ایک اکاؤنٹ میں نظر آتا ہے۔** سیشن کے اندر `claude mcp add` سے شامل کیے گئے سرورز اسی اکاؤنٹ کے ہوتے ہیں۔ کسی سرور کو تمام اکاؤنٹس میں منتقل کرنے کے لیے `ccam mcp import work <server>` استعمال کریں۔

**اکاؤنٹس کی سیٹنگز مختلف ہیں۔** `ccam share work` دکھاتا ہے کہ اکاؤنٹ کیا شیئر کرتا ہے اور کس گروپ کے ذریعے؛ `ccam group join default work` یہ دکھانے کے بعد کہ کیا بدلے گا، اسے وہی شیئر کرواتا ہے جو `default` شیئر کرتا ہے۔ `ccam doctor --fix` ٹوٹے ہوئے لنکس ٹھیک کرتا ہے اور جو فائل بدلتا ہے اس کا بیک اپ رکھتا ہے۔

**دو اکاؤنٹس ایک ہی گفتگو کھولتے ہیں۔** ایک ہی گفتگو پر بیک وقت دو اکاؤنٹس سے کام کرنے سے گریز کریں۔ اگر آپ ایسا کرنے کی کوشش کریں تو ccam آپ کو خبردار کرتا ہے۔

## مجھے کون سا طریقہ چننا چاہیے؟

اگر دو اکاؤنٹس ہوں اور ان میں کچھ بھی شیئر نہ کرنا ہو تو ایلیاس کافی ہے۔ جب آپ شیئر شدہ سیٹنگز اور MCP سرورز، زیادہ اکاؤنٹس، ایک نظر میں استعمال دیکھنے کی سہولت یا گفتگو جاری رکھنا چاہیں تو ccam آپ کو یہ سارا حساب کتاب خود رکھنے سے بچاتا ہے۔ [ایلیاسز کے ساتھ موازنے](/compare/aliases) میں دونوں کے فرق آمنے سامنے دیے گئے ہیں، اور [ccam اور دوسرے اکاؤنٹ سوئچرز](/compare/account-switchers) میں ان ٹولز کا ذکر ہے جو اس کی بجائے ایک ہی لاگ اِن بدلتے ہیں۔

آپ کئی اکاؤنٹس استعمال کر سکتے ہیں یا نہیں، یہ ہر اکاؤنٹ کی شرائط پر منحصر ہے۔ ایسا کرنے سے پہلے انہیں دیکھ لیں۔
