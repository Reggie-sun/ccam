جب Claude Code کا ایک اکاؤنٹ استعمال کی حد تک پہنچ جائے تو وہی گفتگو اپنے کسی دوسرے اکاؤنٹ میں جاری رکھیں: ایک بار گفتگو کی ہسٹری شیئر کریں، پھر `ccam next --continue` چلائیں۔ اگر آپ کے پاس صرف ایک اکاؤنٹ ہے تو Claude Code جو ری سیٹ کا وقت دکھاتا ہے، اس کا انتظار کریں۔

## ایسا ہونے سے پہلے

اکاؤنٹس کو اس طرح سیٹ اپ کریں کہ اکاؤنٹ تبدیل کرنے میں صرف ایک کمانڈ لگے:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

اب کام کے دوران اسٹیٹس لائن اکاؤنٹ اور اس کا 5 گھنٹے کا استعمال دکھاتی ہے، اس لیے حد اچانک سامنے نہیں آتی۔

## جب حد پوری ہو جائے

Claude Code سے باہر نکلیں (`/exit`)، پھر:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22분        █████░░░  68% 1일 9시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
```

سب سے زیادہ گنجائش والے اکاؤنٹ میں گفتگو کھولیں:

```sh
ccam next --auto --continue
```

Claude Code، `work` کے طور پر موجودہ فولڈر کی سب سے حالیہ گفتگو کے ساتھ شروع ہوتا ہے، جس میں اب تک کی ہر بات شامل ہوتی ہے۔

## یاد رکھنے کی باتیں

- `ccam next --continue` اسی فولڈر میں چلائیں جس میں آپ کام کر رہے تھے؛ گفتگو ہر پروجیکٹ فولڈر کے حساب سے الگ محفوظ ہوتی ہے۔
- ایک ہی گفتگو پر بیک وقت دو اکاؤنٹس چلانے سے گریز کریں۔ اگر آپ ایسا کرنے کی کوشش کریں تو ccam آپ کو خبردار کرتا ہے۔
- دوسرے اکاؤنٹ کو بھی اسی گروپ میں گفتگو کی ہسٹری شیئر کرنی چاہیے۔
- آپ اس طرح اکاؤنٹس کے درمیان تبدیل کر سکتے ہیں یا نہیں، یہ ہر اکاؤنٹ کی شرائط پر منحصر ہے۔

`ccam usage` اور `ccam next` کے تمام آپشنز کے لیے [استعمال کی حدیں](/docs/usage-limits) دیکھیں۔
