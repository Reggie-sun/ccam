## کیا ccam، Anthropic کا سرکاری ٹول ہے؟

نہیں۔ ccam ایک غیر سرکاری اوپن سورس پروجیکٹ ہے۔ اس کا Anthropic سے کوئی تعلق نہیں، اور نہ ہی Anthropic اس کی توثیق کرتا ہے۔ یہ `CLAUDE_CONFIG_DIR` سیٹنگ استعمال کرتا ہے، جسے [Claude Code کی دستاویزات](https://code.claude.com/docs/en/env-vars) کئی اکاؤنٹس ساتھ ساتھ چلانے کے لیے بیان کرتی ہیں۔

## کیا مجھے Claude Code کے کئی اکاؤنٹس استعمال کرنے کی اجازت ہے؟

یہ ہر اکاؤنٹ کی شرائط پر منحصر ہے، اور کام کے اکاؤنٹس کے معاملے میں آپ کے ادارے کی پالیسی پر بھی۔ کئی اکاؤنٹس استعمال کرنے سے پہلے انہیں چیک کریں۔ ccam صرف ان اکاؤنٹس کے درمیان تبدیل کرنا آسان بناتا ہے جو آپ کے پاس پہلے سے موجود ہیں۔

## کیا ccam استعمال کی حدوں کو بائی پاس کرتا ہے؟

نہیں۔ ہر اکاؤنٹ کی اپنی حدیں برقرار رہتی ہیں۔ ccam یہ حدیں دکھاتا ہے، اور جب ایک اکاؤنٹ کی حد ختم ہو جائے تو آپ کو اپنے کسی دوسرے اکاؤنٹ پر کام جاری رکھنے دیتا ہے۔

## میں ایک کمپیوٹر پر Claude Code کے دو اکاؤنٹس کیسے استعمال کروں؟

ہر اکاؤنٹ کو `CLAUDE_CONFIG_DIR` کے ساتھ اس کا اپنا کنفیگریشن فولڈر دیں۔ ccam یہ کام آپ کے لیے کرتا ہے: ہر اکاؤنٹ کے لیے `ccam add` چلائیں، پھر انہیں `ccam personal` اور `ccam work` سے شروع کریں، یا ایسے شارٹ کٹس سے جن کے نام آپ خود رکھیں، جیسے `ccwork`۔ [گائیڈ](/guides/multiple-claude-code-accounts) یہ بھی دکھاتی ہے کہ یہ کام ہاتھ سے کیسے کیا جائے۔

## میں دوسرے اکاؤنٹ پر گفتگو کیسے جاری رکھوں؟

`ccam share <name> --history on` سے دونوں اکاؤنٹس کے درمیان گفتگو کی ہسٹری شیئر کریں، پھر `ccam next --continue` چلائیں۔ Claude Code موجودہ فولڈر کی سب سے حالیہ گفتگو اگلے اکاؤنٹ میں کھول دیتا ہے۔

## کیا ccam میرا لاگ اِن دیکھتا یا کہیں بھیجتا ہے؟

ccam کبھی کوئی لاگ اِن کاپی یا شیئر نہیں کرتا۔ یہ کسی اکاؤنٹ کا ایکسیس ٹوکن صرف اس لیے پڑھتا ہے کہ Anthropic کے usage اینڈ پوائنٹ سے اسی اکاؤنٹ کا استعمال معلوم کرے، اور یہ تب ہوتا ہے جب آپ `ccam usage`، `ccam next --auto` یا `ccam doctor` چلاتے ہیں۔ ccam میں کوئی ٹیلی میٹری نہیں ہے اور یہ کہیں اور کچھ نہیں بھیجتا۔

## میرے اکاؤنٹس کہاں محفوظ ہوتے ہیں؟

`~/.local/share/ccam/profiles/<name>/` میں، ہر اکاؤنٹ کے لیے ایک فولڈر۔ macOS پر لاگ اِن بذاتِ خود Keychain میں رہتا ہے، جہاں Claude Code اسے اسی فولڈر سے اخذ کیے گئے ایک نام کے تحت رکھتا ہے۔

## میرے موجودہ ~/.claude کا کیا ہوگا؟

کچھ نہیں، جب تک آپ `ccam import` یا `ccam migrate` نہ چلائیں۔ امپورٹ فولڈر کو اس کی جگہ پر ہی رجسٹر کرتا ہے، اس لیے سادہ `claude` اور `ccam <name>` وہی اکاؤنٹ اور سیٹنگز استعمال کرتے رہتے ہیں۔ `ccam migrate` اس کی سیٹنگز، `CLAUDE.md`، ایکسٹینشنز اور MCP سرورز کو شیئر شدہ سیٹنگز میں کاپی کرتا ہے اور فولڈر کو صرف پڑھتا ہے۔

## ccam کن سسٹمز پر چلتا ہے؟

Linux (Ubuntu، Debian، Fedora، Arch، Alpine اور دیگر) اور macOS۔ Windows پر اسے WSL کے اندر استعمال کریں۔

## کوئی MCP سرور صرف ایک اکاؤنٹ میں کیوں نظر آتا ہے؟

سیشن کے اندر `claude mcp add` سے شامل کیے گئے سرورز صرف اسی اکاؤنٹ کے لیے محفوظ ہوتے ہیں۔ اگلی بار جب آپ وہ اکاؤنٹ شروع کریں گے تو ccam آپ کو اس کے بارے میں بتائے گا؛ سرور کو `ccam mcp import <account> <server>` سے شیئر شدہ گروپ میں منتقل کریں۔

## کیا ccam سے Claude Code سست ہو جاتا ہے؟

ccam کے ذریعے Claude Code شروع کرنے میں تقریباً 4 ملی سیکنڈ کا اضافہ ہوتا ہے، جو ایک لیپ ٹاپ پر `scripts/perf-check.sh` سے ناپا گیا۔ ccam ایک چھوٹی فائل پڑھتا ہے، شیئر کیے گئے لنکس چیک کرتا ہے اور پھر خود کو `claude` سے بدل دیتا ہے، اس لیے جب آپ کام کر رہے ہوتے ہیں تو یہ چل نہیں رہا ہوتا۔

## میں ccam کو اپ ڈیٹ کیسے کروں؟

`ccam update` چلائیں۔ یہ تازہ ترین ریلیز ڈاؤن لوڈ کرتا ہے، اس کا چیک سم جانچتا ہے اور `ccam` فائل بدل دیتا ہے؛ `ccam update --check` صرف یہ بتاتا ہے کہ کوئی نئی ریلیز موجود ہے یا نہیں۔ ccam کبھی خود سے اپ ڈیٹ نہیں ہوتا۔ اگر آپ نے `.deb` پیکیج انسٹال کیا تھا تو اس کے بجائے نئی `.deb` کو apt سے انسٹال کریں۔ [اپ ڈیٹ کرنا](/docs/install#update) دیکھیں۔

## میں ccam کو اَن انسٹال کیسے کروں؟

ہر اکاؤنٹ کا شارٹ کٹ `ccam shortcut <account> --remove` سے ہٹائیں، `~/.local/bin` سے `ccam` حذف کریں، پھر اگر اکاؤنٹس کی مزید ضرورت نہیں تو `~/.config/ccam`، `~/.local/share/ccam` اور `~/.local/state/ccam` ہٹا دیں۔ [انسٹال](/docs/install#uninstall) دیکھیں۔
