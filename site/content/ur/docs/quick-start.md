ہر اکاؤنٹ `ccam add` سے شامل کریں، پھر Claude Code کو `claude1`، `claude2` یا `ccam <name>` سے شروع کریں۔ زیادہ تر لوگوں کو بس اتنا ہی چاہیے۔

## 1. اپنا پہلا اکاؤنٹ شامل کریں

```sh
ccam add
```

وزرڈ ایک نام پوچھتا ہے، جیسے `personal` یا `work`، اور یہ کہ اکاؤنٹ آپ کے دوسرے اکاؤنٹس کے ساتھ کون سے آئٹمز شیئر کرے۔ پھر یہ `claude auth login` چلاتا ہے، جو براؤزر کھولتا ہے تاکہ آپ سائن اِن کر سکیں۔ کام مکمل ہونے پر آپ کو یہ نظر آتا ہے:

```console
✓ personal (me@example.com) 추가됨 — 단축 명령: claude1
```

فی الحال ccam اپنے پیغامات کورین زبان میں دکھاتا ہے؛ کمانڈز اور آپشنز ہر زبان میں ایک جیسے ہیں۔

## 2. دوسرا اکاؤنٹ شامل کریں

```sh
ccam add work
```

براؤزر میں دوسرے اکاؤنٹ سے سائن اِن کریں۔ یہ `claude2` بن جاتا ہے۔

## 3. اکاؤنٹ تبدیل کریں

ان میں سے کوئی بھی کمانڈ Claude Code کو work اکاؤنٹ کے طور پر شروع کرتی ہے:

```sh
claude2
ccam work
ccam 2
```

اکاؤنٹ کے نام کے بعد کی ہر چیز بغیر تبدیلی کے Claude Code کو جاتی ہے، اس لیے آپ وہی آپشنز استعمال کرتے رہتے ہیں جو آپ جانتے ہیں:

```sh
ccam work --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

صرف `ccam` چلانے سے اکاؤنٹ منتخب کرنے کا مینو کھلتا ہے: ایرو کیز اور Enter استعمال کریں، یا اکاؤنٹ کا نمبر دبائیں۔

## 4. طے کریں کہ کیا شیئر کرنا ہے

ڈیفالٹ طور پر MCP سرورز، `settings.json`، گلوبل `CLAUDE.md`، اور ایجنٹس، کمانڈز، اسکلز اور پلگ اِنز اکاؤنٹس کے درمیان شیئر ہوتے ہیں۔ گفتگو کی ہسٹری شیئر نہیں ہوتی۔ اگر آپ ایک اکاؤنٹ کی گفتگو دوسرے میں جاری رکھنا چاہتے ہیں تو دونوں اکاؤنٹس کے لیے اسے آن کریں:

```sh
ccam share personal --history on
ccam share work --history on
```

ccam کچھ بھی تبدیل کرنے سے پہلے دکھاتا ہے کہ وہ کیا منتقل کرے گا۔ تفصیلات کے لیے [شیئرنگ](/docs/sharing) دیکھیں۔

## 5. جب کوئی اکاؤنٹ اپنی حد تک پہنچ جائے

```sh
ccam usage
ccam next --continue
```

`ccam usage` ہر اکاؤنٹ کا 5 گھنٹے اور ہفتہ وار استعمال دکھاتا ہے۔ `ccam next --continue` وہی گفتگو اگلے اکاؤنٹ میں کھولتا ہے۔ [استعمال کی حدیں](/docs/usage-limits) دیکھیں۔

## کیا آپ پہلے سے ~/.claude استعمال کر رہے ہیں؟

دوبارہ سائن اِن کرنے کے بجائے اسے رجسٹر کریں:

```sh
ccam import
```

فولڈر اپنی جگہ پر رہتا ہے، اور سادہ `claude` پہلے کی طرح کام کرتا رہتا ہے۔
