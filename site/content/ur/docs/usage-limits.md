`ccam usage` دکھاتا ہے کہ ہر اکاؤنٹ نے 5 گھنٹے اور ہفتہ وار حدوں کا کتنا حصہ استعمال کر لیا ہے۔ `ccam next --auto` سب سے زیادہ گنجائش والا اکاؤنٹ کھولتا ہے، اور `--continue` موجودہ گفتگو کو ساتھ لے جاتا ہے۔

```console
$ ccam usage
 Account     5-hour        Resets    Weekly        Resets    As of
 1 personal  ██████░░  72% 1h 40m    ███░░░░░  41% 3d 6h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
 3 side      ████████ 100% 22m       █████░░░  68% 1d 9h     12m ago (cached)
→ Most headroom: work   (open it with ccam next --auto)
```

کالم یہ ہیں: اکاؤنٹ، 5 گھنٹے کا استعمال، اس کے ری سیٹ ہونے میں باقی وقت، ہفتہ وار استعمال، اس کے ری سیٹ ہونے میں باقی وقت، اور یہ کہ اعداد کتنے پرانے ہیں۔

## اعداد کہاں سے آتے ہیں

ccam ہر اکاؤنٹ کا اپنا لاگ اِن استعمال کرتے ہوئے، تمام اکاؤنٹس کے لیے بیک وقت Anthropic کے usage اینڈ پوائنٹ سے پوچھتا ہے۔ یہ ہر اکاؤنٹ کے لیے زیادہ سے زیادہ 3 سیکنڈ انتظار کرتا ہے اور ہر اکاؤنٹ کا جواب آتے ہی اسے دکھا دیتا ہے۔

یہ اینڈ پوائنٹ عوامی طور پر دستاویزی نہیں ہے اور بدل سکتا ہے۔ جب کوئی درخواست ناکام ہو تو ccam آخری معلوم اعداد دکھاتا ہے اور انہیں کیش شدہ کے طور پر نشان زد کرتا ہے۔ جو ونڈو ان اعداد کے محفوظ ہونے کے بعد ری سیٹ ہو چکی ہو وہ 0% دکھاتی ہے۔ اگر جواب کا فارمیٹ بدل گیا ہو تو `ccam doctor` آپ کو بتا دیتا ہے۔

60 سیکنڈ سے کم پہلے حاصل کیے گئے اعداد دوبارہ استعمال ہوتے ہیں۔ آپشنز:

| آپشن | اثر |
| --- | --- |
| `--watch [seconds]` | مسلسل ریفریش کریں، ڈیفالٹ طور پر ہر 60 سیکنڈ بعد |
| `--json` | مشین کے پڑھنے کے قابل آؤٹ پٹ |
| `-v` | ماڈل کے لحاظ سے ہفتہ وار حدیں بھی دکھائیں، اور یہ بھی کہ ہر عدد کہاں سے آیا |
| `--no-cache` | ہمیشہ دوبارہ پوچھیں |
| `--source cache` | کبھی نہ پوچھیں؛ صرف محفوظ اعداد دکھائیں |

## میعاد ختم ہونے والے لاگ اِن

جب کسی اکاؤنٹ کے ایکسیس ٹوکن کی میعاد ختم ہو جائے تو ccam اس کی تجدید نہیں کرتا، کیونکہ اگر کوئی Claude Code سیشن وہی لاگ اِن استعمال کر رہا ہو تو تجدید سے وہ سیشن سائن آؤٹ ہو سکتا ہے۔ اکاؤنٹ کو ایک بار `ccam <name>` سے شروع کریں، Claude Code خود اس کی تجدید کر دے گا۔

`ccam usage --refresh` میعاد ختم ہونے والے ٹوکنز کی خود تجدید کرتا ہے، لیکن صرف ان اکاؤنٹس کے لیے جو اس وقت چل نہیں رہے۔ یہ macOS Keychain میں یا امپورٹ کیے گئے `~/.claude` میں محفوظ لاگ اِن کی کبھی تجدید نہیں کرتا۔

## اسٹیٹس لائن میں استعمال

```sh
ccam statusline install
```

اس کے بعد Claude Code اسٹیٹس لائن میں اکاؤنٹ کا نام اور اس کا استعمال دکھاتا ہے، مثلاً `[work] · Opus · 5h 24% · 7d 41%`۔ اگر آپ کے پاس پہلے سے اسٹیٹس لائن کی کوئی کمانڈ ہے تو ccam اسے برقرار رکھتا ہے اور اس کے شروع میں اکاؤنٹ کا نام لگا دیتا ہے۔ اسٹیٹس لائن اپنے اعداد بھی محفوظ کرتی ہے، جنہیں `ccam usage` اس وقت استعمال کرتا ہے جب اینڈ پوائنٹ جواب نہ دے۔

## اکاؤنٹ تبدیل کرنا

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # the next account that shares your conversation history
```

`ccam next` ان اکاؤنٹس کو چھوڑ دیتا ہے جن میں لاگ اِن نہیں کیا گیا، اور `--auto` ان اکاؤنٹس کو چھوڑ دیتا ہے جو 100% پر ہیں۔ گفتگو جاری رکھنے کے لیے ضروری ہے کہ دونوں اکاؤنٹس گفتگو کی ہسٹری شیئر کرتے ہوں؛ [شیئرنگ](/docs/sharing) دیکھیں۔
