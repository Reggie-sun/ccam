Claude Code کے کئی اکاؤنٹس چلانے کا سب سے آسان طریقہ ہر اکاؤنٹ کے لیے ایک شیل ایلیاس ہے۔ ccam اندرونی طور پر یہی کرتا ہے، اور اس کے ساتھ شیئرنگ، اکاؤنٹ تبدیل کرنے اور استعمال پر نظر رکھنے کی سہولت بھی دیتا ہے۔

## ایلیاس والا سیٹ اپ

ہر اضافی اکاؤنٹ کے لیے `~/.bashrc` یا `~/.zshrc` میں ایک لائن شامل کریں، نیا ٹرمینل کھولیں اور لاگ اِن کرنے کے لیے ایلیاس ایک بار چلائیں:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

`claude` آپ کا پہلا اکاؤنٹ ہی رہتا ہے اور `claude-work` دوسرا اکاؤنٹ شروع کرتا ہے۔ یہی وہ طریقہ ہے جو [Claude Code کی دستاویزات میں بیان کیا گیا ہے](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts)۔

## ccam والا سیٹ اپ

ccam انسٹال کریں اور اکاؤنٹ شامل کریں، یہاں اس کی اپنی شارٹ کٹ کمانڈ کے ساتھ:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add work --shortcut ccwork
```

`ccam work` اور `ccwork` اکاؤنٹ شروع کرتے ہیں، اور دونوں اسکرپٹس میں بھی کام کرتے ہیں۔

## آمنے سامنے

| | شیل ایلیاس | ccam |
| --- | --- | --- |
| الگ الگ لاگ اِن | ہاں | ہاں |
| ہر اکاؤنٹ کا سیٹ اپ | `~/.bashrc` میں ترمیم، لاگ اِن | `ccam add` |
| اسکرپٹس اور دوسرے پروگراموں میں کام کرتا ہے | نہیں، ایلیاسز صرف شیل میں چلتے ہیں | ہاں، `ccam work` اور `ccwork` جیسے شارٹ کٹس حقیقی کمانڈز ہیں |
| شیئر شدہ سیٹنگز، `CLAUDE.md`، ایکسٹینشنز | ہاتھ سے کاپی یا لنک | ہر آئٹم الگ، بیک اپ کے ساتھ |
| شیئر شدہ MCP سرورز | ہاتھ سے، ہر اکاؤنٹ میں | ایک بار `ccam mcp add` |
| دوسرے اکاؤنٹ میں گفتگو جاری رکھنا | نہیں | `ccam next --continue` |
| ہر اکاؤنٹ کا استعمال | نہیں | `ccam usage` |
| سب سے زیادہ گنجائش والا اکاؤنٹ چننا | نہیں | `ccam next --auto` |
| اسٹیٹس لائن میں اکاؤنٹ کا نام | نہیں | `ccam statusline install` |
| ٹوٹے ہوئے لنکس کی مرمت | ہاتھ سے | `ccam doctor --fix` |
| اضافی سافٹ ویئر | کوئی نہیں | ایک اسٹیٹک بائنری |

اگر آپ کے دو اکاؤنٹس ہیں اور آپ ان کے درمیان کچھ بھی شیئر نہیں کرنا چاہتے تو ایلیاسز چنیں۔ اگر آپ چاہتے ہیں کہ تمام اکاؤنٹس ایک ہی سیٹ اپ کی طرح محسوس ہوں تو ccam چنیں۔ آپ ایلیاسز سے شروع کر کے بعد میں ccam پر منتقل ہو سکتے ہیں: `ccam import` موجودہ `~/.claude-*` فولڈرز کو ان کی جگہ پر ہی رجسٹر کر دیتا ہے۔

[ایک کمپیوٹر پر کئی اکاؤنٹس کیسے استعمال کریں](/guides/multiple-claude-code-accounts) میں دونوں طریقے مرحلہ وار بیان کیے گئے ہیں، اور [ccam اور دوسرے اکاؤنٹ سوئچرز](/compare/account-switchers) میں ccam کا موازنہ ان ٹولز سے کیا گیا ہے جو ایک ہی لاگ اِن بدلتے ہیں۔
