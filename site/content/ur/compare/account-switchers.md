Claude Code اکاؤنٹس تبدیل کرنے والے ٹولز دو میں سے ایک طریقہ اپناتے ہیں۔ زیادہ تر ٹولز ایک ہی `~/.claude` فولڈر کے اندر لاگ اِن بدل دیتے ہیں، اس لیے ایک وقت میں ایک ہی اکاؤنٹ فعال ہوتا ہے۔ کچھ دوسرے، جن میں ccam بھی شامل ہے، `CLAUDE_CONFIG_DIR` کے ذریعے ہر اکاؤنٹ کو اس کا اپنا فولڈر دیتے ہیں، اس لیے ہر اکاؤنٹ لاگ اِن رہتا ہے اور کئی اکاؤنٹس بیک وقت چل سکتے ہیں۔ ccam اس کے ساتھ سیٹنگز اور MCP سرورز کی شیئرنگ بھی دیتا ہے، اور گفتگو کو دوسرے اکاؤنٹ کے فولڈر میں جاری رکھتا ہے۔

## ایک لاگ اِن بدلنا یا الگ فولڈرز؟

**لاگ اِن بدلنے** میں سیٹنگز، MCP سرورز اور ہسٹری کا ایک ہی سیٹ رہتا ہے، کیونکہ فولڈر ایک ہی ہوتا ہے۔ اکاؤنٹ جلدی بدلتا ہے، اور چلتا ہوا سیشن نیا لاگ اِن لے سکتا ہے۔ لیکن ایک وقت میں صرف ایک اکاؤنٹ فعال ہوتا ہے، اور وہ بھی تمام ٹرمینلز اور ایڈیٹرز کے لیے ایک ساتھ۔

**الگ فولڈرز** وہ طریقہ ہے جو [Claude Code کی دستاویزات میں بیان کیا گیا ہے](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts)۔ ہر اکاؤنٹ لاگ اِن رہتا ہے، اور آپ کام اور ذاتی سیشن ساتھ ساتھ چلا سکتے ہیں۔ اس کی قیمت یہ ہے کہ ہر فولڈر اپنی سیٹنگز، MCP سرورز اور ہسٹری کے ساتھ شروع ہوتا ہے، جب تک کوئی ٹول انہیں شیئر نہ کرے۔

## ٹولز کا موازنہ

ہر پروجیکٹ کی اپنی دستاویزات سے 2026-10-19 کو لیا گیا۔ "دستاویزات میں نہیں" کا مطلب ہے کہ پروجیکٹ اس بارے میں کچھ نہیں کہتا، یہ نہیں کہ فیچر موجود نہیں۔

| ٹول | طریقہ | بیک وقت کئی اکاؤنٹس | 5 گھنٹے اور ہفتہ وار استعمال | حد پوری ہونے پر | پلیٹ فارمز |
| --- | --- | --- | --- | --- | --- |
| ccam | الگ فولڈرز | ہاں | ہاں، `ccam usage` | آپ `ccam next --auto --continue` چلاتے ہیں تاکہ گفتگو سب سے زیادہ گنجائش والے اکاؤنٹ میں جاری رہے | Linux، macOS، WSL |
| [claude-swap](https://github.com/realiti4/claude-swap) | لاگ اِن بدلتا ہے؛ `cswap run` کے ساتھ الگ فولڈرز | ہاں، `cswap run` کے ساتھ | ہاں | `cswap auto` ایک حد پر لاگ اِن بدل دیتا ہے؛ چلتا ہوا سیشن جاری رہتا ہے | Linux، macOS، Windows |
| [CCS](https://github.com/kaitranntt/ccs) | الگ فولڈرز | ہاں | جزوی طور پر، macOS مینو بار ایپ میں | اکاؤنٹ پولز ایک لوکل پراکسی کے ذریعے درخواستیں اگلے اکاؤنٹ کو بھیجتے ہیں | Linux، macOS، Windows |
| [clauth](https://github.com/uwuclxdy/clauth) | لاگ اِن بدلتا ہے؛ `clauth start` کے ساتھ الگ فولڈرز | ہاں، `clauth start` کے ساتھ | ہاں | فال بیک چین میں اگلے اکاؤنٹ پر چلا جاتا ہے | Linux، macOS، Windows |
| [CAAM](https://github.com/Dicklesworthstone/coding_agent_account_manager) | لاگ اِن بدلتا ہے، یا الگ تھلگ پروفائلز | ہاں، الگ تھلگ پروفائلز کے ساتھ | ہاں | `caam run` غیر انٹرایکٹو کمانڈز کو دوسرے اکاؤنٹ پر دوبارہ چلاتا ہے | Linux، macOS، Windows |

| [CCSwitcher](https://github.com/XueshiQiao/CCSwitcher) | لاگ اِن بدلتا ہے | نہیں | ہاں | دستاویزات میں نہیں | macOS |
| [Claude Switcher](https://github.com/Symbioose/claude-account-switcher) | لاگ اِن بدلتا ہے | نہیں | ہاں | 100% پر اختیاری تبدیلی | macOS |

ccswap، claude-swap کا ایک فورک ہے جو Codex کے لاگ اِنز بھی سنبھالتا ہے۔ ان میں سے کئی ٹولز دوسرے کوڈنگ ایجنٹس، جیسے Codex یا Gemini، کے ساتھ بھی کام کرتے ہیں۔

## ccam کس چیز پر توجہ دیتا ہے

- ہر اکاؤنٹ لاگ اِن رہتا ہے۔ اکاؤنٹ بدلنے سے کبھی کوئی اکاؤنٹ لاگ آؤٹ نہیں ہوتا، اور `ccam work` اور `ccam personal` دو ٹرمینلز میں بیک وقت چل سکتے ہیں۔
- MCP سرورز، `settings.json`، `CLAUDE.md`، ایجنٹس، اسکلز اور پلگ اِنز فولڈرز کے درمیان لنکس کے ذریعے شیئر ہوتے ہیں، ہر آئٹم اور ہر اکاؤنٹ کے حساب سے الگ الگ۔ لاگ اِنز کبھی شیئر نہیں ہوتے۔
- شیئر شدہ ہسٹری کے ساتھ ایک کمانڈ، `ccam next --auto --continue`، وہی گفتگو سب سے زیادہ گنجائش والے اکاؤنٹ کے فولڈر میں کھولتی ہے۔
- ccam، Claude Code کو شروع کرتا ہے اور خود کو اس سے بدل دیتا ہے، اس لیے پس منظر میں کچھ نہیں چلتا۔ یہ آپ کے استعمال پر نظر نہیں رکھتا اور خود سے اکاؤنٹ نہیں بدلتا؛ کب بدلنا ہے، یہ آپ طے کرتے ہیں۔

## جہاں دوسرے ٹولز زیادہ کرتے ہیں

- claude-swap، CCS، clauth، CAAM اور cux، WSL کے بغیر Windows پر چلتے ہیں۔ ccam نہیں چلتا۔
- claude-swap، clauth اور cux کسی اکاؤنٹ کے استعمال کی حد پار کرنے پر خود اکاؤنٹ بدل دیتے ہیں۔ ccam یہ فیصلہ آپ پر چھوڑتا ہے۔
- CCSwitcher، Claude Switcher اور claude-swap استعمال کو macOS مینو بار میں دکھاتے ہیں۔
- CCS، CAAM، ccswap اور Claude Switcher، Codex اور دوسرے کوڈنگ ایجنٹس کو بھی سنبھالتے ہیں۔

## کون سا موزوں ہے؟

اگر آپ ایک وقت میں ایک اکاؤنٹ استعمال کرتے ہیں، چاہتے ہیں کہ اکاؤنٹ خود بخود بدلے، یا WSL کے بغیر Windows پر ہیں تو لاگ اِن بدلنے والا ٹول چنیں۔ اگر آپ اکاؤنٹس ساتھ ساتھ، ایک شیئر شدہ سیٹ اپ اور اگلے اکاؤنٹ میں وہی گفتگو چاہتے ہیں تو ccam چنیں۔ اگر آپ کو کچھ بھی شیئر نہیں کرنا تو [سادہ شیل ایلیاسز](/compare/aliases) کافی ہیں۔

آپ کئی اکاؤنٹس استعمال کر سکتے ہیں یا نہیں، یہ ہر اکاؤنٹ کی شرائط پر منحصر ہے۔ ایسا کرنے سے پہلے انہیں دیکھ لیں۔
