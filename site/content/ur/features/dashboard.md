آرگیومنٹس کے بغیر `ccam` ایک فل اسکرین ڈیش بورڈ کھولتا ہے جب اسٹینڈرڈ اِن پٹ اور آؤٹ پٹ ٹرمینل ہوں؛ ورنہ یہ `ccam list` پرنٹ کرتا ہے۔ ڈیش بورڈ ہر اکاؤنٹ کو اس کے استعمال اور گروپس کے ساتھ دکھاتا ہے، اور وہی کام کرتا ہے جو کمانڈز کرتی ہیں: لانچ کرنا، اکاؤنٹ شامل کرنا، لاگ اِن کرنا، گروپس بدلنا، فولڈر کے اصول سیٹ کرنا، جانچ اور مرمت۔ لانچ کرنے سے یہ بند ہو جاتا ہے؛ اکاؤنٹ شامل کرنا یا لاگ اِن کرنا اسے چھوڑ کر ٹرمینل پر جاتا ہے اور پھر واپس آ جاتا ہے۔

```console
 ccam v0.9.0 · 3 accounts · 2 groups         ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health

    # Account     Email             5-hour         7-day Last  Groups
 ❯ 1. personal ✔   me@example.com    █████▊░░  72%   41% 2h    default
   2. work      ▸• dev@company.com   ██░░░░░░  25%  100% now   default team
   3. side         -                 ✘ not logged in         -     no group

 ✔ personal is the default account
 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

پہلا فریم صرف `config.toml` سے بنتا ہے، 100 ms سے کافی کم میں؛ ہر اکاؤنٹ کے جواب دینے پر استعمال بھرتا جاتا ہے۔ فیصد 80% سے پیلا اور 100% پر سرخ ہو جاتا ہے، اور ناکام تلاش کے بعد کیش سے آنے والی قدریں مدھم دکھائی جاتی ہیں۔

## ٹیبز

| ٹیب | کیا دکھاتا ہے | کلیدیں |
| --- | --- | --- |
| Accounts | نمبر، نام، ای میل، 5 گھنٹے کی بار، 7 دن کا استعمال، آخری استعمال، گروپس؛ `✔` ڈیفالٹ، `▸` اس فولڈر کا اکاؤنٹ، `•` چل رہا ہے | نیچے |
| Groups | ہر گروپ، وہ کیا شیئر کرتا ہے اور اس کے اکاؤنٹس، اور وہ اکاؤنٹس جو کسی گروپ میں نہیں | `enter` ترمیم، `n` نیا، `e` نام بدلیں، `x` ہٹائیں |
| Folders | [`ccam folder`](/features/folder) کے اصول اور وہ اصول جو یہاں لاگو ہوتا ہے | `n` یہاں کوئی اکاؤنٹ استعمال کریں، `enter` بدلیں، `x` ہٹائیں |
| Extensions | جو [`ccam ext`](/features/ext) دکھاتا ہے، ہر ایکسٹینشن ایک بار ان گروپس کے ساتھ جن سے وہ آتی ہے | `r` دوبارہ لوڈ کریں |
| Health | جو [`ccam doctor`](/features/doctor) رپورٹ کرتا ہے | `f` مرمت (`doctor --fix`) |

`←`/`→` یا `Tab` ٹیبز بدلتے ہیں، `?` موجودہ ٹیب کی کلیدوں کی فہرست دکھاتا ہے، `r` مختصر کیش کے بغیر استعمال دوبارہ دیکھتا ہے، اور `q` یا `Esc` باہر نکلتے ہیں۔

| کلید | کیا کرتی ہے |

| `1`–`9` | اس نمبر والے اکاؤنٹ پر جاتی ہے؛ 12 کے لیے جلدی سے `1` `2` ٹائپ کریں۔ صرف `Enter` لانچ کرتی ہے |
| `↑`/`↓`، `k`/`j` | اوپر نیچے جاتی ہیں |
| `n` | وہ اکاؤنٹ شروع کرتی ہے جو [`ccam next --auto`](/features/next) چنتا |
| `o` | آپشنز کے ساتھ شروع کرتی ہے: `--continue`، `--resume`، دوسرے آرگیومنٹس، یا ڈرائی رن |
| `u` | استعمال کی تفصیل: 5 گھنٹے، 7 دن اور ماڈل کی ونڈوز، ان کے ری سیٹ کے ساتھ اور یہ کہ اعداد کہاں سے آتے ہیں |
| `a` | اکاؤنٹ شامل کرتی ہے (نیچے والا وزرڈ) |
| `l` | دوبارہ لاگ اِن کرتی ہے |
| `s` | اکاؤنٹ کے گروپس چنتی ہے |
| `d` | اسے ڈیفالٹ اکاؤنٹ بناتی ہے |
| `f` | اسے موجودہ فولڈر میں استعمال کرتی ہے |
| `e` | اس کا نام بدلتی ہے |
| `c` | اس کی شارٹ کٹ کمانڈ سیٹ کرتی یا ہٹاتی ہے |
| `x` | اسے ہٹاتی ہے (پہلے پوچھتی ہے، No سے شروع کر کے) |

## گروپس بدلنا

Groups ٹیب پر `Enter` ایڈیٹر کھولتا ہے: بائیں طرف آئٹمز، دائیں طرف اکاؤنٹس، بدلنے کے لیے `Tab`، آن یا آف کرنے کے لیے `Space`۔ جو آئٹم کسی اکاؤنٹ کو پہلے سے کسی دوسرے گروپ سے ملتا ہو وہ وجہ کے ساتھ دھندلا دکھایا جاتا ہے، اور وہ اکاؤنٹ بھی جسے کوئی آئٹم دو بار ملتا؛ ایک آئٹم صرف ایک گروپ سے آ سکتا ہے۔ `Enter` منصوبہ دکھاتا ہے:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

جو فائل گروپ کی کاپی سے مختلف ہو اس کے بارے میں پہلے پوچھا جاتا ہے (گروپ والی رکھیں، میری استعمال کریں، یا ملا دیں)۔ پھر تبدیلی پس منظر میں اسی کوڈ سے چلتی ہے جس سے [`ccam group`](/features/share): پہلے کنفیگ محفوظ ہوتی ہے، ہر اکاؤنٹ کا ڈیٹا ترتیب سے منتقل ہوتا ہے، اور اصل فائلیں `.ccam-backup/` میں چلی جاتی ہیں۔ جو تبدیلی کسی چلتے ہوئے اکاؤنٹ کا ڈیٹا منتقل کرتی، وہ اکاؤنٹ کے نام کے ساتھ رد کر دی جاتی ہے۔

## اکاؤنٹ شامل کرنا

`a` وہ وزرڈ کھولتا ہے جو `ccam add` بھی ٹرمینل پر استعمال کرتا ہے:

1. اکاؤنٹ کا نام۔
2. یہ کیسے سائن اِن کرتا ہے: ابھی Claude سبسکرپشن (براؤزر میں)، [API key](/features/api)، یا بعد میں Claude سبسکرپشن۔
3. API key کے لیے: ہر لانچ پر ccam کلید کہاں سے پڑھے (`env:NAME` یا `command:COMMAND`)، اینڈ پوائنٹ، کلید کیسے بھیجی جائے اور ماڈل۔
4. شامل ہونے کے لیے گروپس، `default` پہلے سے چنا ہوا؛ جب ابھی کوئی گروپ نہ ہو، تو یہ کہ گروپ `default` کیا شیئر کرے۔
5. شارٹ کٹ کمانڈ، اگر آپ چاہیں۔
6. تصدیق کے لیے خلاصہ۔

`Esc` ایک مرحلہ پیچھے جاتا ہے، اور پہلے مرحلے پر وزرڈ بند کر دیتا ہے۔

## رنگ

رنگ Claude Code کے ٹرمینل UI کے کرداروں کے مطابق ہیں، اس لیے ccam اس کے ساتھ اجنبی نہیں لگتا؛ گروپ کے ناموں کو ان کے نام سے ایک رنگ ملتا ہے۔ ccam ٹرمینل سے اس کا پس منظر پوچھتا ہے اور روشن یا گہری تھیم چنتا ہے۔ `config.toml` میں خود ایک سیٹ کریں:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` تھیمز سرخ اور سبز رنگ کی پہچان میں دشواری والوں کے لیے ہیں اور `-ansi` تھیمز ٹرمینل کے اپنے 16 رنگ استعمال کرتی ہیں۔ `NO_COLOR` رنگ بند کر دیتا ہے۔

## حفاظت اور خاص صورتیں

- ڈیش بورڈ وہی فنکشنز کال کرتا ہے جو کمانڈز، اس لیے ہر اصول برقرار رہتا ہے: ڈیٹا منتقل ہونے سے پہلے منصوبے، چلتے ہوئے اکاؤنٹس کے لیے انکار، بیک اپس، اور لاگ اِن ٹوکنز جو کبھی اکاؤنٹ سے باہر نہیں جاتے۔
- ڈیش بورڈ میں ڈرائی رن نہیں ہے: نام کے بغیر `ccam --dry-run` پرنٹ کرتا ہے کہ اس فولڈر کا اکاؤنٹ کیسے شروع ہوگا، اور کسی اکاؤنٹ پر `o` صرف اسی ایک لانچ کا ڈرائی رن پیش کرتی ہے۔
- Claude Code شروع ہونے یا لاگ اِن کھلنے سے پہلے ٹرمینل بحال کر دیا جاتا ہے۔
- اگر اسکرین کسی ڈائیلاگ کے لیے بہت چھوٹی ہو تو پہلے ٹیب کی قطاریں ہٹتی ہیں؛ لائنیں لپیٹنے کے بجائے `…` کے ساتھ کاٹ دی جاتی ہیں۔
