آرگیومنٹس کے بغیر `ccam` ایک فل اسکرین ڈیش بورڈ کھولتا ہے جب اسٹینڈرڈ اِن پٹ اور آؤٹ پٹ ٹرمینل ہوں؛ ورنہ یہ `ccam list` پرنٹ کرتا ہے۔ ڈیش بورڈ ہر اکاؤنٹ کو اس کے استعمال اور گروپس کے ساتھ دکھاتا ہے، اور وہی کام کرتا ہے جو کمانڈز کرتی ہیں: لانچ کرنا، اکاؤنٹ شامل کرنا، لاگ اِن کرنا، گروپس بدلنا، فولڈر کے اصول سیٹ کرنا، بیک گراؤنڈ سیشنز کی فہرست دکھانا، جانچ اور مرمت۔ لانچ کرنے سے، یا کسی بیک گراؤنڈ سیشن سے جڑنے سے، یہ بند ہو جاتا ہے؛ اکاؤنٹ شامل کرنا یا لاگ اِن کرنا اسے چھوڑ کر ٹرمینل پر جاتا ہے اور پھر واپس آ جاتا ہے۔

```console
 ccam v0.10.0 · 3 accounts · 2 groups     ✔ default · ▸ this folder · • running

  Accounts   Agents   Groups   Folders   Extensions   Health    auto_switch off
 Your Claude accounts and their usage limits; enter launches the selected one.

    # Account      5-hour       Weekly       Fable        Last  Groups
   1. personal ✔   ████▍░  72%  ██▌░░░  41%  █████▎  88%  -     default
 ❯ 2. work      ▸• █▌░░░░  25%  ██████ 100%  ▋░░░░░  10%  -     default team
   3. side         ✘ not logged in                        -     no group

 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

ٹیبز کے ناموں کے نیچے والی لائن ایک جملے میں بتاتی ہے کہ موجودہ ٹیب کس لیے ہے۔ زیادہ چوڑے ٹرمینل پر Accounts ٹیب ہر اکاؤنٹ کی ای میل بھی دکھاتا ہے۔ ٹیبز والی لائن کا آخری حصہ ہر ٹیب پر بتاتا ہے کہ [`auto_switch`](/features/next#auto-switch) آن ہے یا نہیں (Linux اور macOS؛ Windows پر اسے نظر انداز کیا جاتا ہے)؛ جب یہ آن ہو تو Health ٹیب بتاتا ہے کہ اس سیٹنگ کو اب بھی کس چیز کی ضرورت ہے: Claude سبسکرپشن سے سائن اِن کرنے والے ہر اکاؤنٹ میں آن کیا ہوا ccam پلگ اِن، اور Claude Code 2.1.214 یا بعد کا ورژن۔

ہر بار کھلنے پر ڈیش بورڈ پس منظر میں GitHub سے پوچھتا ہے کہ کیا ccam کی کوئی نئی ریلیز موجود ہے؛ پہلا فریم کبھی اس کا انتظار نہیں کرتا، اور آف لائن ہونے پر کچھ نہیں دکھایا جاتا۔ اگر کوئی ہو تو عنوان کے نیچے ایک لائن اس کی سفارش کرتی ہے:

```console
 ● ccam 0.10.2 is available (you have 0.10.1) · press U to update
```

`U` پہلے پوچھتا ہے، پھر اسی طرح اپ ڈیٹ کرتا ہے جیسے [`ccam update`](/features/update) کرتا ہے: ریلیز کو اس کے SHA-256 چیک سمز سے جانچا جاتا ہے اور یہ ایک ہی قدم میں ccam کی جگہ لے لیتی ہے۔ جس ڈیش بورڈ میں آپ ہیں وہ اب بھی پرانا ورژن ہے، اس لیے باہر نکلیں اور `ccam` دوبارہ شروع کریں۔ جب اپ ڈیٹ یہاں نہ ہو سکے، مثلاً `.deb` پیکیج سے انسٹال کیے گئے ccam کے لیے، تو ڈیش بورڈ وہی مشورہ دکھاتا ہے جو `ccam update` دیتا ہے اور پیشکش برقرار رکھتا ہے۔

پہلا فریم صرف `config.toml` سے بنتا ہے، 100 ms سے کافی کم میں؛ ہر اکاؤنٹ کے جواب دینے پر استعمال بھرتا جاتا ہے۔ ہر حد کی اپنی بار ہوتی ہے: 5 گھنٹے کی ونڈو، تمام ماڈلز کی ہفتہ وار ونڈو، اور Fable کی اپنی ہفتہ وار ونڈو؛ `-` کا مطلب ہے کہ اکاؤنٹ کے پاس ایسی کوئی ونڈو نہیں۔ فیصد 80% سے پیلا اور 100% پر سرخ ہو جاتا ہے، اور ناکام تلاش کے بعد کیش سے آنے والی قدریں مدھم دکھائی جاتی ہیں۔ جس ونڈو کو Claude Code نے بھری ہوئی بتایا ہو وہ اپنے ری سیٹ تک 100% دکھاتی ہے۔ میعاد ختم ایکسیس ٹوکن مدھم `⚠ token expired` دکھاتا ہے (Claude Code اگلی بار شروع ہونے پر اس کی تجدید کر دیتا ہے)، جبکہ `⚠ login expired` کا مطلب ہے کہ اکاؤنٹ کو `ccam login` چاہیے۔

## ٹیبز

| ٹیب | کیا دکھاتا ہے | کلیدیں |
| --- | --- | --- |
| Accounts | نمبر، نام، ای میل، 5 گھنٹے، ہفتہ وار اور Fable کی بارز، آخری استعمال، گروپس؛ `✔` ڈیفالٹ، `▸` اس فولڈر کا اکاؤنٹ، `•` چل رہا ہے (وہ Claude Code بھی جو ccam کے بغیر شروع ہوا: سادہ `claude`، کوئی IDE، بیک گراؤنڈ سیشنز اور ان کا daemon) | نیچے |
| Agents | وہ جو [`ccam agents`](/features/agents) دکھاتا ہے: ہر اکاؤنٹ کے بیک گراؤنڈ سیشنز اور کھلے سیشنز، ان کی حالت، فولڈر اور شروع ہونے کے وقت کے ساتھ (نیچے) | `enter` جڑیں (`ccam attach` کی طرح)، `x` روکیں، `r` دوبارہ لوڈ کریں |
| Groups | ہر گروپ، وہ کیا شیئر کرتا ہے اور اس کے اکاؤنٹس، اور وہ اکاؤنٹس جو کسی گروپ میں نہیں | `enter` ترمیم، `n` نیا، `e` نام بدلیں، `x` ہٹائیں |
| Folders | [`ccam folder`](/features/folder) کے اصول اور وہ اصول جو یہاں لاگو ہوتا ہے، تب بھی جب آپ اس فولڈر تک کسی symbolic link کے ذریعے پہنچے ہوں (نئے اصول لنکس حل کر کے محفوظ کیے جاتے ہیں) | `n` یہاں کوئی اکاؤنٹ استعمال کریں، `enter` بدلیں، `x` ہٹائیں |
| Extensions | جو [`ccam ext`](/features/ext) دکھاتا ہے، ہر ایکسٹینشن ایک بار ان گروپس کے ساتھ جن سے وہ آتی ہے، `off:` وہ اکاؤنٹس جن میں کوئی پلگ اِن آن نہیں، کسی اکاؤنٹ کے اپنے سرورز میں وہ سرورز جو اس کے پاس صرف اس فولڈر کے لیے ہیں، `This folder's project`، اور وہ مسائل جو کسی اکاؤنٹ سے متعلق نہیں | `r` دوبارہ لوڈ کریں |
| Health | جو [`ccam doctor`](/features/doctor) رپورٹ کرتا ہے، ہر اکاؤنٹ کے لیے ایک باکس کی صورت میں (نیچے) | `f` منتخب باکس کی مرمت، `F` سب کی مرمت (`doctor --fix`)، `↑`/`↓` باکسز کے درمیان جائیں |

`←`/`→` یا `Tab` ٹیبز بدلتے ہیں، `?` موجودہ ٹیب کی کلیدوں کی فہرست دکھاتا ہے، `r` مختصر کیش کے بغیر استعمال دوبارہ دیکھتا ہے اور Agents، Extensions اور Health ٹیبز دوبارہ لوڈ کرتا ہے، اور `q` یا `Esc` باہر نکلتے ہیں۔

## Accounts ٹیب کی کلیدیں

| کلید | کیا کرتی ہے |
| --- | --- |
| `Enter` | منتخب اکاؤنٹ کے طور پر Claude Code شروع کرتی ہے |
| `1`–`9` | اس نمبر والے اکاؤنٹ پر جاتی ہے؛ 12 کے لیے جلدی سے `1` `2` ٹائپ کریں۔ صرف `Enter` لانچ کرتی ہے |
| `↑`/`↓`، `k`/`j` | اوپر نیچے جاتی ہیں |
| `n` | وہ اکاؤنٹ شروع کرتی ہے جو [`ccam next --auto`](/features/next) چنتا |
| `o` | آپشنز کے ساتھ شروع کرتی ہے: `--continue`، `--resume`، دوسرے آرگیومنٹس، یا ڈرائی رن |
| `u` | استعمال کی تفصیل: 5 گھنٹے، ہفتہ وار اور ماڈل کی ونڈوز، ان کے ری سیٹ کے ساتھ اور یہ کہ اعداد کہاں سے آتے ہیں |
| `a` | اکاؤنٹ شامل کرتی ہے (نیچے والا وزرڈ) |
| `l` | دوبارہ لاگ اِن کرتی ہے |
| `s` | اکاؤنٹ کے گروپس چنتی ہے |
| `d` | اسے ڈیفالٹ اکاؤنٹ بناتی ہے |
| `f` | اسے موجودہ فولڈر میں استعمال کرتی ہے |
| `e` | اس کا نام بدلتی ہے |
| `c` | اس کی شارٹ کٹ کمانڈ سیٹ کرتی یا ہٹاتی ہے |
| `x` | اسے ہٹاتی ہے (پہلے پوچھتی ہے، No سے شروع کر کے) |

**Team اور Enterprise سیٹیں۔** خودکار انتخاب (`ccam next`، `--fallback`، `ccam pick`، ڈیش بورڈ کی `n` کلید، اور جب آپ اسے آن کریں تو [`auto_switch`](/features/next#auto-switch)) ایک ہی Claude Team یا Enterprise تنظیم کی سیٹوں کے درمیان بھی اکاؤنٹ بدلتا ہے۔ Anthropic کا ہیلپ سینٹر کہتا ہے کہ "Each seat on a Team plan is assigned to one named individual, and only that person may use it" (کسی Team پلان کی ہر سیٹ ایک نامزد فرد کو تفویض کی جاتی ہے، اور صرف اسی شخص کو اسے استعمال کرنے کی اجازت ہے) اور "Users can't route their work through another user's account to use that user's remaining usage" (صارفین کسی دوسرے صارف کا باقی ماندہ استعمال کام میں لانے کے لیے اپنا کام اس کے اکاؤنٹ کے ذریعے نہیں چلا سکتے) ([Team پلانز](https://support.claude.com/en/articles/12004354-purchase-and-manage-seats-on-team-plans#h_b8a7d07129)؛ اسی طرح [Enterprise پلانز](https://support.claude.com/en/articles/13393991-purchase-and-manage-seats-on-enterprise-plans#h_fa6b9cade0) کے لیے بھی)۔ اس لیے سیٹوں کے درمیان خودکار انتخاب استعمال کرنے سے Anthropic کی شرائط کی خلاف ورزی ہو سکتی ہے۔ وہاں اسے استعمال کرنا ہے یا نہیں، یہ آپ کا فیصلہ ہے: اس پر انحصار کرنے سے پہلے اپنی تنظیم اور Anthropic سے تصدیق کر لیں۔ ذاتی پلانز (Pro، Max) کی بات [عام سوالات میں شرائط والے نوٹ](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) میں کی گئی ہے۔

## Health ٹیب

Health ٹیب کھولنے پر [`ccam doctor`](/features/doctor) کی جانچیں چلاتا ہے اور وہی منظر بناتا ہے: پہلی لائن میں ہر اکاؤنٹ کا ایک نشان، پھر ہر اکاؤنٹ کا ایک باکس۔ باکس کی ہر قطار ایک جانچا گیا شعبہ ہے، پہلے `Folder`، `Login` اور `Share links`، جن پر `✔` ٹھیک، `ℹ` معلومات، `⚠` انتباہ یا `✘` غلطی کا نشان ہوتا ہے، تاکہ آپ فوراً دیکھ لیں کہ کس اکاؤنٹ میں مسئلہ ہے اور کہاں۔ جو نتائج کسی اکاؤنٹ سے متعلق نہیں وہ `General` باکس میں جاتے ہیں۔

```console
 ✘ personal   ⚠ work

 ╭─ ✘ personal · 3 problems ─────────────────────────────────────────────────╮
 │ ⚠ Folder       folder permissions are 755 (should be 0700)                │
 │ ℹ              unknown entries (ccam knows the folder layout of Claude    │
 │                Code 2.1.309; it may have changed): newthing               │
 │ ⚠ Login        .credentials.json permissions are 644 (should be 0600)     │
 │ ✔              login valid (me@example.com, Claude Team · Acme)           │
 │ ✘ Share links  /home/me/.local/share/ccam/profiles/personal/settings.json │
 │                : set to shared but is a real file, not a link             │
 │ ✔ Usage        usage lookup OK                                            │
 ╰───────────────────────────────────────────────────────────────────────────╯
 ╭─ ⚠ work · 1 problem ──────────────────────────────────────────────────────╮
 │ ✔ Folder       OK                                                         │
 │ ⚠ Login        not logged in → `ccam login work`                          │
 │ ✔ Share links  share links OK                                             │
 ╰───────────────────────────────────────────────────────────────────────────╯

 4 problems; f repairs the selected box, F all of them (ccam doctor --fix).
```

`↑`/`↓` ایک باکس سے دوسرے پر لے جاتے ہیں، اور منتخب باکس کا بارڈر نمایاں رنگ کا ہوتا ہے۔ `f` صرف منتخب باکس کی مرمت کرتا ہے، اسی طرح جیسے `ccam doctor --fix` کرتا: کسی اکاؤنٹ کے باکس پر وہ صرف اسی اکاؤنٹ کی مرمت کرتا ہے، اور `General` باکس پر ان نتائج کی جو کسی اکاؤنٹ سے متعلق نہیں (پلگ اِنز کے راستے اور شارٹ کٹس)؛ باقی ہر اکاؤنٹ صرف دوبارہ جانچا جاتا ہے۔ یہ پہلے پوچھتا ہے (``Like `ccam doctor --fix`: missing links and group folders are made, and a real file where a link belongs is backed up first; where the group has its own copy, the account then sees the group's. Nothing is lost.``)، اور جس باکس میں مرمت کے لیے کچھ نہ ہو وہ بس `nothing to repair in <name>` کہتا ہے۔ `F` سب کچھ ایک ساتھ مرمت کرتا ہے، `ccam doctor --fix` کی طرح، اور `r` دوبارہ جانچتا ہے۔

## Agents ٹیب

Agents ٹیب وہ دکھاتا ہے جو [`ccam agents`](/features/agents) پرنٹ کرتا ہے: ہر اکاؤنٹ کے بیک گراؤنڈ سیشنز اور کھلے سیشنز، اس اکاؤنٹ کے ساتھ جس کا ہر سیشن ہے۔ جب آپ پہلی بار ٹیب کھولتے ہیں، `r` پر، کسی سیشن کو روکنے کے بعد، اور کنفیگ میں تبدیلی کے بعد، یہ ہر اکاؤنٹ کے Claude Code سے ایک ساتھ پوچھتا ہے (`claude agents --json`، ہر ایک کے لیے زیادہ سے زیادہ 15 سیکنڈ)، اور جب تک سب جواب نہ دے دیں `Asking every account's Claude Code for its sessions…` کہتا ہے۔

```console
  Accounts   Agents   Groups   Folders   Extensions   Health    auto_switch off
 Background agents and open sessions of every account; enter attaches to one.

    Account   ID        Name   State          Folder      Started
 ❯  work      -         -      open (busy)    ~/code/web  now
    personal  49ec0028  probe  blocked, idle  ~/code/app  12m

 ✘ lab: could not list its sessions: exit status 1 'claude agents --json' is
   not available in this environment.

 enter to attach · x to stop · r to reload · ? for shortcuts
```

`State` کسی بیک گراؤنڈ سیشن کی حالت اور یہ بتاتا ہے کہ اس کا پروسیس کیا کر رہا ہے، یا انٹرایکٹو سیشن کے لیے `open`، جیسے `ccam agents` میں۔ جس اکاؤنٹ سے پوچھا نہ جا سکا اسے فہرست کے نیچے ایک `✘` لائن ملتی ہے جس میں وہ ہوتا ہے جو Claude Code نے کہا، جیسے اوپر `lab`، جس کا agent view بند ہے۔ مکمل ہو چکے بیک گراؤنڈ سیشنز شامل نہیں کیے جاتے (`ccam agents --all` انہیں دکھاتا ہے)، اور جب ہر اکاؤنٹ نے جواب دے دیا ہو اور کسی کا کوئی سیشن نہ ہو تو ٹیب کہتا ہے ``No sessions. Start one in the background with `ccam <account> --bg "…"`.`` تنگ ٹرمینل پر ٹیب پہلے `Started`، پھر `Name`، پھر `Folder` ہٹا دیتا ہے، اور لمبے فولڈر کو بائیں طرف سے کاٹ دیتا ہے۔

کسی بیک گراؤنڈ سیشن پر `Enter` ڈیش بورڈ بند کر کے اس سیشن کو اسی ٹرمینل میں اس کے اکاؤنٹ کے طور پر کھولتا ہے، جیسے `ccam attach <id>` کرتا ہے؛ ڈیش بورڈ واپس نہیں آتا (Claude Code میں `←` اس کے agent view پر اور `Ctrl+Z` شیل پر لے جاتا ہے)۔ کھلے سیشن کی کوئی id نہیں ہوتی، اس لیے `Enter` اور `x` بس یہ کہتے ہیں کہ بیک گراؤنڈ سیشن درکار ہے۔ `x` پہلے پوچھتا ہے، `No, keep it` سے شروع کرتے ہوئے: ``It runs as personal. Like `ccam personal stop 49ec0028`, Claude Code stops it and keeps its conversation, which `ccam attach 49ec0028` opens again.`` ہاں کہنے پر ccam اس اکاؤنٹ کے طور پر `claude stop <id>` چلاتا ہے، ``49ec0028 (personal) stopped; `ccam attach 49ec0028` opens it again`` یا یہ کہ کیوں نہ روک سکا، بتاتا ہے، اور فہرست دوبارہ پڑھتا ہے۔

## گروپس بدلنا

Groups ٹیب پر `Enter` ایڈیٹر کھولتا ہے: بائیں طرف آئٹمز، دائیں طرف اکاؤنٹس، بدلنے کے لیے `Tab`، آن یا آف کرنے کے لیے `Space`۔ جو آئٹم کسی اکاؤنٹ کو پہلے سے کسی دوسرے گروپ سے ملتا ہو وہ وجہ کے ساتھ دھندلا دکھایا جاتا ہے، اور وہ اکاؤنٹ بھی جسے کوئی آئٹم دو بار ملتا؛ ایک آئٹم صرف ایک گروپ سے آ سکتا ہے۔ `Enter` منصوبہ دکھاتا ہے:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

جو فائل گروپ کی کاپی سے مختلف ہو اس کے بارے میں پہلے پوچھا جاتا ہے (گروپ والی رکھیں، میری استعمال کریں، یا ملا دیں)۔ پھر تبدیلی پس منظر میں اسی کوڈ سے چلتی ہے جس سے [`ccam group`](/features/share): پہلے کنفیگ محفوظ ہوتی ہے، ہر اکاؤنٹ کا ڈیٹا ترتیب سے منتقل ہوتا ہے، اور اصل فائلیں `.ccam-backup/` میں چلی جاتی ہیں؛ جو اکاؤنٹ MCP شیئرنگ چھوڑے وہ گروپ کے سرورز اپنی `.claude.json` میں رکھتا ہے۔ جو تبدیلی کسی چلتے ہوئے اکاؤنٹ کا ڈیٹا منتقل کرتی، وہ اکاؤنٹ کے نام کے ساتھ رد کر دی جاتی ہے، تب بھی جب اکاؤنٹ منصوبہ کھلا ہونے کے دوران شروع ہوا ہو، اور جس منصوبے کو کسی دوسرے ccam کی گروپس کی تبدیلی نے پرانا کر دیا ہو وہ `the groups changed while this plan waited; nothing was moved, make the change again` کے ساتھ رد کر دیا جاتا ہے۔ جب کوئی دوسرا ccam گروپس بدل رہا ہو تو نئی تبدیلی، نام بدلنا یا ہٹانا `another ccam is changing the groups right now` کہتا ہے؛ اور ادھوری رک جانے والی تبدیلی کے بعد یہ تب تک انتظار کرتے ہیں جب تک Health ٹیب پر `F` (یا `ccam doctor --fix`) اسے مکمل نہ کر دے۔

## اکاؤنٹ شامل کرنا

`a` وہ وزرڈ کھولتا ہے جو `ccam add` بھی ٹرمینل پر استعمال کرتا ہے:

1. اکاؤنٹ کا نام۔
2. یہ کیسے سائن اِن کرتا ہے: ابھی Claude سبسکرپشن (براؤزر میں)، [API key](/features/api)، یا بعد میں Claude سبسکرپشن۔
3. API key کے لیے: ہر لانچ پر ccam کلید کہاں سے پڑھے (`env:NAME` یا `command:COMMAND`)، اینڈ پوائنٹ، کلید کیسے بھیجی جائے اور ماڈل۔
4. شامل ہونے کے لیے گروپس، `default` پہلے سے چنا ہوا؛ جب ابھی کوئی گروپ نہ ہو، تو یہ کہ گروپ `default` کیا شیئر کرے۔
5. شارٹ کٹ کمانڈ، اگر آپ چاہیں۔
6. تصدیق کے لیے خلاصہ۔

`Esc` ایک مرحلہ پیچھے جاتا ہے، اور پہلے مرحلے پر وزرڈ بند کر دیتا ہے۔

## اکاؤنٹ ہٹانا

`x` کچھ بھی ہونے سے پہلے پوچھتی ہے، No سے شروع کر کے، اور بتاتی ہے کہ ہٹانے سے کیا ہوتا ہے: `It is logged out first (its login is revoked), then its folder goes to ccam's trash; the groups' shared files stay.` API key اکاؤنٹ کے لیے منسوخ کرنے کو کوئی لاگ اِن نہیں ہوتا، اور جب کسی دوسرے اکاؤنٹ کے پاس وہی لاگ اِن ہو تو اسے لاگ آؤٹ نہیں کیا جاتا۔ امپورٹ کیا گیا اکاؤنٹ اپنا فولڈر رکھتا ہے: `It was imported, so its folder /home/me/.claude stays where it is: it leaves its groups first and keeps a copy of what they share, then ccam forgets it.`

## رنگ

رنگ Claude Code کے ٹرمینل UI کے کرداروں کے مطابق ہیں، اس لیے ccam اس کے ساتھ اجنبی نہیں لگتا؛ گروپ کے ناموں کو ان کے نام سے ایک رنگ ملتا ہے۔ ccam ٹرمینل سے اس کا پس منظر پوچھتا ہے اور روشن یا گہری تھیم چنتا ہے۔ خود ایک سیٹ کرنے کے لیے اسے `config.toml` میں سب سے اوپر، پہلے `[[group]]`، `[[profile]]` یا `[[folder]]` سے اوپر لکھیں:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

`-daltonized` تھیمز سرخ اور سبز رنگ کی پہچان میں دشواری والوں کے لیے ہیں اور `-ansi` تھیمز ٹرمینل کے اپنے 16 رنگ استعمال کرتی ہیں۔ `NO_COLOR` رنگ بند کر دیتا ہے۔

## حفاظت اور خاص صورتیں

- ڈیش بورڈ وہی فنکشنز کال کرتا ہے جو کمانڈز، اس لیے ہر اصول برقرار رہتا ہے: ڈیٹا منتقل ہونے سے پہلے منصوبے، چلتے ہوئے اکاؤنٹس کے لیے انکار، بیک اپس، اور لاگ اِن ٹوکنز جو کبھی اکاؤنٹ سے باہر نہیں جاتے۔
- ڈیش بورڈ میں ڈرائی رن نہیں ہے: نام کے بغیر `ccam --dry-run` پرنٹ کرتا ہے کہ اس فولڈر کا اکاؤنٹ کیسے شروع ہوگا، اور کسی اکاؤنٹ پر `o` صرف اسی ایک لانچ کا ڈرائی رن پیش کرتی ہے۔
- Claude Code شروع ہونے یا لاگ اِن کھلنے سے پہلے ٹرمینل بحال کر دیا جاتا ہے۔
- اگر اسکرین کسی ڈائیلاگ کے لیے بہت چھوٹی ہو تو پہلے ٹیب کی قطاریں ہٹتی ہیں؛ لائنیں لپیٹنے کے بجائے `…` کے ساتھ کاٹ دی جاتی ہیں۔ کم اونچائی والی اسکرین پر اس کے بعد خالی لائنیں اور ٹیب کی وضاحت ہٹتی ہیں، تاکہ کلیدوں والی لائن باقی رہے۔ 40 کالمز یا 8 قطاروں سے کم پر ڈیش بورڈ صرف `Too small: ccam needs 40x8 (now 36x7)` دکھاتا ہے۔
- جب کوئی تبدیلی، ہٹانا، اپ ڈیٹ یا مرمت لاگو ہو رہی ہو تو `Ctrl+C` اس کے مکمل ہونے کا انتظار کرتا ہے: اسٹیٹس لائن `ccam quits when it is done.` کہتی ہے۔
- `U` سے ccam اپ ڈیٹ ہونے کے بعد، جب ڈیش بورڈ اکاؤنٹ شامل کرنے یا لاگ اِن سے واپس آتا ہے تو پیشکش دوبارہ نہیں آتی۔
