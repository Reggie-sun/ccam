عندما يبلغ أحد الحسابات حدّه، تابع المحادثة نفسها في حساب آخر تملكه: شارك سجل المحادثات مرة واحدة، ثم شغّل `ccam next --continue`. إذا كان لديك حساب واحد فقط، فانتظر موعد إعادة الضبط الذي يعرضه Claude Code.

## قبل أن يحدث ذلك

جهّز الحسابات بحيث يتطلب التبديل أمرًا واحدًا:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

يعرض سطر الحالة الآن الحساب واستخدامه خلال 5 ساعات أثناء عملك، فلا يفاجئك بلوغ الحد.

## عند بلوغ الحد

اخرج من Claude Code (`/exit`)، ثم:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

افتح المحادثة في الحساب الأكثر سعة متبقية:

```sh
ccam next --auto --continue
```

يبدأ Claude Code بالحساب `work` مع أحدث محادثة في المجلد الحالي، بما في ذلك كل ما قيل حتى الآن.

## أمور يجب مراعاتها

- شغّل `ccam next --continue` في المجلد نفسه الذي عملت فيه؛ فالمحادثات تُخزَّن لكل مجلد مشروع.
- تجنّب تشغيل حسابين على المحادثة نفسها في الوقت نفسه. يحذّرك ccam إذا حاولت ذلك.
- يجب أن يشارك الحساب الآخر سجل المحادثات أيضًا، ضمن المجموعة نفسها.
- يعتمد السماح لك بالتبديل بين الحسابات بهذه الطريقة على شروط كل حساب.

راجع [حدود الاستخدام](/docs/usage-limits) لمعرفة كل خيارات `ccam usage` و`ccam next`.
