لاستخدام عدة حسابات Claude Code على جهاز واحد، امنح كل حساب مجلد إعدادات خاصًا به. يقرأ Claude Code المجلد من متغير البيئة `CLAUDE_CONFIG_DIR`، ويحتوي كل مجلد على تسجيل الدخول والإعدادات والسجل الخاصة به. يمكنك إعداد ذلك يدويًا باسم مستعار (alias) في الصدفة، أو ترك ccam يفعله.

## يدويًا، باسم مستعار

هذه هي الطريقة التي يصفها توثيق Claude Code. أضف سطرًا لكل حساب إضافي إلى `~/.bashrc` أو `~/.zshrc`:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

افتح طرفية جديدة وشغّل `claude-work`. سيطلب منك Claude Code تسجيل الدخول، لأن المجلد جديد. ومن ثم يصبح `claude` حسابك الأول و`claude-work` حسابك الثاني.

هذه الطريقة تعمل جيدًا مع حسابين. أمور يجب معرفتها:

- يبدأ كل مجلد فارغًا: بلا إعدادات، وبلا `CLAUDE.md`، وبلا خوادم MCP، وبلا وكلاء أو مهارات. تنسخ ما تحتاجه أو تربطه، وتُبقي النسخ متطابقة بنفسك.
- الأسماء المستعارة موجودة فقط في الصدفات التفاعلية. لا تراها السكربتات وملفات Makefile والبرامج الأخرى.
- تُخزَّن خوادم MCP في `.claude.json`، بجوار تسجيل الدخول، لذلك لا يمكن ببساطة ربطها بين المجلدات.
- تبقى المحادثات في الحساب الذي بدأت فيه، لذلك لا يمكنك متابعة محادثة في حساب آخر.
- لا يوجد ما يعرض استخدام كل الحسابات دفعة واحدة.

## باستخدام ccam

يؤتمت ccam الفكرة نفسها ويضيف الأجزاء الناقصة:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
```

الآن يشغّل `claude1` و`claude2`، أو `ccam personal` و`ccam work`، الحسابين. ولأنها برامج حقيقية وليست أسماء مستعارة، فهي تعمل في السكربتات أيضًا. تُشارَك الإعدادات و`CLAUDE.md` وخوادم MCP والإضافات منذ البداية، ويمكنك تفعيل مشاركة سجل المحادثات لمتابعة محادثة على الحساب الآخر باستخدام `ccam next --continue`.

إذا كنت تستخدم `~/.claude` بالفعل، فشغّل `ccam import` بدلًا من إضافة ذلك الحساب مرة أخرى.

## أيهما تختار

لحسابين دون مشاركة أي شيء، يكفي الاسم المستعار. وعندما تريد مشاركة الإعدادات وخوادم MCP، أو حسابات أكثر، أو رؤية الاستخدام بنظرة واحدة، أو متابعة المحادثات، يوفّر عليك ccam عناء المتابعة اليدوية. تعرض [المقارنة](/compare/aliases) الفروق جنبًا إلى جنب.
