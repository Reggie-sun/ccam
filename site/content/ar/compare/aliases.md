الاسم المستعار (alias) في الصدفة لكل حساب هو أبسط طريقة لتشغيل عدة حسابات Claude Code. يفعل ccam الشيء نفسه في الخلفية، ويضيف المشاركة والتبديل وتتبّع الاستخدام.

| | اسم مستعار في الصدفة | ccam |
| --- | --- | --- |
| تسجيلات دخول منفصلة | نعم | نعم |
| الإعداد لكل حساب | تعديل `~/.bashrc` ثم تسجيل الدخول | `ccam add` |
| يعمل في السكربتات والبرامج الأخرى | لا، الأسماء المستعارة تعمل في الصدفة فقط | نعم، `claude2` أمر حقيقي |
| مشاركة الإعدادات و`CLAUDE.md` والإضافات | النسخ أو الربط يدويًا | لكل عنصر، مع نسخ احتياطية |
| مشاركة خوادم MCP | يدويًا، لكل حساب | `ccam mcp add` مرة واحدة |
| متابعة محادثة في حساب آخر | لا | `ccs next --continue` |
| استخدام كل الحسابات | لا | `ccs usage` |
| اختيار الحساب الأكثر سعة متبقية | لا | `ccs next --auto` |
| اسم الحساب في سطر الحالة | لا | `ccam statusline install` |
| إصلاح الروابط المعطلة | يدويًا | `ccam doctor --fix` |
| برامج إضافية | لا شيء | ملف تنفيذي ثابت واحد |

اختر الأسماء المستعارة إذا كان لديك حسابان ولا تريد مشاركة أي شيء بينهما. واختر ccam إذا أردت أن تبدو الحسابات كإعداد واحد. يمكنك البدء بالأسماء المستعارة والانتقال إلى ccam لاحقًا: يسجّل `ccam import` مجلدات `~/.claude-*` الموجودة في أماكنها.

يشرح دليل [كيفية استخدام حسابين على حاسوب واحد](/guides/multiple-claude-code-accounts) الطريقتين خطوة بخطوة.
