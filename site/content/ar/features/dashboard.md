يفتح `ccam` دون وسائط لوحة تحكم بملء الشاشة عندما يكون الإدخال والإخراج القياسيان طرفية، ويطبع `ccam list` في غير ذلك. تعرض لوحة التحكم كل حساب مع استخدامه ومجموعاته، وتفعل ما تفعله الأوامر: التشغيل والإضافة وتسجيل الدخول وتغيير المجموعات وضبط قواعد المجلدات والفحص والإصلاح. ويغلقها تشغيل حساب؛ أما إضافة حساب أو تسجيل الدخول فيتركها إلى الطرفية ثم يعود إليها.

```console
 ccam v0.9.0 · 3 accounts · 2 groups         ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health

    # Account     Email             5-hour         7-day Last  Groups
 ❯ 1. personal ✔   me@example.com    █████▊░░  72%   41% 2h    default
   2. work      ▸• dev@company.com   ██░░░░░░  25%  100% now   default team
   3. side         -                 ✘ not logged in         -     no group

 ✔ personal is the default account
 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

يُرسم الإطار الأول من `config.toml` وحده، في أقل بكثير من 100 ms؛ ثم يُملأ الاستخدام كلما أجاب حساب. وتتحول النسبة إلى الأصفر بدءًا من 80% وإلى الأحمر عند 100%، وتُرسم باهتةً القيمُ الآتية من ذاكرة التخزين المؤقت بعد فشل الاستعلام.

## التبويبات

| التبويب | ما يعرضه | المفاتيح |
| --- | --- | --- |
| Accounts | الرقم والاسم والبريد الإلكتروني وشريط الخمس ساعات واستخدام الأيام السبعة وآخر استخدام والمجموعات؛ `✔` الحساب الافتراضي، و`▸` حساب هذا المجلد، و`•` يعمل | أدناه |
| Groups | كل مجموعة وما تشاركه وحساباتها، والحسابات التي لا تنتمي إلى أي مجموعة | `enter` تحرير، `n` جديدة، `e` إعادة تسمية، `x` إزالة |
| Folders | قواعد [`ccam folder`](/features/folder) والقاعدة التي تنطبق هنا | `n` استخدام حساب هنا، `enter` تغيير، `x` إزالة |
| Extensions | ما يعرضه [`ccam ext`](/features/ext)، كل إضافة مرة واحدة مع المجموعات التي تأتي منها | `r` إعادة التحميل |
| Health | ما يبلّغ عنه [`ccam doctor`](/features/doctor) | `f` إصلاح (`doctor --fix`) |

يبدّل `←`/`→` أو `Tab` بين التبويبات، ويسرد `?` مفاتيح التبويب الحالي، ويعيد `r` الاستعلام عن الاستخدام دون ذاكرة التخزين المؤقت القصيرة، ويُنهي `q` أو `Esc` لوحة التحكم.

## المفاتيح في تبويب Accounts

| المفتاح | ما يفعله |
| --- | --- |
| `Enter` | يشغّل Claude Code بالحساب المحدد |
| `1`–`9` | ينتقل إلى الحساب الذي يحمل ذلك الرقم؛ اكتب `1` `2` بسرعة للحساب 12. ولا يشغّل الحسابَ إلا `Enter` |
| `↑`/`↓`، `k`/`j` | التنقل |
| `n` | يشغّل الحساب الذي سيختاره [`ccam next --auto`](/features/next) |
| `o` | يشغّل مع خيارات: `--continue` أو `--resume` أو وسائط أخرى، أو تشغيل تجريبي |
| `u` | تفاصيل الاستخدام: نوافذ الخمس ساعات والأيام السبعة والنماذج مع أوقات إعادة ضبطها ومصدر الأرقام |
| `a` | يضيف حسابًا (المعالج أدناه) |
| `l` | يسجّل الدخول من جديد |
| `s` | يختار مجموعات الحساب |
| `d` | يجعله الحساب الافتراضي |
| `f` | يستخدمه في المجلد الحالي |
| `e` | يعيد تسميته |
| `c` | يعيّن أمره المختصر أو يزيله |
| `x` | يزيله (يسأل أولًا، ويبدأ التحديد عند No) |

## تغيير المجموعات

في تبويب Groups، يفتح `Enter` المحرر: العناصر على اليسار، والحسابات على اليمين، و`Tab` للتبديل بينهما، و`Space` للتحديد أو إلغائه. والعنصر الذي يحصل عليه أحد الحسابات بالفعل من مجموعة أخرى يظهر باهتًا مع السبب، وكذلك الحساب الذي سيحصل على عنصر مرتين؛ فالعنصر لا يأتي إلا من مجموعة واحدة. ويعرض `Enter` الخطة:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

والملف الذي يختلف عن نسخة المجموعة يُسأل عنه أولًا (الإبقاء على نسخة المجموعة، أو استخدام نسختك، أو الدمج). ثم يجري التغيير في الخلفية بالشيفرة نفسها التي يستخدمها [`ccam group`](/features/share): يُحفظ الإعداد أولًا، وتُنقل بيانات كل حساب بالترتيب، وتذهب الأصول إلى `.ccam-backup/`. والتغيير الذي سينقل بيانات حساب يعمل يُرفض مع ذكر اسم الحساب.

## إضافة حساب

يفتح `a` المعالج نفسه الذي يستخدمه `ccam add` في الطرفية:

1. اسم الحساب.
2. طريقة تسجيل دخوله: اشتراك Claude الآن (في المتصفح)، أو [مفتاح API](/features/api)، أو اشتراك Claude لاحقًا.
3. لمفتاح API: المكان الذي يقرأ منه ccam المفتاح عند كل تشغيل (`env:NAME` أو `command:COMMAND`)، ونقطة النهاية، وطريقة إرسال المفتاح، والنموذج.
4. المجموعات التي ينضم إليها، مع تحديد `default`؛ وقبل وجود أي مجموعات، ما تشاركه المجموعة `default`.
5. أمر مختصر، إن أردت واحدًا.
6. ملخص لتأكيده.

يعود `Esc` خطوة واحدة إلى الوراء، ويغلق المعالج إذا كنت في الخطوة الأولى.

## الألوان

تتبع الألوان أدوار الألوان في واجهة الطرفية لدى Claude Code، فيبدو ccam منسجمًا بجانبه؛ وتأخذ أسماء المجموعات لونًا مشتقًا من أسمائها. ويسأل ccam الطرفية عن لون خلفيتها ويختار سمة فاتحة أو داكنة. ويمكنك تعيين سمة بنفسك في `config.toml`:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

السمات `-daltonized` مخصصة لعمى اللونين الأحمر والأخضر، والسمات `-ansi` تستخدم ألوان الطرفية الستة عشر الخاصة بها. ويوقف `NO_COLOR` الألوان.

## الأمان والحالات الخاصة

- تستدعي لوحة التحكم الدوال نفسها التي تستدعيها الأوامر، فتسري كل القواعد: الخطط قبل نقل البيانات، ورفض العمل على الحسابات التي تعمل، والنسخ الاحتياطية، ورموز تسجيل الدخول التي لا تغادر حسابها أبدًا.
- ليس في لوحة التحكم تشغيل تجريبي: يطبع `ccam --dry-run` دون اسم حساب كيف سيبدأ حساب هذا المجلد، ويعرض `o` على حساب ما تشغيلًا تجريبيًا لهذا التشغيل وحده.
- تُستعاد الطرفية قبل أن يبدأ Claude Code أو يُفتح تسجيل الدخول.
- إذا كانت الشاشة أصغر من أن تتسع لمربع حوار، تُحذف صفوف التبويب أولًا؛ وتُقطع الأسطر مع `…` بدلًا من لفّها.
