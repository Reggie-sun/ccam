يعرض `ccam usage` مقدار ما استخدمه كل حساب من حد الخمس ساعات والحد الأسبوعي والحد الأسبوعي الخاص بكل نموذج (مثل Fable). ويفتح `ccam next --auto` الحساب الأكثر سعة متبقية، وينقل `--continue` المحادثة الحالية معه.

يحصل كل حساب على سطر يبيّن عمر أرقامه، ثم شريط لكل حد مع الوقت المتبقي حتى إعادة ضبطه: نافذة الخمس ساعات، والنافذة الأسبوعية لكل النماذج، والنافذة الأسبوعية الخاصة بكل نموذج مثل Fable. يتحول الشريط إلى الأصفر بدءًا من 80%، وإلى الأحمر عند 100%. ويذكر السطر الأخير الحساب الذي سيفتحه `ccam next --auto`.

## من أين تأتي الأرقام

يطلب ccam من نقطة نهاية الاستخدام لدى Anthropic بيانات كل الحسابات في الوقت نفسه، مستخدمًا تسجيل الدخول الخاص بكل حساب. ينتظر 3 ثوانٍ على الأكثر لكل حساب، ويعرض كل حساب بمجرد أن يصل رده.

نقطة النهاية هذه غير موثقة علنًا وقد تتغير. عندما يفشل طلب ما، يعرض ccam آخر أرقام معروفة ويضع عليها علامة أنها من ذاكرة التخزين المؤقت. وتظهر النافذة التي أُعيد ضبطها منذ حفظ تلك الأرقام بقيمة 0%. ويخبرك `ccam doctor` إذا تغيّر تنسيق الاستجابة.

يُعاد استخدام الأرقام التي جُلبت قبل أقل من 60 ثانية. الخيارات:

| الخيار | التأثير |
| --- | --- |
| `--watch [seconds]` | تحديث مستمر، كل 60 ثانية افتراضيًا |
| `--json` | مخرجات قابلة للقراءة آليًا |
| `-v` | يعرض أيضًا مصدر أرقام كل حساب |
| `--no-cache` | يطلب البيانات من جديد دائمًا |
| `--source cache` | لا يطلب أبدًا؛ يعرض الأرقام المحفوظة فقط |

## تسجيلات الدخول المنتهية

عندما ينتهي رمز الوصول الخاص بحساب ما، لا يجدّده ccam، لأن تجديده بينما تستخدم جلسة Claude Code تسجيل الدخول نفسه قد يؤدي إلى تسجيل خروج تلك الجلسة. شغّل الحساب مرة واحدة باستخدام `ccam <name>` وسيجدّده Claude Code.

يجدّد `ccam usage --refresh` الرموز المنتهية بنفسه، ولكن فقط للحسابات غير قيد التشغيل. ولا يجدّد أبدًا تسجيلات الدخول المخزنة في سلسلة المفاتيح على macOS أو في مجلد `~/.claude` مستورد.

## الاستخدام في سطر الحالة

```sh
ccam statusline install
```

بعد ذلك يعرض Claude Code اسم الحساب واستخدامه في سطر الحالة، مثلًا `[work] · Opus · 5h 24% · 7d 41%`. وابتداءً من 90%، يقترح السطر أيضًا `ccam next --auto --continue`. إذا كان لديك أمر لسطر الحالة بالفعل، يحتفظ به ccam ويضع اسم الحساب قبله. ويحفظ سطر الحالة أرقامه أيضًا، فيستخدمها `ccam usage` عندما لا تستجيب نقطة النهاية.

## التبديل

```sh
ccam next             # the account after the one you used last
ccam next --auto      # the account with the lowest 5-hour usage
ccam next --continue  # carry this folder's conversation on as the next account
```

يتخطى `ccam next` الحسابات غير المسجّل دخولها، ويتخطى `--auto` الحسابات التي بلغت 100% وحسابات المؤسسات الأخرى. وعندما يتشارك الحسابان سجل المحادثات، يفتح `--continue` المحادثة نفسها؛ وإلا ينسخها Claude Code إلى الحساب الجديد. راجع [المشاركة](/docs/sharing) و[التبديل إلى الحساب التالي](/features/next#continue).

في السكربتات والمهام المجدولة التي تشغّل `claude -p`، ضع `--fallback` قبل اسم الحساب. عندما يبلغ ذلك الحساب حده، يشغّل ccam الأمر نفسه مجددًا بالحساب الذي لديه أكبر هامش، ولا يُطبع إلا مخرج التشغيل الذي اكتمل:

```sh
ccam --fallback work -p "review the diff" --output-format json
```
