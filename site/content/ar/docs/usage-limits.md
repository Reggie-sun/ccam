يعرض `ccs usage` مقدار ما استخدمه كل حساب من حدّي الخمس ساعات والأسبوع. ويفتح `ccs next --auto` الحساب الأكثر سعة متبقية، وينقل `--continue` المحادثة الحالية معه.

```console
$ ccs usage
 계정        5시간         초기화      주간          초기화      기준
 1 personal  ██████░░  72% 1시간 40분  ███░░░░░  41% 3일 6시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
 3 side      ████████ 100% 22분        █████░░░  68% 1일 9시간   12분 전 (캐시)
→ 여유가 가장 많은 계정: work   (ccs next --auto 로 바로 열기)
```

الأعمدة هي: الحساب، واستخدام الخمس ساعات، والوقت المتبقي حتى إعادة ضبطه، والاستخدام الأسبوعي، والوقت المتبقي حتى إعادة ضبطه، وعمر الأرقام.

## من أين تأتي الأرقام

يطلب ccam من نقطة نهاية الاستخدام لدى Anthropic بيانات كل الحسابات في الوقت نفسه، مستخدمًا تسجيل الدخول الخاص بكل حساب. ينتظر 3 ثوانٍ على الأكثر لكل حساب، ويعرض كل حساب بمجرد أن يصل رده.

نقطة النهاية هذه غير موثقة علنًا وقد تتغير. عندما يفشل طلب ما، يعرض ccam آخر أرقام معروفة ويضع عليها علامة أنها من ذاكرة التخزين المؤقت. ويخبرك `ccam doctor` إذا تغيّر تنسيق الاستجابة.

يُعاد استخدام الأرقام التي جُلبت قبل أقل من 60 ثانية. الخيارات:

| الخيار | التأثير |
| --- | --- |
| `--watch [seconds]` | تحديث مستمر، كل 60 ثانية افتراضيًا |
| `--json` | مخرجات قابلة للقراءة آليًا |
| `-v` | يعرض أيضًا الحدود الأسبوعية الخاصة بكل نموذج ومصدر كل رقم |
| `--no-cache` | يطلب البيانات من جديد دائمًا |
| `--source cache` | لا يطلب أبدًا؛ يعرض الأرقام المحفوظة فقط |

## تسجيلات الدخول المنتهية

عندما ينتهي رمز الوصول الخاص بحساب ما، لا يجدّده ccam، لأن تجديده بينما تستخدم جلسة Claude Code تسجيل الدخول نفسه قد يؤدي إلى تسجيل خروج تلك الجلسة. شغّل الحساب مرة واحدة باستخدام `ccs <name>` وسيجدّده Claude Code.

يجدّد `ccs usage --refresh` الرموز المنتهية بنفسه، ولكن فقط للحسابات غير قيد التشغيل. ولا يجدّد أبدًا تسجيلات الدخول المخزنة في سلسلة المفاتيح على macOS أو في مجلد `~/.claude` مستورد.

## الاستخدام في سطر الحالة

```sh
ccam statusline install
```

بعد ذلك يعرض Claude Code اسم الحساب واستخدامه في سطر الحالة، مثلًا `[work] · Opus · 5h 24% · 7d 41%`. إذا كان لديك أمر لسطر الحالة بالفعل، يحتفظ به ccam ويضع اسم الحساب قبله. ويحفظ سطر الحالة أرقامه أيضًا، فيستخدمها `ccs usage` عندما لا تستجيب نقطة النهاية.

## التبديل

```sh
ccs next              # the account after the one you used last
ccs next --auto       # the account with the lowest 5-hour usage
ccs next --continue   # the next account that shares your conversation history
```

يتخطى `ccs next` الحسابات غير المسجّل دخولها، ويتخطى `--auto` الحسابات التي بلغت 100%. لمتابعة محادثة، يجب أن يتشارك الحسابان سجل المحادثات؛ راجع [المشاركة](/docs/sharing).
