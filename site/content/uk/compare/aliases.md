Окремий псевдонім оболонки для кожного облікового запису є найпростішим способом запускати кілька облікових записів Claude Code. ccam робить те саме під капотом і додає спільне використання, перемикання та відстеження використання.

## Налаштування з псевдонімами

Додайте по одному рядку для кожного додаткового облікового запису до `~/.bashrc` або `~/.zshrc`, відкрийте новий термінал і один раз запустіть псевдонім, щоб увійти:

```sh
alias claude-work='CLAUDE_CONFIG_DIR=~/.claude-work claude'
```

`claude` залишається вашим першим обліковим записом, а `claude-work` запускає другий. Саме цей спосіб [описано в документації Claude Code](https://code.claude.com/docs/en/authentication#log-in-with-multiple-accounts).

## Налаштування з ccam

Установіть ccam і додайте обліковий запис, тут одразу з власною короткою командою:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add work --shortcut ccwork
```

`ccam work` і `ccwork` запускають обліковий запис, і обидві команди працюють також у скриптах.

## Пліч-о-пліч

| | Псевдонім оболонки | ccam |
| --- | --- | --- |
| Окремі входи | Так | Так |
| Налаштування для кожного облікового запису | Редагування `~/.bashrc`, вхід | `ccam add` |
| Працює в скриптах та інших програмах | Ні, псевдоніми існують лише в оболонці | Так, `ccam work` і короткі команди на зразок `ccwork` є справжніми командами |
| Спільні налаштування, `CLAUDE.md`, розширення | Копіювання або посилання вручну | Так, на вибір для кожного елемента, з резервними копіями |
| Спільні сервери MCP | Вручну, для кожного облікового запису | `ccam mcp add` один раз |
| Продовження розмови в іншому обліковому записі | Ні | `ccam next --continue` |
| Використання всіх облікових записів | Ні | `ccam usage` |
| Вибір облікового запису з найбільшим запасом | Ні | `ccam next --auto` |
| Повторний запуск завдання `-p` від імені іншого облікового запису при ліміті | Ні | `ccam --fallback` |
| Обліковий запис для кожної теки проєкту | Ні | `ccam folder` |
| Назва облікового запису в рядку стану | Ні | `ccam statusline install` |
| Відновлення пошкоджених посилань | Вручну | `ccam doctor --fix` |
| Додаткове програмне забезпечення | Немає | Один статичний двійковий файл |

Обирайте псевдоніми, якщо у вас два облікові записи й ви не хочете, щоб між ними щось було спільним. Обирайте ccam, якщо хочете, щоб облікові записи відчувалися як одне налаштоване середовище. Можна почати з псевдонімів і перейти на ccam пізніше: `ccam import` реєструє наявні теки `~/.claude-*` там, де вони є.

[Як користуватися кількома обліковими записами на одному комп'ютері](/guides/multiple-claude-code-accounts) покроково пояснює обидва підходи, а [ccam та інші перемикачі облікових записів](/compare/account-switchers) порівнює ccam з інструментами, які підміняють один вхід.
