Окремий псевдонім оболонки для кожного облікового запису є найпростішим способом запускати кілька облікових записів Claude Code. ccam робить те саме під капотом і додає спільне використання, перемикання та відстеження використання.

| | Псевдонім оболонки | ccam |
| --- | --- | --- |
| Окремі входи | Так | Так |
| Налаштування для кожного облікового запису | Редагування `~/.bashrc`, вхід | `ccam add` |
| Працює в скриптах та інших програмах | Ні, псевдоніми існують лише в оболонці | Так, `claude2` є справжньою командою |
| Спільні налаштування, `CLAUDE.md`, розширення | Копіювання або посилання вручну | Для кожного елемента, з резервними копіями |
| Спільні сервери MCP | Вручну, для кожного облікового запису | `ccam mcp add` один раз |
| Продовження розмови в іншому обліковому записі | Ні | `ccs next --continue` |
| Використання всіх облікових записів | Ні | `ccs usage` |
| Вибір облікового запису з найбільшим запасом | Ні | `ccs next --auto` |
| Назва облікового запису в рядку стану | Ні | `ccam statusline install` |
| Відновлення пошкоджених посилань | Вручну | `ccam doctor --fix` |
| Додаткове програмне забезпечення | Немає | Один статичний двійковий файл |

Обирайте псевдоніми, якщо у вас два облікові записи й ви не хочете, щоб між ними щось було спільним. Обирайте ccam, якщо хочете, щоб облікові записи відчувалися як одне налаштоване середовище. Можна почати з псевдонімів і перейти на ccam пізніше: `ccam import` реєструє наявні теки `~/.claude-*` там, де вони є.

[Як користуватися двома обліковими записами на одному комп'ютері](/guides/multiple-claude-code-accounts) покроково пояснює обидва підходи.
