Коли один обліковий запис досягає ліміту використання Claude Code, продовжте ту саму розмову в іншому вашому обліковому записі: один раз увімкніть спільну історію розмов, а потім виконайте `ccs next --continue`. Якщо у вас лише один обліковий запис, дочекайтеся часу скидання, який показує Claude Code.

## Заздалегідь

Налаштуйте облікові записи так, щоб перемикання займало одну команду:

```sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

Тепер під час роботи рядок стану показує обліковий запис і його 5-годинне використання, тож ліміт не стане несподіванкою.

## Коли ліміт досягнуто

Вийдіть із Claude Code (`/exit`), а потім:

```sh
ccs usage
```

```console
 1 personal  ████████ 100% 22분        █████░░░  68% 1일 9시간   방금
 2 work      █░░░░░░░   8% 4시간 12분  ██░░░░░░  19% 5일 2시간   방금
```

Відкрийте розмову в обліковому записі з найбільшим запасом:

```sh
ccs next --auto --continue
```

Claude Code запускається як `work` з найновішою розмовою поточної теки, включно з усім, що вже було сказано.

## Що слід пам'ятати

- Виконуйте `ccs next --continue` у тій самій теці, де ви працювали; розмови зберігаються окремо для кожної теки проєкту.
- Не запускайте два облікові записи в одній розмові одночасно. ccam попередить вас, якщо ви спробуєте.
- Інший обліковий запис також має спільно використовувати історію розмов, у тій самій групі.
- Чи можна вам так перемикатися між обліковими записами, залежить від умов кожного облікового запису.

Усі параметри `ccs usage` і `ccs next` див. у розділі [ліміти використання](/docs/usage-limits).
