Коли обліковий запис досягає ліміту використання (його часто називають rate limit), є два варіанти: дочекатися скидання ліміту або просто зараз продовжити ту саму розмову в іншому своєму обліковому записі. З ccam другий варіант займає одну команду, `ccam next --auto --continue`, якщо історія розмов спільна для облікових записів.

## Які ліміти має Claude Code?

У планах Pro і Max Claude Code має [5-годинний ліміт сеансу й тижневий ліміт](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan). Обидва ліміти спільні з Claude у браузері та застосунках, і використання зараховується до обох одночасно. Коли один із них вичерпано, Claude Code [показує повідомлення](https://code.claude.com/docs/en/errors#youve-hit-your-session-limit) на зразок «You've hit your session limit · resets 3:45pm». Зміна моделі не допоможе, бо ліміти діють на всі моделі.

## Варіант 1: дочекатися скидання

Якщо обліковий запис один, зачекайте. Останні версії Claude Code [чекають у відкритому сеансі](https://code.claude.com/docs/en/interactive-mode#wait-for-a-usage-limit-to-reset) і самі продовжують завдання після скидання ліміту. `/usage` у Claude Code показує, яку частину лімітів вашого плану ви вже використали.

## Варіант 2: одразу продовжити в іншому обліковому записі

Якщо у вас є другий обліковий запис, можна одразу продовжити ту саму розмову. Налаштуйте все один раз:

```sh
curl -fsSL https://ccam.dev/install.sh | sh
ccam add personal
ccam add work
ccam share personal --history on
ccam share work --history on
ccam statusline install
```

Тепер під час роботи рядок стану показує обліковий запис і його використання за 5 годин, тож ліміт не стане несподіванкою.

Коли ліміт досягнуто, вийдіть із Claude Code (`/exit`), а потім виконайте:

```sh
ccam usage
```

```console
 1 personal  ████████ 100% 22m       █████░░░  68% 1d 9h     just now
 2 work      █░░░░░░░   8% 4h 12m    ██░░░░░░  19% 5d 2h     just now
```

Відкрийте розмову в обліковому записі, де найбільше запасу:

```sh
ccam next --auto --continue
```

Claude Code запуститься як `work` з останньою розмовою поточної теки, включно з усім, що було сказано досі.

## Чи перемикає ccam облікові записи автоматично?

Ні. Поки ви працюєте, ccam не запущено: він запускає Claude Code і замінює себе ним. Коли перемикатися, вирішуєте ви, а `ccam next --auto` вибирає обліковий запис із найменшим використанням за 5 годин і пропускає ті, що мають 100% або в які не виконано вхід. Деякі інші інструменти натомість підміняють вхід у запущеному сеансі; у чому різниця, пояснює стаття [ccam та інші перемикачі облікових записів](/compare/account-switchers).

## Що варто врахувати

- Виконуйте `ccam next --continue` у тій самій теці, де працювали; розмови зберігаються окремо для кожної теки проєкту.
- Не запускайте два облікові записи на одній розмові одночасно. ccam попередить, якщо ви спробуєте.
- Інший обліковий запис теж має спільно використовувати історію розмов, до того ж у тій самій групі.
- Перше повідомлення в новому обліковому записі може використати більше ліміту, ніж зазвичай, бо цей обліковий запис ще не має розмови в кеші.
- Чи можна так перемикатися між обліковими записами, залежить від умов кожного облікового запису.

Усі параметри `ccam usage` і `ccam next` описано в розділі [ліміти використання](/docs/usage-limits).
