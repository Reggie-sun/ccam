Додайте кожен обліковий запис командою `ccam add`, а потім запускайте Claude Code командою `ccam <name>` або короткою командою з назвою, яку ви вибираєте самі, наприклад `ccwork`. Більшості цього достатньо.

Уже користуєтеся Claude Code? Перш ніж почати, прочитайте розділ [Уже користуєтеся ~/.claude?](#already-using-claude) наприкінці цієї сторінки.

## 1. Додайте перший обліковий запис

```sh
ccam add
```

Майстер запитує назву, наприклад `personal` або `work`, які елементи обліковий запис має спільно використовувати з іншими вашими обліковими записами і чи створити коротку команду (див. крок 3). Потім він виконує `claude auth login`, що відкриває браузер, щоб ви могли увійти. На віддаленій машині ваш браузер може опинитися на сторінці `http://localhost:…/callback`, яка не завантажується; вставте цю адресу в термінал, і ccam завершить вхід. Коли вхід завершиться, ви побачите:

```console
✓ personal (me@example.com) added
  no shortcut (add one with `ccam shortcut personal ccpersonal`)
```

## 2. Перенесіть наявні налаштування

Якщо ви вже користувалися Claude Code, ваші налаштування, `CLAUDE.md` і розширення містяться в `~/.claude`, а сервери MCP — у `~/.claude.json`. Скопіюйте їх до спільної групи `default`, щоб вони були в кожному обліковому записі:

```sh
ccam migrate
```

ccam показує, що він скопіює, і спершу запитує дозволу. Він лише читає `~/.claude`, ніколи не копіює дані входу й не переносить історію розмов, якщо ви не додасте `--history`. Подробиці див. у розділі [копіювання наявного налаштування](/docs/sharing#copy-an-existing-setup).

## 3. Додайте другий обліковий запис

```sh
ccam add work
```

Майстер пропускає назву, яку ви вказали в командному рядку, і показує групи, до яких можна приєднатися, з позначеною `default`. Цього разу дайте обліковому запису власну коротку команду, наприклад `ccwork`, щоб запускати його одним словом. Після вибору груп майстер запитує:

```console
 Create a shortcut command for work? [y/N]
 A command such as ccwork that opens Claude Code as this account.
```

Натисніть `y`, а потім введіть назву або натисніть Enter, щоб прийняти запропоновану:

```console
 Shortcut name [ccwork]: █
 a-z, 0-9, '.', '-' and '_'; Enter alone uses ccwork
```

Потім увійдіть у браузері з іншим обліковим записом. ccam підтверджує обліковий запис і його коротку команду:

```console
✓ work (work@example.com) added
  shortcut: ccwork
```

## 4. Перемикання облікових записів

`ccam work` запускає Claude Code від імені робочого облікового запису. Якщо ви пропустили запитання про коротку команду, її можна додати будь-коли:

```console
$ ccam shortcut work ccwork
✓ shortcut for work: ccwork
```

Тепер кожна з цих команд запускає Claude Code від імені робочого облікового запису (`2` — його номер у `ccam list`):

```sh
ccwork
ccam work
ccam 2
```

Якщо запустити лише `ccam`, відкриється [панель керування](/features/dashboard): перейдіть до облікового запису клавішами зі стрілками або його номером, а потім натисніть Enter.

Усе, що стоїть після короткої команди або назви облікового запису, передається в Claude Code без змін, тож ви й далі користуєтеся звичними параметрами:

```sh
ccwork --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | ccwork -p "what caused this?"
```

## 5. Виберіть, що спільно використовувати

За замовчуванням між обліковими записами спільно використовуються сервери MCP, `settings.json`, глобальний `CLAUDE.md` і розширення (агенти, команди, навички та плагіни) через групу `default`. Історія розмов не є спільною. Додайте її до групи, якщо хочете продовжувати розмови між обліковими записами:

```sh
ccam group set default --add history
```

ccam показує, що він перемістить для кожного облікового запису, перш ніж щось змінити. Подробиці див. у розділі [спільне використання через групи](/features/share).

## 6. Коли обліковий запис досягає ліміту

```sh
ccam usage
ccam next --continue
```

`ccam usage` показує 5-годинне та тижневе використання всіх облікових записів. `ccam next --continue` відкриває ту саму розмову в наступному обліковому записі. У скриптах `ccam --fallback work -p "…"` перемикається сам. Див. [ліміти використання](/docs/usage-limits).

**Місця в планах Team і Enterprise.** Автоматичний вибір облікового запису (`ccam next`, `--fallback`, `ccam pick`, `n` на панелі керування, а також, щойно ви його ввімкнете, [`auto_switch`](/features/next#auto-switch)) також перемикає між місцями однієї організації Claude Team або Enterprise, що може порушувати умови Anthropic. Прочитайте [FAQ](/docs/faq#am-i-allowed-to-use-several-claude-code-accounts) і уточніть це у своїй організації та в Anthropic, перш ніж на нього покладатися.

## Уже користуєтеся ~/.claude?

Зареєструйте її замість повторного входу:

```sh
ccam import
```

Тека залишається там, де вона є, а звичайний `claude` працює як і раніше.
