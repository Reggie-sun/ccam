Додайте кожен обліковий запис командою `ccam add`, а потім запускайте Claude Code через `claude1`, `claude2` або `ccam <name>`. Більшості людей більше нічого не потрібно.

## 1. Додайте перший обліковий запис

```sh
ccam add
```

Майстер запитує назву, наприклад `personal` або `work`, і які елементи обліковий запис має спільно використовувати з іншими вашими обліковими записами. Потім він виконує `claude auth login`, що відкриває браузер, щоб ви могли увійти. Після завершення ви побачите:

```console
✓ personal (me@example.com) added — shortcut: claude1
```

ccam виводить власні повідомлення англійською мовою; команди й параметри однакові для всіх мов.

## 2. Додайте другий обліковий запис

```sh
ccam add work
```

Увійдіть у браузері з іншим обліковим записом. Він стане `claude2`.

## 3. Перемикайтеся

Будь-яка з цих команд запускає Claude Code від імені робочого облікового запису:

```sh
claude2
ccam work
ccam 2
```

Усе, що стоїть після назви облікового запису, передається в Claude Code без змін, тож ви й далі користуєтеся знайомими параметрами:

```sh
ccam work --resume
ccam work -p "fix the failing test" --output-format json
cat error.log | claude2 -p "what caused this?"
```

Якщо виконати `ccam` без аргументів, відкриється вибір облікового запису: використовуйте клавіші зі стрілками та Enter або натисніть номер облікового запису.

## 4. Виберіть, що спільно використовувати

За замовчуванням між обліковими записами спільно використовуються сервери MCP, `settings.json`, глобальний `CLAUDE.md`, а також агенти, команди, навички та плагіни. Історія розмов не є спільною. Увімкніть її для обох облікових записів, якщо хочете продовжувати розмови між ними:

```sh
ccam share personal --history on
ccam share work --history on
```

ccam показує, що він перемістить, перш ніж щось змінити. Подробиці див. у розділі [спільне використання](/docs/sharing).

## 5. Коли обліковий запис досягає ліміту

```sh
ccam usage
ccam next --continue
```

`ccam usage` показує 5-годинне та тижневе використання всіх облікових записів. `ccam next --continue` відкриває ту саму розмову в наступному обліковому записі. Див. [ліміти використання](/docs/usage-limits).

## Уже користуєтеся ~/.claude?

Зареєструйте її замість повторного входу:

```sh
ccam import
```

Тека залишається там, де вона є, а звичайний `claude` працює як і раніше.
