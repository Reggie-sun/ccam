`ccam` без аргументів відкриває повноекранну панель керування, коли стандартне введення й виведення є терміналом; інакше він виводить `ccam list`. Панель показує кожен обліковий запис із його використанням і групами та робить те саме, що й команди: запускає, додає, виконує вхід, змінює групи, задає правила тек, перевіряє й виправляє. Запуск закриває панель; додавання облікового запису або вхід ненадовго віддають термінал і потім повертаються до неї.

```console
 ccam v0.9.0 · 3 accounts · 2 groups         ✔ default · ▸ this folder · • running

  Accounts   Groups   Folders   Extensions   Health

    # Account     Email             5-hour         7-day Last  Groups
 ❯ 1. personal ✔   me@example.com    █████▊░░  72%   41% 2h    default
   2. work      ▸• dev@company.com   ██░░░░░░  25%  100% now   default team
   3. side         -                 ✘ not logged in         -     no group

 ✔ personal is the default account
 enter to launch · n for most room · a to add · s for groups · ? for shortcuts
```

Перший кадр малюється лише з `config.toml`, значно швидше ніж за 100 мс; використання з'являється в міру того, як відповідає кожен обліковий запис. Відсоток стає жовтим від 80% і червоним на 100%, а значення з кешу після невдалого запиту показано блідим кольором.

## Вкладки

| Вкладка | Що показує | Клавіші |
| --- | --- | --- |
| Accounts | номер, назву, адресу електронної пошти, 5-годинну смугу, 7-денне використання, останнє використання, групи; `✔` обліковий запис за замовчуванням, `▸` обліковий запис цієї теки, `•` запущений | нижче |
| Groups | кожну групу, що вона спільно використовує, її облікові записи, а також облікові записи без групи | `enter` змінити, `n` нова, `e` перейменувати, `x` видалити |
| Folders | правила [`ccam folder`](/features/folder) і те, яке діє тут | `n` використовувати обліковий запис тут, `enter` змінити, `x` видалити |
| Extensions | те, що показує [`ccam ext`](/features/ext): кожне розширення один раз разом із групами, з яких воно походить | `r` перезавантажити |
| Health | те, про що повідомляє [`ccam doctor`](/features/doctor) | `f` виправити (`doctor --fix`) |

`←`/`→` або `Tab` перемикають вкладки, `?` показує клавіші поточної вкладки, `r` знову запитує використання в обхід короткочасного кешу, а `q` або `Esc` закриває панель.

## Клавіші на вкладці Accounts

| Клавіша | Дія |
| --- | --- |
| `Enter` | Запустити Claude Code від імені вибраного облікового запису |
| `1`–`9` | Перейти до облікового запису з цим номером; щоб перейти до 12, швидко введіть `1` `2`. Запускає лише `Enter` |
| `↑`/`↓`, `k`/`j` | Переміщення |
| `n` | Запустити обліковий запис, який вибрав би [`ccam next --auto`](/features/next) |
| `o` | Запустити з параметрами: `--continue`, `--resume`, інші аргументи або пробний запуск |
| `u` | Подробиці використання: 5-годинне, 7-денне вікна та вікна моделей із часом скидання й джерелом чисел |
| `a` | Додати обліковий запис (майстер нижче) |
| `l` | Знову виконати вхід |
| `s` | Вибрати групи облікового запису |
| `d` | Зробити його обліковим записом за замовчуванням |
| `f` | Використовувати його в поточній теці |
| `e` | Перейменувати його |
| `c` | Задати або видалити його коротку команду |
| `x` | Видалити його (спершу запитує, курсор стоїть на No) |

## Зміна груп

На вкладці Groups клавіша `Enter` відкриває редактор: елементи ліворуч, облікові записи праворуч, `Tab` перемикає між ними, `Space` вмикає або вимикає. Елемент, який один з облікових записів уже отримує з іншої групи, показано сірим разом із причиною; так само показано обліковий запис, який отримав би елемент двічі. Елемент може надходити лише з однієї групи. `Enter` показує план:

```console
 ──────────────────────────────────────────────────────────────────────────────
  Groups of side

  ● side  +history (group team)
    ⎿  link     projects, history.jsonl: profiles/side → groups/team

  Do you want to apply this plan?
  ❯ 1. Yes
    2. No
```

Про файл, який відрізняється від копії групи, спершу запитують (залишити версію групи, використати мою або об'єднати). Потім зміна виконується у фоновому режимі тим самим кодом, що й [`ccam group`](/features/share): спершу зберігається конфігурація, далі дані кожного облікового запису переміщуються по черзі, а оригінали потрапляють до `.ccam-backup/`. Зміну, яка перемістила б дані запущеного облікового запису, буде відхилено з назвою цього облікового запису.

## Додавання облікового запису

`a` відкриває майстер, який `ccam add` також використовує в терміналі:

1. Назва облікового запису.
2. Спосіб входу: підписка Claude зараз (у браузері), [ключ API](/features/api) або підписка Claude пізніше.
3. Для ключа API: звідки ccam читає ключ під час кожного запуску (`env:NAME` або `command:COMMAND`), кінцева точка, спосіб надсилання ключа й модель.
4. Групи, до яких потрібно приєднатися, з позначеною `default`; поки груп немає, — що спільно використовує група `default`.
5. Коротка команда, якщо вона вам потрібна.
6. Підсумок для підтвердження.

`Esc` повертає на крок назад, а на першому кроці закриває майстер.

## Кольори

Кольори відповідають ролям у терміналовому інтерфейсі Claude Code, тож ccam виглядає поруч із ним природно; назви груп отримують колір залежно від самої назви. ccam запитує в термінала колір його тла й вибирає світлу або темну тему. Задати тему самостійно можна в `config.toml`:

```toml
theme = 'dark'   # auto (default), dark, light, dark-daltonized, light-daltonized, dark-ansi, light-ansi
```

Теми `-daltonized` призначені для людей із червоно-зеленою колірною сліпотою, а теми `-ansi` використовують власні 16 кольорів термінала. `NO_COLOR` вимикає кольори.

## Безпека та граничні випадки

- Панель викликає ті самі функції, що й команди, тож діють усі правила: план перед переміщенням даних, відмова для запущених облікових записів, резервні копії та токени входу, які ніколи не залишають обліковий запис.
- Панель не має пробного запуску: `ccam --dry-run` без назви виводить, як запуститься обліковий запис цієї теки, а `o` на обліковому записі пропонує виконати в пробному режимі лише цей один запуск.
- Термінал відновлюється перед тим, як запускається Claude Code або відкривається вхід.
- Якщо екран замалий для діалогу, спершу зникають рядки вкладки; рядки обрізаються з `…`, а не переносяться.
